## 文件命名规范

- **国赛论文**：`年份+题号_题目名称_队伍XXX.pdf`
  - 例：`2021A题_FAST主动反射面形状调节_队伍A028.pdf`
- **APMCM论文**：`年份APMCM_题号_队伍XXX.pdf`
  - 例：`2022APMCM_A题_队伍A001.pdf`
- **赛题**：`年份+题号_题目名称_赛题.pdf`
- **赛题评述**：`年份+题号_题目名称_赛题评述_主讲人.pdf`
- **分析文档**：`类型_说明.md`
