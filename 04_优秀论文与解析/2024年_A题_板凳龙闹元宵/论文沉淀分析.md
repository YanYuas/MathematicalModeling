# 2024 国一论文沉淀分析 —《基于改进牛顿法的舞龙队轨迹问题》

> 赛题：2024 高教社杯 CUMCM **A 题"板凳龙"**
> 选题类型：运动学建模 + 非线性方程组迭代求解 + 碰撞检测（分离轴定理）+ 优化 + 网格遍历
> 核心工具链：极坐标/直角坐标转换、阿基米德螺线弧长积分、改进牛顿法、速度分解、SAT 分离轴定理、粗细网格遍历

---

## 一、论文定位与整体判断

这是一篇"**几何运动学 + 数值求解 + 工程寻优**"三合一的国一论文。亮点不是单一模型的惊艳，而是**把 5 个问题串成一条完整的技术链**，且每个环节都给出了"为什么这样算"的论证。

**一句话主线**：用阿基米德螺线弧长积分反解龙头位置 → 用"板凳长度距离约束 + 改进牛顿法"迭代出全部板凳位置 → 用"速度分解"递推各板凳速度 → 用"分离轴定理"判断碰撞 → 用"粗细网格遍历"求解 4 个不同优化目标（终止时刻、最小螺距、调头曲线最短、最大速度）。

| 问题 | 优化/求解目标 | 核心方法 | 关键结果 |
|------|-------------|---------|---------|
| 问题一 | 0~300s 每秒位置速度 | 弧长积分反解 + 改进牛顿法 + 速度分解 | 位置/速度表，灵敏度：速度比定值 |
| 问题二 | 首次碰撞终止时刻 | SAT 碰撞判断 + 粗细网格遍历 | **412.474s** |
| 问题三 | 最小螺距 | SAT + 粗细网格遍历 | **41.713cm** |
| 问题四 | 调头曲线最短 | 极角决策变量 + 相切/中心对称约束 | 两圆弧调头方案，-100~100s 位置速度 |
| 问题五 | 最大龙头速度 | 速度约束优化 | 所有把手 ≤2m/s 下的最大 v0 |

## 二、建模思路主线（逐段拆解）

### 2.1 问题重述与五问拆解

板凳龙：223 节板凳首尾相连，龙头板长 341cm、龙身/龙尾 220cm、板宽 30cm，把手孔径 5.5cm，孔心距板头 27.5cm。

- 问题一：等距螺线（阿基米德螺线）盘入，龙头前把手 1m/s，求 0~300s 每秒整队位置与速度
- 问题二：把"即将碰撞时刻"作为盘入终止时刻，求此时位置速度
- 问题三：直径 9m 调头区，求最小螺距使龙头前把手沿螺线盘入边界
- 问题四：两段圆弧相切调头（盘入半径 = 2 × 盘出半径），调整圆弧使调头曲线最短，求 -100s~100s 位置速度
- 问题五：沿问题四路径，龙头速度不变，求各把手 ≤2m/s 下的最大龙头速度

### 2.2 问题一：位置模型 + 速度模型

**关键洞察 1 — 把手位置在螺线上**：题目已保证"所有把手中心位于螺线上"，因此龙头位置 = 螺线上弧长为 $v_0 t$ 的点。

**螺线弧长积分（数学亮点）**：
$$r=b\theta,\quad L=\int_{\theta_1}^{\theta_2}\sqrt{1+\left(\frac{dr}{d\theta}\right)^2}\,d\theta$$
对阿基米德螺线 $r=b\theta$ 有闭式原函数：
$$L=\frac{b}{2}\Big[\theta\sqrt{1+\theta^2}+\ln\big(\theta+\sqrt{1+\theta^2}\big)\Big]\Big|_{\theta_1}^{\theta_2}$$
于是 $l=v_0t$ → 反解 $\theta$ → 得龙头每时刻位置 $(x,y)=(b\theta\cos\theta,\;b\theta\sin\theta)$。

> 教学点：**先找问题的"解析解可逆部分"**。弧长有闭式积分，龙头位置可解析反解，避免纯数值积分，这是打底。

**关键洞察 2 — 板凳位置靠距离约束迭代**：相邻板凳孔心距离固定（$d_0=(341-27.5\times2)\times10^{-2}$m，$d_n=(220-27.5\times2)\times10^{-2}$m），即
$$(x_{n+1}-x_n)^2+(y_{n+1}-y_n)^2=d_n^2$$
且 $x_n=b\theta_n\cos\theta_n,\;y_n=b\theta_n\sin\theta_n$（都在螺线上）。每步求下一个 $\theta_{n+1}$，用**改进牛顿法**解这个非线性方程。

**改进牛顿法四件套**（这篇的命名亮点）：
1. **割线近似切线**：用差分 $\frac{f(x_n+dx)-f(x_n)}{dx}$ 近似 $f'(x_n)$，避免手算导数
2. **强制首步控制**：首步用 $x_0=\theta_n$ 后强制跨出初始步长
3. **小步长搜索**：跨出步长不超过上限 $p$（$x_2=x_1+\min(|dxf(x)|,p)$）
4. **负向重搜机制**：若迭代越界（$x_{n+1}>\theta_n$ 不满足单调），自动回退重搜

> 教学点：**牛顿法遇到工程性困难（导数难求、迭代越界、多解）时的标准补丁**，论文把它们系统化命名并逐一解决，这是"数值方法成熟度"的直接体现。

**关键洞察 3 — 速度分解（运动学核心）**：板凳是刚体，相邻两板通过把手连接，**两板沿连接方向的速度分量相同**：
$$v_{n-1}\cos\varphi_{n-1}=v_n\cos\varphi_n \;\Rightarrow\; v_n=\frac{\cos\varphi_{n-1}}{\cos\varphi_n}v_{n-1}$$
其中 $\varphi$ 是板凳方向与径向的夹角。从龙头 1m/s 逐条递推到龙尾。

**灵敏度分析**：同一舞龙队位置下，龙头把手速度与其他各点速度比值为定值（比例系数只依赖几何构型，与速度大小无关）。

### 2.3 问题二：碰撞判断 + 首次碰撞时刻

**关键洞察 — 板凳不是点，是矩形**：碰撞不是把手撞把手，而是**整块板凳矩形**之间是否相交。

- 由把手中心坐标 + 板长、板宽、把手偏心距，算出每个板凳矩形 4 个顶点 A/B/C/D（式 32）
- **分离轴定理（SAT）**判断两矩形是否碰撞：对每个候选分离轴（边法向），把两矩形顶点投影到轴上，若所有轴上投影区间都重叠 → 相交

**粗细网格遍历求终止时刻**：
```
Step1  粗搜索：[0m, 442m] 步长 1m 扫
Step2  定位碰撞区间 [411m, 413m]
Step3  细搜索：0.001m 步长
Step4  得 412.474m → 412.474s
```

> 教学点：**"先粗扫定位 + 细扫定值"的两阶段网格遍历**，是替代纯二分/纯搜索的工程技巧，计算量可控且结果精确到 0.001。

### 2.4 问题三：最小螺距

核心矛盾：**越靠近螺线中心，板凳越容易碰撞**（曲率大，相邻板挤压）。约束 = 龙头前把手能沿螺线盘入直径 9m 调头区边界 + 全队不碰撞。对每个候选螺距 b 跑一遍碰撞判断，求最小可行 b = 41.713cm。

### 2.5 问题四：调头曲线最短

**几何重构**：
- 调头路径 = 两段圆弧相切连接（盘入半径 2r、盘出半径 r，圆心距 $d_{o_1o_2}=3r$）
- 螺线分内/外两段（问题四后龙先沿螺线盘入，再沿反向螺线盘出）

**决策变量**：切入点与切出点的**极角 $\theta$**（利用"切入切出点极角相等"的几何关系降维）

**约束**：调头空间范围、盘入/盘出曲线**中心对称**、各部分**相切**、板凳**刚体约束**、**碰撞判断**。

**求解**：仍用改进牛顿法求每条板凳位置 + SAT 判碰撞 + 网格遍历。

### 2.6 问题五：最大龙头速度

$$v_n(t)<2\text{m/s}$$
以龙头速度 $v_0$ 为决策变量，约束所有把手速度 ≤2m/s。**关键转机**：问题一的灵敏度分析已证明"同构型下各把手与龙头速度比是定值"，所以不用重新仿真，直接查**最大速度比** $k_{\max}$：
$$v_{0\max}=\frac{2}{k_{\max}}$$
本问调头路径上最大速度比 $k_{\max}\approx4.441$（调头圆弧 2r 段外侧把手走更大弧、速度最高），故最大龙头速度 $v_{0\max}=2/4.441\approx0.45$m/s，并代入原模型验证。

> 教学点：**前面问题做的灵敏度分析，后面问题直接当定理用**。这是全篇最漂亮的一处"模型复用"——问题五没有重跑整条链，而是从不变性一步到位，还反向证明了灵敏度分析的价值。

## 四、论文语言与结构分析

### 4.1 结构骨架

```
摘要（总述 + 按问题一~五分段 + 方法贡献总结 + 关键词）
一、问题重述（1.1 背景 / 1.2 五问）
二、问题分析（2.1~2.5 逐问分析，定方法路线）
三、模型假设（5 条）
四、符号说明（表格）
五~九、逐问模型（各含：模型建立 → 求解算法 → 结果 → 灵敏度分析）
十、模型的推广应用（跨领域推广）
参考文献 + 附录（MATLAB 代码，~56 页）
```

**结构差异点（vs 2007 公交论文）**：本篇**没有独立的"模型评价/优缺点分析"节**，只有"模型的推广应用"。优点是把篇幅全给了模型与求解；缺点是缺少对方法局限性的自省（2007 公交论文 5.4 分算法列优缺点就更好）。可学点：国一新论文靠"推演完整性"得分，但加一小节"模型评价与改进"更稳。

### 4.1.5 摘要关键数字速查

| 问题 | 关键结果 |
|------|---------|
| 二 | 终止时刻 **412.474s**（粗细网格遍历，先 1m 后 0.001m） |
| 三 | 最小螺距 **41.713cm**（先 1cm 后 0.001cm） |
| 四 | 极角 >6.3rad 不再碰撞；切入/切出极角 **15.32rad**；调头曲线长 **12.51m**；较调整前优化 **8.15%** |
| 五 | 最大速度比 4.441 → 最大龙头速度 **0.45m/s** |

### 4.2 摘要写法

**总述段**：一句话点技术全家桶——"基于板凳运动中的刚体限制、板凳之间碰撞情况等约束，利用**速度分解、分离轴定理、改进牛顿法、粗细网格遍历**对不同优化目标下舞龙队的位置和速度进行了求解。"

**逐问段**（每问固定句式）：
```
针对问题X，以[目标]为优化/求解目标，[建模方法]，结合[约束]，使用[求解算法]，求得[关键结果+单位]。
```
例："问题二……以最大化终止时刻为优化目标……建立基于分离轴定理的板凳碰撞判断模型……使用粗细网格遍历求解了舞龙队盘入的终止时刻为 **412.474s**。"

> 教学点：摘要把每个问题压成"目标 + 方法 + 结果"一行，评委 30 秒内就能抓全 5 问的方法链与 3 个关键数字（412.474s / 41.713cm / 0.45m/s）。

**摘要结尾还有一段"方法贡献总结"**（很多论文没有）：
> "本文利用数学方法求解积分原函数，避免了反解积分函数的问题。通过对牛顿法进行改进，把有约束优化问题转化为无约束方程问题。利用分离轴定理，准确且快速地判断图形碰撞关系。使用粗细网格遍历，提高精度的同时减少了计算量。对模型引入刚体约束与碰撞约束，符合实际情况。"

把 4 个核心技术手段 + 每个手段解决的问题，一句话一条点出来。这种"技术贡献清单式"收尾，比泛泛"本模型具有较强实用价值"有力得多。

### 4.3 语言风格特征

1. **逐问自闭环**：五个问题各自"分析→建模→求解→结果→灵敏度"，第 4 问内部甚至分 4 种曲线情况分别建模，工程严谨
2. **推导全展开**：弧长积分 $\int\sec^3u\,du$、牛顿法改进、圆弧参数方程都一步步推，不跳步
3. **物理解释先行**："本文认为由于螺距增大……曲率变小，导致速度衰减变小""阶梯型的平整处限制终止时刻的主要因素应为板宽"——不只给结果，还给**物理直觉**
4. **方法命名工程化**："改进牛顿法"下辖四件套（割线近似/强制首步/小步长/负向重搜），像软件模块一样编号
5. **计算简化有理由**：碰撞检测只判"第一龙身+龙头 vs 其他""极角差<4π"，均给出对称性依据
6. **模型名可复用**：把手位置模型、速度求解模型、顶点计算模型、碰撞判断模型、调头曲线优化模型——名词链清晰

### 4.4 可复用写作模板

**逐问建模段**：
```
[情景] 本文以[目标]为目标，根据[物理/几何关系]建立[模型名]。
引入[变量/坐标系]，[推导公式过程]。
约束：[几何约束] 需满足[条件]，即式(N)。
求解：使用[算法] 求[目标]，Step1~StepN。
结果：得[X] = [数值][单位]。
灵敏度：[参数]变化对[目标]的影响为[趋势]，本文认为原因是[物理解释]。
```

### 4.5 一个值得模仿的细节：分段无解回退

问题四舞龙队跨 4 段曲线，作者把位置模型写成**四情形分支**：先假设在圆弧段联立方程，**若联立无解则回退到上一段**（"若上述联立方程无解，则说明……位于……"，p22 原文）。这种"优先段 + 无解回退"的分段定位算法，把复杂多段路径分解成递归可判定的情形，是数值稳健性的典型写法。

## 六、可复制到下一场比赛的清单

1. **解析优先**：先找闭式解（弧长积分），再上数值方法
2. **牛顿法工程化**：遇到导数难求/越界/多解，用割线近似 + 步长控制 + 重搜
3. **碰撞检测用成熟几何算法**：矩形相交用 SAT，不要自己发明 O(n²) 交点判定
4. **网格遍历先粗后细**：避免纯搜索计算爆炸
5. **降维决策变量**：用几何关系（极角相等、中心对称）减少优化变量
6. **灵敏度分析收尾**：验证模型稳定性，还能反哺后续问题
