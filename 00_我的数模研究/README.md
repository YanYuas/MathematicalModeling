# 我的数模研究

数学建模方法体系知识库，按专题分类整理，每个专题包含理论课件、代码模板、例题实战和参考文献。

## 专题体系

| 编号 | 专题 | 核心内容 | 竞赛出现频率 |
|------|------|----------|-------------|
| 01 | 优化模型 | 线性/整数/非线性规划、动态规划、启发式算法 | ★★★★★ |
| 02 | 方程与动力学模型 | 微分方程、差分方程、PDE、传染病模型 | ★★★★☆ |
| 03 | 评价与决策模型 | AHP、模糊综合、TOPSIS、熵权法、灰色关联 | ★★★★★ |
| 04 | 预测模型 | 回归、时间序列、灰色预测、神经网络、马尔可夫 | ★★★★★ |
| 05 | 统计与数据分析 | 回归、聚类、判别、PCA、假设检验 | ★★★★☆ |
| 06 | 图论与网络模型 | 最短路、最小生成树、最大流、TSP、匹配 | ★★★☆☆ |
| 07 | 插值与数据拟合 | 拉格朗日、样条插值、最小二乘拟合 | ★★★☆☆ |
| 08 | 概率与随机模型 | 蒙特卡洛、排队论、库存模型、马尔可夫链 | ★★★☆☆ |
| 09 | 机器学习与智能算法 | 神经网络、SVM、随机森林、遗传算法、粒子群 | ★★★★☆ |
| 10 | 模糊数学模型 | 模糊综合评价、模糊聚类、模糊模式识别 | ★★★☆☆ |
| 11 | 灰色系统模型 | GM(1,1)预测、灰色关联分析、灰色聚类 | ★★★☆☆ |

## 收集资料的渠道

- **中国大学MOOC**：https://www.icourse163.org （搜索"数学建模"）
- **B站**：搜索"数学建模 清风"、"数学建模 国赛"等
- **知乎**：搜索"数学建模 算法 汇总"

### 代码资源
- **GitHub**：搜索 "mathematical-modeling"、"数模 代码模板"
- **CSDN/博客园**：各类算法实现代码
- **MathWorks File Exchange**：MATLAB官方代码库

### 论文资源
- **知网**：搜索"数学建模 优秀论文"
- **全国大学生数学建模竞赛官网**：http://www.mcm.edu.cn
