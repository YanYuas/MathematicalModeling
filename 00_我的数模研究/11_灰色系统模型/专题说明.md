# 11 灰色系统模型

## 专题简介
处理"小样本、贫信息"的不确定性问题，核心是灰色预测GM(1,1)模型，是数模竞赛中非常实用的工具。

## 核心方法清单
- **灰色预测**：GM(1,1)、GM(1,N)、DGM(1,1)、Verhulst模型
- **灰色关联分析**：关联系数、关联度、优势分析
- **灰色聚类**：灰色变权聚类、灰色定权聚类
- **灰色决策**：灰色局势决策、灰色层次决策
- **灰色控制**：灰色预测控制

## 适用场景
小样本预测（数据量<20）、系统分析、因素关联分析、决策评估

## 需要收集的资料
- [ ] 灰色系统理论课件
- [ ] MATLAB/Python 代码模板（GM(1,1)、灰色关联分析）
- [ ] GM(1,1)模型检验方法（残差检验、关联度检验、后验差检验）
- [ ] 不同灰色预测模型的适用场景对比
- [ ] 经典例题（人口预测、销量预测、经济预测）

## 方法选择速查
- 数据量少（4-10个）且呈指数增长 → GM(1,1)
- 数据呈S形（饱和增长）→ Verhulst模型
- 多因素影响的预测 → GM(1,N)
- 因素间关联程度分析 → 灰色关联分析

## 注意事项
- GM(1,1)适合短期预测，长期预测误差大
- 使用前需做级比检验，判断数据是否适合建模
- 常与其他预测方法组合使用
