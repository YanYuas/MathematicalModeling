## 二、建模手方法论深度拆解

### 2.1 题设逐词点透法（全解总览的核心技巧）

**模板**：把题目原文逐词拆解，每个词分析"字面意思"和"点透（为什么重要）"。

**实际案例**（Q1题设拆解）：

| 词 | 字面 | 点透（为什么重要） |
|---|---|---|
| "轮廓不固定" | 无预定义外框 | 面积是可优化目标而非硬约束 → 成本函数以面积为主项 |
| "没有连接关系" | 无线网无HPWL | Q1只需.blocks的block行，.nets/.pl完全无用 → 退化为纯几何装箱 |
| "面积最小" | 主目标min(W·H) | 面积下界=模块总面积，死区=(W·H−A)/W·H，主目标=压死区 |
| "面积相同" | 副目标生效条件 | 词典序：面积优先，长宽比只在面积相等时生效 |
| "长宽比接近1" | 副目标min\|R−1\| | R定义必须自洽（陷阱T1），等周重述=等面积下周长最小 |

**可复用话术**：
> "XX的字面意思是YY，但更深层的含义是ZZ——这决定了我们的建模方向是..."

**为什么有效**：评阅老师看论文时，最欣赏的就是"你真的读懂了题目"。逐词点透展示了对题目的深刻理解，而不是上来就套模型。

### 2.2 假设系统化法（H1-H4分级）

**模板**：把假设分成4大类，每类每条假设都带"若违背的后果"和"论文写法"。

**实际案例**：

```
H1 几何假设
  H1.1 轴对齐：块边平行轮廓边，仅90°旋转
    若违背：任意角装箱是不同问题，结果不可比
    论文写法：显式声明"仅考虑轴对齐矩形布图"
  H1.2 刚性块：hard block，面积/尺寸不可变
    若违背：若软块可缩放 → 下界失效
    论文写法："模块为硬块（尺寸固定）"

H2 问题结构假设
  H2.1 Q1无连接：无.nets/.pl参与
    若违背：混入HPWL → 变Q2，面积目标被污染
  H2.2 Terminal忽略：Terminal无连接故不参与面积/重叠
    若违背：评阅可能问"轮廓要不要包住terminal坐标"
    → 假设节必须声明！

H3 计算假设
  H3.1 面积守恒：旋转不改面积
    后果：面积目标"退化"（SA梯度弱）→ 用min-max目标缓解

H4 报告假设
  H4.1 R口径：R=max/min ≥1
  H4.2 统计口径：best-of-N + 均值/标准差
```

**可复用模板**：
```markdown
### HX XX假设
| 假设 | 内容 | 若违背的后果 | 论文写法 |
|---|---|---|---|
| HX.1 | | | |
```

**为什么有效**：数学建模=现实→假设→模型→求解→验证。假设是评阅审稿第一眼。没写清楚=被误读。每条假设带"若违背后果"展示了思考的严谨性。

### 2.3 陷阱分级法（T工程级 + M模型级）

**实际案例**：两层陷阱体系

**T系列（工程级，T1-T18）**：实现时容易踩的坑
- T1：R口径歧义（W/H还是max/min）
- T2：加权λ过大牺牲面积
- ...

**M系列（模型级，M1-M12）**：建模思路本身的陷阱

**最深的陷阱——M1面积目标的退化性**：
> 旋转不改变面积、B*-Tree压缩只减面积 → 面积在扰动下是阶梯函数（多数扰动面积不变，突变时跳变）。
> 后果：SA在平台上搜索，接受准则对"同面积"解无区分 → 收敛慢、易停。
> 对策：min-max目标Φ=max(W,H)（有"连续"的压力感）
> 论文卖点：这就是为什么"面积目标"要改成"min-max目标"的根本原因——不是口味，是SA动力学。

**可复用模板**：
```markdown
### MX. 陷阱名称（最深的陷阱）
- 现象：（什么表现）
- 后果：（导致什么问题）
- 对策：（怎么解决）
- 论文卖点：（怎么写成论文亮点）
```

### 2.4 全解总览的"一句话定位"

**模板**：文章开头用一句话说清本问本质。

**实际案例**：
> Q1 = 最小面积矩形装箱 + 长宽比次级目标。只读.blocks，无线网。NP-hard。解法 = B*-Tree + Fast-SA，配几何构造初解 + 下界论证 + 陷阱规避。

**可复用话术**：
> "本问 = [问题本质] + [次级目标]。[数据范围]。[复杂度]。解法 = [核心算法]，配[辅助技巧] + [验证方法] + [防坑措施]。"

## 三、编程手方法论深度拆解

### 3.1 每步【思路】标注法

**模板**：每个阶段开头用【思路】说明为什么这么做，不是做什么。

**实际案例**（Q2阶段0）：
```
## 阶段 0：环境与数据
【思路】这次读三个文件（Q1只读.blocks）。三条免费回归校验：
总面积179501/175696/273170、线网数885/1585/1893、终端数334/564/569
——任一不符即解析bug。hpwl.py已封装解析+评估，直接import复用，别重写。
```

**实际案例**（Q2阶段4成本函数）：
```
【思路】核心设计。公式：Φ = W/W_norm + λ·max(0,(A·R−S²)/S²)
- A·R=M²（恒等式），惩罚只在M>S激活，平滑（SA可试探逼近轮廓）；
- 为什么软惩罚非硬惩罚：inf拒绝困死SA；直接max(W−S,0)+max(H−S,0)
  大权重困局部极小、小权重得不到可行解（论文明确警告）；
- λ必须自适应：线长把块拉散→超轮廓（核心矛盾）。固定λ两难。
```

**可复用模板**：
```markdown
## 阶段N：XXX
【思路】（一句话核心洞察 + 为什么这么做 + 不这么做的后果）
- [ ] 具体任务1
- [ ] 具体任务2
```

**为什么有效**：
1. 防止"知其然不知其所以然"——写思路的过程就是理解的过程
2. 方便后续维护——半年后回来看，知道为什么选这个方案
3. 方便协作——建模手看思路就知道编程手理解对不对

### 3.2 纪律要求清单（必须遵守的规则）

**实际案例**（编程手Q1清单末尾）：
```
纪律要求（必须遵守）
1. ✅ 每步写【思路】，知其然知其所以然
2. ✅ 必须先跑验证题，验证题不对不跑正式数据
3. ✅ 报告best_so_far，不是末态
4. ✅ 固定种子+多次运行，单次结果不可信
5. ❌ 不要自行改模型假设，有问题先反馈
6. ❌ 不要删除旧代码，废弃的移到归档
7. ❌ 不要用"应该可以"代替实际运行
```

**关键纪律——best_so_far**：
> SA末态是"正在搜索的位置"不是"最好解"。必须记录best_so_far，报告它而非末态。

**关键纪律——固定种子×10次**：
> SA方差大（Cornell课程实验统计：100次中仅约70%胜过随机重启爬山），单次运行等于赌博。多次取最优+报均值才是可信结果。

### 3.3 验证题机制（已知正确答案的小问题）

**实际案例**（Q4移交包）：
```
验证题结果速查：
| 模块 | 形状 | 面积 | 顶点 |
| b1 | T | 12 | ... |
| b2 | L | 6 | ... |
总面积=24（面积下界）。最小包络=30（6×5，死区20%）

编程手复算判定标准：
| 编程手结果 | 判定 |
| = 30 | ✅ 与建模手一致，确认最优 |
| < 30 | 检查建模手是否漏候选，优先验证24/25/28/29真可行 |
| > 30 | 检查重叠检测是否误判（贴边vs重叠） |
```

**为什么有效**：验证题是"免费的回归测试"——编程手实现后先跑验证题，对了说明实现基本正确，错了说明有bug。比直接跑正式数据高效得多。

### 4.2 理论实践差距总结（最有价值的反思文档）

**实际案例**（Q1正稿v2→v3的6处翻转）：

| 维度 | v2（理论） | v3（实测） | 翻转原因 |
|---|---|---|---|
| 主算法 | 三阶段Fast-SA主搜索 | FFD target扫描+长条旋转 | SA对构造解无改进 |
| 构造初解角色 | SA初值+精修至2-5% | 确定性定解，SA仅互证 | 构造解已是邻域最优 |
| 长条处理 | 纵横比互补配对（匈牙利） | 单模块90°旋转 | 配对444→459反效果 |
| A_opt来源 | Phase1纯面积SA | FFD target扫描 | 扫描即得最优边长 |
| 温度公式 | c=100公式+87倍回升 | 几何冷却（仅互证用） | c=100在归一化下冻结 |
| 可行区间 | n200[420,440]、n300[523,538] | [420,432]、[523,533] | 建模手早期偏松，实测收紧 |

**最深的翻转——差距1：SA主搜索→构造主路径**：
> v2假设：三阶段Fast-SA为主搜索，构造FFD只作初值。理论依据：SA的Metropolis接受准则允许爬山跳出局部最优，参考论文以此在GSRC基准取得好结果。
>
> v3实测：从最终解跑20级几何冷却SA，三组best全部不降；对FFD构造树施加3×3000次三算子随机扰动，最小面积恒等于构造解面积。构造解已是SA邻域的强局部最优——SA没有改进空间，降级为稳定性验证。
>
> 翻转原因（机理）：FFD行堆叠+target扫描的构造解落在SA三算子的局部最优盆地中——三算子的单步扰动无法表达"全局重构"。参考论文的SA有效是因为其初解随机、解空间探索充分；我们的构造解太"好"，SA反而无用武之地。
>
> 教训：不要因参考论文用SA就默认SA是主路径——实测构造解质量才是判决。

## 五、反馈闭环深度拆解（最核心的协作机制）

### 5.1 反馈闭环的完整流程

```
建模手独立建模（理论推导）
    ↓
打包移交包给编程手（移交说明+清单+验证题+红线）
    ↓
编程手独立实现（按清单，每步写思路）
    ↓
编程手发现问题 → 写《理论问题反馈》
    ↓
建模手融入反馈 → 写《实践反馈融入》
    ├─ 列出验证通过的内容（保留）
    ├─ 列出被证伪的内容（否决）
    └─ 修正后的权威数字表（后续问引用）
    ↓
后续问（Q3/Q4）以修正后的理论为基础，不重复踩坑
```

## 六、参考论文精读方法论

### 6.1 论文获取与处理

**实际操作**：
1. 找到权威论文：Chen & Chang, "Modern Floorplanning Based on B*-Tree and Fast Simulated Annealing", IEEE TCAD 2006
2. 下载PDF（2.4MB）存入辅助文档
3. 提取全文文本：`ref_paper.txt`（49KB）
4. 提取关键章节：`_bstree_extracted.txt`（B*-Tree部分）

### 6.2 论文精读要点

**从论文中提取的关键信息**：

| 信息类型 | 具体内容 | 用途 |
|---|---|---|
| 算法原理 | B*-Tree表示法（有序二叉树，根=左下角） | 建模依据 |
| 温度公式 | T_n = T₁⟨Δcost⟩/(n·c)，c=100, k=7 | 编程实现 |
| 成本函数 | Cost = α·A/A_norm + (1−α)·W/W_norm | Q2建模 |
| 自适应权重 | α = α_base + (1−α_base)·(n_feasible/n) | Q2核心技巧 |
| 实验数据 | GSRC n100/n200/n300结果 | 对标真值 |
| 成功率 | 固定轮廓10%死区时100%成功率 | 可行性判断 |

### 6.3 论文方法的"批判性继承"

**关键教训**（来自理论实践差距总结）：
> 参考论文的SA有效是因为其初解随机、解空间探索充分；我们的构造解太"好"，SA反而无用武之地。
> 不要因参考论文用SA就默认SA是主路径——实测构造解质量才是判决。

**可复用原则**：
1. 论文方法要理解原理，不能照抄参数
2. 论文的实验条件可能与本题不同（初解、迭代次数、数据集）
3. 必须用本题数据实测验证，不能直接套用论文结论
4. 论文方法失效时，要分析机理，不是简单放弃
