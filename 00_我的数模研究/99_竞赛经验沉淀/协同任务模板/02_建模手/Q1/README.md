## 核心方法论模板（复盘精华）

### 模板1：题设逐词点透法（用在全解总览开头）

**目的**：展示对题目的深刻理解，评阅老师最欣赏这一点。

**模板**：
```markdown
## 题设逐词点透

> "（粘贴题目原文）"

| 词 | 字面意思 | 点透（为什么重要） |
|---|---|---|
| "XX" | 字面含义 | 更深层含义 → 这决定了建模方向是... |
| "YY" | | |

**点透结论**：（一句话总结本题的本质和三个隐藏决策）
```

**实际案例**（VLSI Q1）：
| 词 | 字面 | 点透 |
|---|---|---|
| "轮廓不固定" | 无预定义外框 | 面积是可优化目标而非硬约束 → 成本函数以面积为主项 |
| "没有连接关系" | 无线网 | Q1只需.blocks，.nets/.pl完全无用 → 退化为纯几何装箱 |
| "面积相同" | 副目标生效条件 | 词典序：面积优先，长宽比只在面积相等时生效 |

### 模板4：陷阱分级T+M（用在陷阱深挖）

**T系列（工程级）**：实现时容易踩的坑（口径/数值/边界）
**M系列（模型级）**：建模思路本身的陷阱（更深层）

**模板**：
```markdown
## 模型级陷阱深挖（M1-Mn）

### M1. 陷阱名称（最深的陷阱标出来）
- **现象**：（什么表现）
- **后果**：（导致什么问题）
- **对策**：（怎么解决）
- **论文卖点**：（怎么写成论文亮点——不是口味，是XX动力学）
```

**实际案例**（M1面积目标退化性）：
> 旋转不改变面积、B*-Tree压缩只减面积 → 面积在扰动下是阶梯函数 → SA在平台上搜索，收敛慢
> 对策：min-max目标Φ=max(W,H)
> 论文卖点：这就是为什么"面积目标"要改成"min-max目标"的根本原因——不是口味，是SA动力学

### 模板5：三层下界法（用在全解总览的数学结构部分）

**目的**：给结果可信度，"近最优"论证挂在下界上。

```markdown
## 三层下界（结果的锚）

1. **平凡下界**：A ≥ A_total（太松，但必须写）
2. **理论下界**：（如方形下界⌈√A⌉²，太紧，完美平铺才可达）
3. **工程下界**：（如固定宽下界H(W)≥max(A/W, 最长块高)，工程可用）

**点透**：下界1太松、下界2太紧、下界3才是工程可用。论文的"近最优"论证应挂在下界3上。
```
