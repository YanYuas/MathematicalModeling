## 一、参考论文映射法（复盘精华）

**目的**：站在巨人肩膀上，把优秀论文的技巧映射到本题，不是抄袭是转化。

**模板**：
```markdown
## 参考论文的核心启示（对本题的映射总表）

| 参考论文技巧 | 本质 | 本题对应 |
|---|---|---|
| （如：问题分析先定"五因素"） | 先定目标结构再建模 | （如：先定评阅目标结构：面积(主)→长宽比(副)） |
| | | |
| | | |

**一句话主线**：（用一句话说清本问论文的核心叙事）
```

**实际案例**（VLSI Q1映射2007国一）：
| 2007技巧 | 本质 | Q1对应 |
|---|---|---|
| 问题分析先定"五因素+分层序列" | 先定目标结构再建模 | 先定评阅目标结构：面积(主)→长宽比(副)，词典序 |
| 矩阵幂算最少换乘 | 先给下界再搜索 | 三层下界+方形可行区间[LB,UB] |
| 多目标分层序列法 | 免权重，字典序落地 | 词典序=min-max+面积约束 |
| 双求解器互补 | 多解与全局最优互补 | 构造初解+SA精修 |

## 二、论文骨架（每问自成闭环）

```
问题X（QX）：
  X.1 问题分析（定目标结构——对应参考论文的"先定五因素"）
  X.2 数据预处理（原始数据→模型输入）
  X.3 模型假设与符号（假设系统化H1-H4）
  X.4 模型建立（变量/目标/约束）
  X.5 算法设计（求解方法+伪代码+复杂度）
  X.6 下界与验证（结果可信度——三层下界）
  X.7 结果与分析（数据表+图+解读——不是只列数字，要说说明了什么）
  X.8 灵敏度与评价（参数影响+优缺点诚实评价）
```

**结构特点**：每个问题独立闭环（数据→模型→求解→结果→评价），评委顺着读零障碍。

## 三、各部分写作要点

### X.1 问题分析
- 先定目标结构（主目标/副目标/词典序还是加权）
- 明确关键决策
- 问题本质（这是什么数学问题，复杂度）
- 问题特性（数据差异性、约束特点）

### X.2 数据预处理
- 原始数据格式说明
- 清洗/转换步骤
- **数据校验**（已知值对比——免费回归测试）

### X.3 模型假设与符号
- 假设系统化（H1-H4，每条带依据）
- 符号表

### X.4 模型建立
- 决策变量定义（完整）
- 目标函数（主/副）
- 约束条件（逐条）
- 问题类型判定

### X.5 算法设计
- 算法选择依据（为什么选A不选B——参考论文的方法为什么有效/无效）
- 算法步骤（伪代码）
- 复杂度分析
- 参数设置及依据（不要照抄参考论文）

### X.6 下界与验证
- 理论下界（推导）
- 结果与下界对比
- 验证方法（枚举/对标/稳定性互证）

### X.7 结果与分析
- 结果表（多组数据）
- 可视化（布图/收敛曲线/对比图）
- **结果解读**（不是只列数字，要说说明了什么）

### X.8 灵敏度与评价
- 参数敏感性（参数变化对结果的影响）
- 模型优缺点（**诚实评价**，不包装）
- 改进方向

## 四、理论实践差距总结（复盘精华，最重要的反思文档）

**目的**：记录从理论稿到实测定稿的翻转，诚实反思，防后续问重蹈覆辙。

**什么时候写**：编程手独立实现完成，最终结果出来后，论文定稿前。

**模板**：
```markdown
# QX 正稿 vN → vM 理论实践差距总结

> 日期 | 视角：建模手/总指挥
> 价值：①后续问写作防重蹈 ②交代"理论假设vs实测真相"的差距 ③沉淀方法论证的取舍
> 依据：编程手独立实现最终结果

## 一、总纲：vN是"理论推演稿"，vM是"实测定稿"

| 维度 | vN（理论） | vM（实测） | 翻转原因 |
|---|---|---|---|
| 主算法 | | | |
| | | | |

## 二、N处差距详细拆解

### 差距1：XXX → YYY（最大翻转标出来）
**vN假设**：（理论怎么想的，依据是什么）
**vN表述**：（论文里原来怎么写的）
**vM实测**：（实际跑出来什么结果）
**翻转原因（机理）**：（为什么理论不对——要深入到机理，不是"就是不行"）
**教训**：（以后怎么避免）

### 差距2：...
```

**实际案例**（VLSI Q1最大翻转）：
> v2假设：三阶段Fast-SA为主搜索，构造FFD只作初值。理论依据：SA允许爬山跳出局部最优，参考论文以此取得好结果。
> v3实测：从最终解跑20级SA，三组best全部不降。构造解已是SA邻域的强局部最优——SA没有改进空间。
> 翻转原因：FFD构造解落在SA三算子的局部最优盆地中，单步扰动无法表达"全局重构"。参考论文的SA有效是因为初解随机；我们的构造解太"好"，SA反而无用武之地。
> 教训：不要因参考论文用SA就默认SA是主路径——实测构造解质量才是判决。

**关键原则**：
1. 不要包装——理论错了就是错了，诚实写出来
2. 要分析机理——不是"就是不行"，而是"为什么不行"
3. 要给教训——以后遇到类似问题怎么避免
4. 后续问要引用——防止Q3/Q4重复踩坑

## 七、写作纪律

### ✅ 必须做
1. **每问自成闭环**——不把多问混在一起
2. **数字必须来自权威数字表**——不要自己编，不要引用旧文档
3. **诚实评价**——不包装，不夸大，理论实践差距要写
4. **图表有标题、有坐标轴、有图例**
5. **参考论文要注明**——引用要规范

### ❌ 禁止做
1. **不要用"我们的方法非常优秀"这种空话**——用数据说话
2. **不要抄袭**——参考论文的方法要用自己的语言重述
3. **不要把参考论文的结果当成自己的结果**——必须实测
4. **不要忽略理论实践差距**——这是加分项，不是减分项
