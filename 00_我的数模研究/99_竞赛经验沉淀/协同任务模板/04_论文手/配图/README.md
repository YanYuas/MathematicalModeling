# 配图

> 所有论文配图，按问分类

---

## 命名规范

```
Q{问号}_{图类型}_{序号}_{描述}.png

图类型：
- MAIN：主图（论文正文用）
- SIDE：辅图（附录/补充材料用）
- TEMP：临时图（最终不用，归档）

示例：
Q1_MAIN_01_三组布图对比.png
Q2_SIDE_03_收敛曲线.png
```

---

## 图片规范

1. **分辨率**：至少300DPI，宽度≥1000px
2. **格式**：PNG（矢量图优先SVG）
3. **中文显示**：确保中文字体正确，不要方框
4. **坐标轴**：有标签、有单位、有刻度
5. **图例**：清晰可辨
6. **配色**：统一配色方案，不要每张图颜色都不一样
