# 代码库

> 可复用的核心代码，跨问共享

---

## 目录结构

```
代码库/
├── utils/          通用工具（数据解析、可视化、数学工具）
├── algorithms/     核心算法实现
├── models/         数据模型定义
└── tests/          单元测试
```

---

## 代码规范

1. **每个函数有docstring**：功能、参数、返回值
2. **关键步骤有注释**：为什么这么做，不是做什么
3. **可复现**：固定随机种子，结果可重现
4. **模块化**：核心算法与实验代码分离
5. **命名清晰**：函数名/变量名见名知意

---

## 复用原则

- 核心算法放在这里，各问import使用
- 各问的实验代码放在 `QX/` 目录下
- 修改核心代码前先沟通，避免影响其他问
- 废弃的代码移到 `99_归档/废弃方案/`
