# 快速开始清单

> 拿到模板后，按这个清单一步步做，10分钟完成初始化

---

## 第一步：复制模板（2分钟）

- [ ] 把 `协同任务模板/` 整个文件夹复制到你的项目目录
- [ ] 重命名为项目名（如 `2026_国赛A题`）
- [ ] 进入项目目录

## 第二步：初始化Git（3分钟）

- [ ] 运行 `git init`
- [ ] 创建 `.gitignore`（排除 __pycache__、.pyc、.vscode等）
- [ ] 创建dev、modeling、coding、writing分支
- [ ] 初始提交：`git add . && git commit -m "[初始化] 三手分工协同任务模板"`
- [ ] 切换到自己的分支

## 第三步：填写任务说明（3分钟）

- [ ] 打开 `00_任务总控/任务说明.md`
- [ ] 粘贴题目原文
- [ ] 填写分工（建模手/编程手/论文手）
- [ ] 填写时间安排
- [ ] 提交：`git commit -m "[总控] 填写任务说明"`

## 第四步：启动背景研究（2分钟）

- [ ] 建模手打开 `01_背景研究/背景全量研究报告.md`
- [ ] 开始研究问题本质
- [ ] 其他人准备环境、收集参考资料

---

## 日常工作检查

### 每天开始
- [ ] `git pull` 拉取最新
- [ ] 查看 `00_任务总控/进度看板.md`
- [ ] 确认今天的任务

### 每天结束
- [ ] 提交今天的工作
- [ ] 更新 `00_任务总控/进度看板.md`
- [ ] 有阻塞问题写在看板的"当前阻塞"里

### 每完成一个问
- [ ] 建模手：打包移交包给编程手
- [ ] 编程手：按清单实现，反馈问题
- [ ] 建模手：融入反馈，更新权威数字表
- [ ] 论文手：开始写作

---

## 完成标准

### 建模手完成标准
- [ ] 每问8个文件齐全（P0文件必须完整）
- [ ] 移交包已发给编程手
- [ ] 反馈已融入，权威数字表已更新

### 编程手完成标准
- [ ] 验证题结果与建模手一致
- [ ] 正式数据全部跑完
- [ ] 结果已验证（下界对标）
- [ ] 问题已反馈给建模手
- [ ] 代码有注释，可复现

### 论文手完成标准
- [ ] 每问自成闭环
- [ ] 数字与权威数字表一致
- [ ] 配图齐全清晰
- [ ] 多版本迭代，最终定稿

### 整体完成标准
- [ ] 论文格式符合要求
- [ ] 代码可运行
- [ ] 附件完整
- [ ] 最终版本已备份到 `06_交付物/`

---

## 遇到问题怎么办

| 问题 | 怎么办 |
|------|--------|
| 模型有问题 | 写在 `编程手/QX/理论问题反馈.md`，不要自行改 |
| 代码有bug | 先看 `99_归档/废弃方案/` 有没有类似问题 |
| 论文不知道怎么写 | 参考 `04_论文手/Q1/论文组织方案.md` |
| Git冲突 | 看 `UGit协作指南.md` 第五节 |
| 不知道下一步做什么 | 看 `00_任务总控/进度看板.md` |
| 数据对不上 | 以 `00_任务总控/权威数字表.md` 为准 |
