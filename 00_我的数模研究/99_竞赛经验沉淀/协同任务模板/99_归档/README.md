# 归档

> 旧版本和废弃方案，**不要删除**，留痕用

---

## 目录结构

```
归档/
├── 旧版本/       文档的历史版本
└── 废弃方案/     被证伪的思路/代码
```

---

## 归档规则

### 旧版本
- 文档有重大修改时，先把旧版复制到这里
- 命名：`原文件名_v1.md`、`原文件名_v2.md`
- 在文件开头注明：归档日期、归档原因、新版本位置

### 废弃方案
- 方案被证伪/否决时，不要删除，移到这里
- 命名：`原文件名_废弃.md`
- 在文件开头注明：废弃日期、废弃原因、替代方案

---

## 为什么不删除？

1. **可追溯**：知道为什么放弃这个方案，避免重复踩坑
2. **可恢复**：万一新方案有问题，可以回退
3. **可学习**：废弃方案中的错误是宝贵的经验
4. **可审计**：比赛复盘时可以看到完整的思考过程
