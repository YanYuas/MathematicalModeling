# 优化类竞赛真题解析方法论

> 六层钻研法 · 第5层：应用实战（真题篇）
> 总结优化类真题的识别、建模、求解套路，附经典真题解析

---

## 一、如何识别优化类真题？

### 1.1 关键词识别

看到这些词，大概率是优化问题：

| 关键词 | 可能的优化类型 |
|--------|--------------|
| "最优""最佳""最小""最大" | 目标函数优化 |
| "安排""分配""调度""规划" | 线性/整数规划 |
| "路径""路线""巡回" | 最短路/TSP/网络流 |
| "选址""布局" | 0-1规划/混合整数 |
| "参数标定""拟合" | 非线性最小二乘 |
| "控制""策略" | 动态规划/最优控制 |
| "多目标""权衡" | 多目标优化 |
| "不确定性""鲁棒" | 鲁棒优化/随机优化 |

### 1.2 问题结构识别

优化问题的三要素：
1. **决策变量**：我们能控制什么？（产量、路径、参数...）
2. **目标函数**：我们要优化什么？（最小成本、最大收益、最短时间...）
3. **约束条件**：有什么限制？（资源上限、物理规律、技术要求...）

**只要题目中同时存在这三要素，就是优化问题。**

## 二、优化建模的通用步骤

### 第一步：明确决策变量
- 问自己："我能改变什么？"
- 变量要完整（不遗漏）、独立（不冗余）
- 连续变量 vs 整数变量 vs 0-1变量

### 第二步：建立目标函数
- 单一目标：直接写 min/max
- 多目标：加权求和 / ε约束 / Pareto前沿
- 注意量纲统一

### 第三步：列出约束条件
- 物理约束（质量守恒、能量守恒）
- 资源约束（时间、资金、人力）
- 技术约束（规格、标准）
- 逻辑约束（如果...那么...）

### 第四步：选择求解方法
| 问题特征 | 推荐方法 |
|---------|---------|
| 线性目标+线性约束 | 线性规划（单纯形法/求解器） |
| 整数变量 | 整数规划（分支定界/割平面） |
| 非线性目标 | 非线性规划（梯度法/牛顿法/SLSQP） |
| 多目标 | 加权法/NSGA-II |
| 多阶段决策 | 动态规划 |
| 图结构 | 网络优化（最短路/最大流） |
| 大规模复杂 | 启发式算法（GA/SA/PSO/ACO） |

### 第五步：结果分析与验证
- 最优解是否合理？
- 灵敏度分析：参数变化对结果的影响
- 稳定性检验：扰动数据看结果变化
- 多解情况：是否存在多个最优解？

## 三、经典真题解析

### 真题1：2020B 穿越沙漠（已有完整解析）

**问题**：玩家穿越沙漠，有资金和水的限制，不同天气消耗不同，可在村庄补给、矿山挖矿。求最优策略。

**优化建模**：
- 决策变量：每天的行动（走/停/挖矿/买/卖）
- 目标函数：最大化最终资金
- 约束：水和食物不耗尽、时间限制
- 方法：动态规划（状态=日期+位置+物资）

**关键技巧**：状态压缩，将连续的物资量化为离散状态。

---

### 真题2：2019A 高压油管的压力控制

**问题**：高压油管通过喷油器喷油，需要控制调压阀的开闭，使管内压力稳定在100MPa。

**优化建模**：
- 这是一个**微分方程+优化**的混合问题
- 先建立管内压力变化的微分方程（流入量-流出量）
- 然后优化调压阀的开启时间策略，使压力波动最小

**目标函数**：min ∫(P(t) - 100)² dt （压力偏差最小）

**决策变量**：调压阀在每个时刻的开闭状态

**约束**：阀门开闭有最小时间间隔、压力不能超过上限

**求解方法**：
1. 数值求解微分方程（欧拉法/Runge-Kutta）
2. 用优化算法搜索阀门策略（遗传算法/模拟退火）
3. 或者离散化后用动态规划

**关键技巧**：将连续时间离散化为时间段，每个时间段阀门状态固定，转化为组合优化问题。

---

### 真题3：2018A 高温作业专用服装设计

**问题**：设计高温作业服的四层材料厚度，使外部75°C时，内部温度不超过47°C，且厚度最薄。

**优化建模**：
- 先建立热传导方程（抛物型偏微分方程）
- 四层材料的热传导参数不同
- 优化各层厚度，使最终温度达标且总厚度最小

**目标函数**：min 总厚度 = d1 + d2 + d3 + d4

**约束**：t=3000s时，皮肤表面温度 ≤ 47°C

**决策变量**：四层材料的厚度 d1,d2,d3,d4

**求解方法**：
1. 用有限差分法求解热传导方程
2. 用非线性优化（模式搜索/遗传算法）搜索最优厚度
3. 因为热传导方程求解较慢，可以用代理模型（神经网络）加速

**关键技巧**：热传导方程的求解是计算瓶颈，用预计算+插值加速。

---

### 真题4：2017A CT系统参数标定

**问题**：CT系统通过X射线投影重建图像，需要标定系统的几何参数（旋转中心、探测器位置等）。

**优化建模**：
- 这是一个**图像重建+参数优化**问题
- 已知标准模板的投影数据，反求系统参数
- 目标：使重建图像与真实模板的误差最小

**目标函数**：min ||重建图像 - 真实图像||²

**决策变量**：系统几何参数（旋转中心坐标、探测器角度、间距等）

**求解方法**：
1. 建立投影模型（Radon变换）
2. 用滤波反投影（FBP）或迭代重建（ART/SIRT）
3. 用非线性最小二乘优化参数（Levenberg-Marquardt）

**关键技巧**：参数之间存在耦合，需要分步标定（先定旋转中心，再定探测器参数）。

---

### 真题5：2016A 系泊系统的设计

**问题**：设计系泊系统（锚、锚链、浮标、钢管），使浮标在水流中保持合适的吃水深度和倾斜角。

**优化建模**：
- 先建立力学平衡方程（悬链线模型）
- 优化锚链长度、重物质量等参数

**目标函数**：min 锚链长度（或成本）

**约束**：
- 浮标吃水深度在范围内
- 钢管倾斜角不超过限制
- 锚的抓力足够

**求解方法**：
1. 力学建模（悬链线方程/分段刚体模型）
2. 用非线性优化搜索参数
3. 不同水流速度下分别验证

**关键技巧**：力学平衡方程可能有多解，需要物理判断选择合理解。

---

### 真题6：2014A 嫦娥三号软着陆轨道设计

**问题**：设计嫦娥三号从100km环月轨道到月面软着陆的轨道，使燃料消耗最少。

**优化建模**：
- 这是一个**最优控制问题**
- 状态变量：位置、速度
- 控制变量：推力大小和方向
- 目标：燃料消耗最少（等价于速度变化量Δv最小）

**约束**：
- 轨道动力学方程（万有引力+推力）
- 着陆时速度为0
- 推力大小有上限

**求解方法**：
1. 建立最优控制模型（Pontryagin极大值原理）
2. 数值求解（打靶法/直接法离散化）
3. 用非线性规划求解离散后的问题

**关键技巧**：将连续最优控制离散化为非线性规划（直接法），比间接法（解边值问题）更稳定。

## 四、优化类真题的常见套路

### 套路1：物理模型 + 优化参数
**特征**：先建立物理/化学/生物模型（微分方程），然后优化模型中的参数。

**代表**：2019A高压油管、2018A高温作业服、2016A系泊系统

**解法**：
1. 建立物理模型（微分方程/偏微分方程）
2. 数值求解模型
3. 用优化算法搜索参数
4. 注意：物理模型求解要快，否则优化很慢

### 套路2：决策优化（纯优化）
**特征**：没有复杂物理模型，就是资源分配、路径规划、调度等。

**代表**：2020B穿越沙漠、2017B"拍照赚钱"任务定价、2015B出租车资源配置

**解法**：
1. 明确决策变量
2. 建立目标和约束
3. 选择合适的优化算法（LP/IP/DP/启发式）

### 套路3：反问题/参数标定
**特征**：已知观测数据，反求模型参数。

**代表**：2017A CT标定、2013A车道占用率

**解法**：
1. 建立正问题模型（参数→输出）
2. 目标：min ||模型输出 - 观测数据||
3. 用最小二乘/优化算法反求参数

### 套路4：最优控制
**特征**：随时间变化的控制策略。

**代表**：2014A嫦娥三号、2011A城市表层土壤重金属

**解法**：
1. 建立状态方程和控制变量
2. 离散化转化为非线性规划
3. 或用Pontryagin极大值原理解析求解

## 五、比赛实战建议

### 5.1 时间分配
- **前2小时**：理解问题，建立模型框架
- **中间8小时**：编程实现，求解问题
- **后4小时**：结果分析、灵敏度检验、写论文
- **最后2小时**：检查、排版、提交

### 5.2 编程建议
- 先写一个简单版本（小规模/简化模型）验证思路
- 再逐步增加复杂度
- 物理模型求解要封装成函数，方便优化调用
- 用向量化计算（numpy）加速
- 优化算法先用简单的（网格搜索/随机搜索），再用高级的（GA/SA）

### 5.3 论文写作
- 模型建立要清晰：变量定义→目标函数→约束条件
- 算法选择要有理由：为什么用这个算法？
- 结果展示要直观：表格+图+分析
- 灵敏度分析是加分项：参数变化对结果的影响
- 模型优缺点要诚实：什么假设、什么局限

### 5.4 常见失分点
- ❌ 只给结果不给方法（评委不知道你怎么算的）
- ❌ 没有灵敏度分析（结果是否稳定？）
- ❌ 模型太复杂无法求解（纸上谈兵）
- ❌ 忽略约束（结果不可行）
- ❌ 多目标只给一个解（应该给Pareto前沿）

## 七、优化建模的思维框架

```
看到题目
  ↓
识别三要素：决策变量？目标？约束？
  ↓
判断问题类型：线性？整数？非线性？多目标？动态？网络？
  ↓
选择算法：精确算法？启发式？求解器？
  ↓
编程实现：先简单验证，再复杂求解
  ↓
结果分析：最优解合理吗？灵敏度？稳定性？
  ↓
论文写作：模型清晰，算法有据，结果直观
```

记住：**没有最好的算法，只有最合适的算法**。简单问题不要用复杂方法，复杂问题不要硬套简单方法。
