## 📝 真题解析模板

每道真题应该包含以下部分：

### 1. 题目复述
- 用自己的话重述问题
- 明确已知条件和求解目标

### 2. 问题分析
- 问题属于什么类型（优化/评价/预测/分类）
- 可以用什么模型和算法
- 难点在哪里

### 3. 模型建立
- 决策变量
- 目标函数
- 约束条件
- 模型假设

### 4. 算法实现
- 用什么算法求解
- 代码实现（关键部分）
- 参数设置

### 5. 结果分析
- 求解结果
- 灵敏度分析
- 模型检验

### 6. 论文写作要点
- 摘要怎么写
- 图表怎么放
- 创新点在哪里

## 💡 使用建议

1. **先独立思考**：拿到题目先自己想30分钟，不要急着看答案
2. **再看思路**：对照优秀论文的思路，看自己哪里没想到
3. **动手实现**：把核心算法自己写一遍
4. **总结套路**：每类问题的通用解法是什么
5. **记录心得**：把学到的东西写到 `../06_个人研究笔记/`
