# 优化模型参考资料汇总

## 一、经典教材

### 中文教材
1. **《数学模型》（第五版）** - 姜启源、谢金星、叶俊
   - 数学建模入门经典教材
   - 第4章：数学规划模型（线性规划、整数规划、非线性规划）
   - 出版社：高等教育出版社

2. **《数学建模算法与应用》（第2版）** - 司守奎、孙兆亮
   - 算法+MATLAB代码，非常实用
   - 第1-4章：线性规划、整数规划、非线性规划、目标规划
   - 第15章：智能优化算法（遗传算法、模拟退火、粒子群）
   - 出版社：国防工业出版社

3. **《运筹学》（第4版）** - 清华大学出版社
   - 运筹学经典教材，理论扎实
   - 涵盖线性规划、整数规划、非线性规划、动态规划、图论

4. **《最优化理论与方法》** - 陈宝林
   - 非线性优化的经典教材
   - 适合深入学习理论

### 英文教材
5. **《Numerical Optimization》** - Jorge Nocedal, Stephen Wright
   - 数值优化领域的圣经
   - 涵盖无约束优化、约束优化、线性规划

6. **《Convex Optimization》** - Stephen Boyd
   - 凸优化经典教材
   - 免费在线：https://web.stanford.edu/~boyd/cvxbook/

7. **《Integer Programming》** - Laurence Wolsey
   - 整数规划权威教材

## 七、学习路线建议

### 第一阶段：基础（1-2周）
- 线性规划：理解概念，会用linprog
- 整数规划：0-1规划、指派问题
- 教材：姜启源《数学模型》第4章

### 第二阶段：进阶（2-3周）
- 非线性规划：fmincon/SLSQP
- 多目标规划：加权法、理想点法
- 动态规划：背包、最短路径
- 教材：司守奎《数学建模算法与应用》

### 第三阶段：高级（2-3周）
- 遗传算法、模拟退火、粒子群
- 理解原理，会调参数
- 能解决TSP等组合优化问题

### 第四阶段：实战（持续）
- 做国赛真题
- 看优秀论文
- 积累自己的代码模板

## 八、常用技巧

### 8.1 线性化技巧
- 绝对值 |x| ≤ a → -a ≤ x ≤ a
- max(x₁,x₂) ≤ M → x₁≤M, x₂≤M
- if x>0 then y=1 → 大M法
- 乘积xy（x,y为0-1变量）→ 引入z，z≤x, z≤y, z≥x+y-1

### 8.2 求解器选择
- 小规模LP：linprog
- 大规模LP：Gurobi/CPLEX
- 小规模IP：intlinprog
- 大规模IP：Gurobi/CPLEX
- 连续NLP：fmincon/SLSQP
- 全局优化：GA/PSO/SA + 多次运行

### 8.3 调试技巧
- 先小规模测试，再大规模
- 检查约束是否满足
- 输出中间变量
- 用已知答案的例题验证
