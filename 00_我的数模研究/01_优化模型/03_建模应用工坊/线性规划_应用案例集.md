# 线性规划应用案例集

> 每个案例都按照"问题→变量→目标→约束→求解→分析→扩展"的完整流程展开。
> 重点不是答案，而是**从问题到模型的思维过程**。

---

## 案例1：生产计划问题

### 问题描述
某工厂生产甲、乙两种产品，每单位利润分别为3元和5元。
- 生产1单位甲需：1单位原料A、2单位原料B、1小时工时
- 生产1单位乙需：2单位原料A、1单位原料B、1小时工时
- 原料A限量8单位，原料B限量10单位，工时限量10小时

求最大利润的生产方案。

### 建模思维过程

**第一步：识别决策变量**
要决定什么？——每种产品生产多少。
设 x₁ = 甲产品产量，x₂ = 乙产品产量。

**第二步：写目标函数**
要优化什么？——总利润最大。
总利润 = 3x₁ + 5x₂
目标：max 3x₁ + 5x₂

**第三步：列约束条件**
有哪些限制？
- 原料A：x₁ + 2x₂ ≤ 8
- 原料B：2x₁ + x₂ ≤ 10
- 工时：x₁ + x₂ ≤ 10
- 非负：x₁, x₂ ≥ 0

**第四步：检查完整性**
- 变量定义清晰？✓
- 目标函数合理？✓
- 约束完整？✓（注意工时约束可能是冗余的，因为原料约束更紧）
- 量纲一致？✓

### 模型
```
max 3x₁ + 5x₂
s.t. x₁ + 2x₂ ≤ 8
     2x₁ + x₂ ≤ 10
     x₁ + x₂ ≤ 10
     x₁, x₂ ≥ 0
```

### 求解结果
x₁ = 4, x₂ = 2, 最大利润 = 22元

### 结果分析
- 原料A用完（8=8），影子价格 = 7/3 ≈ 2.33元
- 原料B用完（10=10），影子价格 = 1/3 ≈ 0.33元
- 工时剩余4小时（冗余约束），影子价格 = 0
- 结论：原料A是瓶颈资源，应优先保障

### 扩展思考
1. 如果原料A可以2元/单位购买，要买吗？→ 买！影子价格2.33 > 市场价2
2. 如果新增产品丙，利润4元，消耗1A+1B+1工时，要生产吗？→ 机会成本=2.33+0.33=2.66 < 4，生产！
3. 如果甲产品利润降到2.5元，方案变吗？→ 不变（允许范围[2.5, 10]）

## 案例2：运输问题

### 问题描述
3个产地（产量10, 20, 15），4个销地（销量8, 12, 10, 15），单位运费矩阵：
```
      销1  销2  销3  销4
产1    8    7    5    6
产2    4    3    6    5
产3    7    5    4    3
```
求最小总运费的调运方案。

### 建模思维过程

**第一步：识别决策变量**
要决定什么？——每个产地到每个销地运多少。
设 xᵢⱼ = 从产地 i 到销地 j 的运量（i=1,2,3; j=1,2,3,4），共12个变量。

**第二步：写目标函数**
总运费 = ΣΣ cᵢⱼxᵢⱼ
目标：min ΣΣ cᵢⱼxᵢⱼ

**第三步：列约束条件**
- 产地约束：每个产地的运出量 = 产量
  Σⱼ xᵢⱼ = aᵢ （i=1,2,3）
- 销地约束：每个销地的收到量 = 销量
  Σᵢ xᵢⱼ = bⱼ （j=1,2,3,4）
- 非负：xᵢⱼ ≥ 0

**第四步：检查产销平衡**
总产量 = 10+20+15 = 45
总销量 = 8+12+10+15 = 45
平衡！✓（如果不平衡，需要虚拟产地或销地）

### 模型
```
min ΣᵢΣⱼ cᵢⱼxᵢⱼ
s.t. Σⱼ xᵢⱼ = aᵢ   (i=1,2,3)
     Σᵢ xᵢⱼ = bⱼ   (j=1,2,3,4)
     xᵢⱼ ≥ 0
```

### 结构特点
- 约束矩阵是0-1矩阵，每列恰好2个1
- 有一个约束是冗余的（总产量=总销量）
- 基可行解的基变量数 = m+n-1 = 3+4-1 = 6
- 可以用表上作业法（更高效），也可以用单纯形法

### 求解结果
（具体方案略，可用代码求解）
最小总运费 = ？

### 建模技巧
⚠️ **坑1**：产销不平衡时，需要加虚拟产地或销地
- 产 > 销：加虚拟销地，运费=0，销量=产量-销量
- 销 > 产：加虚拟产地，运费=0，产量=销量-产量

⚠️ **坑2**：运输问题的解可能退化（基变量数 < m+n-1），需要补0基变量

## 案例3：指派问题

### 问题描述
4个人做4项工作，每人做一项，每项工作一人做。完成时间矩阵：
```
      工作1  工作2  工作3  工作4
人1      3      8      9      4
人2      5      2      7      6
人3      9      5      4      8
人4      7      6      3      5
```
求最小总时间的指派方案。

### 建模思维过程

**第一步：识别决策变量**
设 xᵢⱼ = 1 如果人 i 做工作 j，否则 0。共16个0-1变量。

**第二步：写目标函数**
min ΣΣ cᵢⱼxᵢⱼ

**第三步：列约束条件**
- 每人做一项：Σⱼ xᵢⱼ = 1 （i=1,2,3,4）
- 每项工作一人做：Σᵢ xᵢⱼ = 1 （j=1,2,3,4）
- xᵢⱼ ∈ {0, 1}

**第四步：判断问题类型**
这是0-1整数规划！但指派问题有特殊结构，可以用匈牙利算法（O(n³)），比一般整数规划快得多。

💡 **技巧**：指派问题是运输问题的特例（产量=销量=1），但因为系数全是1，可以用更高效的匈牙利算法。

### 求解结果
人1→工作4, 人2→工作2, 人3→工作3, 人4→工作1
总时间 = 4+2+4+7 = 17

### 扩展
- 人数 ≠ 工作数：加虚拟人或虚拟工作，成本=0
- 最大化问题（如效率最大）：转化为最小化（用最大值减每个元素）
- 一个人可以做多项工作：去掉"每人做一项"约束，改为工时约束

## 案例4：下料问题

### 问题描述
钢管原材料长19米，客户需要：
- 4米钢管100根
- 6米钢管80根
- 8米钢管60根

如何下料使废料最少？

### 建模思维过程

**第一步：识别决策变量**
这是下料问题的关键——先枚举所有合理的下料方式！

可能的下料方式（19米原料）：
| 方式 | 4米 | 6米 | 8米 | 用料 | 废料 |
|------|-----|-----|-----|------|------|
| 1    | 4   | 0   | 0   | 16   | 3    |
| 2    | 3   | 1   | 0   | 18   | 1    |
| 3    | 2   | 0   | 1   | 16   | 3    |
| 4    | 1   | 2   | 0   | 16   | 3    |
| 5    | 1   | 1   | 1   | 18   | 1    |
| 6    | 0   | 3   | 0   | 18   | 1    |
| 7    | 0   | 0   | 2   | 16   | 3    |

设 xⱼ = 第 j 种下料方式使用的原料根数（j=1,...,7）

**第二步：写目标函数**
min 废料总量 = 3x₁ + 1x₂ + 3x₃ + 3x₄ + 1x₅ + 1x₆ + 3x₇
（或者等价地：min 原料总根数 = Σxⱼ，因为每根原料19米固定）

**第三步：列约束条件**
- 4米需求：4x₁ + 3x₂ + 2x₃ + 1x₄ + 1x₅ ≥ 100
- 6米需求：0x₁ + 1x₂ + 0x₃ + 2x₄ + 1x₅ + 3x₆ ≥ 80
- 8米需求：0x₁ + 0x₂ + 1x₃ + 0x₄ + 1x₅ + 0x₆ + 2x₇ ≥ 60
- 非负整数：xⱼ ≥ 0，整数

### 模型特点
- 变量数 = 下料方式数（需要先枚举）
- 约束数 = 需求种类数
- 是整数规划，但规模不大时可以先解线性规划再取整

💡 **关键技巧**：下料问题的难点不是求解，而是**枚举合理的下料方式**。方式太多会导致变量爆炸，方式太少可能不是最优。

## 案例5：投资组合问题（线性近似）

### 问题描述
有5个投资项目，各项目的：
- 投资额：[200, 300, 150, 400, 250] 万元
- 预期年收益：[20, 40, 15, 50, 30] 万元
- 风险等级：[1, 3, 2, 4, 2]（1低5高）

总资金1000万元，要求平均风险等级 ≤ 2.5，求最大收益。

### 建模思维过程

**第一步：识别决策变量**
设 xᵢ = 投资项目 i 的比例（0 ≤ xᵢ ≤ 1），或者是否投资 yᵢ ∈ {0,1}。

这里假设可以部分投资，用 xᵢ 表示投资比例。

**第二步：写目标函数**
max 总收益 = Σ (收益ᵢ × xᵢ) = 20x₁ + 40x₂ + 15x₃ + 50x₄ + 30x₅

**第三步：列约束条件**
- 资金约束：Σ (投资ᵢ × xᵢ) ≤ 1000
  200x₁ + 300x₂ + 150x₃ + 400x₄ + 250x₅ ≤ 1000
- 风险约束：平均风险 ≤ 2.5
  Σ (风险ᵢ × 投资ᵢ × xᵢ) / Σ (投资ᵢ × xᵢ) ≤ 2.5
  这是分式约束！需要线性化：
  Σ (风险ᵢ - 2.5) × 投资ᵢ × xᵢ ≤ 0
  (1-2.5)200x₁ + (3-2.5)300x₂ + ... ≤ 0
- 比例约束：0 ≤ xᵢ ≤ 1

### 线性化技巧
⚠️ **分式约束的线性化**：
原约束：Σ aᵢxᵢ / Σ bᵢxᵢ ≤ c
转化：Σ (aᵢ - c·bᵢ)xᵢ ≤ 0

这是因为 Σ bᵢxᵢ > 0（投资额为正），两边乘不等号方向不变。

### 模型
```
max 20x₁ + 40x₂ + 15x₃ + 50x₄ + 30x₅
s.t. 200x₁ + 300x₂ + 150x₃ + 400x₄ + 250x₅ ≤ 1000
     -300x₁ + 150x₂ - 75x₃ + 600x₄ - 125x₅ ≤ 0
     0 ≤ xᵢ ≤ 1
```

### 扩展
- 如果只能全投或不投：xᵢ ∈ {0,1}，变成0-1规划
- 如果考虑风险的方差：变成二次规划（非线性）
- 如果有借贷：增加资金变量和利率约束

## 建模通用方法论总结

### 从问题到模型的5步法
1. **找变量**：要决定什么？用什么符号表示？
2. **写目标**：要最大化/最小化什么？用变量怎么表示？
3. **列约束**：有哪些限制？每个限制怎么写成不等式/等式？
4. **查完整**：变量范围写了吗？约束有遗漏吗？量纲一致吗？
5. **判类型**：是线性/非线性？整数/连续？单目标/多目标？

### 常见建模技巧
| 技巧 | 适用场景 |
|------|----------|
| 加松弛变量 | ≤ 约束转等式 |
| 加剩余变量 | ≥ 约束转等式 |
| 虚拟产地/销地 | 产销不平衡运输问题 |
| 枚举下料方式 | 下料问题 |
| 分式线性化 | 比率约束 |
| 0-1变量 | 是/否决策 |
| 大M法 | if-then逻辑约束 |

### 常见错误
⚠️ 忘记非负约束 x ≥ 0
⚠️ 约束方向写反（最大化时资源约束应是 ≤）
⚠️ 目标函数量纲不一致（利润和成本直接加）
⚠️ 把整数变量当连续变量解（得到小数答案）
⚠️ 下料问题忘记枚举下料方式
⚠️ 运输问题产销不平衡时没加虚拟点
