## 一、状态压缩DP

### 1.1 核心思想
当状态需要表示"集合"时，用二进制数压缩状态。第i位为1表示集合包含元素i。

**适用场景**：
- 经过哪些节点（TSP）
- 选了哪些物品（集合覆盖）
- 棋盘哪些位置被占（状态压缩棋盘DP）

**时间复杂度**：通常是 O(2^n × ...)，n一般不超过20。

### 1.2 案例：TSP旅行商问题

**问题**：4个城市，从0出发经过所有城市回到0，求最短路径。

```python
import sys
sys.path.insert(0, '02_算法实现手札/00_手动实现详解')
from importlib import import_module
dp_adv = import_module('13_动态规划进阶_手动实现')

dist = [
    [0, 10, 15, 20],
    [10, 0, 35, 25],
    [15, 35, 0, 30],
    [20, 25, 30, 0],
]
cost, path = dp_adv.tsp_bitmask(dist)
print(f"最短路径：{cost}，路径：{path}")
```

**结果**：最短路径80，路径0→1→3→2→0（或等价路径）。

💡 **技巧**：TSP的状态压缩DP是经典模板。n=20时2^20≈100万，可以接受；n>20就要用启发式算法了。

### 1.3 案例：集合覆盖（状态压缩）

**问题**：U={1,2,3,4,5}，有3个子集S1={1,2}, S2={2,3,4}, S3={1,5}。选最少的子集覆盖U。

```python
# 状态：mask表示已覆盖的元素
# dp[mask] = 覆盖mask所需最少子集数
def set_cover(universe_size, sets):
    n = len(sets)
    full = (1 << universe_size) - 1
    dp = [float('inf')] * (1 << universe_size)
    dp[0] = 0
    
    for mask in range(1 << universe_size):
        if dp[mask] == float('inf'):
            continue
        for s in sets:
            new_mask = mask | s
            dp[new_mask] = min(dp[new_mask], dp[mask] + 1)
    
    return dp[full]

# 子集用二进制表示
S1 = 0b00011  # {1,2}
S2 = 0b01110  # {2,3,4}
S3 = 0b10001  # {1,5}
print(set_cover(5, [S1, S2, S3]))  # 2（选S2+S3）
```

## 二、树形DP

### 2.1 核心思想
在树结构上做DP，从叶子到根计算。每个节点的状态依赖子节点的状态。

**关键**：
1. 先建树（BFS/DFS确定父子关系）
2. 从叶子到根（后序遍历）计算
3. 每个节点维护多个状态（如选/不选）

### 2.2 案例：公司聚会（最大独立集）

**问题**：公司员工组成树状结构，每个人有快乐值。如果选了一个人，就不能选他的直接下属。求最大快乐值。

```python
tree = dp_adv.Tree(5)
tree.add_edge(0, 1)  # CEO→经理1
tree.add_edge(0, 2)  # CEO→经理2
tree.add_edge(1, 3)  # 经理1→员工1
tree.add_edge(1, 4)  # 经理1→员工2
tree.root_tree(0)

happiness = [10, 20, 30, 40, 50]
max_happy = dp_adv.tree_max_independent_set(tree, happiness)
print(f"最大快乐值：{max_happy}")  # 120（选经理2+员工1+员工2）
```

### 2.3 案例：树的直径

**问题**：求树中最长路径的长度。

```python
diameter = dp_adv.tree_diameter(tree)
print(f"树的直径：{diameter}")  # 3（经理2→CEO→经理1→员工1）
```

💡 **技巧**：树的直径也可以用"两次DFS"求：从任意点DFS找最远点A，再从ADFS找最远点B，A-B就是直径。但树形DP可以同时维护更多信息。

## 三、数位DP

### 3.1 核心思想
统计1~n中满足某种数字特征的数的个数。按位处理，用记忆化搜索。

**状态**：(当前位置, 是否受上界约束, 是否已经开始, 自定义状态)

**适用场景**：
- 统计含/不含某些数字的数
- 统计各位和为k的数
- 统计满足某种数字规律的数

### 3.2 案例：统计数字1出现次数

**问题**：1~n中数字1一共出现多少次？

```python
count = dp_adv.count_digit_one(100)
print(f"1~100中1出现{count}次")  # 21次
```

**逐位计算法**（比通用框架更快）：
对每一位，根据当前位的数字分三种情况计算。

### 3.3 案例：不含4和9的数

**问题**：1~n中不含数字4和9的数有多少个？

```python
count = dp_adv.count_numbers_without_49(20)
print(f"1~20中不含4和9的数有{count}个")  # 16个
```

💡 **技巧**：数位DP的通用框架可以处理各种问题，只需修改`digit_func`。前导零的处理很重要（started标记）。

## 四、概率DP（期望DP）

### 4.1 核心思想
计算随机过程的期望。状态E[i]表示在状态i时的期望，根据转移概率列方程。

**关键**：
- 无环的过程：直接从后往前递推
- 有环的过程：解线性方程组（或迭代法）

### 4.2 案例：掷骰子达到目标的期望次数

**问题**：每次掷骰子（1~6），累计点数达到target，求期望次数。

```python
e = dp_adv.dice_expected_rolls(6)
print(f"累计达到6的期望次数：{e:.4f}")  # 约2.16次
```

**转移方程**：E[i] = 1 + (E[i+1]+...+E[i+6])/6

### 4.3 案例：随机游走期望步数

**问题**：在0~n上随机游走，从start出发，到达边界停止，求期望步数。

```python
e = dp_adv.random_walk_expected_steps(10, 5)
print(f"期望步数：{e:.4f}")  # 25（解析解：i*(n-i)）
```

**转移方程**：E[i] = 1 + 0.5*E[i-1] + 0.5*E[i+1]
这是有环的，需要迭代或解方程组。

### 4.4 案例：赠券收集问题

**问题**：n种优惠券，每次随机得一种，求收集齐的期望次数。

```python
e = dp_adv.expected_collect_all_coupons(5)
print(f"收集5种的期望次数：{e:.4f}")  # 11.42
```

**转移方程**：E[i] = n/(n-i) + E[i+1]
解析解：n × H_n（调和级数）

## 五、进阶DP的识别技巧

| 问题特征 | 可能的DP类型 |
|---------|-------------|
| n很小（≤20），涉及"选哪些" | 状态压缩DP |
| 数据结构是树 | 树形DP |
| 问1~n中有多少个数满足... | 数位DP |
| 涉及随机过程、期望 | 概率DP |
| 区间上的最优解 | 区间DP（如矩阵链乘法） |
| 字符串上的最优解 | 字符串DP（如LCS/编辑距离） |

## 六、与基础DP的对比

| 类型 | 状态表示 | 典型问题 | 复杂度 |
|------|---------|---------|--------|
| 线性DP | dp[i] | 背包、LIS | O(n)或O(n²) |
| 区间DP | dp[i][j] | 矩阵链、石子合并 | O(n³) |
| 树形DP | dp[u][状态] | 最大独立集、直径 | O(n) |
| 状态压缩DP | dp[mask][i] | TSP、集合覆盖 | O(2^n × n²) |
| 数位DP | dp[pos][tight][...] | 数字统计 | O(位数×状态数) |
| 概率DP | E[状态] | 期望计算 | 取决于转移图 |

---

## 七、建模比赛中的应用

1. **TSP类问题**：物流配送、路径规划 → 状态压缩DP（n小时）或启发式（n大时）
2. **组织结构优化**：公司、树状网络 → 树形DP
3. **数字统计**：密码计数、号码分析 → 数位DP
4. **随机系统分析**：排队、库存、可靠性 → 概率DP
5. **资源分配**：多阶段决策 → 线性DP/区间DP

💡 **建议**：进阶DP在比赛中属于"加分项"，基础DP是必须掌握的。看到n≤20的"选哪些"问题，第一反应就是状态压缩DP。
