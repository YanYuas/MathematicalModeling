## 二、scipy.optimize 使用指南

### 2.1 线性规划：linprog

```python
from scipy.optimize import linprog

# 问题：min c^T x
# 约束：A_ub @ x <= b_ub
#       A_eq @ x == b_eq
#       lb <= x <= ub

# 示例：max 3x1 + 5x2
# 约束：x1 <= 4, 2x2 <= 12, 3x1 + 2x2 <= 18, x1,x2 >= 0
# 注意：linprog是最小化，所以目标取负

c = [-3, -5]  # 取负，因为是最大化
A_ub = [[1, 0], [0, 2], [3, 2]]
b_ub = [4, 12, 18]
bounds = [(0, None), (0, None)]  # x>=0

result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
print(f"最优值：{-result.fun}")  # 取负回来
print(f"最优解：{result.x}")
print(f"状态：{result.message}")
```

**常用参数**：
- `method='highs'`：默认，最新最快的方法
- `method='simplex'`：经典单纯形法
- `method='interior-point'`：内点法，适合大规模

⚠️ **坑**：scipy的linprog只能做连续线性规划，不能直接做整数规划！整数规划需要用PuLP或Gurobi。

### 2.2 非线性规划：minimize

```python
from scipy.optimize import minimize

# 示例：min (x1-3)^2 + (x2-2)^2
# 约束：x1 + x2 <= 5, x1 >= 0, x2 >= 0

def objective(x):
    return (x[0] - 3)**2 + (x[1] - 2)**2

def constraint(x):
    return 5 - x[0] - x[1]  # >= 0

cons = {'type': 'ineq', 'fun': constraint}
bounds = [(0, None), (0, None)]
x0 = [0, 0]  # 初始点

result = minimize(objective, x0, method='SLSQP', bounds=bounds, constraints=cons)
print(f"最优值：{result.fun}")
print(f"最优解：{result.x}")
```

**常用方法**：
| 方法 | 适用场景 | 需要梯度 |
|------|---------|---------|
| SLSQP | 有约束的非线性规划 | 否（数值差分） |
| L-BFGS-B | 无约束/边界约束 | 否 |
| Nelder-Mead | 无约束，不可导 | 否 |
| trust-constr | 有约束，高精度 | 否 |

### 2.3 全局优化：differential_evolution / basinhopping

```python
from scipy.optimize import differential_evolution

# Rastrigin函数（多峰，容易陷入局部最优）
def rastrigin(x):
    return sum(xi**2 - 10*np.cos(2*np.pi*xi) + 10 for xi in x)

bounds = [(-5.12, 5.12)] * 10
result = differential_evolution(rastrigin, bounds, seed=42)
print(f"最优值：{result.fun}")
print(f"最优解：{result.x}")
```

## 三、PuLP 使用指南

### 3.1 安装

```bash
pip install pulp
```

PuLP自带CBC求解器（免费开源），也可以调用Gurobi/CPLEX（如果安装了）。

### 3.2 线性规划示例

```python
import pulp

# 创建问题（最大化）
prob = pulp.LpProblem("生产计划", pulp.LpMaximize)

# 决策变量
x1 = pulp.LpVariable("产品A", lowBound=0)  # 产品A产量
x2 = pulp.LpVariable("产品B", lowBound=0)  # 产品B产量

# 目标函数：max 3x1 + 5x2
prob += 3 * x1 + 5 * x2, "总利润"

# 约束条件
prob += x1 <= 4, "原料1约束"
prob += 2 * x2 <= 12, "原料2约束"
prob += 3 * x1 + 2 * x2 <= 18, "工时约束"

# 求解
prob.solve(pulp.PULP_CBC_CMD(msg=0))  # msg=0关闭输出

print(f"状态：{pulp.LpStatus[prob.status]}")
print(f"产品A产量：{x1.value()}")
print(f"产品B产量：{x2.value()}")
print(f"总利润：{pulp.value(prob.objective)}")
```

### 3.3 整数规划示例

```python
import pulp

# 0-1背包问题
prob = pulp.LpProblem("背包问题", pulp.LpMaximize)

# 0-1变量：cat='Binary'
x = [pulp.LpVariable(f"物品{i}", cat='Binary') for i in range(5)]

weights = [2, 3, 4, 5, 6]
values = [3, 4, 5, 6, 7]
capacity = 10

# 目标：max Σv_i x_i
prob += sum(values[i] * x[i] for i in range(5))

# 约束：Σw_i x_i <= capacity
prob += sum(weights[i] * x[i] for i in range(5)) <= capacity

prob.solve(pulp.PULP_CBC_CMD(msg=0))

print(f"最大价值：{pulp.value(prob.objective)}")
for i in range(5):
    if x[i].value() > 0.5:
        print(f"  选物品{i}（重量{weights[i]}，价值{values[i]}）")
```

### 3.4 整数变量（非0-1）

```python
# 整数变量：cat='Integer'
x = pulp.LpVariable("数量", lowBound=0, cat='Integer')

# 连续变量：默认
y = pulp.LpVariable("价格", lowBound=0)
```

### 3.5 调用Gurobi求解器

```python
# 如果安装了Gurobi，可以直接调用
prob.solve(pulp.GUROBI_CMD(msg=0))
```

## 四、Gurobi 使用指南

### 4.1 安装和学术授权

1. 注册Gurobi账号：https://www.gurobi.com/
2. 申请学术免费许可（需要学校邮箱）
3. 安装：`pip install gurobipy`
4. 激活许可：`grbgetkey 你的密钥`

### 4.2 线性规划示例

```python
import gurobipy as gp
from gurobipy import GRB

# 创建模型
model = gp.Model("生产计划")

# 决策变量
x1 = model.addVar(lb=0, name="产品A")
x2 = model.addVar(lb=0, name="产品B")

# 目标函数
model.setObjective(3 * x1 + 5 * x2, GRB.MAXIMIZE)

# 约束
model.addConstr(x1 <= 4, "原料1")
model.addConstr(2 * x2 <= 12, "原料2")
model.addConstr(3 * x1 + 2 * x2 <= 18, "工时")

# 求解
model.optimize()

print(f"最优值：{model.objVal}")
print(f"产品A：{x1.x}")
print(f"产品B：{x2.x}")
```

### 4.3 整数规划示例

```python
import gurobipy as gp
from gurobipy import GRB

model = gp.Model("背包问题")

# 0-1变量：vtype=GRB.BINARY
n = 5
x = model.addVars(n, vtype=GRB.BINARY, name="x")

weights = [2, 3, 4, 5, 6]
values = [3, 4, 5, 6, 7]

model.setObjective(gp.quicksum(values[i] * x[i] for i in range(n)), GRB.MAXIMIZE)
model.addConstr(gp.quicksum(weights[i] * x[i] for i in range(n)) <= 10)

model.optimize()

print(f"最大价值：{model.objVal}")
for i in range(n):
    if x[i].x > 0.5:
        print(f"  选物品{i}")
```

### 4.4 Gurobi的优势

- **速度快**：比CBC快10-100倍（大规模问题）
- **功能强**：支持二次规划、多目标、灵敏度分析
- **调试方便**：可以输出不可行约束的冲突集（IIS）

```python
# 调试不可行模型
model.computeIIS()
model.write("infeasible.ilp")  # 写出最小不可行约束集
```

## 五、求解器选择建议

### 5.1 按问题类型

| 问题类型 | 推荐求解器 | 原因 |
|---------|-----------|------|
| 小规模线性规划 | scipy.linprog / PuLP | 简单方便 |
| 大规模线性规划 | Gurobi | 速度快 |
| 整数规划 | PuLP / Gurobi | scipy不支持 |
| 非线性规划 | scipy.minimize | Gurobi支持有限 |
| 多峰全局优化 | scipy.differential_evolution | 启发式全局搜索 |
| 二次规划 | Gurobi | 原生支持 |

### 5.2 按规模

| 规模 | 推荐 |
|------|------|
| 变量<100 | 任意求解器都可以 |
| 变量100-10000 | PuLP+CBC 或 Gurobi |
| 变量>10000 | Gurobi（CBC可能很慢） |

## 六、常见问题和调试技巧

### 6.1 模型不可行怎么办？

1. **检查约束方向**：<= 和 >= 写反了吗？
2. **检查边界**：变量上下界合理吗？
3. **Gurobi用IIS**：`model.computeIIS()` 找出最小不可行约束集
4. **松弛约束**：先去掉一些约束，看哪些是导致不可行的

### 6.2 求解太慢怎么办？

1. **减少整数变量**：能连续就不要整数
2. **添加有效约束**：剪掉不可能的解
3. **调整求解器参数**：
   ```python
   model.setParam('TimeLimit', 60)  # 时间限制60秒
   model.setParam('MIPGap', 0.01)   # 允许1%的最优性间隙
   ```
4. **换求解器**：CBC慢就换Gurobi

### 6.3 结果不对怎么办？

1. **打印约束**：看约束是否按预期建立
2. **小规模测试**：先用已知答案的小例子测试
3. **检查单位**：所有变量的单位一致吗？
4. **检查目标**：最大化还是最小化写对了吗？

---

## 七、比赛实战建议

1. **先用PuLP快速建模**：语法简单，不容易写错
2. **大规模再换Gurobi**：PuLP的模型可以直接调用Gurobi求解
3. **非线性用scipy**：PuLP/Gurobi不擅长非线性
4. **全局优化用启发式**：scipy的differential_evolution，或自己写GA/PSO
5. **保存模型**：`model.write("model.lp")` 可以查看模型文本，方便调试
