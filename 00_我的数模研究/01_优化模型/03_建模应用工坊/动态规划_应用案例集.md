## 案例一：资源分配问题（背包变种）

### 问题描述
某公司有50万元资金，可投资4个项目。每个项目的投资额和预期收益如下（单位：万元）：

| 项目 | 投资额 | 预期收益 |
|------|--------|---------|
| A | 10 | 15 |
| B | 20 | 35 |
| C | 15 | 25 |
| D | 25 | 45 |

每个项目只能投资一次（0-1选择），求最大收益。

### 数学建模
这就是标准的0-1背包问题：
- 物品重量 = 投资额
- 物品价值 = 预期收益
- 背包容量 = 50万

### 代码实现
```python
import sys
sys.path.insert(0, '02_算法实现手札')
from importlib import import_module
dp_mod = import_module('09_动态规划经典算法_手动实现')

weights = [10, 20, 15, 25]  # 投资额
values = [15, 35, 25, 45]   # 预期收益
capacity = 50

max_val, dp_table, selected = dp_mod.knapsack_01_2d(weights, values, capacity)
print(f"最大收益：{max_val}万元")
print(f"投资项目：{[chr(65+i) for i in selected]}")
```

### 结果分析
- 最优方案：投资B(20万,35万) + D(25万,45万) = 45万投入，80万收益
- 剩余5万资金未使用（因为没有更小的投资项目）

💡 **建模技巧**：资源分配是背包问题最直接的应用。如果项目可以投资多次（如分批投资），就变成完全背包。如果有预算约束+其他约束（如风险约束），就是多维背包。

## 案例二：网格最短路径问题

### 问题描述
在一个m×n的网格中，从左上角走到右下角，只能向右或向下走。每个格子有一个"代价"（如地形难度），求最小代价路径。

例：3×3网格
```
1  3  1
1  5  1
4  2  1
```
最小代价路径：1→3→1→1→1 = 7（右→右→下→下）

### 数学建模
**状态定义**：dp[i][j] = 从(0,0)走到(i,j)的最小代价

**状态转移**：
```
dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
```
（从上面来或从左边来，取较小的）

**初始条件**：
- dp[0][0] = grid[0][0]
- 第一行：只能从左边来，dp[0][j] = dp[0][j-1] + grid[0][j]
- 第一列：只能从上面来，dp[i][0] = dp[i-1][0] + grid[i][0]

### 代码实现
```python
def min_path_sum(grid):
    m, n = len(grid), len(grid[0])
    dp = [[0]*n for _ in range(m)]
    
    dp[0][0] = grid[0][0]
    # 第一行
    for j in range(1, n):
        dp[0][j] = dp[0][j-1] + grid[0][j]
    # 第一列
    for i in range(1, m):
        dp[i][0] = dp[i-1][0] + grid[i][0]
    # 其他格子
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
    
    # 回溯路径
    path = []
    i, j = m-1, n-1
    while i > 0 or j > 0:
        path.append((i, j))
        if i == 0:
            j -= 1
        elif j == 0:
            i -= 1
        elif dp[i-1][j] < dp[i][j-1]:
            i -= 1
        else:
            j -= 1
    path.append((0, 0))
    path.reverse()
    
    return dp[m-1][n-1], path

grid = [[1,3,1],[1,5,1],[4,2,1]]
min_cost, path = min_path_sum(grid)
print(f"最小代价：{min_cost}")
print(f"路径：{path}")
```

### 结果分析
- 最小代价：7
- 路径：(0,0)→(0,1)→(0,2)→(1,2)→(2,2)
- 对应代价：1+3+1+1+1=7

💡 **建模技巧**：网格路径问题是二维DP的经典应用。如果可以走8个方向（斜着走），状态转移要考虑8个邻居。如果有障碍物，遇到障碍物时dp设为无穷大。

## 案例三：生产计划问题（多阶段决策）

### 问题描述
某工厂生产某种产品，未来4个月的需求量分别为：[2, 3, 2, 4]（单位：百件）。
- 每月生产能力：5百件
- 每件生产成本：1万元（固定）+ 2万元（可变，与产量相关）
- 每件每月库存成本：0.5万元
- 初始库存=0，期末库存=0

求最小总成本的生产计划。

### 数学建模
**状态定义**：dp[i][s] = 第i个月末库存为s时的最小总成本

**状态转移**：
```
dp[i][s] = min over x (生产x件):
    dp[i-1][s + d_i - x] + 生产成本(x) + 库存成本(s)
```
其中d_i是第i月需求，x是第i月产量，s是月末库存。

约束：
- 0 ≤ x ≤ 5（生产能力）
- s ≥ 0（库存非负）
- s + d_i - x ≥ 0（上月库存+本月产量 ≥ 本月需求）

### 代码实现
```python
def production_plan(demand, capacity=5, setup_cost=1, var_cost=2, hold_cost=0.5):
    n = len(demand)
    max_inv = capacity  # 最大库存
    
    # dp[i][s]：第i月末库存s的最小成本
    INF = float('inf')
    dp = [[INF] * (max_inv + 1) for _ in range(n)]
    
    # 第一个月
    for s in range(max_inv + 1):
        x = demand[0] + s  # 产量 = 需求 + 月末库存
        if 0 <= x <= capacity:
            cost = (setup_cost + var_cost * x if x > 0 else 0) + hold_cost * s
            dp[0][s] = cost
    
    # 后续月份
    for i in range(1, n):
        for s in range(max_inv + 1):
            for x in range(capacity + 1):
                prev_s = s + demand[i] - x  # 上月库存
                if 0 <= prev_s <= max_inv and dp[i-1][prev_s] < INF:
                    prod_cost = (setup_cost + var_cost * x) if x > 0 else 0
                    total = dp[i-1][prev_s] + prod_cost + hold_cost * s
                    dp[i][s] = min(dp[i][s], total)
    
    # 期末库存必须为0
    return dp[n-1][0], dp

demand = [2, 3, 2, 4]
min_cost, dp = production_plan(demand)
print(f"最小总成本：{min_cost}万元")
```

### 结果分析
- 最优生产计划需要通过回溯得到
- 关键权衡：多生产可以节省固定成本，但增加库存成本
- 这是典型的"多阶段决策"问题，DP天然适合

💡 **建模技巧**：生产计划、库存管理、供应链优化都是多阶段决策DP。状态通常是"期末库存"，决策是"本期产量"。如果有多个产品，状态维度会增加。

## 案例四：DNA序列比对（LCS应用）

### 问题描述
两条DNA序列，求它们的最长公共子序列，用于判断基因相似性。

序列A：`ATCGGCTAGCTA`
序列B：`ATCGCTAGCTA`

### 数学建模
直接用LCS算法，字符集为{A, T, C, G}。

### 代码实现
```python
import sys
sys.path.insert(0, '02_算法实现手札')
from importlib import import_module
dp_mod = import_module('09_动态规划经典算法_手动实现')

seq_a = "ATCGGCTAGCTA"
seq_b = "ATCGCTAGCTA"

length, lcs_str, dp = dp_mod.lcs(seq_a, seq_b)
print(f"序列A：{seq_a}")
print(f"序列B：{seq_b}")
print(f"LCS长度：{length}")
print(f"LCS：{lcs_str}")
print(f"相似度：{length/len(seq_a)*100:.1f}%")
```

### 结果分析
- LCS长度：11（序列A长度12，差异在第5位多了一个G）
- 相似度：91.7%
- 这两条序列高度相似，可能是同源基因

💡 **建模技巧**：生物信息学中，序列比对是DP最重要的应用之一。LCS是最简单的比对，更精确的是"带空位罚分的序列比对"（Needleman-Wunsch算法），本质也是DP，只是状态转移更复杂。

## 案例五：多期投资组合优化

### 问题描述
初始资金100万，投资3年。每年可以选择：
- 保守投资：年收益5%，无风险
- 激进投资：年收益20%（概率0.6）或 -10%（概率0.4）

每年末可以调整投资比例。求3年末的期望最大资金。

### 数学建模
这是一个随机动态规划问题（马尔可夫决策过程MDP）。

**状态**：(年份, 当前资金)
**决策**：投资比例（保守比例p，激进比例1-p）
**转移**：资金随收益随机变化

因为资金是连续的，需要离散化。假设资金以10万为单位，范围[0, 200]。

### 代码实现
```python
def multi_period_investment(initial=100, years=3, 
                            risk_free=0.05, aggressive_up=0.2, aggressive_down=-0.1,
                            prob_up=0.6, step=10):
    max_money = 200  # 资金上限（离散化）
    n_states = max_money // step + 1
    
    # dp[year][money] = 第year年末有money万时，后续的最大期望资金
    dp = [[0.0] * n_states for _ in range(years + 1)]
    
    # 最后一年末：就是当前资金
    for m in range(n_states):
        dp[years][m] = m * step
    
    # 逆推
    for year in range(years - 1, -1, -1):
        for m in range(n_states):
            money = m * step
            best = 0
            # 枚举投资比例（10%为步长）
            for p_aggr in range(0, 11):  # 激进投资比例 0%, 10%, ..., 100%
                p = p_aggr / 10
                # 上涨后的资金
                money_up = money * (1 + risk_free * (1-p) + aggressive_up * p)
                # 下跌后的资金
                money_down = money * (1 + risk_free * (1-p) + aggressive_down * p)
                
                # 离散化
                idx_up = min(int(money_up / step), n_states - 1)
                idx_down = min(int(money_down / step), n_states - 1)
                
                # 期望
                expected = prob_up * dp[year+1][idx_up] + (1-prob_up) * dp[year+1][idx_down]
                best = max(best, expected)
            
            dp[year][m] = best
    
    initial_idx = initial // step
    return dp[0][initial_idx], dp

max_expected, dp = multi_period_investment()
print(f"初始资金100万，3年后期望最大资金：{max_expected:.1f}万元")
```

### 结果分析
- 期望最大资金约120-130万（取决于参数）
- 最优策略：早期可以多配置激进投资（时间长，能承受波动），后期转向保守
- 这就是"生命周期投资"的理论基础

💡 **建模技巧**：随机DP（MDP）是动态规划的重要扩展。状态转移是随机的，目标是最大化期望。强化学习就是MDP的近似求解。在建模比赛中，如果问题有不确定性（如需求随机、价格波动），可以考虑随机DP。

## 建模技巧总结

### 1. 如何判断一个问题能不能用DP？
- 问自己：大问题的最优解能不能由小问题的最优解组合得到？（最优子结构）
- 问自己：同一个小问题会不会被反复计算？（重叠子问题）
- 两个都满足 → 可以用DP

### 2. DP解题的标准流程
1. **暴力递归**：先不管效率，写出正确的递归解法
2. **加记忆化**：发现重复计算，加个字典存中间结果
3. **改迭代**：把递归改成循环，从底往上算
4. **优化空间**：看能不能用滚动数组降维

### 3. 常见DP模式
| 模式 | 状态定义 | 典型问题 |
|------|---------|---------|
| 前缀型 | dp[i] = 前i个的最优 | 爬楼梯、打家劫舍 |
| 区间型 | dp[i][j] = 区间[i,j]的最优 | 矩阵链、石子合并 |
| 背包型 | dp[i][j] = 前i个物品容量j | 0-1背包、完全背包 |
| 序列型 | dp[i][j] = 两个序列前i,j | LCS、编辑距离 |
| 网格型 | dp[i][j] = 走到(i,j)的最优 | 最短路径、障碍物 |
| 状态压缩 | dp[mask] = 选了mask集合 | TSP、集合覆盖 |

### 4. 比赛中的注意事项
- n≤20：可以考虑状态压缩DP（2^n）
- n≤1000：二维DP（n²）
- n≤10^5：需要O(n log n)的DP（如LIS二分优化）
- n≤10^6：只能O(n)的一维DP
- 状态空间太大时，考虑用记忆化搜索（只算需要的状态）
