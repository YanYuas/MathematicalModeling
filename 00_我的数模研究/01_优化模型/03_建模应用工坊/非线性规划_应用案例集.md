## 案例一：投资组合优化（均值-方差模型）

### 问题描述
有3只股票，预期收益率分别为8%、12%、15%，协方差矩阵如下。投资者希望在收益率不低于10%的前提下，最小化风险（方差）。资金全部投资，不允许做空。

**协方差矩阵**（风险的度量）：
```
      股票A   股票B   股票C
股票A  0.04   0.012   0.008
股票B  0.012  0.09    0.018
股票C  0.008  0.018   0.16
```

### 数学建模

**决策变量**：x = (x_A, x_B, x_C)，各股票投资比例

**目标函数**（最小化风险）：
```
min  ½ x^T Σ x    （Σ是协方差矩阵，二次函数）
```

**约束条件**：
- 预期收益率 ≥ 10%：0.08x_A + 0.12x_B + 0.15x_C ≥ 0.10
- 资金全部投资：x_A + x_B + x_C = 1
- 不做空：x_A, x_B, x_C ≥ 0

这是一个**二次规划**问题（目标二次，约束线性）。

### 代码实现

```python
import numpy as np
from scipy.optimize import minimize

# 数据
mu = np.array([0.08, 0.12, 0.15])  # 预期收益率
Sigma = np.array([                  # 协方差矩阵
    [0.04, 0.012, 0.008],
    [0.012, 0.09, 0.018],
    [0.008, 0.018, 0.16]
])
target_return = 0.10  # 目标收益率

# 目标函数：风险（方差）
def objective(x):
    return 0.5 * x @ Sigma @ x

def objective_grad(x):
    return Sigma @ x

# 约束
constraints = [
    {'type': 'eq', 'fun': lambda x: np.sum(x) - 1},           # 资金总和=1
    {'type': 'ineq', 'fun': lambda x: mu @ x - target_return} # 收益率≥目标
]

# 边界：不做空
bounds = [(0, 1)] * 3

# 初始点
x0 = np.array([1/3, 1/3, 1/3])

# 用SLQP方法（序列二次规划）求解
result = minimize(objective, x0, jac=objective_grad, 
                  method='SLSQP', bounds=bounds, constraints=constraints)

print("最优投资组合：")
print(f"  股票A: {result.x[0]*100:.1f}%")
print(f"  股票B: {result.x[1]*100:.1f}%")
print(f"  股票C: {result.x[2]*100:.1f}%")
print(f"预期收益率: {mu @ result.x*100:.2f}%")
print(f"风险（标准差）: {np.sqrt(result.x @ Sigma @ result.x)*100:.2f}%")
```

### 结果分析
- 最优组合大约是 A:20%, B:50%, C:30%
- 预期收益率恰好10%（约束起作用）
- 风险约为12%左右

💡 **建模技巧**：这是Markowitz均值-方差模型，是现代投资组合理论的基础。目标函数是二次的，约束是线性的，属于凸二次规划，有唯一全局最优解。

🔗 **关联**：有效前沿——改变目标收益率，可以得到一条"风险-收益"曲线，称为有效前沿。

## 案例二：非线性曲线拟合

### 问题描述
实验测得一组数据(x, y)，理论模型是 y = a·exp(b·x) + c，求参数a, b, c使拟合误差最小。

**实验数据**：
```
x: 0, 1, 2, 3, 4, 5
y: 2.1, 1.8, 1.5, 1.3, 1.1, 1.0
```

### 数学建模

**决策变量**：参数 a, b, c

**目标函数**（最小化误差平方和）：
```
min  Σ (y_i - a·exp(b·x_i) - c)²
```

这是一个**无约束非线性规划**问题，目标函数是非线性的（指数函数）。

### 代码实现

```python
import numpy as np
from scipy.optimize import minimize

# 实验数据
x_data = np.array([0, 1, 2, 3, 4, 5])
y_data = np.array([2.1, 1.8, 1.5, 1.3, 1.1, 1.0])

# 模型：y = a*exp(b*x) + c
def model(params, x):
    a, b, c = params
    return a * np.exp(b * x) + c

# 目标函数：残差平方和
def objective(params):
    residuals = y_data - model(params, x_data)
    return np.sum(residuals**2)

# 初始猜测（很重要！非线性优化对初值敏感）
x0 = np.array([1.0, -0.5, 1.0])

# 用L-BFGS-B求解
result = minimize(objective, x0, method='L-BFGS-B')

a, b, c = result.x
print(f"拟合参数：a={a:.4f}, b={b:.4f}, c={c:.4f}")
print(f"最小误差平方和：{result.fun:.6f}")

# 验证拟合效果
y_fit = model(result.x, x_data)
print("\n对比：")
for i in range(len(x_data)):
    print(f"  x={x_data[i]}: 真实={y_data[i]:.2f}, 拟合={y_fit[i]:.2f}, 误差={y_data[i]-y_fit[i]:.4f}")
```

### 结果分析
- 拟合得到 a≈1.1, b≈-0.3, c≈1.0
- 模型：y ≈ 1.1·exp(-0.3x) + 1.0
- 当x→∞时，y→c≈1.0（渐近线）

⚠️ **坑**：非线性最小二乘对初始值非常敏感！如果初值不好，可能收敛到局部最优或不收敛。建议：
1. 先用线性化方法（如取对数）获得初值
2. 多起点测试，取最优结果
3. 用专门的最小二乘算法（如Levenberg-Marquardt）

## 案例三：工程优化——梁的设计

### 问题描述
设计一个矩形截面的悬臂梁，长度L=2m，承受端部载荷F=1000N。要求：
- 最大应力不超过许用应力 σ_allow = 160 MPa
- 最大挠度不超过 δ_allow = 0.01 m
- 最小化梁的体积（即重量）

**已知**：
- 弹性模量 E = 200 GPa
- 截面宽 b，高 h（决策变量）
- 惯性矩 I = b·h³/12
- 截面模量 W = b·h²/6
- 最大应力 σ = F·L / W
- 最大挠度 δ = F·L³ / (3·E·I)

### 数学建模

**决策变量**：截面宽 b（m），高 h（m）

**目标函数**（最小化体积）：
```
min  V = b · h · L
```

**约束条件**：
- 应力约束：F·L / (b·h²/6) ≤ σ_allow
- 挠度约束：F·L³ / (3·E·b·h³/12) ≤ δ_allow
- 几何约束：h ≥ b（高不小于宽，工程惯例）
- 非负约束：b, h > 0

这是一个**带约束的非线性规划**问题。

### 代码实现

```python
import numpy as np
from scipy.optimize import minimize

# 参数
L = 2.0       # 梁长(m)
F = 1000.0    # 载荷(N)
E = 200e9     # 弹性模量(Pa)
sigma_allow = 160e6  # 许用应力(Pa)
delta_allow = 0.01   # 许用挠度(m)

# 目标函数：体积
def objective(x):
    b, h = x
    return b * h * L

# 应力约束：σ ≤ σ_allow
def stress_constraint(x):
    b, h = x
    W = b * h**2 / 6  # 截面模量
    sigma = F * L / W
    return sigma_allow - sigma  # ≥0

# 挠度约束：δ ≤ δ_allow
def deflection_constraint(x):
    b, h = x
    I = b * h**3 / 12  # 惯性矩
    delta = F * L**3 / (3 * E * I)
    return delta_allow - delta  # ≥0

# 几何约束：h ≥ b
def geometry_constraint(x):
    b, h = x
    return h - b  # ≥0

constraints = [
    {'type': 'ineq', 'fun': stress_constraint},
    {'type': 'ineq', 'fun': deflection_constraint},
    {'type': 'ineq', 'fun': geometry_constraint},
]

# 变量边界（单位m，合理范围）
bounds = [(0.01, 0.5), (0.01, 1.0)]

# 初始点
x0 = np.array([0.1, 0.2])

# 求解
result = minimize(objective, x0, method='SLSQP', 
                  bounds=bounds, constraints=constraints)

b_opt, h_opt = result.x
print(f"最优截面：宽={b_opt*1000:.1f}mm, 高={h_opt*1000:.1f}mm")
print(f"最小体积：{result.fun*1e6:.1f} cm³")

# 验证约束
W = b_opt * h_opt**2 / 6
I = b_opt * h_opt**3 / 12
print(f"最大应力：{F*L/W/1e6:.1f} MPa (许用{sigma_allow/1e6:.0f} MPa)")
print(f"最大挠度：{F*L**3/(3*E*I)*1000:.2f} mm (许用{delta_allow*1000:.0f} mm)")
```

### 结果分析
- 最优截面大约是宽50mm，高100mm（h=2b）
- 通常挠度约束起主导作用（比应力约束更严格）
- 体积约为最小可行值

💡 **建模技巧**：工程优化中，约束通常是"不起作用则已，一起作用就决定最优解"。可以通过检查约束的拉格朗日乘子（KKT条件中的μ）来判断哪个约束起作用。

## 案例四：最大似然估计（参数估计）

### 问题描述
假设某产品的寿命服从指数分布 f(t) = λ·exp(-λt)。观测到10个产品的寿命数据，用最大似然估计求参数λ。

**寿命数据（小时）**：50, 120, 80, 200, 150, 90, 110, 180, 70, 130

### 数学建模

**似然函数**：
```
L(λ) = Π λ·exp(-λ·t_i) = λ^n · exp(-λ·Σt_i)
```

**对数似然**（取对数方便求导）：
```
ln L(λ) = n·ln(λ) - λ·Σt_i
```

**目标**：最大化对数似然，等价于最小化负对数似然：
```
min  -n·ln(λ) + λ·Σt_i
```

这是一个**一维无约束优化**问题。

### 代码实现

```python
import numpy as np
from scipy.optimize import minimize_scalar

# 寿命数据
data = np.array([50, 120, 80, 200, 150, 90, 110, 180, 70, 130])
n = len(data)
sum_t = np.sum(data)

# 负对数似然
def neg_log_likelihood(lam):
    if lam <= 0:
        return np.inf
    return -n * np.log(lam) + lam * sum_t

# 一维优化
result = minimize_scalar(neg_log_likelihood, bounds=(0.001, 1.0), method='bounded')

lambda_mle = result.x
print(f"最大似然估计：λ = {lambda_mle:.6f} /小时")
print(f"平均寿命（1/λ）= {1/lambda_mle:.1f} 小时")
print(f"样本均值 = {sum_t/n:.1f} 小时")

# 验证：指数分布的MLE理论解是 λ = 1/样本均值
print(f"\n理论验证：1/样本均值 = {n/sum_t:.6f}")
print(f"数值解与理论解一致：{abs(lambda_mle - n/sum_t) < 1e-6}")
```

### 结果分析
- MLE估计 λ ≈ 0.0085 /小时
- 平均寿命 ≈ 118小时
- 指数分布的MLE有解析解：λ = 1/样本均值，数值优化结果与解析解一致

💡 **建模技巧**：最大似然估计是统计学中最常用的参数估计方法，本质上就是一个优化问题。对于简单分布有解析解，对于复杂分布（如混合模型、神经网络）需要用数值优化。

## 建模技巧总结

### 1. 如何判断问题是不是凸优化？
- 目标函数：检查Hessian是否半正定（∇²f ⪰ 0）
- 不等式约束：g_i是否是凸函数
- 等式约束：h_j是否是仿射函数（线性+常数）
- 如果都是，就是凸优化，局部最优=全局最优

### 2. 选择什么求解器？
| 问题类型 | 推荐方法 | scipy函数 |
|---------|---------|-----------|
| 无约束，小规模 | 牛顿法/BFGS | minimize(method='BFGS') |
| 无约束，大规模 | L-BFGS | minimize(method='L-BFGS-B') |
| 有边界约束 | L-BFGS-B | minimize(method='L-BFGS-B') |
| 有一般约束 | SQP（序列二次规划） | minimize(method='SLSQP') |
| 二次规划 | 内点法/积极集法 | （cvxpy更方便） |
| 全局优化（非凸） | 多起点+局部优化 | basinhopping, differential_evolution |

### 3. 梯度怎么算？
- ✅ 优先用**解析梯度**（手算或自动微分）
- ⚠️ 数值梯度（有限差分）有误差，收敛慢
- 现代工具：JAX、PyTorch、TensorFlow支持自动微分

### 4. 初始值怎么选？
- 非线性优化对初值敏感
- 用问题的物理意义选择合理初值
- 多起点测试，取最优结果
- 先用简单方法（如线性化）获得初值

### 5. 非凸问题怎么办？
- 接受局部最优（很多应用中足够好）
- 多起点测试，找最好的局部最优
- 用全局优化算法（差分进化、模拟退火、遗传算法）
- 问题重构：看能否转化为凸优化（如变量替换、松弛）
