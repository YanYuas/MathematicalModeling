# 国赛真题案例：2020年B题 穿越沙漠

## 一、题目背景

玩家在沙漠中从起点出发，携带水和食物，经过不同天气（晴朗、高温、沙暴），到达终点。途中可以在矿山挖矿赚钱，在村庄购买物资。目标是在规定天数内到达终点，使剩余资金最多。

### 关键参数
- 起点：有初始资金10000元，可购买水和食物
- 终点：到达后剩余水和食物可按一定价格卖出
- 矿山：挖矿收益，但消耗更多水和食物
- 村庄：可以购买水和食物（价格比起点高）
- 天气：晴朗、高温、沙暴，不同天气消耗不同
- 负重限制：水和食物总重量不超过上限

---

## 二、问题分析

### 2.1 问题本质
这是一个**多阶段决策问题**，每天需要决定：
1. 前往哪个地点（起点/终点/矿山/村庄/沙暴区）
2. 是否在矿山挖矿
3. 是否在村庄购买物资

### 2.2 状态定义
每一天的状态由以下因素决定：
- 当前所在位置
- 当前天数
- 剩余水量
- 剩余食物量
- 剩余资金

### 2.3 为什么用动态规划
- 多阶段决策：每天是一个阶段
- 最优子结构：从某天到终点的最优策略，与之前的决策无关
- 重叠子问题：不同路径可能到达同一状态

---

## 三、模型建立

### 3.1 第一问：只有一种天气（已知天气）

#### 决策变量
设第 t 天在位置 p，剩余水 w、食物 f、资金 m 时：
- xₜ：第 t 天的行动（移动/挖矿/停留）
- dₜ：第 t 天的目的地

#### 状态转移方程
```
dp[t][p][w][f] = 第t天在位置p、剩余水w、食物f时的最大资金

转移：
1. 移动到相邻位置p'：
   dp[t+1][p'][w-w消耗][f-f消耗] = max(..., dp[t][p][w][f])

2. 在矿山挖矿：
   dp[t+1][p][w-w挖矿][f-f挖矿] = max(..., dp[t][p][w][f] + 挖矿收益)

3. 停留：
   dp[t+1][p][w-w停留][f-f停留] = max(..., dp[t][p][w][f])

4. 在村庄购买：
   dp[t][p][w+Δw][f+Δf] = max(..., dp[t][p][w][f] - 花费)
```

#### 边界条件
```
dp[0][起点][初始水][初始食物] = 初始资金
其他状态 = -∞
```

#### 目标函数
```
max dp[T][终点][w][f] + 剩余物资卖出收入
```

### 3.2 第二问：天气未知（需要考虑所有可能）

天气是随机的，需要用**期望最大化**或**鲁棒优化**。

#### 方法1：期望动态规划
```
dp[t][p][w][f] = max over actions of E[dp[t+1][...]]
```
对每种天气按概率加权。

#### 方法2：最坏情况优化（鲁棒）
```
dp[t][p][w][f] = max over actions of min over weather of dp[t+1][...]
```
保证在最坏天气下也能到达。

## 四、核心代码框架（Python）

```python
import numpy as np
from collections import defaultdict

# ============ 参数设置 ============
# 地图：位置编号 0=起点, 1=矿山, 2=村庄, 3=终点, 4+=沙暴区
# 邻接关系
adj = {
    0: [1, 4],      # 起点可去矿山或沙暴区
    1: [0, 2, 4],   # 矿山可去起点、村庄、沙暴区
    2: [1, 3, 4],   # 村庄可去矿山、终点、沙暴区
    3: [],          # 终点
    4: [0, 1, 2, 3] # 沙暴区
}

# 不同天气下的消耗（水, 食物）
consumption = {
    '晴朗': {'移动': (3, 2), '挖矿': (4, 3), '停留': (1, 1)},
    '高温': {'移动': (6, 4), '挖矿': (8, 6), '停留': (2, 2)},
    '沙暴': {'移动': (10, 8), '挖矿': (12, 10), '停留': (3, 3)}
}

# 价格
prices = {
    '起点': {'水': 5, '食物': 10},
    '村庄': {'水': 10, '食物': 20},
    '终点': {'水': 2, '食物': 5}  # 卖出价格
}

mining_income = 1000  # 挖矿一天收益
max_days = 30         # 最大天数
max_weight = 1200     # 最大负重（水和食物总重量）
water_weight = 3      # 每单位水重量
food_weight = 2       # 每单位食物重量

# ============ 动态规划 ============
def solve(weather_forecast):
    """
    weather_forecast: 每天的天气列表
    返回：最大资金和最优路径
    """
    # dp[day][pos][water][food] = 最大资金
    # 用字典稀疏存储
    dp = defaultdict(lambda: -float('inf'))
    parent = {}  # 记录路径

    # 初始状态：第0天在起点，初始购买后
    initial_water = 100
    initial_food = 100
    initial_money = 10000 - initial_water * 5 - initial_food * 10
    dp[(0, 0, initial_water, initial_food)] = initial_money

    for day in range(max_days):
        weather = weather_forecast[day]
        # 遍历所有当前状态
        current_states = [(k, v) for k, v in dp.items()
                          if k[0] == day and v > -float('inf')]

        for (t, pos, water, food), money in current_states:
            # 行动1：移动到相邻位置
            for next_pos in adj[pos]:
                w_cost, f_cost = consumption[weather]['移动']
                new_water = water - w_cost
                new_food = food - f_cost
                if new_water >= 0 and new_food >= 0:
                    new_state = (day + 1, next_pos, new_water, new_food)
                    if money > dp[new_state]:
                        dp[new_state] = money
                        parent[new_state] = ('移动', (t, pos, water, food))

            # 行动2：挖矿（仅在矿山）
            if pos == 1:
                w_cost, f_cost = consumption[weather]['挖矿']
                new_water = water - w_cost
                new_food = food - f_cost
                if new_water >= 0 and new_food >= 0:
                    new_money = money + mining_income
                    new_state = (day + 1, pos, new_water, new_food)
                    if new_money > dp[new_state]:
                        dp[new_state] = new_money
                        parent[new_state] = ('挖矿', (t, pos, water, food))

            # 行动3：停留
            w_cost, f_cost = consumption[weather]['停留']
            new_water = water - w_cost
            new_food = food - f_cost
            if new_water >= 0 and new_food >= 0:
                new_state = (day + 1, pos, new_water, new_food)
                if money > dp[new_state]:
                    dp[new_state] = money
                    parent[new_state] = ('停留', (t, pos, water, food))

            # 行动4：在村庄购买
            if pos == 2:
                for buy_w in range(0, 50, 10):
                    for buy_f in range(0, 50, 10):
                        cost = buy_w * 10 + buy_f * 20
                        if money >= cost:
                            new_water = water + buy_w
                            new_food = food + buy_f
                            if (new_water * water_weight + new_food * food_weight) <= max_weight:
                                new_state = (day, pos, new_water, new_food)
                                new_money = money - cost
                                if new_money > dp[new_state]:
                                    dp[new_state] = new_money
                                    parent[new_state] = ('购买', (t, pos, water, food))

    # 找终点的最优解
    best_money = -float('inf')
    best_state = None
    for (t, pos, water, food), money in dp.items():
        if pos == 3 and t <= max_days:  # 到达终点
            # 卖出剩余物资
            final_money = money + water * 2 + food * 5
            if final_money > best_money:
                best_money = final_money
                best_state = (t, pos, water, food)

    return best_money, best_state, parent


# ============ 回溯路径 ============
def reconstruct_path(best_state, parent):
    path = []
    state = best_state
    while state in parent:
        action, prev_state = parent[state]
        path.append((action, state))
        state = prev_state
    path.reverse()
    return path


# ============ 测试 ============
if __name__ == "__main__":
    # 假设30天天气
    weather = ['晴朗'] * 10 + ['高温'] * 10 + ['沙暴'] * 10
    best_money, best_state, parent = solve(weather)
    print(f"最大资金: {best_money}")
    path = reconstruct_path(best_state, parent)
    for action, state in path:
        print(f"第{state[0]}天: {action}, 位置{state[1]}, 水{state[2]}, 食物{state[3]}")
```

## 五、解题技巧总结

### 5.1 状态压缩
- 水量和食物量不需要每个整数都存，可以按步长（如10）离散化
- 用字典稀疏存储，只存可达状态
- 资金不需要作为状态（因为资金不影响消耗，只影响购买能力）

### 5.2 剪枝策略
- 同一位置、同一天、水和食物都更多但资金更少的状态，可以剪掉
- 超过最大天数的状态不扩展

### 5.3 天气处理
- 第一问：天气已知，直接用确定性动态规划
- 第二问：天气未知，用随机动态规划，对天气取期望
- 可以用蒙特卡洛模拟验证策略的鲁棒性

### 5.4 矿山策略
- 挖矿收益高但消耗大，需要在水和食物充足时去
- 通常策略：先去矿山挖几天，再去村庄补给，最后去终点

## 六、常见错误

1. **忘记负重限制**：购买物资时要检查总重量
2. **忽略沙暴天不能移动**：沙暴天只能停留或挖矿（题目设定）
3. **状态空间爆炸**：水和食物范围太大，需要离散化
4. **资金作为状态**：资金不影响消耗，不需要作为状态维度
5. **终点卖出价格**：到达终点后剩余物资可以卖出，不要忘记
