## 案例一：函数优化（DE vs PSO vs GA）

### 问题描述
求Rastrigin函数的最小值：
```
f(x) = Σ [x_i² - 10cos(2πx_i) + 10], x_i ∈ [-5.12, 5.12]
```
10维，全局最优f(0,0,...,0) = 0。这个函数有大量局部最优，是测试启发式算法的经典问题。

### 算法选择
Rastrigin是多峰连续优化问题，首选DE和PSO（连续优化强），GA作为对比。

### 代码实现
```python
import sys
sys.path.insert(0, '02_算法实现手札')
from importlib import import_module
heur = import_module('10_启发式算法_统一对比框架')

bounds = [(-5.12, 5.12)] * 10

for name in ['DE', 'PSO', 'GA']:
    result = heur.ALGORITHMS[name](heur.rastrigin, bounds, n_iter=500, seed=42)
    print(f"{name}: best_f = {result['best_f']:.6f}, time = {result['time']:.3f}s")
```

### 结果分析
- DE通常能收敛到接近0（<0.01）
- PSO容易早熟，可能停在局部最优
- GA收敛慢，但多样性好

💡 **技巧**：Rastrigin这种多峰函数，DE的差分变异能有效跳出局部最优。如果PSO效果不好，可以调大惯性权重w或增加种群大小。

## 案例二：旅行商问题TSP（ACO）

### 问题描述
10个城市，坐标随机生成。求经过所有城市恰好一次并回到起点的最短路径。

### 算法选择
TSP是离散组合优化问题，ACO天然适合（信息素+概率选择）。也可以用GA（路径编码）。

### 代码实现
```python
import numpy as np

# 生成10个随机城市
np.random.seed(42)
cities = np.random.rand(10, 2) * 100
n = len(cities)

# 距离矩阵
dist = np.zeros((n, n))
for i in range(n):
    for j in range(n):
        dist[i][j] = np.sqrt(np.sum((cities[i] - cities[j])**2))

# 简化版ACO for TSP
def aco_tsp(dist, n_ants=20, n_iter=100, alpha=1, beta=5, rho=0.5, Q=100):
    n = len(dist)
    tau = np.ones((n, n))  # 信息素
    best_path = None
    best_len = float('inf')
    
    for it in range(n_iter):
        all_paths = []
        all_lens = []
        
        for ant in range(n_ants):
            # 每只蚂蚁从随机城市出发
            path = [np.random.randint(n)]
            unvisited = set(range(n)) - {path[0]}
            
            while unvisited:
                # 计算选择概率
                cur = path[-1]
                probs = []
                for j in unvisited:
                    eta = 1.0 / (dist[cur][j] + 1e-10)
                    probs.append((tau[cur][j]**alpha) * (eta**beta))
                probs = np.array(probs) / sum(probs)
                
                # 轮盘赌选择
                next_city = list(unvisited)[np.random.choice(len(unvisited), p=probs)]
                path.append(next_city)
                unvisited.remove(next_city)
            
            # 回到起点
            path.append(path[0])
            path_len = sum(dist[path[i]][path[i+1]] for i in range(n))
            all_paths.append(path)
            all_lens.append(path_len)
            
            if path_len < best_len:
                best_len = path_len
                best_path = path
        
        # 信息素挥发
        tau = (1 - rho) * tau
        
        # 信息素释放
        for path, path_len in zip(all_paths, all_lens):
            for i in range(n):
                tau[path[i]][path[i+1]] += Q / path_len
    
    return best_path, best_len

best_path, best_len = aco_tsp(dist)
print(f"最短路径长度：{best_len:.2f}")
print(f"路径：{best_path}")
```

### 结果分析
- ACO能在100次迭代内找到较好的路径
- 信息素正反馈让好路径被越来越多的蚂蚁选择
- β（启发式重要度）通常取2-5，太大会贪心，太小会随机

💡 **技巧**：TSP是ACO的经典应用。如果城市数很多（>100），可以用2-opt局部搜索改进ACO的解（ACO+局部搜索=MMAS）。

## 案例三：神经网络权重优化（GA）

### 问题描述
用遗传算法优化一个简单神经网络的权重，解决XOR问题。

神经网络结构：2输入→2隐藏→1输出，共6个权重+3个偏置=9个参数。

### 算法选择
神经网络权重优化是连续高维问题，但GA的种群搜索能避免梯度消失/局部最优。这里用GA作为示例。

### 代码实现
```python
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def neural_net(x, weights):
    # 解包权重
    w1 = weights[:4].reshape(2, 2)  # 输入→隐藏
    b1 = weights[4:6]               # 隐藏层偏置
    w2 = weights[6:8]               # 隐藏→输出
    b2 = weights[8]                 # 输出偏置
    
    hidden = sigmoid(x @ w1 + b1)
    output = sigmoid(hidden @ w2 + b2)
    return output

# XOR数据
X = np.array([[0,0],[0,1],[1,0],[1,1]])
y = np.array([0, 1, 1, 0])

def fitness(weights):
    pred = np.array([neural_net(x, weights) for x in X])
    return np.mean((pred - y)**2)  # MSE，越小越好

# 用GA优化
import sys
sys.path.insert(0, '02_算法实现手札')
from importlib import import_module
heur = import_module('10_启发式算法_统一对比框架')

bounds = [(-5, 5)] * 9  # 9个参数
result = heur.genetic_algorithm(fitness, bounds, n_iter=500, pop_size=100, seed=42)
print(f"最小MSE：{result['best_f']:.6f}")
print(f"预测值：{[neural_net(x, result['best_x'])[0] for x in X]}")
```

### 结果分析
- GA能找到MSE<0.01的权重，解决XOR问题
- 神经网络的损失函数有很多局部最优，GA的种群搜索比梯度下降更鲁棒
- 但GA比梯度下降慢很多，实际中还是用反向传播

💡 **技巧**：GA优化神经网络适合小网络、不可导的激活函数、或强化学习中的策略优化。大网络还是用梯度下降。

## 案例四：参数调优（SA）

### 问题描述
一个模拟模型有3个参数，需要调参使输出接近期望值。模型是黑盒（不可导），每次评估需要1秒。

### 算法选择
黑盒优化、单解改进，SA适合。也可以用PSO或DE，但SA实现最简单。

### 代码实现
```python
import numpy as np

# 模拟黑盒模型（实际中是某个仿真程序）
def black_box_model(params):
    a, b, c = params
    # 假设真实最优是a=2, b=3, c=1
    return (a-2)**2 + (b-3)**2 + (c-1)**2 + 0.1*np.random.randn()

def objective(params):
    # 运行5次取平均，减少噪声
    return np.mean([black_box_model(params) for _ in range(5)])

# 用SA优化
import sys
sys.path.insert(0, '02_算法实现手札')
from importlib import import_module
heur = import_module('10_启发式算法_统一对比框架')

bounds = [(0, 5), (0, 5), (0, 5)]
result = heur.simulated_annealing(objective, bounds, n_iter=200, 
                                   T0=10, alpha=0.95, seed=42)
print(f"最优参数：{result['best_x']}")
print(f"最优目标值：{result['best_f']:.4f}")
```

### 结果分析
- SA能在200次迭代内找到接近最优的参数
- 高温时接受差解，能跳出局部最优
- 有噪声时，SA比纯梯度法更鲁棒

💡 **技巧**：黑盒调参是SA的典型应用。如果评估成本很高（如每次几小时），可以用贝叶斯优化（更高效，但实现复杂）。

## 案例五：工程设计优化（DE）

### 问题描述
压力容器设计：4个设计变量（壳体厚度、封头厚度、内径、长度），最小化制造成本，满足压力和几何约束。

这是工程优化中的经典问题，目标函数和约束都是非线性的。

### 算法选择
连续非线性约束优化，DE是首选（收敛快、鲁棒）。约束用罚函数处理。

### 代码实现
```python
import numpy as np

def pressure_vessel(x):
    Ts, Th, R, L = x
    # 成本函数
    cost = 0.6224*Ts*R*L + 1.7781*Th*R**2 + 3.1661*Ts**2*L + 19.84*Ts**2*R
    
    # 约束（违反则加罚）
    g1 = -Ts + 0.0193*R       # 壳体厚度约束
    g2 = -Th + 0.00954*R      # 封头厚度约束
    g3 = -np.pi*R**2*L - 4/3*np.pi*R**3 + 1296000  # 容积约束
    g4 = L - 240              # 长度约束
    
    penalty = 0
    for g in [g1, g2, g3, g4]:
        if g > 0:
            penalty += 1e6 * g**2  # 大罚函数
    
    return cost + penalty

# 用DE优化
import sys
sys.path.insert(0, '02_算法实现手札')
from importlib import import_module
heur = import_module('10_启发式算法_统一对比框架')

bounds = [(0, 100), (0, 100), (10, 200), (10, 240)]
result = heur.differential_evolution(pressure_vessel, bounds, 
                                      n_iter=500, pop_size=50, seed=42)
print(f"最优成本：{result['best_f']:.2f}")
print(f"设计变量：Ts={result['best_x'][0]:.2f}, Th={result['best_x'][1]:.2f}, "
      f"R={result['best_x'][2]:.2f}, L={result['best_x'][3]:.2f}")
```

### 结果分析
- DE能找到满足约束的低成本设计
- 罚函数法简单但可能不稳定，更好的方法是约束支配（如NSGA-II的约束处理）
- 工程优化中，DE通常比GA和PSO更稳定

💡 **技巧**：工程设计优化通常有约束。处理约束的方法：罚函数（简单）、约束支配（优雅）、修复算子（问题相关）。DE+约束支配是工程优化的黄金组合。

## 算法选择决策树

```
问题是连续的吗？
├─ 是 → 维度高吗？
│   ├─ 低(<20) → DE（首选）/ PSO
│   └─ 高(>20) → DE / 协同进化
├─ 否（离散/组合）→ 问题是TSP/调度类吗？
│   ├─ 是 → ACO（首选）/ GA
│   └─ 否 → GA / SA
└─ 不确定/黑盒 → SA（简单）/ DE（通用）
```

### 快速选择表
| 场景 | 首选 | 备选 |
|------|------|------|
| 连续函数优化 | DE | PSO |
| TSP/路径规划 | ACO | GA |
| 调度/排程 | GA | ACO |
| 黑盒调参 | SA | DE |
| 神经网络权重 | GA | DE |
| 工程设计优化 | DE | GA |
| 多目标优化 | NSGA-II | MOEA/D |
| 大规模优化(>100维) | DE | PSO |

### 通用建议
1. **先试DE**：大多数连续优化问题DE都不错，参数少、鲁棒
2. **离散问题用GA或ACO**：不要用PSO/DE（需要改造）
3. **多次运行取平均**：启发式有随机性，一次结果可能是运气
4. **记录收敛曲线**：比赛论文必须有收敛曲线
5. **和精确算法对比**：小问题上精确算法更快，不要为了用启发式而用
