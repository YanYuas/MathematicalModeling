## 一、运输问题

### 1.1 问题描述
m个产地，n个销地。产地i产量a_i，销地j销量b_j，从i到j的单位运费c_ij。求最小总运费的运输方案。

**数学模型**：
```
min ΣΣ c_ij * x_ij
s.t. Σ_j x_ij = a_i    （产地产量约束）
     Σ_i x_ij = b_j    （销地销量约束）
     x_ij >= 0
```

### 1.2 表上作业法步骤

1. **初始基可行解**：最小元素法 或 Vogel近似法
2. **最优性检验**：位势法计算检验数，全部>=0则最优
3. **调整**：找闭回路，调整运量

### 1.3 案例：物资调运

**问题**：3个仓库向4个超市调运物资，求最小运费。

| 仓库\超市 | 超市1 | 超市2 | 超市3 | 超市4 | 产量 |
|----------|-------|-------|-------|-------|------|
| 仓库1 | 3 | 11 | 3 | 10 | 7 |
| 仓库2 | 1 | 9 | 2 | 8 | 4 |
| 仓库3 | 7 | 4 | 10 | 5 | 9 |
| 销量 | 3 | 6 | 5 | 6 | 20 |

**代码**：
```python
import sys
sys.path.insert(0, '02_算法实现手札/00_手动实现详解')
from importlib import import_module
ta = import_module('12_运输问题与指派问题_手动实现')

costs = [[3,11,3,10],[1,9,2,8],[7,4,10,5]]
supply = [7,4,9]
demand = [3,6,5,6]

tp = ta.TransportationProblem(costs, supply, demand)
alloc, cost, iters = tp.optimize('vogel')
print(f"最小运费：{cost}，迭代次数：{iters}")
```

**结果**：
- 最小运费：85
- Vogel法初始解就是最优解（迭代1次）
- 最优方案：
  - 仓库1→超市3：5，仓库1→超市4：2
  - 仓库2→超市1：3，仓库2→超市4：1
  - 仓库3→超市2：6，仓库3→超市4：3

💡 **技巧**：Vogel法通常比最小元素法更接近最优解，甚至直接就是最优解。比赛中优先用Vogel法。

### 1.4 产销不平衡处理

**产量 > 销量**：加一个虚拟销地，销量=产量-销量，运费=0
**产量 < 销量**：加一个虚拟产地，产量=销量-产量，运费=0

```python
# 产量>销量的例子
supply = [10, 8, 6]  # 总产量24
demand = [5, 7, 6, 4]  # 总销量22
# 加虚拟销地，销量=2，运费=0
costs_new = [row + [0] for row in costs]
demand_new = demand + [2]
```

## 二、指派问题

### 2.1 问题描述
n个人做n项任务，每人做一项，每项一人做。人i做任务j的费用c_ij。求最小总费用。

**这是运输问题的特例**：m=n，产量=销量=1。

### 2.2 匈牙利算法步骤

1. **行规约**：每行减该行最小值
2. **列规约**：每列减该列最小值
3. **最少线覆盖所有0**：用Konig定理
4. **线数=n**：找到最优解；否则调整矩阵，回到3

### 2.3 案例：任务分配

**问题**：4个工人做4项任务，求最小总费用。

| 工人\任务 | 任务1 | 任务2 | 任务3 | 任务4 |
|----------|-------|-------|-------|-------|
| 工人1 | 4 | 1 | 3 | 2 |
| 工人2 | 2 | 0 | 5 | 3 |
| 工人3 | 3 | 2 | 2 | 4 |
| 工人4 | 5 | 4 | 1 | 5 |

**代码**：
```python
costs = [[4,1,3,2],[2,0,5,3],[3,2,2,4],[5,4,1,5]]
assignment, total = ta.hungarian_assignment(costs)
print(f"最小费用：{total}")
for i in range(4):
    print(f"  工人{i} → 任务{assignment[i]}")
```

**结果**：
- 最小费用：6
- 工人1→任务4（2），工人2→任务2（0），工人3→任务1（3），工人4→任务3（1）

### 2.4 最大化指派问题

如果是求最大收益（如利润），转化为最小化：
```
c'_ij = max(c) - c_ij
```
然后用匈牙利算法求最小。

### 2.5 人数≠任务数

**人多任务少**：加虚拟任务，费用=0
**人少任务多**：加虚拟人，费用=0

## 三、建模比赛中的应用

### 3.1 常见题型

| 题型 | 模型 |
|------|------|
| 物资调运、物流配送 | 运输问题 |
| 人员分配、排班 | 指派问题 |
| 工厂选址+运输 | 运输问题+0-1规划 |
| 生产计划+运输 | 运输问题+线性规划 |

### 3.2 与其他模型的结合

**运输问题 + 0-1规划（工厂选址）**：
```
min ΣΣ c_ij x_ij + Σ f_i y_i
s.t. Σ_j x_ij <= a_i * y_i   （y_i=1表示建厂）
     Σ_i x_ij = b_j
     x_ij >= 0, y_i ∈ {0,1}
```

**指派问题 + 时间窗**：
每人做任务有时间限制，转化为带约束的指派问题（用整数规划求解器）。

### 3.3 求解器实现（更简单）

实际比赛中，运输问题和指派问题都可以直接用PuLP/Gurobi求解，不用手动写表上作业法：

```python
import pulp

# 运输问题
prob = pulp.LpProblem("运输", pulp.LpMinimize)
x = [[pulp.LpVariable(f"x{i}{j}", lowBound=0) for j in range(n)] for i in range(m)]
prob += sum(costs[i][j]*x[i][j] for i in range(m) for j in range(n))
for i in range(m):
    prob += sum(x[i][j] for j in range(n)) == supply[i]
for j in range(n):
    prob += sum(x[i][j] for i in range(m)) == demand[j]
prob.solve(pulp.PULP_CBC_CMD(msg=0))
```

💡 **建议**：手动实现是为了理解原理，比赛中用求解器更快更稳。但如果题目要求"用表上作业法"，就需要手动实现。

## 四、关键技巧总结

1. **Vogel法优先**：初始解质量高，常直接最优
2. **检验数判断**：全部>=0才是最优（最小化问题）
3. **闭回路调整**：奇数位置减，偶数位置加（从起点开始）
4. **匈牙利算法**：行规约→列规约→覆盖0→调整，循环到完美匹配
5. **不平衡问题**：加虚拟产地/销地，运费=0
6. **最大化问题**：取负或用最大值减
