# 优化建模进阶技巧

## 一、线性化技巧

很多看似非线性的问题，通过引入辅助变量可以转化为线性规划。

### 1.1 绝对值线性化
**问题**：min |x| 或约束 |x| ≤ a

**方法**：引入辅助变量 y，令 y ≥ x 且 y ≥ -x，则 y = max(x, -x) = |x|

```
min y
s.t. y ≥ x
     y ≥ -x
```

**推广**：min Σ|aᵢxᵢ - bᵢ|（L1回归）
```
min Σyᵢ
s.t. yᵢ ≥ aᵢxᵢ - bᵢ
     yᵢ ≥ -(aᵢxᵢ - bᵢ)
```

---

### 1.2 max/min 线性化
**问题**：min max(f₁(x), f₂(x), ..., fₙ(x))（最小最大问题）

**方法**：引入辅助变量 z，令 z ≥ fᵢ(x) 对所有 i

```
min z
s.t. z ≥ f₁(x)
     z ≥ f₂(x)
     ...
     z ≥ fₙ(x)
```

**问题**：max min(f₁(x), f₂(x), ..., fₙ(x))（最大最小问题）

**方法**：引入辅助变量 z，令 z ≤ fᵢ(x) 对所有 i

```
max z
s.t. z ≤ f₁(x)
     z ≤ f₂(x)
     ...
     z ≤ fₙ(x)
```

---

### 1.3 乘积线性化（0-1变量）
**问题**：z = x · y，其中 x, y 都是0-1变量

**方法**：
```
z ≤ x
z ≤ y
z ≥ x + y - 1
z ≥ 0
```
此时 z = 1 当且仅当 x = 1 且 y = 1

**推广**：z = x₁ · x₂ · ... · xₙ（n个0-1变量的乘积）
```
z ≤ xᵢ  (对所有i)
z ≥ Σxᵢ - (n-1)
z ≥ 0
```

---

### 1.4 连续变量与0-1变量的乘积
**问题**：z = x · y，其中 x 是连续变量（0 ≤ x ≤ U），y 是0-1变量

**方法**：
```
z ≤ U · y
z ≤ x
z ≥ x - U · (1 - y)
z ≥ 0
```
此时 y=0 时 z=0，y=1 时 z=x

---

### 1.5 分式规划线性化
**问题**：max (aᵀx + a₀) / (bᵀx + b₀)

**方法**：令 y = x / (bᵀx + b₀)，t = 1 / (bᵀx + b₀)
则转化为：
```
max aᵀy + a₀t
s.t. bᵀy + b₀t = 1
     y, t ≥ 0
```
最后 x = y / t

## 二、大M法（Big-M Method）

### 2.1 基本思想
用一个很大的数 M 来表示逻辑约束，将条件判断转化为线性约束。

### 2.2 if-then 约束
**问题**：如果 f(x) ≤ 0，则 g(x) ≤ 0

**方法**：引入0-1变量 y
```
f(x) ≤ M · (1 - y)    # y=1时 f(x)≤0 必须成立
g(x) ≤ M · y          # y=0时 g(x)≤0 必须成立
y ∈ {0, 1}
```
含义：y=1 → f(x)≤0；y=0 → g(x)≤0。两种情况至少一种成立。

### 2.3 固定费用问题
**问题**：生产某产品有固定成本K，单位成本c，产量x≥0

**方法**：引入0-1变量 y（是否生产）
```
min c·x + K·y
s.t. x ≤ M·y    # y=0时x=0，y=1时x≤M
     x ≥ 0
     y ∈ {0, 1}
```

### 2.4 设施选址问题
**问题**：在候选地点中选择建仓库，每个仓库有建设成本，覆盖需求点

**方法**：
```
min Σfᵢyᵢ + ΣΣcᵢⱼxᵢⱼ
s.t. Σⱼxᵢⱼ ≤ Mᵢyᵢ    # 仓库i的发货量不超过容量（且y=0时不能发货）
     Σᵢxᵢⱼ = dⱼ       # 需求点j的需求必须满足
     xᵢⱼ ≥ 0
     yᵢ ∈ {0, 1}
```

### 2.5 M的选择
- M不能太小：否则会错误地排除可行解
- M不能太大：否则会导致数值不稳定，求解变慢
- 建议：根据问题的上界选择，如产量上限、预算上限等

## 三、分段线性化

### 3.1 适用场景
目标函数或约束是非线性的，但可以用分段线性函数近似。

### 3.2 方法：SOS2约束（特殊有序集）
将非线性函数 f(x) 在区间 [a, b] 上分成 n 段，分点为 x₀, x₁, ..., xₙ

引入权重变量 λ₀, λ₁, ..., λₙ：
```
x = Σxᵢλᵢ
f(x) ≈ Σf(xᵢ)λᵢ
Σλᵢ = 1
λᵢ ≥ 0
λᵢ 是 SOS2 类型（最多两个相邻的λ非零）
```

### 3.3 不用SOS2的实现（用0-1变量）
引入0-1变量 yₖ 表示处于第k段：
```
x = x₀ + Σₖ (xₖ - xₖ₋₁) · zₖ
f(x) = f(x₀) + Σₖ (f(xₖ) - f(xₖ₋₁)) · zₖ
zₖ ≤ yₖ
zₖ ≤ yₖ₋₁  (不对，应该是其他形式)
```
更简单的方式：直接用求解器的SOS2支持（如Gurobi、CPLEX）

## 四、建模常见错误与避坑

### 4.1 变量范围遗漏
- 忘记非负约束 x ≥ 0
- 忘记整数约束
- 忘记0-1约束

### 4.2 约束方向错误
- 最大化问题中约束写反
- 不等式方向搞反（≤ 写成 ≥）

### 4.3 目标函数量纲不一致
- 利润和成本直接相加（单位不同）
- 建议：归一化或加权

### 4.4 不可行问题
- 约束之间矛盾
- 检查方法：逐步放松约束，找到导致不可行的约束

### 4.5 无界问题
- 目标函数可以无限增大/减小
- 检查方法：是否缺少必要的约束

### 4.6 数值问题
- 系数数量级差异太大（如1e-6和1e6同时出现）
- 建议：归一化变量和系数

## 五、建模流程规范

### 5.1 标准建模步骤
1. **明确问题**：决策变量是什么？目标是什么？约束有哪些？
2. **定义变量**：每个变量的含义、单位、范围
3. **建立目标函数**：明确最大化还是最小化
4. **列出约束**：显式约束 + 隐式约束
5. **选择方法**：线性/非线性/整数/启发式
6. **求解验证**：检查解是否满足所有约束
7. **灵敏度分析**：参数变化对结果的影响

### 5.2 论文中的模型表述
```
(1) 决策变量
    xᵢⱼ：从产地i到销地j的运输量（吨）

(2) 目标函数
    min Z = ΣᵢΣⱼ cᵢⱼxᵢⱼ

(3) 约束条件
    Σⱼ xᵢⱼ ≤ aᵢ,  i = 1,2,...,m      (产量约束)
    Σᵢ xᵢⱼ ≥ bⱼ,  j = 1,2,...,n      (销量约束)
    xᵢⱼ ≥ 0                          (非负约束)
```

## 六、从问题到模型的思维方法

### 6.1 识别问题类型
| 问题关键词 | 可能的模型 |
|-----------|-----------|
| 最大利润、最小成本、资源分配 | 线性规划 |
| 是/否选择、选/不选 | 0-1规划 |
| 整数数量、人数、次数 | 整数规划 |
| 多目标、权衡 | 多目标规划 |
| 分阶段、顺序决策 | 动态规划 |
| 路径、网络、连接 | 图论/网络优化 |
| 复杂、非线性、NP难 | 启发式算法 |
| 不确定、随机 | 随机规划/鲁棒优化 |

### 6.2 简化问题的技巧
- 先建立简单模型，再逐步复杂化
- 先小规模测试，再大规模求解
- 忽略次要因素，抓住主要矛盾
- 用已知答案的例题验证模型

### 6.3 模型改进方向
- 增加约束（更贴近实际）
- 细化变量（更精确）
- 考虑不确定性（鲁棒性）
- 多目标（更全面）
- 动态调整（更灵活）
