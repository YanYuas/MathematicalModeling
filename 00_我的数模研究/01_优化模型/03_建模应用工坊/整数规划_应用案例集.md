## 案例一：0-1背包问题

### 问题描述
小明要去露营，背包最多装10公斤。有5件物品可选，每件物品有重量和价值，问怎么装使总价值最大？

| 物品 | 重量(kg) | 价值(元) |
|------|----------|----------|
| 帐篷 | 3 | 10 |
| 睡袋 | 2 | 7 |
| 炉具 | 5 | 15 |
| 食品 | 4 | 8 |
| 水壶 | 3 | 12 |

### 数学建模

**决策变量**：x_i = 1 表示选第i件物品，0表示不选

**目标函数**：max z = 10x₁ + 7x₂ + 15x₃ + 8x₄ + 12x₅

**约束条件**：
- 3x₁ + 2x₂ + 5x₃ + 4x₄ + 3x₅ ≤ 10 （重量限制）
- x_i ∈ {0, 1}

### 代码实现

```python
import numpy as np
from scipy.optimize import linprog

# 物品数据
v = np.array([10, 7, 15, 8, 12])  # 价值
w = np.array([3, 2, 5, 4, 3])     # 重量
W = 10                             # 背包容量
n = 5

# 用分支定界法（最小化形式）
c = -v  # 最大化转最小化
A_ub = w.reshape(1, -1)
b_ub = np.array([W])
bounds = [(0, 1)] * n  # 0-1变量

# 先用LP松弛看一下
result_lp = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
print(f"LP松弛最优：x={result_lp.x}, z={-result_lp.fun}")

# 用分支定界法（调用我们自己实现的）
import sys
sys.path.append('.')
from importlib import import_module
bb = import_module('03_分支定界法_手动实现')
result = bb.branch_and_bound(c, A_ub=A_ub, b_ub=b_ub, 
                              lb=np.zeros(n), ub=np.ones(n),
                              method='best_first', verbose=False)

print(f"整数最优：x={result['x']}, z={-result['obj']}")
print(f"选中物品：{[i+1 for i in range(n) if result['x'][i] > 0.5]}")
```

### 结果分析
- LP松弛最优：x=[0,1,1,0,1]，z=34（恰好是整数解！）
- 整数最优：选睡袋+炉具+水壶，总重量=2+5+3=10kg，总价值=7+15+12=34元

💡 **建模技巧**：背包问题是最基础的0-1规划。当物品数n很大时（>50），分支定界可能很慢，可以用动态规划O(nW)求解，或者用贪心算法获得近似解。

## 案例二：指派问题

### 问题描述
公司有4名员工和4项任务，每人做一项任务，每项任务一人做。不同人做不同任务的成本如下，怎么指派使总成本最低？

|      | 任务A | 任务B | 任务C | 任务D |
|------|-------|-------|-------|-------|
| 张三 | 9 | 2 | 7 | 8 |
| 李四 | 6 | 4 | 3 | 7 |
| 王五 | 5 | 8 | 1 | 8 |
| 赵六 | 7 | 6 | 9 | 4 |

### 数学建模

**决策变量**：x_ij = 1 表示第i人做第j项任务，0表示不做

**目标函数**：min z = ΣΣ c_ij x_ij

**约束条件**：
- Σ_j x_ij = 1 （每人做一项）
- Σ_i x_ij = 1 （每项一人做）
- x_ij ∈ {0, 1}

### 代码实现

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

# 成本矩阵
cost = np.array([
    [9, 2, 7, 8],
    [6, 4, 3, 7],
    [5, 8, 1, 8],
    [7, 6, 9, 4]
])

# 匈牙利算法（指派问题的专用高效算法，O(n³)）
row_ind, col_ind = linear_sum_assignment(cost)

print("最优指派方案：")
names = ['张三', '李四', '王五', '赵六']
tasks = ['A', 'B', 'C', 'D']
total = 0
for i, j in zip(row_ind, col_ind):
    print(f"  {names[i]} → 任务{tasks[j]}，成本={cost[i,j]}")
    total += cost[i,j]
print(f"总成本：{total}")
```

### 结果分析
- 张三→任务B（成本2）
- 李四→任务C（成本3）
- 王五→任务A（成本5）
- 赵六→任务D（成本4）
- 总成本=2+3+5+4=14

💡 **建模技巧**：指派问题有特殊的全幺模结构（totally unimodular），LP松弛的最优解天然是整数！所以可以直接用LP求解，不需要分支定界。匈牙利算法是专门的O(n³)算法，比通用IP求解器快得多。

🔗 **关联**：运输问题也有全幺模结构，LP松弛即整数最优。这就是为什么识别问题结构很重要——特殊结构有特殊算法。

## 案例三：工厂选址问题（混合整数规划）

### 问题描述
公司要在3个候选城市中建厂，供应4个地区的需求。建厂有固定成本，运输有单位成本。每个地区需求必须满足，问在哪建厂、运多少，使总成本最低？

**建厂固定成本**：
| 候选城市 | 建厂成本(万元) | 产能(万件) |
|----------|---------------|-----------|
| 北京 | 200 | 30 |
| 上海 | 150 | 25 |
| 广州 | 180 | 28 |

**单位运输成本(元/件)**：
|      | 地区1 | 地区2 | 地区3 | 地区4 |
|------|-------|-------|-------|-------|
| 北京 | 5 | 3 | 6 | 4 |
| 上海 | 4 | 5 | 3 | 6 |
| 广州 | 6 | 4 | 5 | 3 |

**各地区需求(万件)**：[10, 12, 8, 15]

### 数学建模

**决策变量**：
- y_i = 1 表示在i地建厂，0表示不建（0-1整数变量）
- x_ij = 从i地运到j地的数量（连续变量）

**目标函数**：
min z = Σ 200y₁ + 150y₂ + 180y₃ + ΣΣ c_ij x_ij

**约束条件**：
- Σ_j x_ij ≤ 产能_i × y_i （如果不建厂，运量为0）
- Σ_i x_ij ≥ 需求_j （满足需求）
- x_ij ≥ 0
- y_i ∈ {0, 1}

### 代码实现

```python
import numpy as np
from scipy.optimize import linprog

# 数据
fixed_cost = np.array([200, 150, 180])  # 建厂成本
capacity = np.array([30, 25, 28])       # 产能
demand = np.array([10, 12, 8, 15])      # 需求
trans_cost = np.array([                 # 运输成本
    [5, 3, 6, 4],
    [4, 5, 3, 6],
    [6, 4, 5, 3]
])

n_fac = 3
n_reg = 4
n_x = n_fac * n_reg  # 运输变量数
n_y = n_fac          # 建厂变量数
n_total = n_x + n_y

# 目标函数：min [运输成本, 建厂成本]
c = np.concatenate([trans_cost.flatten(), fixed_cost])

# 约束1：产能约束 Σ_j x_ij - cap_i * y_i ≤ 0
A_ub1 = np.zeros((n_fac, n_total))
for i in range(n_fac):
    for j in range(n_reg):
        A_ub1[i, i*n_reg + j] = 1
    A_ub1[i, n_x + i] = -capacity[i]
b_ub1 = np.zeros(n_fac)

# 约束2：需求约束 -Σ_i x_ij ≤ -demand_j
A_ub2 = np.zeros((n_reg, n_total))
for j in range(n_reg):
    for i in range(n_fac):
        A_ub2[j, i*n_reg + j] = -1
b_ub2 = -demand

A_ub = np.vstack([A_ub1, A_ub2])
b_ub = np.concatenate([b_ub1, b_ub2])

# 变量边界：运输变量≥0，建厂变量0-1
bounds = [(0, None)] * n_x + [(0, 1)] * n_y

# 用分支定界法
import sys
sys.path.append('.')
from importlib import import_module
bb = import_module('03_分支定界法_手动实现')

var_type = ['C'] * n_x + ['I'] * n_y  # 运输连续，建厂整数
result = bb.branch_and_bound(c, A_ub=A_ub, b_ub=b_ub,
                              var_type=var_type,
                              lb=np.zeros(n_total),
                              ub=np.concatenate([np.full(n_x, np.inf), np.ones(n_y)]),
                              method='best_first', verbose=False)

print(f"最优总成本：{result['obj']:.2f}万元")
x = result['x'][:n_x].reshape(n_fac, n_reg)
y = result['x'][n_x:]
print(f"建厂决策：{['建' if yi > 0.5 else '不建' for yi in y]}")
print("运输方案：")
for i in range(n_fac):
    if y[i] > 0.5:
        print(f"  工厂{i+1}: {x[i]}")
```

### 结果分析
- 建厂：北京+上海+广州（全部建厂，因为需求总和45 > 单个工厂产能）
- 或者根据数据可能只建部分工厂

💡 **建模技巧**：这是典型的混合整数规划（MIP）。关键约束是"如果不建厂则运量为0"，用 x_ij ≤ cap_i × y_i 实现。这叫**大M法**的一种形式，这里的M就是产能。

⚠️ **坑**：如果用通用的大M（如M=1000），会导致LP松弛界很差，分支定界很慢。用具体的产能作为M要好得多。

## 案例四：旅行商问题（TSP）

### 问题描述
一个推销员要访问5个城市，从城市1出发，经过每个城市恰好一次，最后回到起点。城市间距离如下，求最短路线。

|      | 城1 | 城2 | 城3 | 城4 | 城5 |
|------|------|------|------|------|------|
| 城1 | 0 | 12 | 10 | 15 | 8 |
| 城2 | 12 | 0 | 7 | 6 | 11 |
| 城3 | 10 | 7 | 0 | 9 | 13 |
| 城4 | 15 | 6 | 9 | 0 | 5 |
| 城5 | 8 | 11 | 13 | 5 | 0 |

### 数学建模

**决策变量**：x_ij = 1 表示从i走到j，0表示不走

**目标函数**：min z = ΣΣ d_ij x_ij

**约束条件**：
- Σ_j x_ij = 1 （每个城市离开一次）
- Σ_i x_ij = 1 （每个城市到达一次）
- **子回路消除约束**：防止出现多个小环
- x_ij ∈ {0, 1}

**子回路消除**（MTZ公式）：
引入辅助变量u_i（表示访问顺序），约束：
u_i - u_j + n × x_ij ≤ n - 1，对所有i,j≥2

### 代码实现

```python
import numpy as np
from itertools import permutations

# 距离矩阵
d = np.array([
    [0, 12, 10, 15, 8],
    [12, 0, 7, 6, 11],
    [10, 7, 0, 9, 13],
    [15, 6, 9, 0, 5],
    [8, 11, 13, 5, 0]
])
n = 5

# 暴力枚举（n=5时只有4!=24种，可行）
best_dist = float('inf')
best_route = None

for perm in permutations(range(1, n)):  # 从城市0出发，排列其他城市
    route = [0] + list(perm) + [0]
    dist = sum(d[route[i], route[i+1]] for i in range(n))
    if dist < best_dist:
        best_dist = dist
        best_route = route

print(f"最短路线：{' → '.join(f'城{c+1}' for c in best_route)}")
print(f"总距离：{best_dist}")
```

### 结果分析
- 最短路线：城1 → 城3 → 城2 → 城4 → 城5 → 城1
- 总距离：10+7+6+5+8 = 36

💡 **建模技巧**：TSP是NP-hard问题，n=5可以暴力枚举，n=20就需要分支定界或启发式算法。子回路消除约束是TSP建模的关键，MTZ公式是最常用的一种。

✨ **创新**：对于大规模TSP，可以先用贪心算法构造初始解，再用2-opt/3-opt局部搜索改进，最后用分支定界精确求解。这叫"启发式+精确"混合策略。

## 建模技巧总结

### 1. 0-1变量的常用建模套路

| 逻辑关系 | 建模方式 |
|----------|----------|
| 选A则不能选B | x_A + x_B ≤ 1 |
| 选A必须选B | x_A ≤ x_B |
| 选A或选B至少一个 | x_A + x_B ≥ 1 |
| 如果x>0则y=1 | x ≤ M·y（大M法） |
| 固定成本+可变成本 | min F·y + c·x, x ≤ M·y |

### 2. 大M法的M怎么选？
- ❌ 不要用M=999999这种"足够大"的数
- ✅ 用问题中具体的上界（如产能、预算、总需求）
- 原因：M越大，LP松弛的界越差，分支定界越慢

### 3. 什么时候用什么方法？
- 变量少（<20）：暴力枚举或分支定界
- 特殊结构（指派、运输）：专用算法（匈牙利、网络流）
- 变量多（>100）：启发式算法（GA、SA、PSO）或专业求解器
- 0-1背包：动态规划O(nW)

### 4. 整数规划 vs 线性规划
- LP：多项式时间可解，可行域凸
- IP：NP-hard，可行域离散
- IP的LP松弛是获得下界的关键工具
- 分支定界=LP松弛+树搜索+剪枝
