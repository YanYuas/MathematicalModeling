核心原理

Core Principles
单纯形法的核心思想

一句话总结：线性规划的可行域是一个凸多面体，最优解一定在顶点上。单纯形法就是从一个顶点出发，每次跳到相邻的更优顶点，直到所有相邻顶点都更差。

关键概念

  • 基解：令非基变量=0，解出基变量，得到的解
  • 基可行解：满足非负约束的基解 ↔ 可行域的顶点
  • 检验数 rⱼ：非基变量增加1单位时目标函数的变化量
  • 进基变量：检验数最负的变量（最小化问题），让它从0开始增大
  • 出基变量：比值测试中最先减小到0的基变量

检验数公式推导

MATH 
目标函数 z = c_B^T x_B + c_N^T x_N
约束     x_B = B^{-1}b - B^{-1}N x_N
代入     z = c_B^T B^{-1}b + (c_N^T - c_B^T B^{-1}N) x_N
检验数   r_N = c_N^T - c_B^T B^{-1}N
当所有 r_j >= 0（最小化），增大任何非基变量都不会使z减小 → 最优！
对偶理论

每个线性规划都有一个"影子问题"——对偶问题。对偶最优解就是每种资源的影子价格。

原问题：max cᵀx, Ax ≤ b, x ≥ 0

对偶问题：min bᵀy, Aᵀy ≥ c, y ≥ 0

✓
强对偶定理
原问题最优值 = 对偶问题最优值。影子价格 yᵢ = ∂(最优值)/∂bᵢ。
互补松弛性

最优解满足：

  • yᵢ × (bᵢ - aᵢx) = 0 → 资源有剩余则影子价格为0
  • xⱼ × (aⱼᵀy - cⱼ) = 0 → 产品不生产则对偶约束有松弛
!
经济含义
"物以稀为贵"——稀缺资源才有正的影子价格，过剩资源不值钱。

应用案例集

Application Cases
案例1 · 生产计划

两种产品，两种原料，求最大利润。

建模关键：变量=产量，目标=利润最大，约束=资源限量。

结果：x₁=4, x₂=2, 利润=22元
案例2 · 运输问题

3产地4销地，求最小总运费。

建模关键：变量=运量xᵢⱼ，约束=产量平衡+销量平衡。

技巧：产销不平衡时加虚拟产地/销地
案例3 · 指派问题

4人4工作，每人一项，求最小总时间。

建模关键：0-1变量xᵢⱼ，约束=每人一项+每项一人。

可用匈牙利算法O(n³)，比一般IP快
案例4 · 下料问题

19米钢管，切4/6/8米，求最少废料。

建模关键：先枚举所有合理下料方式，变量=每种方式用多少根。

难点：枚举下料方式，不是求解
案例5 · 投资组合

5个项目，资金1000万，平均风险≤2.5，求最大收益。

建模关键：分式约束线性化——Σ(aᵢ-cbᵢ)xᵢ≤0。

技巧：比率约束转化为线性约束
建模5步法

①找变量：要决定什么？

②写目标：最大化/最小化什么？

③列约束：有哪些限制？

④查完整：非负约束？量纲一致？

⑤判类型：线性/非线性？整数/连续？

通用方法论，适用于所有优化问题
