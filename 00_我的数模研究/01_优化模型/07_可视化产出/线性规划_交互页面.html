01

直觉与起源

Intuition & Origin

在推导公式之前，先建立几何直觉。线性规划的所有核心概念——基解、检验数、进基出基——都能在一张图上看懂。

从一个具体问题开始

工厂生产两种产品：

  • 甲产品：利润3元/件，消耗1kg原料A + 2kg原料B
  • 乙产品：利润5元/件，消耗2kg原料A + 1kg原料B
  • 原料A限量8kg，原料B限量10kg

问：各生产多少件，利润最大？

MODEL max   z = 3x₁ + 5x₂
s.t.   x₁ + 2x₂ ≤ 8    原料A
      2x₁ + x₂ ≤ 10    原料B
      x₁, x₂ ≥ 0
画出来就明白了
✓
三个关键观察
① 可行域是凸多边形（所有约束半平面的交集）
② 目标函数等高线是平行线，沿法向方向z增大
③ 最大值一定在某个顶点取到（(4,2)，z=22）
从几何到算法：单纯形法的诞生
1947 · 起源
George Dantzig 在美国空军提出单纯形法
二战期间需要优化兵力和物资调度。Dantzig发现：既然最优解在顶点，而顶点数量虽然多，但从一个顶点沿边移动到相邻的更优顶点，通常很快就能到达最优点。这就是单纯形法的核心思想——不枚举所有顶点，而是"走一步看一步"。
几何直觉
顶点 = 基可行解，边 = 一个非基变量进基
在n维空间中，每个顶点由n个约束等式的交点确定。对应到代数上，就是令n个"非基变量"为0，解出m个"基变量"。沿一条边移动，就是让一个非基变量从0开始增大，同时某个基变量减小到0——这就是"进基"和"出基"。
为什么叫"单纯形"
Simplex = 最简单的多面体
二维的单纯形是三角形，三维是四面体。Dantzig最初的方法是在可行域内构造一系列单纯形来逼近最优解，方法因此得名。虽然后来算法演化为沿顶点移动，但名字保留了下来。
💡 顿悟
所有概念都是几何的代数翻译
检验数 = 目标函数在该方向上的变化率；进基 = 选一个能让z增大的方向；出基 = 沿该方向走，最先碰到的约束；主元旋转 = 坐标变换，把新方向作为基轴。理解了几何，代数就是自然而然的。
02

单纯形法原理

Simplex Method

从标准形式到检验数公式，每一步推导都回答"为什么这样做"。理解了检验数的几何意义，就理解了单纯形法的灵魂。

第一步：化为标准形式

单纯形法需要等式约束，所以给每个"≤"约束加一个松弛变量（slack variable），表示资源的剩余量。

STANDARD FORM max   z = 3x₁ + 5x₂ + 0s₁ + 0s₂
s.t.   x₁ + 2x₂ + s₁ = 8
      2x₁ + x₂ + s₂ = 10
      x₁, x₂, s₁, s₂ ≥ 0
i
为什么要松弛变量？
加了松弛变量后，约束矩阵中s₁、s₂的系数构成单位矩阵，直接得到初始基可行解：令x₁=x₂=0，则s₁=8, s₂=10。这就是原点顶点，单纯形法从这里出发。
第二步：检验数——灵魂所在

把目标函数用非基变量表示：

DERIVE 由约束：s₁ = 8 - x₁ - 2x₂
          s₂ = 10 - 2x₁ - x₂
代入目标：z = 3x₁ + 5x₂

检验数 rⱼ = 非基变量xⱼ增加1单位时，z的变化量

这里 r₁ = 3（增加1件甲产品，利润+3），r₂ = 5（增加1件乙产品，利润+5）。

!
几何意义
检验数就是目标函数梯度在各非基方向上的投影。rⱼ > 0 意味着沿xⱼ方向走，z会增大——这个方向值得走！
第三步：进基与出基

进基：选检验数最大的非基变量（最大化问题）。这里 r₂=5 > r₁=3，所以x₂进基。

出基：让x₂从0开始增大，看哪个基变量最先变0：

RATIO TEST s₁ = 8 - 2x₂ → x₂ ≤ 8/2 = 4
s₂ = 10 - x₂ → x₂ ≤ 10/1 = 10

最小比值 = 4 → s₁最先变0 → s₁出基
✓
比值测试的几何意义
沿x₂方向（竖直向上）走，最先碰到的约束是x₁+2x₂=8（在x₂=4处），而不是2x₁+x₂=10（在x₂=10处）。所以从(0,0)走到(0,4)。
第四步：主元旋转（高斯消元）

进基x₂、出基s₁后，新的基变量是{x₂, s₂}。需要把约束方程改写为用新非基变量{x₁, s₁}表示基变量：

旋转前

x₁ + 2x₂ + s₁ = 8
2x₁ + x₂ + s₂ = 10
z - 3x₁ - 5x₂ = 0

旋转后（主元=2）

0.5x₁ + x₂ + 0.5s₁ = 4
1.5x₁ - 0.5s₁ + s₂ = 6
z - 0.5x₁ + 2.5s₁ = 20

新检验数：r₁ = 0.5 > 0（还能增大），r_{s₁} = -2.5 < 0（s₁增大反而减小z）。所以x₁继续进基。

✨
主元旋转的本质
就是坐标变换：把坐标系从"以s₁,s₂为轴"换成"以x₂,s₂为轴"。在新坐标系下，当前顶点就是原点，非基变量=0，基变量=右端项。每一次旋转都是一次坐标平移+旋转。
终止条件与完整流程
✓
最优性判定
当所有检验数 rⱼ ≤ 0（最大化问题），增大任何非基变量都不会让z增大——当前顶点就是最优的！
!
无界判定
如果进基变量所在列的所有系数 ≤ 0，意味着沿该方向走不会碰到任何约束——z可以无限增大，问题无界。

单纯形法四步循环

① 算检验数
所有rⱼ≤0？→ 最优，停止
② 选进基变量
rⱼ最大的非基变量进基
③ 比值测试选出基
最小比值对应的基变量出基
④ 主元旋转
高斯消元，回到①

对偶理论

Duality Theory

每个线性规划都有一个"影子问题"。对偶不是数学游戏，而是理解资源价值的钥匙——影子价格告诉你"多一单位资源值多少钱"。

从经济直觉开始

回到生产计划问题。现在换个角度：如果你是资源出租方，你愿意以什么价格出租原料A和B？

设原料A的租金为y₁元/kg，原料B的租金为y₂元/kg。

对工厂来说，出租资源的收益不能低于自己生产的收益：

  • 生产1件甲产品用(1A+2B)，利润3元 → y₁ + 2y₂ ≥ 3
  • 生产1件乙产品用(2A+1B)，利润5元 → 2y₁ + y₂ ≥ 5

而资源出租方希望总租金最小：min 8y₁ + 10y₂

✓
这就是对偶问题！
原问题是"安排生产最大化利润"，对偶问题是"给资源定价最小化租金"。两个问题的最优值相等——这就是强对偶定理。
原问题 vs 对偶问题
原问题 Primal
max   3x₁ + 5x₂
s.t.   x₁+2x₂ ≤ 8
      2x₁+x₂ ≤ 10
      x₁,x₂ ≥ 0

变量=产量
约束=资源限量
对偶问题 Dual
min   8y₁ + 10y₂
s.t.   y₁+2y₂ ≥ 3
      2y₁+y₂ ≥ 5
      y₁,y₂ ≥ 0

变量=影子价格
约束=利润底线
i
对偶规则速记
max→min，≤→≥，变量数↔约束数，目标系数↔右端项，约束矩阵转置。最优解 y* = (7/3, 1/3)，即原料A影子价格≈2.33元/kg，原料B≈0.33元/kg。
互补松弛性——最深刻的结论

最优解 (x*, y*) 满足：

COMPLEMENTARY SLACKNESS yᵢ × (bᵢ - aᵢx*) = 0    对每个约束 i
xⱼ × (aⱼᵀy* - cⱼ) = 0    对每个变量 j
!
第一式的经济含义
如果某种资源有剩余（bᵢ - aᵢx > 0），那它的影子价格一定为0——过剩的资源不值钱。反过来，如果影子价格为正，说明该资源已耗尽，是稀缺资源。
!
第二式的经济含义
如果某种产品不生产（xⱼ=0），那它的"机会成本"一定高于利润——生产它不划算。反过来，如果生产某种产品（xⱼ>0），那它的机会成本恰好等于利润。
✨
建模手的洞察
互补松弛性是验证最优解的工具：求出解后，检查是否满足互补松弛，可以快速判断解是否最优。也是理解问题结构的工具：哪些资源是瓶颈（y>0），哪些产品值得做（x>0），一目了然。
对偶单纯形法——什么时候用？

原始单纯形法：保持原始可行性（基变量≥0），逐步达到对偶可行性（检验数≥0）。

对偶单纯形法：保持对偶可行性（检验数≥0），逐步达到原始可行性（基变量≥0）。

✓
对偶单纯形法的典型场景
① 增加约束后：原最优解可能不再可行，但检验数仍满足最优性——用对偶单纯形法从当前表继续，不需要从头算
② 改变右端项b后：同理，基变量可能变负，但检验数不变
③ 整数规划的割平面法：每次加割约束后用对偶单纯形法
这就是灵敏度分析的核心工具！

07

深入与边界

Deep Dive

单纯形法不是万能的。理解它的边界——退化、循环、最坏情况复杂度——才能在比赛中灵活选择方法。

退化与循环

退化：基变量中有0。几何上，就是有超过n个约束同时通过一个顶点（顶点"退化"）。

退化本身不是问题，但可能导致循环：单纯形法在几个顶点之间来回跳，永远到不了最优。

!
1955年 Hoffman 发现第一个循环例子
只有3个约束、11个变量，但Dantzig规则下会无限循环。这说明单纯形法不保证有限步终止（除非用防循环规则）。
✓
Bland规则：最简单的防循环方法
进基选下标最小的正检验数变量，出基选下标最小的最小比值变量。1977年证明Bland规则下不会循环。代价是迭代次数可能变多（实验显示最多差10倍）。
Klee-Minty立方体：最坏情况

1972年，Klee和Minty构造了一个"扭曲的立方体"问题：

max   Σ 10^{n-j} xⱼ
s.t.   2Σ_{i

在Dantzig规则下，单纯形法需要访问所有2ⁿ个顶点！

!
复杂度结论
单纯形法的最坏情况是指数时间O(2ⁿ)。但这是人为构造的病态问题，实际问题中平均是多项式时间（通常O(m³)左右）。这就是为什么实际中单纯形法仍然很快。
内点法——另一条路

1984年，Karmarkar提出内点法，从可行域内部出发，沿中心路径逼近最优解。最坏情况是多项式时间O(n³.⁵L)。

单纯形法
  • ✓ 沿顶点移动，路径清晰
  • ✓ 中小规模问题极快
  • ✓ warm start友好（灵敏度分析）
  • ✗ 最坏情况指数复杂度
  • ✗ 超大规模可能慢
内点法
  • ✓ 多项式时间复杂度
  • ✓ 超大规模问题优势明显
  • ✓ 高度并行化
  • ✗ 解在内部，需要额外步骤取顶点
  • ✗ warm start不如单纯形法
i
比赛中的选择
数学建模比赛中，变量和约束通常在几百以内，单纯形法完全够用。而且scipy.optimize.linprog默认用的就是单纯形法（HiGHS求解器）。只有当变量上万时才考虑内点法。
建模手的研究笔记标记
💡
顿悟
检验数不是凭空定义的，它就是目标函数梯度在非基方向上的投影。理解了这一点，进基选择就是"选最陡的上升方向"。
❓
疑问
为什么实际中退化常见但几乎不循环？是否存在某种"概率意义下"的证明？这是研究前沿问题。
⚠️
坑
用scipy.linprog时，如果A不是满秩，可能报错。需要先检查约束的线性相关性，去掉冗余约束。
✨
创新
可以尝试"混合策略"：前几步用Dantzig快速接近最优，最后几步切换到Bland防止循环。兼顾效率和安全性。

应用案例

Applications

5个经典案例，每个都展示完整的建模思维过程——从问题理解到模型构建，再到结果解读。

案例1 · 生产计划

问题：两种产品，两种原料，求最大利润。

建模关键：变量=各产品产量，目标=利润最大化，约束=资源限量。

结果解读：x₁=4, x₂=2, z=22。原料A和B都耗尽，影子价格分别为2.33和0.33。

建模技巧：这是所有线性规划的"原型"，其他问题都是它的变形。
案例2 · 运输问题

问题：3产地4销地，各产地产量、各销地销量、单位运费已知，求最小总运费。

建模关键：变量xᵢⱼ=从i到j的运量，约束=产量平衡+销量平衡。

结构特点：约束矩阵是全幺模矩阵，整数b保证整数最优解。可用表上作业法。

技巧：产销不平衡时加虚拟产地/销地，运费为0。
案例3 · 指派问题

问题：4人4工作，每人做一项，每项一人做，求最小总时间。

建模关键：0-1变量xᵢⱼ，约束=每人一项+每项一人。

特殊解法：匈牙利算法O(n³)，比一般整数规划快得多。

注意：人数≠工作数时加虚拟人/虚拟工作，成本为0。
案例4 · 下料问题

问题：19米钢管，需要切4米、6米、8米三种规格，求最少废料。

建模关键：先枚举所有合理下料方式，变量=每种方式用多少根。

难点：不是求解难，而是枚举下料方式难。需要确保不遗漏合理方式。

技巧：合理下料方式=废料小于最短规格长度的切法。
案例5 · 投资组合

问题：5个项目，总资金1000万，平均风险指数≤2.5，求最大收益。

建模关键：分式约束 (Σaᵢxᵢ)/(Σxᵢ) ≤ 2.5 需要线性化。

Σ(aᵢ - 2.5)xᵢ ≤ 0
技巧：比率约束、分式目标都可以通过交叉相乘转化为线性约束。
