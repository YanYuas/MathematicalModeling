## 一、问题起源：为什么需要整数规划？

### 1.1 从线性规划到整数规划

线性规划假设变量是连续的，可以取任意实数值。但实际问题中，很多变量**必须是整数**：

- 生产多少件产品（不能生产3.7件）
- 指派几个人做几项工作（人不能分割）
- 是否选择某个地点建厂（选或不选，0或1）
- 旅行商问题中是否走某条路

**定义**：如果线性规划中部分或全部变量要求取整数，就称为**整数规划**（Integer Programming, IP）。

| 类型 | 说明 | 例子 |
|------|------|------|
| 纯整数规划 | 所有变量都是整数 | 生产计划（产品件数） |
| 混合整数规划 | 部分变量整数，部分连续 | 建厂（0-1）+ 产量（连续） |
| 0-1规划 | 变量只能取0或1 | 指派问题、选址问题 |

### 1.2 为什么不能直接四舍五入？

一个常见的误区：先解线性规划松弛，然后把非整数解四舍五入。

**反例**：
```
max  x1 + x2
s.t. 3x1 + 5x2 ≤ 15
     5x1 + 2x2 ≤ 10
     x1, x2 ≥ 0, 整数
```

线性规划松弛的最优解：x1≈1.05, x2≈2.37，目标值≈3.42
- 四舍五入：x1=1, x2=2 → 检验约束：3+10=13≤15 ✓，5+4=9≤10 ✓，目标值=3
- 但真正的整数最优解：x1=0, x2=3 → 目标值=3（一样）
- 再试：x1=2, x2=0 → 目标值=2

这个例子四舍五入恰好可行，但看下面这个：

```
max  10x1 + x2
s.t. 2x1 + 5x2 ≤ 11
     x1, x2 ≥ 0, 整数
```

LP松弛最优：x1=5.5, x2=0，目标值=55
- 四舍五入：x1=6, x2=0 → 2×6=12>11，**不可行！**
- 向下取整：x1=5, x2=0 → 目标值=50
- 真正最优：x1=5, x2=0 → 目标值=50（这个例子恰好一样）

再看一个：
```
max  x1 + 5x2
s.t. x1 + 10x2 ≤ 20
     x1 ≤ 2
     x1, x2 ≥ 0, 整数
```

LP松弛最优：x1=2, x2=1.8，目标值=11
- 四舍五入：x1=2, x2=2 → 2+20=22>20，**不可行！**
- 向下取整：x1=2, x2=1 → 目标值=7
- 真正最优：x1=0, x2=2 → 目标值=10！

💡 **顿悟**：向下取整得到的x1=2,x2=1目标值=7，但真正最优是x1=0,x2=2目标值=10。差了3！这说明**简单取整不仅可能不可行，还可能离最优很远**。整数规划需要专门的算法。

## 二、分支定界法（Branch and Bound）

### 2.1 核心思想：分而治之 + 剪枝

分支定界法是1960年由A.H.Land和A.G.Doig提出的，是求解整数规划最常用的方法。

**一句话总结**：把原问题不断分成更小的子问题（分支），同时用线性规划松弛得到的界来剪掉不可能包含最优解的子树（定界）。

### 2.2 为什么用线性规划松弛？

对于最小化问题：
- 整数规划的最优值 ≥ 线性规划松弛的最优值（因为整数可行域是LP可行域的子集）
- 所以LP松弛给出了一个**下界**（lower bound）

对于最大化问题：
- 整数规划的最优值 ≤ LP松弛的最优值
- LP松弛给出一个**上界**（upper bound）

💡 **顿悟**：LP松弛就像一个"宽松版"的问题，它的最优值一定比整数规划好（因为约束更少）。但它告诉我们：整数最优解不可能比这个值更好。这就是"界"的来源。

### 2.3 分支：怎么分？

当LP松弛的最优解中某个变量x_j不是整数时（设x_j = 2.3），我们知道：
- 整数解中x_j要么≤2，要么≥3
- 不可能有x_j=2.3的整数解

所以我们把原问题分成两个子问题：
- **左分支**：添加约束 x_j ≤ floor(2.3) = 2
- **右分支**：添加约束 x_j ≥ ceil(2.3) = 3

这两个子问题的整数可行域合起来 = 原问题的整数可行域（没有遗漏，也没有重叠）。

### 2.4 定界：怎么剪枝？

维护一个全局上界UB（最大化问题）：当前找到的最好整数解的目标值。

对于每个子问题，先解它的LP松弛，得到LP最优值：
- 如果LP最优值 ≤ UB → 这个子问题的整数解不可能比当前最好的更好，**剪掉**（不用再分支了）
- 如果LP最优值 > UB 且 LP解是整数 → 更新UB，**剪掉**（已经找到这个子问题的最优整数解）
- 如果LP最优值 > UB 且 LP解有非整数变量 → **继续分支**

### 2.5 完整算法步骤（最大化问题）

```
输入：整数规划问题 P
输出：最优整数解 x*

1. 初始化：上界 UB = -∞，待处理队列 Q = {P}
2. 当 Q 不为空：
   a. 从 Q 中取出一个子问题 P_i（搜索策略决定取哪个）
   b. 解 P_i 的线性规划松弛，得到最优值 z_LP 和最优解 x_LP
   c. 如果 P_i 不可行 → 跳过（剪枝：不可行）
   d. 如果 z_LP ≤ UB → 跳过（剪枝：界不够好）
   e. 如果 x_LP 全是整数：
      - 更新 UB = z_LP，x* = x_LP
      - 跳过（剪枝：已找到该子问题最优整数解）
   f. 否则：
      - 选一个非整数变量 x_j（分支变量选择策略）
      - 创建左子问题：P_i + (x_j ≤ floor(x_j))
      - 创建右子问题：P_i + (x_j ≥ ceil(x_j))
      - 把两个子问题加入 Q
3. 返回 x* 和 UB
```

### 2.6 三种搜索策略

| 策略 | 方式 | 优点 | 缺点 |
|------|------|------|------|
| 深度优先 DFS | 每次取最新加入的节点（栈） | 内存小，快速找到可行解 | 可能在差的分支上浪费时间 |
| 广度优先 BFS | 每次取最早加入的节点（队列） | 系统地搜索 | 内存大，找到好解慢 |
| 最佳优先 Best-First | 每次取LP最优值最好的节点 | 剪枝效率最高 | 需要优先队列，内存较大 |

💡 **实践建议**：先用深度优先快速找到一个好的可行解（提高UB），然后切换到最佳优先高效剪枝。这叫"混合策略"。

### 2.7 分支变量选择策略

选哪个非整数变量来分支？这会显著影响搜索树大小：

1. **最不可行法**：选分数部分最接近0.5的变量（最难决定的先分）
2. **强分支法**：对每个候选变量，预计算分支后LP目标值的下降量，选下降最多的
3. **伪代价法**：根据历史分支的效果估计每个变量的"代价"

⚠️ **坑**：随便选分支变量可能导致搜索树爆炸。强分支法虽然每次分支要多解几个LP，但整体搜索节点数可能少一个数量级。

## 三、割平面法（Cutting Plane Method）

### 3.1 核心思想：加约束切掉非整数解

割平面法由Ralph Gomory在1958年提出。

**一句话总结**：不分支，而是不断添加新的约束（割平面），这些约束满足：
- ✅ 切掉当前的非整数LP最优解
- ✅ 不切掉任何整数可行解
- 反复加约束，直到LP最优解变成整数

### 3.2 Gomory割的推导

假设我们用单纯形法解LP松弛，最终单纯形表中，某个基变量x_i的取值b_i不是整数。

该行的方程为：
```
x_i + Σ (a_ij × x_j) = b_i    （j遍历非基变量）
```

把每个系数拆成整数部分和分数部分：
```
b_i = floor(b_i) + f_i        （0 < f_i < 1）
a_ij = floor(a_ij) + g_ij     （0 ≤ g_ij < 1）
```

代入原方程：
```
x_i + Σ [floor(a_ij) + g_ij] x_j = floor(b_i) + f_i
```

整理：
```
x_i + Σ floor(a_ij) x_j - floor(b_i) = f_i - Σ g_ij x_j
```

左边全是整数（x_i、x_j是整数，floor是整数），所以右边也必须是整数。

右边 = f_i - Σ g_ij x_j
- f_i 是正分数（0 < f_i < 1）
- Σ g_ij x_j ≥ 0（因为g_ij ≥ 0，x_j ≥ 0）

所以右边 ≤ f_i < 1。又因为右边是整数，所以右边 ≤ 0：

```
f_i - Σ g_ij x_j ≤ 0
```

即：
```
Σ g_ij x_j ≥ f_i
```

这就是**Gomory割平面**！

💡 **顿悟**：这个推导的关键是"左边是整数"。因为x_i和x_j都是整数变量，所以左边的整数组合必须是整数。而右边的分数部分限制了它必须≤0。这个约束在LP松弛中不存在（因为LP不要求整数），所以它能切掉非整数解，但不会切掉任何整数解。

### 3.3 割平面法算法步骤

```
1. 解原问题的LP松弛
2. 如果最优解全是整数 → 完成，返回
3. 选一个非整数基变量x_i，构造Gomory割
4. 把割约束加入单纯形表（用对偶单纯形法继续，因为加入约束后原解可能不可行）
5. 回到步骤2
```

🔗 **关联**：加入割约束后，原最优基解可能不再可行（基变量变负），但检验数仍然满足最优性条件。这时候用**对偶单纯形法**最合适——这正是对偶单纯形法的典型应用场景！

### 3.4 割平面法 vs 分支定界法

| 维度 | 分支定界法 | 割平面法 |
|------|-----------|---------|
| 思路 | 分而治之，搜索树 | 加约束，缩可行域 |
| 内存 | 可能很大（搜索树） | 小（只有一个问题） |
| 收敛 | 找到整数解就停 | 必须加到LP最优解为整数 |
| 数值稳定性 | 好 | 可能产生很大的系数（割的系数会增长） |
| 实际使用 | 主流求解器默认 | 通常作为分支定界的辅助（割平面加强） |

✨ **创新点**：现代求解器（Gurobi、CPLEX）用的是**分支+割**（Branch and Cut）：在分支定界的每个节点都加割平面来加强下界，大大减少搜索节点数。

## 四、0-1规划与隐枚举法

### 4.1 0-1规划的特殊性

0-1规划是整数规划的特例，变量只能取0或1。常见于：
- 指派问题（x_ij=1表示第i人做第j项工作）
- 选址问题（x_i=1表示在i地建厂）
- 背包问题（x_i=1表示选第i件物品）
- 集合覆盖问题

### 4.2 隐枚举法（Implicit Enumeration）

0-1变量只有2^n种组合，n大时不能全枚举。隐枚举法通过分支定界的思想，只枚举一部分。

**核心**：固定部分变量为0或1，估计剩余变量的目标值上界，如果不可能超过当前最好解，就剪掉这个分支。

## 五、常见整数规划问题

### 5.1 背包问题（Knapsack Problem）

```
max  Σ v_i x_i
s.t. Σ w_i x_i ≤ W
     x_i ∈ {0,1}
```

n种物品，价值v_i，重量w_i，背包容量W，选哪些物品使总价值最大。

### 5.2 指派问题（Assignment Problem）

```
min  ΣΣ c_ij x_ij
s.t. Σ_j x_ij = 1  （每人做一项）
     Σ_i x_ij = 1  （每项一人做）
     x_ij ∈ {0,1}
```

特殊结构，可用匈牙利算法O(n³)求解，比一般IP快得多。

### 5.3 旅行商问题（TSP）

```
min  ΣΣ c_ij x_ij
s.t. Σ_j x_ij = 1  （每点离开一次）
     Σ_i x_ij = 1  （每点到达一次）
     子回路消除约束
     x_ij ∈ {0,1}
```

NP-hard问题，需要分支定界或启发式算法。

## 六、注意事项与坑

⚠️ **坑1：大M法的M要选合适**
建模"如果x>0则y=1"这种逻辑约束时，用 y ≥ x/M。M太小会切掉可行解，M太大会导致数值不稳定。建议M取一个合理的上界。

⚠️ **坑2：分支定界可能很慢**
最坏情况下搜索树是指数级的。如果问题规模大（变量>1000），考虑用启发式算法或专业求解器。

⚠️ **坑3：割平面法的数值问题**
Gomory割的系数可能在迭代中迅速增长，导致数值误差。实际中很少单独使用割平面法。

💡 **顿悟：整数规划的本质是离散优化**
线性规划是连续优化，可行域是凸集，最优解在顶点。整数规划的可行域是离散的点集，没有"顶点"概念，所以不能直接用单纯形法。分支定界的本质是"连续松弛+离散搜索"，割平面的本质是"用连续约束逼近离散可行域"。

❓ **疑问：有没有多项式时间算法？**
整数规划是NP-hard问题，一般情况下没有多项式时间算法。但特殊结构（如指派问题、运输问题）有多项式算法。这也是为什么识别问题结构很重要。

✨ **创新：分解方法**
对于大规模整数规划，可以用Benders分解、Lagrangian松弛等方法，把难的整数变量和易的连续变量分开处理。这是当前研究的热点方向。

## 七、与线性规划的关联

🔗 **关联1：LP松弛是所有IP算法的基础**
无论是分支定界还是割平面，都需要反复解LP松弛。所以线性规划是整数规划的基础。

🔗 **关联2：对偶理论在IP中的延伸**
LP的对偶在IP中变成了"整数对偶"，但不再有强对偶定理。Lagrangian松弛就是用对偶思想来获得更好的下界。

🔗 **关联3：灵敏度分析**
IP的灵敏度分析比LP复杂得多，因为整数解可能在参数变化时发生"跳跃"。
