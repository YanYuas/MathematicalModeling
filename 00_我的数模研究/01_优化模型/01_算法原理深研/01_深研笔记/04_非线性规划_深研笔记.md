## 一、问题起源：什么是非线性规划？

### 1.1 从线性规划到非线性规划

线性规划要求目标函数和约束都是线性的。但实际问题中，很多关系是非线性的：

- **投资组合**：风险是收益率的方差（二次函数）
- **曲线拟合**：误差平方和（二次函数）
- **工程设计**：梁的强度与截面积的关系（非线性）
- **化学平衡**：浓度与反应速率的关系（指数/幂函数）
- **神经网络**：损失函数关于权重是非线性的

**定义**：如果目标函数或约束条件中至少有一个是非线性函数，就称为**非线性规划**（Nonlinear Programming, NLP）。

一般形式：
```
min  f(x)
s.t. g_i(x) ≤ 0,  i = 1,...,m
     h_j(x) = 0,  j = 1,...,l
     x ∈ R^n
```

### 1.2 非线性规划 vs 线性规划

| 维度 | 线性规划 | 非线性规划 |
|------|---------|-----------|
| 可行域 | 凸多面体 | 任意形状（可能非凸） |
| 最优解位置 | 一定在顶点 | 可能在内部、边界、任意位置 |
| 求解方法 | 单纯形法（多项式时间） | 迭代法（梯度、牛顿等） |
| 全局最优 | 一定能找到 | 可能只有局部最优 |
| 难度 | 多项式时间可解 | 一般NP-hard |

💡 **顿悟**：线性规划是"简单"的——可行域是凸的，最优解在顶点，单纯形法高效。非线性规划是"复杂"的——可行域可能奇形怪状，可能有很多局部最优，需要用迭代法一步步逼近。

### 1.3 为什么非线性规划难？

**核心困难：局部最优 vs 全局最优**

考虑函数 f(x) = x·sin(x)，在区间[0, 10]上有多个局部极小值。梯度下降法从不同起点出发，可能收敛到不同的局部最优。

```
        /\      /\      /\
       /  \    /  \    /  \
  ____/    \__/    \__/    \____
       局部    局部    全局
       最优    最优    最优
```

⚠️ **坑**：非线性规划算法通常只能保证找到**局部最优**，不能保证全局最优。要找全局最优需要特殊条件（如凸性）或特殊算法（如分支定界、启发式）。

## 二、凸优化：非线性规划中的"好学生"

### 2.1 为什么要研究凸优化？

如果问题是**凸优化问题**，那么：
- ✅ 任何局部最优都是全局最优
- ✅ 有高效的多项式时间算法
- ✅ 有完善的理论（KKT条件、对偶理论）

很多实际问题可以转化为凸优化：
- 线性规划（特殊的凸优化）
- 二次规划（目标二次、约束线性）
- 最小二乘（曲线拟合）
- 逻辑回归（机器学习）
- 投资组合优化（均值-方差模型）

### 2.2 凸集

**定义**：集合C是凸集，如果对任意x, y ∈ C和任意θ ∈ [0,1]，都有 θx + (1-θ)y ∈ C。

直观理解：集合中任意两点的连线都在集合内。

| 凸集 | 非凸集 |
|------|--------|
| 线段、圆、球 | 月牙形、环形 |
| 线性约束的可行域 | 有"凹陷"的形状 |
| 半空间、多面体 | 两个不相交的圆的并集 |

### 2.3 凸函数

**定义**：函数f是凸函数，如果对任意x, y和θ ∈ [0,1]：
```
f(θx + (1-θ)y) ≤ θf(x) + (1-θ)f(y)
```

直观理解：函数图像在任意两点连线的下方。

**二阶条件**（二阶可微时）：f是凸函数 ⟺ Hessian矩阵半正定（∇²f(x) ⪰ 0）

常见凸函数：
- 线性函数 f(x) = a^T x + b（既是凸也是凹）
- 二次函数 f(x) = x^T A x（A半正定时）
- 指数函数 f(x) = e^x
- 负熵 f(x) = x log x
- 范数 f(x) = ||x||

### 2.4 凸优化问题

**定义**：如果目标函数f是凸函数，不等式约束g_i都是凸函数，等式约束h_j都是仿射函数（线性+常数），则称为凸优化问题。

```
min  f(x)        （f凸）
s.t. g_i(x) ≤ 0  （g_i凸）
     h_j(x) = 0  （h_j仿射）
```

💡 **关键性质**：凸优化问题的可行域是凸集，任何局部最优都是全局最优！

## 三、无约束优化：梯度下降法

### 3.1 核心思想：沿负梯度方向走

对于无约束问题 min f(x)，最直观的方法是**梯度下降法**（Gradient Descent）：

1. 计算当前点的梯度 ∇f(x_k)
2. 沿负梯度方向走一步：x_{k+1} = x_k - α·∇f(x_k)
3. 重复直到收敛

**为什么沿负梯度方向？**
梯度 ∇f(x) 指向函数值增长最快的方向，所以负梯度 -∇f(x) 指向函数值下降最快的方向。

数学证明：方向d的方向导数为 ∇f(x)^T d。要最小化方向导数（下降最快），在||d||=1约束下，解为 d = -∇f(x)/||∇f(x)||。

### 3.2 步长选择：固定步长 vs 线搜索

**固定步长**：α是常数
- 优点：简单
- 缺点：α太大会震荡不收敛，α太小收敛慢

**精确线搜索**：找 α = argmin f(x_k - α∇f(x_k))
- 优点：每步下降最多
- 缺点：计算量大

**Armijo准则**（非精确线搜索）：找满足 f(x_k - αd) ≤ f(x_k) - c·α·∇f(x_k)^T d 的最大α
- 优点：计算量小，保证下降
- 实践中最常用

### 3.3 梯度下降法的收敛性

对于凸函数f，梯度下降法的收敛速率是 O(1/k)（k是迭代次数）。

对于强凸函数（Hessian特征值有下界m>0），收敛速率是 O(q^k)，其中 q = (L-m)/(L+m) < 1（线性收敛）。

⚠️ **坑**：如果函数的"条件数"很大（Hessian特征值相差悬殊），梯度下降会走"之字形"，收敛很慢。这时候需要共轭梯度法或牛顿法。

## 四、牛顿法：利用二阶信息

### 4.1 核心思想：用二次函数逼近

梯度下降只用了一阶信息（梯度），牛顿法用了二阶信息（Hessian矩阵）。

在x_k处对f做二阶泰勒展开：
```
f(x_k + d) ≈ f(x_k) + ∇f(x_k)^T d + ½ d^T ∇²f(x_k) d
```

对d求导并令其为0，得到牛顿方向：
```
∇²f(x_k) · d = -∇f(x_k)
d = -∇²f(x_k)^{-1} · ∇f(x_k)
```

迭代公式：x_{k+1} = x_k - ∇²f(x_k)^{-1} · ∇f(x_k)

### 4.2 牛顿法的优点和缺点

**优点**：
- 二次收敛（在最优点附近，误差平方级下降）
- 对条件数大的问题也能快速收敛
- 不需要调步长（纯牛顿法步长=1）

**缺点**：
- 需要计算Hessian矩阵（O(n²)存储，O(n³)求逆）
- Hessian可能不正定（方向不是下降方向）
- 可能不收敛或收敛到鞍点
- 高维问题计算量太大

### 4.3 拟牛顿法：不计算Hessian

为了避免计算Hessian，拟牛顿法用一个近似矩阵B_k来逼近∇²f(x_k)：

- **BFGS**：最常用的拟牛顿法，用秩2更新B_k
- **DFP**：另一种拟牛顿法
- **L-BFGS**：有限内存BFGS，适合大规模问题（不存完整矩阵）

💡 **实践建议**：中等规模问题用BFGS，大规模问题用L-BFGS。scipy.optimize.minimize的默认方法就是L-BFGS-B。

## 五、共轭梯度法：介于梯度和牛顿之间

### 5.1 核心思想：共轭方向

共轭梯度法（Conjugate Gradient, CG）最初是为求解线性方程组 Ax=b 设计的，等价于求解二次函数 f(x) = ½x^T A x - b^T x 的最小值。

**共轭方向**：一组方向d_0, d_1, ..., d_{n-1}满足 d_i^T A d_j = 0 (i≠j)。

对于n维二次函数，共轭梯度法最多n步就能找到精确解！（比梯度下降快得多）

### 5.2 非线性共轭梯度

推广到非线性函数，有多种公式计算搜索方向：
- **Fletcher-Reeves (FR)**：β_k = ||g_k||² / ||g_{k-1}||²
- **Polak-Ribière (PR)**：β_k = g_k^T (g_k - g_{k-1}) / ||g_{k-1}||²
- **Hestenes-Stiefel (HS)**

PR公式通常比FR表现更好，因为它有"自动重启"的特性。

### 5.3 共轭梯度法的优点

- 不需要存储Hessian（只需存储几个向量）
- 比梯度下降收敛快（尤其是二次函数）
- 适合大规模问题（n>1000）

## 六、有约束优化：KKT条件

### 6.1 拉格朗日乘数法

对于等式约束问题：
```
min f(x)
s.t. h_j(x) = 0, j=1,...,l
```

定义拉格朗日函数：L(x, λ) = f(x) + Σ λ_j h_j(x)

最优解满足：∇_x L = 0, ∇_λ L = 0（即h_j(x)=0）

### 6.2 KKT条件

对于一般约束问题（含不等式）：
```
min f(x)
s.t. g_i(x) ≤ 0, i=1,...,m
     h_j(x) = 0, j=1,...,l
```

定义拉格朗日函数：L(x, μ, λ) = f(x) + Σ μ_i g_i(x) + Σ λ_j h_j(x)

**KKT条件**（Karush-Kuhn-Tucker）：
1. **平稳性**：∇f(x*) + Σ μ_i ∇g_i(x*) + Σ λ_j ∇h_j(x*) = 0
2. **原始可行性**：g_i(x*) ≤ 0, h_j(x*) = 0
3. **对偶可行性**：μ_i ≥ 0
4. **互补松弛**：μ_i · g_i(x*) = 0

💡 **互补松弛的含义**：如果约束g_i(x*) < 0（不起作用），则μ_i = 0；如果μ_i > 0，则g_i(x*) = 0（约束起作用）。也就是说，不起作用的约束对应的乘子必须为0。

### 6.3 KKT条件的地位

- 对任意可微问题，KKT条件是**必要条件**（最优解一定满足）
- 对凸优化问题，KKT条件是**充分必要条件**（满足KKT就是最优解）
- 类比：KKT对非线性规划，就像检验数对线性规划

🔗 **关联**：线性规划的对偶理论是KKT条件的特例。线性规划的互补松弛就是μ_i·g_i=0。

## 七、二次规划：特殊的非线性规划

### 7.1 问题形式

```
min  ½ x^T H x + c^T x
s.t. A x ≤ b
     A_eq x = b_eq
```

目标函数是二次的，约束是线性的。这是最简单的非线性规划。

### 7.2 求解方法

- **H半正定**（凸二次规划）：多项式时间可解，可用内点法、积极集法
- **H不定**（非凸）：NP-hard，可能有多个局部最优
- **特殊结构**：如最小二乘，有更高效的算法

常见应用：
- 投资组合优化（均值-方差模型）
- 曲线拟合（最小二乘）
- 支持向量机（SVM）
- 模型预测控制（MPC）

## 八、注意事项与坑

⚠️ **坑1：局部最优不是全局最优**
非线性规划算法通常只找局部最优。如果问题非凸，需要多起点测试，或用启发式算法（GA/SA）找全局。

⚠️ **坑2：梯度下降的步长**
步长太大→震荡不收敛；步长太小→收敛极慢。一定要用线搜索（Armijo准则）。

⚠️ **坑3：牛顿法的Hessian**
Hessian可能不正定，牛顿方向可能不是下降方向。需要修正（如加正则项、用拟牛顿法）。

⚠️ **坑4：数值微分 vs 解析微分**
能用解析梯度就用解析梯度！数值微分有截断误差和舍入误差，会严重影响收敛。

💡 **顿悟：非线性规划的本质**
线性规划是"一次性"的——单纯形法从一个顶点跳到另一个顶点，有限步找到最优。非线性规划是"迭代式"的——从一个起点出发，一步步逼近最优解，永远在"接近"的路上。

❓ **疑问：什么时候用什么算法？**
- 小规模（n<100）：牛顿法或BFGS，收敛快
- 中规模（n<1000）：L-BFGS，平衡速度和内存
- 大规模（n>1000）：共轭梯度法或随机梯度下降（SGD）
- 有约束：内点法或SQP（序列二次规划）
- 非凸全局优化：启发式算法+局部优化

✨ **创新：内点法**
内点法是现代非线性规划的主流方法，通过引入障碍函数把约束问题转化为无约束问题，然后用牛顿法求解。Karmarkar在1984年提出的内点法是线性规划的突破，后来推广到非线性规划。

## 九、与线性规划、整数规划的关联

🔗 **线性规划**：是非线性规划的特例（目标和约束都是线性的）。线性规划的对偶理论是KKT条件的特例。

🔗 **整数规划**：整数规划的LP松弛是线性规划，非线性整数规划的松弛是非线性规划。分支定界法中每个节点都要解一个连续优化问题。

🔗 **机器学习**：逻辑回归、SVM、神经网络训练本质上都是非线性优化问题。梯度下降是深度学习的核心算法。
