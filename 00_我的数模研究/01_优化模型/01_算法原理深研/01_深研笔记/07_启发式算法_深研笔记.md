## 一、问题起源

### 1.1 为什么需要启发式算法？

前面学的算法（单纯形法、梯度下降、动态规划）都有一个共同前提：**问题结构良好**。
- 线性规划：目标和约束都是线性的
- 梯度下降：目标函数可导，且能找到梯度
- 动态规划：有最优子结构和重叠子问题

但实际问题往往是"坏"的：
- 目标函数不可导（如离散问题）
- 有很多局部最优（如Rastrigin函数有几百个局部极小）
- 状态空间太大（如TSP n=100，10^157种路径）
- 问题是黑盒（只知道输入输出，不知道内部结构）

这时候，精确算法要么太慢，要么根本用不了。**启发式算法**就是用来解决这些"坏"问题的。

### 1.2 什么是启发式算法？

启发式（Heuristic）= "找到"的意思。启发式算法不保证找到全局最优，但能在合理时间内找到"足够好"的解。

核心思想：**模拟自然界中的某种过程**，用简单的规则产生复杂的智能行为。

| 算法 | 模拟的自然过程 | 提出时间 |
|------|--------------|---------|
| 遗传算法 GA | 生物进化（适者生存） | 1975, Holland |
| 模拟退火 SA | 物理退火（金属加热后缓慢冷却） | 1983, Kirkpatrick |
| 粒子群 PSO | 鸟群/鱼群觅食 | 1995, Kennedy & Eberhart |
| 蚁群 ACO | 蚂蚁找食物（信息素） | 1991, Dorigo |
| 差分进化 DE | 种群进化（差分变异） | 1997, Storn & Price |

💡 **顿悟**：这5种算法本质都是"试错+学习"——随机生成一些解，然后根据反馈不断改进。区别只是"怎么改进"的策略不同。

## 二、五种算法的核心思想

### 2.1 遗传算法（Genetic Algorithm, GA）

**模拟对象**：生物进化

**核心流程**：
1. **初始化**：随机生成一群"个体"（每个个体是一个解）
2. **选择**：适应度高的个体更可能被选中（适者生存）
3. **交叉**：两个父代交换基因，产生子代（基因重组）
4. **变异**：子代的基因随机突变（保持多样性）
5. **重复**：直到满足终止条件

**关键参数**：
- 种群大小：通常50-200
- 交叉概率：0.6-0.9
- 变异概率：0.01-0.1

**数学表达**：
```
选择：P(选择i) = f(i) / Σf(j)    （轮盘赌）
交叉：child = α·parent1 + (1-α)·parent2  （实数编码）
变异：gene = gene + N(0, σ)      （高斯变异）
```

**优点**：通用、并行、不易陷入局部最优
**缺点**：收敛慢、参数敏感、没有"记忆"

---

### 2.2 模拟退火（Simulated Annealing, SA）

**模拟对象**：金属退火——加热到高温，原子自由运动；缓慢冷却，原子逐渐排列成低能量的稳定结构。

**核心流程**：
1. **初始化**：随机一个解，设定初始温度T
2. **扰动**：在当前解附近随机产生一个新解
3. **接受**：
   - 新解更好 → 一定接受
   - 新解更差 → 以概率 exp(-ΔE/T) 接受（Metropolis准则）
4. **降温**：T = T × α（α通常0.9-0.99）
5. **重复**：直到T足够低

**关键洞察**：高温时容易接受差解（探索），低温时只接受好解（利用）。这就是"探索-利用"的平衡。

**数学表达**：
```
接受概率 P = 1, if ΔE < 0
          = exp(-ΔE/T), if ΔE >= 0
```

**优点**：理论上能收敛到全局最优（降温足够慢）、实现简单
**缺点**：只有一个解（串行）、降温策略敏感、慢

---

### 2.3 粒子群优化（Particle Swarm Optimization, PSO）

**模拟对象**：鸟群觅食——每只鸟根据自己的经验和群体的经验调整飞行方向。

**核心概念**：
- 每个解是一只"粒子"，有位置和速度
- pbest：粒子自己找到的最好位置
- gbest：整个群体找到的最好位置

**速度更新公式**：
```
v(t+1) = w·v(t) + c1·r1·(pbest - x(t)) + c2·r2·(gbest - x(t))
x(t+1) = x(t) + v(t+1)
```
- w：惯性权重（0.4-0.9），大→探索，小→利用
- c1：自我认知系数（通常2）
- c2：社会认知系数（通常2）
- r1, r2：[0,1]随机数

**优点**：收敛快、参数少、有记忆（pbest和gbest）
**缺点**：容易早熟（陷入局部最优）、对高维问题效果下降

---

### 2.4 蚁群算法（Ant Colony Optimization, ACO）

**模拟对象**：蚂蚁找食物——蚂蚁在路上留下信息素，信息素多的路更吸引蚂蚁，正反馈形成最优路径。

**核心流程**（以TSP为例）：
1. **初始化**：每条边的信息素τ_ij = 常数
2. **每只蚂蚁**：根据概率选择下一个城市
   ```
   P(选择j) = (τ_ij^α · η_ij^β) / Σ(τ_ik^α · η_ik^β)
   ```
   - τ_ij：信息素浓度
   - η_ij = 1/d_ij：启发式信息（距离近的更优）
   - α：信息素重要度（通常1）
   - β：启发式重要度（通常2-5）
3. **更新信息素**：
   - 挥发：τ_ij = (1-ρ)·τ_ij
   - 释放：τ_ij += Σ Δτ_ij（路径短的蚂蚁释放更多）
4. **重复**

**优点**：天然适合离散组合优化（TSP、调度）、正反馈强
**缺点**：连续问题不直接适用、收敛慢、参数多

---

### 2.5 差分进化（Differential Evolution, DE）

**模拟对象**：种群进化，但用"差分"来产生变异。

**核心流程**：
1. **初始化**：随机种群
2. **变异**：对每个个体x_i，随机选三个不同个体a,b,c
   ```
   v = a + F·(b - c)
   ```
   F是缩放因子（通常0.5-0.9）
3. **交叉**：v和x_i按概率混合，产生试验个体u
   ```
   u_j = v_j, if rand < CR or j == j_rand
   u_j = x_ij, otherwise
   ```
   CR是交叉概率（通常0.8-0.9）
4. **选择**：u比x_i好就替换，否则保留
5. **重复**

**优点**：收敛快、鲁棒性强、参数少（只有F和CR）、适合连续优化
**缺点**：对离散问题需要改造、种群多样性保持不如GA

## 三、五种算法的对比

### 3.1 核心机制对比

| 维度 | GA | SA | PSO | ACO | DE |
|------|-----|-----|-----|-----|-----|
| 解的数量 | 种群（多个） | 单个 | 种群（多个） | 种群（多只蚂蚁） | 种群（多个） |
| 改进方式 | 选择+交叉+变异 | 随机扰动+概率接受 | 速度更新 | 信息素+概率选择 | 差分变异+交叉 |
| 记忆 | 无（每代重新选） | 无（只有当前解） | 有（pbest+gbest） | 有（信息素矩阵） | 无（只有当前种群） |
| 探索/利用 | 交叉探索，变异探索 | 温度控制 | w控制 | 信息素挥发控制 | F和CR控制 |
| 适合问题 | 通用 | 通用 | 连续优化 | 离散组合优化 | 连续优化 |

### 3.2 探索 vs 利用

所有启发式算法都在平衡两件事：
- **探索（Exploration）**：搜索未知区域，避免陷入局部最优
- **利用（Exploitation）**：在已知好区域附近精细搜索

| 算法 | 探索机制 | 利用机制 |
|------|---------|---------|
| GA | 变异、交叉 | 选择（适者生存） |
| SA | 高温时接受差解 | 低温时只接受好解 |
| PSO | 大w、随机r1/r2 | 小w、向pbest/gbest靠拢 |
| ACO | 信息素挥发、随机选择 | 信息素正反馈 |
| DE | 大F、低CR | 小F、高CR |

💡 **顿悟**：探索和利用是矛盾的。探索多了收敛慢，利用多了容易早熟。好的算法能在两者间动态平衡。

### 3.3 收敛性

- **SA**：理论上保证收敛到全局最优（降温足够慢，T→0）
- **GA**：不保证收敛，但实际效果好
- **PSO**：不保证收敛，容易早熟
- **ACO**：在一定条件下收敛
- **DE**：不保证收敛，但实际收敛快

⚠️ **坑**：不要迷信"全局最优"。SA的理论收敛需要指数级的降温时间，实际中都是近似。所有启发式算法都是"大概率找到好解"，不是"一定找到最优"。

## 四、测试函数

### 4.1 Sphere函数（最简单）
```
f(x) = Σ x_i², x_i ∈ [-5.12, 5.12]
```
- 全局最优：f(0,0,...,0) = 0
- 特点：凸、单峰、光滑
- 用途：测试基本收敛能力

### 4.2 Rosenbrock函数（香蕉函数）
```
f(x) = Σ [100(x_{i+1} - x_i²)² + (1 - x_i)²]
```
- 全局最优：f(1,1,...,1) = 0
- 特点：非凸、山谷狭长、梯度法很难收敛
- 用途：测试算法在弯曲峡谷中的搜索能力

### 4.3 Rastrigin函数（多峰之王）
```
f(x) = Σ [x_i² - 10cos(2πx_i) + 10]
```
- 全局最优：f(0,0,...,0) = 0
- 特点：大量局部最优（n维有10^n个局部极小）
- 用途：测试算法跳出局部最优的能力

### 4.4 Griewank函数（多峰+关联）
```
f(x) = (1/4000)Σx_i² - Πcos(x_i/√i) + 1
```
- 全局最优：f(0,0,...,0) = 0
- 特点：变量间有乘积关联，局部最优数量随维度指数增长
- 用途：测试高维问题的可扩展性

## 六、建模比赛中的启发式算法

### 6.1 什么时候用启发式？
- 精确算法太慢（NP-hard问题）
- 目标函数不可导或不连续
- 问题是黑盒（只有输入输出）
- 只需要"足够好"的解，不需要精确最优

### 6.2 算法选择速查
| 问题类型 | 首选算法 | 备选 |
|---------|---------|------|
| 连续优化（低维） | DE / PSO | GA |
| 连续优化（高维） | DE | PSO |
| 离散组合优化（TSP/调度） | ACO | GA |
| 单解局部搜索改进 | SA | - |
| 多目标优化 | NSGA-II | MOEA/D |
| 不确定/噪声问题 | GA（种群鲁棒） | DE |

### 6.3 比赛中的坑

⚠️ **坑1：不设终止条件**
必须设最大迭代次数或精度阈值，否则可能跑很久。

⚠️ **坑2：参数不调**
默认参数不一定适合你的问题。至少要试2-3组参数。

⚠️ **坑3：只跑一次**
启发式算法有随机性，必须多次运行取平均/最好。

⚠️ **坑4：和精确算法比速度**
小问题上精确算法更快更准。启发式的优势在大问题、难问题上。

⚠️ **坑5：忘记记录收敛曲线**
比赛论文中需要收敛曲线证明算法有效。每次迭代都要记录最优值。

## 七、个人研究笔记

### 💡 顿悟时刻

1. **所有启发式算法都是"随机+反馈"**：不管模拟什么自然过程，本质都是随机生成解，然后根据好坏反馈调整。区别只是调整策略。

2. **种群 > 单个**：GA/PSO/DE/ACO都是种群算法，比SA（单解）更不容易陷入局部最优，因为种群能同时探索多个区域。

3. **记忆很重要**：PSO有pbest/gbest，ACO有信息素，这些"记忆"机制让算法能利用历史经验。GA和DE没有显式记忆，但种群本身就是一种记忆。

4. **没有免费午餐**：没有一种算法在所有问题上都最好。DE在连续优化上通常最强，但在离散问题上不如ACO。

### ❓ 待深入研究

1. 自适应参数调整（让算法自己调参数）
2. 混合算法（如GA+局部搜索、PSO+SA）
3. 代理模型辅助的启发式（用机器学习近似目标函数，减少真实评估次数）
4. 大规模优化（维度>1000时的协同进化、分解策略）

### ✨ 创新方向

1. **算法自动化选择**：用机器学习根据问题特征自动推荐最合适的启发式算法
2. **深度学习+启发式**：用神经网络学习变异/交叉策略（如AlphaGo的思路）
3. **量子启发式**：用量子计算的概念（叠加态）改进搜索
4. **多算法协同**：多种算法同时运行，共享好解（群岛模型）
