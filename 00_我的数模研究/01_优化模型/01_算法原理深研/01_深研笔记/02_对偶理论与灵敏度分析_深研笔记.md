# 对偶理论与灵敏度分析 深研笔记

## 0. 我的一句话总结

每个线性规划都有一个"影子问题"（对偶问题），影子问题的最优解就是原问题每种资源的"隐含价格"；知道了这个价格，就能快速判断参数变化对结果的影响，不用每次都重新求解。

---

## 1. 为什么要研究对偶？

### 1.1 实际痛点
- 求出最优解后，老板问："如果原料多买1单位，利润能增加多少？"
- 传统方法：改参数，重新求解。麻烦！
- 对偶理论：直接从最优表中读出答案，秒回！

### 1.2 理论意义
- 原问题和对偶问题是一枚硬币的两面
- 理解对偶才能真正理解线性规划
- 对偶单纯形法是灵敏度分析的基础

### 1.3 计算优势
- 有时对偶问题比原问题容易求解（约束少的问题）
- 对偶理论是内点法等高级算法的理论基础

## 2. 对偶问题的构造

### 2.1 标准形式的对偶

**原问题（P）**：
```
max  cᵀx
s.t. Ax ≤ b
     x ≥ 0
```

**对偶问题（D）**：
```
min  bᵀy
s.t. Aᵀy ≥ c
     y ≥ 0
```

### 2.2 对偶关系对照表（必须记牢）

| 原问题（最大化） | 对偶问题（最小化） |
|-----------------|-------------------|
| 变量 xⱼ ≥ 0 | 约束 Aᵀⱼy ≥ cⱼ |
| 变量 xⱼ ≤ 0 | 约束 Aᵀⱼy ≤ cⱼ |
| 变量 xⱼ 自由 | 约束 Aᵀⱼy = cⱼ |
| 约束 aᵢx ≤ bᵢ | 变量 yᵢ ≥ 0 |
| 约束 aᵢx ≥ bᵢ | 变量 yᵢ ≤ 0 |
| 约束 aᵢx = bᵢ | 变量 yᵢ 自由 |
| 目标系数 c | 右端项 c |
| 右端项 b | 目标系数 b |

💡 **记忆口诀**：
- 原问题的"变量"对应对偶的"约束"
- 原问题的"约束"对应对偶的"变量"
- 不等号方向：max的≤约束 → y≥0；min的≥约束 → y≥0
- 等号约束 → 自由变量；自由变量 → 等号约束

### 2.3 推导过程（以生产计划为例）

**原问题**：
```
max 3x₁ + 5x₂          （总利润）
s.t. x₁ + 2x₂ ≤ 8      （原料甲限量8）
     2x₁ + x₂ ≤ 10     （原料乙限量10）
     x₁, x₂ ≥ 0
```

**对偶问题的经济含义**：
假设有人要收购你的工厂和资源，他需要给每种资源定一个价格 y₁, y₂。

- 收购成本：8y₁ + 10y₂（他想最小化）
- 约束：生产产品A的资源价值 ≥ 产品A的利润 → y₁ + 2y₂ ≥ 3
- 约束：生产产品B的资源价值 ≥ 产品B的利润 → 2y₁ + y₂ ≥ 5
- 价格非负：y₁, y₂ ≥ 0

**对偶问题**：
```
min 8y₁ + 10y₂
s.t. y₁ + 2y₂ ≥ 3
     2y₁ + y₂ ≥ 5
     y₁, y₂ ≥ 0
```

💡 **顿悟**：对偶问题的本质是"资源定价问题"——在保证不亏本的前提下，最小化收购成本。对偶最优解就是资源的"公平价格"。

## 3. 对偶的基本性质

### 3.1 弱对偶性

**定理**：若 x 是原问题可行解，y 是对偶问题可行解，则 cᵀx ≤ bᵀy。

**证明**：
```
cᵀx ≤ (Aᵀy)ᵀx = yᵀAx ≤ yᵀb = bᵀy
```
第一步用了 Aᵀy ≥ c（对偶约束），第二步用了 Ax ≤ b（原约束）。

**推论**：
- 原问题任一可行解的目标值 ≤ 对偶问题任一可行解的目标值
- 如果找到 x 和 y 使 cᵀx = bᵀy，则两者都是最优解

### 3.2 强对偶性

**定理**：若原问题有最优解，则对偶问题也有最优解，且最优值相等。

```
max cᵀx = min bᵀy
```

💡 **意义**：原问题和对偶问题的最优值是同一个数。这意味着可以通过求解对偶问题来得到原问题的最优值。

### 3.3 互补松弛性

**定理**：若 x* 和 y* 分别是原问题和对偶问题的最优解，则：

```
yᵢ* × (bᵢ - aᵢx*) = 0    对所有 i
xⱼ* × (aⱼᵀy* - cⱼ) = 0    对所有 j
```

**含义**：
1. 如果 yᵢ* > 0，则第 i 个约束取等号（资源用完了）
2. 如果第 i 个约束有松弛（没用完），则 yᵢ* = 0（这种资源不值钱）
3. 如果 xⱼ* > 0，则第 j 个对偶约束取等号
4. 如果第 j 个对偶约束有松弛，则 xⱼ* = 0（这种产品不生产）

💡 **顿悟**：互补松弛性是"物以稀为贵"的数学表达——稀缺的资源才有正的影子价格，过剩的资源影子价格为0。

### 3.4 生产计划例子验证

原问题最优解：x₁=4, x₂=2, 利润=22

对偶问题最优解：
- 原料甲用完了（8=8）→ y₁ > 0
- 原料乙用完了（10=10）→ y₂ > 0
- 产品A生产了（x₁>0）→ y₁ + 2y₂ = 3
- 产品B生产了（x₂>0）→ 2y₁ + y₂ = 5

解方程组：
```
y₁ + 2y₂ = 3
2y₁ + y₂ = 5
```
得 y₁ = 7/3 ≈ 2.33, y₂ = 1/3 ≈ 0.33

验证对偶目标值：8×(7/3) + 10×(1/3) = 56/3 + 10/3 = 66/3 = 22 ✓

## 4. 影子价格

### 4.1 定义
影子价格 yᵢ* = ∂(最优值) / ∂bᵢ，即第 i 种资源增加1单位时，最优值的变化量。

### 4.2 经济含义
- yᵢ* > 0：资源 i 稀缺，增加1单位能增加 yᵢ* 的利润
- yᵢ* = 0：资源 i 过剩，增加不影响利润
- yᵢ* 是资源的"边际价值"，不是市场价格

### 4.3 决策应用
**是否购买额外资源？**
- 如果市场价格 < 影子价格 → 应该购买（划算）
- 如果市场价格 > 影子价格 → 不应该购买（不划算）
- 如果市场价格 = 影子价格 → 买不买都行

**生产计划例子**：
- 原料甲影子价格 = 7/3 ≈ 2.33元/单位
- 如果市场价2元 < 2.33元 → 买！每单位赚0.33元
- 如果市场价3元 > 2.33元 → 不买！

### 4.4 影子价格的适用范围
影子价格只在一定范围内有效！超过范围后，基变量改变，影子价格也变。

**怎么求范围？**
保持当前基不变的条件下，bᵢ 的变化范围。
即 b_bar = B⁻¹(b + Δbᵢeᵢ) ≥ 0，解这个不等式得到 Δbᵢ 的范围。

## 5. 灵敏度分析

### 5.1 目标函数系数 cⱼ 变化

**问题**：cⱼ 变化多少时，最优基不变？

**方法**：最优基不变的条件是所有检验数 ≥ 0（最小化）。
- 如果 xⱼ 是非基变量：只影响 rⱼ，rⱼ' = rⱼ + Δcⱼ ≥ 0 → Δcⱼ ≥ -rⱼ
- 如果 xⱼ 是基变量：影响所有非基变量的检验数，需要重新计算

**生产计划例子**：
- 产品A利润 c₁=3，基变量
- 允许范围：[2.5, 10]
- 在范围内，最优产量不变，但总利润变

### 5.2 右端项 bᵢ 变化

**问题**：bᵢ 变化多少时，最优基不变？

**方法**：b_bar = B⁻¹b ≥ 0
- bᵢ 变化 Δbᵢ → b_bar' = b_bar + Δbᵢ × (B⁻¹的第i列)
- 要求 b_bar' ≥ 0，解不等式

**生产计划例子**：
- 原料甲 b₁=8，允许范围 [4, 16]
- 原料乙 b₂=10，允许范围 [5, 20]
- 在范围内，影子价格不变

### 5.3 增加新变量

**问题**：新增一种产品，要不要生产？

**方法**：计算新变量的检验数 r_new = c_new - c_BᵀB⁻¹A_new
- r_new ≥ 0（最小化）：不生产（机会成本太高）
- r_new < 0：应该生产，重新求解

**经济含义**：c_new 是新产品利润，c_BᵀB⁻¹A_new 是生产新产品消耗资源的机会成本。
- 利润 > 机会成本 → 生产
- 利润 < 机会成本 → 不生产

### 5.4 增加新约束

**问题**：新增一个约束，最优解变吗？

**方法**：
1. 检查当前最优解是否满足新约束
2. 满足：最优解不变
3. 不满足：加入新约束（加松弛变量），用**对偶单纯形法**继续求解

⚠️ **坑**：不要重新用两阶段法！对偶单纯形法快得多，因为检验数已经满足最优性条件了。

### 5.5 约束系数 aᵢⱼ 变化

比较复杂，通常需要重新计算 B⁻¹ 和检验数。
- 如果是非基变量的系数：只影响该列的检验数
- 如果是基变量的系数：影响 B，需要重新求逆，通常直接重新求解

## 6. 对偶单纯形法原理

### 6.1 和原始单纯形法的对比

| | 原始单纯形法 | 对偶单纯形法 |
|---|---|---|
| 保持 | 原可行（b≥0） | 对偶可行（r≥0） |
| 追求 | 对偶可行（r≥0） | 原可行（b≥0） |
| 出基选择 | 比值测试（正系数） | b最负的行 |
| 进基选择 | 检验数最负 | 比值测试（负系数） |

### 6.2 为什么对偶单纯形法能工作？

从一个对偶可行但原不可行的解出发：
- 每次选 b<0 的基变量出基（让它变非基，值从负变0）
- 用比值测试选进基变量，保证旋转后检验数仍≥0（对偶可行）
- 直到所有 b≥0，此时原可行+对偶可行=最优

### 6.3 比值测试的推导

出基行是第 l 行，进基变量是 xⱼ，主元 a_lj < 0。
旋转后新检验数：r'_k = r_k - (r_j / a_lj) × a_lk

要保持 r'_k ≥ 0：
- 对于 a_lk > 0 的列：r'_k = r_k - (负数)×(正数) = r_k + 正数 ≥ 0，自动满足
- 对于 a_lk < 0 的列：需要 r_k - (r_j / a_lj) × a_lk ≥ 0
  - 因为 a_lj < 0, a_lk < 0，所以 (r_j / a_lj) × a_lk = r_j × (a_lk/a_lj) = r_j × (正数)
  - 需要 r_j / a_lj ≤ r_k / a_lk（注意两边都是负数，不等号方向）
  - 即 |r_j / a_lj| ≤ |r_k / a_lk|
- 所以选 |r_j / a_lj| 最小的列进基

## 8. 实战建议

### 8.1 论文中怎么写灵敏度分析
1. 求出最优解后，计算影子价格
2. 分析关键参数的允许变化范围
3. 画龙卷风图展示各参数的影响程度
4. 给出管理建议（如"原料甲的影子价格2.33元，建议市场价低于2.33时采购"）

### 8.2 计算工具
- 手算：用单纯形表，B⁻¹在最优表中
- Python：scipy.optimize.linprog 返回 marginals
- MATLAB：linprog 返回 lambda 结构（对偶变量）

### 8.3 常见错误
⚠️ **错误1**：把影子价格当成市场价格。影子价格是边际价值，只在小范围内有效。
⚠️ **错误2**：忽略影子价格的适用范围，外推过度。
⚠️ **错误3**：增加约束后重新用两阶段法，而不是对偶单纯形法。
