## 一、问题起源：为什么需要多目标规划？

### 1.1 单目标 vs 多目标

单目标规划只有一个目标函数，比如"最大化利润"或"最小化成本"。但现实决策往往涉及**多个相互冲突的目标**：

- **投资**：既要高收益，又要低风险（收益和风险往往正相关）
- **选址**：既要成本低，又要覆盖广（成本低的地方往往覆盖差）
- **生产**：既要产量高，又要污染少
- **调度**：既要时间短，又要成本低
- **设计**：既要性能好，又要重量轻

**定义**：多目标规划（Multi-Objective Programming, MOP）是同时优化两个或多个目标函数的优化问题。

一般形式（最小化）：
```
min  f_1(x), f_2(x), ..., f_k(x)
s.t. x ∈ X （可行域）
```

### 1.2 多目标的本质：权衡（Trade-off）

多目标规划的核心不是"找到最优解"，而是**找到一组权衡方案**，让决策者根据偏好选择。

💡 **顿悟**：单目标规划的答案是"一个点"，多目标规划的答案是"一条曲线"（Pareto前沿）。决策者的工作是在这条曲线上选一个最符合自己偏好的点。

### 1.3 为什么不能简单加权？

一个常见的误区：把多个目标加权求和变成单目标。

```
min  w1·f1(x) + w2·f2(x)
```

问题：
- 权重怎么选？不同权重得到不同解
- 权重的物理意义不明确（"收益的权重0.6"是什么意思？）
- 固定权重只能得到Pareto前沿上的一个点，不是全部
- 非凸Pareto前沿时，加权法会漏掉某些解

所以多目标规划需要专门的理论和方法。

## 二、核心概念：Pareto最优

### 2.1 支配关系（Dominance）

**定义**：解x支配解y（记作x ≺ y），如果：
1. x在所有目标上都不劣于y：f_i(x) ≤ f_i(y) 对所有i
2. x至少在一个目标上严格优于y：f_i(x) < f_i(y) 对某个i

通俗说：x比y"全面不差，且至少有一项更好"。

### 2.2 Pareto最优解

**定义**：解x*是Pareto最优解（非劣解），如果不存在其他解x支配x*。

换句话说：Pareto最优解是"无法在不牺牲其他目标的前提下改进某一个目标"的解。

### 2.3 Pareto前沿（Pareto Front）

所有Pareto最优解的目标函数值构成的集合，称为Pareto前沿。

```
目标2 ↑
      |
      |  ····  ← Pareto前沿（曲线）
      |·     ·
      | ·     ·
      |  ······
      +--------→ 目标1
```

Pareto前沿上的每个点都是"权衡方案"：要改进目标1，就必须牺牲目标2。

### 2.4 弱Pareto最优 vs 强Pareto最优

- **弱Pareto最优**：不存在x使所有目标都严格更优
- **强Pareto最优**：不存在x使所有目标都不劣且至少一个更优

强Pareto最优更严格，通常说的Pareto最优指强Pareto最优。

## 三、经典方法：将多目标转化为单目标

### 3.1 加权法（Weighted Sum Method）

**思想**：给每个目标分配权重，加权求和变成单目标。

```
min  Σ w_i · f_i(x)
s.t. x ∈ X
```

**特点**：
- 简单直观
- 改变权重可以得到不同的Pareto最优解
- 但只能得到Pareto前沿的**凸部分**，非凸部分会漏掉

💡 **权重的选择**：没有统一标准，通常需要决策者参与，或者用等权重、随机权重、自适应权重。

### 3.2 ε约束法（ε-Constraint Method）

**思想**：选一个目标作为主要目标，其他目标作为约束。

```
min  f_1(x)
s.t. f_i(x) ≤ ε_i,  i = 2,...,k
     x ∈ X
```

**特点**：
- 可以得到整个Pareto前沿（包括非凸部分）
- 需要为每个约束目标选择ε值
- 改变ε可以遍历Pareto前沿
- 比加权法更可靠，但计算量更大（每个ε要解一次单目标）

### 3.3 理想点法（Ideal Point Method / TOPSIS）

**思想**：先找到每个目标单独优化时的最优值（理想点），然后找离理想点最近的解。

**理想点**：f* = (f_1*, f_2*, ..., f_k*)，其中f_i* = min f_i(x)

**距离度量**：
- 欧氏距离：min ||f(x) - f*||_2
- 切比雪夫距离：min max_i |f_i(x) - f_i*|
- 加权距离：min Σ w_i |f_i(x) - f_i*|

**特点**：
- 有明确的物理意义（"离最理想的情况有多远"）
- 切比雪夫距离可以得到非凸部分的解
- TOPSIS是理想点法的变种，同时考虑理想点和负理想点

### 3.4 目标规划（Goal Programming）

**思想**：为每个目标设定一个期望值（目标值），最小化偏离目标值的程度。

```
min  Σ (d_i^+ + d_i^-)
s.t. f_i(x) + d_i^- - d_i^+ = g_i  （目标约束）
     d_i^+, d_i^- ≥ 0
     x ∈ X
```

其中g_i是目标值，d_i^+是超出量，d_i^-是未达量。

**特点**：
- 适合有明确目标值的决策问题
- 可以区分"必须达到"和"尽量达到"的目标（优先级）
- 线性目标规划可以用单纯形法求解

## 四、进化多目标优化：NSGA-II

### 4.1 为什么需要进化算法？

经典方法（加权法、ε约束法）每次只能得到一个Pareto最优解，要得到整个前沿需要多次运行。

进化算法（如遗传算法）是**基于种群**的方法，一次运行可以得到一组解，天然适合多目标优化。

### 4.2 NSGA-II的核心思想

NSGA-II（Non-dominated Sorting Genetic Algorithm II）由Deb等人在2002年提出，是最经典的多目标进化算法。

**三大核心机制**：
1. **非支配排序**（Non-dominated Sorting）：将种群按Pareto支配关系分层
2. **拥挤度**（Crowding Distance）：同一层内保持多样性
3. **精英保留**（Elitism）：父代和子代合并选择，保留优秀解

### 4.3 非支配排序

将种群中的个体按支配关系分成多个层次（前沿）：
- F1：当前种群的Pareto最优解（不被任何其他解支配）
- F2：去掉F1后，剩余个体的Pareto最优解
- F3：...以此类推

排序算法：
```
对每个个体p：
  S_p = 被p支配的个体集合
  n_p = 支配p的个体数
n_p = 0的个体放入F1
对F1中的每个个体p：
  对S_p中的每个个体q：
    n_q -= 1
    如果n_q = 0，放入F2
重复直到所有个体分层
```

### 4.4 拥挤度

同一前沿层内，需要保持解的多样性（不要挤在一起）。

拥挤度估计：对每个目标，按目标值排序，相邻两个个体的目标值之差的和。

```
cd(p) = Σ_i (f_i(p_{i+1}) - f_i(p_{i-1})) / (f_i^max - f_i^min)
```

边界点（每个目标的最大和最小）的拥挤度设为无穷大。

**选择规则**：先选前沿层号小的；同一层内，选拥挤度大的。

### 4.5 NSGA-II算法流程

```
1. 初始化种群P0（随机生成N个个体）
2. 非支配排序，计算拥挤度
3. 选择、交叉、变异，生成子代Q0
4. 对每一代t：
   a. R_t = P_t ∪ Q_t （父子合并，2N个个体）
   b. 对R_t非支配排序，得到F1, F2, ...
   c. 从F1开始依次加入新种群P_{t+1}，直到满N个
   d. 如果某一层装不下，按拥挤度排序选最稀疏的
   e. 从P_{t+1}选择、交叉、变异生成Q_{t+1}
5. 输出最终种群的非支配解（Pareto前沿近似）
```

### 4.6 NSGA-II的优点

- ✅ 一次运行得到整个Pareto前沿的近似
- ✅ 非支配排序保证收敛性
- ✅ 拥挤度保证多样性
- ✅ 精英保留防止优秀解丢失
- ✅ 计算效率高（非支配排序O(MN²)，M是目标数）

### 4.7 NSGA-II的参数

| 参数 | 常用值 | 说明 |
|------|--------|------|
| 种群大小N | 50-200 | 目标越多需要越大 |
| 迭代次数 | 100-500 | 问题越复杂需要越多 |
| 交叉概率 | 0.8-0.9 | SBX交叉 |
| 变异概率 | 1/n（n是变量数） | 多项式变异 |
| 交叉分布指数 | 20 | 控制子代离父代的距离 |
| 变异分布指数 | 20 | 控制变异的幅度 |

## 五、性能评价指标

### 5.1 收敛性指标

**世代距离（GD, Generational Distance）**：
```
GD = (Σ d_i^p)^(1/p) / N
```
d_i是得到的解到真实Pareto前沿的最短距离。GD越小，收敛越好。

### 5.2 多样性指标

**间距（Spacing, SP）**：
```
SP = sqrt(Σ (d̄ - d_i)² / (N-1))
```
d_i是解i到最近解的距离。SP越小，分布越均匀。

### 5.3 综合指标

**超体积（HV, Hypervolume）**：
```
HV = volume(∪ [f_i(x), ref])
```
得到的解与参考点围成的区域体积。HV越大，收敛性和多样性都越好。是最常用的综合指标。

## 六、注意事项与坑

⚠️ **坑1：加权法漏掉非凸前沿**
如果Pareto前沿是非凸的，加权法无论怎么选权重都得不到非凸部分的解。这时候要用ε约束法或进化算法。

⚠️ **坑2：目标量纲不一致**
如果目标1是"万元"（数量级10^4），目标2是"小时"（数量级10^1），直接加权会被大数量级的目标主导。必须先**归一化**每个目标到[0,1]。

⚠️ **坑3：NSGA-II的参数敏感**
种群太小→多样性差；迭代太少→没收敛；交叉变异概率不合适→早熟或发散。需要调参。

⚠️ **坑4：Pareto最优解不唯一**
多目标规划的答案是一组解，不是一个解。不要问"哪个最优"，要问"Pareto前沿是什么"。

💡 **顿悟：多目标规划的本质是"决策支持"**
多目标规划不是替决策者做决定，而是给决策者提供一组候选方案（Pareto前沿），让决策者根据自己的偏好选择。算法的任务是"找全、找好"Pareto前沿，而不是"选一个"。

❓ **疑问：目标越多越好吗？**
不是。目标越多，Pareto前沿的维度越高，可视化越难，决策者越难选择。一般建议目标数≤3（可以可视化），超过3个需要先做目标降维或偏好整合。

✨ **创新：偏好驱动的多目标优化**
传统方法先找全Pareto前沿再让决策者选。偏好驱动方法在优化过程中就引入决策者的偏好，只搜索决策者感兴趣的区域，效率更高。这是当前研究热点。

## 七、与单目标规划的关联

🔗 **关联1：加权法是单目标规划**
给定权重后，多目标规划就变成了单目标规划，可以用线性规划、非线性规划、整数规划的所有方法求解。

🔗 **关联2：ε约束法也是单目标规划**
把其他目标变成约束后，仍然是单目标规划。约束的右端ε是参数，改变ε遍历前沿。

🔗 **关联3：NSGA-II用了遗传算法**
NSGA-II本质上是遗传算法的多目标版本，选择机制不同（非支配排序+拥挤度），交叉变异和单目标遗传算法一样。

## 八、学习路径

1. ✅ 先确保单目标规划（线性/非线性/整数）基础扎实
2. 理解Pareto最优和支配关系（核心概念）
3. 掌握经典方法：加权法、ε约束法、理想点法
4. 理解NSGA-II的三大机制（非支配排序、拥挤度、精英保留）
5. 手动实现NSGA-II，直观感受Pareto前沿的形成
6. 学习性能评价指标（HV、GD、Spacing）
7. 研究高级算法：MOEA/D、SPEA2、偏好驱动方法
