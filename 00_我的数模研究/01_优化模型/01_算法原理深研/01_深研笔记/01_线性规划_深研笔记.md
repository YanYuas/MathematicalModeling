# 线性规划 深研笔记

## 0. 我的一句话总结

线性规划就是在"一堆直线围成的区域里"找一个点，让某个线性函数最大或最小；而神奇的是，最优解一定在区域的"角落"上，所以只要沿着角落跳就能找到。

---

## 1. 问题起源

### 1.1 历史背景
线性规划的诞生和二战密切相关。1940年代，美国军方需要解决：
- 如何分配有限的物资（兵力、武器、补给）使作战效果最大？
- 如何安排运输路线使成本最低？

这些问题有一个共同点：**目标和约束都是线性的**。

### 1.2 之前的方法为什么不行？
- 穷举法：变量一多就不可能
- 微积分求导：有约束时不适用，而且约束是不等式
- 图解法：只能解决2个变量的问题

### 1.3 核心突破
1947年，George Dantzig提出了**单纯形法（Simplex Method）**：
- 发现线性规划的可行域是一个**凸多面体**
- 证明了**最优解一定在顶点上**
- 设计了从一个顶点跳到更优顶点的方法

💡 **顿悟**：单纯形法的本质不是"搜索"，而是"跳跃"。它不检查所有点，只在顶点之间移动，而顶点的数量虽然多，但实际中很少需要全部走一遍。

---

## 2. 核心思想

### 2.1 直观解释
想象你在一个多边形的房间里，要找到海拔最高的角落。你不需要走遍每个地方，只需要：
1. 站在一个角落
2. 看看相邻的角落哪个更高
3. 走到更高的那个角落
4. 重复，直到所有相邻角落都比你低

这就是单纯形法！

### 2.2 几何意义
- 线性约束 → 半平面的交集 → 凸多面体
- 线性目标函数 → 一组平行直线（或超平面）
- 最优解 → 这组平行线中，最后离开可行域的那条线接触的点

### 2.3 为什么最优解在顶点？
**定理**：如果线性规划有最优解，那么一定存在一个顶点是最优解。

**直观理解**：目标函数是线性的，意味着它没有"弯曲"。如果最优解在一条边上，那么这条边上的所有点都是最优解，包括端点（顶点）。如果最优解在内部，那可以沿着目标函数增长方向移动到边界，最终到顶点。

❓ **疑问**：这个定理的严格证明需要用到凸分析，我目前的理解是直观层面的。后续需要补一下凸多面体的顶点表示定理。

## 3. 数学推导

### 3.1 标准形式
任何线性规划都可以转化为标准形式：

```
min  cᵀx
s.t. Ax = b
     x ≥ 0
```

**转化技巧**：
- max → min：目标函数取负
- ≤ 约束：加松弛变量 s ≥ 0，Ax + s = b
- ≥ 约束：减剩余变量 s ≥ 0，Ax - s = b
- 自由变量（无正负限制）：x = x⁺ - x⁻，x⁺, x⁻ ≥ 0

### 3.2 基与基解

设 A 是 m×n 矩阵（m个约束，n个变量），且 rank(A) = m。

**定义**：从A的n列中选出m列线性无关的列，组成矩阵 B（m×m），称为**基矩阵**。对应的变量称为**基变量**，其余称为**非基变量**。

**基解**：令非基变量 = 0，解 Bx_B = b，得到 x_B = B⁻¹b。这个解称为基解。

**基可行解**：如果基解满足 x_B ≥ 0，则称为基可行解。

💡 **关键对应**：基可行解 ↔ 可行域的顶点。这是单纯形法的理论基础。

### 3.3 单纯形法的核心推导

#### 步骤1：将目标函数用非基变量表示

设当前基为 B，非基为 N。变量分为 x_B 和 x_N。

约束：Bx_B + Nx_N = b → x_B = B⁻¹b - B⁻¹Nx_N

目标函数：
```
z = c_Bᵀx_B + c_Nᵀx_N
  = c_Bᵀ(B⁻¹b - B⁻¹Nx_N) + c_Nᵀx_N
  = c_BᵀB⁻¹b + (c_Nᵀ - c_BᵀB⁻¹N)x_N
```

令 z₀ = c_BᵀB⁻¹b（当前目标值），检验数 σ_N = c_Nᵀ - c_BᵀB⁻¹N

则 z = z₀ + σ_N x_N

#### 步骤2：判断是否最优

对于最小化问题：
- 如果所有 σ_j ≥ 0（非基变量的检验数非负），则当前解最优
- 因为 x_N ≥ 0，增大任何非基变量都会使 z 增大或不变

对于最大化问题，相反：所有 σ_j ≤ 0 时最优。

#### 步骤3：选择进基变量
选择检验数最负的那个非基变量（最小化问题），让它从0开始增大。

#### 步骤4：选择出基变量
进基变量 x_k 增大时，基变量 x_B = B⁻¹b - B⁻¹Nx_N 会减小。
当某个基变量减小到0时，它必须出基（否则会变负，违反非负约束）。

设 B⁻¹N 的第 k 列为 ā_k，B⁻¹b = b̄。
则 x_B = b̄ - ā_k x_k

要求 x_B ≥ 0 → x_k ≤ b̄_i / ā_{ik}（对 ā_{ik} > 0 的行）

所以 x_k 的最大增量 = min { b̄_i / ā_{ik} | ā_{ik} > 0 }

达到这个最小值的那一行对应的基变量出基。

#### 步骤5：更新基，重复

💡 **顿悟**：单纯形法的每一步，本质上是在解一个"哪个变量该进来，哪个该出去"的问题。检验数告诉我们"该让谁进来"，比值测试告诉我们"该让谁出去"。

### 3.4 退化与循环
**退化**：基可行解中有基变量 = 0。
**问题**：退化时可能出现循环（在几个顶点之间来回跳，不进步）。
**解决**：Bland规则（选择下标最小的进基/出基变量）可以避免循环。

⚠️ **坑**：实际中退化很常见，但循环非常罕见。Bland规则虽然理论上保证不循环，但会降低收敛速度。实际实现中通常不用Bland规则，而是用其他扰动技术。

### 3.5 对偶理论

原问题：
```
max  cᵀx        min  bᵀy
s.t. Ax ≤ b  ↔  s.t. Aᵀy ≥ c
     x ≥ 0           y ≥ 0
```

**强对偶定理**：如果原问题有最优解，对偶问题也有最优解，且最优值相等。

**互补松弛**：x_j × (Aᵀy - c)_j = 0，y_i × (Ax - b)_i = 0

💡 **顿悟**：对偶问题的经济意义——对偶变量 y_i 是第 i 种资源的"影子价格"，表示增加一单位资源能带来多少收益。这在灵敏度分析中非常有用。

## 4. 算法流程

### 4.1 单纯形法伪代码
```
输入：标准形式的线性规划 (A, b, c)，初始基可行解

1. 计算检验数 σ = c - c_BᵀB⁻¹A
2. 如果所有 σ ≥ 0（最小化），返回最优解
3. 选择 σ_k < 0 中最小的 k 作为进基变量
4. 计算 ā = B⁻¹A[:,k]，b̄ = B⁻¹b
5. 如果所有 ā_i ≤ 0，问题无界
6. 选择 θ = min{b̄_i / ā_i | ā_i > 0}，对应行 l 出基
7. 以 (l, k) 为主元进行高斯消元（旋转）
8. 回到步骤1
```

### 4.2 初始基可行解的获取
- 约束都是 ≤：加松弛变量，松弛变量构成初始基
- 有 = 或 ≥ 约束：需要**两阶段法**或**大M法**

### 4.3 复杂度
- 最坏情况：指数时间（Klee-Minty例子）
- 实际情况：通常 O(m) 到 O(m²) 次迭代
- 每次迭代：O(mn) 运算

## 6. 应用实战

### 6.1 适用场景判断
**什么时候用线性规划？**
- 目标函数是线性的
- 约束都是线性的
- 变量是连续的（可以取小数）

**常见应用**：
- 生产计划：有限资源下最大化利润
- 运输问题：供需平衡下最小化运费
- 指派问题：人和工作的最优匹配
- 下料问题：最少浪费的切割方案
- 投资组合：线性近似下的资产配置

### 6.2 建模技巧
1. **变量定义要清晰**：每个变量的含义、单位、范围
2. **约束要完整**：包括显式约束和隐式约束（如非负）
3. **量纲要一致**：目标函数中各项的单位要统一
4. **归一化**：系数数量级差异大时，先归一化

### 6.3 常见坑
⚠️ **坑1：忘记非负约束**
很多实际问题中变量天然非负，但建模时容易忘记写 x ≥ 0。

⚠️ **坑2：约束方向写反**
最大化利润时，资源约束应该是 ≤，不是 ≥。

⚠️ **坑3：把非线性问题强行线性化**
不是所有问题都能线性化。如果目标或约束本质是非线性的，应该用非线性规划。

⚠️ **坑4：整数变量用线性规划求解**
如果变量必须是整数，用linprog会得到小数解，需要用整数规划。

## 7. 对比与思考

### 7.1 单纯形法 vs 内点法
| 维度 | 单纯形法 | 内点法 |
|------|----------|--------|
| 搜索路径 | 在顶点上跳 | 在可行域内部走 |
| 收敛速度 | 实际中快，最坏指数 | 多项式时间 |
| 实现难度 | 简单 | 复杂 |
|  warm start | 支持好 | 支持差 |
| 适合规模 | 中小规模 | 大规模 |

💡 **思考**：内点法理论上更优（多项式时间），但实际中单纯形法往往更快，因为它利用了顶点的稀疏结构。这是一个"理论 vs 实践"的有趣案例。

### 7.2 我的改进想法
✨ **想法1**：混合策略——先用内点法快速接近最优，再用单纯形法精确定位顶点。
✨ **想法2**：学习型进基选择——用机器学习预测哪个进基变量收敛最快。

（这些只是初步想法，需要进一步研究可行性）
