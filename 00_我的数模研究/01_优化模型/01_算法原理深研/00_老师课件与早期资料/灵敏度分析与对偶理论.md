# 灵敏度分析与对偶理论

## 一、为什么需要灵敏度分析

数学建模中，很多参数是估计的、预测的，存在不确定性。灵敏度分析回答：
- 参数变化时，最优解会变吗？
- 变化多少时，最优解开始改变？
- 哪个参数对结果影响最大？

这是竞赛论文中**加分项**，体现模型的严谨性。

---

## 二、线性规划的灵敏度分析

### 2.1 目标函数系数变化

**问题**：max cᵀx, s.t. Ax ≤ b, x ≥ 0

当某个 cᵢ 变化时，最优解是否改变？

**分析方法**：
- 最优基不变的条件：所有非基变量的检验数 ≤ 0（最大化问题）
- 计算 cᵢ 的允许变化范围 [cᵢ_min, cᵢ_max]
- 在范围内变化时，最优基不变（但最优值可能变）

**示例**：
生产计划问题，产品A利润从3元变为4元，最优产量变吗？
- 计算得允许范围 [2.5, 5.0]
- 4在范围内，最优产量不变，但总利润增加

### 2.2 右端项变化（影子价格）

**影子价格**：约束右端项 bᵢ 增加1单位时，目标函数最优值的变化量。

**含义**：
- 影子价格 > 0：该资源稀缺，增加资源能提高利润
- 影子价格 = 0：该资源有剩余，增加资源不影响利润
- 影子价格为对偶变量的值

**示例**：
原料A的影子价格为2元，表示增加1单位原料A，利润增加2元。
- 如果原料A的市场价格 < 2元，应该购买
- 如果市场价格 > 2元，不应该购买

**影子价格的适用范围**：
- 只在一定范围内有效
- 超过范围后，基变量改变，影子价格也改变

### 2.3 增加新变量

**问题**：新增一种产品，是否应该生产？

**方法**：计算新变量的检验数
- 检验数 ≤ 0（最大化）：不生产
- 检验数 > 0：应该生产，重新求解

**经济含义**：新产品的"机会成本"
- 利润 > 机会成本：生产
- 利润 < 机会成本：不生产

### 2.4 增加新约束

**方法**：
1. 先检查当前最优解是否满足新约束
2. 满足：最优解不变
3. 不满足：加入新约束，重新求解（可用对偶单纯形法）

## 三、对偶理论

### 3.1 原问题与对偶问题

**原问题（P）**：
```
max  cᵀx
s.t. Ax ≤ b
     x ≥ 0
```

**对偶问题（D）**：
```
min  bᵀy
s.t. Aᵀy ≥ c
     y ≥ 0
```

### 3.2 对偶关系对照表

| 原问题（max） | 对偶问题（min） |
|--------------|----------------|
| 变量 x ≥ 0 | 约束 Aᵀy ≥ c |
| 变量 x 自由 | 约束 Aᵀy = c |
| 约束 Ax ≤ b | 变量 y ≥ 0 |
| 约束 Ax = b | 变量 y 自由 |
| 目标系数 c | 右端项 c |
| 右端项 b | 目标系数 b |

### 3.3 对偶的基本性质

#### 1. 弱对偶性
若 x 是原问题可行解，y 是对偶问题可行解，则：
```
cᵀx ≤ bᵀy
```
原问题的最优值 ≤ 对偶问题的最优值

#### 2. 强对偶性
若原问题有最优解，则对偶问题也有最优解，且：
```
max cᵀx = min bᵀy
```

#### 3. 互补松弛性
若 x* 和 y* 分别是原问题和对偶问题的最优解，则：
```
yᵢ* × (bᵢ - aᵢx*) = 0   对所有 i
xⱼ* × (aⱼᵀy* - cⱼ) = 0   对所有 j
```

**含义**：
- 约束松弛（有剩余）→ 对应对偶变量 = 0
- 对偶变量 > 0 → 对应约束取等号（紧约束）
- 变量 > 0 → 对应对偶约束取等号
- 对偶约束松弛 → 对应变量 = 0

### 3.4 对偶的经济解释

- **对偶变量 yᵢ**：第 i 种资源的影子价格
- **对偶目标 bᵀy**：资源的总隐含价值
- **对偶约束 Aᵀy ≥ c**：生产单位产品 j 的资源价值 ≥ 产品利润（否则应该生产）

## 四、非线性规划的灵敏度分析

### 4.1 KKT条件中的拉格朗日乘子

对于约束优化问题：
```
min f(x)
s.t. gᵢ(x) ≤ 0
     hⱼ(x) = 0
```

KKT条件中的拉格朗日乘子 λᵢ, μⱼ 就是灵敏度指标：
- λᵢ = ∂f*/∂bᵢ（约束右端变化对最优值的影响）
- λᵢ ≥ 0（不等式约束）
- μⱼ 自由（等式约束）

### 4.2 灵敏度分析的数值方法

当解析方法不可行时，用数值方法：

#### 方法1：扰动法
```
对每个参数 pᵢ：
  1. 求解原问题，得最优值 f*
  2. 将 pᵢ 增加 Δp，求解得 fᵢ⁺
  3. 将 pᵢ 减少 Δp，求解得 fᵢ⁻
  4. 灵敏度 ≈ (fᵢ⁺ - fᵢ⁻) / (2Δp)
```

#### 方法2：归一化灵敏度
```
Sᵢ = (∂f/∂pᵢ) × (pᵢ / f)
```
Sᵢ 表示参数 pᵢ 变化1%时，目标值变化百分之几。

### 4.3 龙卷风图（Tornado Diagram）

将各参数的灵敏度按大小排序，用横向条形图展示：
- 最长的条：最敏感的参数
- 最短的条：最不敏感的参数
- 可以直观看到哪些参数需要精确估计

## 五、整数规划的灵敏度分析

### 5.1 特点
- 整数规划的最优值对参数变化是**不连续**的
- 参数微小变化可能导致最优解跳变
- 影子价格的概念不直接适用

### 5.2 分析方法
1. **分支定界的灵敏度**：分析每个分支的影响
2. **参数化整数规划**：系统地变化参数，观察最优解
3. **鲁棒优化**：考虑参数在一定范围内变化，找最稳健的解

---

## 六、竞赛论文中的灵敏度分析写法

### 6.1 标准结构

```
## 灵敏度分析

### 6.1 参数A的灵敏度
- 将参数A在±20%范围内变化，观察最优值变化
- 结果：最优值从100变为95-105，变化幅度±5%
- 结论：模型对参数A不敏感，结果稳健

### 6.2 参数B的灵敏度
- 将参数B在±20%范围内变化
- 结果：最优值从100变为60-140，变化幅度±40%
- 结论：模型对参数B敏感，需要精确估计

### 6.3 龙卷风图
（插入龙卷风图）

### 6.4 结论
- 最敏感参数：B, C
- 最不敏感参数：A, D
- 建议：对敏感参数进行更精确的测量或预测
```

### 6.2 常用分析维度
1. **目标函数系数**：利润、成本、权重
2. **约束右端项**：资源量、需求量、时间限制
3. **技术系数**：消耗定额、转化率
4. **概率参数**：随机变量的分布参数

### 6.3 可视化
- **龙卷风图**：单参数灵敏度
- **蛛网图**：多参数同时变化
- **三维曲面图**：两个参数的联合影响
- **收敛曲线**：参数变化时最优解的变化轨迹

## 七、鲁棒优化简介

### 7.1 为什么需要鲁棒优化
传统优化假设参数是确定的，但实际中参数可能：
- 预测有误差
- 未来会变化
- 存在异常值

鲁棒优化的目标：找到一个解，在参数的所有可能取值下都表现良好。

### 7.2 基本形式
```
min  max_{p ∈ P}  f(x, p)
s.t. g(x, p) ≤ 0   对所有 p ∈ P
```
其中 P 是参数的不确定集合。

### 7.3 不确定集合的类型
- 盒式集合：pᵢ ∈ [pᵢ_min, pᵢ_max]
- 椭球集合：||p - p₀|| ≤ r
- 预算集合：最多有k个参数偏离名义值

### 7.4 与随机规划的区别
| 方法 | 假设 | 目标 |
|------|------|------|
| 随机规划 | 参数有概率分布 | 期望最优 |
| 鲁棒优化 | 参数在集合内 | 最坏情况最优 |
| 灵敏度分析 | 参数变化范围 | 观察影响 |

## 八、实战案例：生产计划的灵敏度分析

### 问题
某工厂生产A、B两种产品：
- A利润3元，消耗1单位原料甲、2单位原料乙
- B利润5元，消耗2单位原料甲、1单位原料乙
- 原料甲限量8，原料乙限量10

### 最优解
x_A = 4, x_B = 2, 最大利润 = 22元

### 灵敏度分析

#### 1. 利润系数变化
- A的利润允许范围：[2.5, 10]
- B的利润允许范围：[1.5, 6]
- 在范围内，最优产量不变

#### 2. 资源影子价格
- 原料甲的影子价格：1.67元/单位
- 原料乙的影子价格：0.67元/单位
- 含义：增加1单位原料甲，利润增加1.67元

#### 3. 影子价格适用范围
- 原料甲：[4, 16]（当前8）
- 原料乙：[5, 20]（当前10）
- 超过范围后影子价格改变

#### 4. 新增产品C
- C利润4元，消耗1单位甲、1单位乙
- 机会成本 = 1×1.67 + 1×0.67 = 2.34元
- 利润4 > 机会成本2.34，应该生产C
