# 优化模型知识点总结

## 一、优化模型的基本形式

### 1.1 三要素
任何优化问题都包含三个要素：
- **决策变量**：需要确定的未知量 x = (x₁, x₂, ..., xₙ)
- **目标函数**：需要优化（最大/最小）的函数 f(x)
- **约束条件**：决策变量需要满足的限制 g(x) ≤ 0, h(x) = 0

### 1.2 标准形式
```
min (或 max)  f(x)
s.t.  gᵢ(x) ≤ 0   (不等式约束)
      hⱼ(x) = 0   (等式约束)
      x ∈ S       (变量范围)
```

---

## 二、线性规划 (LP)

### 2.1 标准形式
```
min  cᵀx
s.t. Ax = b
     x ≥ 0
```

### 2.2 求解方法
- **图解法**：2个变量时可用
- **单纯形法**：经典方法，从一个顶点跳到另一个顶点
- **内点法**：从可行域内部逼近最优解，适合大规模问题

### 2.3 重要概念
- **可行解**：满足所有约束的解
- **最优解**：使目标函数最优的可行解
- **基解/基可行解**：单纯形法的核心概念
- **对偶问题**：每个LP都有对偶问题，对偶价格=影子价格

### 2.4 灵敏度分析
- 目标函数系数变化的影响
- 右端项变化的影响（影子价格）
- 增加新变量/新约束的影响

### 2.5 常见应用
- 生产计划、资源分配
- 运输问题、指派问题
- 下料问题、配料问题

---

## 三、整数规划 (IP)

### 3.1 分类
- **纯整数规划**：所有变量都是整数
- **混合整数规划**：部分变量是整数
- **0-1规划**：变量只能取0或1

### 3.2 求解方法
- **分支定界法**：最常用，将问题分解为子问题
- **割平面法**：添加约束切割可行域
- **隐枚举法**：0-1规划专用

### 3.3 常见应用
- 指派问题（0-1规划）
- 背包问题（0-1规划）
- 选址问题
- 生产调度（整数变量）

---

## 四、非线性规划 (NLP)

### 4.1 分类
- **无约束优化**：只有目标函数
- **约束优化**：带约束条件
- **凸优化**：目标函数和约束都是凸的（全局最优可保证）
- **非凸优化**：可能存在多个局部最优

### 4.2 无约束优化方法
- **梯度下降法**：沿负梯度方向搜索
- **牛顿法**：利用二阶导数，收敛快
- **拟牛顿法**（BFGS）：近似牛顿法，避免计算Hessian
- **共轭梯度法**：适合大规模问题

### 4.3 约束优化方法
- **拉格朗日乘数法**：等式约束
- **KKT条件**：不等式约束的最优性条件
- **序列二次规划（SQP）**：MATLAB fmincon默认方法
- **罚函数法**：将约束转化为目标函数的惩罚项

### 4.4 凸优化
- 凸函数 + 凸集 = 凸优化
- 局部最优 = 全局最优
- 常见凸优化：线性规划、二次规划、半定规划

---

## 五、多目标规划

### 5.1 特点
- 多个目标函数，往往相互矛盾
- 不存在使所有目标同时最优的解
- 得到Pareto最优解集（折中方案）

### 5.2 求解方法
| 方法 | 思想 | 适用场景 |
|------|------|----------|
| 加权求和法 | 给各目标赋权重，化为单目标 | 有明确偏好 |
| 理想点法 | 最小化到理想点的距离 | 无明确偏好 |
| 分层序列法 | 按优先级依次优化 | 目标有明确优先级 |
| 目标规划 | 设定目标值，最小化偏离 | 有期望目标值 |
| NSGA-II | 生成Pareto前沿 | 需要展示所有方案 |

---

## 六、动态规划 (DP)

### 6.1 基本思想
- 将复杂问题分解为子问题
- 子问题的解被多次使用（重叠子问题）
- 最优子结构：整体最优包含子问题最优

### 6.2 基本要素
- **阶段**：问题分解的步骤
- **状态**：每个阶段的起始条件
- **决策**：从一个状态到下一个状态的选择
- **状态转移方程**：状态之间的关系
- **指标函数**：衡量决策效果的函数

### 6.3 求解步骤
1. 划分阶段
2. 确定状态和状态变量
3. 确定决策和状态转移方程
4. 建立指标函数和最优值函数
5. 逆序（或顺序）递推求解

### 6.4 经典问题
- 背包问题（0-1背包、完全背包）
- 最短路径问题
- 资源分配问题
- 生产计划问题
- 最长公共子序列

## 七、现代启发式算法

### 7.1 为什么需要启发式算法
- 传统方法对NP难问题无效
- 目标函数不可导、不连续
- 需要全局最优，避免局部最优

### 7.2 遗传算法 (GA)
- **灵感来源**：达尔文进化论
- **核心操作**：选择、交叉、变异
- **编码方式**：二进制编码、实数编码
- **适用**：组合优化、参数优化

### 7.3 模拟退火 (SA)
- **灵感来源**：金属退火过程
- **核心**：Metropolis准则，以概率接受劣解
- **参数**：初始温度、降温速度、终止温度
- **适用**：组合优化、全局优化

### 7.4 粒子群算法 (PSO)
- **灵感来源**：鸟群觅食
- **核心**：个体最优(pbest) + 全局最优(gbest)
- **参数**：惯性权重w、学习因子c1/c2
- **适用**：连续函数优化、参数训练

### 7.5 其他启发式算法
- 蚁群算法 (ACO)：路径优化、TSP
- 禁忌搜索 (TS)：避免重复搜索
- 人工鱼群算法 (AFSA)
- 差分进化 (DE)
- 免疫算法

## 八、方法选择指南

### 8.1 按问题类型选择
| 问题特征 | 推荐方法 |
|----------|----------|
| 目标和约束都是线性 | 线性规划 (linprog) |
| 变量要求整数 | 整数规划 (intlinprog) |
| 目标或约束非线性 | 非线性规划 (fmincon/SLSQP) |
| 多个目标 | 多目标规划（加权/理想点/NSGA-II） |
| 多阶段决策 | 动态规划 |
| NP难组合优化 | 启发式算法（GA/SA/PSO） |
| 全局最优要求 | 启发式算法 + 多次运行 |

### 8.2 按数据规模选择
- 小规模（<100变量）：精确方法
- 中规模（100-1000变量）：精确方法或启发式
- 大规模（>1000变量）：启发式算法或分解方法

### 8.3 按解的质量要求
- 需要全局最优证明：精确方法（LP/凸优化）
- 接受近似最优：启发式算法
- 需要Pareto前沿：NSGA-II等多目标进化算法

- `cvxpy`：凸优化
- `scikit-opt`：GA, PSO, SA, ACO

- `linprog`：线性规划
- `intlinprog`：整数规划
- `fmincon`：非线性规划
- `fminimax`：最小最大
- `fgoalattain`：目标达到
- Global Optimization Toolbox：ga, particleswarm, simulannealbnd

### 其他
- LINGO：专门的优化建模语言
- GAMS：通用代数建模系统
