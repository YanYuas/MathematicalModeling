## 文件命名规范

- **教材**：`作者_书名.pdf`
- **优秀论文**：`年份+题号_论文主题_优秀论文.pdf`
- **赛题**：`年份+题号_赛题主题_赛题.pdf`
- **写作指南**：`类型_说明.扩展名`
- **课程课件**：`主题_课件.pdf` 或 `年份+题号_主题_真题分析.扩展名`
- **高数课件**：`高数_第X章第Y节_主题.pdf`
- **代码**：按语言分目录，保留原始文件名
- **赛题评述**：`年份+题号_赛题名称_赛题评述_主讲人.pdf`

## 记忆要点

1. **01_教材与教程**是系统学习的核心，司守奎的两本书是建模必备
2. **02-赛题与论文**中的优秀论文可用于学习写作结构和方法
3. **论文写作指南**有2个大文件（写作方法12.8MB + 注意事项13.3MB），是论文手的重要参考
4. **05_高等数学参考课件**是高数课程内容，不是数模论文，作为数学基础参考
5. **03_国赛代码参考**是2026国赛B题的完整代码，MATLAB和Python都有，可作为编程手的参考
6. 不相关文件（劳务合同、招新表、课程作业等）已移至桌面`散落资料集成`文件夹
7. 4个损坏文件（E题.pdf、2024板凳龙.pdf、B477.docx、赛题评述.pdf）已移至`90_重复与临时文件`
8. .pyc编译文件和重复的result文件已清理
