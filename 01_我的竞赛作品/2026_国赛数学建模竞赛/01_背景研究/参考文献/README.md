## 二、逐篇精读与可用点

### 2.1 Welzl-1991《Smallest enclosing disks》(最小包围圆) —— Q1 核心算法

**论文是什么**：计算几何经典论文。给定平面 n 个点，求能包住全部点的最小半径圆盘，随机化增量算法**期望 O (n) 时间**，实现简单。

**核心方法（可抄伪代码）**：



* 关键引理：最小包围圆由**至多 3 个边界点**决定；去掉一个非边界点，圆不变。

* `MINIDISK(P)` 主过程 + `B_MINIDISK(P,R)`（强制 R 中点都在边界上）两层递归；随机选点，若点在圆外则把它加入边界集重算。

* 复杂度：`t_3(n) ≤ 10n` 次包含测试（论文第 5 页）。

* 工程改进：先随机打乱 + move-to-front 启发式（MTFDISK），实践中查询次数降到约 4n。

**建模手能用什么**：



1. **Q1 标准答案的后半段**："以定位区域直径为直径的圆不能保证覆盖"（等边三角形反例）之后，补一句 "若要保证覆盖，应求最小包围圆"，然后直接实现 Welzl 算法 —— 复杂度 O (n) 期望、代码约 30 行，引这篇原始文献很加分。

2. 定位多边形的顶点数 m ≤ 2n（n 是检测点数），规模极小，暴力 O (m²) 兜底也行，但论文写法用 Welzl。

3. 唯一性证明（两圆半径相等必重合）可直接引用，不需要自己证。

**注意**：这篇是扫描版 PDF，公式要看截图（提取文本乱码），伪代码在正文第 3–4 页。

### 2.2 ITU-R SM.854-3-2011《监测站测向与定位》 —— Q1/Q2 权威依据

**论文是什么**：国际电联建议书（5 页，很短），讲测向（direction finding）与发射源定位的精度分类和工程建议。

**核心内容**：



* **表 2（频率 > 30MHz）测向精度分级**：A 级 ±1°、B 级 ±2°、C 级 ±5°、D 级 >±5°。

* 明确指出：**交会定位（triangulation）的定位精度在整个覆盖区域内不均匀**，取决于测向站之间的几何配置；测向站距离太远时定位区域可能完全消失（建议书 d) e) 条）。

* 介绍了 SSL（单站定位）概念（仅作背景）。

**建模手能用什么**：



1. **B 题的 ±1° 误差假设 = ITU 的 A 级精度标准**。论文里写 "题目给定 ±1° 误差符合 ITU-R SM.854-3 对 >30MHz 测向的 A 级精度要求"，一句话给误差假设挂上权威出处。

2. **Q2 的理论依据**："定位精度取决于测向站几何配置" 正是第二检测点要 "垂直偏移、交会角≈90°" 的根本原因 —— 论文里可直接引这句。

3. 可作为参考文献列表里的标准类引用（格式上很正规）。

**注意**：这是 "建议书" 不是学术论文，适合当背景 / 标准引用，不要引用具体页码数据以外的内容。

### 2.3 Jing-2020《多无人机覆盖路径规划》 —— Q3 路径优化借鉴

**论文是什么**：把多无人机巡检路径规划建模成 **集合覆盖问题 (SCP) + 车辆路径问题 (VRP)** 的混合（SC-VRP），用改进的随机键遗传算法（BRKGA）求解，路径比基线短最多 48%。

**核心内容**：



* 目标：min-max（最小化最长那架飞机的路径）。

* 覆盖率约束：每个被覆盖单元至少被一条选中路径覆盖（约束式 (3)）；也可以只要求覆盖率 ≥ δd（式 (8)）。

* 2-opt 局部改进启发式（算法 3）：交换路径上两顶点，若变短且覆盖不降级就接受。

* 路径基元采样 + 可见性评估 + C-PRM 图。

**建模手能用什么**：



1. **Q3 网格路径的形式化**：机器狗要访问的检测网格点 = "必须覆盖的点集"，路径 = 访问顺序。如果建模手想写 "覆盖路径规划" 章节，可直接套 SCP+VRP 的叙述框架（我们只需单机版，即 TSP 变体）。

2. **2-opt 局部改进**：简单、可落地，编程手实现容易，Q3 路径优化可以直接用（网格点 7–12 个，暴力 2-opt 也很快）。

3. **覆盖率软约束 δd**（式 8）：Q4 讨论 "多方位确认的覆盖程度" 时可用这个建模。

4. 论文结论 "增加飞机数不等于路径线性缩短"—— 可作为我们 "单机狗 vs 多机狗" 讨论的背景。

**注意**：BRKGA 对 7–12 个点过重，不推荐直接用遗传算法；正文伪代码可读性一般，抓 "SCP+VRP 形式化 + 2-opt" 两个点即可。

### 2.4 Shahid-2024《含禁飞区的覆盖路径规划》 —— Q3 扫描路径算法

**论文是什么**：给凹多边形（带洞 / 禁飞区）生成无人机 zigzag（Boustrophedon 往返扫描）覆盖路径：直线骨架偏移保证安全距离、扫描线分解凸子区、DFS 连通、生成 zigzag。

**核心内容（可直接改写）**：



* **zigzag 路径生成**：等距平行线 `y = mx + n·d·√(m²+1)`（式 2，d = 线间距），与凸多边形求交，交替方向连接成往返路径。

* 凸多边形一条 zigzag 就能覆盖；凹多边形先分解再拼。

* 连续路径减少转向、减少无效移动。

**建模手能用什么**：



1. **Q3 侦察阶段用 zigzag 扫描代替点对点跳转**：B 题目标域是圆（凸），不需要分解，直接生成与 x 轴平行的往返扫描线，间距 = 网格间距（约 1500 米），机器狗沿 zigzag 边走边在每个扫描段上扫频道。相比 "访问离散网格点"，省掉大量折返。

2. **"连续路径减少转向" 的论点**可以直接写进论文的路径设计说明。

3. 若 Q4 想引入 "圆内局部区域重点巡逻"，凸分解 + zigzag 的思想可复用。

**注意**：本文没有直线骨架的实现细节（引用了他人算法），我们不需要偏移（B 题无禁飞区），只取 zigzag 生成部分。

### 2.5 Chen-2024《GyroCopter 差示向度定位》 —— Q3 顺序决策借鉴

**论文是什么**：单天线无人机边飞边转（gyration），用相邻 RSSI 差值得到 "伪示向度"（差分化消除环境项），粒子滤波估计多源位置，任务型规划逐个定位。

**核心内容**：



* **任务型规划（算法 1）**：每一步选 "离当前最近的未定位源"，朝它移动（式 12：`a* = argmin d(x̄, fuav(u,a))`）；连续型直接输出指向最近源的速度向量。

* 连续 / 离散两种动作空间（离散 = 8 方向 ×8 秒，连续 = 每秒重规划）。

* 论证 "传感器靠近源能获得更可靠测量"—— 支持逐源逼近策略。

* CRLB 推导最优旋转速度（与本模拟器无关，跳过）。

**建模手能用什么**：



1. **Q3/Q4 的 "先处理哪个源" 决策 = 最近源优先**：论文里的 task-based planner 直接对应我们的场景 —— 机器狗在圆域内发现多个源后，按 "距当前最近" 排序逐个处理（清完一个再下一个），简单有效，可直接写进策略描述并引这篇。

2. **"发现→靠近→再测量→收敛" 的迭代逼近思想**：与我们的 homing（渐进逼近到 near）一致，论文里 "接近源以获得更高 SNR" 可作理论支撑。

3. 离散航路点 vs 连续规划的讨论：我们受 20 分钟现实时间限制，用 "离散航路点 + 每站停测" 即可，论文提供了对照。

**注意**：粒子滤波 / CRLB/RSSI 部分与本模拟器不匹配（模拟器直接给示向度），不要引入；只用 "最近优先 + 逐源处理" 的规划框架。

### 2.6 Masrur-2025《3D 聚类深度学习 RF 定位》 —— 背景与轨迹借鉴

**论文是什么**：面向 AERPAW 竞赛（AFAR，隐藏 RF 源定位挑战），用增强双射线传播模型 + 3D 聚类 + 1D ResNet 从 RSS 轨迹估计源位置，实测平均误差 18.2m。

**核心内容**：



* **固定航路点螺旋轨迹**扫掠区域采 RSS（"确保不遗漏区域"）。

* 固定航路点 vs 自主航路点（自适应）两种轨迹范式。

* sim2real（仿真到现实）gap 的讨论。

**建模手能用什么**：



1. **Q3 侦察覆盖可用螺旋 / 扫描轨迹**：论文明确支持 "用固定路径系统扫掠，避免遗漏区域"，与我们的覆盖网格策略同思路，可引。

2. **"固定航路点 vs 自主航路点" 分类术语**：描述我们的策略属于 "固定覆盖扫描 + 局部自适应逼近" 的混合。

3. 竞赛背景引用：AFAR 挑战赛与本题同为 "隐藏 RF 源定位"，论文可作为 "同类竞赛主流做法" 的背景对比（他们用 RSS + 深度学习，我们用示向度几何，体现方案差异）。

**注意**：DL 定位、双射线模型、3D 聚类**不要引入我们的方案**—— 模拟器是黑盒，只返回示向度，无 RSS、无法训练。这篇定位为 "背景 + 轨迹借鉴"。

### 2.7 Yang-2016《稀疏方法做 DOA 估计》综述 —— 背景引用

**论文是什么**：65 页综述，讲用稀疏表示 / 压缩感知做到达方向（DOA）估计：on-grid /off-grid/gridless 三类方法；含 MUSIC、ESPRIT、Capon 等经典方法回顾。

**核心内容**：



* DOA = 从传感器阵列输出估计来波方向（阵元→导向矢量→阵列流形）。

* 稀疏方法的核心卖点：**不需要先验知道源的数量**、单快拍可用、相关源可用。

* 综述结构：数据模型、稀疏表示与压缩感知、三类稀疏方法、结论。

**建模手能用什么**：



1. **"源数量未知" 的背景论述**：综述反复强调 "传统子空间方法需要先验源数，稀疏方法不需要"—— 与 B 题 "干扰源个数未知" 对应，可在问题分析章节引这句话，说明我们 "不能靠数源停，要靠频道确认停" 的合理性。

2. **文献引用**：MUSIC/ESPRIT/ 波束形成等经典 DOA 方法列全了，论文 "相关工作" 章节缺引用时从这里拿。

3. 误差模型对比：我们的 ±1° 误差是区间约束（几何法），不是稀疏噪声模型 —— 论文中可写 "本题示向度误差为有界区间，采用几何交会而非统计稀疏估计"。

**注意**：这是综述，不提供直接可用的算法实现；**不建议**在方案里引入稀疏恢复（过度工程、模拟器也不提供阵列数据）。定位为纯背景引用。

## 五、使用红线（建模手注意）



1. **不要过度引用**：B 题是应用建模题，参考文献 5–8 篇足够；每引一篇必须真的用到（比如 Welzl 用于 Q1、ITU 用于误差假设、Shahid/Chen 用于 Q3 策略），不要凑数。

2. **不要引入与本模拟器不匹配的方法**：粒子滤波、深度学习、稀疏恢复、RSSI 传播模型都不要进算法主体 —— 模拟器只返回示向度 / 距离状态，黑盒、无训练数据。

3. **引用格式**：论文写作时按 CUMCM 论文格式规范引用（作者、标题、出处、年份），Welzl 是 LNCS 555 (1991) 359–370；ITU 是建议书编号 SM.854-3 (09/2011)；arXiv 论文引用 arXiv 编号。完整元数据直接抄 `背景全量研究报告.md` 第四节表格。

4. **数据真实性**：这些论文的实验数字（如 18.2m 误差、48% 路径缩短）不要直接当 "我们的结果" 写进论文，只能作为对比 / 背景提。
