## 执行摘要

**这个问题本质是什么。** 表面是"机器狗找干扰源"，实质是**两个独立问题的拼接**：
① 前两问是**静态几何/统计估计**问题——在 ±1° 有界方向误差下，把若干条"示向度"射线交叉成的区域刻画清楚（交会定位、定位区域直径、测点选优），可解析、可证明、有经典文献支撑；
② 后两问是**部分可观测的在线搜索—定位—清除决策**问题——在 1800 m 圆域内、源数 10–16 未知、位置/频道/接收半径/定向方向全部未知的条件下，用一条条 HTTP 指令探测并清除，核心产出是对接模拟器的**机器狗程序**。

**标准解法。** 几何层：楔形角域求交 → 凸包 → 旋转卡壳求直径 →（对照）最小包围圆；估计层：Stansfield 加权最小二乘 / 极大似然方位定位；搜索层：蜂窝（正三角）格点覆盖 + 覆盖路径规划（牛耕式/生成树）+ 逐频道状态机 + 渐进逼近（homing）+ 完备性停止条件。**不需要强化学习**：状态空间小（≤20 频道、≤16 源）、虚拟时间预算极宽（100 h），确定性启发式 + 完备性证明是正路。

**最大的坑。** 三处：
1. **"直径圆能覆盖定位区域"是错的**——直径是两点距离，覆盖是全体点约束。等边三角形即反例（外接圆半径 0.577a > 直径圆半径 0.5a）。正确提法是**最小包围圆**。
2. **±1° 误差在远距离被放大到与清除半径同量级**——1000 m 处横向偏 17.46 m、1500 m 处 26.18 m、1800 m 处 31.42 m，全部逼近或超过 20 m 清除半径。所以"定位完直接 clear"会失败，**必须渐进逼近到 `near`（≤5 m）再清除**。
3. **`no_signal` 不等于"该频道无源"**——它同时是"超接收半径""定向源盲区""已清除"三种情况的输出。Q4 的一切难点都从这里长出来。

**置信度。** 题目与两个附件的**规则层**已逐句核对，置信度**高**；**参考材料层**同样**高**——已通过 Crossref / arXiv / ITU 官方接口**逐条核验**（见第四节）；仅《无线电管理条例》一项文号日期待人工核对。

## 一、题设、条件与约束形式化

### 1.1 问题结构

| 问 | 目标 | 已知 | 约束 | 复杂度 |
|----|------|------|------|--------|
| Q1 | 给出"多边形定位区域直径"的**算法**；回答"以该直径为直径的圆能否覆盖定位区域" | 若干检测点坐标 + 各点示向度 | 示向度误差 ±1°；定位区域=所有 2° 楔形角域交集 | 低（几何，可解析证明） |
| Q2 | 给出**第二个检测点的选择策略**，并给出**候选区域** | 某全向源在一点处的示向度 | 待测源距离未知；有效接收半径 ∈[1000,1500] 未知 | 中（几何优化 + 鲁棒性） |
| Q3 | 定量策略 + 算法，使机器狗从原点出发自动定位清除**全部全向源**，并**尽量短** | 源数 ∈[10,16] 未知；20 频道；动作成本规则 | 100% 清除为硬前提；时间次之；须经模拟器正式测试 | 高（在线决策 + 工程实现） |
| Q4 | 同上，但源为**全向 + 定向混合** | 在 Q3 基础上，定向源个数与朝向均未知 | 定向源仅覆盖 ±90° 扇区，存在盲区 | 高（发现难度阶跃） |

### 1.2 数据识别

**本题没有外部数据集。** 这是与大多数 CUMCM 题最大的区别——不存在"标准数据集/公开数据"可比对，全部"数据"由官方模拟器在测试时随机生成，且**接口不返回真值**。必须识别清楚三类"数据"的性质：

| 类别 | 载体 | 是否可读 | 性质 |
|------|------|---------|------|
| 题目参数 | B题.pdf 正文 + 附录 1 | 可读 | 物理常数与规则（半径、误差界、耗时、频道数） |
| 接口规范 | 附件 1、附件 2 | 可读 | HTTP+JSON 协议、计时规则、错误码（**编程手的地基**） |
| 案例真值 | 模拟器内部 | **不可读** | 源数/频道/位置/接收半径/定向方向，正式测试完全不显示 |
| 观测 | `/measure` 响应 | 部分可读 | 每点每频道返回 `direction`(+`svd_deg`) / `near` / `no_signal` |

**关键推论**：由于真值不可读、观测又不完备（`no_signal` 三义），本题的"数据"本质是**序贯决策过程中逐步自造的信息**。所有算法的评价都必须回到模拟器实测，不能靠离线数据集验证。

### 1.3 约束清单

**物理约束**
- C1 目标区域：半径 1800 m 圆域，圆心为原点；x 正东、y 正北（米）。
- C2 干扰源总数 ∈ [10, 16]（Q3/Q4），具体个数未知。
- C3 频道 1–20 整数，**一源一频道**，且不随时间变化。
- C4 有效接收半径 ∈ [1000, 1500] m，**每源不同且接口不返回**。
- C5 全向源覆盖 360°；定向源覆盖定向方向 ±90°（含边界，共 180° 扇区），定向方向未知。
- C6 覆盖角内场强只随距离衰减，与角度无关（⇒ 测向与"能否收到"只依赖距离与是否在扇区内）。

**观测约束**
- C7 示向度误差 ∈ [−1°, 1°]；**同一地点误差固定**（重复检测不改变），只有换地点才重新抽样。
- C8 `near` 判据：距离 ≤5 m **且**在覆盖角内（⇒ `near` 是"已锁定"的强信息）。
- C9 `no_signal` 三义：无未清除源 / 超接收半径 / 不在定向覆盖角内——**不可区分**。

**动作与成本约束（虚拟时间）**
- C10 移动：5 m/s，按前后两个合法动作位置的直线距离计。
- C11 换频：任意两频道间恒为 **1 s**（与频道差无关）；只由 `/measure` 的 `channel` 触发。
- C12 检测：固定 **5 s**（无论结果）。
- C13 清除：成功 5 s（定位 3 + 清除 2），未发现 3 s；**`/clear` 不切换测向机频道**。
- C14 `near` 时可"直接光学精确定位并清除"（也是 5 s 路径）。

**运行约束**
- C15 程序运行时间：`/enter` 后最长 20 min（用响应 `remaining_real_duration_s` 动态取，范围 0–1200）；与 25 min 窗口取**较早者**。
- C16 虚拟世界上限 360000 s（防死循环）；坐标分量绝对值 ≤ 2×10⁶ m。
- C17 串行：收到完整响应才发下一条，禁止并发；`request_id` 幂等（新动作新 ID，重试才复用）。
- C18 每次正式测试生成加密日志（≤2 MB），导出时**不得改名**，放入支撑材料。

## 二、行业理论与标准

### 2.1 行业背景（本题从哪来）

本题是**无线电频谱管理**中"干扰源查处"任务的自动化改造。真实业务链条为三段：

1. **初步监测**——固定监测站/移动监测车大范围扫描，锁定可疑频段与大致区域；
2. **区域性排查**——多站交会（Angle-of-Arrival 交会定位）或时差定位（TDOA），把目标压缩到一片区域；
3. **精准定位**——技术人员携带**便携式测向机**徒步逼近，靠场强变化与方向读数结合经验找到源，最后清除。

题目把第 3 段（也是唯一仍需人工的一段）交给机器狗，正是"危险环境替代人工"的产业动机。这也解释了题目为何**只给方向信息、不给距离信息**——真实测向机就是只出方位角，距离靠逼近过程中的场强变化间接判断（题目简化为"≤5 m 出现 `near`"）。

**行业惯例与本题的对应**（供论文"背景介绍"段使用，标准依据见第四节 [1]）：

| 行业概念 | 本题对应 |
|---|---|
| 测向体制（幅度比较法/干涉仪/多普勒/时差） | 简化为"最大场强方向"的理想测向机 |
| 示向度（bearing / line of bearing, LOB） | `svd_deg` |
| 交会定位（triangulation / cross-fixing） | 附录 2 定义的"定位区域" |
| 测向精度（RMS bearing error） | ±1° 有界误差 |
| 监测网布站优化 | Q3/Q4 的检测点覆盖设计 |
| 干扰源查处时限 | 平均定位清除时间指标 |

### 2.2 问题复杂度

- **Q1**：多项式时间。楔形求交 → 凸包 `O(n log n)`（Andrew 单调链）→ 直径 `O(m log m)` 或 `O(m²)`（本题 m ≤ 2n，规模极小）。**P 类，可精确求解**。"直径圆能否覆盖"是对**最小包围圆**（Welzl 随机增量，期望 `O(n)`）的一次概念辨析。
- **Q2**：连续域上的**单步次优选择**，本质是"使后续定位不确定度最小的实验设计"。可用定位区域直径（或 CRLB）作目标函数做网格搜索，**不涉及 NP-hard**。
- **Q3/Q4**：形式上属 **POMDP / 部分可观测序贯决策**，一般情形 PSPACE-hard；但本题因为**状态空间极小**（≤20 频道二值状态 + 有限网格）、**动作成本确定**、**时间预算极宽**，退化为可解的**覆盖—搜索—确认**问题。真正的 NP-hard 内核是覆盖网格上的**路径排序（TSP/GTSP 性质）**——但规模仅数十点，启发式（最近邻 + 2-opt / LKH）足够。**结论：不需要证明最优，需要证明完备 + 工程可跑通。**

### 2.3 标准解法（按层拆）

**几何层（Q1/Q2 核心）**
- 定位区域 = 若干 **2° 楔形角域的交集**（凸集之交仍凸）⇒ 凸多边形；
- 顶点 = 各楔形**边界射线两两交点**中"落在所有楔形内"的那些；
- 直径 = 凸多边形顶点对的最大距离（**旋转卡壳** Toussaint 1983）；
- 覆盖辨析：需**最小包围圆**（Welzl 1991），其半径 ≥ D/2，等号仅当区域退化为一条直径段。

**估计层（Q1–Q4 共享）**
- 交会定位的标准估计量是 **Stansfield 加权最小二乘**（按各方位线误差分配权重），其偏差与方差由 **Gavish & Weiss 1992** 给出；两测点情形可用**交会角**近似解析：交会角越接近 90°，不确定度越小。

**搜索层（Q3/Q4 核心）**
- **覆盖设计**：正三角格点，间距 d，任意点到最近格点距离 = d/√3。要求 ≤ 最坏接收半径 1000 m ⇒ **d ≤ 1732 m**。
- **路径**：覆盖路径规划（Galceran & Carreras 2013 综述）中的牛耕式（boustrophedon）/生成树覆盖；格点间排序用 TSP 启发式。
- **定位**：两点交叉定位 → Q1 直径作为不确定度指标 → 逐步逼近。
- **逼近（homing）**：沿示向度走一段 → 重测 → 更新方向，直到 `near` → 原地 `/clear`。
- **停止**：所有频道 ∈ {已清除} ∪ {全格点 `no_signal` 确认空} 才能退出（**完备性论证**，见深度钻研报告 §7.5）。

### 2.4 已知的坑（文献 + 本题特有）

| 类别 | 坑 | 后果 |
|---|---|---|
| 几何 | 把"直径圆"当"最小包围圆" | Q1 结论错（等边三角形反例） |
| 几何 | 保留所有射线交点当顶点 | 多边形错误（须过滤"在所有楔形内"） |
| 几何 | 角度跨 0° 处理错（359° vs 1°） | 楔形方向反了 |
| 估计 | 在**同一点**重复测向取平均 | 误差固定，完全无效（C7） |
| 估计 | 用距离很远的两点做交会 | 交会角太小，误差区域被拉长 |
| 搜索 | 把 `no_signal` 当"频道空" | 漏掉远距离源 / 定向盲区源 |
| 搜索 | 定位后直接 `/clear` | ±1° 下偏差 17–31 m > 20 m 半径，常失败 |
| 搜索 | 无覆盖保证就退出 | 清除率 <100%，硬指标失守 |
| 工程 | 并发发请求 / request_id 乱用 | HTTP 409，动作丢失 |
| 工程 | 用固定 1200 s 当预算 | 超时（须用 `remaining_real_duration_s`） |
| 工程 | 日志 >2 MB / 改了文件名 | 上传失败 / 支撑材料不合规 |

## 三、四问难度递进分析

### Q1 —— 定位区域直径与圆覆盖
- **本质**：凸集（楔形）交的几何刻画 + 凸多边形直径计算 + 圆覆盖辨析。
- **难点**：概念陷阱（直径 vs 最小包围圆）；退化情形（近平行、空集、无界）；角度环绕。
- **预期方法**：射线求交 → 点在楔形内过滤 → 单调链凸包 → 旋转卡壳求直径；反例（等边三角形）+ 最小包围圆（Welzl）给出完整回答。
- **数值实感**（本次实测，见附录 A）：两点相距 600 m、源在 (300,500)，交会角约 61.9° 时，定位区域直径 **≈39.6 m**——约为 20 m 清除半径的 **2 倍**。

### Q2 —— 第二检测点选择与候选区域
- **本质**：单步最优实验设计（minimize 后续定位不确定度）。
- **难点**：源距离未知 ⇒ 必须对 d̂ 做鲁棒处理；附加"必须收得到信号"（≤1000 m 最坏）约束把几何候选区域切掉一块。
- **预期方法**：以 Q1 直径（或交会角）为目标；主推**沿示向度侧向偏移** λ∈[300,800] m 的候选带；源较远时先沿示向度推进再侧移；最坏接收半径按 1000 m 设计。

### Q3 —— 全向源自动搜索定位清除（主战场）
- **本质**：带完备性要求的覆盖—搜索—确认序贯决策 + 工程实现。
- **难点**：① 覆盖完备性 vs 时间成本的权衡；② ±1° 误差下如何保证清除命中；③ 源数未知 ⇒ 停止条件只能靠"全频道确认"。
- **预期方法**：五阶段循环（网格侦察 → 频道发现 → 交叉定位 → homing 逼近 → 收尾确认），蜂窝网格 d ≤ 1732 m；频道状态机管理；斜率式路径优化。**可给出 100% 清除的完备性证明**（Q3 相对 Q4 的最大优势）。

### Q4 —— 全向 + 定向混合
- **本质**：在 Q3 上叠加"存在 180° 盲区"的观测不完备性。
- **难点**：静态网格**存在理论死角**（如源在圆周朝圆外发射，圆内全为盲区）；`no_signal` 三义不可分；数量与朝向双未知。
- **预期方法**：Q3 全部流程 + **多方位确认**（对疑似空频道在多个方位补测）；停止条件从"完备"降级为"概率完备 + 演练实证"；论文主动声明理论死角并给出缓解策略——**坦诚论证比假装完备更容易得高分**。
- **关键理论观察**：定向源**一旦被观测到**，homing 依然收敛（沿示向度逼近时始终留在同一扇区），且**清除与朝向无关**（≤20 m 即可）。所以 Q4 的难点被完全收窄到"**发现**"二字。

|---|---|

**A.3 Q1 交会定位算例（实算）**

设定：检测点 S1=(0,0)、S2=(600,0)，源位于 G=(300,500)（到两站距离均约 583 m），示向度 θ1=58.04°、θ2=119.96°，误差 ±1°。

- 四条边界射线两两求交，得定位四边形四个顶点（顺时针）：
  ≈ (299.9, 480.7)、(311.9, 499.8)、(299.9, 520.1)、(288.3, 500.0)
- 四条边长：22.42、23.76、22.42、23.76 m
- 两条对角线：**23.73 m** 与 **39.61 m**
- **定位区域直径 D ≈ 39.61 m**（对角线取大者）
- 对照清除半径 20 m：**D ≈ 2× 清除半径**，即"两点交会后直接清除"在中等交会角下就已经不可靠——这是必须 homing 的直接证据。
- 本例中区域近似菱形，最小包围圆半径 = D/2 ≈ 19.8 m，恰好覆盖（菱形是"直径圆可覆盖"的特例之一）；一般多边形不成立，反例见等边三角形。
