## 阶段1：核心数据结构与基础函数

**【思路】** Q2 的几何只有一个坐标归约 + 三行关系式。基础函数必须先对，因为**交会角的定义（∠S₁GS₂，源处夹角）**是最容易搞反的地方。

- [ ] `to_local(S1, theta1)` → 返回把 S₁ 移到原点、θ₁ 中线转到 +x 轴的变换参数（旋转角 α = θ₁）
- [ ] `to_world(p_local, S1, alpha)` → 逆变换（**输出必须转回原坐标**）
- [ ] `unit(phi_deg) -> np.array([cos, sin])`
- [ ] `basis(theta1_deg) -> (u, v)`：u 沿示向度中线，v = u(θ₁+90°)
- [ ] `decompose(S2, S1, theta1) -> (a, b)`：`a = (S2−S1)·u`，`b = (S2−S1)·v`

**自检**：
- [ ] 任取 S2，`to_world(to_local(S2)) == S2`（往返恒等，容差 1e-9）

## 阶段2：核心算法（7 个模块）

**【思路】** 顺序：**先解析评估 → 再约束判定 → 再候选区域 → 最后扫描可视化**。扫描只用于验证与出图，**不用来求解**。

### M1 三行关系式（全部推导的起点）
- [ ] `phi_of(a, b, d1) -> phi_deg`
  ```
  Delta = d1 - a;  d2 = hypot(Delta, b)
  cos_phi = Delta / d2 ;  sin_phi = abs(b) / d2
  return atan2(sin_phi, cos_phi) 转度
  ```
  【思路】必须同时用 cos 与 sin 分量算 φ（而非只用 arccos），否则 Δ<0 时 φ<90° 的象限会错。

### M2 位置不确定度评估器 E（**本问的目标函数**）
- [ ] `E(a, b, d1, eps_rad=radians(1)) -> float`
  ```
  d2 = hypot(d1 - a, b)
  sin_phi = abs(b) / d2
  return eps_rad * sqrt(d1**2 + d2**2) / sin_phi
  ```
  【思路】E = ε·√(trace M⁻¹)，即 **RMS 位置误差**（Fisher 信息矩阵之逆的迹）。b=0 时 sinφ=0 ⇒ E=+inf（退化）。

### M3 约束判定（**必须对最坏 Δ 遍历**）
- [ ] `feasible_for_all_delta(a, b, d_lo, d_hi, phi_min, R) -> bool`
  ```
  对 d1 in [d_lo, d_hi]（密集采样或解析取端点）：
      若 d2 = hypot(d1-a, b) > R            → False   （可探测不满足）
      若 sin_phi = abs(b)/d2 < sin(phi_min) → False   （角度质量不满足）
  返回 True
  ```
  【思路】**不许只查 Δ=±Δd 两个端点**——本题 E 与约束关于 Δ² 单调（端点即最坏，可只查端点），但**必须在文档中写明依据**；实现上仍建议区间扫描（≥101 点）作交叉校验。

### M4 候选区域计算（**本问的主输出**）
- [ ] `candidate_region(d_hat, Delta_d, phi_min, R) -> dict`
  ```
  b_min = Delta_d * tan(phi_min)
  b_max = sqrt(R**2 - Delta_d**2)          # 需 R > Delta_d，否则不存在
  feasible = (b_min <= b_max)
  phi_max = degrees(acos(Delta_d / R))     # 可达角度上界
  return {"b_min":..., "b_max":..., "feasible":..., "phi_min_max":..., "a": d_hat}
  ```
  【思路】**不可行情形必须显式检出**（b_min > b_max）并返回可达的 φ_min^max，而不是给出反向区间或除零。

- [ ] `candidate_region_full(d_hat, Delta_d, phi_min, R) -> 曲线参数`
  ```
  a_span = R*cos(phi_min) - Delta_d
  对 |a - d_hat| <= a_span：
      m(a) = abs(a - d_hat) + Delta_d
      b_lo(a) = m(a)*tan(phi_min)
      b_hi(a) = sqrt(R**2 - m(a)**2)
  返回 (a, b_lo, b_hi) 曲线族   —— "双翼形"完整版
  ```

### M5 双准则交叉验证（Fisher 视角）
- [ ] `det_M(a, b, d1) -> float`：`sin²φ / (d1²·d2²)`（σ 略去）
- [ ] `trace_inv_M(a, b, d1) -> float`：`d2²·(d1²+d2²) / b²`
- [ ] **断言**：`E(a,b,d1)**2 == eps_rad**2 * trace_inv_M(a,b,d1)`（恒等式，容差 1e-9）
  【思路】这验证"M2 的 E 就是 A-最优准则"，是本问把 E 从启发式升级为严格量的依据。
- [ ] **断言**：固定 b，`argmin_a E == argmin_a trace_inv_M == argmax_a det_M == d₁`
  【思路】即**准则无关最优性定理**——A-最优、D-最优与 E 三者最优第二点同在 `a = d₁`。扫描验证（网格 a ∈ [d₁−300, d₁+300]）。

### M6 网格扫描与可视化
- [ ] `scan(a_range, b_range, d1)` → E 的二维数组（**b=0 附近设为 inf/NaN 并遮罩**）
- [ ] 叠加约束边界（等角线族 b = m(a)·tanφ_min 与等距圆族 b = √(R²−m(a)²)）⇒ **候选区域图**
- [ ] 标注 `a = d₁` 竖线（最优线）与 `b = 0` 水平线（退化线）

### M7 权衡曲线

- [ ] 扫描 Δd ∈ [0, R)，画 φ_min^max vs Δd 曲线（论文主打图之一）
