## 一、编程语言（选一个主力）

### 1.1 Python（首选，生态最全）

**适用场景**：绝大多数数模题目，数据处理、优化、机器学习、可视化

**优点**：
- 库最全，几乎什么都能做
- 语法简单，写得快
- 免费开源
- 社区活跃，问题搜得到答案

**缺点**：
- 纯Python循环慢（但用NumPy向量化就快了）
- 打包成exe麻烦

**必备基础库**：NumPy、SciPy、Pandas、Matplotlib

---

### 1.2 MATLAB（传统强项）

**适用场景**：矩阵运算、控制系统、信号处理、Simulink仿真

**优点**：
- 矩阵运算原生支持，语法接近数学公式
- 工具箱丰富（优化、统计、信号处理）
- 绘图方便
- 调试器好用

**缺点**：
- 收费（学校一般有授权）
- 启动慢
- 做数据处理和机器学习不如Python方便

---

### 1.3 C++（性能优先）

**适用场景**：超大规模数据、需要极致性能、启发式算法加速

**优点**：
- 运行速度最快
- 可以写复杂数据结构

**缺点**：
- 开发慢，调试难
- 没有现成的科学计算库（要自己写或用第三方）
- 数模比赛一般用不到

---

### 1.4 R（统计分析）

**适用场景**：统计建模、时间序列、生物信息

**优点**：
- 统计方法最全
- 绘图美观（ggplot2）

**缺点**：
- 语法奇怪
- 做优化和算法不如Python

---

### 1.5 Julia（新兴选择）

**适用场景**：想要Python的语法+C的速度

**优点**：
- 速度接近C，语法接近Python
- 科学计算友好

**缺点**：
- 生态还不如Python成熟
- 国内资料少

---

### 语言选择建议

| 情况 | 推荐 |
|------|------|
| 大多数题目 | Python |
| 学校有MATLAB授权，团队都会 | MATLAB |
| 超大规模启发式算法 | C++（核心部分）+ Python（外层） |
| 纯统计类题目 | R |

## 四、优化求解器（核心！）

### 4.1 商业求解器（学术免费）

#### Gurobi（最强推荐）

- 支持LP、MILP、QP、MIQP
- 速度最快，工业界标准
- **学术免费**：用学校邮箱申请license
- Python接口：gurobipy

```python
import gurobipy as gp
m = gp.Model()
x = m.addVar(vtype='B', name='x')
m.setObjective(x, gp.GRB.MAXIMIZE)
m.addConstr(x <= 1)
m.optimize()
```

#### CPLEX（IBM出品）

- 和Gurobi同级，速度接近
- 学术免费
- Python接口：docplex

#### MOSEK

- 锥规划、半定规划强项
- 学术免费

---

### 4.2 开源求解器

#### scipy.optimize（入门首选）

- 不用额外安装，随SciPy自带
- 支持：线性规划（linprog）、非线性规划（minimize）、最小二乘
- 适合中小规模问题

```python
from scipy.optimize import linprog, minimize
# 线性规划
res = linprog(c, A_ub=A, b_ub=b)
# 非线性规划
res = minimize(func, x0, method='SLSQP', constraints=cons)
```

#### PuLP（线性规划专用）

- 语法简洁，专门做LP/MILP
- 自带CBC求解器，也可以接Gurobi/CPLEX

```python
import pulp
prob = pulp.LpProblem('test', pulp.LpMinimize)
x = pulp.LpVariable('x', lowBound=0)
prob += 2*x + 3
prob += x <= 5
prob.solve()
```

#### Pyomo（通用建模框架，强烈推荐）

- 类似AMPL的代数建模语言
- 支持接Gurobi、CPLEX、SCIP、GLPK、IPOPT
- 语法接近数学公式，可读性好

#### CVXPY（凸优化专用）

- 专门做凸优化（LP、QP、SOCP、SDP）
- 自动判断问题类型，选求解器
- 支持ECOS、SCS、OSQP、CPLEX、Gurobi

#### Google OR-Tools

- Google出品，功能全面
- 支持运筹优化、约束规划、车辆路径、调度
- 自带SCIP、CBC、GLPK求解器

#### SCIP（最强开源混合整数求解器）

- 学术免费，非商业使用
- 性能接近商业求解器
- Python接口：PySCIPOpt

#### IPOPT（非线性规划首选开源）

- 大规模非线性规划
- 内点法，速度快
- 需要配合建模框架（Pyomo/CasADi）

---

### 4.3 国产求解器

#### MindOpt（阿里云）

- 支持LP、MILP、QP
- 免费额度，国内访问快
- 适合不想申请国外学术license的情况

---

### 4.4 求解器选择速查

| 问题类型 | 首选 | 备选 |
|---------|------|------|
| 线性规划LP | Gurobi / CPLEX | scipy.linprog / PuLP |
| 整数规划MILP | Gurobi / CPLEX | SCIP / OR-Tools |
| 非线性规划NLP | IPOPT + Pyomo | scipy.minimize |
| 凸优化 | CVXPY + Gurobi | scipy |
| 约束规划 | OR-Tools | - |
| 不想装复杂环境 | scipy.optimize | PuLP |

## 五、启发式 / 智能优化算法库

### 5.1 scikit-opt（入门首选，国产）

- 封装7种算法：差分进化、遗传算法、粒子群、模拟退火、蚁群、鱼群、免疫
- API简单，中文文档
- 适合快速验证

```python
from sko.PSO import PSO
pso = PSO(func=demo_func, n_dim=3, pop=40, max_iter=150)
pso.run()
```

### 5.2 DEAP（进化算法框架）

- 最灵活的进化算法框架
- 支持遗传算法、遗传编程、多目标优化
- 可以自定义每一步操作

### 5.3 PyGAD（遗传算法）

- 专门做遗传算法
- API简单，支持Keras/PyTorch集成

### 5.4 pyswarms（粒子群专用）

- 专门做粒子群优化
- 支持多种PSO变体
- 可视化方便

### 5.5 pymoo（多目标优化）

- 多目标优化最强库
- 支持NSGA-II、NSGA-III、MOEA/D等
- 自带测试问题和性能指标

### 5.6 mealpy（最全启发式库）

- 100+种启发式算法
- 统一API，方便对比

---

### 启发式算法选择

| 需求 | 推荐 |
|------|------|
| 快速上手，中文文档 | scikit-opt |
| 遗传算法深度定制 | DEAP |
| 多目标优化 | pymoo |
| 粒子群 | pyswarms |
| 想对比多种算法 | mealpy |

**重要提醒**：数模比赛中，启发式算法建议**自己手写核心部分**，不要完全调库。这样论文里可以写清楚算法步骤，评阅老师更认可。库可以用来做对比实验。

## 八、环境与包管理

### 8.1 Anaconda / Miniconda（推荐）

- 自带Python和常用科学计算库
- conda可以管理Python版本和非Python依赖
- Miniconda是精简版，只装conda，自己按需装包

**常用命令**：
```bash

conda create -n mathmodel python=3.11
```

- Python内置，不用额外装

- Rust写的包管理器，比pip快10-100倍
- 统一了venv + pip + 锁文件
- 新事物，适合喜欢尝鲜的人

## 十三、编程手工作纪律（来自竞赛复盘）

1. **每步写【思路】注释**：为什么这么写，而不是写了什么
2. **先跑验证题再跑正式数据**：验证题不对，正式结果不可信
3. **不自行改模型假设**：有问题先反馈给建模手
4. **不删除旧代码**：废弃的移到归档，留痕
5. **多次运行取最优**：随机算法至少跑10次
6. **固定随机种子**：保证结果可复现
7. **关键数据写入权威数字表**：和论文手共享
