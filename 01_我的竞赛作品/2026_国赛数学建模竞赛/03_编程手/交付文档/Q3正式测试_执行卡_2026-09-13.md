## 四、失败应对

| 现象 | 处理 |
|---|---|
| `/enter` 失败、连不上 | 接口未开放（倒计时没过完）。程序会按附件2 §12 **用原 request_id 自动重试**至 90 s。等即可 |
| 提示「不足 1200 s」 | 说明 /enter 晚于窗口开始 5 分钟。**照常跑**，程序按剩余时间收尾 |
| 终端出现 MATLAB 报错、程序中止 | **不要**点 /exit 查原因（附件2 §9.3 接口已关）。记下报错原文 + 本局 robot_*.jsonl 文件名，事后分析 |
| 某频道一直清不掉 | 阶段 C 单方位 homing 会兜底。跑完看「已清除 / 下界」那一行 |
| 程序卡住不动 | 等；墙钟预算 1200 s。真卡死就 Ctrl+C，本局作废并如实记录 |
| 想改代码 | **不要**。改了 ⇒ 受测版本 ≠ 交付版本。若必须改，改完**重跑全部自测**再考虑 |

⚠️ **不要**在正式测试期间跑离线自测 / 迷你模拟器：它们会占端口、抢 MATLAB、混写 `logs/`。

## 七、红线（违反即整题不计分）

| 红线 | 出处 |
|---|---|
| 只有 4 条 HTTP 指令；**不得并发**；同一 `request_id` 只能重试**完全相同**的动作 | 附件2 §1.4 / §5.3 / §12 |
| 必须**同时**检查 HTTP 状态码与 `accepted` | 附件2 §5.3 |
| `svd_deg` **只在** `measure_result=="direction"` 时存在 | 附件2 §7.2 / §12 |
| `/clear` **不切换**频道；成功只看距离 ≤ 20 m | 附件2 §1.3 / (8) |
| `no_signal` **不等于**附近无源 | 附件2 §2.2 |
| 测试结束后**不要**调 `/exit` 查原因 | 附件2 §9.3 |
| **禁止看模拟器内部数据**（读案例文件 = 绕过题设且加密日志自动上传，一眼可见） | 附件1 §4.6 |
| **不改模拟器 exe 的逻辑**（只能改端口） | 附件1 §4.4 |
| 支撑材料**隐去真实队号** | 格式规范 |
