## 三、三处调优各自的证据形态（**形态不同，别混着看**）

### 3.1 白测消除 —— **改中位数**

格点扫描循环原先只跳"已清除"的频道，**已定位并排队待清**的频道仍被逐格点重测；
而 `triangulate_source` 只读前两个观测 ⇒ 第 3 个起全代码无人读。

| | 真机表现 |
|---|---|
| 修前（23 局） | 白测 **26.5 次/局** |
| 修后 | **2.4 ~ 7.4 次/局**（残下的是清除失败后合法的重新测量） |
| 离线受控（同 3 种子） | 345.1 → **339.1 s/源（−78 s/局）**，移动**一分未变** |

### 3.2 径向布点 —— **改中位数（最大的一刀）**

检测点从"三角格 d=1000"（中心 + 6@1000 + 6@1732）改为
**径向（中心 + 6@1000 + 6@1300，两环错开 30°）**。两项关键指标**没有变差**：

| | 三角格 | 径向 r_out=1300 |
|---|---|---|
| 1-覆盖半径 | 804.6142 m（余量 195.6） | **811.5994 m（余量 188.4）** |
| 第 2 近邻 max | 1059.3906 m | **1059.3906 m（逐位相同）** |
| 自原点开放巡回 | 12000 m | **8283 m** |

> 原判「12000 m 是 13 点集的 MST 精确下界、2-opt 已到地板、砍不动」**只对均匀三角格成立**；
> 把外环半径收进来即可大幅缩短巡回。**但并非越紧越好**：实测 r_out=1500 → 313.7、
> 1400 → 316.9、1300 → **306.9**（最优）、1100 → 313.6、1000 → 339.6（最差一局 418）。
> 再收紧会让「2-观测缺口」里的源离最近格点变远 ⇒ 阶段 C homing 代价暴涨。

### 3.3 圆域截断修复 —— **只砍尾部，不动中位数**

真机 `084008` 暴露：`clip_to_domain` 原先只把圆外**顶点丢掉**、不做边与圆求交，
细长交会区被削成 2 个顶点的退化"多边形" ⇒ `R_MEC` 假性偏小 ⇒ 清除误派发 sweep。
该局频道 5 打了 **97 次** `/clear`（96 败），整局 6175 s。

| | 修前 | 修后 |
|---|---|---|
| 最大单频道 `/clear`（10 局） | **97**、6 | **3**，其余 ≤ 2 |
| direct 命中 | 94.2% | 84.6%（R_MEC 修真后的预期后果，多走廉价 sweep） |
| 清除总耗时 | 101 s | **64 s** |
| 离线受控（同 3 种子） | 4124.5 / 317.3 | **4124.5 / 317.3（逐位相同）** |

> 离线**逐位相同** ⇒ 这刀对良态几何是严格空操作，**收益只体现在尾部**。

## 六、读法纪律（**踩过的坑，别重犯**）

| # | 纪律 | 为什么 |
|---|---|---|
| 1 | **均摊必须连着源数报**（陷阱 R16） | 均摊随源数强变化。修后 10 局均摊 284~388 的摆幅几乎全部来自源数 10~15 |
| 2 | 跨批对比用**平均虚拟时间或固定项 F** | 二者与源数无关 |
| 3 | 不要把离线数字当实测 | 离线 3 个种子全部 direct clear，**完全没触发 homing / 截断退化** |
| 4 | direct 命中率下降 ≠ 变慢 | 截断修复后 94.2% → 84.6%，但清除总耗时反而从 101 s 降到 64 s |

**固定项估计**（修后 10 局）：`F ≈ 3273 s，SE 77 s`，95% 区间 [3100, 3446]。
⇒ `均摊 = F/n + 51`：**n=13 → 303 s，n=10 → 378 s，320 s 的门槛是 n ≥ 13。**
