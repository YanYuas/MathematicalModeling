## 四、离线测试运行器（免 pytest / 免联网）—— ⚠️ 2026-09-13 起位于 `核验脚本/`

本机**未安装 pytest**（numpy 2.4.6 / requests 2.34.2 已有），而项目规则**禁止从终端下载依赖**。
`Q3/SimulatorClient_v1.3.1` 的 36 项测试对 pytest 的依赖面**只有 `pytest.raises`（7 处）+ `pytest.main`（1 处）**，
无 fixture / mark / parametrize / `unittest.TestCase` ⇒ 可用标准库 shim 跑完：

| 文件（均在 `核验脚本/`） | 用途 |
|---|---|
| `_run_offline_tests_no_pytest.py` | 注入极小 `pytest` shim，发现并运行全部 `Test*::test_*`；逐项打印 `[PASS]/[FAIL]`；**自身以 UTF-8 写报告**（控制台是 cp936，重定向编码不稳）；退出码 **0 通过 / 1 有失败 / 2 环境缺依赖** |
| `一键_跑Python客户端测试.bat` | 一键入口（原 `一键_跑离线测试.bat`）。**纯 ASCII + CRLF + 无 BOM**——刻意不含中文 |
| `_offline_tests_result.txt` | 报告（UTF-8，工具/审阅稳定可读） |

### ⚠️ 两个踩过的坑（已修，勿回退）

| # | 坑 | 后果 | 修法 |
|---|---|---|---|
| 1 | **`.bat` 存成 UTF-8（含中文 `echo`）** | cmd 在 **cp936** 控制台按字节解析批处理，**把 `echo` 行拆断**，把行尾当中文当命令执行（报 `'接跑那' is not recognized...`） | **`.bat` 内容改为纯 ASCII**（不赌代码页）；中文说明移到本 README |
| 2 | 用 **`py -3`** 调解释器 | `py -3` 解析到 **Python 3.13**，该环境**没有** `requests`/`numpy` ⇒ `ModuleNotFoundError` | 钉 **`py -3.11`**（本机 3.11.9 才装有依赖）；运行器另加**环境预检**，缺依赖时退码 **2** 并给干净提示 |
