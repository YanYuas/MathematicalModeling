## 一、动手顺序（顺序错了会取不到数据）

1. **确认模拟器已启动并完成在线登录**（本机 2026-09-13 实测时 `jammers-simulator-full.exe` 在 127.0.0.1:2026）。
2. 在模拟器里**选「问题4演练测试」**（不是问题3）。
3. **先双击 `一键_跑Q4.bat`** → 输队号（必须逐字节等于当前登录队号）→ 案例编码可空 → 局数**回车=1**。
   MATLAB 启动约 **40 s**，程序会打印 `[模拟器] 连接中...` 后开始等接口开放（等 90 s）。
4. **看到等待提示后，再去模拟器点「开始测试」**（5 s 倒计时结束接口才开）。
   —— 顺序反了也能救：程序会在 90 s 内反复重试同一个 `request_id`。

## 二、跑起来后立刻看这 5 行（缺哪行就停）

```
[网格] Q4 检测点集（ring / regular_12gon）：内层 13 点 + 外层 12 点 -> 合计 25 点（圆外 12 点，最远 1900.0 m）
[覆盖自检] Q4 surrounding：采样 20517 点（边界带 4681），失败 0 (全域 0.00%，边界带 0.00%) -> 通过
           第三近邻最大 1000.00 m，对 R_eff=1000 的余量 0.00 m（设计条件：三最近邻都须 ≤ R_eff）
[死角回归] G=(1800,0)、u=(1,0)：可见点 [1900 0]（距 100.0 m，共 1 个）
[探针] 无单观测频道（…）⇒ 无需补测        ← 或：单观测频道 [...] ⇒ 启用扇区探针补测
```

**任一行不符就停下**：① surrounding 失败 >0 → 查环带（陷阱 W1/W2，环带被裁回圆域）；
② 死角回归失败 → 同上；③ 检测点数不是 **25**（ring 档）→ 查 `config.q4_grid_mode` 是否被改成 `lattice`（那会回到 31 点）。

## 三、跑完要抄下来的东西

终端末尾会打印 **表 1 四列**（直接抄进论文）与**指标块**：

| 项 | 口径 |
|---|---|
| 测试案例编码 | 从模拟器界面抄（附件1 §4.6） |
| 清除干扰源个数 | 完备性自判 |
| 平均定位清除时间 | **虚拟时间** ÷ 清除个数 |
| 程序运行时间 | **现实墙钟**（/enter → 结束） |

**Q4 增量指标**（用来回填论文组织方案 §三 的【实测待填】）：

- 检测点数 `N`（预期 **25**）、圆外环带点数（预期 12）、档位 `grid_mode`（预期 `ring`）
- `surrounding` 自检结论（失败数应为 0）与 **第三近邻最大 / 余量**
- 三路清除次数：`direct / sweep / homing / homing 断线转扫掠`
- 扇区探针：补测频道数 / 成功数 / 请求次数
- 请求总数、检测数、清除数、切频数
- `R_MEC` 分布（中位 / p90 / 最大）
- 日志体积（**必须 < 2 MB**，附件1 §4.6）
- `日志/run_summary_Q4_<时间戳>.json` —— 机器可读本局汇总

另外**必须**从模拟器界面导出本局的**加密行为日志**（**不要改文件名**）放进支撑材料。

## 四、与离线基线的对照（判"正常 / 异常"）

离线迷你模拟器（同一份代码、确定性种子）给出：

| 指标 | 离线实测 | 真机偏离过大时怀疑 |
|---|---|---|
| 清除比例 | **100%**（标准/极端/全向三档；标准档 16 种子） | <100% ⇒ 看是哪一路清除失败 |
| 平均定位清除时间 `T̄` | **563.1 s/源**（标准档 16 种子；区间 539~616）｜**真机 7 局实测 521.8** | 差 2× 以上 ⇒ 看移动占比（离线 69%） |
| 程序墙钟 | **≤ 6.2 s/局** | 真机含网络，会高一些 |
| 三路分布 | direct 46 / sweep 146 / homing 2 / 兜底 14（16 局合计） | `homing` 大涨 ⇒ 看 `R_MEC` 分布 |
| 探针触发 | 16 局 10 次（全成功） | 大量触发 ⇒ 半平面内格点不足 |
| 移动距离 | **25.3 km/局**（真机 21~27 km） | 明显偏大 ⇒ 看是不是跑成了 lattice 档（31 点、40 km） |

> ⚠️ **离线数字是虚拟时间、不是真机实测**，两者不可互相顶替。

## 五、Q4 专属红线（承 Q3 全部 + 这六条）

1. ❌ 环带**绝不可**再裁剪回圆域（W1，头号坑）
2. ❌ 环带宽度必须 ≥ `d`（**不是** `d/√3`）
3. ❌ 发现判据必须用 surrounding，不能沿用 1000-覆盖
4. ❌ 末端判据用 `/clear`，**不可等 `near`**（定向源盲侧永不 `near`，会死锁）
5. ❌ 构造 `L` 必须做扇区过滤；不可混淆「定向方向 `u`」与「示向度 `θ`」
6. ❌ 不可并发、同一 `request_id` 只重试**完全相同**的动作；同时检查 HTTP 状态码与 `accepted`

## 七、出问题先看哪里

| 现象 | 大概率原因 | 处置 |
|---|---|---|
| `/enter` 等 90 s 超时 | 没点「开始测试」/ 点晚了 / 队号不对 | 重跑；队号逐字节等于登录队号 |
| 日志体积接近 2 MB | 异常高频循环 | 停下查主循环，别把这份交上去 |
| 某频道一直不清 | 退化配对 ⇒ 交会失败 | 看终端有没有 `[定位] 频道 X 交会失败`；记录该局日志 |
| 报 `请求未被接受 (HTTP 400…)` | 字段/坐标/频道非法 | 报错带标识符与响应体，直接看 |
| 到 17:30 还没跑完 | 截止时间 | 17:30 后**不能启动新的**演练；已开始的可以跑完 |
