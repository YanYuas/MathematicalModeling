## 0. 一句话定位

**Q4 = Q3 + 定向源（有效覆盖 = 定向方向两侧各 90°，即一个过源的半平面）。`no_signal` 由二义升为三义（空频道 / 超接收半径 / 盲区），单点 `no_signal` 从此不再蕴含"无源"。**

**核心结论（本报告最重的一条）**：
> **盲区死角确实存在（裁剪到圆域内的网格不成立）——但题面允许检测点位于目标区域之外（`附件2` §1.1），
> 把检测点集扩到"圆域外扩 `d` 的环带"后，`∀G` 都有三个最近格点包围它，
> 死角被完全消除 ⇒ Q4 仍可实现确定性 100% 清除，无需降级为"概率完备性"。**

**第二结论**：`/clear` 的成功条件只看距离（`附录2(8)` 明确"与有效覆盖角度范围无关"）⇒
**`/clear` 是一个与扇区无关的 20 m 邻近性判定器**。由此得到**扫掠清除**这一新清除模式，它在 `R_MEC ≤ 84.0369 m` 时优于 homing，且**完全不依赖扇区**——正好补上 Q4 最脆弱的环节。

## 2. 约束与条件点透

### 2.1 新增：可测性判据（本问的数学核心）

```
全向源（Q3）：  P 可测 G ⟺ ‖P − G‖ ≤ R_eff
定向源（Q4）：  P 可测 G ⟺ ‖P − G‖ ≤ R_eff  ∧  (P − G)·u ≥ 0
                         └─ 距离条件 ─┘     └─ 扇区条件（半平面）─┘

扇区  H(G,u) = { X : (X − G)·u ≥ 0 }        ← 闭半平面（u 为单位定向方向）
有效可测域   = D(G, R_eff) ∩ H(G,u)          ← 半圆盘，**凸集**
```

**为什么"半平面"这三个字是根**：Q3 靠"角域是凸集"（Q1-F5）把问题接入计算几何；Q4 靠"扇区是半平面"把可测性问题接入**凸集分离定理**。两处是同一手法。

/measure 返回 no_signal 的可能原因（Q4 三种，Q3 两种）：

## 3. 问题本质点透

- **为什么 Q4 是"可测性的升级"而非"新问题"**：把 Q3 的"覆盖 ⇒ 必被发现"换成"包围 ⇒ 对任意朝向必被发现"，
  其余（交会定位、清除判据、homing、双钟、停止条件的形式）**全部保留**。
  ⇒ 正确的解法是"**替换一条前提 + 补两个机制**"，不是重做一套策略。

- **为什么"死角"曾被认为不可解（以及为什么它其实可解）**：
  `深度钻研报告` §8.2 举了反例——源在圆周 (1800,0)、定向方向朝正东（圆外），
  则**圆域内所有点**都满足 `(X−G)·u ≤ 0`（等号仅 X=G），故圆内任何检测点都测不到它。
  **这个反例是对的**——但它成立的前提是"检测点集 ⊂ 圆域"。
  `附件2` §1.1 明说可以提交**圆域外**的位置 ⇒ 把格点扩到圆外一圈，该反例立刻被破解：
  此时 G 的三个最近格点中必有一个 x ≥ 1800（在 G 外侧），它就能看到源。
  ⇒ **死角的来源不是"定向"，而是"把网格裁剪到目标区域"这一未经审视的假设。**

- **为什么"清除"在 Q4 里反而变简单了**：`附录2(8)` 说清除与朝向无关 ⇒
  `/clear` 对定向源和全向源行为完全一致。于是最脆弱的"定向"环节（发现、定位）一旦解决，
  清除环节**不需要任何改动**，并且还多出一个扇区无关的强力工具（扫掠清除）。

- **与 Q3 的关系**：`Q3 ⊆ Q4`（全向源 = 定向方向为空的情形）。
  ⇒ Q4 的策略必须在全向源上**退化为 Q3 的策略**（论文里是很好的正确性自检）。

## 4. 数学结构点透（四层结构）

| 层 | Q3 | Q4 的升级 |
|---|---|---|
| **发现层** | 1000-覆盖：`⋃B(p,1000) ⊇ D` | **surrounding**：`∀G ∈ D, G ∈ conv Q(G)`，`Q(G) = {p ∈ P : ‖p−G‖ ≤ 1000}` |
| **定位层** | ≥2 条异点示向度 | ≥2 条**同扇区**示向度（不足时用**扇区探针**补） |
| **清除层** | 直接（`R_MEC ≤ 20`）/ homing | 直接 / **扫掠** / homing —— 三路，且扫掠**与扇区无关** |
| **成本层** | 移动 + 检测 + 切频 + 清除 | 同 Q3 ＋ **外扩环带的额外移动与扫描** |

### 4.1 发现层：surrounding 条件（Q4 的充要条件）

> **定理 Q4-A（发现性，充要）**
> 检测点集 `P` 保证"任意位置、任意朝向的定向源被至少一个检测点测到" ⟺
> ```
> ∀G ∈ D(0,1800) :  G ∈ conv Q(G),      Q(G) = { p ∈ P : ‖p − G‖ ≤ R_w = 1000 }
> ```

**证明**：记 `v_p = p − G`。目标性质是 `∀u ∈ S¹, ∃p ∈ Q(G) : v_p·u ≥ 0`。
（⇐）若 `G ∈ conv Q(G)`，则 `0 ∈ conv{v_p}`，即 `0 = Σλ_p v_p`（`λ ≥ 0, Σλ = 1`）。
对任意 `u`：`0 = (Σλ_p v_p)·u = Σλ_p (v_p·u)` ⇒ 存在 `p` 使 `v_p·u ≥ 0` ✓。
（⇒）若 `G ∉ conv Q(G)`，则 `0 ∉ conv{v_p}`（有限点集，紧）。由**严格分离定理**，
存在 `u` 与 `ε > 0` 使 `v_p·u ≤ −ε < 0` 对所有 `p ∈ Q(G)` 成立 ⇒ 取该 `u` 为定向方向，
所有检测点都落在盲区 ⇒ 该源永不被测到。∎

**点透**：这个条件比 Q3 的 1000-覆盖**严格更强**——它要求"源被检测点包围"而不是"被覆盖"。
一个点可以被单个圆盘覆盖，但不可能被一个点包围；**至少需要 3 个点（非共线）才能包围**。

### 4.2 死角的存在与消除（本问最关键的一步）

**（a）裁剪网格必然有死角。** 取 `P ⊂ D(0,1800)`。对边界点 `G ∈ ∂D`，
令 `u = G/‖G‖`（朝外法向）。对任意 `p ∈ D`：`(p−G)·u = p·û − 1800 ≤ ‖p‖ − 1800 ≤ 0`，
且等号仅当 `p = G`。故若 `G ∉ P`，则 `∀p ∈ Q(G), (p−G)·u < 0` ⇒ `G ∉ conv Q(G)` ⇒ 该源不可测。
⇒ **`∂D \ P ⊂ B`（死角集非空且稠密于边界）**。`深度钻研` §8.2 的反例正是 `G=(1800,0)`、`u=(1,0)`。

**（b）外扩环带消除死角。** 取

```
P = Lattice ∩ ( D(0,1800) ⊕ B(0, d) )        ← 圆域外扩一个「格距 d」的环带
```

则对任意 `G ∈ D`：其**三个最近格点**（在完整三角格中）到 `G` 的距离 `≤ d/√3`，

（含边界）⇒ `G ∈ conv Q(G)` ✓。

⇒ **结合定理 Q4-A：`∀G ∈ D`、`∀u`，必有一个检测点测得该源。死角被完全消除。**

**（c）边界朝向的退化情形（"含"字救命）**：若 `G` 恰落在两格点的连线上，取该连线的外法向 `u`，
则两格点处 `(p−G)·u = 0`。`附录1(3)` 规定扇区"各 90°（**含**）"⇒ 该方向**计入覆盖** ⇒ 仍可测 ✓。
但若扇区不含边界，则此处**恰好失效**。⇒ **"含边界"三个字是外扩环带方案成立的最后一环。**

### 4.3 清除层：扫掠清除（本问新引入的第三种清除模式）

> **引理 Q4-B（`/clear` 是扇区无关的 20 m 判距器）**
> `/clear` 在点 `c` 对频道 `c` 成功 ⟺ 该频道存在未清除源且 `‖c − G‖ ≤ 20`，**与 `G` 的定向方向无关**。
> 出处：`附录2(8)` 明文"光学精确定位及清除操作是否成功仅与清除点与干扰源之间的距离有关，
> 与干扰源信号有效覆盖角度范围无关"。

> **命题 Q4-C（扫掠清除的完备性）**
> 设 `G ∈ L`（`L` 为 Q1 交会定位区域）。用半径 20 的圆盘覆盖 `L`，中心集 `{c₁,…,c_N}`。
> 则依次在 `c_i` 处 `/clear`，**必有一次成功**，且 `N ≈ ⌈1.2091996·(R_MEC/20)²⌉`。

**证明**：`G ∈ L ⊆ ⋃ᵢ B(cᵢ,20)` ⇒ `∃i : ‖cᵢ − G‖ ≤ 20` ⇒ 该次 `/clear` 成功（引理 Q4-B）。∎
（`N` 的估计用平面圆盘覆盖密度 `2π/(3√3) = 1.2091996`；`L` 的尺度用 `R_MEC` 度量。）

**成本与拐点**：

```
扫掠成本 ≈ N × (3 秒失败 + 移动 ≈ 35 m/5 = 7 秒) ≈ 10·N 秒
homing 成本 ≈ 213.49 秒（与 R_MEC 无关，见 Q3 公式表 §7.4）
拐点：1.2091996·(R/20)²·10 = 213.49  ⇒  R* = 84.0369 m
```

⇒ **清除三路选择规则**：

| 条件 | 模式 | 成本 |
|---|---|---|
| `R_MEC ≤ 20` | **直接清除**（在 `c*` 一次 `/clear`） | 5 s + 移动 |
| `20 < R_MEC ≤ 84.0369` | **扫掠清除**（`N ≈ 1.2092(R/20)²` 个中心） | `≈ 10N` s |
| `R_MEC > 84.0369` | **homing**（收缩逼近到 `near` 或小距离后清除） | `≈ 213.49` s |

> **统筹结论（P1：三路降为"两主一兜底"，见 `Q3Q4统筹-层次沿袭与创新.md` §5.2 命题 U2）**
> 参数域内（`d ≤ 1732.0508`、自然几何 `φ_nat = 120°`）`R_MEC ≤ ε_rad·2000 = 34.9066 m`，
> **恒小于拐点 `84.0369 m`** ⇒ **扫掠恒优于 homing** ⇒ **homing 在自然几何下永不启用**；
> 仅当交会角劣化到 **`φ < 21.0832°`**（"仅 1 条同扇区示向度"、"两点近共线"等退化配对）才可能胜出。
> **⇒ 三条影响**：① homing 篇幅降为"兜底"（但"homing 对盲区免疫"仍要单独说明）；
> ② 实现优先级：**扫掠必做、homing 可后置**（接口要留）；③ 消除"何时切 homing"的实现纠结。

**数值（Q3 网格参数下）**：

| `R_MEC` | 来源 | `N` | 扫掠成本 | 对比 homing |
|---|---|---|---|---|
| 20.1533 m | d=1000，φ=120° | **2** | ≈ 20 s | **10.7× 更省** |
| 30.2300 m | d=1500，φ=120° | **3** | ≈ 30 s | **7.1× 更省** |

**点透**：扫掠清除的**成本只与 `L` 的大小有关，与"源有多难测"无关**——
这正是 Q4 需要的性质：**盲区不影响扫掠**。Q4 因此可以"用扫掠兜住所有几何不利的源"。

### 4.4 定位层：扇区探针（保证 L 有界）

**问题**：定向源只在半平面 `H` 内可见。格点落在 `H` 内的数量约为总数的一半
（三角格中，过半平面内包含 `Q(G)` 的 1~2 个点，`d=1500` 时 `Q(G)` 仅 3 点）。
若只有一个格点在 `H` 内 ⇒ **只有 1 条示向度 ⇒ `L` 是无界楔形 ⇒ 无 `R_MEC` ⇒ 无法清除**。

> **引理 Q4-D（扇区探针）**
> 设 `p` 处测得示向度（⇒ `p ∈ H(G,u)`）。取 `n̂ ⊥ (p − G)`（垂直于视线方向），
> 令 `q_± = p ± b·n̂`（`b > 0` 足够小，使 `‖q_± − G‖ ≤ R_eff`）。则
> ```
> max{ (q₊−G)·u , (q₋−G)·u } = (p−G)·u + b·|n̂·u| ≥ 0
> ```
> ⇒ **`q₊` 与 `q₋` 中至少一个仍在扇区 `H` 内**。

**证明**：`(q_± − G)·u = (p−G)·u ± b(n̂·u)`。两式之和为 `2(p−G)·u ≥ 0` ⇒ 至少一个 ≥ 0。∎

**算法**：在 `p` 处得示向度后，先探 `q₊`；若返回 `no_signal`，改用 `q₋`。
**至多 2 次探测**（每次 5 s + 1~2 s 切换）即可获得第二条同扇区示向度 ⇒ `L` 有界 ✓。

**`Q(G)` 规模与 `d` 的关系**（决定"是否需要探针"）：

| `d` | `Q(G)` 内格点数（`R_eff = 1000` 最坏） | 半平面 `H` 内约 | 是否需要探针 |
|---|---|---|---|
| 1500 | 3（三顶点，距 866） | **1~2** | **常需要**（1 的情形） |
| 1000 | 3（距 577）＋ 6（距 1000）= 9 | **~4~5** | 少需要 |
| 1732.0508 | 3（距 1000，恰在边界） | 1~2 | 需要 |

⇒ **Q4 在定位层强烈倾向较小的 `d`**（更多格点落在同一扇区 ⇒ 更多示向度）。

### 4.5 末端清除：为什么不能等 `near`

`附录2(9)`：`near` 的条件是"距离 ≤ 5 m **且位于干扰源信号有效覆盖角度范围内**"。
⇒ 定向源若从盲侧逼近，**即使贴到 1 m 也不返回 `near`**（返回 `no_signal`）。
⇒ Q3 的"homing 到 `near` 再清除"在 Q4 会**永久卡住**。

**修正**：末端判据换成**与扇区无关的两条**：
1. `R_MEC ≤ 84.0369` ⇒ **扫掠清除**（引理 Q4-B，与朝向完全无关）；
2. `R_MEC > 84.0369` ⇒ homing，但**终止条件不是 `near`，而是"估计距离 `r̂ ≤ 20 − 裕量"后直接尝试 `/clear`**，
   失败则继续走一步；`near` 只作**可选加速**（若恰好返回 `near` 就立即清除）。

## 5. 建模点透（策略：Q3 骨架 + 三处替换）

```
继承 Q3 两阶段巡游（侦察巡游 → 清除巡游），三处替换：

替换 1（发现）  检测点集：圆内裁剪  →  圆域外扩 d 环带（不裁剪）
                发现判据：1000-覆盖  →  surrounding（G ∈ conv Q(G)）

替换 2（定位）  交会示向度：≥2 条异点  →  ≥2 条"同扇区"示向度
                不足时启用【扇区探针】：垂直偏移 ±b，至多 2 次探测

替换 3（清除）  两路（直接/homing）  →  三路（直接/扫掠/homing）
                末端判据：near  →  /clear 结果（near 仅作可选加速）
```

**为什么"替换"而不是"重写"**：Q4 中不变的部分占绝大多数——接口、双钟、目标、覆盖的其它要求、
交会几何（Q1）、homing 收缩（Q3 命题 C.4）、移动下界（Steiner）、频道状态机、停机的**形式**。
只有**一条前提**（发现条件）和**两个机制**（扇区探针、扫掠清除）是新的。
论文里把这个"继承/替换"结构写清楚，比从零叙述更能体现对问题的理解。

### 5.1 为什么 surrounding 需要外扩，而 1000-覆盖不需要

- Q3：源必须被某个检测点的**圆盘**罩住 ⇒ 检测点在圆内即可（圆盘可以出圆）；
- Q4：源必须被检测点**包围** ⇒ 包围 `∂D` 上的点就必须有检测点在圆**外**。
  ⇒ **差别来自"圆盘可出圆，但点不能出圆"**。这是一句很容易被忽略的几何直觉。

### 5.2 为什么扫掠清除对 Q4 是"刚需"而不只是"优化"

Q4 中几何不利的源有两类：
1. **朝向不利**（半平面内的格点少）⇒ 交会几何差 ⇒ `R_MEC` 偏大；
2. **位置靠边界**（外扩环带使格点分布不对称）⇒ 同上。

对这两类，homing 也有风险：homing 依赖**连续的示向度**，而定向源一旦在逼近中滑出扇区，
示向度就断。扫掠清除**不读示向度**、只读 `/clear` 结果 ⇒ 对朝向完全免疫。
⇒ **扫掠清除是 Q4 唯一"对朝向免疫"的清除手段**（除"直接清除"外，而直接清除要求 `R_MEC ≤ 20`）。

### 5.3 成本预算（解析推算，**待实测**）

## 6. 下界与完备性

### 6.1 Q4 的移动下界（下界本身不变，但可达性变差）

移动下界的**证明**（Steiner 公式）只依赖"检测点的 1000-圆盘覆盖圆域"，

⇒ 下界不变、实际值上升 ⇒ **"离下界的倍数"在 Q4 会比 Q3 更大**（诚实汇报）。

### 6.3 完备性定理（Q4 版）

> **定理 Q4-E（Q4 完备性）**
> 设检测点集 `P` 满足 surrounding：`∀G ∈ D(0,1800), G ∈ conv{p ∈ P : ‖p−G‖ ≤ 1000}`。
> 若测试结束时 `∀c ∈ {1..20} : σ(c) = 已清除 ∨ σ(c) = 已确认空`，
> 其中"已确认空"定义为 **`∀p ∈ P, measure(p,c) = no_signal`**，
> 则**目标区域内所有干扰源（含定向源）均已被清除**。

**证明（反证）**：设有源 `G`（频道 `c`、定向方向 `u`、有效接收半径 `R_G ≥ 1000`）未被清除，则 `G ∈ D(0,1800)`。
由 surrounding，`G ∈ conv Q(G)`，`Q(G) = {p ∈ P : ‖p−G‖ ≤ 1000} ⊆ {p : ‖p−G‖ ≤ R_G}`。
由定理 Q4-A 的证明，`∃p ∈ Q(G)` 使 `(p−G)·u ≥ 0` ⇒ `p` 满足可测的**两个条件**（距离 ≤ `R_G`、在扇区内）⇒
`measure(p,c)` 必返回 `direction`（若 `‖p−G‖ > 5`）或 `near`（若 `≤ 5`），**不可能** `no_signal`。
这与"`c` 已确认空"矛盾；又 `c` 未被清除。故 `G` 必已被清除。∎

**推论 Q4-E1**：策略满足上式对全部 20 频道 ⇒ **被清除比例 = 100%**，与 `k`、定向源个数、定向方向**全部无关**。
**推论 Q4-E2（Q3 的自洽退化）**：令全部源的 `u` 取"空"，则 `H` 退化为全平面，
surrounding 退化为 1000-覆盖，定理 Q4-E 退化为 Q3 的定理 C ⇒ **Q4 策略在全向源上退化为 Q3 策略** ✓。

### 6.4 算法正确性与终止性

| 项 | 内容 |
|---|---|
| **输入** | 接口可用；`robot_id`；无其他先验 |
| **输出** | 每频道状态 ∈ {已清除, 已确认空}；`/exit`；日志（含 `virtual_time_s`） |
| **正确性** | 由定理 Q4-E：终止时全部源已清除 ⇒ 比例 100%（**含定向源，无需概率论证**） |
| **终止性** | 每频道状态只向 {已清除, 已确认空} 单调推进；surrounding 保证"若存在源则必在某格点被测到"，故"已确认空"只会被赋予真正为空的频道；homing/扫掠均在有限步内给出 `success` 或"`R_MEC` 降到 ≤ 84.0369 转扫掠"；⇒ 有限步终止 |

## ⚠️ 更正（2026-09-12，建模手实测）：外扩环带的宽度与设计条件

**原文档的外扩宽度 `d/√3` 是错的**（那是「最近邻」的覆盖半径，而 surrounding 需要「三最近格点」，第三近邻可达 `d`）：

| 外扩宽度 | 全域 surrounding 失败率 | 边界带 `‖G‖∈[1750,1800]` |
|---|---|---|
| `R + d/√3`（**原值**） | 2.47% | **42.05%** ❌ |
| **`R + d`**（**更正**） | **0.00%** ✅ | **0.00%** ✅ |

**设计条件（新）**：**`d ≤ R_eff`（=1000 m）且外扩宽度 ≥ `d`**。
实测阈值：`d ≤ 1000` → 0%；1050 → 1.77%；1200 → 35.5%；1500 → 91.4%；1732.05 → 100%。
⇒ **`d = 1000` 卡在阈值上**，建议 **`d ≤ 950`** 留余量。

**连带影响**：① Q4 **必须** `d ≤ 1000`（surrounding 的成立条件，不只是"更省"）；
② 代码 `Q4_extensions.generate_extended_grid` 已改（外扩 `d`）+ 新增 `check_surrounding_all` 自检；
