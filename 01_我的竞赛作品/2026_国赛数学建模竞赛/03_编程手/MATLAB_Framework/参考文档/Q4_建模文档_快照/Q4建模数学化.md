## B. 论文引理草稿（"模型建立"节素材）

### L1 扇区-半平面引理
> `\|∠((X−G), u)\| ≤ 90° ⟺ (X−G)·u ≥ 0`。故定向源的有效覆盖扇区 = **过 `G`、以 `u` 为外法向的闭半平面** `H(G,u)`；
> 有效可测域 `M(G) = D(G,R_eff) ∩ H(G,u)` 是**半圆盘**，即**凸集**。

### L2 死角引理（说明为什么"圆内网格"不行）
> 设 `P ⊂ D(0,1800)` 且 `G ∈ ∂D(0,1800) \ P`。取 `u = G/‖G‖`（朝外法向），则
> `∀p ∈ D: (p−G)·u = p·û − 1800 ≤ 0`，**等号仅当 `p = G`**。⇒ `∀p ∈ Q(G), (p−G)·u < 0` ⇒ `G ∉ conv Q(G)`。
> **推论**：`∂D \ P ⊂ B`（死角集）——**裁剪到圆域的检测点集必然存在死角**。

### L3 surrounding 充要引理（Q4 的发现条件）
> `∀u ∈ S¹, ∃p ∈ Q(G): (p−G)·u ≥ 0 ⟺ G ∈ conv Q(G)`。
> **推论**：保证发现 ⟺ 源被检测点**包围**（而非被覆盖）。至少需 3 个非共线检测点。

### L4 外扩环带引理（死角的消除）

> #### 🚨 2026-09-12 更正（建模手实测）：原 L4 的**外扩宽度用错了量**
>
> 原证明写「三个最近格点到 `G` 的距离 `≤ d/√3`」—— **`d/√3` 是「最近邻」的覆盖半径，不是「第三近邻」的界**。
> 实测（d=1000，三角格）：**最近邻最大 574.56 m（= `d/√3`）；第三近邻最大 997.77 m（= `d`）**。
> 故按 `d/√3` 外扩时，边界源的三最近格点会有部分落在环带之外 ⇒ 实测**全域失败 2.47%、边界带 42.05%**。
>
> #### L4′（更正版）
> 取 `P = Lattice ∩ D(0, R_domain + d)`（**外扩宽度 = `d`**，非 `d/√3`）。则 `∀G ∈ D(0,1800)`：
> 其三最近格点均在 `P` 内、且距 `G ≤ d`；由「`G ∈ conv{三最近格点}`」（实测 4000 点失败 0）得 `G ∈ conv Q(G)`。
> **所需条件**：三最近邻都须落在 `Q(G) = {p : ‖p−G‖ ≤ R_eff}` 内 ⇒ **`d ≤ R_eff`（=1000 m）**
> （比原来的 `d ≤ 1732.0508` **严格得多**）。
>
> **实测阈值**：`d ≤ 1000` → surrounding 失败 **0.00%**；1050 → 1.77%；1100 → 7.43%；
> 1200 → 35.5%；1500 → **91.4%**；1732.05 → **100%**。
> ⇒ **`d = 1000` 恰好卡在阈值上（余量 0），建议 `d ≤ 950`**；且 Q4 **必须**用 `d ≤ 1000`。
>
> #### ~~原文（已作废）~~
> ```
> 取 P = Lattice ∩ (D(0,1800) ⊕ B(0, d))。则 ∀G ∈ D(0,1800)，其在完整三角格中的三个最近格点
> 到 G 的距离 ≤ d/√3，故它们到 D 的距离也 ≤ d/√3 ⇒ 全在 P 内；且 G ∈ conv{三点}（含边界）。
> ⇒ G ∈ conv Q(G) ✓。所需条件 d/√3 ≤ 1000 ⟺ d ≤ 1732.0508 m（与 Q3 覆盖约束相同）。
> ```

### L5 `/clear` 判距器引理（扇区无关）
> `/clear` 在 `c` 处成功 ⟺ 该频道存在未清除源且 `‖c−G‖ ≤ 20`，**与 `u` 无关**（`附录2(8)`）。

## C. 核心命题的完整证明

### C.1 命题 Q4-A：surrounding 条件的充要性

**陈述**：`P` 保证"任意位置、任意朝向的定向源被至少一个检测点测到" ⟺ `∀G ∈ D, G ∈ conv Q(G)`。

**证明**：记 `v_p = p − G`（`p ∈ Q(G)`）。
（⇐）若 `G ∈ conv Q(G)`，则 `∃{λ_p ≥ 0, Σλ_p = 1}` 使 `Σ_p λ_p p = G`，
故 `Σ_p λ_p v_p = Σ_p λ_p (p − G) = 0`，即 `0 ∈ conv{v_p}`。对任意 `u ∈ S¹`：
`0 = (Σ_p λ_p v_p)·u = Σ_p λ_p (v_p·u)`。由于 `λ_p ≥ 0` 且不全为 0，
上式为零意味着**至少一个 `v_p·u ≥ 0`**（否则全部 `< 0` 将使其严格为负）。
取该 `p`：`‖p−G‖ ≤ 1000 ≤ R_G` 且 `(p−G)·u ≥ 0` ⇒ 由 Q4-F1，`p` 可测该源 ✓。

（⇒）设 `G ∉ conv Q(G)`。`{v_p}` 是有限点集，`conv{v_p}` 是紧凸集。由 `0 ∉ conv{v_p}` 与
**严格分离定理**，`∃u ∈ S¹, ε > 0` 使 `v_p·u ≤ −ε < 0`（`∀p ∈ Q(G)`）。
取该 `u` 为定向方向，则所有邻域检测点都落在盲区 ⇒ 该源**永不**被测到，与"保证发现"矛盾。∎

**注（闭性）**：`G ∈ ∂conv Q(G)` 时，`∃p` 使 `v_p·u = 0`，因扇区"各 90°（**含**）"仍计入覆盖 ✓。
若扇区不含边界，则需 `G ∈ int conv Q(G)`——这正是 `附录1(3)` 那个"含"字的作用。

### C.2 命题 Q4-B：`/clear` 是扇区无关的 20 m 判距器

**陈述**：`/clear` 在 `c` 处成功 ⟺ 该频道存在未清除源 `G` 且 `‖c−G‖ ≤ 20`，**与 `u` 无关**。

**证明**：直接引 `附录2(8)`："光学精确定位及清除操作是否成功**仅与清除点与干扰源之间的距离有关**，
与干扰源信号有效覆盖角度范围无关"；并 `附录2` §8.2 列出成功条件为"距离 ≤ 20 米"。
⇒ 与 `u` 无关。∎

### C.3 命题 Q4-C：扫掠清除的完备性

**陈述**：设 `G ∈ L`，`{c₁..c_N}` ⊇ 覆盖 `L` 的 20-半径盘中心集。则 `∃i` 使第 `i` 次 `/clear` 成功。

**证明**：`G ∈ L ⊆ ⋃ᵢ B(cᵢ,20)` ⇒ `∃i : ‖cᵢ − G‖ ≤ 20` ⇒ 由命题 Q4-B，第 `i` 次成功 ✓。
（前面的 `i−1` 次可能失败，各耗 3 s；第 `i` 次耗 5 s。）∎

**`N` 的估计**：`L` 的尺度由 `R_MEC`（最小包围圆半径）度量，`N ≈ ⌈1.2091996·(R_MEC/20)²⌉`
（用平面圆盘覆盖最优密度 `2π/(3√3)`，承 Q3 命题 C.1）。

### C.4 命题 Q4-D：扇区探针引理

**陈述**：`p ∈ H(G,u)` ⇒ `q_± = p ± b n̂` 中至少一个属于 `H(G,u)`（`n̂ ⊥ (p−G)`）。

**证明**：`(q_± − G)·u = (p − G)·u ± b(n̂·u)`。两式相加 = `2(p−G)·u ≥ 0`（因 `p ∈ H`）⇒ 至少一个 `≥ 0` ✓。
更强：`max = (p−G)·u + b|n̂·u| ≥ 0`。∎

**注**：`n̂ ⊥ (p−G)` 是为保证探针点与源的**距离**基本不变（`‖q_±−G‖ = √(r² + b²)`），
从而探针点仍在 `R_eff` 内（取 `b` 足够小）。

### C.5 命题 Q4-E：Q4 完备性定理

**陈述**：若 `P` 满足 `∀G ∈ D(0,1800) : G ∈ conv{p ∈ P : ‖p−G‖ ≤ 1000}`，
且测试结束时 `∀c ∈ {1..20} : σ(c) = 已清除 ∨ σ(c) = 已确认空`（后者定义为全 `P` 上 `no_signal`），
则目标区域内**所有干扰源（含定向源）均已被清除**。

**证明（反证）**：设有源 `G`（频道 `c`、定向方向 `u`、接收半径 `R_G ≥ 1000`）未被清除，`G ∈ D(0,1800)`。
由 surrounding，`G ∈ conv Q(G)`，其中 `Q(G) = {p : ‖p−G‖ ≤ 1000} ⊆ {p : ‖p−G‖ ≤ R_G}`。
由命题 Q4-A 的（⇐）方向，`∃p ∈ Q(G)` 使 `(p−G)·u ≥ 0`。
该 `p` 同时满足：距离 `‖p−G‖ ≤ 1000 ≤ R_G` ✓，扇区 `(p−G)·u ≥ 0` ✓ ⇒ 由 Q4-F1 `p` 可测该源。
于是 `measure(p,c)` 返回 `direction`（若 `‖p−G‖ > 5`）或 `near`（若 `≤ 5`），**不可能** `no_signal`。
这与 "`c` 已确认空" 矛盾；又 `c` 未被清除，故 (a) 不成立。矛盾 ⇒ 假设不成立 ⇒ `G` 已被清除。∎

**推论 Q4-E1**：满足上式对全部 20 频道 ⇒ **被清除比例 = 100%**，与 `k`、定向源个数、定向方向**全部无关**。
**推论 Q4-E2（`Q3 ⊆ Q4`）**：令全部 `u_i = ∅`，则 `H` 退化为全平面，`conv Q(G)` 条件退化为 1000-覆盖，
命题 Q4-E 退化为 Q3 的定理 C ⇒ **Q4 策略在全向源上退化为 Q3 策略**（免费的正确性自检）。

### C.6 命题 Q4-F：死角的存在（说明 Q3 网格不能直接用）

**陈述**：若 `P ⊂ D(0,1800)`，则 `∃G ∈ D(0,1800)` 与 `u ∈ S¹`，使 `∀p ∈ Q(G), (p−G)·u < 0`。

**证明**：取 `G ∈ ∂D \ P`（这样的 `G` 存在，因为 `∂D` 不可数而 `P` 可数），`u = G/‖G‖`。
`∀p ∈ D`：`(p−G)·u = p·û − ‖G‖ ≤ ‖p‖ − 1800 ≤ 0`，且等号要求 `p = ‖p‖û` 且 `‖p‖ = 1800`，即 `p = G`。
`G ∉ P` 故 `∀p ∈ Q(G) ⊆ P` 都有 `(p−G)·u < 0` ✓。∎

**推论 Q4-F1**：`深度钻研报告` §8.2 的反例（`G=(1800,0)`、`u=(1,0)`）是此命题的特例，
**且是全类中最典型的一个**（边界 + 朝外）。
**推论 Q4-F2**：该死角**仅由"裁剪"造成**；由引理 L4，外扩环带后不再存在此类 `G`。
⇒ **Q4 的死角是伪影（artifact），不是问题本身的性质。**

### C.7 复杂度（与 Q3 同量级）

surrounding 条件的验证：对 `D(0,1800)` 采样并在每点做一次"点是否在凸包内"判定，`O(N_sample · |Q| log|Q|)`。
策略的 NP-hard 性承 Q3 命题 C.7（覆盖巡游 + TSP + 集合覆盖），Q4 只把覆盖条件收紧 ⇒ **仍为 NP-hard**，
且实例规模仍小（`N ≤ 27`、`k ≤ 16`、`20` 频道）⇒ 同样走"精确子程序 + 完备性证明 + 在线启发式"。
