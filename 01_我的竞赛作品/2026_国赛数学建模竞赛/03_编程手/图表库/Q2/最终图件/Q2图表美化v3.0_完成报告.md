### 1. 🔴 P0-0: Unicode下标缺字修复（最高优先级）

**原问题**: 
- A套: `² ̂ ₁ ₂ ⇒ − ⟺` (7个字符) 显示为方框
- B套: `₁ ₂ ⟹` (3个字符) 显示为方框

**根本原因**: 
```python
# ❌ 错误写法（只取首字体，不构成字形回退链）
plt.rcParams["font.sans-serif"] = ["SimHei", "Microsoft YaHei", "DejaVu Sans"]
```

**解决方案**: 
```python
# ✅ 正确写法（构成逐字回退链）
plt.rcParams["font.family"] = ["Microsoft YaHei", "SimHei", "DejaVu Sans", "Arial"]
```

**效果**: 
- Microsoft YaHei有₁₂字形 → 下标正常显示
- 如YaHei没有，回退到DejaVu Sans → 继续寻找
- **所有8张图通过缺字检测，无告警**

### 7. 🛡️ 程序化缺字检测

**实现**: 自动捕获matplotlib的Glyph missing告警

```python
with warnings.catch_warnings(record=True) as w:
    warnings.simplefilter("always")
    fig.savefig(...)
    
    glyph_warnings = [x for x in w if 'Glyph' in str(x.message)]
    if glyph_warnings:
        raise AssertionError(f"[ERROR] {name} has missing glyphs!")
```

**效果**: 
- ✅ 自动检测，无需人工核对
- ✅ 所有8张图通过检测

### 2. U+0302组合音标符告警

**影响**: 极低（不影响论文，显示无异常）

**可选修复**: 
```python
# 如需彻底消除告警，改用mathtext
```
