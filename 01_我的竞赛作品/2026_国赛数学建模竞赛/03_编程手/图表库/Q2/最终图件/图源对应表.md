### ⚠️ 交付缺陷：脚本的相对路径**与交付布局不符**（入库时**未改动**）

两个脚本都写了 `OUT = ROOT / "图集_v1"`，而 `ROOT = Path(__file__).resolve().parent` = **`源码/`**
⇒ 它们会往 **`源码/图集_v1/`** 写，而交付的图在 **包根 `图集_v1/`**。
`generate_f1_f3_direct.py` 还写了 `CSV = ROOT.parent / "data" / ...`
⇒ 找的是包根 **`data/`**，而交付目录叫 **`数据/`**。

**⇒ 按现状直接跑会 `FileNotFoundError`。** 要让它们跑起来，最小改法是各改 2 行：

```python
# 源码/generate_f1_f3_direct.py
OUT = ROOT.parent / "图集_v1"                                    # 原: ROOT / "图集_v1"
CSV = ROOT.parent / "数据" / "r1_r2_boundary_contract.csv"        # 原: ROOT.parent / "data" / ...

# 源码/generate_f4_direct.py
OUT = ROOT.parent / "图集_v1"                                    # 原: ROOT / "图集_v1"
```

> 有意思的是，`优化方案代码/generate_f2_enhanced_v1.py`（嵌两层）用的
> `ROOT.parent.parent / '数据'` **反而是对的** ⇒ 三个脚本的路径口径没统一。
> **本次入库不改代码**（保持交付原样）；要复现就按上面 2 行改，改完自行记录。

另：`generate_f4_direct.py` 还会写 `ROOT/f4_search_hierarchy.csv` 与 `ROOT/f4_manifest.json`

## 五、「共同区间为空」的物理含义（**写论文时的口径**）

- **名义工况**（α=0）：b ∈ **[627.23, 664.26] m** —— 有解
- **鲁棒工况**（∀α∈[−1°,1°]）：距离约束要 **b ≤ 638.34**，角度约束要 **b ≥ 649.88**
- ⇒ **共同区间为空，缺口 11.54 m**。最严的两端分别出现在 **α=−1°（距离最严）** 与 **α=+1°（角度最严）**
- **可保证的交会角上限 = 39.6161°**（**名义上界 40°**）；四层搜索里 **≥40° 的候选点数 = 0**

> ⚠️ **别把 39.6161 写成"我们做到了 40°"**。权威数字表 §四 的判定是
> **「几何与闭式解 ✅ 通过；鲁棒保证 ❌ 不通过」**，本图集画的正是**不通过的那一面**。
