## 二、数据结构适配修复

### 问题1：凸包返回类型
**错误**：`'list' object has no attribute 'vertices'`  
**根因**：误认为`convex_hull()`返回list，实际返回`Polygon`对象  
**修复**：
```python
poly = convex_hull(vertices)  # 返回Polygon对象
verts = poly.vertices  # 提取list[np.ndarray]
```

### 问题2：函数返回值解包
**错误**：`not enough values to unpack (expected 3, got 2)`  
**根因**：
- `diameter_bruteforce(poly)` 返回 `(distance, (pt_a, pt_b))`（2个值）
- `mec_bruteforce(verts)` 返回 `(center, radius)`（2个值）

**修复**：
```python
# 旧：diam_val, pt_a, pt_b = diameter_bruteforce(poly)
# 新：
diam_result = diameter_bruteforce(poly)
diam_val = diam_result[0]
pt_a, pt_b = diam_result[1]

# 旧：mec_val, center, radius = mec_bruteforce(verts)
# 新：
center, radius = mec_bruteforce(verts)
```

### 问题3：数据字段名称
**错误**：`'monte_carlo'`、`'param_scans'`、`'d'` 不存在  
**修复**：
```python
# 数据结构实际为：
# - gamma_mc['n2']['gammas']（非'gamma_samples'）
# - scan_n, scan_grid（非'param_scans'）
# - scan_grid[i]['eps']（非'd'，是角度误差）

gamma_samples = []
for key in data['gamma_mc'].keys():
    gamma_samples.extend(data['gamma_mc'][key]['gammas'])

n_values = [item['n'] for item in data['scan_n']]
eps_vals = sorted(set(item['eps'] for item in data['scan_grid']))
```
