### ⚠️ 关键问题（6个维度）

#### 🗂️ **问题1：目录结构不一致**
**严重程度：中**

| 层级 | 索引文档描述 | 代码实际输出 | 现有实际目录 |
|------|------------|------------|------------|
| 输出根目录 | `02_几何示意/` | `01_生图代码/figs/01_论文用_美化版/A_几何示意/` | `02_几何示意/` |
| 分类 | `02/03/04/05/` | `A/B/C/D/` | `02/03/04/05/` |

**影响**：
- 运行 `q1_figures_beautified.py` 会在 `01_生图代码/figs/` 创建新目录
- 现有的 `02_几何示意/` 等目录不会被更新
- 可能导致版本混乱、文件冗余

#### 🔧 **问题2：缺少自动化工具**
**严重程度：高**

- ❌ 无批量生成脚本（需手动编辑py文件选择要生成的图）
- ❌ 无图片质量检查（分辨率、文件大小、SVG有效性）
- ❌ 无自动化测试（验证12个函数是否都能正常运行）
- ❌ 无环境依赖管理（requirements.txt 缺失）

#### 📦 **问题3：Python环境未标准化**
**严重程度：中**

```python
# q1_figures_beautified.py 导入依赖
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.patches as mpatches
# ... 但缺少 requirements.txt
```

**缺失文件**：
- `requirements.txt` - pip依赖清单
- `environment.yml` - conda环境配置（可选）
- `README_环境配置.md` - 环境搭建指南

#### 🧪 **问题4：代码可维护性待提升**
**严重程度：低**

1. **硬编码文件名判断**（第97-100行）：
```python
if name.startswith('fig5_1_6') or name.startswith('fig5_1_8') or ...
```
应改为配置驱动或映射表

2. **全局变量使用**：
```python
SCAN_DATA = None  # 全局缓存
```
应封装为类或单例模式

3. **缺少类型注解**：
```python
def save_fig(fig, name, use_tight=True):  # 参数类型不明确
```

4. **魔法数字多**：
```python
LW = {'main': 2.4, 'theory': 1.6, 'aux': 0.8}
DPI = 300
```
应集中到配置文件

#### 📝 **问题5：文档-代码不同步**
**严重程度：中**

| 文档声明 | 实际情况 |
|---------|---------|
| "图表总数：12张论文用图" | 索引中列出15张（包含3张旧版/变体） |
| "按分类保存到对应子目录（02_几何示意/等）" | 实际输出到 `figs/01_论文用_美化版/A_*/` |
| "运行方式：python q1_figures_beautified.py" | 需手动修改 `if __name__ == '__main__'` 部分 |

#### 🔍 **问题6：缺少验证机制**
**严重程度：高**

- ❌ 无图片生成后的自动校验（文件是否存在、大小是否合理）
- ❌ 无数据完整性检查（scan_results.json格式验证）
- ❌ 无视觉回归测试（图片diff对比）
- ❌ 无性能基准（生成12张图耗时、内存占用）

    """生成所有图表并返回统计信息"""
    results = {'success': [], 'failed': []}
    total_time = 0
    
    for fig_id, info in FIGURE_REGISTRY.items():
        if verbose:
            print(f"[{fig_id}] 生成 {info['name']}...", end=' ')
        
        start = time.time()
        try:
            info['func']()
            elapsed = time.time() - start
            total_time += elapsed
            results['success'].append((fig_id, info['name'], elapsed))
            if verbose:
                print(f"✓ ({elapsed:.2f}s)")
        except Exception as e:
            results['failed'].append((fig_id, info['name'], str(e)))
            if verbose:
                print(f"✗ {e}")
    
    return results, total_time
