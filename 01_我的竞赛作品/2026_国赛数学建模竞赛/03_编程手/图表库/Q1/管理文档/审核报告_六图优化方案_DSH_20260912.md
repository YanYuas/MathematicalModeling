## 零、本次审核实际做了什么（方法透明）

送审词要求"打开图亲手确认"。本节点无法直接看图，因此**不靠肉眼**，改用四条可复核的证据链，并让其中两条互相验证：

| 链路 | 方法 | 覆盖 |
|------|------|------|
| A. 矢量源码取证 | 解析 5 张图的 `.svg`（matplotlib 输出），提取全部 `<text>` 内容、`font-size`、`font-family` | 文本内容、字号、字体（**不依赖渲染**） |

## 二、对《送审提示词》本身的审核（用户直接要求的产出）

### 2.1 🔴 硬错误：γ 的定义写反了（倒数）

送审词 §一 第 27 行：

> 核心结论是缺口比 `γ = D/(2·R_MEC) ≤ 1.01`

**项目内权威定义恰恰相反**，且方向也相反：

| 来源 | 原文 | 定义 |
|------|------|------|
| `02_建模手/Q1/Q1公式表.md:52` | `γ = R_MEC / (D/2) ∈ [1, 2/√3 ≈ 1.1547]` | ✅ 权威 |
| `02_建模手/Q1/Q1建模数学化.md:248` | `覆盖缺口比 γ = R_MEC / (D/2) ∈ [1, 2/√3 ≈ 1.1547]` | ✅ |
| `04_论文手/Q1/正稿.md:555` | `定义覆盖缺口比 γ = R_MEC/(D/2) ∈ [1, 2/√3 ≈ 1.1547]` | ✅ |
| `04_论文手/Q1/正稿.md:367` | `γ | 27 个扫描算例 + 8000 例蒙特卡洛 | γ ∈ [1.000000, 1.001401]` | ✅ |
| `实验结果/q1_main.py:800` / `q1_scan.py:52` | `gamma = R_MEC / (D / 2)` | ✅ 代码 |
| **`送审提示词:27`** | **`γ = D/(2·R_MEC) ≤ 1.01`** | ❌ **倒数，且阈值方向反** |

两种定义在 γ=1 处重合，所以一直没被发现。**正确表述**：γ ∈ [1, 2/√3]，本题实测上界 **γ ≤ 1.0014**（不是 1.01）；"γ≤1.01" 是**图上用的宽松参考阈值**，不是理论结论。

**风险外溢**：`01_生图代码/q1_figures_beautified_v2.py:475` 写的是 `缺口比 $\gamma = D/R_{MEC}$`（错的），而 `q1_figures_beautified.py:1166` 写的是 `\gamma = R_{MEC}/(D/2)`（对的）。`P0-P8修复报告.md:31` 把错误定义当作"已修复项"记录在案。**方案下一步要新写的 `q1_figures_*.py v2.0` 若以 v2 脚本为基线，会把错误定义带进新图，与图5.1-7 v1.3 直接冲突。**

→ **建议**：送审词 §一 第 27 行改为 `γ = R_MEC/(D/2) ∈ [1, 2/√3]，本题实测 γ ≤ 1.0014`；并在 v2.0 公共层把 γ 的字符串常量统一（唯一来源）。

### 2.2 🟡 引导性暗示一：§维度4 把方案的自述当既成事实

## 五、数据完整性问题

### 5.1 热力图"插值造假"——**判断不成立，但方案问对了方向**

送审词 §维度3 问：这个"插值造假"的判断是否成立？插值是否本来就是常规做法？界限在哪里？

**答案：不成立。** 理由是 `scan_grid` 的结构：

```
n_phi = 9   φ ∈ {30,45,60,75,90,105,120,135,150}
n_eps = 6   ε ∈ {0.5,0.75,1.0,1.25,1.5,2.0}
点数 = 54 = 9×6  满格 = True          ← 完整规则张量网格，无缺角、无孔洞
```

对**完整的规则网格**做 `bilinear` 插值渲染，是科学可视化的标准做法（任何 CFD/FEM 后处理都这么做），与"用插值冒充实测"不是一回事。界限在于三点：

1. **数据是否规则采样**：是（9×6 满格）→ 合规。
2. **图注是否披露分辨率**：现图 suptitle 写"（真实扫描数据）"，**没有披露这是 9×6 网格** → 这才是真实缺陷。
3. **渲染是否暗示了数据不具备的分辨率**：视觉桥确认"色阶过渡细腻、无明显方格边界" → **确实暗示了更高分辨率**。这是视觉诚实问题，不是造假。

**更好的解法（方案给的三选一之外）**：D(φ,ε) 在本问题里**有解析闭式**（我已独立导出并验证，见 §九.2）：

```
对称双站构型下，定位区域是平行四边形，顶点由 4 条边界射线两两相交给出：
   θ₁ = 90° − φ/2,  θ₂ = 180° − θ₁
   a = tan(θ₁+ε),  b = tan(θ₁−ε)
   竖弦 V  = (L/2)·(a−b)                     ← 何时为直径见下
   横弦 Hh = L·(a−b)/(a+b) = L·sin2ε/sinφ
   边长 S  = L(a−b)√(1+a²) / (2(a+b))
   D = max(V, Hh, S)      （V > Hh ⟺ a+b > 2 ⟺ φ < 90°，即在 d < L/2 侧 V 胜）
```

**因此正确做法是**：把它作为**模型解析曲面**在细网格上求值绘制（明示"模型曲面"），再把 **54 个实测采样点以标记叠加**做校验。这既诚实、又高分辨率、还顺带证明了闭式与实测一致——**比方案的三选一（bilinear / 留白 pcolormesh / 气泡散点）严格更优**。方案把问题框成"好看 vs 诚实"的假二分，是因为它没意识到被插值的对象是解析函数而不是经验数据。

### 9.2 图5.1-11(c) 理论式偏离的归因 → **不是"适用域问题"，是"画错了物理量 + 画错了半区"。送审词给出的假设方向相反。**

**读码**（`q1_figures_beautified.py:1566-1572`）：

   我原稿用的 `L·ε·csc²(φ/2)` 在一阶意义下等价，但系统性偏低：**φ=20° 时 −0.990%**（350.7592 → 347.2867），基线处 −0.0948%，φ=90° 处 −0.0406%。复核用精确式逐点比对：φ=80/60/40/20 时它**与实测 D 完全相等**（25.3586 / 41.9305 / 89.7365 / 350.7592），而这四处正是竖弦为直径的区间——**这同时反证了整条"竖弦 vs 横弦"结构**。
2. **交叉点是 90.0349°，不是 90°**。二分法与闭式 `135° − arcsin(cos2ε/√2)` 一致给出 **φ* = 90.0348924184°**；在 φ=90° 处竖弦反而比横弦**大 0.0127637 m（+0.0610%）**。故 §9.2 中"φ ≥ 90° 段完全吻合"应读作 **φ ≥ 90.0349°**。
3. **图中曲线还额外偏高 0.0203%**：代码写的是 `2·ε_rad = 0.03490658503988659`，而 `sin(2ε) = 0.03489949670250097`——用 2ε 代替 sin2ε，使"理论式"整条曲线**恒偏高 0.0203%**。这是一处独立的小瑕疵，方案与送审词都未提及。
4. **新增边界**：该恒等式**在 φ > 178° 处整体失效**。φ 超过 180°−2ε 后两站的跨站交点已落到射线之外（φ=179° 时 x_cross = 899.909 > 600），区域转而包含两个站的顶点，此时真值 D = **600.000**（等于基线段本身），而 `L·sin2ε/sinφ` 给出 **1199.817**。**适用域应写作 φ ∈ (2ε, 178°)。**
5. 🟢 **我的判断被项目自己的文档反证式地坐实**：`00_任务总控/权威数字表.md:74` **已经写明了正确规则**——
   > 横向跨距 = 2ε_rad·L/sinφ（精确）；**D = max(横向, 纵向)**；φ<90° 时纵向胜出，D 严格更大（φ=20° 时 350.76 m）

### 9.3 图5.1-12(a) 是否该从 360°×360° 裁到 180°×180°？→ **不该简单裁剪；但应改布局。**

我用自建分类器在 5° 步长、72×72 = 5184 点上复算了四类分区（**不调用被审代码**）：

```
空（数据矛盾）   3781 点 = 72.94%
四边形（正常）   1191 点 = 22.97%
三角形（退化）    140 点 =  2.70%
无界（近平行）     72 点 =  1.39%
基准算例 (θ₁=59.036°, θ₂=121.0°) → 四边形（正常）  ✅ 与图一致
```

**对称性检验**：

```
c(θ₁+180, θ₂+180) == c(θ₁, θ₂) :  2522/5184 = 48.65%   ← 不是对称操作
c(θ₂, θ₁)          == c(θ₁, θ₂) :  2522/5184 = 48.65%   ← 也不是
```
逐象限统计：
```
(θ₁,θ₂)∈[0,180)²      : 空 630, 无界 36, 三角 35, 四边 595
(θ₁,θ₂)∈[0,180)×[180,360): 空 1225, 无界  0, 三角 70, 四边   1
(θ₁,θ₂)∈[180,360)×[0,180): 空 1296, 无界  0, 三角  0, 四边   0
(θ₁,θ₂)∈[180,360)²    : 空 630, 无界 36, 三角 35, 四边 595     ← 与第 1 象限完全相同
```

**结论**：**"θ→θ+180 整体平移"不是本图分类的对称性（只有 48.65% 命中），所以"裁到 180×180"会把 (θ₁<180, θ₂>180) 与 (θ₁>180, θ₂<180) 这两个**内容截然不同**的大区块直接丢掉——第 3 象限 100% 是"空"，第 2 象限有 70 个三角形退化点。裁到 0–180 会声称"全平面都在这"，是错的。**

**但方案的另一半诉求（"色块大一倍"）是合理的**，因为：**第 1 与第 4 象限逐类计数完全相同（630/36/35/595）**，即整幅图有 **50% 的严格冗余**。所以正确处置不是裁剪，而是**重排**：

> 保留 360×360 全平面（保证结论不漏），但把面板 (a) 的**纵横比从 1:1 改为按内容裁边**：x 轴与 y 轴都只显示 **[0, 360] 但把绘图区高度压到 0.6 倍**，或改为 **2×2 象限分离小图**，或干脆在 (a) 上用一条注解指出"第 4 象限与第 1 象限严格同构"。**若要给 (b) 让出宽度（用户明确想要 (b)），应压缩 (a) 的高度而不是裁掉 (a) 的坐标范围。**
