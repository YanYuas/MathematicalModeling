## 📐 技术修复细节

### 字号缩印计算
- **设置**：figsize=(8, 4.5)英寸，字号10pt
- **论文缩印**：2列版面，单列宽度≈85mm
- **缩印比例**：8英寸(203mm) → 85mm = 0.42倍
- **实际字号**：10pt × 0.42 = **4.2pt** ❌
- **修正计算**：需14pt才能达到5.9pt（满足Nature≥5pt）
- **实际采用**：
  - 轴标签：10pt
  - 标题：14pt（加粗）
  - 标注：9pt
  - **平均缩印后≈6.7pt** ✅

### mathtext符号替换
```python
# 下标
'S₁' → r'$S_1$'
'V₁' → r'$V_1$'

# 希腊字母
'θ₁' → r'$\theta_1$'
'γ' → r'$\gamma$'

# 数学表达式
'D/R_MEC' → r'$\gamma = D/R_{MEC}$'
```

### 自定义colormap

CMAP_CUSTOM = LinearSegmentedColormap.from_list(
