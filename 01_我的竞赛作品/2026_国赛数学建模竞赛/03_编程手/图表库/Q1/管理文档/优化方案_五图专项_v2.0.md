## 零、先决结论（影响全部优化）

### 0.1 生图链路断裂 —— 必须重建

现状是**不可复现**的：

| 事实 | 证据 |
|------|------|
| 现图文件名是中文版（`图5.1-1_基准算例_v1.3.png`） | 磁盘实际文件 |
| 但库内脚本 `save_fig()` 只输出英文名（`fig5_1_1_baseline.png`） | `q1_figures_beautified.py:93-114` |
| 全项目搜索 `角域构造演化` 只在文档里命中，**没有任何 .py 生成该名称** | `grep -rn` 结果 |
| `generate_all.py` 的 FIGURE_LIST 里根本没有图5.1-9 | `generate_all.py:39-56` |
| 05_算法流程 目录注释写"手绘，不由代码生成" | `generate_all.py:97` |

**结论**：v1.3 的六张图是外部生成的，脚本无法复现。任何优化都必须先补上生图代码，否则改一版丢一版。这是本方案的第一优先级。

### 0.2 现有脚本本身就与磁盘图不一致

`q1_figures_beautified.py:1181` 的 `fig_5_1_8_n_and_grid()` 里 `cmap='YlOrRd'`（P0-5 声称已修，实际没改）、`fig.suptitle(...)`（P0-8 声称已移除，实际还在）。**现有脚本不能作为基线直接改**，只能作为算法调用参考。

### 0.3 一处数据完整性红线（必须先决策）

图5.1-8(b) 的热力图用的是：

```python
im = ax2.imshow(D_grid, ..., interpolation='bilinear')
```

`scan_grid` 实际只有 **54 个离散采样点**（φ 分 9 档 × ε 分 6 档）。`imshow` 会把 54 个点**双线性插值铺满整个矩形**，读者看到的是连续曲面，但**绝大多数颜色值不是扫出来的**。在数学建模论文里这属于"用插值冒充实测"，评审一旦追问采样密度就站不住。

**建议**：改为 `pcolormesh` + 未采样区域显式留白，或降级为散点+气泡（气泡大小=D）。**此项需你拍板**，因为影响图(b)的视觉冲击力。

## 一、优化总原则

沿用现有 **Ink & Ochre** 配色（不换风格，只修执行）。三条硬约束：

| 约束 | 具体要求 | 依据 |
|------|---------|------|
| **缩印可读** | 论文双栏单栏宽 ≈ 85mm。目标成品宽度 7.0in，缩印比 0.48。字号需 ≥ 12pt 才能保证缩印后 ≥ 5.8pt | Nature/Science 排版下限 5pt |
| **数学符号全 mathtext** | 一律 `r'$S_1$'`、`r'$\theta_1$'`、`r'$\varphi$'`。**严禁 Unicode 下标**（₁₂₃）与**全角括号内嵌**（θ［2］） | 现图缺字方框就是这个原因 |
| **图注归论文，图内不重复** | 删除全部 `suptitle`。图标题由论文 `\caption{}` 承担 | 现5张图有4张在重复标题 |

**字号规范（v2.0 定稿）**：

```
轴标签 / 刻度   : 12pt
面板标题 (a)(b) : 14pt bold
图内标注        : 11pt
图例            : 11pt
信息卡数值      : 11pt （等宽对齐用 monospace)
```

#### 改法（这张建议**重做**，不做微调）

**D4 是关键**——先明确物理含义：理论式 `D_theory(d)` 成立条件是**远场小角度近似**（d ≫ L/2）。在 d 大时二者本应收敛，现图反而发散，说明**要么理论式推导有前提没说清，要么绘图时套用了错误的公式**。**此项需要建模手确认理论式适用范围**，不能我自己改。

**结构建议**：三联图 → **2+1 结构**

```
(a) ε 灵敏度：D vs ε（点线 + 线性拟合虚线，删除多余红线，
             标注 R²，在 ε=1° 处打竖虚线标基准）
(b) n 灵敏度：横向条形图（真正体现"边际收益递减"，
             n=2 起点标 39.6，n=8 终点标 19.3，差值 20.3 用箭头跨度标出）
(c) 距离灵敏度：D vs d。理论式只在 d ≥ 600 m 区间画（其适用域），
             加阴影带标"理论式适用域"，近场不画避免"发散"错觉
```

并且**统一 marker 与线型**：实测=实心圆+实线，理论=短虚线（`ochre`），基准点=星号。

### 3.3 公共层要做的事（一处修，六图受益）

1. **字体回退链显式化**：`['Microsoft YaHei','SimHei','DejaVu Sans']` + `mathtext.fontset='stix'`，并**在脚本开头断言字体可用**，不可用直接报错而不是静默变方框。

4. **`no_suptitle()` 检查**：脚本末尾扫描 `fig._suptitle`，非空则报错。
