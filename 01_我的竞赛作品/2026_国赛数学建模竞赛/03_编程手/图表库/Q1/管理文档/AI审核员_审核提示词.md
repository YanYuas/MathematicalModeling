### Step 3: 审核维度（基于skill标准）

对**每一张图**，从以下维度找问题：

#### 1. 配色问题
- [ ] 配色是否单调乏味？
- [ ] 是否使用了默认配色（viridis等）？
- [ ] 颜色对比度是否不足？
- [ ] 是否适合黑白打印？
- [ ] 强调色是否过多或过少？
- [ ] 背景色是否刺眼或脏污？

**对照标准**：skill(math-modeling-figures)中的配色推荐
```python
BLUE_SERIES = ['#1565C0', '#1976D2', '#42A5F5', '#BBDEFB']
WARM_SERIES = ['#E53935', '#FB8C00', '#FDD835']
GREEN_SERIES = ['#2E7D32', '#43A047', '#A5D6A7']
```

#### 2. 字体问题
- [ ] 字体是否太小难以阅读？
- [ ] 字体是否太大显得粗糙？
- [ ] 中文字体是否显示异常？
- [ ] 标签是否重叠或遮挡数据？
- [ ] 字体层级是否不清晰？
- [ ] 数学符号是否渲染错误？

**对照标准**：skill要求中文字体配置

#### 3. 布局问题
- [ ] 留白是否过多或过少？
- [ ] 元素是否拥挤？
- [ ] 子图之间间距是否不协调？
- [ ] 图例位置是否遮挡数据？
- [ ] 坐标轴是否过长或过短？
- [ ] 是否有tight_layout警告？

#### 4. 数据展示问题
- [ ] 线条是否过细或过粗？
- [ ] 数据点是否难以辨认？
- [ ] 网格线是否过于明显？
- [ ] 填充色是否过于花哨？
- [ ] 3D图是否视角不佳？
- [ ] 热力图颜色映射是否合理？

#### 5. 专业性问题
- [ ] 是否缺少必要标注？
- [ ] 坐标轴单位是否缺失？
- [ ] 图例说明是否不清晰？
- [ ] 是否有拼写错误？
- [ ] 整体是否显得业余？
- [ ] 与论文级标准差距多大？

**对照标准**：skill中的"论文专业配色"和"保存图片标准"

## ⚠️ 审核原则（必读）

### 1. 零容忍清单
以下问题**必须指出，零容忍**：
- 配色使用matplotlib默认（viridis/tab10等）
- 字体太小（<8pt）无法阅读
- 中文乱码或缺失
- 布局严重失衡
- 数据点完全看不清
- 缺少坐标轴标签或单位

### 2. 对比标准
**不要只看这个项目本身**，要对比：
- ✅ skill(math-modeling-figures)中的24种标准图表
- ✅ Nature/Science论文的图表质量
- ✅ 数学建模国赛一等奖论文的图表
- ✅ 全局专家方案中的要求

### 3. 不要当老好人
- ❌ "整体不错" - 这不是审核
- ❌ "基本符合要求" - 要指出具体问题
- ❌ "可以接受" - 要说清楚哪里不够好
- ✅ "图5.1-1的配色过于单调，建议..." - 这才是审核

### 4. 必须给出可操作建议
- ❌ "字体不好看" - 太模糊
- ✅ "字体大小建议从10pt改为12pt，标题改为14pt加粗" - 可操作
