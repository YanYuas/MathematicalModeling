## 生图代码说明

### q1_figures_beautified.py（统一美化版生图脚本）

包含12个图表函数：
1. `fig_5_1_1_baseline()` - 基准算例
2. `fig_5_1_2_wedge_evolution()` - 角域构造演化
3. `fig_5_1_3_jung_counterexample()` - Jung反例
4. `fig_5_1_4_jung_sandwich()` - Jung夹逼
5. `fig_5_1_5_vertex_filtering()` - 顶点过滤
6. `fig_5_1_6_param_scan()` - 参数扫描
7. `fig_5_1_7_gamma_distribution()` - γ分布
8. `fig_5_1_8_n_and_grid()` - n扫描+热力图
9. `fig_5_1_10_geometry_construction()` - 交会定位区域构造
10. `fig_5_1_11_sensitivity_triplet()` - 灵敏度三联图
11. `fig_5_1_12_param_space_partition()` - 参数空间四类分区
12. `fig_5_1_13_phi_D_theory()` - φ-D曲线与理论式验证

**运行方式**:
```bash
cd 01_生图代码
python q1_figures_beautified.py
```

输出自动按分类保存到对应子目录（02_几何示意/、03_参数扫描/等），文件名格式为 `fig5_1_X_名称.png/svg`。

### 数据文件说明

**q1_scan_results.json** 包含：
- `scan_phi`: 15组 φ扫描（phi, h, D, R, gamma, nv）
- `scan_n`: 5组 n扫描（n, D, R, gamma, nv）
- `scan_eps`: 7组 ε扫描（eps, D, R, gamma, nv）
- `scan_grid`: 54组 (φ,ε)网格扫描（phi, eps, D, gamma）
- `gamma_mc`: 蒙特卡洛γ分布（n2~n5，各2000样本）
- `selfcheck_phi61_92`: 基准题自检数据

## 关键数据（防错）

- 基准算例：S₁=(0,0), S₂=(600,0), G=(300,500), ε=1°
- D = 39.598 m, R_MEC = 19.799 m, γ = 1.000
