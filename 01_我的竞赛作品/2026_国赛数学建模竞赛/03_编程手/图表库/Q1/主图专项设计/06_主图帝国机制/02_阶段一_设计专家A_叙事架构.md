## 1. 不可变数学事实与符号表（唯一口径，全文引用）

**符号表（与正文一致，禁止引入 `d_max`、`R*` 等异名）：**

| 符号 | 含义 | 本图允许出现的形式 |
|---|---|---|
| `S_i` | 第 i 个测站位置 | 仅特例口袋出现 `S1`、`S2` |
| `theta_i` | 第 i 个示向度（度） | 仅特例口袋出现数值 |
| `eps` = 1° | 示向度误差半角 | 角域扇形标注 |
| `u(phi)` | 单位方向向量 `(cos phi, sin phi)` | 生成器层文字 |
| `W_i` | 角域 `{S_i + t·u(phi) : t>=0, abs(phi-theta_i)<=eps}` | 输入层唯一对象 |
| `L` | 定位区域 `= ∩ W_i`，凸多边形 | 全局 |
| `D` | 直径 `max{\|\|p-q\|\| : p,q in L}` | 全局 |
| `P, Q` | 直径端点（顶点对） | 全局 |
| `R_MEC` | 最小覆盖圆半径 | 全局 |
| `C*` | 最小覆盖圆圆心 | 特例口袋 |
| `gamma` | `R_MEC / (D/2)` ∈ [1, 2/sqrt(3)] | 全局（唯一放缩指标） |
| `D/sqrt(3)` | Jung 上界 | 全局 |
| `angle PXQ` | 顶点 X 处对直径端点的张角 | 判据层唯一度量 |

**数值锚点（来源 `verify_facts.json`，mpmath 40 dps 定义驱动复算，8 项口径 4 位小数吻合，`doc_crosscheck.all_match=true`）：**

- 基准特例：`P1=(288.1342, 499.7929)`、`P2=(300.0000, 480.7768)`、`P3=(311.8658, 499.7929)`、`P4=(300.0000, 520.3752)`；
  `D = 39.5983 m`（端点 `P2,P4`）；`C* = (300.0000, 500.5760)`，`R_MEC = 19.7992 m`；
  `D/2 = 19.7992 m`，`D/sqrt(3) = 22.8621 m`，`gamma = 1.0000`；
  各顶点 `angle P2 X P4 = 118.0725° >= 90°` ⇒ **本例确被直径圆覆盖**。
- 反例（等边三角形，归一化 `D = 1`）：`R_MEC = 1/sqrt(3) = 0.57735 > D/2 = 0.5`，顶点角 `60° < 90°` ⇒ **直径圆不覆盖**。
- 一般结论：**以 D 为直径的圆不保证覆盖 L**；正确替代是 MEC，满足夹逼 `D/2 <= R_MEC <= D/sqrt(3)`。
- 定义域前提（Charter 登记的主动异议）：`D` 存在要求 `L` 有界；判据为各角域外法向角排序后**最大相邻间隔 <= 180°**。基准例 `120.0725°` → 有界；同向楔形 `182°` → 无界（`D = +inf`，本判据不适用）。

**四个必须被读者辨认的层次（本文件全部方案的验收底线）：**
L1 输入角域 `W_i` / L2 一般凸区域 `L` 与直径 `D` / L3 直径圆覆盖判据（Thales） / L4 最小覆盖圆的界（Jung 夹逼）。

**证明结构（主图必须承载的骨架，任何方案不得断链）：**
```
误差角域是凸集
      ↓
角域相交得到凸多边形 L ──────→ 直径 D（顶点对）
      ↓                              ↓
Thales 顶点判据                 反例：等边三角形
      ↓                              ↓
具体 L 是否覆盖              一般情形不能保证
      └────────→ MEC 与 Jung 夹逼 ←────────┘
```

**全局硬禁止（三案共同遵守）：** 横向三联 / 全景+局部放大（inset axes）/ 均分网格面板 / 海报式装饰 /
单一基准菱形占满整张图 / 把 `D/sqrt(3)` 画成小于 `R_MEC` 的圆 / 把 `G` 当测站 / 使用 `d_max`、`R*` /

# 方案 A：判据脊柱 · 否定旁路

**核心结论（一句话）：** 以直径 D 为直径的圆**不保证**覆盖定位区域 L——等边三角形即反例；覆盖的充要条件是 L 的全部顶点满足 Thales 判据 `angle PXQ >= 90°`，正确替代是满足 Jung 夹逼 `D/2 <= R_MEC <= D/sqrt(3)` 的最小覆盖圆。

## A-7 数学风险与规避

| # | 风险（最可能被审稿人指为逻辑漏洞） | 规避办法 |
|---|---|---|
| R1 | **`L` 有界性被默认**：若 `L` 无界则 `D=+inf`，整条"直径→判据→MEC"链失去定义域。 | ② 层标题固定写"`L = ∩ W_i`（前提：`L` 有界，外法向最大相邻间隔 <= 180°）"；④ 层脚注一行小字"若 `L` 无界则 `D=+inf`，本判据不适用"。 |
| R2 | **`gamma=1` 被读成一般性质**（本案最大风险）。 | ① `gamma` 只出现在 ④ 的半径标尺与特例口袋，且特例口袋首行**固定文案**"特例验证 · 非一般结论"；② 结论条只写一般结论，不出现 `gamma`；③ 机检断言：文本 `gamma` 与文本"特例"的 bbox 上下距离 <= 容差（强制同区）。 |
| R3 | **Thales 被当成充分条件**（实为充要，且"只需检查顶点"依赖凸性）。 | ③ 层标题写"充要条件"；副标题写"凸性 ⇒ 只需检查顶点"；顶点用 ● 实心标记强调"全部顶点"。 |

# 方案 B：判据平面 · 构型相图

# 方案 C：半径标尺 · 缺口裁决

**核心结论（一句话）：** 任何构型的最小覆盖圆半径都落在归一化区间 `[1, 2/sqrt(3)]`（即 `D/2 <= R_MEC <= D/sqrt(3)`）内；"缺口宽度" `gamma - 1` 正是**直径圆未覆盖 L 的度量**——一般情形 `gamma > 1`（缺口 > 0），只有 `gamma = 1`（缺口退化为 0）时直径圆才恰好覆盖。

## C-2 版面草图（通栏 16.0 cm × 9.5 cm）

# 3. 评分与首选裁定

**评分维度与权重（按 Charter 的目标状态设定，权重和为 1）：**
数学论证力 0.35 / 视觉独创性 0.20 / 论文可读性 0.25 / 实现可控性 0.20。每维 1–10 分，加权求和。

| 方案 | 数学论证力(0.35) | 视觉独创性(0.20) | 论文可读性(0.25) | 实现可控性(0.20) | **加权总分** |
|---|---|---|---|---|---|
| **A 判据脊柱 · 否定旁路** | **9.5** | 8.0 | **9.0** | **9.0** | **8.98** |
| B 判据平面 · 构型相图 | 7.5 | **9.5** | 7.0 | 6.0 | 7.48 |
| C 半径标尺 · 缺口裁决 | 8.0 | 8.5 | 8.5 | 9.0 | 8.43 |

**评分理由（逐维）：**

- **数学论证力。** A 以**逻辑蕴含方向**为版面主轴，`W_i ⇒ L ⇒ D ⇒ (Thales | 反例) ⇒ 结论` 的每一步都有专属层节，证明结构的六条边全部可见，且"具体 L 是否覆盖"与"一般情形不能保证"两条出口分别落在脊柱与旁路，论证完备性最高（9.5）。C 把"不能保证"压缩成缺口宽度，是最锋利的**单点论证**，但它**无法承载 `W_i → L → D` 的构造链**（只能退化为 11% 的微型生成链），四层次承载不均衡，且 `theta_min` 维度缺失，无法证明 Thales 判据的充要性（8.0）。B 的 L 形折线本身就是"覆盖 `<=>` `gamma=1`"的图形化陈述，论证力强，但它证明的是**平面上的可达集结构**，对"`L` 有界前提""只需检查顶点"等细节无处安放，且引入新记号 `theta_min` 增加正文负担（7.5）。
- **视觉独创性。** B 的"直角折线 + 两臂 + 点–实例引线"是三案中最不可能被误认为模板图的机制（9.5）。C 的"诺谟图共原点钉带"次之（8.5）。A 的"纵向论证脊柱 + 否定旁路合流"在同济式数学论文图里罕见，但纵向分层仍有被读作"流程图的变体"的可能（8.0）。
- **论文可读性。** A 的读图路径是**单向的**（自上而下），3 秒抓手（红色 90° 参考线 + 结论条）与 30 秒证据链的衔接最自然，且不要求读者具备坐标读图经验（9.0）。C 的标尺直观但需要读者接受"归一化半径"这一抽象（8.5）。B 要求读者理解"点 = 构型"的相图语义，对评委的抽象迁移成本最高（7.0）。
- **实现可控性。** C 最简（单标尺 + 三行钉 + 三列证物，几何量最少，断言最好写，只有 9.5 cm 高），9.0。A 次之（手工 `add_axes` 六块，几何全由既有复算层供给，断言 18 条均可机检），9.0。B 最差：需要 20000 凸包枚举数据落盘、剖面区域填充与斜纹在灰度下的可辨性需要额外验证、散点数据来源需在正文交代（6.0）。

**首选裁定：方案 A（判据脊柱 · 否定旁路）为唯一主架构。**

**裁定理由（三条）：**
1. Charter §1 的目标状态是"让读者不读图注也能区分四个层次"——只有 A 为四个层次各自分配了**独立且不等权**的层节，四层次的位置本身就是版面结构。
2. Charter §1 的止损规则是"把 `gamma=1` 表述为一般性质即停"——A 用**物理隔离的特例口袋**（独立底色 + 固定文案 + 机检 N10 的 bbox 距离断言）从版面上阻断该误读，是三个方案中唯一把"防误读"做成**结构性**而非"文字提醒类"的。
3. A 的证明结构六条边全部可见，与 Charter 给出的证明骨架**逐边对应**，评审可以直接按图复核，无需在正文与图之间来回映射。

**吸收条款（依 Charter §3：只允许从落选方案吸收至多一项不破坏主架构的机制）：**
从 **方案 C** 吸收**唯一一项**机制——**"缺口"表达**，用于 A 案第 ④ 层的 Jung 夹逼：`D/2` 与 `R_MEC` 之间的偏离不再仅用三个刻度数字表示，而用一段带斜纹的**缺口条**表示，宽度等于 `gamma - 1`。
该机制不改变 A 的纵向主轴、不新增面板、不增加分区，只替换 ④ 层内部的绘制笔法，符合"不破坏主架构"的约束。
**不吸收 B 的任何机制**（`theta_min` 新记号会增加正文负担，且相图语义与纵向论证轴不兼容）。

## 4.4 可直接用于论文的中文图注

> **图 1　带 ±1° 误差示向度的定位区域：直径圆覆盖判据、一般反例与最小覆盖圆的夹逼。**
> ① 每条带误差的示向度与其半角 `eps = 1°` 构成一个凸角域 `W_i = {S_i + t·u(phi) : t >= 0, |phi − theta_i| <= eps}`；
> ② 各角域之交 `L = ∩ W_i` 为凸多边形（以 `L` 有界为前提，即各角域外法向角排序后最大相邻间隔 <= 180°），其顶点由各边界射线两两求交后经"属于全部角域"过滤得到，直径 `D = max{‖p − q‖ : p, q ∈ L}` 由顶点对取到；
> ③ 覆盖判据（Thales）：以直径端点 `P, Q` 为直径的圆覆盖 `L`，**当且仅当** `L` 的全部顶点 `X` 满足 `angle PXQ >= 90°`（凸性使得只需检查顶点）；
> ③′ 反例（等边三角形，归一化 `D = 1`）：三个顶点角均为 `60° < 90°`，最小覆盖圆半径 `R_MEC = 1/sqrt(3) ≈ 0.5774 > D/2 = 0.5`，故直径圆**不覆盖** `L`——这说明**以 `D` 为直径的圆一般不保证覆盖定位区域**；
> ④ 正确替代是最小覆盖圆，其半径满足 Jung 夹逼 `D/2 <= R_MEC <= D/sqrt(3)`；图中归一化半径轴 `r = R/(D/2)` 上的"缺口"宽度 `gamma − 1`（`gamma = R_MEC/(D/2)`）即"直径圆未能覆盖的部分"的度量，一般情形缺口大于零。
> 右下角灰框为**两站基准特例**：`S1 = (0,0)`、`S2 = (600,0)`、`theta1 = 59.036243°`、`theta2 = 120.963757°`，`L` 为凸四边形，`D = 39.5983 m`（端点 `P2, P4`），`R_MEC = 19.7992 m`，`C* = (300.0000, 500.5760)`，`gamma = 1.0000`（本例 `D/2 = R_MEC`，两圆重合），各顶点处 `angle P2XP4 = 118.0725° >= 90°`，故**该算例**确被直径圆覆盖。该算例仅用于算法验证，其 `gamma = 1` 属特例，**不构成一般结论**；作为对照，本例的 `D/sqrt(3) = 22.8621 m` 仍严格大于 `R_MEC`。所有数值由 `mpmath` 40 位精度定义驱动复算（`verify_facts.json`，8 项口径四位小数吻合）。
