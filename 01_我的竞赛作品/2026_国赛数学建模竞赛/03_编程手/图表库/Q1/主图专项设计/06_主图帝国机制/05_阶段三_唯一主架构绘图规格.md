## 1. 唯一主架构与核心结论

**核心结论（图上结论条原文）：**

> 以 `D` 为直径的圆**不保证**覆盖定位区域 `L`；覆盖的**充要判据**是全部非直径端点顶点满足 `angle PXQ >= 90°`，等价于 `gamma = 1`。正确替代是最小覆盖圆，`gamma ∈ [1, 2/sqrt(3)]`，等边三角形取上界。

**架构形状：** 顶部通栏输入构造链 → 中部**左右分叉**（左侧反例分支 / 右侧判据分支）→ 底部汇合于 MEC 与 `gamma` 归一化轴 → 右下角低对比度特例口袋。

**为什么是分叉而不是序列：** 反例走的是**存在性证否**（一个反例即否定全称命题），判据走的是**全称充要判定**（对所有顶点成立才覆盖）。这是两类不同的逻辑行为，把它们排成上下序列会让读者以为它们是同类证据；并排分叉则强制读者看出这是两条**独立**路径，最终共同支撑同一结论。

## 2. 架构裁定：为什么是这一个

### 2.1 来源与去重

| 输入 | 处理 |
|---|---|
| `03_阶段二_匿名裁决裁定书.md` 的胜者「分叉式覆盖判决桥」 | **采用为唯一主架构的拓扑** |
| `02_阶段一_设计专家A_叙事架构.md` 的首选「判据脊柱·否定旁路」 | **不采用其拓扑**（纵向脊柱＋单侧旁路，反例被降为旁路），仅吸收其**实现级工艺**（坐标表 + 对象字典 + 断言写法 + 画布尺寸口径）。这不构成路由文件 §5 禁止的"版式硬拼"——被复用的是验收工艺，不是布局 |
| 专家A 方案 C 的「缺口条」机制 | **吸收（Charter §3 允许的唯一一项）**：用于底部 MEC 层，把 `gamma` 从 1 到 `2/sqrt(3)` 的偏离画成可见缺口，而不是三个孤立刻度数字 |

### 2.2 与阶段二裁定的唯一偏离（已披露）

阶段二给出的配额是「反例 38% / 判据 21% / MEC 11%」。本规格调整为**反例 29.5% / 判据 20.1% / MEC 18.9%**，理由是阶段三证明了等边三角形不只是"某个反例"，而是 `gamma` 的**极值构型**（由 Jung 定理取全局上界 `2/sqrt(3)`）。因此底部 `gamma` 层从"一个界"升级为"全图综合"，需要一根可读的归一化轴；反例仍为最大单一内容块。阶段二裁定的全部**硬约束**均未被破坏：

| 约束 | 实际 | 通过 |
|---|---|---|
| 反例为最大单一内容块 | 29.5% > 27.0% > 20.1% > 18.9% | 是 |
| 判据 >= 20% | 20.1% | 是 |
| MEC 与 Jung >= 12% | 18.9% | 是 |
| 特例 <= 5% | 4.5% | 是 |
| 输入链顶部通栏 | 宽度 0.92，通栏 | 是 |

## 5. 绘图规格 R1–R14

- **R1 画布与字体。** `figsize=(6.2992, 5.3150)`；`rcParams`：`font.sans-serif=['SimHei','Microsoft YaHei']`、`axes.unicode_minus=False`、`pdf.fonttype=42`、`svg.fonttype='none'`、`axes.linewidth=0.8`、`axes.spines.top/right=False`、`legend.frameon=False`。
- **R2 分区。** 严格按 §3 坐标表；禁止 `subplots`；任意两个可见 axes 面积不得相等。
- **R3 结论条。** `ax_head` 内 11 pt 粗体，原文见 §1；「不保证」三字加粗并着色 `#B64342`。
- **R4 输入链。** `ax_chain` 左起依次画：抽象角域示意（无测站名、无坐标、无米制数值）→ `∩` → `L` 多边形 → `P,Q` → 候选直径圆；相邻元素间用 `arrowstyle='-|>'` 细箭头（0.9 pt，`#767676`）。链尾固定一行 8 pt 灰字：

  > 前提：`L` 非空且有界（外法向角排序后最大相邻间隔 `<= 180°`）；各站误差半角 `eps` 相同。若 `L` 无界则 `D = +inf`，直径圆与 Jung 夹逼均无定义。

- **R5 分叉。** 链条末端向 `ax_cex` 与 `ax_crit` 各引一条分叉箭头；两分支必须**处于同一水平带**（中心 y 之差 `<= 0.02`），使读者一眼看出是并列的两条独立路径。
- **R6 反例分支。** 标题固定「等边三角形反例（`n >= 3`，归一化 `D = 1`）」；画等边三角形（红 `#B64342` 粗线 1.6 pt，顶点 ▲ 3.5 pt）；三内角各画红弧并标 `60°`；叠画 `D/2` 点线圆（半径 0.5）与 MEC 实线圆（半径 `1/sqrt(3) = 0.5773503`），两圆之间以浅红斜纹填充并在旁标「缺口 `gamma − 1`」；右下红戳方框（红边 1.6 pt，红字 10.5 pt 粗）「直径圆不覆盖」；**`axis('off')` 且刻度长度为 0**。
- **R7 判据分支。** 标题固定「覆盖判据：Thales 顶点角【充要】」；重绘 `L`（更大比例、同一几何）；对**每个非直径端点顶点**画两条到 `P`、`Q` 的细弦（0.6 pt，alpha 0.6）与角弧（红 1.6 pt），逐点标实际角度（本例 `118.0725°`）；`P`、`Q` 处**只画实心方标记，不得画角弧**（该处弦长为 0，夹角无定义）；画贯穿的 90° 红细实线（0.8 pt）与直角符号；右上放 ✓ 与「`angle PXQ >= 90°` `=>` 覆盖」。
- **R8 汇合。** `ax_cex` 与 `ax_crit` 各向下引一条 `FancyArrowPatch` 进入 `ax_mec`；左侧入流线型 `(0,(4,2))` 且中点标「证否（存在性）」，右侧入流实线且中点标「充要判定（全称）」；两线在 `ax_mec` 上方汇成 **⊥ 形**（8 pt 灰字「两路独立证据共同支撑」）。
- **R9 MEC 与 γ 轴。** `ax_mec` 画水平归一化轴，范围 `r = R/(D/2) ∈ [1.00, 1.18]`；`r = 1` 处画深蓝粗竖线（1.6 pt）并标「`gamma = 1 <=> 覆盖`」；`r = 2/sqrt(3) = 1.1547` 处画 teal 虚竖线并标「`gamma = 2/sqrt(3)`（等边三角形取此上界）」；两线之间画 teal 空心区间条 + 斜纹缺口条，标 8 pt「一般情形 `1 < gamma <= 2/sqrt(3)`，缺口 `gamma − 1 > 0`」。**本区不得出现任何米制数值**。

## 8. 论文图注（可直接使用）

> **图 X　定位区域直径圆的覆盖判据与一般反例。**
>
> 以带 `±1°` 误差的示向度构造前向角域 `W_i`，其交 `L = ∩ W_i` 若**非空且有界**（外法向角排序后最大相邻间隔 `<= 180°`），则直径 `D` 由其顶点对取得。**以 `D` 为直径的圆一般不保证覆盖 `L`**：当 `n >= 3` 个检测站的误差半角同为 `eps` 时，存在使 `L` 为**等边三角形**的构型（归一化 `D = 1`），其第三顶点落在直径圆之外、该顶点处张角 `60° < 90°`，而最小覆盖圆半径 `R_MEC = 1/sqrt(3) = 0.5774 > D/2 = 0.5`，即 `gamma = 2/sqrt(3) = 1.1547`。
>
> 覆盖的**充要判据**为：以直径端点 `P, Q` 为直径的圆覆盖 `L`，当且仅当 `L` 的**全部非直径端点顶点** `X` 满足 `angle PXQ >= 90°`（`L` 与圆盘均凸，故只需检查顶点；`P`、`Q` 处夹角无定义）。正确替代是最小覆盖圆，满足 `D/2 <= R_MEC <= D/sqrt(3)`，等价地 `1 <= gamma <= 2/sqrt(3)`，其中 `gamma = R_MEC/(D/2)`；**`gamma = 1` 当且仅当直径圆恰好覆盖 `L`**。等边三角形取上界 `2/sqrt(3)`，即 `gamma` 的极值构型。
>
> 右下角方框为**两站基准算例的特例验证**：`S1=(0,0)`、`S2=(600,0)`，`D = 39.5983 m`，`R_MEC = 19.7992 m`，`C* = (300.0000, 500.5760)`，`gamma = 1.0000`，非直径端点 `P1,P3` 均满足 `angle P2 X P4 = 118.0725° >= 90°`，故**该算例**被直径圆覆盖。**此为特例，不构成一般保证**；当 `gamma > 1` 时，直径圆不覆盖。

## 9. 禁止清单

**禁止出现的表述（来自阶段三裁决）：**

1. 「本题区域族内 `gamma <= 1.01`，等边三角形不可达」——已在 `n = 3` 处被构造反例证伪；
2. 「两站角域交集是中心对称的近似平行四边形」——基准算例即非中心对称（对角中点相距 `0.783112`），且族 B 不含平行四边形；
3. 「两站角域交集必有 `gamma = 1`」——已在 50 位精度下证伪（`gamma = 1.00058845064345962`）。

**禁止出现的图形元素：**

- 横向三联、全景+局部放大、等大网格、海报式辐射；
- 在任何通用数轴上标注米制数值；
- 在 `P`、`Q` 两顶点处画角弧；
- 把 `D/sqrt(3)` 画成小于 `R_MEC` 的圆；
- 把 `G` 画成测站型标记；
- 让反例与特例同底色、同尺度、同对比度。
