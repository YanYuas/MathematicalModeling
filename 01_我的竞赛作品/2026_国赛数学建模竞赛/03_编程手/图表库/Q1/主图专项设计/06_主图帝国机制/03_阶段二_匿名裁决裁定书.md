## 0. 裁决前置：先核验裁决包自身的事实

我不先评分，先验证候选方案所依赖的数值。全部用 `audit_adjudication_package.py` 复算：

| 裁决包断言 | 核验结果 |
|---|---|
| 等边三角形 `R_MEC = D/sqrt(3) > D/2` | **正确**：`D=1`，`R_MEC=0.5773502692=1/sqrt(3)`，`D/2=0.5000000000` |
| `gamma = 2/sqrt(3)` | **正确**：`gamma = 1.1547005384 = 2/sqrt(3)` |
| 对角 `60° < 90°`，第三顶点在圆外 | **正确**：第三顶点到圆心距离 `0.8660254038`，超出半径 `0.5` 达 `0.3660254038`；张角 `60.000000°` |
| `gamma` 与尺度无关 | **正确**：原尺度/毫米量纲/放大 1000 倍三种情形 `gamma` 恒为 `1.0000000000`，而米制值随之变化 |

**结论：裁决包事实层可信，可直接作为评分基准。**

但核验同时暴露**四个候选共用**的四个缺陷，先于评分登记，因为它们会同时压低四案的分数：

- **T1（实现陷阱，四案皆中）**：基准算例四个顶点中，只有 `P1`、`P3` 处 `∠P2 X P4` 有定义（`118.0725°`）；`P2`、`P4` 本身即直径端点，对应弦长为 0，角**无定义**。任何写成"在每个顶点画角弧并标角度"的规格，字面执行都会在 `P2/P4` 产生无定义标注。
- **T2（定义域缺口，四案皆中）**：裁决包事实 #1/#2 未声明 `L` **有界**。同向楔形算例（`theta1=theta2=0°`）下 `L` 无界、`D=+inf`，"直径圆 / 判据 / MEC"整条链失去定义域。有界判据：外法向角排序后最大相邻间隔 `<= 180°`（基准例 `120.0725°` 通过）。
- **T3（符号纪律）**：`gamma` 是尺度无关量，米制值 `19.7992 / 22.8621` 是尺度相关量。通用 Jung 数轴必须用归一化 `r = R/(D/2) ∈ [1, 2/sqrt(3)]`；把米制刻度写进通用数轴即触发淘汰规则。
- **T4（可强化项）**：四案都把 `D/2` 当作"下界"。实际更强：`gamma = 1 ⟺ 直径圆覆盖 L` 是**充要**的。用它可以把"反例 vs 特例"的差别归结为单一标量 `gamma`，比"下界取等"的说法锋利得多。

## 1. 逐案评分

维度权重按裁决包：**数学正确性 40% / 叙事不混淆 25% / 论文适配 20% / 可复现性 15%**。

| 候选 | 数学正确性 (40%) | 叙事不混淆 (25%) | 论文适配 (20%) | 可复现性 (15%) | **加权总分** |
|---|---|---|---|---|---|
| **A 分叉式覆盖判决桥** | **9.0** | **8.5** | **8.0** | **9.0** | **8.68** |
| B1 垂直三段论 | 7.5 | 5.5 | 5.5 | 9.0 | 6.83 |
| B2 左右对比 | 8.0 | 4.0 | 4.0 | 9.0 | 6.35 |
| B3 中心反例+周边 | 8.0 | 5.0 | 5.0 | 7.5 | 6.58 |

**扣分理由（只列决定性项）：**

- **A 数学 9.0**：反例（存在性证否）、Thales（全称充要判据）、MEC/Jung（普适替代）三类陈述齐备且位置分离，是四案中唯一把"证否"与"判定"当作**两类不同逻辑行为**处理的。扣 1.0 是因为"判据与 MEC"合计仅占 18%，承载不足（见修正 1）。
- **A 叙事 8.5**：特例被压到 6% 低对比度小几何，是全案防误读最强的一处。扣分在于分叉合流处未规定两条入流的**语义区分**——"存在一个反例即否定全称命题"与"所有顶点满足则覆盖"是不同类型陈述，若用同一种箭头汇合，会被读成两条同类证据。
- **B1 叙事 5.5 / 适配 5.5**：下部 30% 放基准特例，与中部 30% 的判据**等权**。这把特例从"验证"升格为与判据同级的内容，正是淘汰规则"用基准两站特例代替一般反例"的软性变体。且 40/30/30 近似均分，触碰"均分网格"。
- **B2 叙事 4.0 / 适配 4.0**：左 50% / 中 20% / 右 30% 是**明确的横向三栏**，且"反例"与"特例"被并置为左右两块等权面板。中栏 20% 要同时放 Jung 区间与 Thales，密度不可实现。
- **B3 叙事 5.0 / 适配 5.0 / 可复现 7.5**：中心—外围辐射是海报式信息组织，中心约 50% 的反例向外发散四路，连线必然跨越几何对象，会**用连线掩盖真实几何关系**；且中心—外围阅读路线不稳定，无唯一入口。可复现性扣分因为辐射布局的几何比例约束难以机检。

## 2. 逐案最致命的数学或版式风险

| 候选 | 最致命风险 |
|---|---|
| **A** | **判据被降格**。反例占 48%，而 Thales 判据与 MEC 界合计仅 18%。题目要求的是"一般结论 **+ 判据 + 正确替代**"——只给否定不构成完整回答。若判据区小到读不清"所有顶点"这个量词，A 就从"完整回答"退化为"一个反例图"。 |

## 4. 修正条款（"只能增加、不许改变主架构"，共 6 条）

均不改变 A 的"顶部输入链 → 左右分叉 → 底部汇合"拓扑，只增加内容或调整分支配额。

1. **判据扩权（对应风险 T-致命）**：把"判据与 MEC 18%"拆为 **Thales 判据 ≥ 20%**、**MEC 与 Jung 界 ≥ 12%**；反例由 48% 降至 ≤ 40%，输入链保持 28%。分叉拓扑不变，仅改配额。理由是题面要求给出判据与正确替代，判据必须是可读的独立区，而不是反例的附属注释。
2. **合流语义显式化**：两条入流分别标注为"**证否（存在性）**"与"**充要判定（全称）**"，并使用不同线型进入汇合点；汇合点画成 ⊥ 形而非 Y 形，表达"两条独立证据共同支撑同一结论"，而非"两条同类证据合并"。
3. **端点角退化处理（T1）**：Thales 判定区**不得**在 `P`、`Q` 两顶点画角弧——该处弦长为 0，夹角无定义。改为在 `P`、`Q` 处只画"端点落在圆上"的实心方标记，角弧仅画在其余顶点（基准例为 `P1`、`P3`，标 `118.0725°`）。规格中"每个顶点"必须改写为"每个非直径端点顶点"。
4. **有界前提入图（T2）**：在输入链末端增加一行条件文本"**前提：`L` 有界（外法向最大相邻间隔 `<= 180°`）**"；并在 MEC 区脚注"若 `L` 无界则 `D = +inf`，本判据不适用"。
5. **通用数轴归一化（T3）**：MEC 与 Jung 区**一律**使用归一化半径轴 `r = R/(D/2) ∈ [1.00, 1.18]`，刻度标 `1`、`2/sqrt(3)=1.1547`；米制值 `19.7992 m / 22.8621 m` **只允许**出现在两站特例区。
6. **反例区关刻度并标归一化（T3）**：反例卡关闭全部坐标刻度，标题固定为"归一化（尺度无关）`D = 1`"，与特例区的米制值物理隔离，阻断尺度因果误读。

## 6. 最终中文图注

> **图 X　定位区域直径圆覆盖判据与一般反例。**
>
> 以带 ±1° 误差的示向度构造凸角域 `W_i`，其交 `L = ∩ W_i` 为有界凸多边形，直径 `D` 由其顶点对取得。**以 `D` 为直径的圆一般不保证覆盖 `L`**：等边三角形即为反例，其直径圆半径 `D/2` 小于最小覆盖圆半径 `R_MEC = D/sqrt{3}`，第三顶点落在直径圆之外，该顶点处张角 `60° < 90°`（归一化 `D = 1`，`gamma = 2/sqrt{3}`）。
>
> 覆盖的充要判据为：以直径端点 `P, Q` 为直径的圆覆盖 `L`，当且仅当 `L` 的**全部非直径端点顶点** `X` 满足 `∠PXQ >= 90°`（凸性保证只需检查顶点）。正确替代是最小覆盖圆，满足夹逼 `D/2 <= R_MEC <= D/sqrt{3}`，等价地 `1 <= gamma <= 2/sqrt{3}`，其中 `gamma = R_MEC/(D/2)`；**`gamma = 1` 当且仅当直径圆恰好覆盖 `L`**。
>
> 右下角方框为**两站基准算例的特例验证**：`S1=(0,0)`、`S2=(600,0)`，`D = 39.5983 m`，`R_MEC = 19.7992 m`，`gamma = 1.0000`，各顶点 `∠P2 X P4 = 118.0725° >= 90°`，故**该算例**被直径圆覆盖。**此为特例，不构成一般保证**；一般情形下 `gamma > 1`，直径圆不覆盖。
