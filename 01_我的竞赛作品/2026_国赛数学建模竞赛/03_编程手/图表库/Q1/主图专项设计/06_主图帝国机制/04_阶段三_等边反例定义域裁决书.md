## 1. 三个集合族及其判断

| 族 | 定义 | 等边三角形是否属内 | gamma 取值 |

## 2. 族 B 的四个子命题

### B-1 中心对称性：**不成立**（已证伪）

对凸四边形，中心对称 ⟺ 两条对角线互相平分。基准两站算例：

| 量 | 值 |
|---|---|
| 对角 `P1P3` 中点 | `(300.000000, 499.792881)` |
| 对角 `P2P4` 中点 | `(300.000000, 500.575993)` |
| 两点距离 | `0.783112` ≠ 0 |

故基准 `L` **不是中心对称的**。文档 B 的"中心对称的近似平行四边形"不成立。

**进一步（已证明）：族 B 中根本不存在平行四边形。** 四个边界线方向为 `theta_1 ± eps`、`theta_2 ± eps`；`L` 为平行四边形要求两对边分别平行，唯一可能是 `theta_2 ≡ theta_1 (mod 180°)`。但此时

- `theta_2 = theta_1`：四外法向仅两个方向，间隔 `182° > 180°` ⇒ `L` **无界**（数值确认：法向最大间隔 182.000°）；
- `theta_2 = theta_1 + 180°`：数值确认 `L` **为空**。

两种情形都不属于族 B（族 B 要求非空且有界）。30 万次抽样中族 B 的 47 892 个四边形里，平行四边形个数为 **0**。

### B-2 `gamma = 1`：**不成立**（已证伪）

在 50 位精度下确认的反例（浮点搜索 + 高精度复核）：

| 参数 | 值 |
|---|---|
| `phi`（S2 相对 S1 的方位） | `5.920050` rad |
| `theta_1` | `39.090274°` |
| `theta_2` | `129.153862°` |
| `eps` | `1°`（两站相同） |
| `D` | `0.0348995182` |
| `R_MEC` | `0.0174598978` |
| **`gamma`** | **`1.00058845064345962`** |

`gamma - 1 = 5.88e-4 > 0` 严格成立，且远大于高精度容差（`~1e-30`）。对应的最小非端点顶点角为 `88.047° < 90°`，与 Thales 判据一致（不覆盖 ⇒ `gamma > 1`）。

**但该偏差极小**：30 万抽样 + 60 起点爬山后，族 B 的 `gamma` 最大值仅在 `1.00059` 量级。故文档 B 的"数值上 gamma ≈ 1"作为**观察**是合理的，作为**断言**是错的。

### B-3 等边三角形不可达：**成立**（已证明）

**证明.** 设 `L = W_1 ∩ W_2` 是等边三角形 `T`。`L` 的每条边（facet）必落在某个 `W_i` 的一条边界线上，故 `T` 的三条边线取自四条线 `{ l_1^-, l_1^+, l_2^-, l_2^+ }`。由抽屉原理，其中两条来自同一楔形，设为 `l_j^-` 与 `l_j^+`；这两条线均过 `S_j`，且方向相差恰为 `2*eps = 2°`。而等边三角形任意两边（作为直线）夹角为 `60°`。`2° ≠ 60°`，矛盾。∎

**数值印证：** 20 万次抽样中族 B 的全部三角形（占比约 4.3%），其内角恒含一个 `2°` 角；最接近等边者为 `[68.9636°, 109.0364°, 2.0000°]`，与 `60°` 的最大偏离为 `58.000°`，从未接近 `0`。

**注：** 该证明**只对 n = 2 有效**，因为"抽屉原理给出两条边来自同一楔形"依赖楔形个数为 2。n >= 3 时该论证失效——这正是族 C 的反例得以存在的原因。

## 3. 族 C：等边三角形的显式构造（**已证明 + 已验证**）

### 3.1 构造

取边长 `side = 1` 的等边三角形 `ABC`（`A=(0,0)`, `B=(1,0)`, `C=(0.5, sqrt(3)/2)`），高 `h = sqrt(3)/2`。对**每条边**：

1. 把检测站放在该边**起点沿边方向后退 `back` 处**；
2. 令楔形的一条边界射线与该边**共线**，另一条（旋转 `+2*eps = +2°`）**转入三角形内部**。

**可行阈值（解析）：** 三角形相对该站的张角由对顶点 `C` 决定，`tan(angle) = h/(back + side/2)`；要求 `angle <= 2*eps`，得

```text
back >= h / tan(2*eps) - side/2 = 0.8660254038 / tan(2°) - 0.5 = 24.799723 - 0.5 = 24.299723
```

数值实验中交集恰好在 `back = 24.3` 从六边形退化为三角形，与解析阈值吻合。

### 3.2 判决证书（`back = 30`）

| 站 | 坐标 | `theta` | 两条边界射线方向 | 负责的边 |
|---|---|---|---|---|
| `S1` | `(-30.000000, 0.000000)` | `1.000000°` | `0.0000° / 2.0000°` | `AB`（方向 `0.0000°`） |
| `S2` | `(16.000000, -25.980762)` | `121.000000°` | `120.0000° / 122.0000°` | `BC`（方向 `120.0000°`） |
| `S3` | `(15.500000, 26.846788)` | `-119.000000°` | `-120.0000° / -118.0000°` | `CA`（方向 `-120.0000°`） |

- 三个楔形半角**均为** `eps = 1°`；
- 交集顶点数 = **3**，顶点为 `(0,0)`、`(1,0)`、`(0.5, 0.866025)`，与目标等边三角形的最大偏差 `5.3e-15`；
- `D = 1.0000000000`；
- `R_MEC = 0.5773502692 = 1/sqrt(3)`；
- **`gamma = 1.1547005384 = 2/sqrt(3)`**；
- 直径圆覆盖 = **False**。

### 3.3 推论

1. **等边三角形属于族 C**，故 `gamma = 2/sqrt(3)` 在族 C 中**可达**，文档 B 的 "`gamma <= 1.01`" 被直接证伪。
2. 由 Jung 定理 `R_MEC <= D/sqrt(3)` 即 `gamma <= 2/sqrt(3)`，故等边三角形取到**全局上界**。它不仅是一个反例，而是**极值构型**。
3. 因此族 C 的 `gamma` 值域为 `[1, 2/sqrt(3)]`，两端点：`1` 由两站基准算例取到（覆盖），`2/sqrt(3)` 由上述三等站构造取到（不覆盖）。

## 4. 主图表述的裁定

**裁定：采用「可作为题设区域族内的严格反例」，但必须附带量词条件。**

理由：题面为"若干检测点"的一般情形（路由文件 §6 亦以 `n` 个示向度定义输入，两站算例被明确标为"基准特例"），故题设区域族是 **C 而非 B**。既然等边三角形已被显式构造为 C 的成员（第 3 节），它就是**族内**的合法反例，而非仅对任意凸集成立的理论反例。

**但必须同时满足以下限定，否则该表述会被审稿人合法推翻：**

- 若论文把问题一限定为**恰好两站**，则等边三角形**不可达**（第 2 节 B-3），此时必须改用「只能作为任意凸多边形的理论反例」的表述；
- 无论哪种情形，主图与图注都必须写出 `n >= 3` 与**同半角** `eps` 这两个条件。

**必须从所有文档中删除的表述：**

1. "本题区域族内 `gamma <= 1.01`，等边三角形不可达"——已在 `n = 3` 处被构造反例证伪；
2. "两站角域交集是中心对称的近似平行四边形"——基准算例即非中心对称，且族 B 不含平行四边形；
3. "两站角域交集必有 `gamma = 1`"——已在高精度下证伪（`gamma = 1.0005884506`）。

## 5. 严谨的论文主结论（只用量词已证明的范围）

> **命题（一般否定结论）。** 设 `n >= 2` 个检测站 `S_i` 的示向度误差半角同为 `eps`，`W_i` 为相应前向角域，`L = ∩_{i=1}^{n} W_i` 非空、有界，`D` 为 `L` 的直径，`R_MEC` 为 `L` 的最小覆盖圆半径，`gamma = R_MEC/(D/2)`。则：
>
> 1. `D/2 <= R_MEC <= D/sqrt(3)`，即 `1 <= gamma <= 2/sqrt(3)`；
> 2. 以一组直径端点 `P, Q` 为直径的圆覆盖 `L`，当且仅当 `L` 的每个**非直径端点**顶点 `X` 满足 `angle PXQ >= 90°`；等价地，覆盖当且仅当 `gamma = 1`；
> 3. **当 `n >= 3` 时，以 `D` 为直径的圆不保证覆盖 `L`**：存在满足上述全部条件的构型使 `L` 为等边三角形，此时 `gamma = 2/sqrt(3)`，直径圆不覆盖（第 3 节构造）；
> 4. 两站基准算例 `gamma = 1.0000` 是该族内 `gamma = 1` 的一个实例，**不构成一般保证**。

**量词边界（必须在正文写清）：**

- 第 3 条**必须**带 `n >= 3`。对 `n = 2`，等边三角形不可达，该条的**构造性证明失效**；
- 对 `n = 2`，能证明的只是 `L` 为四边形（或退化为三角形）且非中心对称、非平行四边形，且 `gamma` 可严格大于 `1`（第 2 节 B-2），但 `gamma` 的上确界**未定**；
- 所有条目都以 `L` **非空且有界**为前提。

## 7. 可验证构造与证明线路（交给 Codex 做数值/符号检查）

**最短线路（族 C 反例，7 步）：**

1. 取 `A=(0,0)`、`B=(1,0)`、`C=(0.5, sqrt(3)/2)`；`h = sqrt(3)/2`。
2. 断言阈值 `back_min = h/tan(2*eps) - 0.5`，在 `eps = 1°` 时等于 `24.299723`（容差 `1e-6`）。
3. 对 `i = 0,1,2`：`P = T[i]`，`Q = T[(i+1) % 3]`，`u = (Q-P)/|Q-P|`；`S_i = P - back*u`；`theta_i = atan2(u_y, u_x) + eps`。
4. 取 `back = 30`，构造 `W_i = { S_i + t u(phi) : t >= 0, |phi - theta_i| <= eps }`。
5. 用半平面表示求交：`n_1 = (d_{1y}, -d_{1x})`、`n_2 = (-d_{2y}, d_{2x})`，`d_{1,2} = u(theta_i ∓ eps)`，约束 `n·(x - S_i) <= 0`；两两求交并用"属于全部半平面"过滤。
6. 断言：交集顶点数 == 3；顶点与 `{A, B, C}` 的最大偏差 `<= 1e-12`；`D == 1`；`R_MEC == 1/sqrt(3)`；`gamma == 2/sqrt(3)`；直径圆覆盖 == False。
7. 断言每条边与对应站的边界射线共线（方向差 `<= 1e-12`）。

**族 B 反例（`gamma > 1`）线路：**

1. `S1 = (0,0)`，`S2 = (cos phi, sin phi)`，`phi = 5.920050`。
2. `theta_1 = 39.090274°`，`theta_2 = 129.153862°`，`eps = 1°`。
3. 求交后断言：顶点数 == 4；`D = 0.0348995182`；`R_MEC = 0.0174598978`；**`gamma - 1 > 5e-4`**；最小非端点顶点角 `< 90°`。
4. 建议在 50 位精度实现该断言，浮点双精度下该值仍可分辨（偏差 `5.88e-4` 远大于容差）。

**族 B 等边不可达（符号检查）：**

- 断言：任一楔形的两条外法向夹角恒为 `2*eps + 180 = 182°`；
- 断言：`182 mod 360 ∉ {120, 240}`（容差 `1e-9`）；
- 由此等价于"等边三角形的三条外法向不可能由两个楔形提供"。

**关于文档 B 的数值实验：** 文档 B 以数值实验支持"本题区域族内 `gamma <= 1.01`"。该数值结论**与本次构造不矛盾**——因为它极可能只在 `n = 2` 的子族上采样，而反例位于 `n = 3`。这正说明：**未声明 `n` 的数值实验不能支撑关于"本题区域族"的一般断言**。本裁决的所有"已证明"条目均附解析构造或证明，不以抽样替代一般证明。
