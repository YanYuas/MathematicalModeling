# 阶段三：问题一“等边反例是否属于题设区域族”的定义域裁决

## 任务性质

你是独立的计算几何审稿人。不要设计图，不要讨论颜色和版式；请裁定一个会决定问题一主图主结论的数学范围问题。

## 题设模型

对每个检测站 `S_i`，有示向度 `theta_i` 与误差 `eps=1°`。允许位置集合为前向角域：

`W_i = { S_i + t u(phi) : t >= 0, |phi-theta_i| <= eps }`。

定位区域为 `L = intersection_i W_i`。只有当 `L` 非空且有界时，定义其直径 `D` 与最小覆盖圆半径 `R_MEC`。

## 已确认的任意凸集事实

对任意有界凸集：

- 以直径端点为直径的圆不保证覆盖；等边三角形是反例；
- `D/2 <= R_MEC <= D/sqrt(3)`；
- `gamma=R_MEC/(D/2)=1` 当且仅当存在以一组直径端点为直径的圆覆盖该集合；
- 对固定直径端点 `P,Q`，覆盖当且仅当每个非端点顶点 `X` 满足 `angle(PXQ)>=90°`。

这些事实不能自动推出等边三角形属于题设的角域交集族。

## 项目文档出现的冲突

- 文档 A 的口径：题目问“若干检测点”的一般情形，因此应给等边三角形反例，说明直径圆不保证覆盖。
- 文档 B 的强化口径：对于“两站、同一误差半角的角域交集”，区域是中心对称的近似平行四边形，`gamma=1`；等边三角形不可达。
- 文档 B 又曾把这一强化口径写成“本题区域族内 gamma<=1.01，等边三角形不可达”，但只提供数值实验，没有给出 n 任意时的证明。

## 请严格完成以下裁决

1. 区分三个集合族，并逐一判断：
   - A：任意有界凸多边形；
   - B：两个同半角前向角域的非空有界交集；
   - C：任意 n>=2 个同半角前向角域的非空有界交集。
2. 对 B 给出证明或反例：是否必有中心对称性、是否必有 `gamma=1`、等边三角形是否不可达？
3. 对 C 给出证明、构造反例或明确“不足以断言”。重点回答：能否选取检测站和中心方向，使 L 为等边三角形或使 `gamma>1`？
4. 判定“等边三角形反例”在问题一主图中应采用以下哪一表述：
   - 可作为题设区域族内的严格反例；
   - 只能作为任意凸多边形的理论反例，必须与题设角域族明确区分；
   - 不应使用。
5. 给出严谨的论文主结论，只允许使用已证明的量词范围。
6. 列出主图必须显示的前提条件：非空、有界、n 的范围、是否同半角等。
7. 提供最短的可验证构造或证明线路，供 Codex 实现数值/符号检查。

输出必须明确区分“已证明”“数值观察”“猜想”，不得以 20,000 次随机实验替代一般证明。
