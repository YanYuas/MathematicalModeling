# 问题一主图：Claude、DeepSeek、Codex 多模型协作提示词（v2）

## 统一事实卡（每个模型都必须先遵守）

这是数学建模论文问题一的两站角域定位案例，旧版“三站、五边形、S3”已经废弃，禁止复用。

- 观测站：`S1=(0,0)`，`S2=(600,0)`；真源：`G=(300,500)`。
- 角域：`Wi = W(Si, theta_i, eps)`，`eps=1 degree`；`theta1=59.036243 degree`，`theta2=120.963757 degree`。
- 可行域：`L=W1∩W2`，是四边形。
- 顶点：`P1=(288.1342,499.7929)`，`P2=(300.0000,480.7768)`，`P3=(311.8658,499.7929)`，`P4=(300.0000,520.3752)`。
- 直径端点：`P2,P4`；`D=39.5983 m`。
- 最小覆盖圆：`C*=(300.0000,500.5760)`，`R_MEC=19.7992 m`。
- 本例：`gamma=R_MEC/(D/2)=1.0000`，故 `R_MEC=D/2`；Jung 上界为 `D/sqrt(3)=22.8621 m`。

唯一目标：让读者不看代码也能追踪同一对象如何经历“测角约束 → 求交为 L → P2/P4 形成直径 → 最小覆盖圆结论”。

禁止：虚构 S3；五边形；手改数值；把 `D/sqrt(3)` 画成小于 `R_MEC` 的圆；把 G 当作测站；使用 `d_max` 或 `R*` 等与正文不一致的符号。

## 1. Claude：视觉方案竞赛提示词（最适合做创意结构）

你是一名数学建模论文的资深科学图表编辑。请基于“统一事实卡”为问题一提出 **3 个完全不同的信息组织方案**，目标是生成一张可投稿的论文主图，不是做装饰性信息图。

请只关注：读图路径、跨阶段对象追踪、主次层级、审稿风险和版式创新。不要改变数学事实，也不要写 Python 代码。

每个方案必须说明：
1. 一句话叙事结论；
2. 画布布局（给 ASCII 草图）；
3. 读图顺序；
4. `S1,S2,G,W1,W2,L,P1-P4,P2/P4,C*,D,R_MEC` 分别出现在哪里，如何保持身份连续；
5. 怎样避免“全景+局部放大”只是尺度因果、不是计算因果；
6. 会造成的审稿误读风险；
7. 最后按数学表达、创新性、单栏论文适配性、实现复杂度评分。

强制至少包含一个“上方通栏真实比例全景 + 下方阶段链”的方案、一个“约束逐层收缩”的方案、一个“几何证据链/数据卡”的方案。不要提出三站或五边形方案。

最后选出一个首选方案，给出不超过 12 条的版面规范。请将“纯生图模型的概念草图”和“最终可复现矢量论文图”严格区分。

## 3. Codex：融合与实现提示词（最适合最终落地）

你是负责最终交付的图表工程师。输入将包含 Claude 的视觉方案和 DeepSeek 的数学审核。请按以下顺序工作：

1. 先列出两份意见的共同点、冲突点和采用决策；
2. 只选择一个主图结构，写出一页可审阅的图表合同：核心结论、每个面板的证据职责、共享对象、图例语义、物理量单位；

实现限制：最终论文图必须用可复现矢量绘图生成。可以制作一张无文字、无数字的概念草图作版式探索，但不能把生成式图片作为包含数学结论的论文主图。
