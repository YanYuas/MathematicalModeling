## 一、怎么重新生成

```bat
cd 03_编程手\图表库\Q1\00_投稿集_v3.0
python q1_figures_v3.py                ← 生成全部 13 张
python q1_figures_v3.py --paper-only   ← 只生成正文 6 张（5.1-1~5 与 5.1-9）
```

**唯一入口是 `q1_figures_v3.py`**（503 行）。它：
1. 把 `source/` 加进 `sys.path`，`import q1_figures_legacy_clean as legacy`、`import q1_figures_beautified_v2 as fixed`；
2. 用 `prepare()` 把**统一调色板 / 线宽 / 600 dpi / 输出目录**注入这两个模块（行 118-127）；
3. 用 `paper_layout()` 临时抹掉旧图的图内标题、把过宽画布压到 8 英寸宽（行 130-164）；
4. 逐张生成，最后写 `图表清单_v3.json` 与 `核心图数值核验.json`。

**为什么是"注入"而不是"改脚本"**：历史出图脚本（`source/` 下 3 个）保留原样不动，
统一版式靠运行期打补丁实现 ⇒ **旧脚本仍能独立跑出旧版式**，这是有意的。

### 🚨 两个必须知道的陷阱

**陷阱 1：正文 图 5.1-2 ≠ `fig5_1_2_wedge_evolution`**
正文 **图 5.1-2 用的是 `fig5_1_10_geometry_construction`**（两站交会定位区域构造）。
`fig5_1_2_wedge_evolution`（角域构造演化）**也被生成、也留在库里，但正文没引用它**。
⇒ **按图注文字取图，不要按数字取图。**（这个坑在旧版就存在，`图表库/README.md` §四 也记过）

**陷阱 2：`fig5_1_9` 有**两份**定义，生效的是后者**
文件里行 ~390-408 定义了 `fig5_1_9_algorithm_flowchart()`（画流程图），
但**行 426 `fig5_1_9_algorithm_flowchart = lambda: redesigned.flowchart(save_figure)` 把它覆盖了**
⇒ **实际生效的是 `core_redesign.flowchart`**，行 390-408 那段是**死代码**。
同理被覆盖的还有 `fig5_1_1 / 5_1_3 / 5_1_4 / 5_1_10`（行 422-425）
⇒ 这 5 张图的**真正实现都在 `core_redesign.py`**，本文件里的同名函数都不生效。
**⇒ 要改这 5 张图，去改 `core_redesign.py`，改 `q1_figures_v3.py` 里的同名函数没用。**

### ⚠️ 数值口径：`39.598327` vs `39.597766` **不是 bug，别去"修"**

`核心图数值核验.json` 记 `D = 39.59832714358373 / R = 19.799163571791894`（**精确角口径**）。
项目的 MATLAB 断言侧打印 `D = 39.597766 / R_MEC = 19.798883`（**四舍五入角口径**）。

**两者都对**：`00_任务总控/权威数字表.md` §三 的口径说明（2026-09-11 补）已记录
—— 用四舍五入角 θ₁=59.036°、θ₂=120.964° 时顶点 y 变 480.772/499.788/520.370 ⇒ D=39.597766；
**两种口径的 D 都四舍五入为 39.598**，验证题容差 ±0.05 m 对两者都成立（差 0.00056 m）。
权威数字表登记的**头条值就是 `D = 39.598 m` / `R_MEC = 19.799 m`** ⇒ **本包与之一致**。
