## 五、纪律（沿用）

1. **图件的数值只能来自模型，不能反过来**（红线 **R9**）：本项目两次"数值编造"都发生在这里
   ——Q1 的 `np.random.beta` 伪造 γ 分布、Q2 v3.0 的硬编码流带宽度/玩具公式。
   "定性/简化"注释**不构成免责**。
   > ✅ **2026-09-13 入库的两套都过了 R9 核查**：Q1 v3 的源数据 SHA-256 与 `图表清单_v3.json` 一致、
   > `核心图数值核验.json` 的 D/R/γ 与权威数字表 §三 同口径；Q2 鲁棒性图集的 CSV 被脚本
   > `np.isclose` 断言钉死（改数据当场失败，不会静默出错图）。
   > 🔴 **但发现一处视觉缺陷**：图 5.1-8 的「基准」两字落进 mathtext ⇒ PNG/PDF 显示方框
   > —— 位置与修法见 `Q1/00_投稿集_v3.0/图源对应表.md` §五 第 4 条。**投稿前必修。**
2. **弃用图必须从交付目录移出并加标记**（`99_归档/废弃方案/`）。
3. **中文显示不得出现方框**：`✅/❌` 类 emoji 在微软雅黑/SimHei/DejaVu 中**都没有字形**；
   下标 `₁₂₃₄` 雅黑缺但 **DejaVu 有兜底**、不会方框（探测脚本见 `Q1/01_生图代码/_font_coverage_check.py`）。
4. 新增图件后**同步 `04_论文手/QX/配图/`**（论文侧副本）并更新 `QX/配图清单.md`。
