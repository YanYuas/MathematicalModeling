### 问题2：γ分布图表类型

**DeepSeek推荐**：✅ **Raincloud plot（雨云图）**

**理由**：
- 同时展示原始点、密度和箱线统计
- 适合有界分布\[1.0, 1.1547\]
- 避免KDE越界问题

**关键设计**：
1. 用`scipy.stats.gaussian_kde`对边界做反射
2. `ax.axvspan(1, 2/np.sqrt(3), alpha=0.12)`铺Jung窄带
3. 双箭头标注"夹逼厚度≈0.1547"
4. 配色：墨色点 + 赭石密度 + 浅灰背景
5. Inset显示ECDF或局部放大

---

### 问题3：参数空间可视化

**DeepSeek推荐**：✅ **2D热力图 + 分级等高线**

**理由**：
- θ₁-θ₂空间本质是周期环面
- 不可行区用灰+斜线，可行区用奶油→赭石渐变
- 边界用粗暗线+白色描边

**关键设计**：
1. `np.meshgrid`生成网格，计算可行标志与γ值
2. `np.ma.masked_where`屏蔽不可行区
3. `pcolormesh` + `contour`分级显示
4. Inset放大退化区（θ₁≈θ₂）
5. 注意0°/360°周期边界

## 🎨 最终设计方案

### Fig4：γ分布统计

**图表类型**：Raincloud plot + Jung窄带标注

**视觉策略**：
- 半小提琴（左侧）+ 抖动散点（中）+ 箱线图（右）
- Jung理论窄带\[1.0, 1.1547\]浅灰背景
- 双箭头标注"夹逼厚度0.1547"
- Inset显示ECDF累积分布

**配色方案**：
```python
点: PALETTE_A['ink']      # 墨色 #1C1C1C

```

**数据保留承诺**：
- 使用原始γ值数组，不做插值或平滑
- 反射KDE严格限制在\[1.0, 1.1547\]边界内

**数据保留承诺**：
- 使用q1_main.py计算的原始(φ, D)对
- 误差棒反映真实±1°角度误差传播

### Fig6：参数空间分类

**图表类型**：2D热力图 + 等高线 + 扇形剖面inset

**视觉策略**：
- 主图：θ₁-θ₂热力图（200×200网格）
- 不可行区：灰色 + 45°斜线hatch
- 可行区：奶油→赭石→深褐渐变
- 等高线：γ=1.05, 1.10标注性能分级
- Inset：固定θ₂−θ₁的扇形剖面，显示边界跃变

**配色方案**：
```python

不可行: PALETTE_A['slate'] + hatch='///'
边界线: PALETTE_A['ink'] + linewidth=2.5 + 白色描边
```

**数据保留承诺**：
- 网格计算基于q1_main.py的build_wedges逻辑
- 可行性判断使用原始凸包面积阈值
