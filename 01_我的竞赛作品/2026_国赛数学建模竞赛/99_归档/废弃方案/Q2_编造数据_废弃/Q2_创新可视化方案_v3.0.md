### 核心创新图（8张正文）

#### 图1：信息流Sankey图 - "两个信息缺口的级联效应" ⭐⭐⭐

**形式**：Sankey流图（信息流动可视化）

**设计**：
```
[完美信息]
    ├─ [源距已知] (d₁=752.5 m) ──→ [φ可达90°] ──→ [E极小]
    │       ↓ Δd=747.5 m不确定
    ├─ [源距未知] ──→ [φ上限41.63°] ──→ [E增大]
    │       ↓ α∈[-1°,1°]不确定
    └─ [双重不确定] ──→ [φ上限39.616°] ──→ [空集/零裕度]
                              ↓ 代价-2.01°
                         [可行域收缩]
```

**技术**：
- 工具：`plotly`（交互式）或`matplotlib_sankey`
- 宽度编码信息量损失
- 颜色渐变：绿→黄→红（信息丰富→稀缺）

**创新点**：
- 首次用流图展示"信息级联效应"
- 直观展示φ_max从90°→41.63°→39.616°的三级衰减
- 可视化"两个信息缺口"的概念

#### 图2：参数空间热力图 - "可行域的崩塌" ⭐⭐⭐

**形式**：2D热力图 + 等高线 + 动画序列

**设计**：
```
4帧动画序列（2×2网格）：

Frame 1: α=0°（理想基准）
  - 热力图：(a, b)平面，颜色编码φ值
  - 可行域：大片绿色区域（φ≥40°）
  - 等高线：φ=40°, 45°, 50°, 60°, 90°

Frame 2: α=±0.5°（轻微鲁棒）
  - 可行域收缩至狭长条带
  - 颜色从绿色变为黄色

Frame 3: α=±0.9°（临界边缘）
  - 可行域几乎消失
  - 仅剩细线，颜色橙色

Frame 4: α=±1°（完全鲁棒）
  - 零裕度定点：单个红色像素
  - 标注：(764, 651)
  - 叠加：空集区域（灰色网格纹理）
```

**技术**：
- `seaborn.heatmap` + `matplotlib.contour`
- `matplotlib.animation.FuncAnimation`生成GIF
- 颜色：`viridis`渐变（绿→黄→紫）

**创新点**：
- 动画展示可行域"崩塌"过程
- 热力图+等高线双重编码
- 视觉冲击力强（大→小的动态变化）

#### 图3：小提琴图 - "φ分布的α敏感性" ⭐⭐

**形式**：Violin Plot（小提琴图）

**设计**：
```
x轴：α值（-1°, -0.5°, 0°, +0.5°, +1°）
y轴：φ可达范围（度）

每个α值对应一个"小提琴"：
- 小提琴宽度：φ的分布密度
- 中位线：φ中位数
- 箱体：25%-75%分位
- 须线：最小-最大值

颜色编码：
- α=0：绿色（宽胖小提琴，分布广）
- α=±0.5°：黄色（收窄）
- α=±1°：红色（极窄，接近线段）
```

**技术**：
- `seaborn.violinplot`
- 数据：对每个α，在(a,b)网格上采样1000个点的φ值

**创新点**：
- 统计分布可视化（不只是单点）
- 直观展示"分布收缩"而非"点退化"
- 符合独立审核建议："连续收缩无突变"

---

#### 图4：径向图 - "360°全方位布站策略" ⭐⭐⭐

**形式**：极坐标图（Polar Plot）

**设计**：
```
极坐标系：
- 角度：S₂相对S₁的方位角θ（0°-360°）
- 半径：最优距离r（m）

曲线：
1. 蓝色实线：α=0时的最优r(θ)
2. 橙色虚线：α=±1°时的最优r(θ)
3. 绿色区域填充：可行距离范围

特殊标注：
- θ=90°：最优方向（正侧方）
- θ=0°/180°：退化方向（共线）
```

**技术**：
- `matplotlib.pyplot.polar`
- 半径计算：r = √(R² - d₁²·sin²θ)

**创新点**：
- 极坐标天然适合"方位选择"问题
- 360°视角，空间感强
- 视觉隐喻："雷达扫描"

---

#### 图5：瀑布图 - "φ_max的逐级衰减" ⭐⭐

**形式**：Waterfall Chart（瀑布图）

**设计**：
```
x轴：信息条件
  1. 完美信息
  2. 源距已知
  3. 源距未知（Δd=747.5）
  4. 示向度误差（α=±1°）
  5. 双重不确定

y轴：φ_max（度）

柱子：
  1. 90°（绿色，基准）
  2. -48.4° → 41.6°（黄色下降段）
  3. -2.0° → 39.6°（红色下降段）

连接线：瀑布流动效果
```

**技术**：
- 自定义`matplotlib`绘制或`plotly.graph_objects.Waterfall`

**创新点**：
- 瀑布图天然适合"逐级损失"叙事
- 量化每个信息缺口的代价
- 视觉隐喻："信息瀑布"

#### 图6：树状图 - "决策树：目标角vs可行性" ⭐⭐

**形式**：决策树（Decision Tree Diagram）

**设计**：
```
根节点：φ_min目标设定
  ├─ φ=42° → [不可行] (❌ 空集)
  ├─ φ=40° → [临界] (⚠️ 同口径空集)
  ├─ φ=39.616° → [零裕度] (⚠️ 单点)
  ├─ φ=39° → [可行] (✓ 17 m²)
  ├─ φ=38° → [宽松] (✓ 310 m²)
  └─ φ=35° → [富余] (✓ 1200 m²)

每个分支标注：
- 可行域面积（m²）
- 布站自由度等级
```

**技术**：
- `graphviz`或`networkx` + `matplotlib`
- 颜色：红（不可行）→橙（临界）→绿（可行）

**创新点**：
- 决策树直观展示"目标角-裕度权衡"
- 对照独立审核建议："可查表结论"
- 实用性强（工程师可直接使用）

#### 图7：等高线叠加图 - "E景观+约束边界" ⭐

**形式**：多层叠加（Contour + Overlay）

**设计**：
```
底层：E等高线（地形图风格）
  - 颜色：terrain色谱（蓝→绿→黄→红）
  - 等高线：15级密集
  - 标注：E=15, 18, 21, ...

中层：约束边界
  - φ≥40°：粗红色虚线
  - d₂≤1000：粗橙色虚线
  - 交集区域：半透明绿色填充

顶层：关键点
  - 理论最优：(752.5, b_opt)，绿色五角星
  - 零裕度定点：(764, 651)，橙色圆圈
  - 采样点网格：灰色小点（展示搜索密度）
```

**技术**：
- `matplotlib.contourf` + `fill_between`
- 透明度层次：alpha=1.0→0.6→0.3

**创新点**：
- 地形图隐喻："E景观"
- 多层信息叠加，信息密度高
- 展示"约束交集"的几何直观

#### 图8：Parallel Coordinates - "参数空间高维投影" ⭐⭐

**形式**：平行坐标图（Parallel Coordinates）

**设计**：
```
轴（从左到右）：
  1. Δd（源距不确定度，m）
  2. φ_min（目标角，度）
  3. R（探测范围，m）
  4. φ_max（可达上界，度）
  5. 可行性（0=空集, 1=可行）

每条线：一组参数配置
  - 颜色：根据可行性（红=不可行，绿=可行）
  - 透明度：alpha=0.3（180条线叠加）
  - 高亮：验证题配置（粗黄色线）
```

**技术**：
- `plotly.express.parallel_coordinates`
- 数据：180组参数扫描结果

**创新点**：
- 高维数据降维可视化
- 一图展示180组实验
- 可交互筛选（Plotly支持）
- 参考[arxiv.org高维参数空间](https://arxiv.org/html/2204.13812v1)

#### 图9：Chord Diagram - "约束之间的相互作用" ⭐

**形式**：和弦图（Chord Diagram）

**设计**：
```
节点（圆周上）：
  - θ₁已知
  - α不确定
  - d₁未知
  - φ≥40°约束
  - d₂≤1000约束

连线（和弦）：
  - α不确定 → φ约束：粗红线（强耦合）
  - d₁未知 → d₂约束：粗橙线
  - θ₁ → α：细蓝线
  
宽度编码：约束紧密程度
```

**技术**：
- `holoviews.Chord`或`circos`（需R接口）

**创新点**：
- 和弦图展示"约束网络"
- 视觉隐喻："多方牵制"
