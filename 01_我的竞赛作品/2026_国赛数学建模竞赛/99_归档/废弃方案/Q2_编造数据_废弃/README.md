## 三、⚠️ 图形式借鉴评估（**取形式、绝不取数值**）

> 用户指示："图的形式可以借鉴"。**但"可以借鉴"是有条件的** —— 逐形式评估如下：

| 形式 | 可借鉴？ | 理由与改法 |
|---|---|---|
| **决策树 / 流程图** | ✅ **可用** | 只是结构表达，不承载数值。用**本队真实的判据**（`R_MEC ≤ 20` 直接 / `≤ 84.0369` 扫掠 / 否则 homing）重画即可。 |
| **瀑布图** | ✅ **推荐** | 审核建议：表达"信息缺口级联"用**两段式瀑布图**（`90° → 41.63° → 39.6161°`），**数值真实**且可核。 |
| **表（查表式结论）** | ✅ **推荐** | 审核给出的真实落地结论：目标角 `39.5° → 可行域 ≈17 m²`、`39.0° → ≈310 m²`、`38.0° → ≈1276 m²`（1 m 网格）；`39.6161° → 单点`。**可直接进论文**（我方口径一致）。 |
| **热力图 + 等高线融合** | ⚠️ **形式可用，须重算** | 形式没问题；但必须用**真 E 公式** `E = ε·√(d₁²+d₂²)·d₂/\|b\|`，且 `r` 取 `{5,1500}` 端点、`α` 取 `[−ε,ε]` 的**最坏**。 |
| **小提琴图（分布）** | ⚠️ **形式可用，须真采样** | 必须由**真实参数分布**（如全域 `R_MEC` 抽样）驱动，**不得用 `uniform` 拼一个"看起来像分布"的形状**。 |
| **平行坐标** | ⚠️ **可用，须真数据** | 需真实多维参数扫描结果（本队已有 180 例参数扫描 CSV 可用）。 |
| **Sankey 流图** | ❌ **不适用本题** | 审核要点：① Sankey 的前提是**流量守恒**，而"信息缺口"**不是守恒量**；② 本图的流带宽度是**硬编码常量**，属"图表说谎"。⇒ 改用**瀑布图**。 |

**结论**：**可借鉴的是"版式与叙事结构"，不是"数值与比例"**。
若采纳任一形式，**必须用 `03_编程手/Q2/代码/` 的权威脚本重出**，并逐图核对数值与
`00_任务总控/权威数字表.md` §四 一致。
