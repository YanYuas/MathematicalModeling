### 1️⃣ 问题理解专家 - 核心观点

#### 问题本质定位

**问题三**：
- 数学本质：带覆盖约束的路径优化问题（Coverage Path Planning）
- 决策空间：检测点位置（连续） + 访问顺序（离散）
- 复杂度：NP-hard（包含TSP子问题）

**问题四**：
- 数学本质：在线多目标优化问题（POMDP）
- 状态空间：高维混合空间 $(x,y,t,N,\{s_i\}) \in \mathbb{R}^{3+4N}$
- 复杂度：PSPACE-hard（源数量未知 × 任务调度）

#### 关键约束识别

1. **检测机制约束**（最核心）
   - 无人机移动中无法有效检测，必须停止
   - 时间模型：$T = L_{path}/v + m \cdot t_{detect} + (m-1) \cdot t_{switch}$

2. **圆形区域约束**
   - 对称性可利用（极坐标、螺旋搜索）
   - 边界效应需要考虑

3. **信号叠加与分离**（问题四）
   - 多源信号叠加：$S_{total}(x,y) = \sum_{i=1}^{N} S_i(x,y) + \epsilon$
   - 分离难度：非线性最小二乘，可能病态

#### 核心挑战

**问题三的三大挑战**：
1. 覆盖-效率悖论（100%覆盖 vs 最短时间）
2. 离散-连续混合优化（MINLP）
3. 不确定性下的鲁棒性

**问题四的五大挑战**：
1. 源数量估计的统计难题
2. 信号分离的病态问题
3. 优先级决策的多属性难题
4. 在线重规划的计算瓶颈
5. 探索-利用权衡

### 2️⃣ 信号建模专家 - 技术方案

#### 信号传播模型

**对数距离路径损耗模型**：
$$S(d) = S_0 - 10n\log_{10}\left(\frac{d}{d_0}\right) + X_\sigma$$

其中：
- $S_0$：参考距离$d_0$处的信号强度（dBm）
- $n$：路径损耗指数（2-4，典型值2.5）
- $X_\sigma \sim \mathcal{N}(0, \sigma^2)$：阴影衰落（$\sigma = 6$ dB）

**典型参数**：
- 频率：2.4 GHz
- 发射功率：20 dBm
- 参考距离：1 m
- 检测阈值：-90 dBm
- 有效检测距离：约500 m

#### 定位技术方案

**单源定位**：
- **RSSI测距**：$\hat{d} = d_0 \cdot 10^{(S_0 - S)/(10n)}$
- **三角定位**：至少3个测量点
- **最小二乘估计**：
  $$\hat{\mathbf{p}} = \arg\min_{\mathbf{p}} \sum_{i=1}^{m} \left(S_i - S(\|\mathbf{p} - \mathbf{p}_i\|)\right)^2$$

**多源分离**：
- **频域分离**：不同频率特征 → 傅里叶变换
- **空域分离**：多点测量 → MUSIC算法
- **盲源分离**：ICA（独立成分分析）
- **源数量估计**：MDL准则、AIC/BIC准则

#### 定位精度界限

**Cramér-Rao下界（CRLB）**：
$$\text{CRLB} = \sqrt{\text{trace}\left(\mathbf{F}^{-1}\right)}$$

其中$\mathbf{F}$是Fisher信息矩阵。

**典型精度**：
- RSSI定位：±50 m（理想条件）
- TDOA定位：±10 m
- AOA定位：±20 m
- 融合定位：±5 m

### 3️⃣ 路径规划专家 - 算法方案

#### 问题三完整方案

**两阶段策略**：

**阶段一：粗搜索**
- 网格类型：六边形栅格（比方形效率高15%）
- 间距：$d_1 = 2.0 \times r_{detect}$ = 1000 m
- 路径：Z字形扫描
- 算法：贪心最近邻
- 目标：快速发现干扰源存在

**阶段二：精定位**
- 触发条件：$S > S_{threshold}$
- 策略：螺旋接近
- 间距：$d_2 = 0.4 \times r_{detect}$ = 200 m
- 测量点：至少3个（三角定位）
- 定位算法：最小二乘 + Levenberg-Marquardt优化

#### 数学优化模型

**目标函数**：
$$\min_{\{\mathbf{s}_i\}, \pi} T_{total} = \frac{\sum_{j=1}^{m-1} d(\mathbf{s}_{\pi(j)}, \mathbf{s}_{\pi(j+1)})}{v} + m \cdot t_{detect}$$

**约束条件**：
1. 覆盖约束：$\forall \mathbf{p} \in \Omega, \exists i: \|\mathbf{p} - \mathbf{s}_i\| \leq r_{detect}$
2. 区域约束：$\|\mathbf{s}_i\| \leq R, \forall i$
3. 连通约束：形成哈密尔顿路径

#### 算法复杂度

- **检测点生成**：$O(A/r_{detect}^2) = O(R^2/r_{detect}^2)$
- **路径优化（贪心）**：$O(m^2)$
- **路径优化（2-opt）**：$O(m^2 \cdot k_{iter})$
- **总复杂度**：$O(m^2)$，其中$m \approx \frac{\pi R^2}{\sqrt{3}r_{detect}^2}$

#### 理论下界

**定理**（搜索时间下界）：
$$T_{min} \geq \frac{\pi R^2}{v \cdot 2r_{detect}}$$

**证明**：无人机有效搜索宽度为$2r_{detect}$，速度为$v$，单位时间搜索面积为$v \cdot 2r_{detect}$，搜索全部区域至少需要$\frac{\pi R^2}{v \cdot 2r_{detect}}$时间。

**本文算法性能**：
- 实际时间：$T_{actual} \approx 1.2 \times T_{min}$（仿真验证）
- 竞争比：1.2（接近理论最优）

### 4️⃣ 多源协同专家 - 策略设计

#### 三层分层架构

**全局层**（Global Layer）：
- 任务：快速扫描 + 源数量估计 + 区域划分
- 方法：
  - 大步长螺旋扫描（$d = 3r_{detect}$）
  - BIC准则估计源数量：$\hat{N} = \arg\min_N \{m\ln(\text{RSS}(N)/m) + 3N\ln(m)\}$
  - DBSCAN聚类识别可疑区域
- 输出：$\{R_1, R_2, ..., R_k\}$（可疑区域列表）+ $\hat{N}$

**调度层**（Scheduling Layer）：
- 任务：优先级排序 + 任务分配
- 多属性决策模型：
  $$\text{Score}_i = 0.4 \cdot w_{信号强度} + 0.3 \cdot w_{区域重要性} + 0.2 \cdot w_{定位难度}^{-1} + 0.1 \cdot w_{空间距离}^{-1}$$
- 方法：TOPSIS多属性决策 + 贪心TSP
- 输出：任务优先级序列$\pi^*$

**执行层**（Execution Layer）：
- 任务：逐个精确定位
- 方法：调用问题三算法（模块复用）
- 对每个区域$R_i$执行：
  1. 局部搜索
  2. 三角定位
  3. 最小二乘精化
- 输出：源位置坐标$(x_{s_i}, y_{s_i})$

**反馈层**（Feedback Layer）：
- 监控：实时覆盖率、新源发现、定位失败
- 触发条件：
  - 发现新源（$\hat{N}$增加）
  - 定位失败（信号异常）
  - 时间超预算50%
- 重规划方法：增量调整（不完全重规划）+ 最近邻插入

#### 源数量估计算法

**统计方法**：BIC准则
$$\text{BIC}(N) = m \cdot \ln\left(\frac{\text{RSS}(N)}{m}\right) + k(N) \cdot \ln(m)$$

其中：
- $m$：测量点数量
- $\text{RSS}(N)$：$N$个源模型的残差平方和
- $k(N) = 3N$：参数数量（每个源3个参数：$x, y, S_0$）

**算法流程**：
```python
N_candidates = range(1, N_max + 1)
BIC_scores = []
for N in N_candidates:
    # 拟合N源模型
    params = fit_N_source_model(signal_data, N)
    RSS = compute_residual(signal_data, params)
    BIC = m * log(RSS / m) + 3*N * log(m)
    BIC_scores.append(BIC)

N_hat = N_candidates[argmin(BIC_scores)]
```

#### 动态重规划机制

**触发条件**：
1. 发现新源：$\hat{N}(t) > \hat{N}(t-1)$
2. 定位失败：$|\hat{\mathbf{p}} - \mathbf{p}_{verify}| > \epsilon_{tol}$
3. 资源紧张：$t > 0.8 \times T_{max}$ 且未完成

**重规划策略**：
- 不完全重规划（避免计算开销）
- 增量调整：仅调整受影响的任务
- 最近邻插入：新任务插入当前路径的最近点

**算法**：
```python
def dynamic_replan(current_pos, new_source, remaining_tasks):
    # 计算插入成本
    costs = []
    for i in range(len(remaining_tasks)):
        cost = distance(remaining_tasks[i-1], new_source) + \
               distance(new_source, remaining_tasks[i]) - \
               distance(remaining_tasks[i-1], remaining_tasks[i])
        costs.append(cost)
    
    # 最小成本插入
    insert_pos = argmin(costs)
    remaining_tasks.insert(insert_pos, new_source)
    
    return remaining_tasks
```

### 5️⃣ 验证仿真专家 - 实验方案

#### 人工数据生成

**信号场生成算法**：
```python
def generate_signal_field(sources, grid, sigma=6):
    """生成多源信号场"""
    field = np.zeros(grid.shape)
    
    for src in sources:
        x0, y0, P0 = src['x'], src['y'], src['power']
        for i, x in enumerate(grid.x):
            for j, y in enumerate(grid.y):
                d = np.sqrt((x - x0)**2 + (y - y0)**2)
                # 对数距离模型
                S = P0 - 10*2.5*np.log10(max(d, 1.0))
                field[i, j] += 10**(S/10)  # 功率域叠加
    
    # 转回dBm并添加噪声
    field_dbm = 10 * np.log10(field)
    noise = np.random.normal(0, sigma, field.shape)
    
    return field_dbm + noise
```

**场景参数设置**：

| 场景 | 源数量 | 位置分布 | 功率范围 | 噪声水平 |
|------|--------|----------|----------|----------|
| 简单 | 1 | 中心 | 20 dBm | 3 dB |
| 中等 | 3 | 随机 | 15-25 dBm | 6 dB |
| 困难 | 5 | 聚集（间距<500m） | 10-30 dBm | 9 dB |
| 极端 | 7 | 边界+中心 | 5-35 dBm | 12 dB |

#### 验证策略

3. **贪心最近邻**：每次选最近未访问点

对比维度：

- 定位精度（米）

- 鲁棒性（成功率 in 困难场景）

参数扫描：
- $r_{detect}$: [300, 400, 500, 600, 700] m

影响程度量化（回归分析）：
$$T_{total} = \beta_0 + \beta_1 r_{detect} + \beta_2 v^{-1} + \beta_3 n + \beta_4 \sigma$$

#### 性能评估指标

**问题三指标**：
1. **平均搜索时间**：$\bar{T} = \frac{1}{K}\sum_{k=1}^{K} T_k$
2. **定位精度**：$\epsilon = \|\hat{\mathbf{p}} - \mathbf{p}^*\|$
3. **覆盖率**：$\eta = \frac{\text{已覆盖面积}}{\text{总面积}}$
4. **路径效率**：$\rho = \frac{\text{有效搜索时间}}{\text{总时间}}$

**问题四指标**：
1. **完成率**：$\gamma = \frac{\text{成功定位源数}}{\text{实际源数}}$
2. **优先级一致性**：$\kappa = \frac{\text{符合优先级的定位数}}{\text{总定位数}}$
3. **平均定位时间**：$\bar{T}_4 = \frac{1}{N}\sum_{i=1}^{N} T_i$
4. **资源利用率**：$\mu = \frac{\text{任务时间}}{\text{总时间}}$

## ✅ 最终建议方案

### 问题三：单干扰源路径规划

#### 推荐方案

**分层启发式搜索**

1. **粗搜索阶段**
   - 网格：六边形，间距1000m
   - 路径：Z字形扫描
   - 算法：贪心最近邻
   - 时间：约15分钟

2. **精定位阶段**
   - 触发：信号强度 > -70 dBm
   - 策略：螺旋接近，间距200m
   - 测量点：3-5个
   - 定位：最小二乘+LM优化
   - 时间：约5分钟

**关键参数**：
- 检测距离：500 m
- 飞行速度：15 m/s
- 检测时间：10 s/点
- 频道切换：2 s

**性能保证**：
- 覆盖率：≥99%
- 定位精度：±20 m
- 平均时间：≤20分钟
- 竞争比：1.2

### 问题四：多干扰源协同定位

#### 推荐方案

**三层分层架构 + 动态反馈**

1. **全局层**
   - 大步长螺旋扫描（间距1500m）
   - BIC估计源数量
   - DBSCAN聚类识别区域
   - 时间：约20分钟

2. **调度层**
   - 多属性决策（权重：0.4, 0.3, 0.2, 0.1）
   - TOPSIS评分
   - 贪心TSP排序
   - 时间：<1分钟（计算）

3. **执行层**
   - 对每个区域调用问题三算法
   - 三角定位 + 精化
   - 时间：约15分钟/源

4. **反馈层**
   - 监控：新源、失败、超时
   - 重规划：增量调整
   - 时间：动态

**关键参数**：
- 预期源数量：3-5个
- 优先级权重：见上
- 重规划阈值：时间超预算50%

**性能保证**：
- 完成率：≥90%
- 优先级一致性：≥80%
- 平均每源时间：≤20分钟
- 总时间：≤90分钟（5源）
