# 问题三：单干扰源无人机巡航路径规划 - 初步建模框架

## 一、问题分析

### 1.1 问题描述
设计无人机巡航路径规划方案，使得能够快速发现并定位干扰源，给出最优巡航路线。

### 1.2 核心目标
- **主目标**：最小化发现干扰源的时间
- **次要目标**：最小化飞行路径长度，最大化搜索效率

### 1.3 关键约束
1. 无人机性能约束（速度、续航、机动性）
2. 检测设备约束（探测距离、信号衰减）
3. 环境约束（搜索区域边界、禁飞区）
4. 定位精度要求

## 二、符号定义

### 2.1 空间与坐标
- $\Omega \subset \mathbb{R}^2$：搜索区域
- $(x, y)$：平面坐标
- $(x_s, y_s)$：干扰源真实位置（未知）
- $(x_u(t), y_u(t))$：无人机在时刻 $t$ 的位置
- $\mathcal{P} = \{P_1, P_2, ..., P_n\}$：路径航点序列

### 2.2 信号与检测
- $S(d)$：距离为 $d$ 时的信号强度
- $R_{det}$：有效检测距离
- $\sigma$：测量噪声标准差
- $P_{det}(d)$：距离为 $d$ 时的检测概率

### 2.3 无人机参数
- $v$：巡航速度（常数或变速）
- $v_{max}$：最大速度
- $r_{min}$：最小转弯半径
- $T_{max}$：最大飞行时间（续航限制）
- $E_{total}$：总能量预算

### 2.4 时间相关
- $T_{search}$：搜索时间
- $T_{locate}$：定位时间
- $T_{total} = T_{search} + T_{locate}$：总时间

## 三、数学模型构建

### 3.1 信号传播模型

#### 自由空间路径损耗模型（FSPL）
$$S(d) = S_0 - 10n\log_{10}\left(\frac{d}{d_0}\right) + \epsilon$$

其中：
- $S_0$：参考距离 $d_0$ 处的信号强度
- $n$：路径损耗指数（通常 $n \in [2, 4]$）
- $\epsilon \sim \mathcal{N}(0, \sigma^2)$：测量噪声

#### 检测概率模型
$$P_{det}(d) = \begin{cases}
1 & d \leq R_{det} \\
e^{-\alpha(d - R_{det})} & d > R_{det}
\end{cases}$$

### 3.2 覆盖模型

#### 圆形覆盖模型
无人机在位置 $(x_u, y_u)$ 时，覆盖区域为：
$$C(x_u, y_u) = \{(x,y) \in \Omega : \|(x,y) - (x_u, y_u)\| \leq R_{det}\}$$

#### 累积覆盖率
$$\text{Coverage}(t) = \frac{\text{Area}\left(\bigcup_{t'=0}^{t} C(x_u(t'), y_u(t'))\right)}{\text{Area}(\Omega)}$$

### 3.3 路径规划优化模型

#### 模型一：最短时间模型

**目标函数**：
$$\min_{{\mathcal{P}}} T_{total} = T_{search} + T_{locate}$$

**约束条件**：
1. 路径连续性：$\|P_{i+1} - P_i\| \leq v \cdot \Delta t$
2. 边界约束：$P_i \in \Omega, \forall i$
3. 覆盖约束：$\text{Coverage}(T_{search}) \geq \theta$ （覆盖阈值）
4. 能量约束：$\sum_{i=1}^{n-1} \|P_{i+1} - P_i\| \leq v \cdot T_{max}$

#### 模型二：贝叶斯概率更新模型

定义概率密度函数 $p(x_s, y_s | \text{observations})$ 表示干扰源位置的后验概率。

**贝叶斯更新**：
$$p(x_s, y_s | S_1, ..., S_t) \propto p(S_t | x_s, y_s) \cdot p(x_s, y_s | S_1, ..., S_{t-1})$$

**信息增益**：
$$I(P_i) = H[p(x_s, y_s | S_1, ..., S_{i-1})] - \mathbb{E}[H[p(x_s, y_s | S_1, ..., S_i)]]$$

**目标函数**：
$$\max_{\mathcal{P}} \sum_{i=1}^{n} I(P_i) - \lambda \cdot T_{total}$$

## 四、求解策略

### 4.1 搜索模式分类

#### 4.1.1 预定路径搜索
- **栅格扫描**（Grid Search）：S型、弓字型路径
- **螺旋搜索**（Spiral Search）：由外向内或由内向外
- **扇形扫描**（Sector Search）：扇区分割覆盖

**优点**：实现简单，覆盖保证
**缺点**：不利用实时信息，效率可能较低

#### 4.1.2 自适应搜索
- **梯度下降法**：沿信号强度梯度方向移动
- **爬山算法**：局部搜索最优
- **信息熵引导**：向不确定性最高区域移动

**优点**：利用实时信息，效率高
**缺点**：可能陷入局部最优

#### 4.1.3 混合策略
- **粗搜索+细定位**：先快速覆盖，发现信号后精确定位
- **多尺度搜索**：大步长初搜，小步长精搜

### 4.2 优化算法

#### 4.2.1 图搜索算法
- 将搜索区域离散化为网格图
- 使用 A* 或 Dijkstra 算法规划路径
- 启发函数设计：未覆盖区域的距离

#### 4.2.2 动态规划
- 状态：$(x, y, t, \text{CoveredArea})$
- 转移：可能的移动方向
- 价值函数：负时间或信息增益

#### 4.2.3 智能优化算法
- **遗传算法**：编码为航点序列，交叉变异生成新路径
- **粒子群算法**：粒子表示路径方案，全局最优引导
- **蚁群算法**：信息素指导路径选择

### 4.3 两阶段求解框架

#### 阶段一：搜索阶段（Search Phase）
**目标**：快速发现干扰源存在
**方法**：
1. 高速巡航，大范围覆盖
2. 持续监测信号强度
3. 判断准则：$S > S_{threshold}$

#### 阶段二：定位阶段（Localization Phase）
**目标**：精确确定干扰源位置
**方法**：
1. 在多个位置测量信号强度和方向
2. 三角定位或最小二乘估计
3. 精度验证：$\|\hat{x}_s - x_s\| < \epsilon_{tol}$

**数学表述**：
$$\hat{x}_s, \hat{y}_s = \arg\min_{x,y} \sum_{i=1}^{m} \left(S_i - S(d_i)\right)^2$$

其中 $d_i = \|(x,y) - (x_{u,i}, y_{u,i})\|$，$m$ 为测量点数量。

## 五、模型假设（在无数据情况下）

### 5.1 基本假设
1. 搜索区域为矩形：$\Omega = [0, L_x] \times [0, L_y]$
2. 干扰源位置固定不变
3. 无人机高度恒定，简化为二维问题
4. 信号各向同性传播
5. 环境中无障碍物

### 5.2 参数假设（示例）
| 参数 | 符号 | 假设值 | 说明 |
|------|------|--------|------|
| 搜索区域 | $L_x \times L_y$ | $10 \text{km} \times 10 \text{km}$ | 典型监控区域 |
| 无人机速度 | $v$ | $15 \text{ m/s}$ | 巡航速度 |
| 检测距离 | $R_{det}$ | $500 \text{ m}$ | 有效探测半径 |
| 路径损耗指数 | $n$ | $2.5$ | 半开放环境 |
| 续航时间 | $T_{max}$ | $30 \text{ min}$ | 电池容量 |

### 5.3 灵敏度分析准备

## 六、性能评估指标

### 6.1 时间指标
- **平均搜索时间** $\mathbb{E}[T_{search}]$
- **定位时间** $T_{locate}$
- **总任务时间** $T_{total}$

### 6.2 路径指标
- **路径总长度** $L_{path} = \sum_{i=1}^{n-1} \|P_{i+1} - P_i\|$
- **路径平滑度** $\sum_{i=1}^{n-2} \|\theta_{i+1} - \theta_i\|$ （航向角变化）

### 6.3 效率指标
- **覆盖效率** $\eta = \frac{\text{CoveredArea}}{L_{path}}$
- **单位时间覆盖率** $\frac{\text{CoveredArea}}{T_{search}}$

### 6.4 精度指标
- **定位误差** $\epsilon = \|(\hat{x}_s, \hat{y}_s) - (x_s, y_s)\|$
- **定位成功率** $P_{success} = P(\epsilon < \epsilon_{tol})$

```python
# 主算法：无人机巡航路径规划
def UAV_Search_And_Localize(Omega, R_det, v, T_max):
    # 初始化
    current_pos = initial_position()
    signal_detected = False
    time = 0
    
    # 阶段一：搜索
    search_path = generate_search_path(Omega, R_det, strategy='adaptive')
    
    for waypoint in search_path:
        # 移动到航点
        current_pos = move_to(waypoint, v)
        time += distance(current_pos, waypoint) / v
        
        # 检测信号
        signal_strength = measure_signal(current_pos)
        
        if signal_strength > threshold:
            signal_detected = True
            break
        
        if time > T_max:
            return "Search Timeout"
    
    # 阶段二：定位
    if signal_detected:
        measurement_points = plan_measurement_positions(current_pos, R_det)
        signal_measurements = []
        
        for point in measurement_points:
            current_pos = move_to(point, v)
            signal = measure_signal_and_direction(current_pos)
            signal_measurements.append(signal)
        
        # 定位计算
        estimated_position = triangulation(signal_measurements, measurement_points)
        
        return estimated_position, time
    else:
        return "Source Not Found"

# 搜索路径生成
def generate_search_path(Omega, R_det, strategy):
    if strategy == 'grid':
        return grid_search_path(Omega, R_det)
    elif strategy == 'spiral':
        return spiral_search_path(Omega, R_det)
    elif strategy == 'adaptive':
        return adaptive_search_path(Omega, R_det)
    else:
        raise ValueError("Unknown strategy")
```
