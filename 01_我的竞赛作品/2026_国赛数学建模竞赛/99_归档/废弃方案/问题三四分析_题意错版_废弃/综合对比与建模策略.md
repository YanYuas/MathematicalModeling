# 问题三与问题四对比分析与建模策略

## 一、问题对比矩阵

### 1.1 核心要素对比

| 要素 | 问题三 | 问题四 | 难度提升因子 |
|------|--------|--------|--------------|
| **问题性质** | 单目标搜索优化 | 多目标序列优化 | 组合爆炸 |
| **状态空间** | $(x, y, t)$ 连续 | $(x, y, t, N, \{s_i\})$ 高维混合 | $O(N!)$ |
| **信息完备性** | 部分可观测 | 高度不确定 | 信息熵×N |
| **决策复杂度** | 路径规划 | 路径+调度+优先级 | 多层决策树 |
| **算法类型** | 确定性/启发式 | 在线/自适应 | 实时性挑战 |
| **模型复杂度** | 中等 | 高 | NP-hard |

### 1.2 数学特征对比

| 数学特征 | 问题三 | 问题四 |
|----------|--------|--------|
| **优化类型** | 单目标优化<br>$\min T_{total}$ | 多目标优化<br>$\min (T, E), \max W$ |
| **约束结构** | 线性+二次约束 | 非凸约束+整数约束 |
| **可分解性** | 可分为搜索+定位两阶段 | 阶段耦合，需协同优化 |
| **确定性** | 随机性较低 | 强随机性（源数量未知） |
| **求解方法** | 动态规划/贪心可行 | 需启发式/元启发式 |

### 1.3 技术挑战对比

#### 问题三的技术挑战（5个）
1. **覆盖路径设计**：保证搜索完备性
2. **信号检测**：噪声环境下的可靠检测
3. **定位精度**：测量误差的影响
4. **能量约束**：续航限制下的路径优化
5. **实时性**：在线调整的计算开销

#### 问题四的技术挑战（10个）
1. ✅ **问题三的所有挑战**
2. ➕ **源数量估计**：统计推断的准确性
3. ➕ **信号分离**：混叠信号的解耦
4. ➕ **优先级决策**：多目标权衡
5. ➕ **任务调度**：NP-hard组合优化
6. ➕ **动态重规划**：在线算法的性能保证
7. ➕ **信息融合**：多次测量的一致性
8. ➕ **计算复杂度**：可扩展性问题
9. ➕ **鲁棒性**：干扰叠加的容错能力
10. ➕ **协调开销**：多任务切换的代价

## 三、建模方法论的选择

### 3.1 问题三的建模方法

#### 方法A：确定性优化（推荐用于理论分析）
**数学工具**：
- 运筹学（线性规划、整数规划）
- 图论（最短路径、网络流）
- 动态规划

**适用场景**：
- 环境信息较完整
- 追求最优解
- 计算时间充裕

**优点**：理论保证、可证明最优性
**缺点**：计算复杂度高、对不确定性敏感

#### 方法B：启发式搜索（推荐用于实际应用）
**算法家族**：
- A*、RRT*（快速随机树）
- 贪心算法、爬山法
- 模拟退火、遗传算法

**适用场景**：
- 需要快速响应
- 环境动态变化
- 近优解可接受

**优点**：速度快、易实现
**缺点**：无最优性保证

#### 方法C：混合策略（本题推荐）
**组合方案**：
- 粗搜阶段：确定性栅格覆盖
- 细搜阶段：自适应启发式搜索
- 定位阶段：最优化估计（最小二乘）

**理由**：
- 发挥各方法优势
- 理论与实践平衡
- 易于论文呈现

### 3.2 问题四的建模方法

#### 方法A：分层优化（推荐）
**层次结构**：
```
上层：任务分配与优先级决策
  ├─ 源数量估计
  ├─ 优先级排序
  └─ 任务分配（TSP变体）
    ↓
下层：单任务路径规划
  └─ 调用问题三的算法
```

**优点**：
- 降低复杂度（分而治之）
- 模块清晰，易于实现和测试
- 符合实际决策流程

**实现**：
1. 用BIC估计源数量
2. 多属性决策确定优先级
3. 贪心/动态规划分配任务
4. 每个任务复用问题三算法

#### 方法B：联合优化（理论最优）
**统一目标函数**：
$$\min_{\{\mathcal{P}_i\}_{i=1}^N, \pi} \sum_{i=1}^{N} \left[\alpha \cdot T_{\pi(i)} + \beta \cdot E_{\pi(i)} - \gamma \cdot w_{\pi(i)} \cdot (N-i)\right]$$

**求解**：
- 遗传算法（编码为任务序列+路径参数）
- 粒子群优化
- 差分进化

**优点**：理论上可达全局最优
**缺点**：计算量极大，维度灾难

#### 方法C：在线学习（创新方向）
**框架**：强化学习
- **状态**：$s_t = (\text{pos}, \{\text{discovered}\}, \text{resources})$
- **动作**：$a_t = (\text{next\_target}, \text{path\_type})$
- **奖励**：$r_t = -\Delta t + w_i \cdot \mathbb{I}(\text{completed})$

**算法**：
- Q-learning
- Deep Q-Network (DQN)
- Proximal Policy Optimization (PPO)

**优点**：
- 自适应性强
- 可迁移到新场景
- 前沿研究方向（加分项）

**缺点**：
- 需要大量训练数据
- 无理论保证
- 实现复杂

```python
def generate_signal_field(sources, grid):
    """生成多源信号场"""
    field = np.zeros(grid.shape)
    for src in sources:
        x0, y0, P0 = src['x'], src['y'], src['power']
        for i, x in enumerate(grid.x):
            for j, y in enumerate(grid.y):
                d = np.sqrt((x - x0)**2 + (y - y0)**2)
                field[i, j] += P0 * (d0 / max(d, 1e-6)) ** n
    
    # 添加噪声
    field += np.random.normal(0, sigma, field.shape)
    return field
```

### 4.4 理论界的推导

#### 问题三的理论下界
**定理（搜索时间下界）**：
$$T_{min} \geq \frac{\text{Area}(\Omega)}{v \cdot 2R_{det}}$$

**证明**：
无人机有效搜索宽度为 $2R_{det}$，速度为 $v$，
则单位时间搜索面积为 $v \cdot 2R_{det}$，
搜索全部区域至少需要 $\frac{\text{Area}(\Omega)}{v \cdot 2R_{det}}$ 时间。

**意义**：任何算法的性能不会低于此界

#### 问题四的复杂度下界
**定理（调度复杂度）**：
当源位置已知时，最优访问顺序问题是NP-hard的。

**证明**：归约到带权旅行商问题（TSP）。

**意义**：不存在多项式时间精确算法（除非P=NP）

### 6.3 常见陷阱与注意事项

#### ❌ 陷阱1：模型过于简化
**表现**：假设干扰源位置已知、信号无噪声等
**后果**：失去实际意义，评委认为未理解题意

#### ❌ 陷阱2：模型过于复杂
**表现**：引入过多深度学习、高级理论
**后果**：模型难以验证，逻辑不清晰

#### ❌ 陷阱3：缺乏对比
**表现**：只有一种方法，没有基准对比
**后果**：无法证明方法的优越性

#### ❌ 陷阱4：结果缺乏分析
**表现**：只给出数值结果，无深入讨论
**后果**：显得肤浅，缺少洞察

#### ✅ 正确做法：
1. 模型由简到繁，层层递进
2. 假设合理且明确说明
3. 多种方法对比，突出所选方法
4. 结果充分讨论，分析原因和规律
