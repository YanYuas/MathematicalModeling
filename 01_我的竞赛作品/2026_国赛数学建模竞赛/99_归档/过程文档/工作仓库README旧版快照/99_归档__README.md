## 归档规则

### 旧版本
- 文档有重大修改时，先把旧版复制到这里
- 命名：`原文件名_v1.md`、`原文件名_v2.md`
- 在文件开头注明：归档日期、归档原因、新版本位置

### 废弃方案 / 一次性历史件
- 方案被证伪、跑题、或含编造数据时，**不要删除**，移到这里
- 命名：`原文件名_废弃.md`；目录用 `<类型>_<日期>/`
- **每个归档目录必须有 `README.md`**，写明：归档日期、归档人、来源、归档原因、**逐条处置对照**

### 归档 ≠ 可以再引用
- 归档件**默认不可作为论文、交付物或支撑材料的依据**；
- 若确需引用（如 AI 合规的证据链），**必须在该处写全新路径**，并在归档 README 中登记"谁引用了它"。

---

## 为什么不删除？

1. **可追溯**：知道为什么放弃这个方案，避免重复踩坑
2. **可恢复**：万一新方案有问题，可以回退
3. **可学习**：废弃方案中的错误是宝贵的经验
4. **可审计**：比赛复盘时可以看到完整的思考过程

## 🚨 两次"数值编造"事件（流程教训，共用一套对策）

| 次 | 事件 | 手法 | 被抓出方式 |
|---|---|---|---|
| **1** | Q1 γ 分布 | `np.random.beta` 伪造采样 ⇒ 与解析分布不符 | 建模手复算发现 |
| **2** | Q2 可视化 v3.0 | 先出图后填数：硬编码玩具公式 / 硬编码流带宽度 / `uniform` 拼"分布" | 队友**自查** + 外部 AI（DeepSeek）两轮 |

**教训**：**图的数值只能来自模型，不能反过来**；"定性/简化"注释**不构成免责**——图一旦入论文，读者按图读数。

**已写入纪律的对策**：
1. 出图脚本必须**显式调用权威公式**（不得内联重写）；
2. 每张图须附**数据来源**（公式编号或 CSV）；
3. 弃用图**必须**从交付目录**移出**并加标记（本目录即此用途）；
4. **凡"结果好看"的结论优先复核**（两次最严重错误均属此类）。
