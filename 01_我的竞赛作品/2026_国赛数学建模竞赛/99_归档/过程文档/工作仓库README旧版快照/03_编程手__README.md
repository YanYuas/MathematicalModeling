### 3.2 时间账**精确闭合**（重要工具性结论）

用 `核验脚本/_analyze_real_runs.py` 对 10 局逐局复核：

```
虚拟时间 = 移动(|Δpos|/5) + 检测次数×5 + 频道切换×1 + 清除(成功×5 / 失败×3)
```

| 分量 | n=10 一局 | 占比 | n=16 一局 | 占比 |
|---|---|---|---|---|
| **移动** | 3325 s | **71.8%** | 4156 s | **79.3%** |
| 检测 | 1055 s | 22.8% | 845 s | 16.1% |
| 频道切换 | 202 s | 4.4% | 163 s | 3.1% |
| 清除 | 50 s | 1.1% | 80 s | 1.5% |

⇒ **移动是唯一的大头（72~79%）**，其余三项已被定理钉住（空频道必须"每频道在全部格点 no_signal"才能判空）。

## 二、核心方法论

### 每步【思路】标注

不要只写代码，每一步都要写为什么这么做：

```python
# 【思路】用B*-Tree表示布局，因为可以O(n)计算面积
class BStarTree:
    ...
```

### 验证题机制

- 建模手会提供已知答案的验证题
- 编程手必须先跑验证题，答案对了再跑正式数据
- 验证题不对 → 查bug，不要硬跑正式数据

### 纪律要求（必须遵守）

1. 每步写【思路】
2. 验证题不对不跑正式数据
3. 不自行改模型假设
