## 一、问题本质

**B 题 = 两个问题的拼接：**

- **Q1 / Q2 = 静态几何与估计**：在 **±1° 有界方向误差**下，把若干条"示向度"射线交成的区域刻画清楚（交会定位区域、直径、最小包围圆、测点选优）。**可解析、可证明、有经典文献支撑。**
- **Q3 / Q4 = 部分可观测的在线搜索—定位—清除决策**：1800 m 圆域内，源数（10–16）、位置、频道、有效接收半径（1000–1500）、定向朝向**全部未知**，靠逐条 HTTP 指令探测并清除。**核心产出是对接模拟器的机器狗程序。**

**评价指标是词典序**：**先保证全部清除（硬）**，再压缩定位清除时间（软）——注意题面"平均定位清除时间"的分子是**虚拟时间**，而现实 `≤ 1200 s` 是**硬约束**（两时钟不可混用，见 Q3）。

## 二、整体建模路线（四问是一条链，不是四道题）

```
【几何内核】角域 = 半平面交 → 单调链凸包 → 旋转卡壳求直径 → Welzl 最小包围圆
        │                                   （Q1 建立，Q2/Q3/Q4 全部复用，零修改）
        ├─► Q1  定位区域 L、直径 D、最小包围圆半径 R_MEC   ← 输出"L 的尺度"
        ├─► Q2  L 的尺度对"第二测点位置"的依赖 ⇒ 实验设计（取 φ 接近 90°）
        ├─► Q3  R_MEC 从"输出量"搬成"判据输入"：R_MEC ≤ 20 ⟺ 可清除
        └─► Q4  发现条件由「1000-覆盖」升级为「surrounding」（定向源有盲区）
```

**最值钱的一次"搬运"**：`R_MEC` 从 Q1 的输出量，变成 Q3 的**清除判据输入**——四问因此成为一条链。
详见 `Q3Q4统筹-层次沿袭与创新.md`（八层矩阵 + 五条统一结果）与 `Q3Q4统筹-统一命题深化.md`（U1–U5 证明）。

## 三、各问建模概要

### Q1 — 定位区域与圆覆盖

| 项 | 内容 |
|---|---|
| 目标 | 由两条含 ±1° 误差的示向度求：定位区域 `L`（角域之交，**凸**）、直径 `D`、最小包围圆半径 `R_MEC` |
| 约束 | 示向度误差为**有界区间**（非概率）；同一地点误差**固定**（⇒ 必须换点重测） |
| 方法 | 半平面交 → 单调链凸包 → 旋转卡壳（⊕ 暴力互验）→ Welzl 最小包围圆；Thales 判据 |
| 核心结论 | 夹逼 **`D/2 ≤ R_MEC ≤ D/√3`**（γ = `R_MEC/(D/2)` ∈ [1, 2/√3 = 1.1547]，等边三角形取上界）；"以直径为直径的圆**不能**保证覆盖"（等边三角形反例） |
| 基准 | `S1=(0,0), S2=(600,0), θ1=59.036°, θ2=120.964°` ⇒ `D=39.5978`、`R_MEC=19.7989` |
| 文档 | `Q1/`：全解总览 / 建模数学化 / 数学原理总理顺 / 公式表 / 模型假设与陷阱深挖 / 深度分析 / 陷阱与几何拓展 / 完整思路 / 经验总结 + `Q1三侧联合审计.md`、`建模手-联合校验报告.md`、`扫描结果-影响与建议.md` |

### Q2 — 第二测点选择（实验设计）

| 项 | 内容 |
|---|---|
| 目标 | **源距未知**的前提下，选第二个测向站位置使定位误差最小 |
| 约束 | **不得使用真源距**（不可观测量）；`d₂ ≤ 1000`（有效接收半径最坏档）；`φ ≥ φ_min` |
| 方法 | 三行关系式 `cosφ = Δ/d₂`、`sinφ = |b|/d₂` ⇒ `E ≍ ε·√(d₁²+d₂²)/sinφ` ≡ `E = ε·√(d₁²+d₂²)·d₂/|b|`；**正交最优** `a = d₁ ⟺ φ = 90°` |
| 核心结论 | **可保证交会角上限 39.6161°**（@`(a,b)=(764,651)`）；`φ_min=40°` 下**候选域为空集**（`b_min=650.00 > b_max=638.00`）；`ρ = D/E ∈ [2.23, 2.43]`（**不是** 2）；跨问改善 `D=35.414 m / −10.57%` |
| ⚠️ 口径 | 标准结果 `φ=90°` 是**单点最优**；`α=0` 的闭式解**不得**称作"鲁棒最优"，应叫**中线理想模型下的条件最优 + 中点对准策略** |
| 文档 | `Q2/`：九件套 ± + 3 个复核脚本 + `建模手-联合校验报告.md`、`经验总结.md` |

### Q3 — 多源自动搜索、定位与清除（主战场）

| 项 | 内容 |
|---|---|
| 目标 | 1800 m 圆域内、**数量未知**的 10–16 个源，**保障完全清除** |
| 两层结构 | **覆盖层**（三角格布点，保证"发现"）→ **定位层**（复用 Q1 交会管线）→ **成本层**（1200 s 现实约束下的在线决策） |
| 核心结论 | ① **两时钟分离**（虚拟时间 = 目标；现实 ≤1200 s = 硬约束）；② **清除判据 `R_MEC ≤ 20`（充要）**，清除点须取**最小包围圆圆心**（非质心）；③ 移动时间**下界 703.7168 s**（Steiner，与策略无关）；④ **完备性定理**：覆盖网格 + 20 频道状态穷尽 ⇒ 清除比例 **100%**，且**不需已知源总数** |
| 网格 | 默认 **`d = 1000`**（13 点；裁剪后实测空隙 901.92 m，裕量 98.08 m）；`d=1500` 为 7 点，仅作对照 |
| ⚠️ 必须分档 | `R_MEC` **全域分布极宽**（可解区中位 55.0 / p95 453 / max 750 m，**32.7% 超拐点 84.0369**）⇒ 清除必须**分档**（直接 / 扫掠 / 渐进逼近），**"以扫掠为主、homing 兜底"是错的** |
| 文档 | `Q3/`：九件套 + `00-移交说明.md` |

### Q4 — 全向 + 定向混合源

| 项 | 内容 |
|---|---|
| 目标 | 定向源（±90° 扇区盲区）下的多方位确认 |
| 只改两处、扩一处 | **发现条件** 1000-覆盖 → **surrounding**；**检测点集** 圆内裁剪 → **外扩环带**；**清除** 新增扫掠档。其余（交会管线、判据、homing 引理、下界）**全部继承 Q3** |
| 核心结论 | 扇区 = **闭半平面** `H(G,u) = {X : (X−G)·u ≥ 0}`；**surrounding 充要性**：`∀G ∈ D, G ∈ conv{p ∈ P : ‖p−G‖ ≤ 1000}` ⟺ 任意朝向的定向源必被至少一点测到 |
| ⚠️ 设计定理 | 外扩宽度须 **≥ `d`**（**不是** `d/√3`：那是最近邻半径，而 surrounding 用**三最近邻**，第三近邻可达 `d`）；且 `d ≤ R_eff`。实测 `d=1500` 时 surrounding 失败 **91.4%** |
| 文档 | `Q4/`：九件套 + `00-移交说明.md` |
