# HelloMathModeling · CUMCM2026 B题

> 2026 年全国大学生数学建模竞赛 B 题：**无线电干扰源的快速自动定位与清除**
> 三手分工协作：建模手 / 编程手 / 论文手
> 协作方式：UGit / Git 版本控制

---

## 这是什么？

这是一个数学建模竞赛的协同工作仓库。模拟三人团队（建模手、编程手、论文手），每个人独立工作，通过"移交—反馈"机制保证质量。

**核心思想**：
- 建模手负责数学建模（问题分析、模型假设、公式推导、算法设计）
- 编程手负责代码实现（算法编码、实验验证、模拟器对接）
- 论文手负责论文写作（组织方案、正文撰写、图表排版、参考文献）
- 三手通过 `00_任务总控/` 下的共享文件同步进度和数据

## B题概要

**题目**：无线电干扰源的快速自动定位与清除

**核心问题**：
- **Q1**：给定两个测向站的示向度（含 ±1° 误差），求干扰源的定位区域、直径和最小包围圆
- **Q2**：在源距未知的情况下，如何选择第二个测向站的位置，使定位误差最小
- **Q3**：设计多源（10-16 个）场景下的自动定位与清除策略，在时间窗口内完成全部清除
- **Q4**：考虑定向干扰源（±90° 扇区盲区）的多方位确认策略

**关键规则**：
- 圆域半径 1800m，移动速度 5m/s，清除半径 20m
- 示向度误差 ±1°，同地点误差固定（必须换点重测）
- 模拟器接口：`http://127.0.0.1:2026`，POST /enter /measure /clear /exit
- **9-13 17:30 后不可启动新测试，建议 15:30 前完成正式测试**

## 协作规范

详见 [`UGit协作指南.md`](./UGit协作指南.md)，核心要点：

### 提交信息格式
```
[角色] 问号：具体做了什么
```
角色标签：`[建模手]` / `[编程手]` / `[论文手]` / `[总控]` / `[工具]`

### 好的提交信息
```
[建模手] Q1：完成最小包围圆 Welzl 算法推导
[编程手] Q1：参数扫描完成，γ 实测 ≤1.01
[论文手] Q1：正稿回填扫描实测数据
[总控] 更新权威数字表，Q1 联合校验通过
```

### 禁止
- 提交信息写"更新""修改""完成"
- 直接在 main 分支上提交
- 强制推送（git push --force）
- 改别人目录下的文件（有建议写反馈）
