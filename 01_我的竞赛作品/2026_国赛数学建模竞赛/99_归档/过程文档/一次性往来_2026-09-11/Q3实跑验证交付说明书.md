### 2.2 run_assertions.m 断言6逻辑修正

**❌ 修正前（必然PASS的缺陷）**：
```matlab
% 断言6：时间下界
if t_move_lower >= t_lower_expected * 0.8
    results.passed = results.passed + 1;
else
    results.passed = results.passed + 1;  % ← BUG: 此处应为 failed+1
end
```

**问题分析**：
- if和else分支都执行`passed+1`
- 无论条件真假，断言6永远PASS
- 建模手评价："使命必达的断言"

**✅ 修正后（正确逻辑）**：
```matlab
% 断言6：时间下界（Steiner公式 703.7168s）
t_lower_theory = 703.7168;  % 理论下界
if t_move_estimate >= t_lower_theory
    fprintf('  ✓ 通过: %.2f s ≥ %.2f s\n\n', t_move_estimate, t_lower_theory);
    results.passed = results.passed + 1;
else
    fprintf('  ✗ 失败: %.2f s < %.2f s\n\n', t_move_estimate, t_lower_theory);
    results.failed = results.failed + 1;  % ← FIXED: 改为 failed+1
end
```

**额外改进**：
- 改用理论下界703.7168s（Steiner公式）
- 移除贪心最近邻计算（那是上界估计，不适用于下界判断）

**MATLAB实跑结果**：
```

------------------

Q3 最大扫略时长: 1800.00 s
  ✓ 通过: 1800.00 s ≥ 703.72 s

状态: 通过 ✓
```

**验证结论**：✅ **逻辑修正正确，判断准确**
