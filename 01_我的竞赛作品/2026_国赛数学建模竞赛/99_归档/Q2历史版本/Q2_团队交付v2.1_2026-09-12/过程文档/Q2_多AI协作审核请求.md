## 🎯 问题二核心内容摘要

### 问题定位
**输入**：已知某全向干扰源在检测点S₁处测得的示向度θ₁（±1°误差）

**输出**：
- 第二检测点S₂的选择策略
- S₂的候选区域（参数化表达）

**本质**：鲁棒最优实验设计问题
- 决策变量：S₂ = S₁ + a·u + b·v（连续二维）
- 核心难点：源距d₁完全未知
- 目标函数：最小化定位不确定度（用Q1的直径D）

### 三个核心结论

**结论1：正侧方最优性**
```
a = d₁ ⟺ φ = 90° ⟺ S₂与源"正侧方"对齐
```
- 几何：S₂位于"过源、垂直于视线"的直线上
- Thales：以S₁S₂为直径的圆必过源

**结论2：退化条件（反直觉）**
```
b = 0 ⟹ 三点共线 ⟹ sin φ = 0 ⟹ 零信息
```
**沿示向度方向前进对定位完全无用**

**结论3：可行性上界（最诚实）**
```
Δd ≤ R·cos φ_min ⟺ φ_min ≤ arccos(Δd/R)
```
在Δd=747.5m、R=1000m时：**最多保证约40°交会角**

### 候选区域
**简化版（推荐）**：
```
S₂ = S₁ + 752.5·u + b·v
b ∈ ±[627.23, 664.26] 米
```
两条对称线段，宽度仅37m

**数值基准**：
- b_min = 627.23 m
- b_max = 664.26 m  
- φ(最坏) = 40.00°
- E(名义) = 17.10 m
- |S₁S₂| = 979.63～1003.74 m
