## 2. 假设敏感性预检

### 2.1 关键歧义识别

| 歧义点 | 可能解释A | 可能解释B | 影响 |
|--------|-----------|-----------|------|
| **"较好的定位效果"** | 交会角尽量大 | 定位区域直径尽量小 | 决定目标函数 |
| **源距未知的处理** | 假设某个典型值 | 区间鲁棒设计 | 决定方案鲁棒性 |
| **接收半径R的选择** | 用中值1250m | 用最坏值1000m | 决定可行域大小 |
| **候选区域的定义** | 单个最优点 | 参数化集合 | 决定答案形式 |

### 2.2 快速验算与逻辑递进

**歧义1："较好的定位效果"的量化**

- **解释A**：只看交会角φ → 无尺度信息，无法比较不同距离配置
- **解释B**：用Q1的直径D → 综合φ和距离，有明确物理意义 ✓
- **结论**：采用解释B，用D或其解析代理E = ε√(d₁²+d₂²)/sinφ

**歧义2：源距未知的处理**

- **解释A**：假设d₁=750m → 只对特定距离最优，不鲁棒
- **解释B**：d₁ ∈ [d̂-Δd, d̂+Δd]，按最坏情况设计 ✓
- **验算**：d₁ ∈ (5,1500] → Δd = 747.5m，接近R=1000m
- **递进性检查**：Q3需要"确保能收到信号" → 必须鲁棒设计
- **结论**：采用解释B，Δd区间 + 最坏情况约束

**歧义3：接收半径R的选择**

- **解释A**：R=1250m（中值）→ 若实际R=1000m，S₂收不到信号
- **解释B**：R=1000m（最坏）→ 保守但确保可探测 ✓
- **与Q3的一致性**：Q3要求"确保所有源被清除" → 必须按最坏设计
- **结论**：采用解释B，R_worst = 1000m

**歧义4：候选区域形式**

- **解释A**：只给一个最优点 → 不符合题目"候选区域"要求
- **解释B**：参数化给出区间或集合 ✓
- **结论**：给出b ∈ [b_min, b_max]的区间表达

### 2.3 最终采用的解释汇总

| 决策 | 采用 | 理由 |
|------|------|------|
| 目标函数 | Q1的直径D（或解析代理E） | 综合性度量，有物理意义 |
| 鲁棒化 | Δd区间 + 最坏取界 | 源距完全未知，必须鲁棒 |

### 3.2 坐标系与参数化

**坐标归约**（WLOG，不失一般性）：
- 取S₁为原点
- 取θ₁的中线方向为+x轴

**参数化决策变量**：
```
S₂ = S₁ + a·u + b·v
```
其中：
- u = (cos θ₁, sin θ₁)：沿示向度中线方向
- v = (-sin θ₁, cos θ₁)：垂直于示向度方向
- a：沿视线方向的偏移（米）
- b：横向偏移（米）

**派生量**：
- Δ = d₁ - a：深度偏差
- d̂ = 752.5m：源距估计（区间中点）
- Δd = 747.5m：源距不确定半径

### 3.3 三行基础关系式（全部推导的起点）

设源 G = (d₁, 0)，第二点 S₂ = (a, b)：

```
d₂ = √(Δ² + b²)
cos φ = Δ / d₂  
sin φ = |b| / d₂
```

## 4. 问题二数学模型

### 4.1 问题目标

**主目标**：选择S₂使定位不确定度最小

**度量指标**：
- **精确度量**：D（问题一的定位区域直径）
- **解析代理**：E(S₂) ≍ ε_rad · √(d₁² + d₂²) / sin φ

其中 ε_rad = π/180 弧度。

### 4.2 模型假设

**H1. 有界误差模型**：示向度误差在[-1°, +1°]闭区间内，非概率分布

**H2. 全向源假设**：干扰源360°均匀辐射，可探测性只取决于距离

**H3. 源距未知假设**：d₁ ∈ (5, 1500]，在此区间内无先验分布信息

**H4. 最坏接收半径**：设计按R_worst = 1000m，确保可探测性

**H5. 闭式解假设**：存在解析最优性条件，无需数值优化

### 4.3 目标函数

**解析形式**（便于推导）：
```
E(a, b, Δ) = ε_rad · √(d₁² + Δ² + b²) · √(Δ² + b²) / |b|
```

**物理三因子分解**：
```
E = ε（观测精度）× √(d₁²+d₂²)（尺度）× 1/sin φ（几何放大/GDOP）
```

### 4.4 约束条件

**C1. 可探测约束**（硬约束）：
```
∀Δ ∈ [-Δd, Δd] : d₂ = √(Δ² + b²) ≤ R_worst = 1000
```

**C2. 非退化约束**（质量约束）：
```
∀Δ ∈ [-Δd, Δd] : sin φ = |b|/d₂ ≥ sin φ_min
```

其中φ_min是保证的最小交会角（可调参数，建议40°）

**C3. 可先行约束**（信息约束）：
```
S₂的选择只能依赖S₁、θ₁、ε、R范围，不能依赖G或d₁的真值
```

### 4.5 最优性条件（核心定理）

**定理1（正侧方最优性）**：

固定|b| > 0，E(a)在a = d₁处取唯一极小。

**证明**：E中Δ只以Δ²形式出现，E关于Δ²单调递增，故Δ² = 0即Δ = 0 = d₁ - a最优。∎

**几何解释**：
- a = d₁ ⟺ cos φ = 0 ⟺ φ = 90°
- S₂与源在"沿视线同一深度"，横向拉开
- **Thales等价**：∠S₁GS₂ = 90° ⟺ G在以S₁S₂为直径的圆上

**推论**：最优策略是 **a = d̂ = 752.5m**（用估计值替代未知d₁）

**定理2（退化条件）**：

b = 0 ⟹ sin φ = 0 ⟹ E → ∞

**几何解释**：S₁、S₂、G三点共线，两条视线重合，零信息增益

**反直觉结论**：**沿示向度方向前进对定位完全无用**

### 4.6 鲁棒化设计

由于d₁未知，取a = d̂后，实际Δ = d₁ - d̂ ∈ [-Δd, Δd]

**角度质量约束的下界**：

要求 ∀Δ, sin φ ≥ sin φ_min：
```
|b|/√(Δ² + b²) ≥ sin φ_min
⟹ |b|² ≥ Δ² · tan²φ_min
⟹ |b| ≥ |Δ| · tan φ_min

最坏情况取|Δ| = Δd：
b_min = Δd · tan φ_min
```

**可探测约束的上界**：

要求 ∀Δ, d₂ ≤ R_worst：
```
√(Δ² + b²) ≤ R_worst
⟹ b² ≤ R_worst² - Δ²

最坏情况取|Δ| = Δd：
b_max = √(R_worst² - Δd²)
```

### 4.7 候选区域

**简化版（推荐实现）**：

```
S₂ = S₁ + d̂·u + b·v
b ∈ ±[b_min, b_max]
```

即：两条对称的线段

**完整版（允许a偏离d̂）**：

```
S₂ = S₁ + a·u + b·v
|a - d̂| ≤ a_span
m(a)·tan φ_min ≤ |b| ≤ √(R_worst² - m(a)²)
```

其中：
- a_span = R_worst·cos φ_min - Δd
- m(a) = |a - d̂| + Δd

即：两片"翼形"区域

### 4.8 可行性条件（诚实上界）

**定理3（可行性不等式）**：

候选区域非空 ⟺ b_min ≤ b_max ⟺
```
Δd ≤ R_worst · cos φ_min
```

等价地：
```
φ_min ≤ arccos(Δd / R_worst)
```

**数值代入**：
- Δd = 747.5m，R_worst = 1000m
- arccos(0.7475) ≈ 41.63°

**最诚实的结论**：

在完全不知道源距的情况下，**最多只能保证约40°的交会角**。

这不是算法问题，是信息量的硬限制。

## 5. 求解方法

### 5.1 算法流程（闭式，无需迭代）

```
输入：S₁, θ₁, ε=1°, φ_min（建议40°）

步骤：
1. 计算源距估计：d̂ = (5 + 1500)/2 = 752.5 m
2. 计算不确定半径：Δd = (1500 - 5)/2 = 747.5 m
3. 检查可行性：Δd ≤ 1000·cos φ_min
   若不可行 → 报告 φ_min^max = arccos(747.5/1000) ≈ 41.63°
4. 计算候选区域边界：
   b_min = Δd · tan φ_min
   b_max = √(1000² - Δd²)
5. 构造坐标：
   u = (cos θ₁, sin θ₁)
   v = (-sin θ₁, cos θ₁)
6. 输出候选区域：
   简化版：S₂ = S₁ + 752.5·u + b·v, b ∈ ±[b_min, b_max]
   完整版：（翼形，见§4.7）

输出：候选区域参数、b_min、b_max、可行性状态、移动距离|S₁S₂|
```

### 5.2 为什么不用启发式算法

| 问题特征 | 结论 |
|----------|------|
| 决策空间 | 连续ℝ²，光滑 |
| 目标函数 | 关于Δ²单调，无局部极小 |
| 最优性条件 | 闭式：a = d̂ |
| 约束 | 两条线性/二次不等式 |

**用SA/GA/PSO等启发式 = 用大炮打蚊子**

会让评委怀疑没识别出问题类型。

## 8. 代码实现要点

### 8.1 核心函数

**函数1：候选区域计算**
```python
def compute_candidate_region(S1, theta1, phi_min=40, R_worst=1000):
    """
    输入：S1坐标, theta1(度), phi_min(度), R_worst(米)
    输出：d_hat, Delta_d, b_min, b_max, feasible, phi_min_max
    """
    # 1. 源距估计
    d_hat = (5 + 1500) / 2
    Delta_d = (1500 - 5) / 2
    
    # 2. 可行性检查
    phi_min_max = np.degrees(np.arccos(Delta_d / R_worst))
    feasible = (Delta_d <= R_worst * np.cos(np.radians(phi_min)))
    
    if not feasible:
        return d_hat, Delta_d, None, None, False, phi_min_max
    
    # 3. 候选区域边界
    b_min = Delta_d * np.tan(np.radians(phi_min))
    b_max = np.sqrt(R_worst**2 - Delta_d**2)
    
    return d_hat, Delta_d, b_min, b_max, True, phi_min_max
```

**函数2：位置误差解析式**
```python
def position_uncertainty(a, b, d1, epsilon_deg=1):
    """
    输入：a, b(米), d1(米), epsilon_deg(度)
    输出：E(米)
    """
    epsilon_rad = np.radians(epsilon_deg)
    Delta = d1 - a
    d2 = np.sqrt(Delta**2 + b**2)
    
    if abs(b) < 1e-12:  # 退化
        return np.inf
    
    E = epsilon_rad * np.sqrt(d1**2 + Delta**2 + b**2) * d2 / abs(b)
    return E
```

**函数3：候选区域坐标生成**
```python
def generate_S2_candidates(S1, theta1, b_min, b_max, d_hat, n_points=100):
    """
    输入：S1, theta1(度), b_min, b_max, d_hat, 采样点数
    输出：S2坐标列表（两条线段）
    """
    theta1_rad = np.radians(theta1)
    u = np.array([np.cos(theta1_rad), np.sin(theta1_rad)])
    v = np.array([-np.sin(theta1_rad), np.cos(theta1_rad)])
    
    b_samples = np.linspace(b_min, b_max, n_points)
    
    S2_upper = [S1 + d_hat * u + b * v for b in b_samples]
    S2_lower = [S1 + d_hat * u - b * v for b in b_samples]
    
    return S2_upper, S2_lower
```

## 附录：数学证明细节

### A.1 命题1的完整证明

**命题**：固定|b|>0，E(a)在a=d₁处取唯一极小。

**证明**：
设Δ = d₁ - a，则：
```
E(Δ) = ε_rad · √(d₁² + Δ² + b²) · √(Δ² + b²) / |b|
```

注意Δ只以Δ²形式出现。

令f(x) = √(d₁² + x + b²) · √(x + b²)，x = Δ²

对x求导：
```
f'(x) = 1/(2√(d₁²+x+b²)) · √(x+b²) + √(d₁²+x+b²) · 1/(2√(x+b²))
      = [√(x+b²)/(2√(d₁²+x+b²)) + √(d₁²+x+b²)/(2√(x+b²))]
```

由于两项均>0（b>0保证），故f'(x)>0，f(x)关于x单调递增。

因此E(Δ)关于Δ²单调递增，在Δ²=0即Δ=0处取极小。

即a=d₁最优。∎

### A.2 可行性不等式的证明

**命题**：b_min ≤ b_max ⟺ Δd ≤ R·cos φ_min

**证明**：
```
Δd·tan φ_min ≤ √(R² - Δd²)
```

两边平方：
```
Δd²·tan²φ_min ≤ R² - Δd²
Δd²(tan²φ_min + 1) ≤ R²
Δd²·sec²φ_min ≤ R²
Δd·sec φ_min ≤ R
Δd ≤ R·cos φ_min
```
∎
