### 问题3：M2 & C2 - D/E比值断言与实测不符

**位置**：
- §4.1-4.3（155-182行）
- §7.2断言6（415-418行）
- Q1文档中的"不可互换"说明

**问题描述**：
1. **断言6要求**：D/E ∈ [0.5, 2]
2. **实测结果**：
   - Q1基准：D/E = 2.43
   - Q2名义点：D/E = 2.00
   - Q2远源：D/E = 2.61
   - **实测族完全不在[0.5,2]内**（除ρ=2切点外）

3. **理论解释**：
   - φ=90°时，E = ε·|S₁S₂|，D = 2ε·|S₁S₂|，故ρ=2
   - ρ=2是理想构型的**下确界**，不是均值
   - 线性化误差带给出 D_lin/E ∈ [2, 2√2]

4. **自相矛盾**：
   - Q1文档早写"D/E=2.43，不可互换"
   - Q2正稿496行也说"同时报告"
   - 但断言6要求ρ∈[0.5,2]

**修改建议**：
1. **删除断言6的硬编码区间**
2. 改为分别报告D和E：
```markdown
**验证方法6：双度量一致性检查**
- 计算Q1精确直径D
- 计算Q2解析代理E
- 同时报告两者及其比值ρ=D/E
- 预期：ρ ≥ 2（理论下界），实测约在[2.0, 2.6]范围
- 注意：D和E是不同度量，不能直接替换
```

3. 在§4.2中补充说明：
```markdown
**E与D的关系**：
- E是位置不确定度的解析近似（小角近似）
- D是定位区域的精确几何直径
- 理论关系：D ≥ 2E（φ=90°时取等）
- 两者不能互相替换，应同时报告
```

### 问题4：R1 - 方向不确定性遗漏（最严重）

**位置**：
- §3.3三行关系式（139行`G=(d₁,0)`）
- §4.6-4.7约束推导
- 整个候选区域计算

**问题描述**：
1. **坐标归约合法**：将θ₁旋转到x轴 ✓
2. **假设源在中线不合法**：将G也放在x轴 ✗
3. **正确关系**：
   - 真实源有角偏差α，|α|≤ε
   - G = (d·cosα, d·sinα)
   - d₂² = d² + a² + b² - 2d(a·cosα + b·sinα)
   - sinφ = |b·cosα - a·sinα| / d₂

**数值反例**：
- **反例1（角度失保）**：
  - a=752.5, b=b_min, d=1500, α=+1°
  - 实际γ = 39.81° < 40°（不满足保证）
  
- **反例2（距离失保）**：
  - b=b_max, d=1500, α=-1°
  - 实际d₂ = 1017.41m > 1000m（不满足约束）

**影响**：
- 当前候选区域只是"中线理想模型"
- 不能声称对完整±1°误差有鲁棒保证

**修改建议**：

**选项A：明确降级为中线模型**
```markdown
## 4.7 候选区域（中线理想模型）

**适用条件**：
- 假设真实源在测量中线上（α=0）
- 仅考虑源距d的不确定性
- **不考虑方向偏差α∈[-1°,+1°]的影响**

**候选区域**：
S₂ = S₁ + d̂·u + b·v, b ∈ ±[b_min, b_max]

**局限性**：
- 实际方向偏差可使交会角降至39.81°
- 实际距离可达1017.41m
- 需要后续完整角域分析补充鲁棒保证
```

**选项B：补充完整角域分析（推荐给维度7）**
```markdown
## 4.7 候选区域（完整角域鲁棒设计）

**步骤1**：计算完整几何关系
d₂² = d² + a² + b² - 2d(a·cosα + b·sinα)
sinφ = |b·cosα - a·sinα| / d₂

**步骤2**：重新求sup和inf
sup_{d,α} d₂  （对d∈[5,1500], α∈[-1°,+1°]）
inf_{d,α} sinφ

**步骤3**：修正边界
b_min^* ≥ b_min（补偿角偏差）
b_max^* ≤ b_max

**步骤4**：验证修正后的候选区域
```

**修改位置**：
- [ ] §3.3补充α参数
- [ ] §4.6-4.7标注适用条件
- [ ] 新增"完整角域分析"章节（或标记为待补充）
