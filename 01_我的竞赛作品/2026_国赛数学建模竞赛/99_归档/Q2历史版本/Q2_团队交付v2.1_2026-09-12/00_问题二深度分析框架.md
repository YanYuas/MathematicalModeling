## 🎯 问题二核心定位

**一句话**：用一条示向度做"下一个观测点"的最优实验设计（带未知源距的鲁棒版）

### 题设精读
> "已知某全向干扰源在一个检测点处测得的示向度，请给出第二个检测点的选择策略，以获得关于该干扰源较好的定位效果，并给出第二个检测点的候选区域。"

### 问题本质
- **类型**：鲁棒最优实验设计问题
- **决策空间**：连续二维 (a, b) ∈ ℝ²
- **目标**：最小化定位不确定度（Q1的直径D或其解析代理E）
- **难点**：源距d₁完全未知 → 必须鲁棒设计
- **复杂度**：有闭式最优性条件，**无需启发式算法**

---

## 📐 数学核心结构

### 三行关系式（全部推导的起点）
设源 G = (d₁, 0)，第二点 S₂ = (a, b)，记 Δ = d₁ - a：

```
d₂  = √(Δ² + b²)
cos φ = Δ / d₂  
sin φ = |b| / d₂
```

### 三个核心结论

**1. 最优性条件（最漂亮的结论）**
```
a = d₁  ⟺  φ = 90°  ⟺  S₂与源"正侧方"对齐
```
- 几何意义：S₂位于"过源、垂直于S₁G"的直线上
- Thales等价：以S₁S₂为直径的圆必过源

**2. 退化条件（反直觉结论）**
```
b = 0  ⟹  三点共线  ⟹  sin φ = 0  ⟹  零信息
```
**沿示向度方向前进对定位零信息增益**

**3. 可行性上界（最诚实的结论）**
```
Δd ≤ R·cos φ_min  ⟺  φ_min ≤ arccos(Δd/R)
```
在Δd=747.5m、R=1000m时：**最多只能保证约40°的交会角**

## 📊 候选区域参数化

### 简化版（两条对称线段）
```
S₂ = S₁ + d̂·u + b·v
b ∈ ±[b_min, b_max]

b_min = Δd·tan φ_min        （角度质量约束）
b_max = √(R_worst² - Δd²)   （可探测性约束）
```

### 数值算例（基准）
| 参数 | 值 | 说明 |
|------|-----|------|
| d̂ | 752.5 m | 源距估计（区间中点） |
| Δd | 747.5 m | 源距不确定半径 |
| φ_min | 40° | 保证的最小交会角 |
| b_min | **627.23 m** | 横向偏移下界 |
| b_max | **664.26 m** | 横向偏移上界 |
| 区域宽度 | **37 m** | 接近可行性上限 |
