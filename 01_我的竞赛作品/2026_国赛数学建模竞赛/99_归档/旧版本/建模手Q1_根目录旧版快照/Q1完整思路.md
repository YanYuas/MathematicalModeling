## 0. 一页速览

### 0.1 一句话

**Q1 = 把 n 条带 ±1° 误差的示向度升格为 n 个 2° 角域，取交集得凸多边形 L，求其直径 D；"以 D 为直径的圆能否覆盖 L"答案是【否】，反例等边三角形，正解是最小包围圆（半径被 Jung 定理夹在 [D/2, D/√3]）。**

### 0.2 全景链条

```
题面（n 个检测点 + n 个示向度 → 求定位区域直径；问直径圆能否覆盖）
  │ ① 词义解析
  ▼
【升格】一条示向度 → 一个 2° 角域（有界不确定性，不是概率）
  │ ② 角域 = 两个半平面之交 ⇒ 凸
  ▼
【结构】L = ⋂Wᵢ 是凸多边形
  │ ③ L 有界 ⟺ 方向区间之交为空（定理 G0）
  │ ④ 顶点 = 边界射线两两交点 ∩ 在所有角域内
  ▼
【算法】射线求交 + 过滤 → 凸包 → 旋转卡壳/暴力求直径
  │ ⑤ 双实现交叉验证
  ▼
【判据】D 与 D-圆
  │ ⑥ 反例：等边三角形（∠60°<90°）
  │ ⑦ Thales 判据：覆盖 ⟺ 全顶点 ∠PXQ≥90°
  │ ⑧ 正解：最小包围圆，Jung 夹逼 [D/2, D/√3]，缺口 ≤15.5%
  ▼
【第二重读法】线性化：Fisher 信息矩阵 M 给误差椭圆（从 Q2 反哺）
  ▼
【统一】圆锥几何 / 配极对偶 / Helly 数 3
  ▼
输出：算法 + D + R_MEC + 覆盖判定 + 退化分类
```

### 0.3 三个"第一次看到就该记住"的点

1. **"示向度"不是一条射线，是一个 2° 角域。** 漏了这一步，区域退化成一个点、D=0，Q1 直接错。
2. **"以直径为直径的圆能否覆盖"答案是"不能保证"。** 直径是**两两约束**，圆覆盖是**单点约束**，后者严格更强。
3. **本题没有优化、没有启发式。** 它是 P 类凸几何精确问题。用 SA/GA 会被评阅怀疑没识别问题类型。

## 第一步：题意 → 数学对象

### 1.1 题面逐词

> "已知若干个检测点坐标及某干扰源关于这些检测点的示向度，请给出采用交会定位法（见附录 2）计算多边形定位区域直径（即区域内任意两点之间距离的最大值）的算法。以定位区域直径为直径的圆能否覆盖此定位区域？"

| 词 | 点透 |
|---|---|
| 若干个检测点 | n 未定；**n≥2 才有界** |
| 示向度 | **角度观测**，只给方向不给距离 |
| 交会定位法（附录2图2） | 官方已定义：**定位区域 = 角域之交**（红线四边形） |
| 多边形定位区域 | 角域凸 ⇒ 交凸 ⇒ **必是凸多边形**（这三个字给了凸性） |
| 直径 = 区域内任意两点距离最大值 | 凸性 ⇒ 最远点对在**顶点** |
| 以直径为直径的圆 | **最大概念坑**（见第四步） |
| 能否覆盖 | **证伪题**：反例即可答"否"，但要满分需三层 |

### 1.2 三个关键决策（进论文假设节）

| 决策 | 取值 | 理由 |
|---|---|---|
| 误差模型 | **有界区间** [−1°,1°]，非概率 | 题设写"范围"，不是"分布"；有界 ⇒ 凸性链成立 |
| 角域开闭 | **闭**（含 ±1° 边界） | 保证 L 紧，D 的 max 可达 |
| 是否与目标圆域求交 | **主口径不截断** | 题面未给圆域约束；截断版作对照 |

### 1.3 形式化

```
坐标归约：Sᵢ, θᵢ, ε = 1°
角域（射线族）：W(S,θ,ε) = { S + t·u(φ) : t ≥ 0, |angdiff(φ,θ)| ≤ ε }
                     = {X : cross(u₋,X−S) ≥ 0} ∩ {X : cross(u₊,X−S) ≤ 0},  u± = u(θ±ε)
定位区域：L = ⋂ᵢ₊₁ⁿ Wᵢ
主输出： D = max{ ‖p−q‖ : p,q ∈ L }
副输出： R_MEC = min_c max_{X∈L} ‖X−c‖
```

**两处必须钉死**（否则实现必错）：
- `angdiff(φ,θ) = ((φ−θ+180°) mod 360°) − 180°`，**禁止直接相减**（跨 0° 会错）；
- 角域是 **t ≥ 0 的射线族**，不是直线族（直线族会造出反向假交点）。

> 详见 [[Q1建模数学化.md]] §A、[[Q1公式表.md]] F1-F6。

## 第二步：三个基础定理（有证明，可写论文）

### 定理 1（凸性）— 全题多项式可解的唯一原因

**陈述**：每个 Wᵢ 是凸集（两个闭半平面之交）；有限交仍凸 ⇒ **L 是凸多边形**。

**证明**：`W = {X : cross(u₋,X−S) ≥ 0} ∩ {X : cross(u₊,X−S) ≤ 0}`，其中 cross 关于 X 是线性的，故每个集合是闭半平面。半平面凸，凸集之交凸。∎

**推论**：L 上最远点对必在**极点（顶点）**取到 ⇒ D 可枚举顶点求得，无需遍历区域内部。

### 定理 2（顶点枚举 + 过滤）

**陈述（正）**：L 的每个顶点必是某两条角域边界射线 `rᵢ^a`、`rⱼ^b` 的交点。

**陈述（反向不成立——实现红线）**：两条边界射线的交点**未必**属于 L。故

```
P 是 L 的顶点 ⟺ t ≥ 0 ∧ s ≥ 0 ∧ ∀k: P ∈ Wₖ
```

**证明（正）**：L 的边界由各角域的边界射线片段拼成；两条片段的相接处即顶点。∎

> **这是 Q1 第一大实现坑（W2）**：漏掉 `∀k: P ∈ Wₖ`，凸包含假点、D 偏大。

### 定理 3（有界性判据，新，来自统筹文档）

**陈述**：`L = ⋂ᵢWᵢ` **有界 ⟺ 各方向区间之交为空：`⋂ᵢ [θᵢ−ε, θᵢ+ε] = ∅`**。

**证明**：凸集的回收锥 `recess(W) = {d : W+td ⊆ W, ∀t≥0}` 就是该角域（平移到原点），且 `recess(⋂Wᵢ) = ⋂recess(Wᵢ)`。L 有界 ⟺ `recess(L) = {0}` ⟺ 各角域无公共方向 ⟺ 方向区间交为空。∎

**推论**：
- n=2 时 **L 无界 ⟺ `|θ₁ − θ₂| < 2ε = 2°`**（两站几乎朝同一方向看 ⇒ 源极远、两视线近乎平行）；
- n 站时只要有公共方向即无界。

**价值**：把 Q1 原有的模糊描述"近平行 ⇒ 无界"升级为**可计算、可验证的充要条件**。**替换原 G2。**

> 详见 [[Q1建模数学化.md]] §G 定理 G0、[[../Q1Q2统筹-几何创新.md]] §6。

## 第三步：算法主线（四件套）

### 3.1 构造 L：两条路线

| 路线 | 复杂度 | 适用 | 定位 |
|---|---|---|---|
| **射线两两求交 + 过滤** | O(n³) | **n ≤ 8 首选**（本题典型 n=2~6），逻辑直观、易断言 | **主路径** |
| 半平面交（排序增量/分治） | O(n log n) | n > 8 | 备选 |

```
Step 1  对每个 i 生成两条边界射线 rᵢ^± = Sᵢ + t·u(θᵢ ± ε)，t ≥ 0
Step 2  枚举 i<j、a,b ∈ {+,−}，解 2×2 线性方程组求交点
        t = cross(Sⱼ−Sᵢ, uⱼ^b)/det,  s = cross(Sⱼ−Sᵢ, uᵢ^a)/det,  det = cross(uᵢ^a, uⱼ^b)
        需 |det| > 1e-12（近平行跳过），t ≥ 0，s ≥ 0
Step 3  过滤：保留满足 ∀k: P ∈ Wₖ 的交点        ← 最容易漏
Step 4  单调链凸包（Andrew 1979）→ 严格顶点序列 V（逆时针、无共线点）
```

### 3.2 求直径：双实现

```
D = max{ ‖p−q‖ : p,q ∈ V }
旋转卡壳（Toussaint 1983）O(m log m)  ≡  O(m²) 暴力
```

**两套都实现，结果必须完全一致**——这是免费的 bug 探测器（离散几何实现中最有效的手段）。

### 3.3 求最小包围圆

```
Welzl 随机增量，期望 O(n)  ｜  O(n³) 暴力（枚举点对定圆 + 三点定外接圆）作基准
```

**注意**：MEC 由 **2 或 3** 个边界点决定（不可能是 1 个，除退化为单点）。

### 3.4 为什么不用启发式

| 问题特征 | 结论 |
|---|---|
| 决策空间：无（L 由输入唯一确定） | **不是优化问题，是计算问题** |
| 结构：凸几何，多项式可解 | 有精确算法 |
| 无 NP-hard、无组合爆炸 | **绝对不要引入 SA/GA** |

## 第四步：覆盖问题——三层回答（本问最大得分点）

### 4.1 为什么直觉会错

直觉："直径是最长距离，以它为直径的圆当然装得下整个区域。"
**错在哪**：直径约束的是"**任意两点**距离 ≤ D"（两两约束）；圆覆盖约束的是"**所有点到某个固定圆心**距离 ≤ D/2"（单点约束）。**后者严格更强。**

### 4.2 第一层：反例（等边三角形）

取 L = 等边三角形，边长 a ⇒ D = a。
以任一边 AB 为直径作圆（圆心 = AB 中点，半径 a/2）：顶点 C 到该圆心距离 = 高 = **0.866a > 0.5a** ⇒ C 在圆外 ⇒ **不覆盖**。
（Thales 更简洁：∠ACB = 60° < 90°。）

### 4.3 第二层：充要判据（Thales 逆定理）

**定理**：`X 在以 PQ 为直径的圆内（含边界） ⟺ ∠PXQ ≥ 90°`。

**证明**：设 M = (P+Q)/2，
```
‖X−M‖² − (D/2)² = (X−P)·(X−Q) = ‖P−X‖‖Q−X‖cos∠PXQ
左 ≤ 0 ⟺ X 在圆内；右 ≤ 0 ⟺ ∠PXQ ≥ 90°。∎
```

**可计算判据**：`D-圆覆盖 L ⟺ 对 L 的每个顶点 X，∠PXQ ≥ 90°`。

**判据为何成立（两条等效论证，建议写第一条）**：
1. **凸性论证（更简洁）**：圆盘是凸集，L 是凸多边形，而 **L = conv(V)**（V 为顶点集）。故 `V ⊆ 圆盘 ⟹ conv(V) = L ⊆ 圆盘` ✓。
2. **极值论证**：角度函数 ∠PXQ 在凸多边形上的极值必在顶点取得。

**⇒ 只需校验顶点**，O(m)。**这条"凸集覆盖顶点即覆盖整体"是本题把"点集最小覆盖圆"结论合法迁移到"连续凸区域"的关键一句**（见 §12 的课题素材）。

### 4.4 第三层：正解 + 定量界（Jung 定理）

```
R_MEC  ≥ D/2          （圆须容下直径两端点）
R_MEC  ≤ D/√3 ≈ 0.5774D    （Jung 定理 1901）
```

**Jung 上界证明**：设最小包围圆圆心 O、半径 R，圆周上有 2 或 3 个支撑点。
- 2 点：必互为对径 ⇒ R = D/2 ≤ D/√3 ✓
- 3 点：构成三角形，最大角 α ≥ 60°，其对边 s ≤ D；由正弦定理 `s = 2R sinα ≥ 2R sin60° = √3 R` ⇒ R ≤ D/√3 ✓ ∎

**取等**：下界 ⟸ L 落在以 D 为直径的圆内；上界 ⟸ **等边三角形**。

**定量结论**：直径圆最坏比所需圆**小 2/√3 − 1 ≈ 15.5%**。

**缺口比**：`γ = R_MEC/(D/2) ∈ [1, 2/√3 ≈ 1.1547]`。

### 4.5 三个层次的评分

| 层 | 内容 | 评分 |
|---|---|---|
| L1 | 答"不能" | 及格 |
| L2 | + 反例（等边三角形） | 良好 |
| L3 | + Thales 判据 + 最小包围圆 + Jung 界 | **满分** |

### 4.6 附加歧义（更深一层，建议写）

**直径对可能不唯一**：凸多边形达到 D 的顶点对可能不止一组，**不同对给出不同的圆** ⇒ "能否覆盖"可能给出不同答案，而题设问的是唯一的是非。
**处理**：报告三种口径（任取一对 / 存在一对成立 / 所有对都成立），并指出**唯一无歧义的做法是采用最小包围圆**。

> 详见 [[Q1建模数学化.md]] §H、[[Q1陷阱与几何拓展.md]] W5。

## 第五步：Q1 的第二重读法（信息几何，从 Q2 反哺）

> 这一步是**统筹 Q1+Q2 才浮现的**，单看 Q1 文档没有。

### 5.1 L 是精确的，误差椭圆是线性的

Q1 给的是**精确的可行域 L**（非线性，由角度约束直接得来）。Q2 的 Fisher 信息矩阵给出的是**线性化的误差椭圆**。两者是同一个人不确定度的两种描述：

```
Fisher 信息矩阵  M = JᵀJ/σ² ,  Jᵢ = (1/dᵢ)·n̂ᵢ^⊥
两站闭式：det M = sin²φ/(σ⁴d₁²d₂²)
误差椭圆 = 协方差 σ²M⁻¹ 的置信集
```

**⇒ 结论**：
- L 的**形状**（沿角平分线方向被拉长的细长四边形）与误差椭圆的**长短轴方向一致**；
- 误差椭圆的**短轴方向 ⊥ 角平分线**——这正是 Q2"正侧方最优"的几何根源；
- **Q1 与 Q2 共享同一个 M**，是**伴随对偶**：Q1 用 M 把观测推成区域，Q2 用 M 挑观测。

### 5.2 两个不确定度度量的关系（实测，诚实）

| 量 | 定义 | 性质 |
|---|---|---|
| **D** | 区域直径（最坏两点） | 精确、非线性 |
| **E** | ε√(trace M⁻¹)（RMS 位置误差） | 闭式、线性化 |

**实测（Q1 基准算例）**：D = 39.60 m，E = 16.31 m ⇒ **D/E ≈ 2.43**。
**这不是普适常数**（换到 φ=90° 的配置后 D/E ≈ 2.00）。**论文应同时报告两者并说明语义差别**。

### 5.3 跨问交叉验证（本篇最漂亮的实测结果）

把 Q1 基准算例的 S₂ 移到 Q2 意义下的最优位置（保持横向偏移 |b| 不变，令 Δ = d₁ − a = 0）：

| 配置 | S₂ | \|S₁S₂\| | 交会角 φ | **D** | E |
|---|---|---|---|---|---|
| **Q1 原例** | (600, 0) | 600 m | 61.92° | **39.60 m** | 16.31 m |
| **Q2 最优位** | (741.19, 235.29) | 777.64 m | 90° | **27.15 m** | 13.57 m |
| 改善 | — | +29.6% 行程 | — | **−31.4%** | −16.8% |

**⇒ 两个问题互相验证，并给出可量化改进**（代价是行程 +29.6%）。这是把 Q1 与 Q2 串成一篇的**最强证据**。

## 第六步：统一视角（三条，各写一小节）

### 6.1 圆锥曲线统一（射影·圆锥）

Q1 的覆盖判据（Thales）与 Q2 的最优条件（Thales）**是同一个"点—圆锥关联"命题的两面**：
```
Q1: X 落在"以 PQ 为直径的圆"内      ⟺ ∠PXQ ≥ 90°
Q2: G 落在"以 S₁S₂ 为直径的圆"上    ⟺ ∠S₁GS₂ = 90°
```
**推广（展望）**：把圆换成椭圆 ⇒ **各向异性**（清除精度/测向误差横向≠纵向）下的整套理论。
⚠️ 诚实边界：一般范数下 Jung 常数不再是 1/√3，需重推。**只写"模型推广"一节，不深入。**

### 6.2 配极对偶（射影·配极）—— 覆盖问题的第二视角

```
(⋂ᵢ Cᵢ)° = conv(⋃ᵢ Cᵢ°)    ⇒  L = ⋂半平面  ⟺  L° = conv(点)
L ⊆ B(0,R)  ⟺  L° ⊇ B(0,1/R)  ⇒  覆盖 ⟺ "对偶多边形内切圆够大"
Jung 的对偶形式：inr(L°) ≥ √3/D
```
**自洽检验（等边三角形）**：L° 同样是等边三角形，`inr(L°) = 1`，而 `√3/D = √3/√3 = 1` ✓ **取等一致**。
**⇒ 对偶给出同样的 15.5% 缺口**——两套推导互相印证。

### 6.3 Helly 数 "3" 的三重奏（免费的高雅统一）

平面上 `d+1 = 3` 在本问题出现三次，**根源相同**：
| 出现处 | 陈述 |
|---|---|
| **L ≠ ∅ 的判定** | 任意 3 个角域相交 ⇒ 全体相交（**Helly 定理**） |
| **最小包围圆的决定** | MEC 由 ≤3 个边界点决定（**LP-type 组合维数 3**） |
| **Jung 等号** | 等边三角形（3 点配置）取等 |

**论文点一句**即可，成本极低、观感极好。

## 第七步：完整可执行流程（给编程手）

```
输入：{(Sᵢ, θᵢ)}, ε=1°

1  归一化：angdiff 统一角度，mod 360
2  构造边界射线 rᵢ^±（t ≥ 0）
3  两两求交（det 判平行），得候选点
4  过滤：保留 ∀k: P ∈ Wₖ 的点            ← 红线，必查
5  单调链凸包 → V（逆时针、无共线点）
6  直径 D  ← 旋转卡壳  ⊕  O(m²) 暴力（必须一致）  ← 红线
7  最小包围圆 R_MEC ← Welzl  ⊕  O(n³) 暴力（容差 1e-9）  ← 红线
8  覆盖判定 ← 对 ∀X∈V 检查 ∠PXQ ≥ 90°，P/Q 为直径端点
9  枚举所有直径对（‖p−q‖ ≥ D − 1e-9），逐一报告覆盖判定  ← 处理歧义
10 有界性检查 ← 定理 G0（方向区间之交是否为空）
11 输出：V、D、直径端点、R_MEC、γ=R_MEC/(D/2)、覆盖判定、退化报告

断言（每个用例必过）：
 A1 顶点序列严格凸（相邻三点叉积同号）
 A2 旋转卡壳 D == O(m²) 暴力 D（完全相等）
 A3 Welzl R_MEC == 暴力 R_MEC（1e-9）
 A4 D/2 ≤ R_MEC ≤ D/√3            ← 违反即 bug
 A5 覆盖判定 == (R_MEC ≤ D/2 + 1e-9)
 A6 基准算例 D = 39.60 ± 0.01
 A7 直径对枚举完备
```

> 详见 [[Q1建模数学化.md]] §E。

### 13.2 **必补的一句论证**（课题没有，Q1 必须有）

课题研究的是**点集**的最小覆盖圆，而 Q1 的定位区域是**连续凸区域**。合法性桥梁：

> **"圆盘是凸集，L 是凸多边形且 L = conv(V)，故覆盖 V 等价于覆盖 L。"**

这句话**必须在论文里写明**，否则"把点集算法用到区域上"是逻辑跳跃。（已写入 §4.3。）

## 一句话收束

**Q1 的完整思路是一条四级链**：① 把"示向度"正确升格为**角域**（决定区域语义）→ ② 用**凸性**把问题压成凸多边形计算（决定可解性）→ ③ 用**三层回答**答完整覆盖问题（决定得分）→ ④ 用**信息几何/对偶/Helly**给它第二重读法并与 Q2 接上（决定深度）。
