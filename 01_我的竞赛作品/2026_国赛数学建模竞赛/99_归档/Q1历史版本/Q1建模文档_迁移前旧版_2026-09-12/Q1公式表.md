## 一、输入与角域（问题的数学对象）

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F1 | 角度环绕函数 | `angdiff(φ,θ) = ((φ−θ+180°) mod 360°) − 180°` ∈ (−180°,180°] | 防跨 0° 错误；**禁止直接用 φ−θ** |
| F2 | 单位方向向量 | `u(φ) = (cos φ, sin φ)` | 方位角约定：正东 0°，逆时针为正 |
| F3 | 角域（射线族定义） | `W(S,θ,ε) = { S + t·u(φ) : t ≥ 0, \|angdiff(φ,θ)\| ≤ ε }` | 示向度不确定性的正确刻画 |
| F4 | 叉积 | `cross(a,b) = aₓb_y − a_ybₓ` | 定向判据基础 |
| F5 | 角域的两半平面形式 | `W = {X : cross(u₋,X−S) ≥ 0} ∩ {X : cross(u₊,X−S) ≤ 0}`，`u± = u(θ±ε)` | **核心化归**：角域 = 2 半平面交 ⇒ 凸 |
| F6 | 定位区域 | `L = ⋂ᵢ₌₁ⁿ Wᵢ`（可再 ∩ 目标圆域 D((0,0),1800) 截断） | 凸多边形；截断与否须声明口径 |
| F7 | 定位区域直径 | `D = max{ ‖p−q‖ : p, q ∈ L }` | **主输出** |
| F8 | 最小包围圆半径 | `R_MEC = min_c max_{X∈L} ‖X − c‖` | **覆盖问题的正解** |

## 二、顶点枚举与定位区域构造

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F9 | 边界射线 | `rᵢ^a = Sᵢ + t·u(θᵢ + aε)`，a ∈ {+,−}，t ≥ 0 | 每个角域两条 |
| F10 | 射线参数式 | `rᵢ^a(t) = Sᵢ + t·uᵢ^a` | 用于求交 |
| F11 | 两射线交点 | 解 `Sᵢ + t·uᵢ^a = Sⱼ + s·uⱼ^b`（2×2 线性方程组） | 行列式 `det = cross(uᵢ^a, uⱼ^b)`，det≠0 才有唯一解 |
| F12 | 交点参数 | `t = cross(Sⱼ−Sᵢ, uⱼ^b)/det`，`s = cross(Sⱼ−Sᵢ, uᵢ^a)/det` | 需 `t ≥ 0 ∧ s ≥ 0` |
| F13 | **顶点过滤判据** | P 是 L 的顶点 ⟺ `t≥0 ∧ s≥0 ∧ ∀k: P ∈ Wₖ` | **最容易漏的一步**；P∈Wₖ 用 F5 判定 |

## 三、凸包与直径

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F14 | 凸包顶点集 | `V = monotoneChain(候选交点集)` | 输出严格凸、逆时针、无共线点 |
| F15 | 直径（原始定义） | `D = max_{p,q ∈ V} ‖p − q‖` | 由凸性，仅需枚举顶点对 |
| F16 | 直径（旋转卡壳） | 沿凸包边旋转得到对踵点对，取最大距离 | O(m log m)（排序后 O(m)） |
| F17 | 直径（暴力） | 完全枚举顶点对取最大 | O(m²)；**作为 F16 的正确性基准** |
| F18 | 最远点对在顶点 | 凸集上最远点对必为极点对 | F15/F17 合法性的理论依据 |
| F19 | 复杂度汇总 | 半平面交 O(n log n) / 射线求交 O(n³)；凸包 O(m log m)；直径 O(m log m) 或 O(m²)；MEC 期望 O(n) | 全题均为多项式 |

## 四、覆盖判定与界

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F20 | Thales 圆内判据 | `X 在以 PQ 为直径的圆内 ⟺ ∠PXQ ≥ 90°` | 由 `(X−P)·(X−Q) ≤ 0` 导出 |
| F21 | 覆盖充要条件 | `D-圆覆盖 L ⟺ ∀X ∈ V, ∠PXQ ≥ 90°`（P,Q 为直径端点） | 角函数在凸多边形顶点取极值 |
| F22 | 等边三角形反例 | 边长 a ⇒ D = a；对角顶点处 ∠ = 60° < 90° ⇒ **不覆盖** | 第一层回答 |
| F23 | Jung 定理（上界） | `R_MEC ≤ D/√3` | 由最大角 α ≥ 60° 及正弦定理 `s = 2R sin α ≥ √3 R` 导出 |
| F24 | 显然下界 | `R_MEC ≥ D/2` | 圆须容下直径两端点 |
| F25 | **双侧夹逼** | `D/2 ≤ R_MEC ≤ D/√3 ≈ 0.5774 D` | **本问最亮的定量结果** |
| F26 | 覆盖缺口比 | `γ = R_MEC / (D/2) ∈ [1, 2/√3 ≈ 1.1547]` | 最坏缺口 **15.5%** |
| F27 | 取等条件 | 下界取等 ⟺ L 落在以 D 为直径的圆内；上界取等 ⟺ L 是等边三角形 | 两个极端对照图 |

## 五、误差传播与几何量级

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F28 | 横向偏移 | `Δ = d · tan(ε)` | 1° 在千米尺度的放大（1000m→17.455m） |
| F29 | ε 单调性 | `ε₁ ≤ ε₂ ⇒ L(ε₁) ⊆ L(ε₂) ⇒ D(ε₁) ≤ D(ε₂)` | 最坏情况在 ε=1° 取到，合法化鲁棒设计 |
| F30 | 量级关系（非精确解） | `D ≍ 2ε_rad · d_eff / sin φ` | **只写 ∝ 关系**；精确常数依赖构型，由算法精算 |

## 七、退化情形口径表

| 情形 | 判定式 | 口径 |
|---|---|---|
| n = 1 | 单条示向度 | 无界楔形 ⇒ D 未定义，报"无界" |
| 近平行 | `\|angdiff(θᵢ,θⱼ)\| < 2ε` | 边界近平行 ⇒ 报"无界/病态" |
| 空交集 | `⋂Wᵢ = ∅` | 报"输入不自洽，无可行定位区域" |
| 退化为线段 | m = 2 | `D = 线段长`，`R_MEC = D/2` |
| 退化为点 | m ≤ 1 | `D = 0`（完美定位） |
| 边界点归属 | 交点恰在角域边界 | **取闭角域**，容差 `1e-9` |
