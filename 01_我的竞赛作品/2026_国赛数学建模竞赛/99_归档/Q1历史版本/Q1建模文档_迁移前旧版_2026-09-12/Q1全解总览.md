## 0. 一句话定位

**Q1 = 带角度不确定性（±1°）的方位交会定位区域的凸几何刻画。定位区域 = n 个 2° 楔形角域的交集（凸多边形）。解法 = 半平面交（或射线两两求交+过滤）→ 单调链凸包 → 旋转卡壳求直径。"直径圆能否覆盖"的答案是【否】，反例为等边三角形；正解是最小包围圆，其半径被 Jung 定理夹在 [D/2, D/√3] 之间。**

## 1. 题设逐词点透

> "已知若干个检测点坐标及某干扰源关于这些检测点的示向度，请给出采用交会定位法（见附录 2）计算多边形定位区域直径（即区域内任意两点之间距离的最大值）的算法。以定位区域直径为直径的圆能否覆盖此定位区域？"

| 词 | 字面 | 点透（为什么重要） |
|---|---|---|
| "若干个检测点" | n 个点，n 未定 | **n≥2 才有界**：单条示向度只能给出无界楔形（射线族），n=1 时区域无界、直径未定义。n≥2 且方向不平行才闭有界。必须讨论退化 |
| "示向度" | 检测点指向干扰源的最大场强方位角 | 是**带误差的观测**，不是真方位。它定义的不是一条射线，而是一个**角域**——这是全题第一个关键跳跃 |
| "采用交会定位法（见附录2）" | 附录给了两站交会图 | 附录 2 图 2 明确：**实线与相邻虚线夹角 1°**，红线四边形 = 定位区域 ⇒ 官方已把"定位区域"定义为**两个 2° 角域的交**。n 站即 n 个角域交 |
| "多边形定位区域" | 区域是多边形 | **点透**：角域是凸集（两半平面之交），凸集之交仍凸 ⇒ 区域必是**凸多边形**。这一句"多边形"三个字直接给了凸性，是后面一切算法的基础 |
| "直径 = 区域内任意两点距离最大值" | 定义式 | 标准定义：`D = max{ ‖p−q‖ : p,q ∈ L }`。**凸性 ⇒ 最远点对必在顶点上** ⇒ 无需遍历区域内所有点 |
| "以直径为直径的圆" | 半径 D/2 的圆 | **本题最大的概念陷阱**。直径是"两点距离"，圆覆盖是"全体点约束"，两者不等价（§4.3）。题问"能否覆盖"，标准答案是**不能保证**，须给反例 |
| "能否覆盖此定位区域" | 是/否 + 理由 | 这是**证伪题**：只需一个反例即可回答"否"；但完整答案应给出（a）反例（b）充要判据（c）正确的替代（最小包围圆）——三层递进才是满分回答 |

**点透结论**：Q1 是"**凸几何 + 不确定性传播**"问题，无任何优化、无任何启发式，全部可精确求解。三个隐藏决策：(a) 角域的边界取法（闭/开、含不含端点）；(b) 顶点枚举 vs 半平面交的实现路线；(c) 覆盖问题的回答深度（只说"不能" vs 给出 Jung 界与最小包围圆）。

## 2. 约束与条件点透

```
输入：n 个检测点 S₁…Sₙ ∈ ℝ²，及各自测得示向度 θ₁…θₙ ∈ [0°,360°)
误差：|θᵢ − θᵢ^true| ≤ ε = 1°（题设 Figure 1 给出误差范围 [−1°,1°]）
角域：Wᵢ = { Sᵢ + t·u(φ) : t ≥ 0, |∠(φ, θᵢ)| ≤ ε }，u(φ)=(cosφ, sinφ)
定位区域：L = ⋂ᵢ Wᵢ     （必要时再 ∩ 目标圆域 D((0,0),1800) 截断）
输出1：D = max{ ‖p−q‖ : p,q ∈ L }
输出2：以 D 为直径的圆是否覆盖 L（是/否 + 反例 + 正解）
```

**为什么约束这么少**：
- 本题**没有优化**——区域是输入决定的，不是我们选的。所谓"算法"就是"精确算出这个几何对象"。
- 唯一的"不确定"来自 ε=1°。**若 ε=0，区域退化成一个点（真源位置），D=0**。所以 D>0 的全部来源就是这 1°。这给了 Q1 一个漂亮的口径：**D 是"1° 误差在几何上的放大倍数"的度量**。

**两个必须钉死的边界约定（否则实现必错）**：
1. **闭角域**：题设写"±1°（含）"是定向源覆盖角的口径；对示向度误差，附录只说"误差在[−1°,1°]范围内"。**建议取闭角域**（含边界），理由是闭集保证交集闭、直径可达（min/max 存在），数值上更稳健。
2. **射线方向 t≥0**：角域是**射线族**不是直线族。若误写成直线（t ∈ ℝ），两条反向延伸的边界会造出假交点，区域错误地扩大甚至变空。

**admissible 类洞察（类比 VLSI 的"左下压实"，本题的对应物是"束紧"）**：
> 设 L = ⋂Wᵢ。若把任一角域收紧（ε 取更小），L 只会变小（单调性：ε₁ ≤ ε₂ ⇒ L(ε₁) ⊆ L(ε₂)）。因此 **D(ε) 是 ε 的单调不减函数**。
> 推论：误差越大区域越大，定位越差；题设给的是 ε 的**上界**，故 D 的**最坏值**由 ε=1° 取到。这一条让"最坏情况分析"成为可能，也是 Q2 选点策略的理论起点。

## 3. 问题本质点透

- **为什么是几何不是统计**：若误差是随机的（如高斯），定位区域应是置信椭圆（统计）。但题设明确"误差在 [−1°,1°] 范围内"——这是**有界不确定性**，不是随机分布。有界 ⇒ 区域是**确定性集合**（所有可能位置），不是概率区域。这个区分决定了一切：**不要引入概率模型**。
- **复杂度**：确定性多项式问题（P）。角域 = 2 个半平面，n 个角域 = 2n 个半平面 ⇒ 半平面交 O(n log n)；凸包 O(m log m)；直径 O(m)（凸包后旋转卡壳）；最小包围圆期望 O(n)（Welzl）。**没有 NP-hard，没有启发式**。
- **为什么"很简单"反而是好事**：Q1 是全题唯一有**精确解**的问。它的价值不在算法难度，而在**概念严谨性**——评阅看的是：
  (a) 有没有把"示向度"正确地升格为"角域"；
  (b) 顶点过滤做对没有（最容易错的一步）；
  (c) 覆盖问题答得完整不完整（反例 + 判据 + Jung 界）。
- **与 Q2/Q3/Q4 的关系**：Q1 提供**精度度量 D**。Q2 用 D 作为选点目标函数；Q3/Q4 的交叉定位与 homing 用 D 判断"是否已足够接近"。**Q1 是全题的公制尺**。

## 4. 数学结构点透（本问灵魂）

### 4.1 三层结构：精确界 → 夹逼 → 判据

（对标 VLSI 的"三层下界"，本题的结构是三段式）

| 层 | 内容 | 作用 |
|---|---|---|
| **精确层** | L 是多边形，D、顶点、面积均可**精确算出**（无近似） | 本题无"估计"成分，答案是数不是区间 |
| **夹逼层** | 最小包围圆半径 R_MEC ∈ [D/2, D/√3]（**Jung 定理**） | 量化回答"直径圆够不够"，给出最坏缺口 |
| **判据层** | 以 PQ 为直径的圆覆盖 L ⟺ ∀X∈L, ∠PXQ ≥ 90°（**Thales**） | 可判可证，把"能否覆盖"变成可计算条件 |

### 4.2 Jung 定理：覆盖问题的定量答案（本问最亮的数学点）

> **Jung 定理（1901）**：平面上直径为 D 的点集，必可被半径 R ≤ D/√3 的圆覆盖。

配合显然的下界 R ≥ D/2（圆必须包含直径的两端点），得到**双侧夹逼**：

```
D/2  ≤  R_MEC  ≤  D/√3 ≈ 0.5774·D
```

- **下界 D/2 的取等**：当 L 是**线段**（或全部点落在以 D 为直径的圆内）时。
- **上界 D/√3 的取等**：**等边三角形**——这正是本题反例，且是唯一取等形状。
- **缺口量化**：最坏情况下，以 D 为直径的圆半径 D/2，实际需要 D/√3，**差 2/√3 ≈ 1.1547，即 15.5%**。

**点透**：这比"举个等边三角形反例"高一个层次——它把"能不能覆盖"变成"最多差多少"。论文写"**直径圆一般不能覆盖，最坏缺口 15.5%（Jung 定理，等边三角形取等）**"，评阅立刻知道你读过经典结果而不是碰巧想了个反例。

### 4.3 覆盖判据（Thales）：把"能否覆盖"变成可计算条件

> **Thales 定理的逆用**：点 X 在以 PQ 为直径的圆内 ⟺ ∠PXQ ≥ 90°。

于是：

```
以直径端点 P,Q 为直径的圆覆盖 L  ⟺  ∀X ∈ L，∠PXQ ≥ 90°
```

- 由于 L 凸且角函数在顶点取极值，**只需对所有顶点校验** ⇒ O(m) 判据。
- **等边三角形**：取任一边为直径，对角顶点处 ∠ = 60° < 90° ⇒ 不覆盖 ✓
- **§4.4 算例**（钝角/近菱形的四边形）：对角顶点处 ∠ ≈ 90° 附近...实际 ∠ ≈ 118° > 90° ⇒ 覆盖 ✓

**点透**：这个判据让"能否覆盖"从"画图看看"变成"算几个角"。同时它解释了**什么时候能覆盖**：L 越"扁"越容易覆盖（越接近退化线段），越"圆"越难（等边三角形最难）。

本题**没有外部数据集**（详见 `01_背景研究/背景全量研究报告.md` §1.2），所以"数据画像"改为**参数敏感度画像**。以下数值均由 GeoGebra CAS 独立复核：

## 5. 建模点透（楔形 → 交集 → 凸包 → 直径，每一步为什么）

### 5.1 为什么"一条示向度"必须升格为"一个 2° 角域"

| 候选 | 含义 | 判定 |
|---|---|---|
| 一条射线 | 忽略误差 | **错**：与题设"误差[−1°,1°]"直接矛盾 |
| 一条概率分布 | 高斯等 | **错**：题设是有界不确定性，不是随机分布 |
| **一个 2° 角域** | 所有可能方向的集合 | **选它**：与题设误差范围一一对应，且保证凸性 |

点透：**角域的凸性是全题能"多项式可解"的唯一原因**。若误差是概率分布，区域将变成非凸的置信集，直径问题立刻变难。

### 5.2 为什么交集的顶点 = "边界射线两两交点 ∩ 在所有角域内"

角域 Wᵢ 的边界是两条射线 `rᵢ⁺ = Sᵢ + t·u(θᵢ+ε)`、`rᵢ⁻ = Sᵢ + t·u(θᵢ−ε)`（t≥0）。

- L 的边界必由某些 rᵢ^± 的片段组成（因为 L 由这些半平面/角域围成）；
- 因此 L 的顶点必是**两条边界射线的交点**；
- 但两条边界射线的交点**不一定**属于所有角域 ⇒ **必须过滤**。

```
候选顶点 = { rᵢ^a ∩ rⱼ^b : i<j, a,b∈{+,−}, 交点满足 t≥0,s≥0, 且 ∈ Wₖ ∀k }
```

**点透**：漏掉"且 ∈ Wₖ ∀k"这一步，会把大量假点当成顶点，凸包直接错、直径直接错。这是 Q1 实现第一大坑（见 §6 T2）。

### 5.3 为什么凸包：候选点里混着内部点

即便过滤后，候选点集也可能包含共线点/冗余点。**单调链凸包（Andrew 1979，O(m log m)）** 输出严格凸包顶点序列，供直径计算使用。

### 5.4 为什么直径是 O(m)，以及旋转卡壳

- **凸性 ⇒ 最远点对在顶点上**（严格：对凸集，argmax 距离的点对必是极点对）。所以只需在 ≤m 个顶点上求最大距离。
- **暴力 O(m²)**：本题 m ≤ 2n，n 小（个位数到十几），**暴力完全够用**。
- **旋转卡壳 O(m log m)**（Toussaint 1983）：论文写这个更专业，且它是"对踵点对"的标准算法。**建议两者都实现，互相校验**。

**点透**：本题规模极小，"选哪个"不是性能问题而是**表述问题**——论文里写"凸包 + 旋转卡壳 + O(m²) 暴力交叉验证"，体现你知道两套方法并做了自检。

### 5.5 覆盖问题的三步回答（评分点）

```
第1步（反例）：等边三角形 —— 以边为直径的圆漏掉对角顶点（∠=60°<90°）
第2步（判据）：Thales —— 覆盖 ⟺ 所有顶点处 ∠PXQ ≥ 90°
第3步（正解+界）：最小包围圆（Welzl，期望O(n)）；Jung 定理给出 R_MEC ∈ [D/2, D/√3]
```

**点透**：只答"不能"是及格；答"不能 + 反例"是良好；答"不能 + 反例 + 判据 + 最小包围圆 + Jung 界"是满分。本题是**证伪题**，深度全在第三层。

## 6. 陷阱点透（浓缩为机理）

| 陷阱 | 一句话机理 |
|---|---|
| T1 直线 vs 射线 | 角域是 t≥0 的射线族，误用直线族 ⇒ 假交点、区域错大 |
| T2 顶点不过滤 | 两两交点未必在所有角域内，不滤则凸包全错（**最大实现坑**） |
| T3 直径圆=最小包围圆 | 概念混淆 ⇒ Q1 结论直接错（等边三角形反例） |
| T3b **直径对可能不唯一** | 凸多边形可有多组直径对，**不同对给出不同的圆 ⇒ 覆盖答案可能不一致**，而题目问的是唯一的是非。对策：枚举所有直径对 + 用唯一的最小包围圆（详见 `Q1陷阱与几何拓展.md` W5） |
| T4 角度跨 0° | θ=359° 与 1° 的角差必须用 `min(\|Δ\|, 360−\|Δ\|)` |
| T5 退化未讨论 | n=1 无界、方向近平行无界、无交集（数据矛盾）——必须分类讨论 |
| T6 与圆域求交 | 是否把 L 再 ∩ D(0,1800) 截断？**要声明**，两种口径给不同 D |
| T7 闭/开角域 | "±1°含不含端点"未声明 ⇒ 顶点算不算得进去 |
| T8 精度与容差 | 浮点下"点在角域内"要用容差 1e-9，否则边界点被误删 |
| M1 垂直平分线不出现 | 两站情形区域是四边形，不是垂线对——别套用"两直线交点"直觉 |
| M2 D 单调性误用 | 加检测点 D 单调不增（仅当真源在交中），别声称"点数越多越好"以外的性质 |
| M3 用 D 当"误差" | D 是长度（m），不是角度；与 ε 量纲不同 |

（完整分级见 `Q1模型假设与陷阱深挖.md` + `Q1陷阱与几何拓展.md`）

## 7. 创新点点透

| 创新 | 点透 |
|---|---|
| **1 半平面交统一建模** | 每个 2° 角域 = 2 个半平面 ⇒ n 个角域 = 2n 个半平面交，规约到计算几何标准问题，O(n log n)。比"射线两两求交 O(n³)"快且不会漏顶点 |
| **2 Jung 定理定量化** | 把"能否覆盖"从是非题升级为"最坏缺口 15.5%"。引经典定理，评阅友好，且给出等号条件（等边三角形） |
| **3 Thales 覆盖判据** | 把几何判断变成顶点角度的 O(m) 数值判据，可编程、可证明 |
| **4 双向验证（旋转卡壳 ⊕ 暴力）** | m 极小，两法必须给同一 D ⇒ 免费的自检，消除实现 bug |
| **5 误差传播闭式（小角近似）** | D ≈ 2d·sin ε / sin φ 的量级关系，把 D 与"站距 d、交会角 φ、误差 ε"直接挂钩，为 Q2 的选点提供解析依据 |
| **6 ε 单调性引理** | L(ε) 随 ε 单调扩张 ⇒ D(ε) 单调不减。这让"最坏情况分析"合法化（Q2 取 ε=1° 做鲁棒设计） |
| **7 退化分类学** | 把 n=1/近平行/空集/无界四种退化情形完整分类，逐个给出处理口径——展现严谨性 |

| 化归 | 点透 |
|---|---|

## 9. 非欧/射影几何评估点透（对标 VLSI 的"射影评估"节）

**直接结论：射影几何、非欧几何均不适用于 Q1。**

原因：
1. 射影变换**不保角度**——而本题的**全部信息就是角度**（示向度 ±1°）。在射影下"1°"没有意义 ⇒ 直接冲突；
2. 射影不保垂直、不保距离、不保圆（圆可变成圆锥曲线）⇒ "直径""圆覆盖"全部失效；
3. 非欧（双曲/球面）几何的"直线"不是欧氏直线，而本题明确约定"测向机与所有干扰源位于同一平面"（附录 2 §略 / 题设附录2(7)）⇒ 平面欧氏是题设给定，不是可选项。

**可借鉴的"对偶/结构"思想（射影精神，非射影操作）**：
- **D1 点-线对偶**：检测点 Sᵢ ↔ 角域边界射线。对偶空间里"角域交"变成"点集的对偶包"，可作理论小节的另一种表述（**不进方法层**）。
- **D2 极坐标/方位空间**：把每条示向度看作 (θ, d) 空间中的约束，L 是这些约束的交——与 Hough 变换（方位-距离投票）同源。**可在论文里一句点出"与 Hough 变换思想同源"，但不实现**。
- **D3 圆几何（Thales/Jung）**：这才是本题真正用到的经典几何——**进方法层**。

**论文定位建议**：射影/非欧放"理论讨论"一句带过并说明为何不适用（**说明不适用本身就是严谨性的体现**）；**圆几何（Thales、Jung）才是本文正牌工具**，应重点写。
