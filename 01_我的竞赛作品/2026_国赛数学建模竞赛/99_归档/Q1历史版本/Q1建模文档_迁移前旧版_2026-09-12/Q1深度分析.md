## 1. 题设精读

> "已知若干个检测点坐标及某干扰源关于这些检测点的示向度，请给出采用交会定位法（见附录 2）计算多边形定位区域直径（即区域内任意两点之间距离的最大值）的算法。以定位区域直径为直径的圆能否覆盖此定位区域？"

**逐词拆解**：

| 词 | 含义 | 建模影响 |
|---|---|---|
| 若干个检测点 | n 个，n 未指定 | n≥2 才有界；须讨论 n=1 退化 |
| 示向度 | 检测点处测得的最大场强方位角 | **带 ±1° 误差的角度观测**，不是位置观测 |
| 交会定位法 | 附录 2 图 2 给出 | 官方定义：**定位区域 = 角域交**（红线四边形） |
| 多边形定位区域 | 区域是多边形 | **点透**：角域凸 ⇒ 交凸 ⇒ 必为凸多边形 |
| 直径 = 区域内任意两点距离最大值 | 定义式 | 凸性 ⇒ 最远点对在顶点 ⇒ 可枚举 |
| 以直径为直径的圆 | 半径 D/2 的圆 | **最大概念坑**：一般**不能**覆盖 |
| 能否覆盖 | 是/否 | **证伪题**：需反例 + 判据 + 正解 |

**关键结论：Q1 = 有界角度不确定性下的方位交会定位区域的凸几何刻画 + 圆覆盖辨析。** 多项式可解（P），**无优化、无启发式**。

## 2. 约束与条件形式化

```
输入：n 个检测点 S₁…Sₙ；各站示向度 θ₁…θₙ；误差半角 ε = 1°
角域：Wᵢ = { Sᵢ + t·u(φ) : t ≥ 0, |angdiff(φ, θᵢ)| ≤ ε }
      等价：Wᵢ = {X: cross(uᵢ₋, X−Sᵢ) ≥ 0} ∩ {X: cross(uᵢ₊, X−Sᵢ) ≤ 0}
定位区域：L = ⋂ᵢ Wᵢ        （凸多边形）
主输出：D = max{‖p−q‖ : p,q ∈ L}
副输出：R_MEC（最小包围圆半径）
判定：以 D 为直径的圆是否覆盖 L
```

**三个要点**：
1. **唯一"不确定"来自 ε=1°**：ε→0 时 L 退化为点，D=0。**D>0 全部由这 1° 产生**。
2. **角域是射线族（t≥0）**，不是直线族——这是实现的第一红线。
3. **凸性由"角域=两半平面交"保证**，是后续一切算法的基础。

**两个必须声明的口径**（进论文假设节）：
- 闭角域（含 ±1° 边界）——保证 L 紧，D 可达；
- 是否与目标圆域 D(0,1800) 求交——**主口径不截断**（题设未给圆域约束）。

## 3. 数学结构深度理解

### 3.1 三层结构（对标 VLSI 的"三层下界"）

| 层 | 内容 | 性质 |
|---|---|---|
| **精确层** | L、D、顶点、面积**精确可算** | 无近似、无区间 |
| **夹逼层** | `D/2 ≤ R_MEC ≤ D/√3`（Jung 定理） | 覆盖问题的**定量**回答 |
| **判据层** | 覆盖 ⟺ 所有顶点 ∠PXQ ≥ 90°（Thales） | 可计算、可证明 |

**关键洞察**：本题**没有"下界论证"的需求**（不像 VLSI 的近似最优需要下界背书），因为答案是**精确**的。取而代之的理论亮点是 **Jung 夹逼**——它回答的是"直径圆差多少"，而不是"我们的解离最优多远"。

### 3.2 误差传播的量级

| 源距 | 1° 横向偏移（d·tan1°） |
|---|---|
| 1000 m | 17.455 m |
| 1500 m | 26.183 m |
| 1800 m | 31.419 m |

**点透**：这解释了为什么 Q1 值得单独成问——1° 在公里尺度上的放大与"20 m 清除半径"同量级，直接决定 Q3 的策略设计（必须 homing 逼近）。

### 3.3 基准算例画像（实测）

| 量 | 值 |
|---|---|
| 站 | S₁=(0,0)，S₂=(600,0) |
| 真源 | G=(300,500)（距两站 583.10 m） |
| 交会角 φ | 61.92° |
| 定位区域顶点 | (299.9,480.7) (311.9,499.8) (299.9,520.1) (288.3,500.0) |
| 边长 | 22.42 / 23.76 / 22.42 / 23.76 m |
| 对角线 | 23.73 / **39.61** m |
| **直径 D** | **39.61 m** |
| **R_MEC** | **19.80 m**（= D/2，**下界取等**） |
| γ | 1.000 ⇒ **本例覆盖成立** |
| D/20 m | 1.98 |

**几何结论**：
1. 中等交会角（62°）下，两站交会给出 ≈2 倍清除半径的区域 ⇒ **直接清除必失败**；
2. 本例区域近菱形 ⇒ 下界取等 ⇒ **覆盖成立**——这是"能覆盖"的典型；
3. **反例（上界取等）是等边三角形**（γ = 1.1547）——两者构成 §5 创新点 4 的对照图。

## 4. 建模：角域交 + 凸包 + 直径 + 最小包围圆

### 4.1 表示：半平面交（或射线求交）

| 方案 | 复杂度 | 适用 |
|---|---|---|
| 射线两两求交 + 过滤 | O(n³) | **n ≤ 8 首选**（本题典型 n=2~6），逻辑直观、易断言 |
| 半平面交（排序增量/分治） | O(n log n) | n > 8 |

### 4.2 直径

```
D = max{ ‖p−q‖ : p,q ∈ V }，V = 凸包顶点集
旋转卡壳 O(m log m)  ≡  O(m²) 暴力（双实现交叉验证）
```

### 4.3 覆盖判定与正解

```
判据：以直径端点 P,Q 为直径的圆覆盖 L ⟺ ∀X∈V: ∠PXQ ≥ 90°
正解：R_MEC（Welzl 期望 O(n)）
界  ：D/2 ≤ R_MEC ≤ D/√3，缺口比 γ = R_MEC/(D/2) ∈ [1, 1.1547]
```

### 4.4 终止与输出

本题无迭代，一次算完。输出：D、直径端点、顶点序列、R_MEC、γ、覆盖判定、（可选）区域面积 A_L。

## 5. 几何创新点考察（本报告重点）

### 创新点 1：半平面交统一建模（把测向问题规约到计算几何）
**想法**：每个 2° 角域 = 2 个过检测点的半平面之交 ⇒ n 个角域 = 2n 个半平面求交。
- **数学依据**：半平面与角域的等价性（F5）。
- **收益**：从"两两求交 O(n³) + 易漏顶点"升级到"标准半平面交 O(n log n)"，且方法学上把**无线电测向问题**接入**计算几何工具箱**。
- **论文价值**：一句话让评阅定位你的方法学——"本文将该问题规约为半平面交问题"。

### 创新点 2：Jung 定理定量化（覆盖问题的最优回答）
**想法**：不只说"不能覆盖"，而是给出"最坏差多少"。
- **数学依据**：Jung 定理 `R_MEC ≤ D/√3`，配合显然下界 `R_MEC ≥ D/2`。
- **收益**：把是非题升级为定量问题，**缺口 15.5%**，且等号条件明确（等边三角形）。
- **论文价值**：引经典结果（Jung 1901）而非自创命题，可信度与深度同时提升。

### 创新点 3：Thales 充要判据
**想法**：用圆周角定理把"几何覆盖"变成"顶点角度不等式"。
- **数学依据**：`(X−P)·(X−Q) = ‖X−M‖² − (D/2)²`。
- **收益**：O(m) 可计算判据，可编程、可证明。
- **论文价值**：从"画图说明"升级为"判据证明"。

### 创新点 4：下界取等 vs 上界取等的对照图
**想法**：把"基准算例（菱形，γ=1.000，可覆盖）"与"等边三角形（γ=1.1547，不可覆盖）"画在同一张图里。
- **收益**：一张图同时展示"什么时候能覆盖"与"什么时候不能"，可视化说服力极强。
- **论文价值**：这是 Q1 最有辨识度的一张图。

### 创新点 5：误差传播闭式（量级关系）
**想法**：`D ≍ 2ε_rad·d_eff / sin φ`。
- **收益**：把 D 与"站距、源距、交会角、误差"直接挂钩，**为 Q2 选点提供解析依据**（φ→90° 最优）。
- **诚实边界**：精确常数依赖几何构型，**只写 ∝ 关系**，不声称闭式精确解（基准算例验证：预测 23.1 m vs 实测 39.61 m，量级相符）。

### 创新点 6：ε 单调性与最坏情况分析
**想法**：`ε₁ ≤ ε₂ ⇒ L(ε₁) ⊆ L(ε₂) ⇒ D 单调不减`。
- **收益**：合法化"按 ε=1° 做最坏情况鲁棒设计"（Q2 直接受益）。
- **论文价值**：一个几乎免费的引理，撑起整个鲁棒性论证。

### 创新点 7：退化分类学（G1-G7）
**想法**：显式枚举 n=1 / 近平行 / 空集 / 退化为线段 / 退化为点 / 跨 0° / 边界归属 七类。
- **收益**：稳健性 + 严谨性；避免评阅用退化用例质疑。

### 创新点 8：多尺度不确定度描述
**想法**：除 D 外报 R_MEC、区域面积 A_L、最小宽度 w。
- **收益**：回应"单一标量 D 刻画不足"（M5），展示对"不确定度"的完整理解。
- **论文价值**：结果表更丰满，且与 Q3 的"何时可清除"直接关联（A_L 小 ⇒ 定位准）。

## 8. 待验证假设

2. **半平面交与射线求交的切换阈值**——需实测确定 n 的分界点（估计 n≈8）。
3. **误差是否严格为区间模型**——若评阅期待分布模型，需在"模型评价"一节说明选择理由。
4. **n 站时的最优站数**——D 随 n 单调不增，但边际收益递减；Q2 需给出"加几个站够了"的分析。
