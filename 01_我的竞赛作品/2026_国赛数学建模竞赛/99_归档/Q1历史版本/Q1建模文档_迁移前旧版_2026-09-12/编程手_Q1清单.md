## 阶段1：核心数据结构与基础函数

**【思路】** Q1 的全部对象是**点、向量、角域、凸多边形**。基础函数必须先写对，因为**顶点过滤**和**角度环绕**是两个最高频的 bug 源（建模手标为红线 W2/W3）。

- [ ] `angdiff(phi, theta) -> float` —— 角度环绕（见阶段0校验）
- [ ] `u(phi) -> (cx, sy)` —— 单位方向向量
- [ ] `cross(a, b) -> float` = `a.x*b.y − a.y*b.x`
- [ ] `Wedge(S, theta, eps)` 数据结构：
  - `apex`（顶点 S）、`theta`、`eps`
  - `rays`：两条边界射线 `r⁻ = S + t·u(θ−ε)`、`r⁺ = S + t·u(θ+ε)`，**t ≥ 0**
- [ ] `contains(W, P) -> bool` —— **点在角域内**（用两半平面形式，带容差）：
  ```
  cross(u_minus, P−S) >= -EPS  and  cross(u_plus, P−S) <= EPS
  ```
  【思路】用叉积判向，**必须带 EPS（1e-9）**，否则边界顶点会被浮点误差误删。
- [ ] `Polygon` 数据结构：顶点序列（**逆时针**、无共线点）

**自检**：
- [ ] 构造一个已知角域，验证 4 个点（内/外/边界上/顶点处）的 `contains` 判定

## 阶段2：核心算法（6 个模块）

**【思路】** 顺序很重要：**先做对的、慢的，再做快的**。M2+M3+M4-暴力 能立刻给出基准算例答案；只有在它对了之后，才加 M4-卡壳、M5-Welzl 这些"快但对不齐就找不到 bug"的实现。

### M1 角域构造
- [ ] `build_wedges(points, thetas, eps) -> list[Wedge]`

### M2 交点枚举 + 过滤 → 候选顶点
- [ ] `intersect_rays(rA, rB) -> Point | None`
  ```
  det = cross(uA, uB)
  if abs(det) < 1e-12: return None        # 近平行，跳过
  t = cross(B−A, uB) / det
  s = cross(B−A, uA) / det
  if t < 0 or s < 0: return None          # 射线反向，排除（W1）
  return A + t*uA
  ```
- [ ] `candidate_vertices(wedges) -> list[Point]`
  ```
  枚举 i<j，各自 a,b ∈ {−,+}  →  intersect_rays
  保留 P 满足：∀k: wedges[k].contains(P)   ← ★★★ 最高频 bug（W2），必写
  ```
  【思路】**顶点枚举引理的反向不成立**——两条边界射线的交点未必属于区域。漏掉 `∀k` 过滤，凸包含假点、D 偏大。**这是 Q1 第一大实现坑。**

### M3 单调链凸包
- [ ] `convex_hull(points) -> Polygon`（Andrew 单调链）
  - 【思路】用**严格** `cross <= 0` 剔除共线点（W8），否则旋转卡壳在共线边退化
  - 自检：Q1 基准算例必须恰好输出 **4 个顶点**

### M4 直径（**双实现，必须一致**）
- [ ] `diameter_bruteforce(poly) -> (D, (p,q))` —— O(m²)，**先写这个**
- [ ] `diameter_rotating_calipers(poly) -> (D, (p,q))` —— 旋转卡壳 O(m log m)
  - 【思路】卡壳实现注意**指针环回一圈即停**，否则死循环（W9）
- [ ] **断言**：两者结果**完全相等**（不是近似）

### M5 最小包围圆（**双实现，必须一致**）
- [ ] `mec_bruteforce(points) -> (center, R)` —— 枚举点对定圆 + 三点定外接圆，取能覆盖全体的最小者
- [ ] `welzl_mec(points) -> (center, R)` —— 随机增量，期望 O(n)
  - 【思路】必须正确处理边界集 0/1/2/3 个点的四种情形（W10）；洗牌时**固定随机种子**
  - 【思路】近共线三点外接圆病态 ⇒ 用 `EPS = 1e-12` 比较，近共线时用**最长边直径圆兜底**
- [ ] **断言**：两者 R 之差 < 1e-9

### M6 覆盖判定（Thales）+ 直径对枚举
- [ ] `thales_inside(P, Q, X) -> bool`：`dot(X−P, X−Q) <= EPS`（等价 `∠PXQ ≥ 90°`）
- [ ] `covers(poly, P, Q) -> bool`：`all(thales_inside(P,Q,X) for X in poly.vertices)`
  - 【思路】**只需校验顶点**——圆盘凸、`L = conv(V)` ⇒ 覆盖顶点即覆盖整个 L
- [ ] `all_diameter_pairs(poly, D) -> list[(p,q)]`：枚举 `‖p−q‖ ≥ D − 1e-9` 的顶点对
  - 【思路】**直径对可能不唯一，不同对给出不同的圆**（W5）⇒ 必须逐一报告：任取一对是否覆盖 / 是否存在一对覆盖 / 是否所有对都覆盖

### M7 有界性检查（定理 G0）
- [ ] `is_bounded(wedges) -> bool`：各方向区间 `[θᵢ−ε, θᵢ+ε]` 之交是否为空
  - 【思路】n=2 时等价于 `|θ₁−θ₂| ≥ 2ε`；不有界 ⇒ **直径未定义**，直接报"无界"，不返回 NaN
