### 3. 验证数据

**基准算例（已验证）**
```
输入：S₁=(0,0), S₂=(600,0), G=(300,500), ε=1°
输出：
  - 直径 D = 39.598327 m ✓
  - 最小包围圆半径 R_MEC = 19.799164 m ✓
  - γ = R_MEC/(D/2) = 1.000000 ✓（下界取等）
  - Jung上界：D/√3 = 22.862159 m ✓
```

**重要发现**
1. φ-D精确公式：`D = L·sin(2ε)/sinφ`（相对误差≤7×10⁻¹⁴）
2. 实测6000组：96.15%的γ精确等于1，max(γ)=1.006748 < 1.01
3. n站灵敏度饱和：2站39.60m → 3站30.30m → 4站24.19m → 5/6站不变
