## 快速开始

### 第一步：配环境

打开 `编程手工具大全.md`，按推荐组合配好环境：
- **编辑器**：VS Code + Python插件
- **环境**：Miniconda，创建数模专用环境
- **基础库**：NumPy + SciPy + Pandas + Matplotlib
- **优化求解器**：Gurobi（学术免费）+ scipy.optimize
- **启发式**：scikit-opt

### 第二步：读移交包

建模手完成建模后，会在 `02_建模手/QX/` 下放移交包：
- `00-移交说明.md`：文件清单、验证题、红线制度
- `QX深度分析.md`：算法思路
- 数据文件

**先读移交说明，再动手写代码。**

### 第三步：按清单执行

打开 `QX/编程手_QX清单.md`，按P0→P1→P2顺序执行：
1. 数据解析
2. 核心算法实现
3. **验证题复算（必须通过！）**
4. 正式数据运行（至少10次取最优）

### 第四步：反馈问题

发现理论问题时，填写 `QX/理论问题反馈.md`，及时通知建模手。

### 第五步：归档结果

- 实验数据放在 `QX/实验结果/`
- 可复用代码移到 `代码库/`
- 废弃代码移到 `99_归档/`

## 核心方法论

### 每步【思路】标注

不要只写代码，每一步都要写为什么这么做：

```python
# 【思路】用B*-Tree表示布局，因为可以O(n)计算面积
class BStarTree:
    ...
```

### 验证题机制

- 建模手会提供已知答案的验证题
- 编程手必须先跑验证题，答案对了再跑正式数据
- 验证题不对 → 查bug，不要硬跑正式数据

### 纪律要求（必须遵守）

1. 每步写【思路】
2. 验证题不对不跑正式数据
3. 不自行改模型假设
4. 不删除旧代码
5. 多次运行取最优（N≥10）
6. 固定随机种子，保证可复现

## 代码库规范

可复用的核心代码放在 `代码库/`：
- 命名：`功能_版本.py`，如 `bstar_tree_v1.py`
- 每个文件顶部写说明：功能、用法、作者
- 函数要有docstring
- 关键算法要有【思路】注释
