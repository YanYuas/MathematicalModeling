## 一、模型假设系统化（每条带"若违背"后果）

### H1 几何与物理假设

| 假设 | 内容 | 若违背的后果 | 论文写法 |
|---|---|---|---|
| **H1.1** | 平面欧氏几何：测向机与所有干扰源位于同一平面 | 非欧/球面几何下"角度、距离、圆"全部变形 ⇒ 交会模型失效 | `附录2(7)` 题设给定，直接引 |
| **H1.2** | 目标区域 = 半径 1800 m 的闭圆域 `D((0,0),1800)`；坐标 x 东 y 北，正东 0° 逆时针正 | 圆域变了 ⇒ 覆盖面积极变、网格点数失效 | 题设给定 |
| **H1.3** | **误差是有界区间模型**（`δ ∈ [−1°,1°]`），**不是概率分布** | 若按概率建模 ⇒ 需引入题面未给的分布假设，结论失去确定性 | 必须在假设节**显式声明**"有界不确定性模型"，并说明为何拒绝统计模型 |
| **H1.4** | 示向度 = 真方位 + δ，`\|δ\| ≤ 1°`；**同一地点 δ 固定**，换点重新抽取 | 若误认为每次测量独立 ⇒ 会做同点重复测量（零信息，白花 5 s） | `附录2(1)` 原文 |
| **H1.5** | 定位区域 `L` = 多个 2° 角域之交（**闭角域**，含 ±1° 边界） | 开角域 ⇒ `L` 非闭，最远点可能取不到，`D`/`R_MEC` 不达 | 沿用 Q1 口径；声明"取闭角域以保证紧性" |
| **H1.6** | 全向源场强仅随距离衰减、与角度无关；`R_eff` 内必可测 | 违背后"覆盖 ⇒ 必被发现"不成立 ⇒ **定理 C 第 2 步的前提失效**（Q4 的情形）；**升级发现条件为 surrounding 后可重建**（Q4 命题 Q4-E） | `附录1(3)(4)`；**Q3 的完备性完全依赖此条，须重点声明** |
| **H1.7** | 清除成功仅取决于真实距离 ≤ 20 m，**与朝向、与 `R_eff` 无关** | 若清除受朝向限制 ⇒ 清除判据 `R_MEC ≤ 20` 失效，**且扫掠清除（Q4-F32）不成立** | `附录2(8)` 原文（"与干扰源信号有效覆盖角度范围无关"）；**Q4 中此条是主心骨** |
| **H1.8** | 距离 ≤ 5 m 且覆盖内时返回 `near`，**不返回示向度** | 若以为 near 也给角度 ⇒ 丢失"可原地清除"的捷径信息 | `附录2(9)`；`near` 是**可直接清除**的信号 |

### H2 问题结构假设

| 假设 | 内容 | 若违背的后果 | 论文写法 |
|---|---|---|---|
| **H2.1** | 源数 `k ∈ [10,16]`，具体未知 | 若 `k` 可知 ⇒ 可用计数作停止条件，定理 C 可简化 | 题设给定；**必须声明"总数未知"才需要完备性论证** |
| **H2.2** | 每源频道互不相同、位于 1..20、不随时间变化；一源一频道 | 若频道可复用 ⇒ 一次 `success` 不能确定该频道清完 | `附录1(1)` |
| **H2.3** | 不同干扰源的信号互不影响 | 若相互干扰 ⇒ 示向度可能对应多个源，交会模型失效 | `附录1(2)` |
| **H2.4** | 目标区域中**均为全向源**（Q3） | 见 H1.6 | 题设给定；**Q4 明确打破此条** |
| **H2.5** | 每源有效接收半径 `R_i ∈ [1000,1500]`，**接口不返回** | 若误按 1250/1500 设计覆盖 ⇒ 漏掉远处源 | `附录2(2)`；**取最坏 1000（引理 W(a)）** |
| **H2.6** | 环境在单次测试内静态：源不动、频道不变、`R_eff` 不变 | 若源会移动 ⇒ 覆盖与交会结论全部失效（需在线重估） | 题设未提运动，按静态建模并**在假设节声明** |
| **H2.7** | 请求串行：一次动作收到完整响应后再发下一个；无并发 | 并发会触发 HTTP 409 或语义错乱 | `附件2` §1.4 明文要求 |
| **H2.8** | 单只机器狗、起点 (0,0)、初始频道 1 | 多机时下界与覆盖结构改变（多旅行商） | 题设给定；多机仅作 §12 开放问题 |

### H3 数据与接口假设

| 假设 | 内容 | 若违背的后果 | 论文写法 |
|---|---|---|---|
| **H3.1** | 虚拟耗时规则：移动 `‖ΔP‖/5`；检测 5 s；切频 1 s（仅当频道变化）；清除 5 s（成功）/ 3 s（未发现） | 计时口径错 ⇒ 上报的"平均定位清除时间"整篇错 | `附件1` §2 / `附件2` §4；逐项对应 Q3-F27–F29 |
| **H3.2** | **双钟**：虚拟时间 = 上报口径（无实质上限）；现实时间 = 硬约束 ≤ `min(1200 s, 窗口剩余)` | 混淆 ⇒ 目标与约束互换，策略方向错 | **Q3 的第一口径问题**，见 `Q3全解总览.md` §2.1 |
| **H3.3** | `request_id` 是会话内幂等键：新动作新 ID；**仅**网络失败重测同一动作时复用原 ID + 原内容 | 复用 ID 改内容 ⇒ HTTP 409；新动作复用旧 ID ⇒ 动作被去重而**静默丢失** | `附件2` §5.3 |
| **H3.4** | 必须**同时**检查 HTTP 状态与 `accepted` | 只看其一 ⇒ 把 `accepted=false` 当成功，状态机污染 | `附件2` §5.2/§5.3 |
| **H3.5** | 坐标：有限数值（无 NaN/∞），`\|x\|,|y| ≤ 2000000`；`channel` 为 1..20 的**整数**（`1.0` 可，`1.5` 报 400） | 越界 ⇒ HTTP 400，动作不执行且**不推进位置与虚拟时间** | `附件2` §1.1/§5.1/§7.4 |
| **H3.6** | 必须使用 `/enter` 返回的 `remaining_real_duration_s ∈ [0,1200]`，**不得假定 1200** | 晚进入时按 1200 规划 ⇒ 超时中止，**占用一次正式测试机会** | `附件2` §4.5/§12 |
| **H3.7** | 机器狗程序须自行记录指令序列与响应（模拟器无此功能）；加密日志上传上限 2 MB | 日志超限或缺失 ⇒ 支撑材料不合规 | `附件2` §12 |
| **H3.8** | 判读结果用英文码（`direction/near/no_signal/success/no_target_in_range/user_exit`），**不依赖界面中文** | 依赖中文 ⇒ 界面变动即失效 | `附件2` §12 |
| **H3.9** | 接口**不返回**：源数、位置、频道集合、有效接收半径 | 若假定某信息可得 ⇒ 整条推理链空中楼阁 | `附件2` §1.3/§2.1 |
| **H3.10** | 未声明的 JSON 字段 ⇒ HTTP 200 + `accepted=false`（**不被忽略**） | 字段拼错却被"忽略" ⇒ 实际返回 `accepted=false`，动作未生效 | `附件2` §5.1（这是"帮发现拼写错误"的设计） |

### H4 算法假设

| 假设 | 内容 | 若违背的后果 | 论文写法 |
|---|---|---|---|
| **H4.1** | 检测点集对 `D(0,1800)` 的 1000-覆盖**包含边界** | 边界缝隙 ⇒ 边界附近的源永不 no_signal 也永不被发现 ⇒ **定理 C 失效** | 覆盖自检（Q3-F11）必须**边界加密** |
| **H4.2** | 用于交会的两个检测点**必须互异** | 同点 ⇒ `δ` 固定 ⇒ 两个角域几乎重合，`L` 巨大甚至无界（零新信息） | `附录2(1)` 直接推论 |
| **H4.3** | homing 的距离估计 `r̂` 由 Q1 交会区域给出 | 无距离估计 ⇒ 步长盲选，过冲风险 | 引理 H2 的工程版 |
| **H4.4** | 距离估计相对误差 `η ≤ D/r ≤ 2ε_rad = 0.0349066` | 低估 `η` ⇒ `λ_safe` 偏小，homing 提前判停，落点超 20 m | 保守取上界；实测可收紧（**待标定**） |
| **H4.5** | 现实时间充足：`n_req·τ_req ≪ 1200 s` | 高频请求 ⇒ 现实超时 | 约束式 Q3-F36；`τ_reserve ≈ 60 s` |
| **H4.6** | 数值判定用容差 `1e-9`（边界点归属、Jung 界断言） | 浮点误差把边界顶点误删/误判 ⇒ `L` 少一个顶点 ⇒ `D` 错 | 与 Q1 同口径 |

## 二、建模级陷阱深挖（M1–M17）

> M 类 = **自己容易犯的建模错**。每条给"为什么容易犯 + 后果 + 对策"。

| 编号 | 陷阱 | 触发条件 | 后果 | 规避方法 |
|---|---|---|---|---|
| **M1** | **把"发现"当"可清除"** | 认为"测到 `direction` 就能清" | 发现半径 ≥1000 m 与清除半径 20 m 差 **50 倍**；直接清必失败 | 建立"发现 ≠ 可清除"的分界；用 `R_MEC ≤ 20` 判据 |
| **M2** | **用 D 而非 `R_MEC` 作清除判据** | 图省事用 Q1 最显眼的输出 D | Jung 给的是**充分非必要**；`34.6410 < D ≤ 40`（γ≡1 时）本可直接清除却被判需 homing ⇒ 白付 homing | 用充要判据 `R_MEC ≤ 20`（定理 G3）；D 只作充分代理备用 |
| **M3** | **把"覆盖"当"布点够多就行"** | 凭直觉布点或按均值半径设计 | `R_w` 用错或边界漏覆盖 ⇒ 漏源 ⇒ **定理 C 失效** | `R_w = 1000` 最坏 + 三角格 + 边界自检 |
| **M4** | **用计数作停止条件** | 写"清够 16 个就退出" | 总数未知；若实际 k<16 会一直等，若逻辑漏洞会漏源 | 用完备性停止条件（定理 C） |
| **M5** | **忽视空频道确认成本** | 认为"没有 signal 的频道就没源" | 违反完备性；且成本 `(20−k)×N×5`（k=10 时 400 s）漏算 ⇒ 结论"比下界还快" | 显式列成本项（Q3-F34）；顺路在阶段 A 完成 |
| **M6** | **沿示向度一路走到底** | 把 homing 当成"朝那个方向走" | 越过源后 continue 走到远处，反复来回 | 用收缩步长 `h ≈ r̂`（引理 H2）+ 反向检测兜底（Q3-F45） |
| **M7** | **homing 用固定步长** | 图简单取 h=200~300 m 常数 | 近距离时大幅过冲；远距离时步数过多 | 自适应 `h_k ≈ r̂_k`；固定步长只作降级模式 |
| **M8** | **单点示向度就判"已定位"** | 测到一个 `direction` 就以为知道源在哪 | 单条示向度是无界楔形（Q1 已证），`L` 无界、`D` 未定义 | 必须 ≥2 个**异点**示向度；单点情形走 homing |
| **M9** | **同点重复测量** | 想"再测一次确认" | `δ` 固定 ⇒ 结果完全相同，白花 5 s | 换点再测（H1.4） |
| **M10** | **忘记圆域截断可免费收紧 `L`** | 只用角域交求 `L` | 丢掉"源必在 1800 圆内"这一免费信息，`R_MEC` 偏大 | `L* = L ∩ D(0,1800)`（Q3-F14）；论文声明口径 |
| **M11** | **把"平均定位清除时间"当直接目标优化** | 想"最小值优先" | 分母（清除个数）有自由度 ⇒ **漏源反而让指标变好看**，病态激励 | 先用完备性把分母锁死，再优化时间 |
| **M12** | **混淆虚拟时间与现实时间** | 用墙钟估"定位清除总时间" | 口径错 ⇒ 上报数据整篇不可用 | 双钟分离（`Q3全解总览.md` §2.1） |
| **M13** | **假定每局都有 1200 s** | 硬编码超时预算 | 晚进入时不足 ⇒ 超时中止，浪费一次正式测试 | 读 `remaining_real_duration_s`（H3.6） |
| **M14** | **用最近邻贪心当路径最优** | 图快 | 路径偏长；移动是总时间大头 | N ≤ 12 ⇒ 精确 DP（`O(N²2^N)`）或 2-opt |
| **M15** | **声称"随机撒点也能保证覆盖"** | 把"高概率覆盖"当"保证覆盖" | 完备性论证失效（存在正概率缝隙） | 只用确定性覆盖（三角格） |
| **M16** | **把 Q2 的"选点优化"照搬到 Q3** | 想"给每个源优化第二检测点" | Q3 的检测点由**覆盖约束**锁定，不自由选点；照搬会破坏覆盖 | 显式说明两问差异（`Q3建模数学化.md` H.2） |
| **M17** | **认为"源少就轻松"** | 直觉 `k` 小 ⇒ 快 | 空频道确认成本 `(20−k)N·5` **与 k 反相关**；k=10 比 k=16 多付 240 s | 显式计入（M5 同一根源） |

### T21 · 把「单点最坏」当作「全域上界」

| 项 | 内容 |
|---|---|
| **表现** | 用「源恰在格心 ⇒ `φ_nat = 120°`」算出 `R_MEC ≤ 34.9066 m`，随即断言这是**参数域上界**，并据此推出「扫掠恒优于 homing」 |
| **机理** | `φ_nat = 120°` 只是**一个构型**。源靠近**两格点连线**时 `φ → 180°`，定位区域退化为弓形，`R_MEC → d/2`（d=1500 约 **750 m**）——比 34.9066 m 大 **21 倍** |

| **反例** | 源 `(−1153.3, −600.6)`，两格点夹角 `φ = 179.994°` ⇒ `R_MEC = 718.75 m` |
| **对策** | ① 「最坏情形 = 源在单元中心」**必须证明**，否则改写成条件命题；② 涉及"全域/上界/恒成立"的结论一律先做**面积均匀抽样**；③ 策略按 `R_MEC` **分布**设计 |
