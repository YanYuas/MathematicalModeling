> **触发点**：旧判据「13 点巡回 12000 m 是下界、2-opt 已到地板」**只是均匀三角格的性质**，
> 不是"13 点 1-覆盖圆域"的性质。三角格的巡回结构是"内外环来回跳"（径向跳 732 m × 12 次）；
> **把外环半径收进来**即可大幅缩短。1-覆盖由**内环 `d` + 两环错开 30° 填角**决定，故退化很小。
>
> ⚠️ **巡回更短 ≠ 更好，且理论外推不可靠**：离线 3 种子均摊随 `r_outer` **非单调** ——
> 1500→313.7、1400→316.9、**1300→306.9（最优）**、1100→313.6、**1000→339.6**。
> 收到 1100/1000 后巡回继续变短、均摊反而变差：**「2-观测缺口」里的源离最近格点变远**
> （483→683→782 m），阶段 C homing 起点变远、代价暴涨。
> ⇒ **目标函数不能只含巡回长度，必须含"缺口中源到最近格点的距离"。现有成本模型（F59 等）没有这一项。**

## 三、成本层（两个钟）

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F26 | **虚拟时间分解** | `T_vir = T_move + T_measure + T_switch + T_clear + T_optical` | = 最终 `virtual_time_s`；**上报口径的分子** |
| F27 | 移动耗时 | `T_move = Σ ‖ΔP_k‖ / 5` | 速度 5 m/s |
| F28 | **检测耗时** | `T_measure^{(k)} = 5 + 1·[channel_k ≠ channel_{k−1}] + ‖ΔP_k‖/5` | 切换只由**成功的 /measure** 触发 |
| F29 | **清除耗时** | `T_clear^{(k)} = (5 若 success 否则 3) + ‖ΔP_k‖/5` | `/clear` **不产生**切换耗时、**不改**频道（附件2 §4.4） |
| F30 | **现实时间约束** | `T_real = T_end − T_enter ≤ min(1200 s, 25 min 窗口剩余)` | **硬约束**；与 F26 不同钟 |
| F31 | 可用现实时间 | `T_real^{avail} = remaining_real_duration_s ∈ [0, 1200]` | 必须**读响应值**，不得假定 1200 |
| F32 | 单点全频道扫描成本 | `c_scan = 20×5 + 19×1 = 119 s` | 首频道可用当前频道省 1 次切换 |
| F33 | 全网格扫描成本 | `C_scan = N·c_scan` | N=8 ⇒ **952 s** |
| F34 | **空频道确认成本** | `C_empty = (20 − k)·N·5` | k=10 ⇒ **400 s**；k=16 ⇒ 160 s。**固有成本** |
| F35 | 平均定位清除时间 | `T̄ = T_vir / k_cleared` | 题面第二指标；完备时 `k_cleared = k` |
| F36 | 请求总数约束 | `n_req · τ_req ≤ T_real^{avail} − τ_reserve` | `τ_req` = 单请求往返开销；`τ_reserve` ≈ 60 s 收尾裕量 |

## 四、清除与 homing 控制律（保证收敛与必中）

> v1.1.0 起本节含两条清除路线的公式：homing（F37–F45）与**扫掠清除**（F56–F60）。

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F37 | 一步后真实距离 | `r' = √( r² + h² − 2·r·h·cos δ )`，`\|δ\| ≤ ε` | 沿测得方位走 h 步的精确式 |
| F38 | 最优步长 | `h* = r·cos δ ⇒ r' = r·sin\|δ\| ≤ r·sin ε` | 需知 δ，不可实现；作理论基准 |
| F39 | **免知识步长** | `h = r ⇒ r' = 2r·sin(\|δ\|/2) ≤ 2·sin(ε/2)·r` | **无需知道 δ** |
| F40 | **收缩率（理想）** | `λ = 2·sin(ε/2) = 0.0174531` | 与 δ 无关；ε=1° |
| F41 | 距离估计相对误差 | `η ≤ D / r ≈ 2·ε_rad = 0.0349066` | 由 Q1 交会区域给出 r̂ |
| F42 | **收缩率（工程）** | `λ_safe = sin ε + 2·ε_rad = 0.0523590` | 含 r̂ 误差的最坏收缩 |
| F43 | k 步后距离 | `r_k ≤ λ^k·r_0`（`λ ∈ {λ, λ_safe}`） | `r_0 ≤ 1500` |
| F44 | 步数估计 | `K = ⌈ ln(r_target/r_0)/ln λ ⌉`；`r_target = 5`（near 阈值） | λ ⇒ 2 步；λ_safe ⇒ 2 步 |
| F45 | 过冲检测 | 若 `\|angdiff(θ_new, θ_old)\| > 90°` ⇒ 已越过源 ⇒ 半步回退重测 | 工程兜底（r̂ 有偏时） |
