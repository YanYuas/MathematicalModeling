## 一、工作流程复盘（可复用的五步法）

Q3 走的是与 Q1/Q2 同一套流程，但顺序上有一处关键调整：

```
① 口径先行：先把"两个钟""分母是清除个数""清成功只与距离有关"三条口径钉死
   ↓（Q1/Q2 是"几何先行"，Q3 是"口径先行"——因为 Q3 的口径比几何更容易错）
② 三层分解：覆盖层（静态可行性）/ 定位层（局部可判定）/ 成本层（可度量）
   ↓
③ 找接口：把 Q1 的 R_MEC、Q2 的 φ=90° 直接接进来 → 得到清除判据与网格间距红线
   ↓
④ 建保障：完备性定理（硬约束）+ homing 收缩引理（逼近保证）+ 三层下界（评价标尺）
   ↓
⑤ CAS 复核：所有解析数值独立复核，抓到 4 处错（见 §三）
```

**为什么 Q3 要"口径先行"**：Q1/Q2 的核心风险在几何（几何错了结论就错）；
Q3 的核心风险在**口径**——两个钟、分母、清除条件，任何一条错都会让整篇数据不可用，
而几何（覆盖、交会、homing）反而是可以直接继承 Q1/Q2 的成熟部分。
**风险在哪里，就先钉哪里**——这是本次最有用的一条流程经验。

## 三、分析阶段真实踩过的坑（非示例）

### 坑 1：覆盖密度公式记错——写成 `2π/√3`

**经过**：凭记忆写"平面等圆覆盖最优密度 `2π/√3 ≈ 3.6276`"，代入得 `N ≥ 11.75`，
与面积界 `N ≥ 4` 相差 3 倍，**明显不合理**才发现不对。
**正确值**：三角格覆盖密度 = `πr² / ((3√3/2)r²)` = **`2π/(3√3) = 1.2091996`**（我漏了分母的 3）。
**教训**：**记住的常数必须验证**。凡是"经典常数"，要么查证要么当场推。
本项目有 CAS 工具，成本几乎为零——**这条坑完全可以用一次 CAS 调用避免**。
（发现后立即 CAS 复核：`2π/(3√3)·3.24 = 3.9178066 ⇒ N ≥ 4`，与面积界一致，结论未变。）

### 坑 2：三个数值手算错（CAS 抓出）

| 量 | 我手算的 | CAS 正确值 | 偏差 |
|---|---|---|---|
| `R_MEC`（d=1500，φ=120°） | 30.24 | **30.2300** | +0.010（0.03%） |
| `R_MEC`（d=1000，φ=120°） | 20.16 | **20.1533** | +0.007（0.03%） |
| `1500·λ_safe` | 78.5398 | **78.5385** | +0.0013（0.002%） |

**教训**：**三位以上有效数字的乘法一律走 CAS**。手算只在"量级估算"阶段可用（如判断 3.6 与 1.2 哪个合理）。
注意坑 2 的第三个数字错得极小（78.5398 vs 78.5385），**手工复核根本看不出来**——
这正是"必须用工具"的理由。

### 坑 3：差点用 `D ≤ 40` 作清除判据

**经过**：第一版思路是"Q1 的 D ≤ 2×清除半径 = 40 ⇒ 可清除"，因为 `D` 是 Q1 最显眼的输出。
**问题**：`D` 与 `R_MEC` 的关系是 Jung 夹逼 `D/2 ≤ R_MEC ≤ D/√3`，**`D ≤ 40` 只是充分条件**；
在本题区域族的实际情形（γ ≡ 1，`R_MEC = D/2`）下，`34.6410 < D ≤ 40` 这一整段**本可直接清除**却被判成需要 homing。
**教训**：**"够用的代理量"与"充要的判据"要分清**。当手上有更紧的界（`R_MEC` 可精确算）时，
不要退回到松的界（`D`）——松的界不会算错，但会**平白多付成本**，且丢掉原结论的精度。
**副产品**：这个自查促成了"用 Chebyshev 中心（最小包围圆圆心）作清除点"的正确定位（并发现该术语有歧义，见 `Q3陷阱与几何拓展.md` W18）。

### 坑 4：把"虚拟时间 3500~5000 s"与"现实时间上限 1200 s"当成矛盾

**经过**：读到权威数字表 §二 写"Q3 虚拟时间预算 ≈3500~5000 s"，同时又读题面"程序运行时间最长 20 分钟 = 1200 s"，
第一反应是"数字表算错了，怎么可能 5000 > 1200"。
**真相**：**两个钟**。虚拟时间（`virtual_time_s`）是上报口径、上限 360000 s；
现实时间（墙钟）是硬约束 1200 s。5 s 检测**不占现实时间** ⇒ 虚拟 5000 s 可能只花现实几十秒。
**教训**：**看到"两个数字互相矛盾"时，先怀疑自己漏了一个维度**，而不是怀疑数据。
这个坑一旦没绕过，整篇 Q3 的口径会全错（会把目标与约束互换）。
**副产品**：这件事直接催生了文档里 `§2.1 双钟分离` 那一节，成了 Q3 最被强调的一条口径。

### 坑 5：差点把"深度钻研报告"的估算当结论引用

**经过**：`01_背景研究/B题-无线干扰源-深度钻研.md` §7.5 有一张"扫描成本预算"表，
给出 3500~5000 s 的合计，写得很像结论。
**问题**：那是**赛前估算**，没有实测、也没标"待验证"，且其中一项（网格点数）在 §二 已被修正过
（30~45 点 → 7~9 点，见权威数字表 §七 留痕）。
**对策**：把它降级为"参考估算"，另建**三层下界**（L1=703.7168 s / L2=1178.72 s）作真正的标尺，
并显式写出"估算与下界差 3~4 倍"的**归因**（全频道保险扫描 + homing + 收尾确认）。
**教训**：**赛前估算可以借思路，不能借数字**。凡是"看起来像结论"的旧文本，先问它有没有验证状态标注。

### 坑 6：`φ_nat` 直觉以为是 90°，实际是 120°

**经过**：因为 Q2 的核心结论是"φ=90° 最优"，接手 Q3 时直觉认为"网格的自然交会角应该也是 90°"，
于是按 90° 算 `d ≤ 1145.9156 m`。
**问题**：三角格中，**源落在单元中心**时到最近两个格点的距离都是 `d/√3`，两格点相距 `d`。
解这个三角形得 `cos φ = −1/2 ⇒ φ = 120°`，**不是 90°**。
**教训**：**继承结论 ≠ 继承数值**。"φ=90° 最优"是 Q2 的**最优选点结论**，
而 Q3 的检测点被**覆盖约束**锁定，不能自由选点 ⇒ 自然几何由格型决定，必须重新算。
**这个坑如果不绕过来，`d ≤ 1145.9156`（错）与 `d ≤ 992.3920`（对）差 15%**，
会让编程手生成一个"以为免 homing 但实际每源都要 homing"的网格。

### 坑 7：差点漏掉空频道确认成本

**经过**：算 L2 下界时先写 `移动 + 2k·5 + k·5`，结果 833.72 s，
与 §7.5 估算差 5 倍多，觉得"下界太松、没意义"。
**问题**：漏了 **`(20−k)×N×5` 的空频道确认成本**——而它是完备性定理的**必要条件**
（不知道哪些频道是空的，就不能说"清完了"）。加上 280 s 后 L2 = 1178.72 s，与估算的差距缩小到 3~4 倍。
**教训**：**算下界时，把"完备性要求的动作"逐条过一遍**，不要只数"对源做的动作"。
**并且注意它是反向因子**：k 越**小**，空频道越多、成本越**大**（k=10 时 400 s）——
直觉（"源少更轻松"）在这里是错的。

### 坑 8：一度想用"随机撒点 + 高密度"替代覆盖论

**经过**：早期考虑"随机撒很多点，密度足够高就能覆盖"，因为实现简单。
**问题**：随机撒点只能给**概率覆盖**（"漏一个源"的概率小但非零），而题面要求"**确保**"。
要用随机达到确定性覆盖所需的点数**远超**覆盖论下界（经典的 ε-网/生日问题现象）。
**对策**：改用三角格（确定性覆盖半径 `d/√3`，一次性锁死 `d ≤ 1732.0508`）。
**副产品**：在对比格型时发现**正方形格在 d=1500 下覆盖半径是 `d/√2 = 1060.66 > 1000`，根本不满足约束**——
这比"三角格密度最优"是**更硬的理由**，也成了论文里一个很好的对照点。

## 五、三手协作经验（Q3 视角）

### 建模手（总指挥）→ 编程手

- **给判据，不给"感觉"**：本次交付的核心是三条**可执行判据**
  （`R_MEC ≤ 20` 判直接清除、`λ_safe` 判 homing 停止、`σ(c)` 状态表判停机），
  而不是"应该差不多了"。
- **给验收线**：`Q3深度分析.md` §4.3 明确"验收线 ①（判据回归 + 覆盖自检）不过，不准往下走"——
  与 Q2 的"验证题不对，不跑参数扫描"同一纪律。
- **双轨交给实测**：`d` 的两个取值都给出解析结论，**不替编程手拍板**，但要写清"为什么只能实测定"。

### 建模手 → 论文手

- **公式编号可直接引用**：`Q3公式表.md` 的 F1–F61（v1.1.0）与正文一一对应，论文公式按此编号。
- **证明已备好**：命题 C.1–C.7 均有完整证明（含 NP-hard 归约），论文手无需自行推导。
- **8 张图清单已给**（`Q3全解总览.md` §11），且每张都说明"要展示什么"。
- **诚实素材已备**：下界与估算的 3~4 倍差距**连同归因**一起给，论文按"下界 + 构造值 + 归因"三段式写。

`02_建模手/实践反馈融入.md` 与 `00_任务总控/权威数字表.md` §五。

## 六、可复用到 Q4 的方法论

| 方法 | Q3 怎么用的 | Q4 怎么用 |
|---|---|---|
| **取最坏值 + 保证** | `R_w = 1000`、`\|δ\| ≤ 1°` | 同样：定向方向未知 ⇒ 取最坏朝向 |
| **口径先行** | 先钉双钟与分母，再谈几何 | Q4 同样先钉"`no_signal` 三义"的口径 |
| **三层分解** | 覆盖 / 定位 / 成本 | Q4 加"确认层"（区分空频道与盲区） |
| **找接口** | 直接接 Q1 的 `R_MEC`、Q2 的 φ=90° | **Q4 可直接继承 Q3 的覆盖、交会、`R_MEC` 判据、homing** |
| **可判定停止条件** | 定理 C | **前提失效点已定位** ⇒ 升级发现条件为 surrounding 可重建（Q4 命题 Q4-E） |
| **收缩引理** | homing（只看示向度，与盲区无关） | **Q4 仍成立**，但须先进入覆盖扇区才能拿到示向度 |
| **下界 + 构造 + 归因** | Steiner 下界 | 同框架；注意盲区会**抬高**下界（须多测才能确认） |
| **CAS 复核每个数** | 抓出 4 处错 | **照做**（本次坑 1/2 全部靠它发现） |

**给 Q4 的一句话**：
**Q4 = Q3 + "`no_signal` 从二义变三义"。⇒ 只有完备性论证需要重建，其余（覆盖、交会、清除判据、homing）全部可直接继承。
不要从零开始，也不要把 Q3 的定理 C 直接搬过去——它的第 2 步会被盲区打断。**

## 七、一句话总结

**Q3 最花时间的不是数学，而是"口径"：两个钟、分母、清除条件，任何一条错都让整篇数据不可用。
最有用的一条纪律是"每个常数都过一遍 CAS"——本次 8 个坑里有 2 个（覆盖密度公式、三个数值）
纯靠 CAS 抓出，手算复核看不出来。
最关键的一个判断是"拒绝 RL"：题面的误差是区间、总数未知、要求"确保"——
一句话就决定了这是一道"覆盖论 + 可判定性"的题，而不是一道"学习"的题。**

## 九、v1.1.0 修正记录（写 Q4 时回改的两处）

> **触发**：编写 `02_建模手/Q4/` 时对 Q3 结论的复核。现记为**第 9 个真实踩坑**（前 8 个见 §三）。

### 坑 9：把"清除"只当成"定位完成后的一次动作"，漏掉了 `/clear` 自带的判定信息

**经过**：写 Q3 时把清除模式二分为"`R_MEC ≤ 20` ⇒ 直接清除；否则 homing"，
并据 homing 的 ≈213.49 s/源 推算出 `d=1500` 明显不如 `d=1000`。

**问题**：`附录2(8)` 明说清除成功**只与距离有关**（与朝向无关）⇒
**`/clear` 的返回值本身携带信息**：`success` / `no_target_in_range` 就是一个"源是否在 20 m 内"的判定。
⇒ 已知 `G ∈ L` 时，用 20-半径盘覆盖 `L`、逐个 `/clear`，**必有一次成功**（扫掠清除）。
成本 `10N`（`N = 3` 时 ≈30 s），比 homing 省 7 倍；拐点 `R* = 84.0369 m`。

**修正**：清除扩为三路；`d=1500` 的代价从"213.49 s/源"改为"30 s/源"；
`d` 的取舍由"明显倾向 1000"改为"几乎打平，改由裕量与定位富余决定"。

**教训（新增方法论）**：**把"动作"也当成"观测"来审视。**
凡是返回值携带信息的动作（`/clear`、将来的其它接口），都不只是"执行"，
而是一次**测量**——测量就可以用来减少不确定性，而不只是消耗时间。
这个视角差异直接改变了一个主参数的结论。

### 坑 10（表述）：把"定理的前提失效"写成了"定理失效"

**经过**：认定 Q4 的定向盲区会让完备性论证失效，在 Q3 多处写下"定理 C 失效"。

**问题**：失效的是**定理第 2 步的前提**（"全向 ⇒ 覆盖内必可测"），不是**结论**。
把发现条件从"1000-覆盖"升级为"surrounding"（源被检测点包围）+ 检测点外扩环带后，
定理**仍然成立**。写"失效"会让人以为 Q4 无法给出确定性保证——与题面"确保"冲突，且低估了可解性。

**教训**：**术语要精确到"前提失效"与"结论失效"这一层。** 二者的处理方式完全不同：
前者换前提，后者推翻结论。
