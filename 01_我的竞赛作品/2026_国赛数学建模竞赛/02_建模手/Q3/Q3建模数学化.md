### A.2 形式化：带未知的鲁棒在线决策（min–max）

Q3 的最简严格形式是**两目标、最坏情形**的部分可观测序贯决策：

```
状态 s = ( Φ , 机器狗状态 )      机器狗状态 = (当前位置, 当前频道, 已清除集合, 日志)
观测 o =  measure_result ∈ { no_signal, near, direction(svd_deg) }
        | clear_result  ∈ { success, no_target_in_range }
动作 a = (measure, p, c) | (clear, p, c) | (exit)
```

**为什么不写成标准 POMDP 的期望型**：`δ` 是**有界区间**而非概率分布（`附录2(1)`），
`k`、`g_i`、`R_i` 亦无先验分布。故期望无处可求。正确的形式是**最坏情形（对抗）形式**：

```
世界  w ∈ W :  k ∈ [10,16],  {c_i} ⊂ {1..20},  g_i ∈ D((0,0),1800),
               R_i ∈ [1000,1500],  δ(·) ∈ [−1°,1°]（按地点固定）
信念  B(s)  = 与已观测序列相容的全部世界集合（集合型信念，不是概率分布）

求策略 π 使：
   (完备性／硬)   ∀w ∈ W,  终止时  σ_w(c) ∈ {已清除, 已确认空} 对全部 c ∈ {1..20}
   (效率／软)     minimize  max_{w ∈ W} T_vir(π, w)
   (现实／硬)      T_real(π) ≤ min(1200 s, 25 min 窗口剩余)
```

**点透**：这个形式把题面"**在确保所有干扰源被清除的前提下，时间越短越好**"逐字翻译成
"**硬约束求可行 + 最坏情形最小化**"。它同时说明为什么 RL（优化期望回报）在本问**方向就错了**——
本问没有期望可优化，只有*保证*与*最坏情形*。

### A.3 决策变量（可执行策略的参数化）

| 变量 | 类型 | 含义 | 取值范围 |
|---|---|---|---|
| `P = (p_1,…,p_N)` | 连续点集 | 检测点位置 | 圆域内外均可（接口允许出圆） |
| `route` | 排列 + 起点固定 | 检测点拜访次序（含路径形状） | `N!` 种，起点为 P₀ |
| `scan_ord(p) ⊆ {1..20}` | 子集序列 | 在 p 处扫描的频道及顺序 | 依赖频道状态机 |
| `clear_rule` | 规则 | 清除点选择：`c*` 直接清 / homing | {直接, homing} |
| `h_k` | 实数序列 | homing 步长 | `h_k ≈ r̂_k` |
| `stop_rule` | 谓词 | 停止条件 | 定理 C（F53） |

**关键非对称**：`P`、`route` 必须在**测量之前**选定（只能用先验：圆域、`R_w ∈ [1000,1500]`、20 频道、`k ≤ 16`）；
`scan_ord`、`clear_rule`、`h_k` 是**在线**决策，可用观测（这是"部分可观测"的实质）。

### A.4 目标函数

**主目标**（题面第二指标，最小化）：

```
min  T̄ = T_vir / k_cleared        （完备时 k_cleared = k）
其中 T_vir = T_move + T_measure + T_switch + T_optical + T_clear      （Q3-F26）

```

**次级目标**（合规性）：现实时间 `T_real` 尽量远离上限（留裕量给重试与收尾）。

### A.5 约束条件

**硬约束（必须满足）**

1. **完备性**：终止时 `∀c ∈ {1..20} : σ(c) = 已清除 ∨ ∀p ∈ P, measure(p,c) = no_signal`（定理 C，Q3-F53）
2. **覆盖**：`⋃_{p∈P} B(p, 1000) ⊇ D((0,0),1800)`（Q3-F1）——它与 (1) 一起才蕴含"全部清除"
3. **动作合法性**：`channel ∈ {1..20}` 整数；`|x|,|y| ≤ 2000000`；有限数值（无 NaN/∞）；串行、无并发
4. **幂等**：新动作新 `request_id`；仅网络失败重测同一动作时复用原 ID 与原内容（改内容报 409）
5. **现实时间**：`T_real ≤ min(1200 s, 窗口剩余)`，且必须读 `remaining_real_duration_s`，不得假定 1200
6. **虚拟时间**：`T_vir ≤ 360000 s`（题设上限，实际不构成约束）
7. **起点与初态**：`p_1 = P₀ = (0,0)`，`ch_0 = 1`

**软约束（尽量满足）**

1. **请求总数**：`n_req · τ_req ≤ T_real^{avail} − τ_reserve`（Q3-F36，`τ_reserve ≈ 60 s`）
2. **路径经济**：`route` 近似 TSP 最优（移动是总时间大头）
3. **不重复测量同点同频道**（同点误差固定，零信息）
4. **避免无效 `/clear`**（3 s 且零信息）——只在 `R_MEC ≤ 20` 或 `near` 时清除
5. **日志体积 < 2 MB**（上传上限）

## B. 论文引理草稿（"模型建立"节素材）

### L1 覆盖-发现引理
> 检测点集 `P` 对最坏接收半径 1000 覆盖 `D((0,0),1800)` ⟹ 圆域内**任意**位置、**任意**频道的全向源，至少在一个 `p ∈ P` 处返回 `direction` 或 `near`（不可能 `no_signal`）。
> **推论**：`no_signal` 在**全部** `p ∈ P` 上出现 ⟹ 该频道确无未清除源。

### L2 最小覆盖点数引理
> `N ≥ ⌈area(D(0,1800))/area(B(0,1000))⌉ = ⌈3.24⌉ = 4`（面积界）；
> 更强，用平面等圆覆盖最优密度 `2π/(3√3) = 1.2091996`：`N ≥ ⌈3.9178066⌉ = 4`。
> **构造上界**：间距 `d ≤ 1732.0508` 的三角格即可，取 d=1500 得 7~9 点。

### L3 清除判据引理（充要）
> 两站交会得 `L`，`c*` 为其 Chebyshev 中心。则 `在 c* 处 /clear 必成功 ⟺ R_MEC(L) ≤ 20`。
> **推论**：`R_MEC` 才是判据；`D ≤ 34.6410`（Jung）只是**充分**代理。

### L4 基线上限引理
> 对称双站、`γ ≡ 1`（Q1 扫描实测）：`R_MEC = ε_rad·L/sin φ`。
> 令 `R_MEC ≤ 20` 得 `L ≤ 40 sin φ/(2ε_rad)`：`φ=90° ⇒ L ≤ 1145.9156 m`；`φ=120° ⇒ L ≤ 992.3920 m`。

### L5 homing 收缩引理
> 距离 `r` 处沿测得方位走 `h`：`r' = √(r² + h² − 2rh cos δ)`。
> `h = r ⇒ r' = 2r sin(|δ|/2) ≤ 2sin(ε/2)·r`，**收缩率 `λ = 0.0174531` 与 δ 无关**。

### L6 覆盖巡游下界引理
> 为覆盖 `D(0,1800)`，路径长 `P` 满足 `2·1000·P + π·1000² ≥ π·1800²`（Steiner 公式），即 `P ≥ 3518.5838 m`，`t_move ≥ 703.7168 s`。

### L7 完备性引理
> `P` 覆盖圆域 ∧ 全部 20 频道 ∈ {已清除}∪{全 P 上 no_signal} ⟹ 全部源已被清除（反证法）。
> **推论**：这是一个**可判定**的停止条件，且不需要知道 `k`。

### L8 空频道成本引理
> 仍有 `20 − k` 个频道为空；每个空频道须在 `N` 个检测点上逐一确认 ⟹ `C_empty = (20−k)·N·5` 秒。
> `k` 越小越贵：`k=10, N=8 ⇒ 400 s`。

## C. 核心命题的完整证明

### C.1 命题：最小覆盖点数（L2 的证明）

**陈述**：覆盖 `D(0,R)` 所需半径 `r` 圆盘数 `N ≥ (R/r)²`；进一步 `N ≥ D_cov·(R/r)²`，`D_cov = 2π/(3√3)`。

**证明（第一式）**：覆盖圆盘的总面积 `N·πr²` 必不小于被覆盖区域面积 `πR²`（重叠只增面积）⇒ `N ≥ (R/r)²`。R=1800, r=1000 ⇒ 3.24 ⇒ `N ≥ 4`。∎

**证明（第二式）**：由平面等圆覆盖的**最优密度** `D_cov = 2π/(3√3) = 1.2091996`（Oler 1961 / Kershner 1939 的结果：密度 = 圆盘面积 / 基本单元面积 = `πr² / ((3√3/2)r²)`，单元取间距 `√3 r` 的三角格），有 `总覆盖面积 ≥ D_cov · 被覆盖面积`。故 `N·πr² ≥ D_cov · πR² ⇒ N ≥ D_cov (R/r)² = 1.2091996 × 3.24 = 3.9178066 ⇒ N ≥ 4`。∎

**注**：两式同时给 `N ≥ 4`，互相印证。构造（7~9）与下界（4）的差距来自**边界效应**——圆域被六边形单元切开，边缘单元的有效被覆盖面积小于单元面积。

### C.2 命题：清除判据 `R_MEC ≤ 20`（L3 的证明，充要）

**陈述**：`在 c* 处 /clear 必然成功 ⟺ R_MEC(L) ≤ 20`。

**证明**：
（⇐）真源 `G ∈ L`（`δ ∈ [−1°,1°]` 的区间模型保证实测示向度与 `G` 相容）。由定义
`R_MEC = max_{X∈L} ‖X − c*‖`，故 `‖G − c*‖ ≤ R_MEC ≤ 20`。`/clear` 的成功条件仅为"清除点与源距离 ≤ 20"（`附录2(8)`："与信号有效覆盖角度范围无关"），故必成功。

（⇒）设 `R_MEC > 20`。则 `∃X_0 ∈ L` 使 `‖X_0 − c*‖ = R_MEC > 20`。对任意候选清除点 `c`：
`max_{X∈L} ‖X − c‖ ≥ R_MEC > 20` ⇒ 存在 `X ∈ L` 与 `c` 距离 > 20。取该 `X` 为真源（与观测相容），则在该点 `c` 处 `/clear` 失败。故不存在能保证成功的清除点。∎

**推论 C.2a**：由 Jung（Q1-F25）`R_MEC ≤ D/√3`，故 `D ≤ 20√3 = 34.6410` 是充分条件；**用 D 会漏掉 `34.6410 < D` 且 `R_MEC ≤ 20` 的算例**（`γ ≡ 1` 时 `D < 40` 都合格）。

### C.3 命题：直接清除的基线上限（L4 的证明）

**陈述**：对称双站配置下 `R_MEC = ε_rad·L/sin φ`；`R_MEC ≤ 20 ⟺ L ≤ 40 sin φ/(2ε_rad)`。

**证明**：由 Q1 扫描实测结论（`03_编程手/Q1/实验结果/Q1_参数扫描报告.md` §6）：
(i) 对 `φ ≥ 90°`，`D = 2ε_rad·L/sin φ`（精确，非近似）；
(ii) 对称两站配置 `γ ≡ 1.000000` ⟹ `R_MEC = D/2`。
两式合并：`R_MEC = ε_rad·L/sin φ`。取 `φ = 90°`：`R_MEC = ε_rad L ≤ 20 ⇒ L ≤ 20/ε_rad = 20·180/π = 1145.9156 m`。
取 `φ = 120°`：`R_MEC = ε_rad L/sin120° ≤ 20 ⇒ L ≤ 40·sin120°/(2ε_rad) = 992.3920 m`。∎

**推论 C.3a（网格间距红线）**：三角格中，源落在单元中心时其最近两格点相距 `d`、到源距离均 `d/√3`，源处夹角恰 `120°`。代入上式 ⇒ **`d ≤ 992.3920 m` 时"发现即可在 c\* 直接清除"**（免 homing）。

**推论 C.3b**（**v1.1.0 修正**）：`d = 1500` 时 `R_MEC = 30.2300 m > 20` ⇒ **不能就地直接清除**；
`d = 1000` 时 `R_MEC = 20.1533 m`，也略超（差 0.15 m，即 0.77%）。
**但"不能直接清除"不等于"必须 homing"**——由命题 C.8（扫掠清除，见下）：
`R_MEC = 30.2300 ⇒ N_sweep = 3`（≈30 s），`R_MEC = 20.1533 ⇒ N_sweep = 2`（≈20 s），
**均远优于 homing 的 213.49 s**。⇒ 工程上 `d=1000` 与 `d=1500` 的"扫描+清除"成本几乎打平，
`d` 的取舍改由裕量与定位富余决定（仍须实测）。若严格要求 `N_sweep = 1`（即免扫掠、免 homing），
则须 `R_MEC ≤ 20` ⇒ 由推论 C.3a 取 `d ≤ 992.3920 m`。

### C.4 命题：homing 收缩（L5 的证明）

**陈述**：`h = r ⇒ r' = 2r sin(|δ|/2)`，且 `r' ≤ 2 sin(ε/2)·r`。

**证明**：以当前点为原点、测得方位为 +x 轴。真源位于 `r·(cos δ, sin δ)`。走 `h` 后落点 `(h, 0)`，故
```
r'² = (h − r cos δ)² + (r sin δ)² = h² − 2hr cos δ + r²  ⇒  r' = √(r² + h² − 2rh cos δ)
```
取 `h = r`：`r'² = 2r²(1 − cos δ) = 4r² sin²(δ/2) ⇒ r' = 2r sin(|δ|/2) ≤ 2r sin(ε/2)`（`|δ| ≤ ε`，sin 在 [0,90°] 单增）。∎

**推论 C.4a（收缩率与误差无关）**：`λ = 2 sin(ε/2) = 2 sin(0.5°) = 0.0174531`，`r_k ≤ λ^k r_0`。`r_0 ≤ 1500` ⇒ `r_1 ≤ 26.1796`、`r_2 ≤ 0.45691 m < 5 m`（两步进 `near`）。

**推论 C.4b（工程版）**：步长需用距离估计 `r̂`（由 Q1 交会区域给出），相对误差 `η ≤ D/r ≤ 2ε_rad = 0.0349066`。最坏收缩
```
λ_safe = sin ε + 2ε_rad = 0.0174524 + 0.0349066 = 0.0523590
1500 → 78.5385 → 4.1122 m      （两步进 near 阈值内）
```

**推论 C.4c（最优步长）**：`h* = r cos δ ⇒ r' = r sin|δ|`。由于 `δ` 不可知，`h*` 不可实现，仅作理论基准；`h = r` 是唯一"免知识"的安全选择。

### C.5 命题：移动时间下界（L6 的证明，Steiner 公式）

**陈述**：任何保证发现全部源的策略，其移动时间 `t_move ≥ 703.7168 s`。

**证明**：设机器狗轨迹为曲线 `γ`，长 `P`。保证发现 ⟹ 检测点集（⊂ γ 上的点）的 1000-圆盘覆盖 `D(0,1800)` ⟹ `γ` 上点的 1000-圆盘亦覆盖（检测点是 `γ` 的子集）：
```
area( γ ⊕ B(0,1000) ) ≥ π·1800²
```
由 Steiner 公式（曲线与半径 r 圆盘的 Minkowski 和面积）：`area(γ ⊕ B_r) ≤ 2rP + πr²`（自交/重叠只会减少面积，故为**上界**）。于是
```
2·1000·P + π·1000² ≥ π·1800²
P ≥ π(1800² − 1000²)/2000 = π·2 240 000/2000 = 3518.5838 m
t_move ≥ P/5 = 703.7168 s
```
∎

**点透**：这是**与策略无关**的下界。它把"我们的解离最优多远"变成可汇报的比值，而不是自说自话。

### C.6 命题：完备性定理（L7 的证明）

**陈述**：设 `⋃_{p∈P} B(p,1000) ⊇ D((0,0),1800)`，且测试结束时
```
(a) 每个频道 c ∈ {1..20}：已被成功清除，或
(b) c 在 P 的每一个点上 /measure 均返回 no_signal
则目标区域内所有干扰源均已被清除。
```

**证明（反证）**：设有源 `G`（频道 `c`、位置 `g ∈ D(0,1800)`）未被清除。
由覆盖条件 `∃p ∈ P : ‖g − p‖ ≤ 1000 ≤ R_c`（`R_c ≥ 1000`，引理 W(a)）。
`G` 为**全向**源 ⇒ 在 `p` 处测频道 `c` 必返回 `direction`（若 `‖g−p‖ > 5`）或 `near`（若 `≤ 5`），
**不可能** `no_signal`（`附录2(2)`：全向源只要距离不超接收半径必可测；`附录2(9)`：≤5 m 返回 near）。
这与 (b) 矛盾。又 `c` 未被清除，故 (a) 不成立。矛盾 ⇒ 假设不成立，`G` 必已被清除。∎

**推论 C.6a（比例 100%）**：策略若满足 (a)∨(b) 对全部 20 频道，则 `被清除比例 = k/k = 100%`，与 `k` 无关。
**推论 C.6b**（Q4 的处境，**v1.1.0 修正**）：定理 C 的**唯一**依赖是"全向 ⟹ 覆盖内必可测"。
Q4 引入定向源后，"在 `p` 处 `no_signal`"可能是**盲区**而非"无源" ⇒ (b) 不再蕴含"无源" ⇒
**定理 C 第 2 步的前提失效**。
**但这不是"结论失效"**：把发现条件由"1000-覆盖"升级为"**surrounding**"（`∀G ∈ D, G ∈ conv{p ∈ P : ‖p−G‖ ≤ 1000}`，
即源必须被检测点**包围**），并在检测点集上**外扩 `d` 的环带**（题面 `附件2` §1.1 允许检测点位于目标区域外），
则定理**仍然成立**（Q4 命题 Q4-E）⇒ Q4 为**确定性 100%**，无需降级为概率完备性。
**这是 Q3→Q4 最干净的接口**：Q4 的难度是"**把发现条件从覆盖升级为包围**"，
其余（交会、`R_MEC` 判据、homing、扫掠清除）**全部可直接继承**。

### C.8 命题：扫掠清除的完备性（**v1.1.0 补入**）

**陈述**：设 `G ∈ L`，`{c₁..c_N}` 为覆盖 `L` 的 20-半径盘中心集。
> ⚠️ **2026-09-12 更正（审核）**：`N = ⌈1.2091996(R_MEC/20)²⌉` 是**覆盖密度给出的渐近计数**，
> 且方向是「**至少**」而非「至多」，**不能**直接当作构造性覆盖的中心数写进完备性证明。
> **正确表述**：**存在** `N ≤ C·(R_MEC/20)²` 的覆盖（**六边形构造，含边界修正项**）。
> 且**实现上必须真的产出覆盖集**（审核 P0-2：现有两个实现只取前 `N_sweep` 个点，
> 真源可能距所有尝试点 > 20 m ⇒ 「必有一次成功」在实现层不成立）。
则依次在 `cᵢ` 处 `/clear`，**必有一次成功**。

**证明**：由 `附录2(8)`，"光学精确定位及清除操作是否成功**仅与清除点与干扰源之间的距离有关**，
与干扰源信号有效覆盖角度范围无关" ⇒ `/clear` 的成功条件恰为 `‖c − G‖ ≤ 20` ⇒ 它是**20 m 邻近性判定器**。
又 `G ∈ L ⊆ ⋃ᵢ B(cᵢ,20)` ⇒ `∃i : ‖cᵢ − G‖ ≤ 20` ⇒ 第 `i` 次成功 ✓。（前面 `i−1` 次失败各耗 3 s，第 `i` 次 5 s。）∎

**成本与拐点**：`C_sweep ≈ N×(3 + 移动≈7) = 10N = 12.09(R_MEC/20)²`，
`C_homing ≈ 213.49 s`（与 `R_MEC` 无关）⇒ 拐点 `R* = 84.0369 m`（CAS 复核）。
**三路选择规则**：`R_MEC ≤ 20` 直接清除；`20 < R_MEC ≤ 84.0369` 扫掠清除；`R_MEC > 84.0369` homing。
**对 Q4 的意义**：扫掠清除**与朝向完全无关**（只读 `/clear` 结果）⇒ 它是 Q4 中唯一"对盲区免疫且不需要 `near`"的清除手段。

### C.7 复杂度归约（NP-hard 判定）

**命题**：Q3 的离线最优化是 **NP-hard**。

**证明（归约链）**：
(i) 即使 `k`、`Φ` 已知，清除次序仍是**欧氏 TSP 的变体**（须依次接近各源至 20 m），TSP ∈ NP-hard；
(ii) 覆盖部分要求"路径的 1000-圆盘邻域覆盖圆域"，即**覆盖巡游问题（covering tour / k-SPP）**，亦 NP-hard；
(iii) 发现部分含**集合覆盖**结构（用最少的"点×频道"测量辨识全部源），NP-hard。
Q3 同时含三者的松弛 ⇒ **NP-hard**。∎

**为什么仍可解**：实例规模极小——`N ≤ 12`（检测点）、`k ≤ 16`、`20` 频道，且
- 覆盖部分有**闭式构造**（三角格，`O(1)` 参数）；
- 次序部分是 `N ≤ 12` 的 TSP ⇒ 精确 DP `O(N²2^N) ≈ 12²·4096 = 5.9×10⁵` 可**精确求解**；
- 发现部分被**状态机**在线解决（不需离线最优）。
⇒ **用"精确子程序 + 完备性证明 + 在线启发式"替代全局最优化**，这是本问选型的数学依据。

### H.3 Q3 → Q4（难点定位）

| Q3 结论 | Q4 用法 |
|---|---|
| 定理 C（完备性） | Q4 中其**前提**失效（定向盲区破坏 (b)）；把发现条件升级为 surrounding + 检测点外扩 `d` 环带后**重建**（Q4 命题 Q4-E） |
| **扫掠清除（命题 C.8）** | Q4 **直接继承**，且成为主心骨：它与朝向无关，是 Q4 中唯一对盲区免疫的清除手段 |
| 覆盖网格 | Q4 仍需，但 `no_signal` 不再蕴含"无源" |
| homing 收缩引理 | Q4 **仍成立**（homing 只看示向度，与盲区无关；但盲区内测不到示向度 ⇒ 须先进入覆盖扇区） |
| 清除判据 `R_MEC ≤ 20` | Q4 **仍成立**（`附录2(8)`：清除与朝向无关） |
| 频道状态机 | Q4 需新增状态"疑似盲区" |

**给 Q4 的一句话**：Q4 = Q3 + "`no_signal` 从二义变三义" ⇒ **只有完备性论证需要重建**，其余（覆盖、交会、清除判据、homing）全部可直接继承。
