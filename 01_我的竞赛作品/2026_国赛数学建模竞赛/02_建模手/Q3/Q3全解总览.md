## 0. 一句话定位

**Q3 = 未知环境下（源数 10–16、位置、频道、有效接收半径 1000–1500 全未知）单只机器狗的"发现 → 定位 → 清除 → 确认清完"在线决策问题。数学上是部分可观测的覆盖巡游 + 组合清除序问题；解法 = 确定性启发式（1000-覆盖三角网格作侦察骨架 + Q1 交会定位 + homing 逼近 + 频道状态机）+ 完备性证明（保证清除率 100%）+ 路径与顺序优化（压时间）。**

**全局最易错的一条口径**：本问有**两个钟**——优化目标是**虚拟时间**（题面表 1 的"平均定位清除时间"，即最终 `virtual_time_s` 的分解），硬约束是**现实时间 ≤ 1200 s**（/enter 后 20 min，且与 25 min 测试窗口取较早者）。两者不同钟，混淆则整篇口径错。

## 1. 题设逐词点透

> "已知目标区域中的干扰源均为全向干扰源，总数在 10-16 个之间，但具体个数未知。现派出一只机器狗从原点出发，测向机初始频道为 1，对目标区域中的干扰源进行自动定位并清除。要求在确保所有干扰源被清除的前提下，完成任务的时间越短越好。请制定机器狗自动搜索定位及清除的策略，并设计相应的算法。请通过模拟器进行演练测试（见附录 3 中的说明），计算关于演练测试的以下统计值，以此检验策略的有效性：被清除干扰源个数的比例 = 被清除干扰源的个数 / 干扰源总数；平均定位清除时间 = 定位清除总时间 / 被清除干扰源的个数。其中定位清除总时间包含机器狗移动时间、频道切换时间、检测时间、光学精确定位时间及清除时间等。"

| 词 | 字面 | 点透（为什么重要） |
|---|---|---|
| "**均为全向**干扰源" | 360° 无盲区 | 可探测性**只取决于距离**（`附录1(4)` 场强仅随距离衰减）。这一句是整问可解的根：它让"覆盖 ⇒ 必被发现"成立。**Q4 加定向源后此条的前提失效**（no_signal 变三重歧义），需把发现条件升级为 surrounding 才可重建——见 §0.1 修正 2 |
| "总数在 10-16 个之间，但**具体个数未知**" | 区间未知量 | ⇒ **禁止用"清够 16 个就停"**。总数未知 ⇒ 计数不能作停止条件 ⇒ 必须用**完备性判据**（§6.3），否则漏源、比例 < 100% |
| "频道位于常见的 **20 个**频道中" | 1–20 | ⇒ 20−k 个频道**必然为空**（k≤16 ⇒ 至少 4 个）。而"证明某频道为空"要**遍历覆盖全圆域的检测点**——这是一笔**被多数队伍忽略的固有成本**（§6.2） |
| "**有效接收半径 1000–1500 m**"（`附录2(2)`，且"不返回"） | 每源不同、未知 | ⇒ 任何"保证"必须对 **R_eff = 1000（最坏）** 成立。按 1250 或 1500 设计 ⇒ 必然漏掉远处源 |
| "派**一只**机器狗" | 单机 | ⇒ 无协同，路径优化是**单体覆盖巡游**（covering tour），不是多旅行商 |
| "从**原点**出发" | 起点固定 | ⇒ 巡检路径必须从 (0,0) 起（且应在终点顺路回家收尾，虽非硬约束） |
| "测向机**初始频道为 1**" | 状态机初态 | ⇒ 首次检测频道 1 **无**切换耗时；此后频道只被**成功的 /measure** 改变（`/clear` 不切频道，`附件2` §4.4） |
| "**在确保所有干扰源被清除的前提下**，完成任务的时间越短越好" | 主从目标 | **完备性 = 硬约束，时间 = 软目标**。为压时间而牺牲完备性的方案直接出局（题面第一句话就锁死了） |
| "被清除个数的**比例** = 个数 / **总数**" | 第一指标 | 演练结束模拟器**会给总数**；正式测试不给 ⇒ 按策略自判（策略完备则比例 ≡ 100%） |
| "**平均定位清除时间** = 总时间 / **被清除个数**" | 第二指标 | 分母是**被清除个数**而非总数——完备时两者相同；**分子 = 最终 `virtual_time_s`** |
| "定位清除总时间包含移动、切频、检测、光学定位、清除" | 口径清单 | = 虚拟时间；**不含** /enter 与 /exit（二者不推进虚拟钟，`附件2` §4.1） |

**点透结论**：Q3 = **"覆盖论（保证发现） + 在线决策（保证清除） + 路径优化（保证效率）"三层复合**。三个隐藏决策：

1. **侦察网格怎么布**（间距 d、格型、点数）——决定"保证发现"与扫描成本，且通过交会角反噬清除方式；
2. **清除走哪一路**（直接 / 扫掠 / homing）——由 Q1 的 **R_MEC ≤ 20 m** 判据与 **`R* = 84.0369 m`** 拐点决定（§4.2、§4.3、§0.1）；
3. **停止条件怎么定**——才能既 100% 清除又不做无谓的全网格空扫（§6.3）。

## 2. 约束与条件点透

```
环境（全部未知，接口不返回）：
  源数 k ∈ [10,16] ； 频道 C ⊂ {1..20}（一源一频道）； 位置 ⊂ D((0,0),1800)
  有效接收半径 R_eff ∈ [1000,1500]（每源不同）
已知（题设给定）：单机 ； 起点 P₀=(0,0) ； 初始频道 1 ； 清除半径 20 m ； near 阈值 5 m ； 速度 5 m/s

观测量（/measure，每个动作 5 s 检测）：
  "no_signal"  ← 该频道无未清除源 ∨ 距离 > R_eff        （Q3 无盲区，只有这两个原因）
  "near"       ← 距离 ≤ 5 m ⇒ 可原地直接清除（无需示向度）
  "direction"  ← 距离 ≤ R_eff，返回 svd_deg（±1°，同点重复测量误差不变）

动作与虚拟耗时（附件 1 表 1 / 附件 2 §3）：
  /measure : 5 s +（channel 变化时 1 s）+ ‖ΔP‖/5
  /clear   : 3 s（no_target_in_range）或 5 s（success）+ ‖ΔP‖/5 ；不切频道、不改频道
  /enter   : 0 s   /exit : 0 s

双钟：
  虚拟钟（= 优化目标）：累计动作耗时；配置上限 360000 s ≈ 100 h ⇒ 不构成约束
  现实钟（= 硬约束）：/enter 起 ≤ min(1200 s, 25 min 窗口剩余)；响应给 remaining_real_duration_s
```

### 2.1 为什么必须分清两个钟（本问第一口径陷阱）

| | 虚拟时间 | 现实时间 |
|---|---|---|
| 定义 | 移动 + 切频 + 检测 + 光学定位 + 清除 的累计 | /enter 到测试结束的真实墙钟时长 |
| 上限 | 360000 s（≈100 h），实际不构成约束 | **1200 s**（且与 25 min 窗口取较早者） |
| 出现位置 | 题面表 1 的"**平均定位清除时间**"（分母 = 清除个数） | 题面表 1 的"**程序运行时间**" |
| 角色 | **优化目标** | **硬约束** |
| 加速方式 | 少移动、少测量、少切频 | 少发请求、单请求开销低 |

**点透**：题面写"5 秒检测"只增加**虚拟**时间，现实中**不需要等待 5 秒**（`附件2` §12）。所以虚拟时间报 3500 s 时，现实可能只花几十秒。⇒

- **不要**为了压虚拟时间而不敢做必要测量——虚拟时间有 100 小时余量；
- **要**盯住**请求总数 × 单请求往返开销**：若每次请求耗 100 ms（HTTP + JSON + Python 开销），10⁴ 次请求 = 1000 s，**逼近 1200 s 硬限**。这才是现实钟的真身，也是 `附件2` §12 "应避免异常高频循环、日志上传上限 2 MB" 的由来。

### 2.2 最坏化引理（对应 Q1 的"admissible 类"洞察）

> **引理 W**（最坏化合法性）：
> (a) `R_eff ≥ 1000` 且未知 ⇒ 任何"保证发现"的论断必须对 `R_eff = 1000` 成立；
> (b) `k ≤ 16` 且未知 ⇒ 任何"保证清完"的停止条件必须对"最后一个源在最后才被发现的极端次序"成立；
> (c) `|δ| ≤ 1°` 为区间模型（非随机） ⇒ 结论须对 δ 的全部取值成立（不是"期望意义"）。

**点透**：这三条把"在线决策"中最讨厌的"未知"全部转成了**可设计的最坏情形**。Q1 的 ε-单调性引理做的是同一件事（把 ε 的最坏值 1° 钉住）。**全题的方法论一致：把未知化为有界，再把有界的最坏值钉成设计输入。**

### 2.3 三个必须钉死的口径

1. **清除点判据**：`/clear` 成功**仅取决于真实距离 ≤ 20 m**（`附录2(8)` 明确"与信号有效覆盖角度范围无关"）⇒ 用 Q1 的 **R_MEC(L) ≤ 20 m** 判定"可保证清除"（§4.2）。
2. **同点重复测量无效**：题设"同一地点电磁环境固定，重复检测不改变检测误差"（`附录2(1)`）⇒ **换点才有新信息**。同点重测 = 白花 5 s。这是题面第一陷阱。
3. **定位区域口径**：沿用 Q1 定的"**主口径不截断**"；但 Q3 中源必在半径 1800 的圆域内 ⇒ 允许把 `L ← L ∩ D(0,1800)` **额外收紧**（提高精度、缩短 homing）。此收紧是额外的合法信息，须在论文声明。

## 3. 问题本质点透

- **为什么"是 POMDP 但不需要 POMDP 方法"**：状态不可观测（源数/位置/频道/半径），动作有代价，形式上确是部分可观测序贯决策。但
  (a) 状态空间小且离散（20 频道 × 圆域采样）；
  (b) **无对抗、无随机回报**（误差是有界区间，不是概率分布）；
  (c) 虚拟时间预算近乎无限。
  ⇒ 适用的是**确定性启发式 + 完备性证明**，而不是 RL/蒙特卡洛树搜索。**引入 RL 会丢掉"清除率 = 100%"的可证保证**，而这是题面第一硬约束。这是本问最重要的选型判断。

- **为什么"完备性"才是硬骨头**：总数未知 ⇒ 唯一可证的停止条件是
  > 20 个频道中，每个频道要么已被清除，要么在**覆盖全圆域的检测点集**上**全部** `no_signal`。
  这要求 (a) 检测点集对最坏接收半径 1000 **覆盖整个圆域**；(b) 对每个"疑似空"频道**遍历全部检测点**；(c) 已清除频道从"疑似空"中剔除。缺任一条都可能漏源。§6.3 给出严格证明。

- **为什么"时间"有下界、且可压**：时间 = 移动 + 检测 + 切频 + 清除。
  - 移动被**覆盖巡游下界**锁死：`t_move ≥ 703.72 s`（§6.1，Steiner 公式）；
  - 检测与切频被"频道数 × 检测点数"锁死（全 20 频道 × 7~9 点，每点 119 s）；
  - 清除被 `5k` 锁死（k ≥ 10 ⇒ ≥ 50 s）。
  可压的只有**顺序与复用**：沿路顺扫、先清已发现频道、疑似空频道最后集中确认、路径 TSP/2-opt。**下界给出"我们离最优多远"的诚实标尺**。

- **与 Q1/Q2/Q4 的关系**：
  - **Q1 给清除判据**（R_MEC ≤ 20 m）与精度度量 D —— 这是 Q3 判别"走哪一路清除"的**唯一依据**；
  - **Q2 给选点准则**（φ = 90° 最优 ⇒ 基线 ≤ 1145.9 m 即可直接清除）—— 这是 Q3 网格间距的**设计输入**；
  - **凸性主线（统筹 P3，2026-09-11 补）**：四问的可解性**全部**来自"不确定集是凸集"（Q1 角域、Q2 可行域、

### 4.1 覆盖层：最小点数下界与三角网格构造

**面积下界**（圆盘覆盖圆盘，最朴素）：

```
N ≥ area(D(0,1800)) / area(B(0,1000)) = (1800/1000)² = 3.24  ⇒  N ≥ 4
```

**覆盖密度下界**（用平面圆覆盖的最优密度，Kershner 1939：三角格密度 `2π/(3√3) = 1.2091996`）：

```
N ≥ 1.2091996 × 3.24 = 3.9178066  ⇒  N ≥ 4
```

**三角格构造**：格点间距 d 的三角格，任意点到最近格点距离 ≤ `d/√3`。要求

```
d/√3 ≤ R_eff^worst = 1000   ⇒   d ≤ √3·1000 = 1732.0508 m
```

取 **d = 1500 m**（最大空隙 866.0254 m，对最坏接收半径留 133.97 m 裕量）。格点数估算：圆域面积 ÷ 六边形单元面积

```
π·1800² / ((√3/2)·1500²) = 5.22374 个单元
```

含边界修正 ⇒ **7~9 个检测点**（圆域被六边形单元切碎，边缘单元利用率低，故实际点数大于单元数）。

若取 d = 1000：单元数 `11.7534` ⇒ 约 **10~12 点**（裕量更大：空隙 577.35 m）。

**点透**：下界 4 与构造 7~9 的差距**全部来自边界效应**。论文写"**下界 4（面积 + 覆盖密度双证），构造 7~9**"，立刻显出你知道最优与构造的差距，而不是随手布点。**注意：`深度钻研报告` §7.5 曾用 "d=1200 ⇒ 10~12 点"作备选，与本表口径一致（d 越小点越多），不矛盾。**

### 4.2 定位层（一）：`R_MEC ≤ 20 m` 才是清除判据 —— Q1 → Q3 的真正接口

> **定理 G3（Q3 清除判据，充要）**
> 设某频道源的两个示向度来自**不同**检测点，交会定位区域为 `L`（Q1 定义），取 `c*` 为 `L` 的最小包围圆圆心（即 Chebyshev 中心）。则
> ```
> 在 c* 处 /clear 必然成功   ⟺   R_MEC(L) ≤ 20 m
> ```

**证明**：
（⇐）真源 `G ∈ L`（±1° 区间模型成立 ⇒ 实测示向度与真方位相容）。由 R_MEC 定义，`‖G − c*‖ ≤ max_{X∈L}‖X − c*‖ = R_MEC(L) ≤ 20` ⇒ /clear 距离条件满足 ⇒ 必成功。
（⇒）若 `R_MEC(L) > 20`，则存在 `X ∈ L` 使 `‖X − c*‖ > 20`。取该 `X` 为真源位置（与观测相容、且在圆域内），则任何清除点 `c` 都满足 `max_{X∈L}‖X − c‖ ≥ R_MEC(L) > 20`，即不能保证覆盖全部 $L$ ⇒ 无必然成功保证。∎

**为什么不是用直径 D 判**：由 Jung，`R_MEC ≤ D/√3`，故 `D ≤ 20√3 = 34.6410` 是**充分**条件；但 `R_MEC` 是**充要**的。**用 D 会漏掉 `34.64 < D ≤ 40` 这一整段本可直接清除的算例**（当 γ ≡ 1 时这一段是有效的）。论文里两个都给，判据用 R_MEC。

**基准算例卡线（Q1 算例）**：

| 量 | 值 | 判定 |
|---|---|---|
| 定位区域直径 D | 39.598 m | 39.598 ≤ 40 ⇒ 用 D 判也"过" |
| **R_MEC** | **19.799 m** | **19.799 ≤ 20 ⇒ 可直接清除 ✓** |
| 裕量 `20/R_MEC` | **1.0102** | **仅 1.0%** |

**点透**：这是全问最有说服力的一个数字——Q1 的标准算例（φ = 61.92°，基线 600 m，站距 583 m）**刚好**卡在清除半径上，裕量 1%。⇒ "两点交会后原地直接清除"在中等交会角下**勉强可行**，几何稍差（基线更长、交会角更钝、或偏移方向不利）就**不能直接清除，须改用扫掠或 homing**（§0.1 修正 1）。这一条同时解释了 §4.3 的基线上限为什么是设计红线。

### 4.3 定位层（二）：直接清除的基线上限（Q2 落地到网格设计）

```

```

**情形 B：φ = 120°**（三角网格点、源在单元中心的自然几何）。`D = 2·ε_rad·L/sin(120°)`，对称配置 γ ≡ 1 ⇒ `R_MEC = D/2 = ε_rad·L/sin(120°)`：

```

### 4.4 成本层：homing 收缩引理（"必须逼近也能保证收敛"的解析背书）

> **引理 H（单步收缩）**
> 在真实距离 `r` 处测得方位（真实偏差 δ，`|δ| ≤ ε`），沿该方位走一步 `h`，落点的真实距离为
> ```
> r' = √( r² + h² − 2·r·h·cos δ )
> ```
> 取 `h = r·cos δ`（最优步长）⇒ **`r' = r·sin|δ| ≤ r·sin ε`**；
> 取 `h = r`（无需知道 δ）⇒ **`r' = 2r·sin(|δ|/2) ≤ 2·sin(ε/2)·r`**。

**推论 H1（收缩率与误差无关）**：取 `λ = 2·sin(ε/2)`，则 `r_{k} ≤ λ^k · r_0`，**对任意 `|δ| ≤ ε` 成立**。ε = 1° 时

```
λ = 2·sin(0.5°) = 0.0174531
1500 → 26.1796 → 0.45691 m   （两步进入 5 m 的 near 阈值，三步进入 0.008 m）
```

**推论 H2（工程版，含距离估计误差）**：步长需用**距离估计** `r̂`（由 Q1 交会区域给出，相对误差 `η ≤ D/r ≈ 2ε_rad`）。取保守

```
λ_safe = sin ε + 2ε_rad = 0.0174524 + 0.0349066 = 0.0523590
1500 → 78.54 → 4.112 m     （两步进入 near 阈值内）
```

**点透**：这是"**即使必须走 homing 也能保证收敛**"的完整解析背书——每一步把距离乘以一个**与 δ 无关的常数**。它同时解释了为什么"1° 误差 + 20 m 清除半径"的组合是可解而非绝望的：1° 在 1500 m 处横偏 26.18 m（略超 20 m，不能一步直接清），但**两次逼近后误差降到 4.1 m**，远优于 20 m。**homing 不是"尽力而为"，是有收缩率保证的算法。**

## 5. 建模点透（五阶段循环，逐步为什么）

```
阶段0 侦察布点   三角网格，默认 d=1000（对照 1500），**13（7）**个检测点，从原点起
阶段1 频道发现   每个检测点扫 20 频道；记录每频道的 (位置, 结果) 历史
阶段2 交会定位   某频道在≥2 个不同检测点测得 direction ⇒ Q1 求 L，取 MEC 圆心 c*
阶段3 判别清除   R_MEC(L) ≤ 20 ⇒ 在 c* 原地 /clear；否则 homing 逼近至 near 再 /clear
阶段4 收尾确认   剩余频道在全部检测点补测；全点 no_signal ⇒ 判空；意外 signal ⇒ 回阶段2
阶段5 退出       全部频道 ∈ {已清除} ∪ {已确认空} ⇒ /exit
```

### 5.1 阶段 0：为什么三角格、为什么默认 `d = 1000`

- **为什么三角格**：平面用等圆覆盖的最优密度是三角格 `2π/(3√3) = 1.2092`（Kershner 1939）。同间距下三角格的**最大空隙最小**（`d/√3` vs 正方形格的 `d/√2`）。⇒ 同等点数下裕量最大，反正同样点数下最省。
- **为什么默认 `d = 1000`**（**2026-09-12 按审核 P0-14 更正；v1.1.0 曾改称 d=1500，方向错了**）：
  - d=1500 ⇒ **7 点**、扫描成本最低；但 `R_MEC = 30.2300 m > 20`（格心），且**全域**中位 55 m、p95 453 m ⇒ **绝大多数源要走扫掠甚至 homing**；
  - d=1000 ⇒ **13 点**、扫描成本 +45%；清除侧：最坏配对口径下 32.7% 需 homing，**运行口径实测 90.7% 走直接档**
    （~~免扫掠面积占比 81.6%、100% ≤ 84.04~~ 🚨 2026-09-13 作废，见上文更正）；
  - 清除侧净差 ~1300 s ≫ 扫描侧净差 714 s ⇒ **d=1000 净胜 ~600 s**。
  ⇒ **默认档取 `d = 1000`**（`R_MEC = 20.1533 m`，严格说 > 20，故仍可能触发扫掠；真免扫掠阈值 `d ≤ 992.2912`），实测定档见 §5.6。
- **为什么从原点起**：题设硬性。origin 恰在圆域中心，作为第 1 个检测点天然合理（覆盖最中心区域）。

### 5.2 阶段 1：为什么全扫 20 频道，成本怎么算

源频道未知 ⇒ 在检测点必须逐频道尝试。单点成本：

```
20 次 /measure × 5 s 检测 = 100 s
19 次频道切换 × 1 s      =  19 s        （首次可用初始频道 1 省 1 次；后续点首频道也与上次末频道不同）
单点合计                  ≈ 119 s
```

8 点合计 ≈ **952 s**。**优化**：一旦某频道已清除，后续点不再测该频道；已定位正在 homing 的频道可跳过。

### 5.3 阶段 2：为什么两点够（单点是楔形不是点）

Q1 已证：**单条示向度只给出无界楔形**（射线族），直径未定义 ⇒ 必须**两个不同点**的两个 direction 才能求有界的 L。**关键实现细节**：两点必须**不同**（同点误差固定，"换点才有新信息"，§2.3 口径 2）。

### 5.4 阶段 3：为什么不一发现就清除（D ≈ 2×清除半径）

最坏情况下 1500 m 处 1° 误差横偏 26.18 m > 20 m 清除半径 ⇒ 直接清除必失败（白花 3 s 且暴露信息为零）。判别规则（v1.1.0：**三路**，见 §0.1 修正 1）：

```
求 L 与 R_MEC(L)
  若 R_MEC ≤ 20 m            ：在 c*（最小包围圆圆心）原地 /clear  ⇒ 必成功
  否则若 R_MEC ≤ 84.0369 m   ：【扫掠清除】用 20-半径盘覆盖 L，逐个 /clear，必有一次成功
                              （N ≈ ⌈1.2091996·(R_MEC/20)²⌉ 次；R_MEC=30.23 ⇒ 3 次 ≈ 30 s）
  否则（R_MEC > 84.0369 m）  ：进入 homing，沿最新示向度逼近，直到近距后原地 /clear
```

**为什么新增扫掠这一路**：`/clear` 的成功只与**距离**有关（`附录2(8)`），
所以它是"与朝向无关的 20 m 判距器"；已知源在 `L` 内，用 20-盘盖住 `L` 就必有命中。
**成本 `10N` 与 `R_MEC` 平方成正比，而 homing 成本恒为 ≈213.49 s、与 `R_MEC` 无关** ⇒
两者在 `R_MEC* = 84.0369 m` 处交叉。

### 5.5 阶段 4：为什么必须做，成本多少

**完备性要求**（§6.3）：20−k 个空频道必须被"证明为空"，而"空"的定义是**在覆盖全圆域的检测点集上全部 no_signal**。故

```
空频道确认成本 ≈ (20 − k) × N_grid × 5 s
k=10 ⇒ 10 × 8 × 5 = 400 s   （最坏）
k=16 ⇒  4 × 8 × 5 = 160 s   （最好）
```

**优化**：把"疑似空频道"的确认**摊到阶段 1 的巡检顺路做**（同一检测点一次测完所有未清除频道），避免二次遍历。**这是本问最容易被忽略的一笔固有成本**，也是一支"只追已发现源"的队伍必然漏掉的部分。

## 6. 下界与完备性（本问最硬的两块）

### 6.1 移动时间的覆盖巡游下界（Steiner 公式）

**定理 M（移动下界）**：为**保证发现**任意位置的源，检测点（或更一般地，路径上的点）对最坏接收半径 1000 的圆盘必须**覆盖**整个 `D(0,1800)`。设路径长为 P，则

```
area( path ⊕ B(0,1000) ) = 2·1000·P + π·1000²  ≥  π·1800²
⇒  P ≥ π(1800² − 1000²)/2000 = 3518.5838 m
⇒  t_move ≥ P/5 = 703.7168 s
```

**依据**：Steiner 公式（Minkowski 和面积）：曲线 `γ` 与半径 r 圆盘的 Minkowski 和面积为 `2rP + πr²`。

**点透**：这是**与策略无关**的下界——**任何**机器人、**任何**启发式，只要它保证发现全部源，移动就至少要 703.72 s。论文里这个数字的意义是：它把"我们离最优还有多远"变成一个可汇报的比值，而不是自说自话。

### 6.2 三层下界汇总

| 层 | 内容 | 数值（k = 13，N_grid = 8） |
|---|---|---|
| **L1 理论下界** | 移动 ≥ 3518.5838 m（定理 M）；发现每源需 ≥1 次有效测量；清除每源需 ≥1 次成功 /clear | `t ≥ 703.7168 s` |
| **L2 松弛下界** | 移动 + 每源 ≥2 次方位测量（定位需两点）+ k 次清除 + 空频道确认 | `703.72 + 2×13×5 + 13×5 + 7×8×5 = 703.72 + 130 + 65 + 280 = 1178.72 s` |
| **L3 构造下界** | 本策略实测虚拟时间（**待模拟器实测**） | 【待实测】 |
| **对照：现行估算** | 深度钻研 §7.5 的扫描成本预算 | 3500~5000 s |

**点透**：L2 = 1178.72 s 与 §7.5 估算的 3500~5000 s 之间有 **3~4 倍**差距。差距**不是算法差**，而是三笔"保证性开销"：① 阶段 1 的**全频道全网格保险扫描**（~952 s，远超 L2 假设的"每源 2 次"）；② homing 的**多次逼近**（每源 ~210 s，L2 假设 0）；③ 收尾确认的重测。**诚实写法**：给出 L1/L2 下界 + 构造值 + 差距归因，而不是只报一个漂亮的估算值。

### 6.3 完备性定理（"清除率 = 100%"的严格依据）

> **定理 C（完备性）**
> 设检测点集 `P` 满足 `⋃_{p∈P} B(p,1000) ⊇ D(0,1800)`。若在测试结束时，
> ```
> (a) 对每个频道 c ∈ {1..20}：c 已被成功清除，或
> (b) c 在 P 的每一个点上 /measure 均返回 no_signal，
> ```
> 则**目标区域内所有干扰源均已被清除**。

**证明**（反证）：设有源 G（频道 c、位置 P_G ∈ D(0,1800)）未被清除。由覆盖条件，存在 `p ∈ P` 使 `‖P_G − p‖ ≤ 1000 ≤ R_eff`（引理 W(a)：R_eff ≥ 1000）。G 为**全向**源（题设）⇒ 在 p 处测频道 c **必然**返回 `direction` 或 `near`（`附录2(2)(9)`，无盲区、场强仅随距离衰减），**不可能** `no_signal`。这与 (b) 矛盾；又 c 未被清除故 (a) 不成立。故假设不成立，G 必已被清除。∎

**推论 C1**：策略满足 (a)∨(b) 对全部 20 频道 ⇒ **被清除比例 = 100%**（分母 = 总数，与 k 无关）。
**推论 C2**（停止条件的充分性）：全部 20 频道 ∈ {已清除} ∪ {全 P 上 no_signal} 是**可判定的停止条件**，且一旦成立即可安全 `/exit`，无需知道 k。
**推论 C3**（Q4 的处境，**v1.1.0 修正**）：定理 C 的**唯一**依赖是"全向 ⇒ 覆盖内必可测"。
Q4 引入定向源后，"在 p 处 no_signal"可能是**盲区**而非"无源" ⇒ (b) 不再蕴含"无源" ⇒
**定理 C 第 2 步的前提失效**。**但这不是"结论失效"**：把发现条件从"1000-覆盖"升级为
"surrounding（源被检测点包围）"后，定理**仍然成立**（Q4 命题 Q4-E）。详见 §0.1 修正 2。

**点透**：定理 C 是 Q3 整篇的**理论骨架**——它把"确保所有干扰源被清除"这个题面硬约束，转成了两条可执行、可检查的条件。同时它**精确指出了 Q4 的难点位置**（盲区打破 (b)），这是 Q3→Q4 最干净的接口。

### 6.4 算法正确性与终止性（模板要求）

| 项 | 内容 |
|---|---|
| **输入** | 接口可用；`robot_id`；无其他先验 |
| **输出** | 每个频道状态 ∈ {已清除, 已确认空}；`/exit`；日志（含 `virtual_time_s`） |
| **正确性** | 由定理 C：终止时全部 k 源已清除 ⇒ 比例 100% |
| **终止性** | 虚拟时间有上限 360000 s（题设），策略每步单调推进（每频道状态只向 {已定位 → 逼近中 → 已清除 / 已确认空} 前进）；homing 由引理 H 保证有限步进入 near；⇒ 有限步终止 |
| **实时终止性** | 现实时间 ≤ 1200 s；策略用 `remaining_real_duration_s` 预留收尾裕量（如 60 s），超限前强制进入收尾 |
| **鲁棒性** | 网络失败按 `request_id` 幂等重试；HTTP 状态与 `accepted` 双检；坐标分量 |x|,|y| ≤ 2000000 |

## 7. 陷阱点透（浓缩为机理）

| 陷阱 | 一句话机理 |
|---|---|
| **T1 同点重复测量** | 误差固定不变（`附录2(1)`）⇒ 白花 5 s。**永远换点再测** |
| **T2 `no_signal` ≠ 空频道** | 三重原因（空 / 超距 / 盲区；Q3 无盲区故前二）。必须靠**覆盖网格 + 全点确认**排除 |
| **T3 定位完直接 clear** | D ≈ 2×清除半径（基准算例 R_MEC=19.799，裕量 1%）⇒ **必用 R_MEC 判据**，超阈则 homing |
| **T4 假设每频道都有源** | 20 频道里至少 4 个空 ⇒ 在空频道上耗掉整轮扫描 = 纯浪费 |
| **T5 用现实时间算平均定位清除时间** | 口径错。分子用**最终 `virtual_time_s`**；现实时间是另一列 |
| **T6 提前退出** | 漏源 ⇒ 比例 < 100%，直接违反题面第一硬约束。用定理 C 的停止条件 |
| **T7 按 R_eff = 1250/1500 设计覆盖** | 漏掉远处源。必须按最坏 **1000** |
| **T8 `/clear` 会切频道** | **不会**（`附件2` §4.4）⇒ 无需为清除付切换耗时，也不改频道状态 |
| **T9 坐标/频道类型错** | `channel` 必须 1..20 整数（1.0 可，1.5 报 400）；坐标分量 |值| ≤ 2000000，NaN/∞ 报 400 |
| **T10 假设每局都有 1200 s** | 响应给 `remaining_real_duration_s ∈ [0,1200]`；晚进入则不足。**必须读该值** |
| **T11 忽视 request_id 幂等** | 新动作必须新 ID；**仅**网络失败重试同一动作时复用原 ID + 原内容；同 ID 改内容报 409 |
| **T12 只查 `accepted` 或只查 HTTP 状态** | 二者必须同查；`accepted=false` 时 `virtual_time_s=0` **不是**当前虚拟时刻 |
| **M1 把"发现"当"可清除"** | 发现（≤R_eff）与可清除（≤20 m）差 50 倍。**这是本问策略的核心分界** |
| **M2 把覆盖当"布点够多就行"** | 覆盖是**最坏半径**下的保证，且**含边界**；否则定理 C 失效 |
| **M3 用计数（清够 16）作停止条件** | 总数未知；计数无意义。用完备性判据 |
| **M4 忽视空频道确认成本** | 它占 L2 下界的 280 s / 1178.72 s ≈ 24%，且 k 越小越贵 |
| **M5 homing 步长取固定值** | 引理 H2 的收缩依赖 `h ≈ r̂`；固定步长在近距离会过冲。用自适应 + 反向检测兜底 |
| **M6 忘记圆域截断可提高精度** | 源必在 D(0,1800) 内 ⇒ `L ∩ D(0,1800)` 是**免费**的额外约束，可减小 R_MEC |
