## 〇、总纲：Q3 的完整因果链

```
题目要求：确保全部干扰源被清除 + 时间越短越好（单机、全未知环境）
  │
  ├─→ 本质是什么？
  │      → 部分可观测的在线"覆盖—发现—定位—清除"决策
  │      → 误差是有界区间（非随机）、无先验分布、总数未知
  │      ⇒ 这是【最坏情形保证】问题，不是【期望最优】问题
  │
  ├─→ 用什么数学结构描述？
  │      → 三层分解：覆盖层（静态可行性）/ 定位层（局部可判定）/ 成本层（可度量）
  │      → 为什么不合成一个大优化？因为三层的时间尺度与信息可得性完全不同
  │        （覆盖层离线可定、定位层在线判定、成本层事后统计）
  │
  ├─→ 为什么目标要写成"双层"？
  │      → 题面第一句"在确保所有干扰源被清除的前提下"= 硬约束（完备性）
  │      → 第二句"时间越短越好"= 软目标（最坏虚拟时间）
  │      → 单目标化（如"比例 × 1/时间"）会允许"漏一个源换速度"，直接违反题面
  │
  ├─→ 约束为什么这么列？
  │      → 覆盖约束：把"保证发现"变成静态几何（圆盘覆盖）
  │      → 状态穷尽约束：把"保证清完"变成可判定谓词（定理 C）
  │      → 两钟约束：虚拟时间是目标（题面口径），现实时间是硬限（20 min）
  │
  ├─→ 这个模型能解吗？
  │      → 含覆盖巡游 + TSP + 集合覆盖的松弛 ⇒ NP-hard（命题 C.7）
  │      → 但规模极小：N ≤ 12 检测点、k ≤ 16 源、20 频道
  │      → 覆盖有闭式三角格构造；次序是 N ≤ 12 的 TSP（精确 DP 可行）
  │      ⇒ 可行路径 = 精确子程序 + 完备性证明 + 在线启发式
  │
  └─→ 用什么算法解？
         → 三角格覆盖（d ≤ 1732，取 1500/1000）
           → Q1 交会求 L 与 R_MEC
             → 判据 R_MEC ≤ 20：是 ⇒ 在 Chebyshev 中心直接清除
                               否 ⇒ homing（收缩率 λ = 0.0174531 保证收敛）
               → 频道状态机 + 完备性停止条件（定理 C）
                 → 两阶段巡游（侦察巡游 → 清除巡游）压时间
```

**一句话**：Q3 的因果链是"**题面硬约束（清完）→ 覆盖论 → 观测可靠性 → 可判定停止条件**"与
"**题面软目标（最快）→ 成本分解 → 下界 → 构造与优化**"两条链的汇合。

## 一、第一性原理：问题到底是什么

### 1.1 从题设到数学对象：三个"未知"如何变成设计输入

| 未知量 | 题设给的界 | 转化方式 | 成为什么设计输入 |
|---|---|---|---|
| 源数 `k` | [10,16] | **不知道就不数**——用状态穷尽替代计数 | 停止条件（定理 C） |
| 位置 `g_i` | ⊂ `D(0,1800)` | 覆盖论：把"任意位置"变成"圆盘覆盖" | 网格间距 `d ≤ 1732.0508` |
| 频道 `c_i` | ⊂ {1..20} | 频道正交 ⇒ 逐频道独立状态机 | 扫描成本 `20×5+19×1 = 119 s/点` |
| 有效接收半径 `R_i` | [1000,1500] | **取最坏**（引理 W(a)） | 覆盖半径 = 1000 |
| 单次误差 `δ` | [−1°,1°]，同点固定 | 有界区间 ⇒ 最坏情形分析 | 清除判据阈值、收缩率 `λ` |

**第一性原理**：题面所有"未知"都**给了界**。凡是给了界的未知，都能通过"取最坏值 + 保证对最坏成立"
转化为确定性的设计输入。**这是全题的解题总纲**，也是 Q1（把 ε 钉在 1°）用过的同一招。

### 1.2 为什么是"最坏情形保证"而不是"期望最优"

- 误差模型是**区间**（`附录2(1)`："所有这些误差在 [−1°,1°] 范围内"），**不是概率分布**；
- `k`、`g_i`、`R_i` **无先验分布**；
- ⇒ **期望无处可求**。若硬套期望（如假设误差均匀分布），论文将建立在一个题面**没有给**的假设上。

**对比 Q1**：Q1 也明确拒绝概率模型（"若误差是随机的，定位区域应是置信椭圆，但题设是有界不确定性"）。
**Q3 必须保持同一口径**——这是全题方法论的一致性，也是评阅会检查的点。

### 1.3 为什么难点在"完备性论证"而不在"算法速度"

| 顾虑 | 实情 |
|---|---|
| "时间会不会不够？" | 虚拟时间上限 360000 s（100 h），实际用量 3500~5000 s ⇒ 余量 70 倍以上 |
| "现实时间会不会超？" | 上限 1200 s；5 s 检测**不占现实时间** ⇒ 现实开销 = 请求数 × 往返开销，可控 |
| **"会不会漏源？"** | **这才是唯一的真风险**。总数未知 ⇒ 无法用计数判断"清完了" ⇒ 必须可证的停止条件 |

⇒ **策略的正确性几乎全部重量压在定理 C（完备性）与支撑它的覆盖条件上**。算法速度只影响"多快"，
不影响"是否达标"。这一判断决定了整份文档的着力点：**覆盖的严格性 + 停止条件的可判定性**。

## 二、核心数学原理（逐条展开）

### 2.1 覆盖条件与最小点数：为什么下界是 4、构造是 7~9

**链条**：
```
要"保证发现"⇒ 任意位置、任意频道的源在某个检测点被"罩住"
  ⇒ 源的 R_eff ≥ 1000 ⇒ 检测点的 1000-圆盘必须覆盖整个圆域
    ⇒ N ≥ area 比 = (1800/1000)² = 3.24 ⇒ N ≥ 4          （面积界）
    ⇒ 更强：用最优覆盖密度 2π/(3√3) = 1.2091996
       N ≥ 1.2091996 × 3.24 = 3.9178066 ⇒ N ≥ 4          （密度界）
      ⇒ 构造：三角格 d/√3 ≤ 1000 ⇒ d ≤ 1732.0508
        取 d=1500 ⇒ 单元数 5.22374 ⇒ 含边界 7~9 点
```

**为什么用三角格而不是正方形格**：三角格的**覆盖半径**是 `d/√3`，正方形格是 `d/√2`（对角线半长）。
同间距下三角格最大空隙更小；等价地，达到同一覆盖半径，三角格所需的点更少。
这就是"平面等圆覆盖最优密度由三角格达到"（`2π/(3√3)`）的含义。**这是 Q1"半平面交统一建模"
那种"把工程问题接上经典结论"的同一种手法**——论文里引 Kershner/Oler 的覆盖密度，比自创布点规则可信得多。

### 2.2 清除判据 `R_MEC ≤ 20`：为什么不是用直径 D

**链条**：
```
题面：清除成功只取决于"清除点与源的距离 ≤ 20"（与朝向、与误差无关）
  ⇒ 若已知源一定落在集合 L 内，则存在保证成功的清除点 ⟺ L 能被某个 20 半径圆盘覆盖
    ⇒ ⟺ R_MEC(L) ≤ 20                                    （命题 C.2，充要）
```

**为什么很多人会用 D**：Q1 的输出里 D 是最显眼的量。由 Jung（Q1-F25），`R_MEC ≤ D/√3`，
所以 `D ≤ 34.6410` 就足以保证清除。但这是**充分不必要**的——当 `γ ≡ 1`（本题区域族的实际情形）时，
`R_MEC = D/2`，于是 `D ∈ (34.6410, 40]` 的整个区间**本该可以直接清除，用 D 判却会判成需要 homing**。

**点透**：这是一个"**知道更紧的界就要用更紧的界**"的判断。用 D 不算错（保守），但会**平白多付 homing 成本**，
且丢掉了 Q1 最漂亮的一个结论（`γ ≤ 1.01` ⇒ `R_MEC ≈ D/2`）的直接用途。

**数值验证（Q1 基准算例）**：`D = 39.598`、`R_MEC = 19.799`、裕量 `20/19.799 = 1.0102`。
**注意 39.598 < 40**：若用 `D ≤ 40` 判也"过"，但这只是巧合；`D` 在 34.64~40 之间的算例才是判据的用武之地。

### 2.3 基线上限与网格间距的锁定：`φ_nat = 120°` 是怎么来的

**链条**：
```
Q1 实测：φ ≥ 90° 时 D = 2ε_rad·L/sin φ（精确）；对称配置 γ ≡ 1 ⇒ R_MEC = ε_rad·L/sin φ
  ⇒ R_MEC ≤ 20 给出基线上限 L ≤ 40 sin φ/(2ε_rad)
    ⇒ 三角格中，源落在单元中心时：到最近两格点距离均 d/√3，两格点相距 d
       ⇒ 三角形 S₁S₂G 中 |S₁G| = |S₂G| = d/√3，|S₁S₂| = d
          ⇒ cos φ = (d²/3 + d²/3 − d²)/(2·d²/3) = −1/2 ⇒ φ = 120°
      ⇒ L = d = 间距本身！代入：d ≤ 40 sin120°/(2ε_rad) = 992.3920 m
```

**点透**：这条链把"**网格间距**"从一个工程拍脑袋的参数，变成由两条硬约束（清除半径 20 m、
误向误差 1°）**反解出来的确定值**。而且它揭示了一个反直觉的事实：

> **间距越大，"免 homing"越难**——因为交会基线 L 就是间距 d，而 `R_MEC ∝ L`。

于是"省扫描 ⇒ 用大间距"与"免 homing ⇒ 用小间距"**直接冲突**。这个冲突是 Q3 唯一的主参数决策
（d=1500 的 30.2300 m vs d=1000 的 20.1533 m，见 §4.4）。

### 2.4 homing 的收缩结构：为什么 `h = r` 是唯一"免知识"的安全选择

**链条**：
```
已知：沿测得方位走 h，真实偏差 δ 未知但 |δ| ≤ ε
  一步后距离 r' = √(r² + h² − 2rh cos δ)          （余弦定理直接给出）
  作为 h 的函数：f(h) 在 h* = r cos δ 取极小，极小值 = r sin|δ|
    ⇒ 最优步长 h* 需要知道 δ —— 但 δ 正是我们要克服的未知
    ⇒ 退而求其次：选 h 使得 f(h) 的上界最小且不依赖 δ
       h = r ⇒ r' = 2r sin(|δ|/2) ≤ 2 sin(ε/2)·r     （与 δ 无关！）
```

**为什么这个结果重要**：它把 homing 从"启发式逼近"升级为**收缩映射**——
`r_{k+1} ≤ λ r_k`，`λ = 2 sin(0.5°) = 0.0174531`。于是

```
1500 → 26.1796 → 0.45691 m     （两步进入 5 m 的 near 阈值）
```

**收敛性不再依赖运气**。这也是"1° 误差 + 20 m 清除半径"这个看似苛刻的组合**为什么可解**的答案：
1° 在 1500 m 处横偏 26.18 m（略超 20 m，不能直接清），但两次逼近后降到 0.46 m，
**比清除半径好 43 倍**。

**工程修正的动机**：`h = r` 需要知道 `r`。实际上 `r` 由 Q1 交会区域估计，相对误差
`η ≤ D/r ≤ 2ε_rad = 0.0349`。取最坏叠加 `λ_safe = sin ε + 2ε_rad = 0.0523590`，
两步后 4.1122 m —— 仍稳稳进入 near 阈值。**保守化不改变结论的可用性**。

### 2.5 空频道成本：为什么 `(20−k)` 是个"反向因子"

**链条**：
```
题库是 20 个频道，源只有 k ∈ [10,16] 个 ⇒ 必有 20−k ∈ [4,10] 个频道是空的
  ⇒ 要"证明某频道为空"，必须在覆盖全圆域的全部检测点上测它（定理 C 的条件 (b)）
    ⇒ 空频道确认成本 C_empty = (20−k) × N × 5 秒
      ⇒ k 越**小**，C_empty 越**大**（k=10 ⇒ 400 s；k=16 ⇒ 160 s）
```

**点透**：这是一个**容易被忽略、且方向反直觉**的成本项。直觉是"源越少越轻松"，
但完备性要求把"空"也证明出来，于是**源少的局反而更贵**。多数队伍的策略是"只追已发现的信号"，
把空频道当作"没有源"直接忽略——**这恰好违反完备性，是漏源误判的典型来源**。

### 2.6 扫掠清除：为什么"清除"能压过"定位精度"（**v1.1.0 补入**）

**链条**：
```
题面：清除成功只与"清除点与源的距离 ≤ 20"有关（附录2(8)，与朝向、与 R_eff 无关）
  ⇒ /clear 是一个【20 m 邻近性判定器】（每次失败仅 3 s）
    ⇒ 已知 G ∈ L 时，用 20-半径盘覆盖 L，逐个 /clear，【必有一次成功】（命题 C.8）
      ⇒ 成本 10N（N ≈ 1.2092(R_MEC/20)²），与 L 的大小平方成正比
        ⇒ 与 homing（恒 213.49 s，与 R_MEC 无关）在 R* = 84.0369 m 处交叉
```

**点透**：这条原理把"清除"从一个**几何定位精度问题**降为一个**覆盖问题**——
而"覆盖"正是本题已经用了两次的工具（Q3 发现、Q4 包围），密度常数也是同一个 `2π/(3√3)`。
**三条链用同一把工具，是本题方法学上最整齐的一处。**

**为什么 v1.0.0 漏了它**：v1.0.0 只把"清除"看成"定位完成后的一次动作"，
因此只在"精度够不够（`R_MEC ≤ 20`）"上做二分（够 ⇒ 直接；不够 ⇒ homing），
**忽略了 `/clear` 本身携带的判定信息**（它返回 `success`/`no_target_in_range`，是一个测量）。
**教训**：**把"动作"也当成"观测"来审视**——凡是返回值携带信息的动作，都不只是"执行"。

### 2.8 完备性定理的三步结构：覆盖 → 观测可靠性 → 状态穷尽

**链条**（定理 C 的骨架）：
```
欲证"全部源已清除" （一个关于**不可观测全集**的断言）
  ⇒ 反证：设某源 G 未清除
    ⇒ 第 1 步（覆盖）：∃p ∈ P 使 ‖g − p‖ ≤ 1000 ≤ R_G
    ⇒ 第 2 步（观测可靠性）：G 全向 ⇒ 在 p 处测其频道必得 direction 或 near，**不可能** no_signal
    ⇒ 第 3 步（状态穷尽）：但该频道满足条件 (b)（全 P 上 no_signal）
      ⇒ 矛盾 ⇒ G 已清除 ∎
```

**三步各自依赖什么**：

| 步 | 依赖 | 在哪里被保证 | Q4 是否仍成立 |
|---|---|---|---|
| 1 覆盖 | 网格对照最坏半径 1000 的覆盖（含边界） | 引理 L1 / 覆盖自检（Q3-F11） | ✅ 仍成立 |
| 2 观测可靠性 | **全向源无盲区**（`附录1(3)(4)`） | 题设 | ⚠️ **前提失效**（定向盲区）；**升级发现条件为 surrounding 后可重建**（Q4 命题 Q4-E） |
| 3 状态穷尽 | 频道状态机 + 40 次测量上限 | 实现纪律 | ✅ 仍成立 |

**点透**：定理 C 的"弱点"被**精确定位在第 2 步**，而第 2 步只依赖题设的"全向"二字。
⇒ **Q4 的难度 = 重建第 2 步**（需要"多点交叉确认"区分"空频道"与"盲区"）。这是全题最干净的一个跨问接口。

## 三、成本函数设计：完整逻辑链

### 3.1 为什么用虚拟时间而不是现实时间做目标

题面明确定义"定位清除总时间包含机器狗移动时间、频道切换时间、检测时间、光学精确定位时间及清除时间等"
——**这七项全部是虚拟时间**（`附件1` §2.1~2.4 逐项给了虚拟耗时）。所以

```
被清除比例 = 清除个数 / 总数                    （虚拟口径的统计量）
平均定位清除时间 = 最终 virtual_time_s / 清除个数   （虚拟口径的比值）
```

**推论**：优化目标是**虚拟时间**。若误用现实时间做目标，会把"网络快"当成绩效，方向全错。

### 3.2 为什么现实时间只能做约束

`T_real`（/enter 到结束的墙钟）与 `T_vir` 的比例取决于**单请求往返开销**：

```
T_real ≈ n_req · τ_req ,   而   T_vir ≈ Σ(5 s 检测 + 1 s 切换 + ‖ΔP‖/5 + 3/5 s 清除)
```

两者完全不成比例：5 s 虚拟检测的现实代价可能只有 5 ms。⇒
**`T_real` 不含任何"策略优劣"的信息，只能当资源上限**。正确用法：

```
n_req · τ_req ≤ remaining_real_duration_s − τ_reserve         （Q3-F36）
```

**反面教训**：若把 `T_real` 当目标，优化器会倾向"少测量"——而少测量正是漏源的根源。

### 3.3 为什么"平均定位清除时间"的分母是清除个数

题面写死：`分母 = 被清除干扰源的个数`。这有个**隐蔽的后果**：策略若不完备（漏掉 1 个源），
分母变小 ⇒ **平均值可能反而更好看**。⇒

> **不能优化"平均定位清除时间"本身**——它有鼓励漏源的病态激励。

正确做法：**先用完备性定理把 `清除个数 = 总数` 锁死**（此时分母无自由度），再优化时间。
这也再次说明为什么题面把它写成"在**确保所有干扰源被清除**的前提下"——**约束先于目标**。

### 3.4 为什么目标里要显式含空频道成本

因为它占 `L2` 下界的 280/1178.72 ≈ **24%**（k=13），且完全由题面的"20 个频道"与"10~16 个源"决定。
不把它算进去，就会出现"我们的程序比下界还快"的荒谬结论（因为漏了空频道确认）。
⇒ **成本模型必须把空频道确认列为显式项**（Q3-F34）。

## 四、策略（算法）选择的合理性

### 4.1 为什么不用 RL / 蒙特卡洛树搜索

| 理由 | 说明 |
|---|---|
| 目标不匹配 | RL 优化**期望**回报；本问的误差是**区间**模型、无先验分布 ⇒ 期望无定义（§1.2） |
| 硬约束不可保证 | RL 给的是"高概率清完"，而题面要求"**确保**全部清除"。定理 C 给的是**必然性**，RL 给不了 |
| 收益为零 | 虚拟时间余量 70 倍以上；状态空间小到可穷举 ⇒ RL 的"近似"没有可换取的性能 |
| 可解释性 | 评阅要的是"策略 + 算法 + 完备性论证"，不是训练曲线 |

**点透**：**拒绝 RL 是一个正面的建模判断**（对应 Q1 拒绝概率模型、Q2 拒绝启发式搜索）。
三问一致的方法论：**题面给了什么就用什么，不给的不自己加。**

### 4.2 为什么三角格比随机采样好

随机采样只能给"期望覆盖"，无法给"**保证**覆盖"——存在正概率的未覆盖缝隙（"生日问题"型的覆盖需要
远超理论下界的点数才能把失败概率压到可接受）。而三角格覆盖的缝隙 `d/√3` 是**确定的**，
可用 `d ≤ 1732.0508` 一次性锁死。**完备性定理要求确定性覆盖，随机采样在原理上就出局。**

### 4.3 为什么"两阶段巡游"优于"纯循环"（对深度钻研 §7.4 的细化）

深度钻研 §7.4 给的是**五阶段循环**（发现 → 定位 → 逼近 → 收尾 → 退出，每次发现就当场处理）。
工程上有一个更优的细化：

```
两阶段：
  阶段 A（侦察巡游）：按 TSP 序遍历检测点，每点扫全部未清除频道，**只记录不行动**
                      （遇 near 例外：原地直接清除，零成本）
                      ⇒ 巡游结束时，每个可发现频道都有 ≥2 条异点示向度
  阶段 B（清除巡游）：对每个已定位频道算 L 与 R_MEC
                      R_MEC ≤ 20 ⇒ 登记 MEC 圆心进"清除点集"
                      R_MEC > 20 ⇒ 登记 homing 起点
                      ⇒ 对清除点集做 TSP，一趟走完
```

**为什么更好**：
1. 阶段 A 结束时每源已有 **≥2 条**示向度（纯循环里第一对示向度不足以定 L，须等待）；
2. 清除点集可**统一 TSP**，避免"发现一个就跑一趟再回来"的往返浪费；
3. homing 被压缩成**少数几何不利源**的补救（d=1000 时甚至完全不触发）；
4. 空频道确认**顺路摊在阶段 A** 完成（每点扫全世界），不产生额外巡游——这是 §2.5 那笔 24% 成本的正确消化方式。

**代价**：阶段 A 的时间窗内，源仍在发射（不构成问题——清除没有时限，只有总时间预算）。
**须实测确认**：两阶段 vs 纯循环的时间差（列入 E.2 对照）。

### 4.4 为什么 d 要做双轨而不是单点最优

| d | 点数 | 扫描成本 | `R_MEC`（单元中心） | 处置 |
|---|---|---|---|---|
| 1500 | 7~9 | ~952 s | **30.2300 m** | 每源付**扫掠清除** ≈ 30 s（v1.1.0 修正；非 homing 213.49 s） |
| 1000 | 10~12 | ~1428 s（+50%） | **20.1533 m** | 差 0.15 m ⇒ 工程上视作"免 homing" |

**为什么不定死一个**：
- 两者的差不是"对错"而是"**成本结构**"：d=1500 省 476 s 扫描、多付约 `k×213.49` s homing；
  `k=13` 时 homing 约 2775 s ⇒ **d=1500 明显更差**（若 homing 真按 213 s/源计）。
- 但 **homing 的真实成本依赖 `r̂` 的精度**（§2.4）：若交会估计足够准，实际步数少于 2 大步，
  成本可能降到 ~100 s/源 ⇒ 两者接近。
- ⇒ **这是一个只能实测标定的量**。写双轨（并用 E.4 的权衡曲线呈现）是**诚实的科学姿态**，
  比拍一个数强。**这也是本问留给模拟器的第一个、也是唯一的主标定任务。**

### 4.5 为什么必须读 `remaining_real_duration_s`

题面：`/enter` 成功 5 分钟内进入可用足 20 min；晚于 5 分钟则不足。
**若硬编码 1200 s**，在晚进入的情形下会超时被中止，测试作废（占用一次正式测试机会）。
⇒ `附件2` §12 明确要求"使用 `/enter` 返回的 `remaining_real_duration_s` 控制现实运行时间"。
这是**合规性**要求，不是优化项。
