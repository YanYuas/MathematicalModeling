## 一、问题本质再思考

### 1.1 抛开表面：这个问题在优化什么？

表面说法是"清完 + 最快"。但把动作拆开看，真正的结构是**一次资源分配的两难**：

```
时间 = 移动 + 检测 + 切频 + 清除
        ↑        ↑
   用来"发现"  用来"确认没漏"
```

- **发现**要求"走遍"（覆盖整个 1800 圆域）——费移动；
- **确认没漏**要求"测遍"（每个频道在每个检测点上都要测）——费检测与切频；
- **清除**本身很便宜（5 s/源），**贵的是"知道源在哪"**。

**点透**：Q3 不是"清得快"，而是"**用最少的信息代价把所有源都找出来，并证明找全了**"。
一次 `/measure` 花 5 s 虚拟时间，但它的价值取决于**在什么位置、对什么频道**测——这才是决策变量。

### 1.2 三层不可观测性（问题难在哪一层）

| 层 | 不可观测的东西 | 能否用"取最坏值"消除 |
|---|---|---|
| **结构层** | 有效接收半径 `R_i ∈ [1000,1500]` | ✅ **能**。取 `R_w = 1000`，覆盖设计对最坏成立（引理 W(a)） |
| **几何层** | 源位置 `g_i`、误差实现值 `δ` | ✅ **能**。位置由覆盖 + 交会约束；`δ` 由区间模型 `\|δ\| ≤ 1°` 约束 |
| **数量层** | 源数 `k`、频道集合 `{c_i}` | ❌ **不能**。没有"最坏 k"可用——`k` 越大源越多，`k` 越小空频道越多，两头都费时间 |

**点透**：**前两层都可以"取最坏 + 保证"**，这是 Q1/Q2 用过的同一招。**只有第三层不行**——
所以第三层必须靠**可判定的停止条件**（定理 C）来绕开，而不是靠"取最坏值"。

**这解释了整份文档的着力点**：覆盖的严格性（第 1 层）+ 交会判据（第 2 层）+ 完备性定理（第 3 层）。

### 1.3 为什么"完备性"必须排在"时间"前面

题面原句：「**在确保所有干扰源被清除的前提下**，完成任务的时间越短越好」。

它把一个二阶问题变成了一阶：
```
错误表述：max  清除比例 / 时间
正确表述：min  时间   s.t.  清除比例 = 100%
```

**差别的实质**：在"比值"表述下，"漏掉 1 个源但快 30%"可能得分更高 ⇒ 优化器会去漏源。
更隐蔽的是 §3.3 那条：**"平均定位清除时间"的分母是清除个数**——漏源会让分母变小，
指标反而"变好看"。⇒ **必须先用完备性把分母锁死，再优化时间。**

## 二、候选算法对比

### 2.1 五族候选策略

| 族 | 代表 | 核心机制 |
|---|---|---|
| **A 随机/撒点搜索** | 均匀随机测点、随机频道序 | 期望覆盖；靠采样密度碰运气 |
| **B 系统覆盖巡游** | 三角/正方网格 + 蛇形/螺旋/ TSP 路径 | 确定性覆盖；点集由间距锁死 |
| **C 信息驱动（主动感知）** | 按"观测的信息增益"选下一个 (位置, 频道) | 贝叶斯/熵减；贪心或前瞻 |
| **D 前沿探索（RRT/边界驱动）** | 朝"未探索区域"或"未判明频道"扩张 | 增量建图；不做全局规划 |
| **E 强化学习** | PPO/DQN 类，端到端策略 | 从模拟器学策略 |

### 2.2 对比表

| 族 | 覆盖保证 | 完备性可证 | 数据需求 | 可实现性（9-12 前） | 与题面硬约束匹配 |
|---|---|---|---|---|---|
| A 随机 | ❌ 只有概率覆盖 | ❌ | 无 | 高 | ❌ 存在正概率漏源 |
| **B 系统覆盖** | ✅ **确定性 1000-覆盖** | ✅ **有（定理 C）** | 无 | 高 | ✅ **完全匹配** |
| C 信息驱动 | ⚠️ 依赖前瞻深度 | ⚠️ 难 | 需概率模型——**题面没给** | 中 | ⚠️ 前提不成立 |
| D 前沿探索 | ⚠️ 覆盖随终止条件 | ❌ | 无 | 中 | ❌ 无停止判据 |
| E RL | ❌ 高概率 | ❌ | 需大量仿真 | 低（时间不够） | ❌ 与"确保"矛盾 |

### 2.3 为什么排除 A / C / D / E（逐条给理由，不是印象）

**排除 A（随机撒点）**：要用随机撒点把"漏一个源"的概率压到工程可接受（如 < 1e-6），
所需点数**远超**覆盖论下界（这是经典的"生日问题/ε-网"现象），且**永远不能给"保证"**。
题面要求"确保"，随机在原理上出局。

**排除 C（信息驱动）**：它的前提是**有概率模型**（后验、熵）。
但题面的误差是**区间**（`附录2(1)`）、`k`/`g_i`/`R_i` **无先验分布** ⇒ 熵与信息增益**无定义**。
硬套（如假设均匀分布）等于**自行给题面加假设**——与 Q1 拒绝概率模型、Q2 拒绝启发式是同一个纪律。
**保留其思想的一个子集**：把"优先扫候选频道"这类**序**的启发式作为可选加速（不影响完备性）。

**排除 D（前沿探索）**：它天然没有"什么时候停"的判据（探索到没有新前沿就停？失败模式是漏源）。
Q3 需要的恰恰是**可判定的停止条件**（定理 C），这与前沿探索的设计哲学相反。

**排除 E（RL）**：三条理由同时成立——
(i) 目标不匹配（RL 优化期望，本问无期望可优化，§1.2 第 3 层）；
(ii) 硬约束给不了（RL 的高概率清完 ≠ 题面要求的"确保"）；
(iii) 时间与收益都不划算（虚拟时间余量 70 倍以上，状态空间小到可穷举，RL 的"近似"换不到任何东西）。

### 2.4 B 族内部的进一步比较

| 变体 | 覆盖 | 扫描成本 | 交会几何 | 需 homing | 综合 |
|---|---|---|---|---|---|
| B1 三角格 d=1500 + 蛇形 | ✅ | 低（7~9 点 ≈ 952 s） | `R_MEC = 30.2300 m` | ✅ 每源 |
| **B2 三角格 d=1000 + TSP** | ✅ | 中（10~12 点 ≈ 1428 s） | `R_MEC = 20.1533 m` | ⚠️ 临界 |
| B3 正方格 d=1500 | ✅ | 低（覆盖半径 `d/√2 = 1060.66 > 1000` ❌ **不满足 F3**！） | — | — | ❌ **出局** |
| B4 三角格 d=1732.0508（覆盖极限） | ✅ | 最低（单元数 3.91781） | `R_MEC = 34.9066 m` | ✅ 大量 | 覆盖刚好、时间最差 |
| B5 螺旋/蛇形连续扫 | ✅ | 路径长 | 交会基线不定 | ✅ 大量 | 作为 B1/B2 的**路径实现**，非独立方案 |

**重要发现（B3）**：**正方形格在 d=1500 时覆盖半径是 `d/√2 = 1060.66 m > 1000`，直接违反覆盖约束**。
正方形格要满足覆盖须 `d ≤ 1000√2 = 1414.2136 m`。→ 这给"为什么必须用三角格"提供了**比"密度最优"更硬的理由**：
**同间距下正方形格根本不可行**。论文里这是一个很漂亮的对照点。

**B4 的意义**：`d = 1732.0508` 是覆盖的**理论上限**，此时单元数 3.91781（接近下界 4），
扫描最省，但 `R_MEC = ε_rad·1732.0508/sin120° = ε_rad·2000 = 34.9066 m`（**仅格心构型**）⇒ 每源都要清除。
> 🚨 **2026-09-12 更正（审核 P0-14）**：`d` 的默认档取 **1000**（非 1500）——
> 免扫掠面积占比 **81.6%**，清除侧净胜 ~600 s。
⇒ 再次印证 §4.4 的"省扫描 ⇄ 免 homing"冲突**贯穿整个 d 区间**。

### 2.5 最终选型

**选 B2 为主、B1 为对照**（即"两阶段巡游 + 判据清除 + homing 兜底 + 频道状态机"），
**d 取 1000 与 1500 双轨实测标定**（`Q3数学原理总理顺.md` §4.4）。

```
两阶段：
  阶段 A 侦察巡游：TSP 序遍历检测点，每点扫全部未清除频道（顺路完成空频道确认）
                  记录每频道的 (位置, 结果) 历史；遇 near 立即原地 /clear
  阶段 B 清除巡游：对已定位频道算 L 与 R_MEC（复用 Q1 管线）
                  R_MEC ≤ 20 ⇒ 登记 MEC 圆心；> 20 ⇒ 登记 homing 起点
                  对清除点集做 TSP，一趟走完；homing 逐源执行
```

**为什么两阶段优于"发现一个就处理一个"**（对深度钻研 §7.4 五阶段循环的细化）：
1. 阶段 A 结束时每个可发现频道已有 **≥2 条异点示向度**（单条不足以定 `L`，见 Q1）；
2. 清除点可**统一 TSP**，避免往返；
3. 空频道确认**顺路摊完**，不产生额外巡游（这是 280 s 那笔成本的正确消化方式）；
4. homing 被压缩为**少数几何不利源**的补救（d=1000 时基本不触发）。

**预期效果**（解析推算，**待实测**）：

| 项 | d=1500 | d=1000 |
|---|---|---|
| 扫描 | ~952 s | ~1428 s |
| 清除（**v1.1.0：扫掠清除**，`N`=3 / 2，`≈10N` s/源 × 13） | **~390 s** | **~260 s** |
| 合计（粗算，不含网格间移动） | **~1342 s** | **~1688 s** |

⇒ **v1.1.0 修正**：v1.0.0 按 homing（213.49 s/源 ⇒ 2775 s）推算得"d=1500 明显更差、倾向 d=1000"；
补入扫掠清除后（≈30 s/源），**两者几乎打平**（1342 vs 1688，差距在网格移动上，而 `d=1000` 的点更多、TSP 更长）。
⇒ **`d` 的取舍改由"裕量 + 定位富余"决定**（`d=1000` 的 `R_MEC = 20.1533` 更贴阈值、且对 Q4 的定向源能给出更多同扇区示向度），
**但仍以模拟器标定为准**——这是 Q3/Q4 唯一需要实测标定的主参数，两问可合并做。

## 三、参数设计

### 3.1 参数表

| 参数 | 含义 | 初值 | 来源 | 调整方向 |
|---|---|---|---|---|
| `d` | 三角格间距 | **1000 与 1500 双轨** | 解析（Q3-F23）+ 待实测 | 见 §2.5；同时影响扫描成本与 `R_MEC` |
| `φ_nat` | 网格自然交会角 | **120°** | 推导（`Q3数学原理总理顺.md` §2.3） | 固定（三角格几何决定） |
| `R_w` | 设计用最坏接收半径 | **1000 m** | 引理 W(a) | 固定（不可放宽） |
| `r_clear` | 清除半径 | **20 m** | 题设 | 固定 |
| `r_near` | 近距阈值 | **5 m** | 题设 | 固定 |
| `v` | 移动速度 | **5 m/s** | 题设 | 固定 |
| `ε` | 误差半角 | **1°** | 题设 | 固定 |
| `h_k` | homing 步长 | `≈ r̂_k`（自适应） | 引理 H2 | 实测 `η` 后收紧 |
| `λ_safe` | 收缩率上界（判停用） | **0.0523590** | 推论 C.4b | 实测 `η` 后收紧至接近 0.0174531 |
| `τ_reserve` | 现实时间收尾裕量 | **60 s** | 工程判断 | 实测单请求开销后定 |
| `N` | 检测点数 | 10~12（d=1000）/ 7~9（d=1500） | Q3-F9 | 随 d |
| `δ_margin` | 判据数值容差 | **1e-9**（+ 可选工程裕量） | 实现 | 固定 |

### 3.2 参数如何定：两类，别混

| 类别 | 参数 | 定法 |
|---|---|---|
| **解析锁定**（不由实测决定） | `R_w=1000`、`φ_nat=120°`、`d ≤ 992.3920`（免 homing 条件）、`λ`、`λ_safe` | 已 CAS 复核，见 `Q3公式表.md` §七 |
| **实测标定**（必须跑模拟器） | `d` 定档、`η`、`τ_reserve`、实际步数分布 | 9-12 标定，回填权威数字表 §五 |

**纪律**：解析锁定的参数**不得因实测"看起来可以放宽"而改**——它们承载完备性论证。
实测只能标定第二类。

### 3.3 敏感性

| 参数扰动 | 对时间的影响 | 对完备性的影响 |
|---|---|---|
| `d` 从 1500 → 1000 | 扫描 +~476 s，homing −~2775 s（解析） | 无（两者都满足覆盖） |
| `R_w` 从 1000 → 1250（**违规**） | 时间下降 | 🚨 **完备性丧失**（漏远处源）——**禁止** |
| `ε` 从 1° → 0.5°（假想） | homing 成本大降（`λ` 减半） | 无 | 
| `k` 从 16 → 10 | 清除 −30 s；**空频道 +240 s** | 无（但需正确实现空频道确认） |
| `η` 从 0.0349 → 0.01（实测收紧） | homing 步数可能 2 → 1~2；`λ_safe` 从 0.0524 降到 ~0.028 | 无 |

**最敏感的是 `R_w`**——它是唯一"一动就破完备性"的参数。这正是引理 W(a) 存在的意义。

## 五、一句话总结

**Q3 的难点不在算法速度而在论证完备性：三层不可观测性里，前两层（结构、几何）可以用"取最坏值 + 保证"消除，
只有数量层不能——于是必须用可判定的停止条件（定理 C）绕开它。
算法选型因此收敛到"系统覆盖巡游（三角格，因为正方形格在 d=1500 下根本不满足覆盖）
+ Q1 的 `R_MEC ≤ 20` 判据 + homing 收缩 + 频道状态机"，而 `d` 是唯一需要模拟器标定的主参数。**
