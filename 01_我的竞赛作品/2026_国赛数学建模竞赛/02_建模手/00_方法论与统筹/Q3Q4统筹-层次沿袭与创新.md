## 1. 八层分解与沿袭/创新矩阵

把四问共同的问题结构拆成八层（L0 最底、L7 最高）：

| 层 | 名称 | 内容 | Q1 | Q2 | Q3 | Q4 |
|---|---|---|---|---|---|---|
| **L0** | 几何基元 | 角域、半平面、圆盘、凸包、最小包围圆 | 角域 = 半平面交 | 复用 L0 | 复用 L0 + **圆盘并** | 复用 L0 + **扇区 = 半平面** |
| **L1** | 度量 | 定位区域 `L`、直径 `D`、`R_MEC`、交会角 `φ`、误差放大 `ε_rad` | 建立 | 复用为**目标** | 复用为**判据输入** | 复用（加扇区过滤） |
| **L2** | 可测性/感知 | "什么条件下源能被测到" | — | — | **1000-覆盖** | **surrounding（包围）** |
| **L3** | 判别谓词 | 把几何问题变成可计算的是/否 | **Thales 判据**、Jung 夹逼 | **可行性不等式** | `R_MEC ≤ 20` | `R_MEC ≤ 20` + surrounding 自检 |
| **L4** | 目标函数 | 优化什么 | `min D`（但实际是"算出 D"） | `min E`（选点） | `min T_vir` | `min T_vir` |
| **L5** | **在线决策** | 策略、状态机、停机条件 | ❌ | ❌ | ✅ **五阶段/两阶段巡游 + 频道状态机 + 完备性停机** | ✅ 同 Q3 + **扇区探针** |
| **L6** | **成本-保证** | 时间、下界、保证强度 | 精确解（无成本概念） | 可行性天花板 | **双钟 + 三层下界 + 完备性定理** | 同 Q3 + **确定性 100%（非概率）** |
| **L7** | 稳健/最坏化 | 未知量怎么处理 | `ε` 区间（最坏 1°） | `Δd` 区间（最坏 `|Δ|=Δd`） | `R_eff` 最坏 1000、`k` 用状态穷尽绕开 | `∀u` 用凸包包含消掉 |

**读法**：
- **L0–L4 是"几何链"**，Q1 建立、Q2 第一次复用、Q3/Q4 第二次复用 —— **沿袭层**；
- **L5–L6 是"决策-成本链"**，Q1/Q2 完全没有，Q3 建立、Q4 扩展 —— **创新层**；
- **L7 是"最坏化层"**，四问都在用，但**每问的未知量不同**，是沿袭的"方法论"而非"代码"。

**⇒ 沿袭是"空间"的（同一个几何对象），创新是"时间"的（同一空间中如何行动）。**
这句可以当论文的方法总览开篇：**Q1/Q2 回答"源在哪里"，Q3/Q4 回答"如何把它找出来并清除"——前者是几何，后者是在几何之上的序贯决策。**

## 2. 沿袭清单（Q1/Q2 → Q3/Q4，逐层给"提供了什么 / 怎么用"）

### 2.1 L0 几何基元层：**零修改复用**

| Q1/Q2 的基元 | Q3 用法 | Q4 用法 |
|---|---|---|
| 角域 `W(S,θ,ε)`（Q1-F3） | 交叉定位构造 `L` | 同 Q3，**外加扇区过滤** |
| **角域 = 2 半平面之交**（Q1-F5） | —— | **Q4 的扇区本身就是半平面** ⇒ 与 Q1 同一类对象 |
| 射线两两求交 + **顶点过滤**（Q1-F13） | 直接调用 | 直接调用 |
| 单调链凸包（Q1-F14） | 直接调用 | 直接调用 |
| 直径（旋转卡壳 ⊕ 暴力互验，Q1-F16/F17） | 直接调用 | 直接调用 |
| **最小包围圆 `R_MEC`（Welzl，Q1-F8）** | **判据输入** | 同 Q3 |
| Thales 圈（Q2-F26/F27） | 网格间距设计的几何来源 | 同 Q3（承 Q1/Q2） |

**点透**：Q4 的"扇区 = 半平面"与 Q1 的"角域 = 半平面交"是**同一个几何对象**。
⇒ **Q1 建模时引入的"半平面"这一基元，在 Q4 中第二次成为主角**；
而它中间在 Q2/Q3 里退居次要（Q2 只用它的边界射线，Q3 只用它的交）。
**这是一个"基元复用"的漂亮例子**——建模时选对了基元（半平面），后两问白捡。

### 2.2 L1 度量层：复用为不同角色

| 度量 | Q1 角色 | Q2 角色 | Q3 角色 | Q4 角色 |
|---|---|---|---|---|
| `L`（定位区域） | **输出** | 间接（经 `E`） | **判据输入** | **判据输入（加扇区过滤）** |
| `D`（直径） | **主输出** | 交叉验证 | 充分代理（`D ≤ 34.6410`） | 同 Q3 |
| **`R_MEC`** | 覆盖问题的**正解** | 未用 | **清除判据（充要）** | 同 Q3 |
| `φ`（交会角） | 参数画像 | **决策变量**（选点） | 网格反解的中间量 | 同 Q3 |
| `ε_rad` 与横偏 | 痛感来源 | `E` 的因子 | homing 必要性 | 同 Q3 |

**点透**：**同一个 `R_MEC`，在 Q1 里是"问题的答案"，在 Q3/Q4 里变成"动作的判据"。**
这就是"沿袭"最有价值的形式——不是照抄结论，而是**把一个度量从"输出位"搬到"输入位"**。
论文里把这条写清楚（"Q1 的覆盖结论被 Q3 直接用作清除判据"），比说"我们复用了 Q1"有力得多。

### 2.3 L3 判别层：方法论的直接继承

| Q1/Q2 的判别范式 | Q3/Q4 的对应 |
|---|---|
| **Thales 判据**：把"圆覆盖"变成"顶点角度不等式"（可计算） | **`R_MEC ≤ 20`**：把"能否清除"变成半径比较（可计算） |
| **Jung 夹逼**：把"差多少"量化 | **三层下界**：把"离最优多远"量化 |
| **可行性不等式** `Δd ≤ R_w cos φ_min`：把可行性变成一条不等式 | **设计定理**（§5.1）：把四问可行性合成一条链 |
| **有界性判据**（Q1/Q2 的定向 matroid 视角） | surrounding 自检（`G ∈ conv Q(G)`） |

**点透**：**"把几何问题变成可计算谓词"是全题贯穿的第三种表达方式**
（前两种是"取最坏值"与"用凸性"）。这一范式在 Q1 里以 Thales 判据出现，
在 Q2 里以可行性不等式出现，在 Q3/Q4 里以 `R_MEC ≤ 20` 与完备性停机条件出现。
**四问的"结论"形态都是一条可检查的谓词**，这是全题最一致的写法。

### 2.4 L7 最坏化层：同一方法论、不同未知量

| 问 | 未知量 | 界的来源 | 最坏化的具体做法 |
|---|---|---|---|
| Q1 | `ε`（示向度误差） | 题设 `[−1°,1°]` | 取 `ε = 1°`；`ε` 单调性引理（Q1-F29） |
| Q2 | `d₁`（源距） | 题设 `(5,1500]` | 取 `|Δ| = Δd = 747.5`；对最坏 Δ 遍历/端点 |
| Q3 | `R_eff`、`k`、`δ` | 题设 `[1000,1500]`、`[10,16]`、`[−1°,1°]` | `R_w = 1000`；`k` **不可最坏化** ⇒ 用状态穷尽绕开 |
| Q4 | 再加 `u`（定向方向） | 无先验 | **用凸包包含把 `∀u` 整体消掉**（不逐点取最坏，而是整维消掉） |

**点透**：Q1/Q2/Q3 的最坏化是"**取端点**"（一维量的最坏值）；
Q4 的最坏化是"**消量词**"（一整维连续量）。
⇒ **这是最坏化手法的升级**：从"选取最坏样本"到"证明不存在坏样本"。
论文里可以把这个层次讲出来：**"我们不仅取最坏值，在 Q4 中我们直接消去了整维未知。"**

## 3. 创新清单（Q3/Q4 相对 Q1/Q2）

### 3.1 新增层次：**L5 在线决策层**（体量最大）

| 创新 | 内容 | 为什么 Q1/Q2 没有 |
|---|---|---|

### 3.2 新工具（Q1/Q2 一次都没用过）

| 工具 | 用在哪 | 为什么 Q1/Q2 不需要 |

### 3.3 新视角（本批最有方法论价值的四条）

| 视角 | 内容 |
|---|---|
| **∀u 消量词** | 面对"对任意朝向成立"，不去逐点验证，而是找它的**等价凸包条件**（`∀u ∃p : v_p·u ≥ 0 ⟺ 0 ∈ conv{v_p}`） |
| **把动作当观测** | `/clear` 不只是"执行"，它返回 `success`/`no_target_in_range`，是一个 **20 m 邻近性判决器** ⇒ 由此得到扫掠清除 |
| **前提失效 vs 结论失效** | 定理在扩展问题中"失效"时，先分清失效的是**前提**还是**结论**；前者只需换前提（Q4 的定理 C 就是可重建的） |
| **自加约束的自查** | 遇到"某约束下无解"的结论，先检查那个约束是不是**题面强加的**（Q4 的死角就是"检测点在圆内"这一自加假设的产物） |

### 3.4 新保证

| 保证 | Q1/Q2 的保证 | Q3/Q4 的保证 |
|---|---|---|
| 形态 | 精确解（Q1）/ 可行性边界（Q2） | **完备性定理**（清除比例 = 100%） |
| 强度 | 确定性 | **确定性**（Q4 也是确定性的，非概率——这是与 `深度钻研` §8.3 路线的关键差别） |
| 边界 | Jung 夹逼（缺口 ≤ 15.5%） | 三层下界（`L1 ≤ L2 ≤ OPT ≤ L3`）+ 差距归因 |
| 反例 | 等边三角形（Q1 的覆盖反例） | 死角（Q4 的反例）+ **它的消除**（外扩环带） |

**点透**：Q1 的"覆盖反例（等边三角形）"与 Q4 的"死角反例"**结构相同**——
都是"用一个反例否定一个过强命题，再给出修正后的正确命题"。
**这是全题最一致的"辩证结构"**（Q1：直径圆不够 ⇒ 最小包围圆；Q4：圆内网格不够 ⇒ 外扩环带）。
论文里把这一对反例并列，是很强的叙事。

## 5. 四问合一的统一结果（本报告的实质产出）

### 5.1 统一结果 U1：**设计定理**（约束链只有一处生效）

把四问对"检测点集"的可行性条件合成一条链：

```

(d) [Q3 免 homing] R_MEC ≤ 84.0369                ⇒  d ≤ 4169.8749 m     ✗ 非约束（> (a)）
```

**⇒ 约束链只在 (c) 处生效**：(a) 与 (d) 都是松的。
**设计定理**：若要求"发现即可原地清除"（免扫掠、免 homing），**唯一的紧约束是 `d ≤ 992.3920 m`**；

**点透**：这是 Q1（`R_MEC`）+ Q2（`φ=90°` 最优 ⇒ 自然几何 120°）+ Q3（覆盖）+ Q4（包围）
四问结论的**合成**，也是全题唯一一条"把四问写在一行里"的结果。**论文的"模型设计"节可以直接用它开篇。**

### 5.2 统一结果 U2（**⚠️ 2026-09-12 已更正为条件命题**）：格心构型下的 homing 封顶

> #### 🚨 更正说明（第三方审核 P0-13）
>
> **原 U2 把「单点最坏」当成了「全域上界」⇒ 是假定理。**
> `φ_nat = 120°` 只在**源恰在格心**时成立；源靠近**两格点连线**时 `φ → 180°`、`R_MEC → d/2`（d=1500 约 **750 m**）。
> 独立抽样（6000 点）：可解区 **中位 55.0 m / p95 453 m / max 750 m / 32.7% > 84.0369**；
> `30.2300 m` 只覆盖 **13.9%**；d=1500 时 **56.8% 区域连 2 条示向度都拿不到**。
> ⇒ **homing 会被启用**；论文禁止写「homing 永不启用」。
>
> #### 更正后的表述（**原文保留于下方，已作废**）
>
> **条件命题**：**格心构型下** `R_MEC = ε_rad·d/sin120°`，`d ≤ 1732.0508` 时 `≤ 34.9066 m`
> ⇒ 该构型下扫掠优于 homing。**但非全域上界** ⇒ 按分布/期望设计，并加**自适应补测**。
>
> #### ~~原文（已作废）~~
> ```
> 在自然几何（源落于格点三角形内，取其两顶点 ⇒ φ_nat = 120°）下：
>   R_MEC = ε_rad·d/sin120° ≤ ε_rad·1732.0508/0.866025 = 30.2300/0.866025 = 34.9066 m
> 而扫掠/homing 拐点 R* = 84.0369 m
> ⇒ 34.9066 < 84.0369 ⇒ 【扫掠恒优于 homing】⇒ homing 在本问参数域内永不启用
> ```

homing 唯一可能胜出的情形：交会几何劣化到

```
R_MEC > 84.0369 ⇒ ε_rad·L/sinφ > 84.0369（L ≤ 1732.0508）
⇒ sin φ < 30.2300/84.0369 = 0.359723 ⇒ φ < 21.0832°
```

⇒ **只有交会角劣化到 `φ < 21.0832°` 时，homing 才优于扫掠**（对应"仅 1 条同扇区示向度"、
"两点近共线"等退化配对）。

**优化提案**：Q3/Q4 的"三路清除"应改述为"**两主一兜底**"：

| 路 | 条件 | 地位 |
|---|---|---|
| 直接清除 | `R_MEC ≤ 20` | **主路 1** |
| 扫掠清除 | `20 < R_MEC ≤ 84.0369`（自然几何下**覆盖全部剩余情形**） | **主路 2** |
| homing | `R_MEC > 84.0369`（自然几何下**不可达**；仅退化配对触发） | **兜底** |

**价值**：① 论文里 homing 的篇幅可从"主算法"降为"兜底算法"（但**收缩引理仍要写**，它是理论完备性的一部分，且 Q4 中 homing 对盲区免疫这一点要单独说明）；
② 编程手的实现优先级随之明确（扫掠必做、homing 可后置）；③ 消除"什么时候用 homing"的实现纠结（答案是"几乎不用，但必须有"）。

### 5.3 统一结果 U3：**凸性 ⇒ 可解性**（全题方法论主线）

| 问 | 不确定集/约束集 | 凸性 | 带来的可解性 |
|---|---|---|---|
| Q1 | 角域 `W` = 2 半平面之交 | ✅ 凸 | `L` 是凸多边形 ⇒ 最远点对在顶点 ⇒ 直径多项式可解 |
| Q2 | 可行域 `{b : b_min ≤ |b| ≤ b_max}` | ✅ 区间 | 闭式解 `a = d₁`；可行性 = 一条不等式 |
| Q3 | 覆盖所需圆盘并 | ✅ 凸（每个圆盘凸） | 三角格构造 + 点数下界 |
| Q4 | 扇区 `H(G,u)` = 闭半平面 | ✅ 凸 | **分离定理可用** ⇒ `∀u` 可消 ⇒ surrounding 可判定 |

**统一命题（U3）**：**全题四问的可解性，全部来自"相关集合是凸集"。**
- Q1 若误差是概率分布 ⇒ 置信集非凸 ⇒ 直径问题变难（Q1 已明确拒绝）；
- Q4 若盲区边界是曲线（如方向依赖的多径遮挡）⇒ `M(G)` 非凸 ⇒ 分离定理失效、surrounding 无充要形式；

**⇒ 这正是 Q1 的"射影/非欧评估"与 Q4 的"累积遮挡推广"所指向的同一件事**：
**凸性是本题的"可解性边界"。** 论文里把它写成方法学结论，比逐问叙述更有分量。

### 5.4 统一结果 U4：**误差的放大与压缩两相**

```
一次性使用（Q1/Q2）：误差被放大   D ≈ 2ε_rad·L/sinφ ；  E ≈ ε_rad·√(d₁²+d₂²)/sinφ
                      ⇒ 放大因子 1/sinφ ≥ 1（φ 越小越坏，最坏发散）
迭代使用（Q3/Q4）：  误差被压缩   r_{k+1} ≤ 2sin(ε/2)·r_k = 0.0174531·r_k
                      ⇒ 压缩因子 λ < 1（与 δ 无关，与 sinφ 无关）
```

**点透**：**同一个 1°，一次性交会把误差放大到 17.5~31.4 m（超清除半径），
而迭代逼近把它压缩到 0.46 m（两步）。** 这个对比解释了 Q1 的"痛感来源"为什么必须由 Q3 的 homing 来消解，
也是 Q1 与 Q3 之间最直接的因果接续。**论文里把这两行并列，是一个很有力的对照。**

### 5.5 统一结果 U5：**定向先验的信息含量 + 一个免费判别器**

**命题**：设某源在点 `p₁, p₂, p₃` 处均测得 `direction`。则存在单位向量 `u` 使 `(pᵢ−G)·u ≥ 0`（`i=1,2,3`）
当且仅当 `G ∉ int conv{p₁,p₂,p₃}`。

**证明**：令 `vᵢ = pᵢ − G`。满足 `vᵢ·u ≥ 0 (∀i)` 的**非零** `u` 存在
⟺ 锥 `cone{vᵢ} ≠ ℝ²` ⟺ `0 ∉ int conv{vᵢ}` ⟺ `G ∉ int conv{p₁,p₂,p₃}`。
（`cone{vᵢ} = ℝ²` 当且仅当 `0` 落在 `conv{vᵢ}` 的内部；退化情形 `G ∈ ∂conv` 给出一个射线状的极锥，仍含非零 `u`，
与"扇区含边界"的口径一致。）∎

**三条推论（可直接用）**：

| 编号 | 推论 | 用途 |
|---|---|---|
| **U5-a** | **定向源不可能在其格点三角形的三个顶点上全部被测到**（三点互夹 120°，装不进任何半平面）⇒ 只可能被测到 1~2 次 | 解释了 Q4 中 `n_obs(G) = 1~2` 的机理；**也是 Q4 扇区探针必要性的根据** |
| **U5-b** | **判别器**：若某频道在互相包围的三个（或更多）格点上**全部**返回 `direction`，则该源**必为全向** | **免费的一致性断言**：对定向源的构造用例，出现 3/3 即说明扇区判定实现有 bug |
| **U5-c** | 定向源会**排除**一个区域：`G ∉ int conv(观测点集)` | 可作为 `L` 的**额外收紧**（把 `conv(观测点)` 的内部从 `L` 中挖掉） |

**U5-c 是真正可用的新信息吗？（2026-09-11 已实测否决）**：Q4 中若某频道在点集 `S`（全体测到 `direction` 的点）上被观测，
则源满足 `G ∉ int conv(S)`。当 `|S| ≥ 3` 时这是一条非凸约束，**理论上**可在 `L` 上"挖洞"以缩小 `R_MEC`。
**但 V3 数值实验（`Q3Q4统筹-U5c挖洞实验.py`，480 配置 × 4 参数组）证明收益可忽略**：
正收益占比 0~0.24%、最大 `ΔR_MEC = 2.9118 m`；即使洞内删掉了 `L` 的 45.7%，`R_MEC` 也不变。
**机理：挖洞是"切掉一块"而非"整体收缩"** —— `R_MEC` 由最远点对决定，切除一侧不改变包围圆半径。
⇒ **P6 已否决**（保留 U5-a 的机理解释与 U5-b 的零成本判别器）。

**点透**：这条结果把"**观测本身携带的信息**"从"源在角域内"（Q1 已用）推进到
"**源不在观测点的凸包里**"（Q4 新增，因为定向源的可见性有方向性）。
⇒ 这是"把动作/观测当作信息源"这一视角的又一实例（与扫掠清除同源）。
