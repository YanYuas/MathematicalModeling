## 1. 延承核：半平面（Q1 的角域 ↔ Q4 的扇区）

### 1.1 统一命题

> **命题 S（半平面是 Q1/Q4 的公共基元）**
> Q1 的角域 `W(S,θ,ε) = {S + t·u(φ) : t ≥ 0, |angdiff(φ,θ)| ≤ ε}` 是 **2 个半平面之交**；
> Q4 的扇区 `H(G,u) = {X : (X−G)·u ≥ 0}` 是 **1 个半平面**。
> 两者都是 `{X : a·X ≥ b}` 形式的**闭凸集**。

**证明**：Q1 已证（`Q1-F5`）：由 `|angdiff(φ,θ)| ≤ ε` 得两条过 `S` 的边界直线，角域是它们所界定的一对半平面之交。
Q4：由 `|∠((X−G),u)| ≤ 90°` ⟺ `(X−G)·u ≥ 0`，即 `u·X ≥ u·G`，是单个闭半平面。∎

### 1.2 两种用法（为什么"之交"与"单个"的差别重要）

| | Q1 用法 | Q4 用法 |
|---|---|---|
| 对象 | 半平面**之交**（限定方向范围） | 半平面**本身**（限定可见侧） |
| 几何含义 | "源在我的观测方向上" | "我在源的可见侧" |
| 触发的数学 | 半平面交 ⇒ `L` 凸 ⇒ **极点枚举** | 极锥 ⇒ **全称量词可消** |
| 结果 | `D`、`R_MEC` 可精确算 | `∀u` 消成 `conv` 包含 |

**点透**：同一对象在 Q1 里用来"**界定**一个区域"，在 Q4 里用来"**裁定**一个可见性"。
前者是**构造性**用法（求交），后者是**判定性**用法（对偶）。
**⇒ 一个基元的两套用法，正是"沿袭"与"创新"在同一处的交汇。**

## 2. 【新结果】命题 U1：设计定理（四问约束链）

### 2.1 陈述

> **命题 U1（检测点集的设计定理）**
> 设圆域半径 `R = 1800`、最坏接收半径 `r = 1000`、清除半径 `ρ = 20`、示向度误差 `ε = 1°`、
> 检测点集为三角格（间距 `d`），源落在格点三角形内（取其两顶点作为交会站，自然交会角 `φ_nat = 120°`）。
> 则"保证发现 + 保证清除"的检测点集须同时满足四条约束：
> ```
> (a) [Q3 覆盖]      d/√3 ≤ r                    ⇒  d ≤ √3·r = 1732.0508 m
> (b) [Q4 包围]      检测点外扩环带（宽度 = **d**） ⇒  P = Lattice ∩ (D ⊕ B(0, d))   ← **2026-09-12 更正**
> (c) [Q1+Q2 免扫掠]  R_MEC = ε_rad·d/sin φ_nat ≤ ρ  ⇒  d ≤ ρ·sin φ_nat / ε_rad = 992.3920 m  ★
> (d) [Q3 免 homing]  R_MEC ≤ R* = 84.0369 m     ⇒  d ≤ R*·sin φ_nat / ε_rad = 4169.8749 m  ✗
> ```
> **其中只有 (c) 生效**（(a) 与 (d) 均为松约束）。

### 2.2 四条约束的推导

**(a) 覆盖**：三角格的覆盖半径为 `d/√3`（间距 `d` 的格点到单元内任意点的最大距离）。
要保证"任意位置的源至少被一个检测点罩住"，须 `d/√3 ≤ r`（`r` 取最坏值 `1000`，Q3 引理 W(a)）。∎

**(b) 包围**：Q4 的发现条件是 `∀G : G ∈ conv{p ∈ P : ‖p−G‖ ≤ r}`（surrounding）。
对 `G ∈ D`，其**最近邻**距 `G ≤ d/√3`，而**第三近邻可达 `d`**，故它们到 `D` 的距离 `≤ d` ⇒
检测点集须包含"到 `D` 的距离 `≤ d`"的全部格点 ⇒ 环带宽度为 **`d`**。∎
（原证明把三点的共同界写成 `d/√3`，**低估第三近邻**；实测按 `d/√3` 建环带时边界带失败 **42.05%**。）

**(c) 免扫掠**：对称配置下 `γ ≡ 1`（Q1 扫描实测），故 `R_MEC = D/2 = ε_rad·L/sin φ`（`L` = 基线的长）。
取 `φ = φ_nat = 120°`（源落在格点三角形内时，两顶点在源处的夹角；由三角形 `|S₁G| = |S₂G| = d/√3`、`|S₁S₂| = d`
得 `cos φ = (d²/3 + d²/3 − d²)/(2d²/3) = −1/2`，故 `φ = 120°`）、`L = d`：
`R_MEC = ε_rad·d/sin120° ≤ ρ ⇒ d ≤ ρ·sin120°/ε_rad = 20×0.866025/0.01745329 = 992.3920 m`。∎

**(d) 免 homing**：同上取 `R* = 84.0369 m`（扫掠/homing 拐点，见命题 U2）：
`d ≤ R*·sin120°/ε_rad = 84.03685×0.866025/0.01745329 = 4169.8749 m`。∎

### 2.4 推论

**推论 U1-a**：若要求"发现即可在原地清除"（`N_sweep = 1`），则间距必须 `d ≤ 992.3920 m`；
若接受扫掠清除，间距可放宽到 `d ≤ 1732.0508 m`（覆盖上限）。
**推论 U1-b**：**Q2 的"`φ=90°` 最优"结论，其真正的落地形态不是"选一个 90° 的第二点"，
而是"把网格间距压到 `≤ 992.3920 m`"**——因为 Q3/Q4 中检测点由覆盖/包围约束锁定，没有选点自由度。
**推论 U1-c**：设计定理是**唯一一条把四问写在同一个不等式链里**的结果。
**推论 U1-d（🚨 2026-09-12 作废）**：原文称「`d/√3` 这个量同时是"环带宽度"（Q4）与"覆盖半径"（Q3）」——
**该"一个量两种用途"的卖点不成立**：更正后**覆盖半径仍是 `d/√3`**，而**环带宽度是 `d`**。以下原文仅存留痕：
**同一几何量的两种用途**（Q4 里它决定"点要放到哪里"，Q3 里它决定"点要放多密"）。

### 3.2 证明

`R_MEC` 在自然几何下为 `ε_rad·d/sin φ_nat`，关于 `d` 单调增（`φ_nat` 固定），故
```
max R_MEC = ε_rad·1732.0508/sin120° = 30.229989/0.866025 = 34.9066 m     （CAS）
```
扫掠成本 `C_sweep = 10·N_sweep`，`N_sweep = ⌈1.2091996(R_MEC/20)²⌉`；homing 成本 `C_homing = 213.49 s`（与 `R_MEC` 无关）。
两者相等给出拐点 `R* = 84.0369 m`（CAS：`1.2091996(R/20)²·10 = 213.49 ⇒ R = 84.03685`）。
因 `34.9066 < 84.0369`，在 `d ≤ 1732.0508` 的整个参数域内均有 `C_sweep < C_homing`。∎

**注**：`R*` 的值依赖成本模型（`≈10 s/次`，含 `≈35 m` 移动）；若成本模型取 `8 s/次`，则 `R* = 93.9725 m`——
仍远大于 `34.9066 m`，**结论不变**。这是 U2 的**鲁棒性**：它不依赖成本模型的精确取值。

### 3.3 `φ` 阈值（homing 唯一可能胜出的条件）

交会几何可由多种原因劣化（两个观测点近共线、Q4 中只有 1 条同扇区示向度且探针失效等）。
设基线上限 `L ≤ 1732.0508`，则
```
R_MEC = ε_rad·L/sin φ > 84.0369  ⇒  sin φ < 30.229989/84.03685 = 0.359723
                                 ⇒  φ < 21.0832°        （CAS）
```
⇒ **homing 仅在 `φ < 21.0832°` 时优于扫掠**（`φ_nat = 120°` 距此阈值有 99° 的余量）。

### 3.4 推论：清除由"三路"降为"**两主一兜底**"

| 路 | 条件 | 自然几何下是否触发 | 地位 |
|---|---|---|---|
| 直接清除 | `R_MEC ≤ 20` | `d ≤ 992.3920` 时触发 | **主路 1** |
| 扫掠清除 | `20 < R_MEC ≤ 84.0369` | `d > 992.3920` 时触发（**覆盖全部剩余情形**） | **主路 2** |
| homing | `R_MEC > 84.0369` | **不可达**（仅 `φ < 21.0832°` 的退化配对） | **兜底** |

**⇒ 对论文与实现的三条影响**：
1. homing 的**篇幅权重**可从"主算法"降为"兜底算法"（但**收缩引理必须保留**——它是理论完备性的一部分；
   且 Q4 中"homing 对盲区免疫"这一性质要单独说明）；
2. 编程手的**实现优先级**明确：扫掠必做、homing 可后置（但接口要留）；
3. 消除实现层的纠结（"何时切 homing"）——答案是"自然几何下几乎不用，但必须有"。

## 4. 【新结果】命题 U3：凸性是可解性的共同来源（四种机制）

### 4.1 陈述

> **命题 U3**：Q1–Q4 四问的可解性**全部**来自凸性，但凸性在四问中**以四种不同机制**发挥作用：
> ```
> Q1：集合凸      （角域 = 半平面交 ⇒ L 凸）      ⇒ 极点枚举 ⇒ 直径/包围圆多项式可解
> Q2：函数凸/单峰 （E 关于 |Δ| 单调）              ⇒ 闭式解 a = d₁
> Q3：单元凸      （单个检测圆盘凸）               ⇒ 覆盖论可用（密度、格点构造、点数下界）
> Q4：对偶可算    （半平面的极锥非平凡）           ⇒ 全称量词 ∀u 可整体消去
> ```

### 4.2 四种机制的说明与出处

| 问 | 凸性的载体 | 用到的凸性结论 | 出处 |
|---|---|---|---|
| Q1 | `L = ⋂ Wᵢ`（凸多边形） | 凸集上最远点对必为极点对 | `Q1-F18` |
| Q2 | `E` 仅通过 `Δ²` 依赖 `Δ` | 单调性 ⇒ 极值在 `Δ = 0` | `Q2` 命题 C.1 |
| Q3 | 每个 `B(p,r)` 凸 | 等圆覆盖的密度与格点构造 | `Q3` 命题 C.1 |
| Q4 | `H(G,u)` 凸 ⇒ 极锥 `{u : (pᵢ−G)·u ≥ 0}` 非平凡 | `cone{vᵢ} = ℝ² ⟺ 0 ∈ int conv{vᵢ}` | 本文件命题 U5 |

### 4.3 凸性一旦丢失会怎样（三个反例，说明它是**可解性边界**）

| 问 | 若换成非凸的模型 | 后果 |
|---|---|---|
| Q1 | 误差为**两个分离的区间**（如 `[−1°,−0.5°] ∪ [0.5°,1°]`）⇒ 角域分成两块 | `L` 非凸（甚至不连通）⇒ "最远点对必在极点"失效，须枚举**全部连通块**再取最大，复杂度上升 |
| Q1' | 误差为**概率分布** | 不是凸性丢失，而是**结论语义改变**：区域从"所有可能位置"变成"置信区域"，Q1 已明确拒绝（题设是有界不确定性） |

## 5. 【新结果】命题 U4：误差的两相（一次性放大 vs 迭代压缩）

### 5.1 陈述

> **命题 U4**：同一个示向度误差 `ε = 1°`，在"一次性使用"与"迭代使用"两种模式下**行为相反**：
> ```
> 一次性（Q1/Q2）：  放大    D = 2·ε_rad·L / sin φ          （放大因子 1/sin φ ≥ 1）
> 迭代（Q3/Q4）：    压缩    r_{k+1} ≤ 2·sin(ε/2)·r_k       （压缩因子 λ = 0.0174531 < 1）
> ```

### 5.2 统一推导

**一次性（Q1 的精确式）**：两条示向度各自的横向不确定度为 `2ε_rad·dᵢ` 量级；
两线的交点位移被夹角 `φ` 的余割放大：`D = 2·ε_rad·L/sin φ`（`L` = 基线长，`φ ≥ 90°` 时精确）。
关键：**`1/sin φ` 无上界**——`φ → 0`（两站近共线）时 `D → ∞`。

**迭代（Q3 的收缩引理）**：在真实距离 `r` 处沿测得方位走一步 `h = r`，落点距离
```
r' = √(r² + h² − 2rh·cos δ) = 2r·sin(|δ|/2) ≤ 2·sin(ε/2)·r
```
关键：**`2sin(ε/2)` 与 `δ`、与 `φ` 都无关**，只与 `ε` 有关；`δ → 0` 时 `r' → 0`。

**两个极限方向相反**：`φ → 0` 使一次性的 `D` 发散；`δ → 0` 使迭代的 `r'` 消失。
⇒ **"差几何"可以通过"多迭代"消解，但"一次交会"不能。**

### 5.3 数值对照（论文可直接用）

| 使用方式 | 最坏放大/压缩 | 数值 | 与 `ρ = 20 m` 比较 |
|---|---|---|---|
| 一次性（裸横偏 @1000 m） | `d·tan1°` | **17.4551 m** | 0.87 倍（勉强） |
| 一次性（裸横偏 @1500 m） | `d·tan1°` | **26.1826 m** | **1.31 倍（超标）** |
| 一次性（两点交会，Q1 基准算例 `φ=61.92°`） | `÷sin φ` | `D =` **39.598 m** | **1.98 倍（超标）** |
| 迭代（Q3/Q4，理想） | `×0.0174531` | 1500 → 26.1796 → **0.45691 m** | **0.023 倍（远优）** |
| 迭代（Q3/Q4，工程含 `r̂` 误差） | `×0.0523590` | 1500 → 78.5385 → **4.1122 m** | **0.21 倍（优）** |

**点透**：**这个对照把 Q1 的"痛感来源"与 Q3 的"解法"接成了一条因果线**——
Q1 的 17.5~31.4 m 横偏正是"必须迭代"的理由，而 Q3 的 `λ = 0.0174531` 正是"迭代有效"的保证。
**建议论文里把这张表放在问题 3 的 homing 节，作为对问题 1 的呼应。**

## 6. 【新结果】命题 U5：定向观测的信息含量（观测点凸包外）

### 6.1 陈述

> **命题 U5**
> 设某源在点 `p₁,…,p_k`（`k ≥ 2`）处均测得 `direction`（即该源在这些点可见）。
> 则存在单位向量 `u ∈ S¹` 使 `(pᵢ − G)·u ≥ 0`（`∀i`）
> **当且仅当** `G ∉ int conv{p₁,…,p_k}`。
> **⇒ 观测本身携带信息：`G ∉ int conv(观测点集)`。**

### 6.2 证明

令 `vᵢ = pᵢ − G`。满足 `vᵢ·u ≥ 0 (∀i)` 的**非零** `u` 存在
⟺ 极锥 `C° = {u : vᵢ·u ≥ 0 ∀i}` 非平凡
⟺ 生成的锥 `C = cone{vᵢ}` 不是整个 `ℝ²`
⟺ `0 ∉ int conv{vᵢ}`（有限点集：`cone` 张满全平面当且仅当原点落在凸包内部）
⟺ `G ∉ int conv{p₁,…,p_k}`。∎

**退化情形**：`G ∈ ∂conv{pᵢ}` 时 `C°` 是一条射线（非平凡）⇒ 仍有非零 `u`（对应扇区边界恰为 90°，与"含边界"口径一致）。

### 6.3 三条推论

| 编号 | 推论 | 用途 |
|---|---|---|
| **U5-a** | **定向源不可能在其格点三角形的三个顶点上全部被测到**（三点互夹 120°，装不进任何半平面）⇒ `n_obs(G) ∈ {1,2}` | 解释了 Q4 中"半平面只含 `Q(G)` 的 1~2 个点"的机理；**扇区探针必要性的根据** |
| **U5-b** | **全向判别器**：若某频道在互相包围的三个（或更多）点上**全部**返回 `direction`，则该源**必为全向** | **免费的一致性断言**：对定向源的构造用例，出现 3/3 即说明扇区判定实现有 bug（列入 Q4 断言表） |
| **U5-c** | **`L` 的额外收紧**：`L ← L \ int conv(S)`，`S` = 该频道全部测到 `direction` 的点集（`|S| ≥ 3` 时） | ❌ **已否决**（V3 实验，见 §6.5） |

### 6.5 U5 的数值验证（V3 实验，2026-09-11）

脚本：`02_建模手/Q3Q4统筹-U5c挖洞实验.py`（numpy，可复现）。
配置：`G` 在圆域内随机 60 个 × `u` 均布 8 个方向 = 480 配置/参数组；`d ∈ {1500,1000}`、`R_eff ∈ {1000,1500}`。
交会站取"离源最近的 `S` 中两点"（Q3/Q4 的 homing 起点逻辑）。

| `d` | `R_eff` | `|S|` 中位 | `|S| ≥ 3` 占比 | `ΔR_MEC` 中位 | `ΔR_MEC` 最大 | 正收益占比 | 洞内被删的 `L` 采点 最大占比 |
|---|---|---|---|---|---|---|---|
| 1500 | 1000 | 1 | 0.0% | 0.0000 m | 0.0000 m | 0/30 | 0% |
| 1500 | 1500 | 2 | 4.0% | 0.0000 m | 0.0000 m | 0/258 | 11.8% |
| 1000 | 1000 | 2 | 2.9% | 0.0000 m | 0.0000 m | 0/259 | 0% |
| 1000 | 1500 | 3 | 64.6% | 0.0000 m | **2.9118 m** | **1/424 (0.24%)** | **45.7%** |

**三条结论**：

1. **`|S| ≤ 2` 时约束为空**：`conv(S)` 是线段或点，`int conv(S) = ∅` ⇒ 挖洞无对象可施。
   实测 `|S|` 中位 1~3（最坏半径 `R_eff = 1000` 时中位仅 1~2）⇒ **验证了 U5-a**
   （"半平面只含 `Q(G)` 的 1~2 点"）。
2. **即使挖掉近半个 `L`，`R_MEC` 也不降**：`d=1000, R_eff=1500` 组里洞内删掉的 `L` 采样点最多达 **45.7%**，
   但 `R_MEC` 变化为 **0**。**机理：挖洞是"切掉一块"而不是"整体收缩"**——
   `R_MEC` 由 `L` 的**最远点对**决定，只有当被切掉的恰是长轴端点时才会降；切除一侧不改变包围圆半径。
3. **正收益占比 0~0.24%**（唯一正例削减 2.9118 m）⇒ **收益可忽略**。

**⇒ 结论：U5-c 不采纳**（P6 否决）。**这条"否决"本身是有价值的产出**——
它避免了一个听起来很聪明、实际无收益的实现复杂度（且该复杂度会引入"非凸 `L`"这一新麻烦）。

**保留但降级的**：U5-a（解释 `n_obs ≤ 2`）与 U5-b（全向判别器）**仍采纳**——
前者是机理说明，后者是一条**零成本**的断言（已加入 `Q4建模数学化.md` 断言 13）。
