## 1. 延承核：Thales 二次型

### 1.1 统一命题

**命题 0（Thales 二次型）** 设 A ≠ B ∈ ℝ²，记

```
T(A, B; X) = (X − A)·(X − B)
D(A,B)     = 以 AB 为直径的闭圆盘（圆心 (A+B)/2，半径 |AB|/2）
```

则对任意 X：

```
T(A, B; X)  ≤ 0    ⟺    X ∈ D(A,B)    ⟺    ∠AXB ≥ 90°
T(A, B; X)  = 0    ⟺    X ∈ ∂D(A,B)   ⟺    ∠AXB = 90°
```

**证明**：设 M = (A+B)/2，则

```
‖X − M‖² − (|AB|/2)² = ‖X‖² − X·(A+B) + A·B = (X − A)·(X − B) = T(A,B;X)
```

（直接展开即得）。故 `T ≤ 0 ⟺ X ∈ D`。又 `T = ‖X−A‖·‖X−B‖·cos∠AXB`，故 `T ≤ 0 ⟺ cos∠AXB ≤ 0 ⟺ ∠AXB ≥ 90°`，`T = 0 ⟺ ∠AXB = 90°`。证毕。

**注**：这一条同时给出 Q1 与 Q2 的全部几何来源，无需分别陈述。

### 1.2 两种用法

**Q1（内性）**：设 V 为定位区域 L 的顶点集，P、Q 为 L 的一组直径端点。则

```
D(P,Q) ⊇ L   ⟺   T(P,Q; X) ≤ 0  ∀X ∈ V
```

（**只需校验顶点**——理由见命题 I。）

**Q2（边界性）**：设 S₁ 固定，第二检测点 S₂ 待选。则

```
φ = ∠S₁GS₂ = 90°   ⟺   T(S₁,S₂; G) = 0
```

即 **源落在以 S₁S₂ 为直径的圆周上**。

**Q1 与 Q2 的对偶**：

| | 已知 | 未知/待定 | T 的角色 |
|---|---|---|---|
| Q1 | 直径端点 P,Q | 待判定点 X | **不等式**（内性） |
| Q2 | 基点 S₁ | 待选的 S₂（使 T 对源取零） | **方程**（边界性） |

## 2. 【新结果】命题 I：90° 是超水平集凸性的临界阈值

> 这是本次最深的一条。它解释了 **Q1 的"只查顶点"为什么成立**，也解释了 **Q2 的最优阈值为什么也是 90°**——两者不是巧合，而是同一个临界值。

### 2.1 陈述

记角度函数的**超水平集**

```
S(α) = { X ∈ ℝ² : ∠AXB ≥ α },     α ∈ (0°, 180°)
```

**命题 I**：`S(α)` 为凸集 **⟺** `α ≥ 90°`。

**等价表述**：90° 是使超水平集成为凸集的**最小（临界）阈值**。

### 2.2 结构引理

**引理 I.1（两圆盘结构）** 不妨取 A = (−1, 0)、B = (1, 0)（相似变换不改变角度与凸性）。对 `α ≠ 90°`，定义

```
ρ(α) = 1 / sin α           （圆盘半径）
c(α) = cot α               （圆心到 AB 中点的有向距离）
D±(α) = 以 (0, ±c(α)) 为心、ρ(α) 为半径的闭圆盘
```

则

```
α > 90° :   S(α) = D₊(α) ∩ D₋(α)        （两圆盘之交）
α < 90° :   S(α) = D₊(α) ∪ D₋(α)        （两圆盘之并）
α = 90° :   D₊ = D₋ = 以 AB 为直径的圆盘
```

**证明**：过 A、B 的圆，圆心在中垂线上。设圆心 (0, h)，半径 ρ，则 `1 + h² = ρ²`。圆周上 X 处所张的 ∠AXB 等于弧 AB（不含 X 的那段）所对圆心角之半。

取圆心在 (0, c)、半径 ρ = 1/sin α 的圆（此时 `1 + c² = ρ²` 要求 `c² = csc²α − 1 = cot²α`，即 `c = ±cot α` ✓）。则 A、B 分居圆心下方，圆心到 AB 的距离为 |c|。弦 AB 所对的圆心角 θ 满足 `sin(θ/2) = 1/ρ = sin α`，即 `θ = 2α`（取 α ≤ 90° 时）或 `θ = 360° − 2α`。

- 若 `c = cot α > 0`（即 α < 90°），圆心在上方，**不含** X 的弧取下方短弧时圆心角为 `2α`（因 α<90° 时 2α<180°，是短弧）… 需分区讨论；
- 要点是：**圆周上满足 ∠AXB = α 的点集恰为这两条弧**（上弧与下弧），且
  - α < 90° 时两弧分别在 AB 两侧**向外凸出**，围出的区域是两圆盘的**并**；
  - α > 90° 时圆心穿越到对侧，围出的区域是两圆盘的**交**；
  - α = 90° 时 c = 0，两圆盘重合为直径圆盘。

严格写法：点 X 在圆盘 D₊ 内 ⟺ X 与圆心的连线…（略）。关键判别：沿中垂线，`∠AXB = 2·arctan(1/|y|)`，故沿中垂线 `S(α) ∩ {x=0} = {(0,y) : |y| ≤ cot(α/2)}`。

- α < 90°：`D₊ ∩ {x=0} = [c − ρ, c + ρ] = [−tan(α/2), cot(α/2)]`（用 `c − ρ = cot α − csc α = −tan(α/2)`，`c + ρ = cot α + csc α = cot(α/2)`）。它只覆盖中垂线的上半段，下半段由 D₋ 覆盖 ⇒ 并集恰为 `|y| ≤ cot(α/2)` ✓
- α > 90°：`c < 0`，同理 `D₊ ∩ {x=0} = [c−ρ, c+ρ] = [−cot(α/2), tan(α/2)]`，`D₋ ∩ {x=0} = [−tan(α/2), cot(α/2)]`，交集恰为 `|y| ≤ tan(α/2)`。而 α>90° 时 `cot(α/2) < 1 < tan(α/2)`，故 `tan(α/2)` 是 S(α) 沿中垂线的半幅 ✓ 与 `S(α)∩{x=0}` 一致。

∎

**引理 I.2** 两闭圆盘的**交**是凸集（圆盘凸，交凸）✓；两闭圆盘的**并**通常非凸。

### 2.3 命题 I 的证明

**（⟸）** α ≥ 90° 时由引理 I.1，`S(α) = D₊ ∩ D₋`（α=90° 时两者重合），两圆盘之交为凸集 ✓。

**（⟹）** α < 90° 时给出非凸见证。取

```
X± = ( −1 − δ , ± rδ ),      r > tan α,   δ > 0 充分小
```

（A = (−1,0)、B = (1,0)）。计算 X± 处的张角：向量 `X± → A = (δ, ∓rδ)`、`X± → B = (2+δ, ∓rδ)`，故

```
cos∠AX±B = [ δ(2+δ) + r²δ² ] / ( δ√(1+r²) · √((2+δ)² + r²δ²) )
δ→0 时  ⟶  1 / √(1 + r²)
```

从而 `∠AX±B → arctan r > α`（因 r > tan α），故当 δ 充分小时 `X± ∈ S(α)`。

而**中点** `X₀ = (−1−δ, 0)`：向量 `X₀→A = (δ, 0)`、`X₀→B = (2+δ, 0)` 同向，`∠AX₀B = 0 < α`，故 `X₀ ∉ S(α)`。

于是 `X± ∈ S(α)` 但 `(X₊ + X₋)/2 = X₀ ∉ S(α)` ⇒ **S(α) 非凸**。∎

**注**：任取 α < 90°，取 `r > tan α` 即可构造见证 ⇒ 结论对所有 α < 90° 成立。

### 2.4 数值见证 ✅

取 A = (−1,0)、B = (1,0)：

| 点 | ∠AXB（CAS 实测） | 归属 |
|---|---|---|
| `(−1.04, +0.15)` | **70.87°** | ∈ S(60°) |
| `(−1.04, −0.15)` | **70.87°** | ∈ S(60°) |
| 二者中点 `(−1.04, 0)` | **0°** | ∉ S(60°) |

⇒ **S(60°) 非凸**（见证成立）。

对照 α = 90°：`(−1.04, ±0.15)` 到原点距离 `√(1.04²+0.15²) = 1.0505 > 1` ⇒ 在直径圆盘**外**，与 `∠ = 70.87° < 90°` 一致 ✓；而 S(90°) 即该圆盘，凸 ✓。

另取 `r = tan 85°`、`δ = 10⁻³`：`X₊ = (−1.001, 0.01143)` 处 ∠ = **84.67°**（受有限 δ 修正，极限为 arctan r = 85°），中点 ∠ = **0°** —— 说明临界性可以逼近到 90° 而始终非凸。

### 2.5 三个推论

**推论 I.1（Q1 顶点判据的确切理由）**
Q1 的判据"`D(P,Q) ⊇ L ⟺ 对每个顶点 X 有 ∠PXQ ≥ 90°`"成立的**真正原因**是：**90° 这个阈值恰好使超水平集成为凸集**。由 `L = conv(V)` 与 `S(90°) = D(P,Q)` 凸，得 `V ⊆ S ⟹ conv(V) ⊆ S` ✓。

**推论 I.2（判据的临界性）**
若题面阈值不是 90°（例如"能否用 120° 视角锥覆盖"），则**顶点判据一般不成立**——因为 `S(120°)` 虽凸（= 两圆盘之交），但 `S(60°)` 非凸。**"只查顶点"这一简化恰好在 90° 有效。**

**推论 I.3（Q1/Q2 阈值同源）**
Q1 的覆盖阈值与 Q2 的最优阈值都是 90°，其共同根源是：**90° 是 T(A,B;X) 符号改变的唯一分界，也是超水平集凸性的唯一临界值**。两问共用同一个临界角。

## 3. 【新结果】命题 II：正交最优性的外接圆分解

> Q2 的最优性（`a = d₁`）在 [[Q2/Q2全解总览.md]] §4.2 中由"E 关于 Δ² 单调"证明。这里给出**第二条独立证明**，并揭示目标函数的**尺度–形状分解**。

### 3.1 尺度–形状分解

Q2 的目标为

```
E = ε · √(d₁² + d₂²) / sin φ
```

考虑三角形 △S₁GS₂，记 `L = |S₁S₂|`，`R_c` 为其**外接圆半径**。由正弦定理（边 L 对角 φ）：

```
L / sin φ = 2 R_c        ⟹        1 / sin φ = 2 R_c / L
```

代入即得**分解式**：

```
E = ε · √(d₁² + d₂²)  ·  (2 R_c / L)
     ╰──── 尺度因子 ────╯    ╰─ 形状因子 ─╯
```

**点透**：尺度因子只含两段距离 `d₁, d₂`；形状因子 `2R_c/L` 是三角形的**相似不变量**（只依赖形状，不依赖大小）。**目标函数于是正交分解为「大小」×「形状」。**

### 3.2 形状因子的下界与等号条件

**命题 II.1** 对任意非退化三角形，`2R_c / L ≥ 1`，等号成立 **⟺** 边 L 所对的角（即 φ = ∠S₁GS₂）等于 90°。

**证明**：由正弦定理 `L = 2R_c sin φ`，故 `2R_c/L = 1/sin φ ≥ 1`，等号 ⟺ `sin φ = 1` ⟺ `φ = 90°`（φ ∈ (0°,180°)）。∎

**几何读法**：`R_c ≥ L/2` 即"外接圆半径不小于任一边之半"，等号当且仅当该边为直径——**又是 Thales**。

### 3.3 最优构型的刻画

由命题 II.1，`E ≥ ε√(d₁²+d₂²)`，等号当且仅当 `φ = 90°`。而 `φ = 90°` 时：

- 三角形 △S₁GS₂ 在 **G 处直角**，故 `S₁S₂` 为斜边，`L² = d₁² + d₂²`；
- 其**外接圆以 S₁S₂ 为直径**，即命题 0 的 Thales 圆；
- 形状因子 `2R_c/L = 1` 取到最小值。

**⇒ 最优构型的完整刻画**：

> **最优第二检测点使三角形 △S₁GS₂ 在源处构成直角三角形，且其外接圆恰为以 S₁S₂ 为直径的 Thales 圆。**

**与 Q1 的延承**：Q1 的覆盖判定用的是"以直径为直径的圆盘"；Q2 的最优构型用的是"以两测点为直径的圆"。**同一个 Thales 圆，Q1 问区域是否被它包含，Q2 让源落在它上面。**

### 3.4 两条证明的关系

| 证明 | 依据 | 给出 |
|---|---|---|
| §3（本条） | 正弦定理 + `sin φ ≤ 1` | 最优的**构型刻画**（φ=90°, 外接圆为 Thales 圆） |
| 统筹文档 §2 | E 关于 Δ² 单调 | 最优的**位置坐标**（a = d₁） |

两者互为补充：前者说明"最优长什么样"，后者给出"最优在哪里"。

## 4. 命题 III：准则无关最优性（谱判据）

> 完整推导见 [[Q1Q2统筹-几何创新.md]] §2。此处只列需要写进论文的**完整陈述与证明**。

### 4.1 Fisher 信息矩阵

方位观测 θᵢ = atan2(G_y − S_iy, G_x − S_ix) 对源位置的梯度为

```
Jᵢ = ∂θᵢ/∂G = (1/dᵢ) · n̂ᵢ^⊥          （n̂ᵢ^⊥ = 垂直于视线的单位向量）
```

故 Fisher 信息矩阵 `M = (1/σ²) Σᵢ JᵢᵀJᵢ`。在归约坐标（S₁ 为原点、θ₁ 中线为 +x 轴、G = (d₁,0)、S₂ = (a,b)）下

```
J₁ = (0, 1/d₁),        J₂ = (b, Δ)/d₂²,        Δ = d₁ − a,  d₂ = √(Δ²+b²)
```

得

```
M = (1/σ²) · [ [ b²/d₂⁴ ,  bΔ/d₂⁴ ],
               [ bΔ/d₂⁴ ,  1/d₁² + Δ²/d₂⁴ ] ]
```

### 4.2 两个闭式不变量

```
det M        = b² / (σ⁴ d₁² d₂⁴)  =  sin²φ / (σ⁴ d₁² d₂²)
trace(M⁻¹)   = d₂² (d₁² + d₂²) / b²  · σ²
```

**⇒ E = ε·√(trace(M⁻¹))**（令 σ = ε），即 E 是 **1σ 位置的均方根误差**，亦即 **A-最优实验设计准则**。

**推导校验**：`E² = ε²(d₁²+d₂²)d₂²/b²` 与 `trace(M⁻¹)` 的表达式一致 ✓（本会话已数值验证）。

### 4.3 命题 III（准则无关最优性）

**陈述**：设 S₁、G 固定。则任意只依赖 M 的**谱**（特征值）的准则——A-最优（min trace M⁻¹）、D-最优（max det M）、E-最优（min λ_max(M⁻¹)）——其最优第二点均在 **a = d₁**。

**证明**：考察 M 的元素。Δ 只以两种形式进入：`Δ²`（对角元），以及 `Δ·|b|·sign(Δ)`（非对角元）。后者对应坐标轴的反射变换（在 (u,v) 基下改变 v 的定向），**不改变 M 的特征值**。故 M 的谱只依赖 **Δ²**。

- `trace(M⁻¹) = d₂²(d₁²+d₂²)/b²` 中 `d₂² = Δ²+b²` ⇒ 关于 Δ² 单调增 ⇒ 极小在 Δ = 0；
- `det M = b²/(σ⁴d₁²d₂⁴)` ⇒ 关于 Δ² 单调减 ⇒ 极大在 Δ = 0；
- E-最优由对称性同理。∎

**意义**：把"正侧方最优"从"本文选了一个合适的目标函数"提升为"**由几何结构本身决定**"。

## 5. 命题 IV：有界性定理（回收锥）

### 5.1 回收锥的两个引理

**定义**：凸集 C 的**回收锥** `recess(C) = { d ∈ ℝ² : C + td ⊆ C, ∀t ≥ 0 }`。

**引理 IV.1** 设 `C₁,…,Cₙ` 为闭凸集且 `⋂Cᵢ ≠ ∅`，则

```
recess( ⋂ᵢ Cᵢ ) = ⋂ᵢ recess(Cᵢ)
```

**证明**：
(⊆) 设 `d ∈ recess(⋂Cᵢ)`。取 `x ∈ ⋂Cᵢ`，则 ∀t≥0，`x + td ∈ ⋂Cᵢ ⊆ Cᵢ` ⇒ `d ∈ recess(Cᵢ) ∀i`。
(⊇) 设 `d ∈ ⋂ᵢ recess(Cᵢ)`。取 `x ∈ ⋂Cᵢ`，则 ∀i、∀t≥0，`x + td ∈ Cᵢ` ⇒ `x + td ∈ ⋂Cᵢ` ⇒ `d ∈ recess(⋂Cᵢ)`。∎

**引理 IV.2** 非空闭凸集 C 有界 **⟺** `recess(C) = {0}`。

**证明**：
(⇒) 若 `0 ≠ d ∈ recess(C)`，取 `x ∈ C`，则 `‖x + td‖ → ∞`（t→∞），C 无界，矛盾。
(⟸) 若 C 无界，取 `x₀ ∈ C` 与点列 `xₙ ∈ C` 使 `‖xₙ − x₀‖ → ∞`。令 `eₙ = (xₙ − x₀)/‖xₙ − x₀‖`，由单位圆紧性取子列 `eₙ → e`（‖e‖ = 1）。对任意固定的 t ≥ 0，当 n 充分大时 `t/‖xₙ−x₀‖ ≤ 1`，由凸性
```
x₀ + t·eₙ = (1 − t/‖xₙ−x₀‖)·x₀ + (t/‖xₙ−x₀‖)·xₙ ∈ C
```
令 n → ∞ 并由 C 闭得 `x₀ + t·e ∈ C`。对一切 t ≥ 0 成立 ⇒ `e ∈ recess(C)`，且 `e ≠ 0`。∎

### 5.2 命题 IV（有界性判据）

**陈述**：设 `Wᵢ = W(Sᵢ, θᵢ, ε)` 为角域，`L = ⋂ᵢ Wᵢ`。则

```
L 有界   ⟺   ⋂ᵢ [θᵢ − ε, θᵢ + ε] = ∅        （方向区间之交为空）
```

**证明**：角域 `W(S,θ,ε) = S + K(θ,ε)`，其中 `K(θ,ε)` 是以原点为顶点、张角 2ε 的闭凸锥。锥的回收锥是自身，故 `recess(Wᵢ) = Kᵢ`。

由引理 IV.1（需 `L ≠ ∅`；若 `L = ∅` 则另有约定，且空集按定义有界）：`recess(L) = ⋂ᵢ Kᵢ`。

由引理 IV.2：`L 有界 ⟺ ⋂ᵢ Kᵢ = {0} ⟺ 各锥无公共方向 ⟺ ⋂ᵢ [θᵢ−ε, θᵢ+ε] = ∅`。∎

**推论 IV.1**：n = 2 时 `L` 无界 ⟺ `|θ₁ − θ₂| < 2ε = 2°`。

**推论 IV.2**：n 站时只要有公共方向即无界 ⇒ **所有检测点朝同一方向观测时不可定位**（对应"源极远、诸视线近乎平行"）。

## 6. 命题 V：配极对偶下的 Jung 定理

### 6.1 配极基本事实

对含原点为内点的闭凸集 C，定义**极集** `C° = { y : ⟨x,y⟩ ≤ 1, ∀x ∈ C }`。则（标准结果）：

```
(⋂ᵢ Cᵢ)° = conv( ⋃ᵢ Cᵢ° )                    （交 ⟷ 包）
C ⊆ D          ⟹   D° ⊆ C°                     （包含反转）
( B(0,R) )° = B(0, 1/R)
```

### 6.2 命题 V（半径–内切半径对偶）

**陈述**：设 L 为含原点的紧凸集，`R₀(L) = max{‖x‖ : x ∈ L}`（以原点为中心的最小包围圆半径），`inr(·)` 为内切圆半径。则

```
R₀(L) = 1 / inr( L° )
```

**证明**：`inr(L°) = max{ r : B(0,r) ⊆ L° }`。由包含反转，
```
B(0,r) ⊆ L°   ⟺   (L°)° ⊆ (B(0,r))°   ⟺   L ⊆ B(0, 1/r)
```
（用到双极定理 `(L°)° = L`，对含原点的闭凸集成立）。故
```
inr(L°) = max{ r : L ⊆ B(0,1/r) } = 1 / min{ R : L ⊆ B(0,R) } = 1 / R₀(L)
```
∎

### 6.3 推论：Jung 定理的对偶形式

取 L 的最小包围圆圆心为原点，则 `R₀(L) = R_MEC`。Jung 定理 `R_MEC ≤ D/√3`（D = 直径）对偶为

```
inr( L° )  ≥  √3 / D
```

**等号条件**：L 为**等边三角形**（Jung 上界取等）。

**验证（等边三角形）** ✅：取 L 为外接圆半径 1 的等边三角形（边长即直径 `D = √3`，内切圆半径 1/2）。其半平面表示为 `{x : ⟨û_k, x⟩ ≤ 1/2}`（û_k 为单位外法向），故

```
L° = conv{ 2û₁, 2û₂, 2û₃ }    （外接圆半径 2、内切圆半径 2·cos60° = 1 的等边三角形）
inr(L°) = 1 = √3/√3 = √3/D     ✓ 取等
```

**验证（Q1 基准算例）** ✅：该筝形的 `R_MEC = 19.799`、`D = 39.598`、`√3/D = 0.04374`。将区域平移使最小包围圆圆心为原点后，其极集的最紧半平面距离为 `1/19.799 = 0.05051` ⇒ `inr(L°) = 0.05051 ≥ 0.04374` ✓ 成立（本例 `R_MEC = D/2` 取下界，故取严格不等号）。

**自洽检验**：把直径圆半径 `D/2` 代入对偶即得"对偶内切半径 `2/D`"；而 Jung 界给出 `√3/D`。二者之比 `(2/D)/(√3/D) = 2/√3 ≈ 1.1547` —— **与主推导给出的最坏缺口完全一致** ✓。对偶视角与主视角互相印证。

## 7. 命题 VI：组合型是仿射不变量

### 7.1 陈述

**命题 VI**：设 A 为可逆仿射变换。则 `L` 与 `A(L)` 的**顶点数相同**，且"哪两条边界射线产生哪个顶点"的对应关系相同。

**证明**：
1. 仿射变换保持直线与凸性，故把凸多边形映为凸多边形，顶点映为顶点；
2. 角域 `Wᵢ = Sᵢ + Kᵢ`（Kᵢ 为锥），`A(Wᵢ) = A(Sᵢ) + A(Kᵢ)`（A 线性部分把锥映为锥）；
3. 仿射变换与交可交换：`A(⋂Wᵢ) = ⋂A(Wᵢ)`；
4. 故 `L` 的每个顶点（= 某两条边界射线的交且在 L 内）在 A 下仍对应相同的一对边界射线，且仍在 `A(L)` 内。∎

**更精确的语言**：`L` 的组合型由 `2n` 条边界射线的**有序拟阵（oriented matroid）**决定，而有序拟阵在可逆线性变换下不变。

### 7.2 推论

**推论 VI.1**：Q1 的答案分两部分——**组合部分**（顶点数、顶点与约束对的对应）是仿射不变量；**度量部分**（D、R_MEC、面积）依赖具体角度与距离。

**推论 VI.2（n = 2 的完全分类）**：由命题 IV 与上述，
| 条件 | L 的形状 | 顶点数 |
|---|---|---|
| 方向区间相交 | 无界 | 直径未定义 |
| 区间不相交 + 一般位置 | 凸四边形 | 4 |
| 区间不相交 + 一个交点落在其余角域外 | 凸三角形 | 3 |
| 交集为空 | ∅ | 0 |

**Q1 基准算例验证** ✅：方向区间 [58.036°, 60.036°] ∩ [119.964°, 121.964°] = ∅（有界 ✓），实测恰 4 个顶点 ✓。
