## 0. 结论先行

**能创新，但创新的位置和直觉相反。**

| 路线 | 判定 | 一句话 |
|---|---|---|
| 射影几何（变换） | ❌ | 射影不保角度，而本题**全部信息就是角度** ⇒ 不能施加射影变换 |

## 1. 概念澄清：修正 Q1/Q2 文档里"射影不适用"的准确含义

Q1/Q2 文档写的是"**射影变换不适用**"。这句话对，但**不等于"射影几何无用"**。必须分清三件事：

| 用法 | 是否可用 | 理由 |
|---|---|---|
| 对问题**施加**射影变换 | ❌ | 射影不保角度/距离/圆/垂直；本题的输入（±1°）、目标（1/sinφ）、结论（圆覆盖）全部被破坏 |
| 用射影**对偶**做化归 | ✅ | 点线对偶、配极对偶都是**结构工具**，不需要变换整个问题 |
| 用**圆锥曲线**理论 | ✅ | 圆是圆锥曲线；Thales/Jung 是圆锥几何定理，天然属于射影框架 |

**一句话**：射影几何给的是**结构（关联、对偶、圆锥）**，不是**变换**。用它做结构，不用它做变换。

## 2. 创新 A（信息几何）：Fisher 信息矩阵统一 Q1+Q2 — 建议**必写** ✅

### A.1 关键发现：Q2 的 E 不是启发式，它精确等于 RMS 位置误差

**推导**（两站方位定位）。设站 i 的观测为方位角 θᵢ，源位置 p，σ 为角误差标准差（本题取 ε）。

```
∂θᵢ/∂p = (1/dᵢ)·n̂ᵢ^⊥        （n̂ᵢ^⊥ = 垂直于视线的单位向量）
Jᵢ = ∂θᵢ/∂p                  （2 维行向量）
Fisher 信息矩阵：M = (1/σ²)·Σᵢ JᵢᵀJᵢ
```

取 S₁ 为原点、源 G=(d₁,0)、第二点 S₂=(a,b)，记 Δ = d₁−a、d₂=√(Δ²+b²)：

```
J₁ = (0, 1/d₁),          J₂ = (b, Δ)/d₂²
M  = (1/σ²)·[[ b²/d₂⁴ ,  bΔ/d₂⁴ ],
             [ bΔ/d₂⁴ ,  1/d₁² + Δ²/d₂⁴ ]]
```

两个**闭式不变量**：

| 量 | 闭式 | 意义 |
|---|---|---|
| `det M` | `b² / (σ⁴ d₁² d₂⁴)` = `sin²φ / (σ⁴ d₁² d₂²)` | D-最优性（信息体积） |
| `trace(M⁻¹)` | `d₂²(d₁² + d₂²) / b²` ·σ² | A-最优性（方差和） |

于是：

```
E = ε·√(d₁²+d₂²)/sinφ          （Q2 文档里的"解析代理"）
E² = ε²·(d₁²+d₂²)·d₂²/b²
   = ε²·trace(M⁻¹)/σ²
```

**⇒ E = ε·√(trace(M⁻¹))，即"1σ 位置的 RMS 误差"。** ✅ 数值验证（d₁=583.1、|b|=514.5）：E 与 `ε√(trace M⁻¹)` 完全一致。

**意义**：Q2 的目标函数**从"看起来像启发式的小角近似"升级为"严格的信息论量"**。论文里可以写"本文以 A-最优设计准则（最小化 Fisher 信息矩阵逆的迹，即 RMS 位置误差）为目标"，一句话接上实验设计传统（Fedorov；GDOP；CRLB——见 `01_背景研究/背景全量研究报告.md` §4.2 [4]）。

### A.2 创新核心：**准则无关最优性定理** ✅

**定理**：设 S₁、G 固定，|b| 固定。则对**任何只依赖 M 的谱（特征值）判据**——A-最优（min trace M⁻¹）、D-最优（max det M）、E-最优（min λ_max(M⁻¹)）——最优第二点都在 **Δ = 0（即 a = d₁）** 取到。

**证明**：在 S₁ 为原点、G=(d₁,0) 的坐标下，M 的四个元素只通过 `Δ²`、`b²`、`Δ·|b|·sign(Δ)` 依赖 Δ。其中 `Δ·|b|` 项只出现在非对角元，其符号变化等效于**坐标轴反射**，**不改变 M 的特征值**。故 M 的谱只依赖 **Δ²**。

- `trace(M⁻¹) = d₂²(d₁²+d₂²)/b²`，其中 `d₂² = Δ²+b²` ⇒ 关于 Δ² 单调增 ⇒ 极小在 **Δ=0** ✅
- `det M = b²/(σ⁴d₁²d₂⁴)` ⇒ 关于 Δ² 单调减 ⇒ 极大在 **Δ=0** ✅
- E-最优同理（对称性）∎

**意义**：Q2 文档里只证了"对 E 最优"。现在结论**升级**为：**"正侧方"最优与设计准则无关**——这不是我们挑了个好目标函数的结果，而是几何本身决定的。**这是 Q2 最强的一条定理**，值得单独成节。

**数值验证** ✅（固定 |b|=514.5）：

| Δ | −300 | −150 | **0** | +150 | +300 |
|---|---|---|---|---|---|
| A-最优 `(d₁²+d₂²)d₂²/b²` | 930915 | 680528 | **604716** | 680528 | 930915 |
| D-最优 `1/det M ∝ d₁²d₂⁴/b²` | 1.616e11 | — | **9.000e10** | — | 1.616e11 |

两准则同点取极小，且关于 Δ=0 对称 ✅

### A.3 Q1 与 Q2 的**伴随性**（统一叙事）

```
同一个 Jacobian J = [J₁; J₂]，同一个信息矩阵 M = JᵀJ/σ²

Q1（正问题）：给定测点 → M 已知 → 把观测噪声映射成位置区域 L（或误差椭圆）
Q2（反问题）：给定源   → 选测点使 M 良态（max det M 或 min trace M⁻¹）
```

**这是"定位"与"布点"的伴随对偶**：Q1 是 M 的**前推**，Q2 是 M 的**后拉**。论文可以这样写：

> "问题 1 与问题 2 在数学上共享同一个 Fisher 信息矩阵 M = JᵀJ：前者用 M 把角度观测的不确定性映射为位置的不确定性区域，后者用 M 评价候选测点的信息质量。二者构成一对伴随问题。"

**交叉验证副产物** ✅：把 Q1 基准算例的 S₂ 代入 Q2 的准则，得 Δ = 274.4 ≠ 0 ⇒ **Q1 里那个 S₂ 在 Q2 意义下是非最优的**；固定 |b| 移到 Δ=0，E 从 **16.31 m → 13.57 m（−17%）**。**两个问题互相验证，且给出可量化改进**——这是全篇最漂亮的跨问结果。

### A.4 E 与 D 的关系（诚实说明）

| 量 | 定义 | 性质 |
|---|---|---|
| E | ε√(trace M⁻¹) | RMS 误差，闭式，**线性化** |
| D | 定位区域直径 | 最坏情况，**精确非线性** |

Q1 基准算例（φ=61.92°）：E = 16.31 m，D = 39.598 m ⇒ **D/E ≈ 2.43**。
**这不是常数**——D 刻画"最坏两点距离"，E 刻画"RMS"。两者**不可互换**，论文应同时报告并说明语义差别（这本身就是严谨性的体现）。

## 3. 创新 B（射影·圆锥曲线）：Thales → 圆锥，各向异性推广 ✅

### B.1 观察：Q1 与 Q2 的核心定理都是"圆锥关联定理"

| 问题 | 定理 | 圆锥表述 |
|---|---|---|
| Q1 覆盖 | Thales 逆：∠PXQ ≥ 90° ⟺ X 在圆内 | X 在**圆**（圆锥）内 |
| Q2 最优 | ∠S₁GS₂ = 90° | G 在**以 S₁S₂ 为直径的圆**（圆锥）上 |

两者都是"**点与圆锥的位置关系**"。射影几何的基本事实：**圆是圆锥曲线的一般位置，一切圆定理都是圆锥定理**（内接角定理、极线、幂、根轴、Miquel、Pascal）。

**⇒ 统一命题**：Q1 与 Q2 的核心结论可以合并陈述为——

> "**两者都归结为：某个特定点（源 / 待覆盖点）是否落在某个圆锥曲线（圆）的指定一侧。**"

### B.2 真推广：各向异性 → 椭圆

若把"圆"换成**椭圆**（即把 Euclidean 范数换成加权范数），整套理论的形式不变，只需换"直径圆"为"直径椭圆"：

| 原（各向同性） | 推广（各向异性） |
|---|---|
| 半径 R 的清除圆 | 椭圆清除域 |
| 圆的直径圆 | 椭圆的共轭直径矩形 |
| Thales：∠PXQ ≥ 90° | 共轭极线判据（polarity w.r.t. 椭圆） |
| Jung：`R_MEC ≤ D/√3` | **⚠️ Jung 常数变为 1/2 ≤ J ≤ 1/√3 之间**（一般范数下非常数） |

**现实意义**：若机器狗的光学/激光清除精度是各向异性的（横向≠纵向），或测向误差在不同方位不等，这套推广直接可用。

**⚠️ 诚实边界**：**一般范数下 Jung 常数不再是 1/√3**，需要重推。**不建议在本届竞赛正文深入**，只作为"模型推广"一节的展望。

## 4. 创新 C（射影·点线对偶）：Q1 ⟶ 线横截问题 ✅

### C.1 对偶化归（这是真正的射影应用）

**点线对偶**：点 p=(p₁,p₂) ↔ 直线 p*: y = p₁x − p₂（保持关联关系）。

对 Q1：源 G 在楔形 Wᵢ 内 ⟺ **直线 ℓᵢ = line(Sᵢ, G) 的方向落在 [θᵢ−ε, θᵢ+ε] 内**。

对偶后：
- 直线 ℓᵢ = line(Sᵢ,G) ↔ 点 `Sᵢ* ∩ G*`（两对偶直线的交点）
- "方向落在区间内" ⟺ 该点在**对偶平面的一条线段 Dᵢ 上**（Dᵢ = 对偶直线 Sᵢ* 上斜率介于 tan(θᵢ±ε) 的那一段）

**得到**：

> **Q1 的定位区域 L ⟺ 对偶平面中，所有与 n 条线段 D₁…Dₙ 都相交的直线 G\* 的集合。**

这是经典的 **line transversal（直线横截）问题**。✅

### C.2 接上 Hadwiger 横截定理（Helly 型）

**Hadwiger 横截定理**：平面上互不相交的紧凸集族存在直线横截 ⟺ 存在一个线性序，使得**任意三个**都有一条与该序一致的横截直线。

**这是 Helly 型定理**——判定存在性只需检验**三元组**。用于 Q1：
```
L ≠ ∅ 的快速判定 ⟺ 任意 3 条对偶线段存在一致的直线横截
```

### C.3 价值与诚实的成本

| 项 | 评价 |
|---|---|
| 理论价值 | ✅ 把 Q1 从"半平面交"重新表述为"直线横截"，接上横截几何（Hadwiger/Santá）这一支文献 |
| 算法价值 | ⚠️ **不优于**直接半平面交（O(n log n)）；对偶算法更绕 |
| 论文定位 | **写进"方法对比/理论视角"一节**，作为"同一问题的第二种几何表述"；**不要作为主算法** |

## 5. 创新 D（射影·配极对偶）：Jung 定理的对偶形式 ✅

### D.1 配极对偶把"交"变成"包"

对含原点的凸集 C，定义极集 `C° = { y : ⟨x,y⟩ ≤ 1 ∀x ∈ C }`。基本定理：

```
(⋂ᵢ Cᵢ)° = conv(⋃ᵢ Cᵢ°)
```

**⇒ Q1 的定位区域（2n 个半平面之交）对偶为"2n 个点的凸包"**（对半平面情形，Cᵢ° 退化为点）。

### D.2 覆盖问题的对偶形式

对含原点的 L：

```
L ⊆ B(0,R)   ⟺   L° ⊇ B(0, 1/R)
（包含关系在配极下反转，且 B(0,R)° = B(0,1/R)）
```

**⇒ Q1 的"直径圆能否覆盖"对偶化为"对偶多边形 L° 的内切圆够不够大"。**

### D.3 Jung 的对偶形式与自洽检验 ✅

`R_MEC(L) = 1 / inr(L°)`（含原点的凸集），Jung `R_MEC ≤ D/√3` 对偶为：

```
inr(L°)  ≥  √3 / D           ——「对偶 Jung 不等式」
```

**等边三角形检验**（L = 外接圆半径 1 的等边三角形，D = √3）：
- L° = 另一个等边三角形，`inr(L°) = 1`（计算：外接圆半径 2，内切圆半径 2·cos60° = 1）✅
- `√3/D = √3/√3 = 1` ✅ **取等成立**

**⇒ 对偶给出同样的 15.5% 缺口**（2/√3），两套推导自洽 —— 这是一个很好的**交叉检验**。

**论文定位**：写进"理论的另一视角"，展示"同一个覆盖问题有配极对偶的读法"，且该读法与主推导一致。**不必作为主推导**。

## 6. 创新 E（仿射·不变量）：有界性判据 + 组合型分类 — 建议**必写** ✅✅

### E.1 尖锐判据：定位区域有界 ⟺ 方向区间不相交

**定理**：设 Wᵢ 为 Sᵢ 处方向区间 `[θᵢ−ε, θᵢ+ε]` 的角域（射线族）。则

```
L = ⋂ᵢ Wᵢ 有界   ⟺   ⋂ᵢ [θᵢ−ε, θᵢ+ε] = ∅      （方向区间交为空）
```

**证明**：凸集 W 的**回收锥** `recess(W) = { d : W + td ⊆ W ∀t≥0 }` 就是 W 的角域本身（平移到原点）。有
```
recess(⋂ Wᵢ) = ⋂ recess(Wᵢ)
```
`L` 有界 ⟺ `recess(L) = {0}` ⟺ 各角域无公共方向 ⟺ 方向区间交为空。∎

**推论**：
- **n=2 时**：`L` 无界 ⟺ `|θ₁ − θ₂| < 2ε = 2°`（两站"几乎朝同一方向看"）。物理上即**源极远、两视线近乎平行**。
- **n 站时**：只要有一个方向被所有角域共享，就无界 ⇒ **所有检测点朝同一方向观测时不可定位**。

**✅ 这比 Q1 文档现有的"近平行 ⇒ 无界"（G2）精确得多**——把模糊的"近平行"变成了一个**可计算、可验证的充要条件**。**建议直接替换 Q1 文档的 G2。**

### E.2 n=2 的组合型完全分类 ✅

由 E.1 与顶点枚举引理：

| 条件 | L 的形状 | 顶点数 |
|---|---|---|
| 方向区间相交 | **无界**（条带/扇形） | 直径未定义 |
| 区间不相交 + 交集非空（一般位置） | **四边形**（凸） | 4 |
| 区间不相交 + 一个边界射线交点落在其余角域外 | **三角形**（凸，退化） | 3 |
| 交集为空 | **空集**（数据不自洽） | 0 |
| 边界射线恰好过另一角域顶点 | 退化（顶点重合并） | 2/3 |

**Q1 基准算例**：区间 [58.036°, 60.036°] ∩ [119.964°, 121.964°] = ∅ ⇒ 有界 ✅，且输出恰为 4 个顶点 ✅ 与实算一致。

**⇒ 给出 n=2 的"类型图"**：在 (θ₁,θ₂) 平面（固定 S₁、S₂、ε）上画出四条分区边界。**这是一张漂亮且信息量高的论文图**，且**直接回答了"什么时候 Q1 的直径有定义"**。

### E.3 仿射不变量视角：oriented matroid

`L` 的**组合型**（顶点数、以及"哪个角域对产生哪个顶点"）只依赖 `2n` 条边界直线的**排列组合结构**，即它们的 **oriented matroid**（有向拟阵）。有向拟阵是**仿射不变量**（在仿射变换下不变）。

**⇒ 命题**：Q1 的答案的**组合部分**是仿射不变量；只有**度量部分**（D、R_MEC）依赖具体的角度与距离。

**价值**：给出"实例分类"的理论语言；并把"退化情形"定义为**非单纯（non-uniform）有向拟阵**——这是一个干净的退化理论。

**⚠️ 诚实**：这条偏理论，**建议只写一句**放进"模型讨论"，不展开。

## 7. 创新 F（共形/Möbius）：为什么本题的答案总是"圆" ⚠️

**观察**：Q1 的覆盖判据（Thales）、Q1 的正解（最小包围圆）、Q2 的最优条件（Thales）——**三处结论都落在"圆"上**。

**解释（框架性）**：本题的输入是**纯角度**数据，而**保角的变换群是 Möbius（反演）群**，不是射影群也不是仿射群。Möbius 变换保持**圆与直线**（直线 = 过 ∞ 的圆）并保持角度。因此**以角度为输入的问题，其"自然几何"是反演几何，其不变量落在圆上**。

**⚠️ 诚实的限制**：
1. 角域的**直边**在反演下变成圆 ⇒ 角域**不被 Möbius 群保持** ⇒ **不能**直接用 Möbius 变换做化归；
2. 因此这条是**解释性框架**（说明"为什么是圆"），**不是可用的化归工具**。

**建议**：写成"几何定位"一节的**一段话**，展示对问题几何性质的自觉。**不要深入**。

## 9. Helly 数的三重奏（一个漂亮的统一观察）

平面上"3"这个数字在本问题中出现**三次**，且**根源相同**（都是 `d+1 = 3`）：

| 出现处 | 陈述 | 依据 |
|---|---|---|
| **L ≠ ∅ 的判定** | 任意 3 个角域相交 ⇒ 全体相交 | **Helly 定理**（R² 的 Helly 数 = 3） |
| **最小包围圆的决定** | MEC 由 ≤3 个边界点决定 | **LP-type 组合维数 = 3** |
| **Jung 上界取等** | 等边三角形（3 点）取等 | 三点配置达到极值 |

**⇒ 论文可以点一句**："本问题的三个关键结构（可行性、最小包围圆、Jung 等号）都由**平面 Helly 数 3** 支配。" 这是一个**优雅的跨结论统一**，成本极低。

## 12. 一句话总结

**Q1 与 Q2 的创新不在"换一种几何变换"，而在三处结构**：
1. **信息几何**——Q1 与 Q2 共享同一个 Fisher 信息矩阵，是**伴随对偶**；由此 E 获得严格身份，且"正侧方最优"升级为**准则无关定理**；
2. **射影的"结构用法"而非"变换用法"**——圆锥曲线统一两个 Thales 结论、点线对偶化归为线横截、配极对偶给出 Jung 的对偶形式；
3. **仿射不变量**——把"定位区域有界"从模糊的"近平行"变成充要判据，并给出 n=2 的完全分类。

**射影变换与非欧几何确定不适用**（不保角度），但**射影的关联/对偶/圆锥结构是本题最富矿的几何资源**。
