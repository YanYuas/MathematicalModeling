### 1.1 复核中找到的**理论解释**（本轮新增，是最大收获）

**定理（中心对称 ⇒ γ≡1）**：设 K 为中心对称紧凸集，c 为对称中心。由最小包围圆的唯一性，MEC 圆心必为 c，
故 `R_MEC = max‖x−c‖`；又对径点 `2c−x ∈ K` 给出 `D = 2max‖x−c‖`。故 **γ = R_MEC/(D/2) ≡ 1**。∎

**数值验证**：正方形 / 一般平行四边形 / 中心对称六边形 均给出 γ = **1.000000**；等边三角形给出 1.154692 ✓

**结构洞察**：L 的两条**对边**落在**同一顶点**的两条边界射线上，而这两条射线**夹角恰为 2ε**。
⇒ **L 的两组对边各偏离平行 ≤ 2°** ⇒ **L 是"2ε-近平行四边形"** ⇒ 它是中心对称形状的 **O(ε) 扰动**
⇒ **γ = 1 + O(ε)**。

**ε 依赖实测**：`γ−1` 从 ε=0.05° 的 1×10⁻⁶ 单调增到 ε=4° 的 3.4×10⁻²，**ε→0 时 γ→1** ✓ 与 O(ε) 一致。

**⇒ 等边三角形（需 3 个 60° 角）与"两组各差 2° 的对边"在结构上不相容。**

（重建检测点数组时丢弃了先前扰动 ⇒ "接受的状态" ≠ "评估的状态"）。**该数值作废。**
同构型独立复算 `mec_bruteforce = welzl = 独立暴力 = 0.407211` 三者一致，确认 MEC 实现无误。
