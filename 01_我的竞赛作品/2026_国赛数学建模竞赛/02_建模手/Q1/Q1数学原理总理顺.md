## 一、第一性原理：问题到底是什么

### 1.1 从题设到数学对象

题设三个关键词决定了问题形态：

- **"示向度"** → 这是**角度观测**，不是位置观测。测向机只给方向，不给距离 ⇒ 单站的约束是"源在这条射线上（某处）"。
- **"误差在 [−1°,1°] 范围内"** → 约束不是射线而是**角域**，且是**有界区间**而非概率分布 ⇒ 定位区域是**确定性集合**。
- **"定位区域直径"** → 需要一个"区域有多不确定"的标量度量；直径是最粗也是最自然的（最大可能误差）。

数学对象：`L = ⋂ᵢ W(Sᵢ, θᵢ, 1°)`，求 `D = max‖p−q‖`，并回答 `D` 圆是否覆盖 `L`。

### 1.2 为什么"角度误差"必须被认真对待（两个数量级）

| 场景 | 1° 的横向偏移 |
|---|---|
| 源距 1000 m | 17.455 m |
| 源距 1500 m | 26.183 m |
| 源距 1800 m | 31.419 m |

（单位：`d·tan(1°)`，本次 CAS 实测）

**含义**：1° 听起来微不足道，但在本题的公里级尺度上放大成 17–31 m。**Q1 的全部内容，就是研究这个放大量在两条（或多条）方位线之间如何合成。** 这也是为什么 Q1 不是"小儿科"——它的数值尺度直接决定了 Q3 能否直接清除。

### 1.3 为什么问题退化为纯几何（而非统计）

| 误差模型 | 定位区域形态 | 求解难度 |
|---|---|---|
| 高斯随机误差 | 置信椭圆（统计） | 需要概率模型、置信水平 |
| **有界区间误差（题设）** | **凸多边形（确定）** | **多项式可解，精确** |
| 无误差 ε=0 | 单点 | 平凡 |

题设写的是"误差在 [−1°, 1°] **范围内**"——这是**区间**，不是分布。因此：
- **不需要**假设误差分布、**不需要**置信水平；
- 区域是"所有可能位置的集合"，**精确可算**；
- 论文里若引入概率模型 = 自己给题目加条件（评分风险）。

**点透**：这个模型选择是 Q1 的第一个（也是最重要的）建模决策，且题设已经把答案给你了——照抄"有界"二字即可。

## 二、核心数学原理（逐条展开）

### 2.1 角域的凸性（地基）

```
W(S, θ, ε) = { S + t·u(φ) : t ≥ 0, |angdiff(φ, θ)| ≤ ε }
```

**等价形式（关键）**：记 `u₋ = u(θ−ε)`、`u₊ = u(θ+ε)`：

```
W = { X : cross(u₋, X−S) ≥ 0 }  ∩  { X : cross(u₊, X−S) ≤ 0 }
```

**证明等价**：两式分别表示"X−S 在 u₋ 的逆时针侧"与"X−S 在 u₊ 的顺时针侧"。两者同时成立 ⟺ X−S 的方向介于 u₋ 与 u₊ 之间（逆时针张开 2ε）⟺ X−S 与 u(θ) 的夹角 ≤ ε。∎

**为什么至关重要**：角域 = **两个过 S 的闭半平面之交**。半平面是凸集，凸集之交凸 ⇒ **Wᵢ 凸**。有限个凸集之交仍凸 ⇒ **L 凸**。

**反事实**：若误差描述为"概率密度"，则区域成为水平集，一般非凸，直径问题立刻从 P 变难。**凸性是全题多项式可解的唯一原因。**

### 2.2 顶点枚举引理（实现的地基）

**引理**：L 的每个顶点必是某两条角域边界射线 `rᵢ^a`、`rⱼ^b` 的交点。

**证明**：L 由 2n 条边界射线 `rᵢ^±`（i=1..n）围成（部分是某角域的边）。L 的边界沿着这些射线走；两条射线的相接处即顶点。∎

**致命细节（实现红线）**：引理**反向不成立**。两条射线可以相交于 L 之外。因此：

```
顶点 ⟺ 交点 P 满足：t ≥ 0（在 rᵢ^a 上）∧ s ≥ 0（在 rⱼ^b 上）∧ P ∈ Wₖ ∀ k=1..n
```

**点透**：漏掉第三个条件，候选点集会包含大量假点，凸包直接错、直径直接错。这是 Q1 最常见的实现 bug（陷阱 T2），也是"能把 Q1 做对"与"能写出 Q1 算法"的分界线。

### 2.3 凸包与直径（计算的地基）

- **凸包（Andrew 单调链，O(m log m)）**：候选点集可能含共线点/内部点，凸包输出严格顶点序列。
- **直径定理**：凸集上最远点对必为**极点对**（顶点对）。**证明直觉**：固定 p，函数 `‖p−·‖` 是凸函数，其在凸集上的最大值必在极点取到；再对最大值点 q 重复一次。∎
- **旋转卡壳（Toussaint 1983）**：利用"对踵点对随边旋转单调推进"的性质，O(m log m)（排序后 O(m)）求出所有对踵点对。

**为什么本题可以暴力**：m ≤ 2·C(n,2)·4 ≈ 2n(n−1)，n 是个位数到十几 ⇒ m ≤ 数百。**O(m²) 暴力完全可行**，且更不容易写错。

**点透**：本题的算法选择不是性能问题而是**表述问题**——论文里写"凸包 + 旋转卡壳，并以 O(m²) 暴力交叉验证"，既专业又可自证正确。

### 2.4 ε 单调性（最坏情况分析的地基）

**引理**：ε₁ ≤ ε₂ ⇒ Wᵢ(ε₁) ⊆ Wᵢ(ε₂) ⇒ L(ε₁) ⊆ L(ε₂) ⇒ **D(ε₁) ≤ D(ε₂)**。

**作用**：
1. 题设 ε ≤ 1° ⇒ **最坏情况在 ε = 1° 取到**，Q2 的鲁棒设计可以合法地"按 1° 设计"；
2. 提供了 D 关于 ε 的单调性，实验设计中 ε 扫描的预期趋势可直接写出（线性量级）；
3. 是"加站只会更好"结论的理论支撑（同理由角域单调性给出）。

## 三、覆盖问题的完整逻辑链（本问最大考点）

### 3.1 为什么直觉会错

直觉："直径是区域内最长距离，那以它为直径的圆当然装得下整个区域。"
**错在哪**：直径只约束了"任意两点距离 ≤ D"，而圆覆盖约束的是"所有点到**某个固定圆心**的距离 ≤ D/2"。前者是**两两约束**，后者是**一点约束**——后者严格更强。

**类比**：一根长 L 的杆子能放进直径 L 的圆（杆是线段），但一个边长为 L 的等边三角形放不进（角太"尖"，撑出去了）。

### 3.2 反例：等边三角形（第一层回答）

取 L = 等边三角形，边长 a。则 D = a。
以任一边 AB 为直径作圆，圆心 = AB 中点，半径 a/2。
顶点 C 到该圆心距离 = 高 = (√3/2)a ≈ 0.866a ⇒ **C 在圆外** ⇒ 不覆盖。

用 Thales 更简洁：∠ACB = 60° < 90° ⇒ C 不在以 AB 为直径的圆内。

### 3.3 充要判据：Thales 逆定理（第二层回答）

```
X 在以 PQ 为直径的圆内（含边界） ⟺ ∠PXQ ≥ 90°
```

**证明**：`‖X−M‖² − (D/2)² = (X−P)·(X−Q) = ‖P−X‖‖Q−X‖cos∠PXQ`，其中 M 为 PQ 中点。
左式 ≤ 0 ⟺ X 在圆内；右式 ≤ 0 ⟺ ∠PXQ ≥ 90°。∎

**判据（可计算）**：以 D 端点为 P,Q，覆盖 L ⟺ **L 的每个顶点 X 满足 ∠PXQ ≥ 90°**（角函数在凸多边形上于顶点取极值）。

**点透**：这把"图形能否覆盖"变成"算几个角度"，可编程、可证明、可写进论文。

### 3.4 正解与定量界：最小包围圆 + Jung 定理（第三层回答）

- **正解**：应求**最小包围圆**（minimal enclosing circle），半径 R_MEC，用 Welzl 随机增量算法期望 O(n) 求得（也可 O(n³) 暴力，本题规模完全够）。
- **双侧夹逼（Jung 定理 1901）**：

```
D/2 ≤ R_MEC ≤ D/√3 ≈ 0.5774·D
```

**上界证明**：设最小包围圆圆心 O、半径 R，圆周上有 2 或 3 个支撑点。
- 2 点：必为对径点 ⇒ R = D/2 ≤ D/√3；
- 3 点：构成的最大角 α ≥ 60°，其对边 s ≤ D，由正弦定理 s = 2R sin α ≥ 2R sin60° = √3R ⇒ R ≤ D/√3。∎

**取等**：下界 ⟸ L 落在以 D 为直径的圆内（如基准算例的菱形）；上界 ⟸ L 是等边三角形。

**定量结论**：以 D 为直径的圆最坏情况下比所需的圆**小 2/√3 − 1 ≈ 15.5%**。

### 3.5 四层回答的价值排序

| 层次 | 内容 | 评分 |
|---|---|---|
| L1 | 答"不能" | 及格 |
| L2 | + 反例（等边三角形） | 良好 |
| L3 | + 充要判据（Thales）+ 正解（最小包围圆）+ 定量界（Jung） | **满分** |

**论文卖点**：这是一道**证伪题**，题面只问"能否覆盖"，但完整答案应包含"不能、为什么不能（反例）、什么时候能（判据）、正确做法是什么（最小包围圆）、差多少（Jung 界）"。四层递进 = 完整理解问题。

## 四、算法选择的合理性

### 4.1 求定位区域：半平面交 vs 射线两两求交

| 方案 | 思路 | 复杂度 | 稳健性 | 定论 |
|---|---|---|---|---|
| 射线两两求交 + 过滤 | 枚举 i<j, a,b∈{±}，求交、判 t≥0、判在所有角域内 | O(n³)（n² 交点 × n 次判定） | **高**（无浮点累积，逻辑直观） | **小规模首选** |
| 半平面交（排序增量/分治） | 2n 个半平面 → 交多边形 | O(n log n) | 中（浮点退化需小心） | **大规模首选** |

**选型逻辑**：本题 n 通常为 2–6（交会定位的实际站数），m ≤ 数百。
- **n ≤ 8 用射线求交**：三次方在 n=8 时约 500 次操作，可忽略，且代码短、不易错；**便于逐个断言**。
- **n > 8 用半平面交**：n 大时三次方开始吃紧。
- **建议**：实现两者，**互为交叉验证**（与直径双实现同理）。

### 4.2 求直径：暴力 vs 旋转卡壳

| 方案 | 复杂度 | 说明 |
|---|---|---|
| O(m²) 暴力 | O(n⁴) 量级 | 本题完全可行，**作为正确性基准** |
| 旋转卡壳 | O(m log m)（排序后 O(m)） | 论文表述更专业 |

**为什么两个都写**：m 很小 ⇒ 性能不是问题；**双实现交叉校验是免费的 bug 探测器**——两法给不同 D 必然有 bug。这在离散几何实现里极其有效。

### 4.3 求最小包围圆：Welzl vs 暴力

| 方案 | 复杂度 | 说明 |
|---|---|---|
| Welzl 随机增量 | 期望 O(n) | 理论优雅，论文卖点；需注意洗牌 |
| 暴力（枚举 2 点/3 点定圆再验证） | O(n³) / O(n⁴) | 逻辑最直观，**作为正确性基准** |

**注意**：最小包围圆由 2 个或 3 个边界点决定（**不可能是 1 个**，除非退化到单点）。暴力法的正确姿势：枚举所有点对（直径定圆）与所有三点组（外接圆定圆），取能覆盖全部点的最小者。

### 4.4 为什么不需要任何启发式

- 问题是**确定性凸几何**，P 类，可精确求解；
- 没有 NP-hard、没有组合爆炸、没有需要"近似"的地方；
- **因此绝对不要引入模拟退火/遗传算法**——那是 Q3/Q4 的工具，用在 Q1 上是"用大炮打蚊子"，且会让评阅怀疑你没识别出问题类型。

**点透**：Q1 的难度在**概念**不在**算法**。识别出"这是凸几何精确问题"本身就是建模能力。

## 六、数学链条完整性自查（每个环节都闭环）

| 环节 | 数学保证 | 断了会怎样 |
|---|---|---|
| 示向度 → 角域 | 有界不确定性的正确刻画 | 区域语义错（射线/概率） |
| 角域 = 半平面交 | 凸性 | 区域可能非凸，直径问题变难 |
| 交集凸性 | L 是凸多边形 | 最远点对不在顶点，D 算错 |
| 顶点过滤 | 候选点 ∈ L | 凸包含假点，D 错 |
| 凸包 | 严格顶点序列 | 冗余点干扰旋转卡壳 |
| 直径在极点取到 | O(m) 可求 | 只能暴力全区域采样 |
| Thales 判据 | 覆盖可判定 | 只能画图，无法证明 |
| Jung 定理 | R_MEC 双侧夹逼 | "能否覆盖"回答不了定量 |
| ε 单调性 | 最坏情况合法 | Q2 鲁棒设计无依据 |
| 双向实现 | 正确性自证 | 单实现 bug 无法发现 |

**结论**：Q1 是一个完整闭环的凸几何链条，每一环都有初等证明。**没有任何一环依赖启发式或概率假设**——这正是它相对 Q3/Q4 的价值：**提供一把精确的尺子**。
