## A. 问题的严格形式化

### A.1 记号

| 符号 | 含义 | 定义域 |
|---|---|---|
| Sᵢ | 第 i 个检测点坐标 | ℝ² |
| θᵢ | 在 Sᵢ 处测得的示向度 | [0°, 360°) |
| ε | 示向度误差半角 | 固定 1° |
| u(φ) | 单位方向向量 | (cos φ, sin φ) |
| Wᵢ | 第 i 个角域（楔形） | ℝ² 的子集 |
| L | 定位区域 | ℝ² 的子集 |
| D | 定位区域直径 | ℝ≥₀ |

### A.2 角度环绕函数（第一处实现级定义）

```
angdiff(φ, θ) = ((φ − θ + 180°) mod 360°) − 180°   ∈ (−180°, 180°]
```

**必须用这个函数**，不能直接 `φ − θ`。否则 θ=359°、φ=1° 会被算成 −358° 而非 +2°。

### A.3 角域的形式化（第二处关键定义）

```
W(S, θ, ε) = { S + t·u(φ) : t ≥ 0, |angdiff(φ, θ)| ≤ ε }
```

**等价的两半平面交形式**（这是全题最重要的化归，直接接入计算几何）：

记 `u₋ = u(θ−ε)`、`u₊ = u(θ+ε)`，则

```
W = { X : cross(u₋, X−S) ≥ 0 }  ∩  { X : cross(u₊, X−S) ≤ 0 }
其中 cross(a,b) = aₓb_y − a_ybₓ
```

**校验**：`cross(u₋, X−S) ≥ 0` 表示 X−S 在 u₋ 的逆时针侧；配合 `cross(u₊, X−S) ≤ 0` 表示 X−S 在 u₊ 的顺时针侧；两者合起来正是"介于 u₋ 与 u₊ 之间（逆时针，ε>0）"。✓

**点透**：角域 = 2 个过 S 的半平面之交 ⇒ **凸集**。这是 L 是凸多边形的**唯一原因**，也是全题多项式可解的根本。

### A.4 定位区域与两个输出

```
定位区域   L = ⋂ᵢ₌₁ⁿ Wᵢ            （凸多边形；n≥2 且方向不全平行时闭有界）
主输出     D = max{ ‖p − q‖ : p, q ∈ L }        —— 区域直径
副输出     R_MEC = min_c max_{X∈L} ‖X − c‖      —— 最小包围圆半径
覆盖判定   以 D 为直径的圆是否覆盖 L（布尔 + 理由）
```

### A.5 决策变量 / 目标 / 约束（Q1 的特殊性）

> **注意：Q1 不是优化问题。** 决策变量为"无"——L 由输入唯一确定，我们的任务是**精确计算**它，而非寻找最优。

| 项 | 内容 |
|---|---|
| 决策变量 | 无（区域由输入决定） |
| 目标（任务） | 精确算出 D；判定覆盖；给出正解 |
| 硬约束（输入侧） | 每个 X∈L 必满足全部 n 个角域约束（L 的定义式即约束） |
| 输出约束 | 顶点序列必须构成严格凸多边形；D 必须由顶点对取到 |

## B. 论文引理草稿（"模型建立"节素材）

### L1 角域凸性引理
> 每个角域 Wᵢ 是凸集（两个半平面之交）。凸集的有限交仍是凸集，故定位区域 L = ⋂Wᵢ 是凸集。
> **推论**：L 是凸多边形；L 上最远点对必在 L 的顶点处取到，故 D 可在 O(m²)（或旋转卡壳 O(m log m)）内求得，无需遍历区域内部。

### L2 顶点枚举引理
> L 的每个顶点必是某两条角域边界射线的交点。
> **证明**：L 的边界由各 Wᵢ 的边界射线片段拼成；两条边界片段的连接处就是交点，即顶点。∎
> **注意**（实现红线）：该引理的反向**不成立**——两条边界射线的交点未必属于 L。必须附加过滤条件（见 L3）。

### L3 顶点过滤判据
> 射线 `rᵢ^a = Sᵢ + t·u(θᵢ + aε)`（a∈{+,−}, t≥0）与 `rⱼ^b` 的交点 P 是 L 的顶点
> ⟺ P 满足 t≥0、s≥0，且 P ∈ Wₖ 对**所有** k=1..n 成立。

### L4 ε 单调性引理
> 固定检测点与示向度，令 L(ε) 为误差半角 ε 时的定位区域。则 ε₁ ≤ ε₂ ⇒ L(ε₁) ⊆ L(ε₂)。
> **推论**：D(ε) 关于 ε 单调不减。故题设 ε ≤ 1° ⇒ **D 的最坏值在 ε = 1° 取到**，最坏情况分析合法。

### L5 Thales 覆盖判据
> 设 P, Q 为直径端点，M = (P+Q)/2。对任意 X：
> `X 落在以 PQ 为直径的圆内（含边界） ⟺ ∠PXQ ≥ 90°`
> **证明**：`‖X−M‖² − (D/2)² = (X−P)·(X−Q) = ‖P−X‖·‖Q−X‖·cos∠PXQ`。
> 左式 ≤ 0 ⟺ X 在圆内；右式 ≤ 0 ⟺ cos∠PXQ ≤ 0 ⟺ ∠PXQ ≥ 90°。∎
> **推论（判据）**：以 PQ 为直径的圆覆盖 L ⟺ 对 L 的**每个顶点** X 有 ∠PXQ ≥ 90°（角函数在凸多边形的顶点取极值）。

### L6 Jung 定理与双侧夹逼
> **Jung 定理（1901）**：平面上直径为 D 的点集必可被半径 r ≤ D/√3 的圆覆盖。
> 结合显然下界 r ≥ D/2（圆必须容下直径两端点），得 `D/2 ≤ R_MEC ≤ D/√3`。
> **取等条件**：下界取等 ⟺ 点集落在以 D 为直径的圆内；上界取等 ⟺ 点集是**等边三角形**。

### L7 覆盖问题的完整回答（三段式）
> (a) **一般不能覆盖**：反例 = 等边三角形（以任一边为直径的圆，对角顶点处 ∠ = 60° < 90°）。
> (b) **充要判据**：L5。 (c) **正解**：改用最小包围圆，半径被 L6 夹逼，最坏缺口 2/√3 ≈ 1.1547（15.5%）。

## C. 两个核心命题的完整证明

### C.1 命题一：直径圆一般不能覆盖

**反例构造**：取 L = 等边三角形 ABC，边长 a。则 D = a（任一边都是直径对）。
取直径对 (A,B)，圆心 M = AB 中点，半径 a/2。
C 到 M 的距离 = 三角形高 = (√3/2)a ≈ 0.866a > a/2。
⇒ C 在圆外 ⇒ **不覆盖**。∎

**换用 Thales 判据**：∠ACB = 60° < 90° ⇒ C 不在以 AB 为直径的圆内。两法一致。

**最小包围圆视角**：等边三角形的最小包围圆是外接圆，半径 a/√3 ≈ 0.5774a > a/2 ⇒ 缺口比 `(a/√3)/(a/2) = 2/√3 ≈ 1.1547`。

### C.2 命题二：Jung 界 D/2 ≤ R_MEC ≤ D/√3

**下界**：最小包围圆必含直径两端点 P,Q，‖P−Q‖ = D ⇒ 半径 ≥ D/2。∎

**上界（Jung）**：设 L 的最小包围圆圆心 O、半径 R。
由最小性，圆周上存在 **2 或 3 个支撑点**使圆心落在其凸包内。

- **情形 1（2 点）**：两点必互为对径（否则可缩小圆），故 R = D/2 ≤ D/√3。✓
- **情形 2（3 点）**：设三点构成三角形，边长 s ≤ D。三点都在半径 R 的圆上且圆心在其内部 ⇒ 三角形是**锐角或直角**三角形，且其最大角 α ≥ 60°（三角和 180°）。
  由正弦定理，α 的对边 `s = 2R sin α`。
  故 `D ≥ s = 2R sin α ≥ 2R sin 60° = √3 R`  ⇒  `R ≤ D/√3`。✓ ∎

**取等**：α = 60°（等边）且 s = D ⇒ 等边三角形，边长即直径。此时三点等距分布在外接圆上，R = D/√3。

**点透**：上界的证明只用到了"最小包围圆的支撑点结构 + 正弦定理 + 角度下界"三个初等事实，**可在论文中完整给出**，是低成本高回报的理论亮点。

### C.3 Q1 与后续问的接口命题

**命题（2026-09-11 参数扫描修正版）**：设两检测点相距 L（基线），源处交会角为 φ。定位区域 L 是**菱形结构**，其两对角线为：

```
横向跨距（垂直于角平分线） = 2·ε_rad · L / sin φ        —— 精确
纵向跨距（沿角平分线）      = 另一表达式（随 φ 变化）
D = max( 横向跨距 , 纵向跨距 )
```

**⇒ 两条精确结论**：

```
(1) D ≥ 2·ε_rad·L / sin φ            （横向跨距是 D 的下界）
(2) 等号成立 ⟺ φ ≥ 90°                （此时横向跨距 ≥ 纵向跨距）
(3) D 的最小值 = 2·ε_rad·L，在 φ = 90° 取到
```

**独立核验**（直接解四边形顶点，不经扫描脚本）：

| φ | 横向跨距 | 纵向跨距 | D | 2ε_rad·L/sinφ |
|---:|---:|---:|---:|---:|
| 30° | 41.8794 | 157.0099 | **157.0099** | 41.8879 |
| 60° | 24.1791 | 41.9305 | **41.9305** | 24.1840 |
| **90°** | 20.9397 | 20.9525 | **20.9525** | 20.9440 |
| 120° | 24.1791 | 13.9655 | **24.1791** | 24.1840 |
| 150° | 41.8794 | 11.2252 | **41.8794** | 41.8879 |

**⚠️ 修正说明（原表述作废）**：本节原写 `D ≍ 2ε_rad·d_eff/sinφ`（d_eff 为源距尺度），
**该式只在 φ ≥ 90° 成立**。φ < 90° 时纵向跨距胜出，D 显著更大
（φ=20° 时 D = 350.76 m，是同 φ 下 2εL/sinφ = 61.2 m 的 5.7 倍）。
根源：小交会角对应**源远于半基线**，区域沿视线方向被拉长，横向跨距不再是直径。
**原"d_eff 为源距尺度"的说法也应改为"精确用基线 L"**（对称构型下横向跨距只依赖 L 与 φ，与源距无关）。

**推论（Q2 的种子，更正后仍成立）**：D 在 **φ = 90°** 取最小值 2ε_rad·L，且关于 φ 对称地增大；
故 **φ→90° 最优** 的结论不变。这是 Q2"第二检测点选择策略"的解析起点。

## G. 退化情形分类学（必须逐个处理）

> **定理 G0（有界性判据，2026-09-10 补充）**：设 Wᵢ 为 Sᵢ 处方向区间 `[θᵢ−ε, θᵢ+ε]` 的角域（射线族），则
> **`L = ⋂ᵢ Wᵢ` 有界 ⟺ 各方向区间之交为空：`⋂ᵢ [θᵢ−ε, θᵢ+ε] = ∅`**。
> **证明**：凸集的回收锥 `recess(W) = {d : W+td ⊆ W, ∀t≥0}` 即该角域本身（平移至原点），且 `recess(⋂Wᵢ) = ⋂recess(Wᵢ)`。`L` 有界 ⟺ `recess(L) = {0}` ⟺ 各角域无公共方向 ⟺ 方向区间交为空。∎
> **推论**：n=2 时 `L` 无界 ⟺ `|θ₁ − θ₂| < 2ε = 2°`（两站几乎朝同一方向看，对应"源极远、两视线近乎平行"）；n 站时只要有公共方向即无界。
> **价值**：把"近平行 ⇒ 无界"从模糊直觉升级为**可计算、可验证的充要条件**（详见 [[../Q1Q2统筹-几何创新.md]] §6）。

| 编号 | 情形 | 判定 | 处理口径 |
|---|---|---|---|
| G1 | n = 1 | 单条示向度 ⇒ 无界楔形 | 直径未定义；报告"无界"（或与圆域截断后报告扇形） |
| G2 | 方向区间相交（n=2 时 `\|Δθ\| < 2ε`） | **定理 G0**：存在公共方向 ⇒ 无界 | 报告"区域无界/病态"；真源数据通常不出现 |
| G3 | 空交集 L = ∅ | 数据矛盾（真源不存在于任何公共区域） | 报告"无可行定位区域"；说明输入不自洽 |
| G4 | 交集退化为一条线段 | 恰在临界 | D = 线段长；R_MEC = D/2（下界取等） |
| G5 | 交集退化为一个点 | ε→0 或强约束 | D = 0；定义为"完美定位" |
| G6 | 顶点跨 0° | θ 接近 0/360 | 用 `angdiff` 统一处理，禁止直接相减 |
| G7 | 边界点归属 | 交点恰落在某角域边界上 | 取**闭角域**口径（含边界），用容差 1e-9 判定 |

## H. "以直径为直径的圆"的歧义消解（消 T3）

### H.1 三种可能的解读

| 解读 | 半径 | 是否覆盖 L | 说明 |
|---|---|---|---|
| (a) **以直径端点连线为直径**的圆 | D/2 | **一般不覆盖** | **题设所指**（"以定位区域直径为直径的圆"） |
| (b) 以 D 为**半径**的圆 | D | 恒覆盖 | 平凡，无讨论价值 |
| (c) 最小包围圆 | R_MEC ∈ [D/2, D/√3] | 恒覆盖（定义） | 正解 |

**题设取 (a)**，因为"直径为直径"字面即"圆的直径等于区域的直径"。

### H.2 论文写法

> "题设所问'以定位区域直径为直径的圆'即半径 D/2、以直径两端点为对径点的圆（解读 a）。本文证明该圆一般**不能**覆盖定位区域，并给出反例、充要判据（Thales）与正确替代（最小包围圆，半径上界由 Jung 定理给出）。为消除口径歧义，结果表中同时报告 D、R_MEC 与缺口比 γ。"

### H.3 与"面积相同"类的歧义对照

VLSI 题有"面积相同"的词典序歧义；本题有"直径圆"的定义歧义。**处理手法一致**：显式枚举解读、指明题设所指、并给出通用结论（γ 比值），使任何解读下答案都自洽。

### H.4 附加歧义：直径对本身可能不唯一（更深一层）

**问题**：凸多边形达到直径 D 的**顶点对可能不止一组**。不同的直径对给出**不同的圆**，因而"能否覆盖"可能给出**不同答案**——而题设问的是唯一的是非。

**特例**：正方形两条对角线都是直径对，但它们给出同一个外接圆 ⇒ 答案一致。**一般凸多边形不保证如此**（如接近等宽的凸体，可有多组近似垂直的直径对）。

**处理（三种口径，全部报告，最强最诚实）**：
```
口径 A：任取一组直径对 —— 说明"题设隐含某条直径"，取其一组做答
口径 B：存在一组直径对使覆盖成立 —— 较弱的结论
口径 C：所有直径对都使覆盖成立 —— 最强的结论
```

**正解**：改用**唯一**的最小包围圆（MEC）。MEC 对任意紧集唯一存在，覆盖问题在 MEC 口径下**无歧义**。

**论文写法**：
> "注意到若干凸多边形存在多组直径对，而不同的直径对将给出不同的外接圆，故'以直径为直径的圆能否覆盖'在严格意义上依赖于直径的选取。本文在给出题设所问（任取一组直径）的结论之外，进一步报告'所有直径对'的存在性与普遍性两个更强结论，并指出**唯一无歧义的做法是采用最小包围圆**。"

**点透**：这条歧义**不是刁难**，而是本题的隐藏深度。发现它并给出处理，是把"陷阱"转成"亮点"的典型（对照 VLSI 题 T16"面积相同"的操作化）。
