# 问题一主图：Claude 与 Codex 独立完整方案竞赛

## 规则

把下方“不可变事实”与“统一任务”原样分别发送给 Claude 和 Codex。两者均须独立完成全部工作：理解数学、判断论文叙事、提出创新图表架构、定义视觉语义、列出实现和验收要求。

不要把模型分工为“一个做数学、一个做审美”，不要把两个回答预先拼接，也不要向任一模型展示另一模型的答案。已有图全部废弃，旧版布局不得作为参考。

## 不可变事实

这是数学建模论文问题一的两站角域定位案例。

- 观测站：`S1=(0,0)`，`S2=(600,0)`；真源：`G=(300,500)`。
- 测角误差：`eps=1 degree`；`theta1=59.036243 degree`，`theta2=120.963757 degree`。
- 可行区域：`L=W1∩W2`，为凸四边形。
- 顶点：`P1=(288.1342,499.7929)`，`P2=(300,480.7768)`，`P3=(311.8658,499.7929)`，`P4=(300,520.3752)`。
- 直径端点：`P2,P4`；`D=39.5983 m`。
- 最小覆盖圆：`C*=(300,500.5760)`，`R_MEC=19.7992 m`。
- `gamma=R_MEC/(D/2)=1.0000`，本例取 Jung 下界；`D/sqrt(3)=22.8621 m`。

核心论断：两站的 1° 角域把真源附近的不确定性限制为一个直径 39.598 m 的凸四边形；该区域的最小覆盖圆半径恰为 `D/2`。

绝对禁止：S3、五边形、伪造数值、错画 Jung 上界、只换颜色字体边距、横向三联小图、全景+局部放大旧模板、将生成式图片直接作为含公式与数值的论文图。

## 统一任务（分别发送给 Claude 和 Codex）

你是一名同时具备计算几何、数学建模论文写作、科学图表设计和可复现图表工程能力的首席设计师。请完全从零为“问题一”设计一张论文主图。不要参考或修补任何已有图；不要采用横向三联、全景+局部放大、均分网格等旧结构。

基于上述不可变事实，独立提出 **3 个完整且彼此结构不同的主图方案**。每个方案都必须同时回答数学、视觉、论文叙事和工程实现问题。

对每个方案输出：

1. 方案名及一句话结论；
2. ASCII 版面草图，标注主视觉与辅助证据占比；
3. 读图路线：读者如何在不读图注的条件下理解 `W1,W2 -> L -> P2/P4 -> C* -> R_MEC=D/2`；
4. 几何设计：所有对象的出现位置、颜色、线型、标签和跨区域身份继承；
5. 数学设计：哪些公式/数值要显示，哪些不应放在图内；Jung 夹逼应怎样准确表达；
6. 创新机制：说明它如何真正改变信息组织，而非只改装饰；
7. 论文适配：单栏或通栏、推荐尺寸、信息密度控制与审稿风险；
8. 工程实现：Python/Matplotlib 如何从同一计算对象渲染，不要写完整代码；
9. 可机检验收标准：至少 8 条，涵盖顶点、直径、圆心、半径、符号、字体和 SVG/PDF；
10. 该方案最大的失败风险以及规避办法。

然后将三个方案按“数学论证力、视觉独创性、论文可读性、实现可控性”评分，选择一个唯一首选。为首选方案写出：

- 最终画布结构；
- 颜色和对象字典；
- 12 条绘图规格；
- 可直接用于论文的中文图注。

最后用审稿人身份批评自己的首选方案，列出 3 条最可能被质疑的问题，并给出修正动作。
