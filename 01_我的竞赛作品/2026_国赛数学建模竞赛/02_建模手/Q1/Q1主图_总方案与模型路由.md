# 问题一主图：总方案与外部模型路由

## 1. 先纠正主图要回答的问题

问题一不是“画出某个两站算例的最小覆盖圆”。它要求：

1. 将带 ±1° 误差的示向度建模成凸角域；
2. 对角域交得到的凸多边形计算直径 `D`；
3. 回答“以 `D` 为直径的圆能否覆盖定位区域”；
4. 给出一般结论、判据与正确替代。

一般结论是：**不能保证覆盖**。等边三角形是反例；最小覆盖圆满足 `D/2 ≤ R_MEC ≤ D/√3`。两站基准算例 `L` 恰有 `gamma=1`，只能作为“该算例下直径圆正好覆盖”的特例和算法验证，不能替代一般结论。

因此新主图应承担“证明结构”，而非复现测站地图：

```text
误差角域是凸集
        ↓
角域相交得到凸多边形 L ───→ 直径 D（顶点对）
        ↓                              ↓
Thales 顶点判据                 反例：等边三角形
        ↓                              ↓
具体 L 是否覆盖              一般情形不能保证
        └──────────→ MEC 与 Jung 夹逼 ←──────────┘
```

## 2. 设计竞赛的边界

- 完全废弃所有既有版式，不把现图作为参考图。
- 允许展示真实两站基准算例，但它必须被标为“特例验证”。
- 必须展示一般反例或等价的“不能保证”证据；不能让 `gamma=1` 被误读为一般性质。
- 必须让读者辨认四个不同层次：输入角域、一般凸区域、直径圆覆盖判据、最小覆盖圆的界。
- 禁止横向三联、全景+局部放大、均分面板、单一基准菱形占满整张图。
- 最终图由代码生成；生成式图片只可用于无文字的版式探索，不能成为论文成图。

## 4. 模型选择：谁应生成“独立完整方案”

### 首选：Claude Opus 级模型

外部模型并不会自动拥有本工作区的技能或文件。每次调用都必须附上本文件的“不可变数学事实”和“任务边界”，不能只说“按已有 skill 完成”。

## 6. 不可变数学事实（每个外部模型必须收到）

- 输入为 `n` 个带误差的示向度；第 i 个角域为 `Wi={Si+t u(phi): t≥0, |phi-theta_i|≤eps}`，其中 `eps=1°`。
- `L=∩Wi` 是凸多边形；顶点由边界射线两两求交后，经“属于全部角域”过滤得到。
- `D=max(||p-q||:p,q∈L)`，对凸多边形只需检查顶点对。
- 一般不保证半径 `D/2` 的直径圆覆盖 L；等边三角形为反例。
- 覆盖判据：以直径端点 `P,Q` 为直径的圆覆盖 L，当且仅当所有顶点 `X` 满足 `∠PXQ≥90°`。
- 正确替代：最小覆盖圆，`D/2≤R_MEC≤D/√3`；等边三角形取上界。
- 基准特例：`S1=(0,0),S2=(600,0),G=(300,500)`；`L` 为四边形；`D=39.5983m,R_MEC=19.7992m,D/2=R_MEC`。它只验证“本例覆盖”，不是一般结论。
