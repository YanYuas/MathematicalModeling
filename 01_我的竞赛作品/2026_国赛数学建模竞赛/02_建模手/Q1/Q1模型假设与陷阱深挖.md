## 一、模型假设系统化（H1-H4，每个带"若违背"后果）

数学建模 = 现实 → **假设** → 模型 → 求解 → 验证。假设是评阅审稿第一眼。没写清楚 = 被误读。

### H1 几何假设

| 假设 | 内容 | 若违背的后果 | 论文写法 |
|---|---|---|---|
| H1.1 **平面欧氏** | 测向机与所有干扰源位于同一平面 | 若三维（有高度差）⇒ 示向度是俯仰投影角，角域模型失效 | "题设附录 2(7) 明确同平面，采用平面欧氏几何" |
| H1.2 **角度约定** | 正东 0°，逆时针为正，范围 [0°,360°) | 与题目约定不符 ⇒ 全部方向反了 | 显式写出约定与 `u(φ)=(cosφ,sinφ)` |
| H1.3 **闭角域** | 误差 ±1° **含边界**，Wᵢ 取闭集 | 取开集 ⇒ 交集可能不闭 ⇒ 直径 sup 不可达 | "取闭角域，保证 L 紧，D 可达"（并在结果中给边界处理口径） |
| H1.4 **角域是射线族** | t ≥ 0（单向） | **误用直线族（t∈ℝ）⇒ 出现反向假交点，区域错大甚至变空** | "角域为自检测点出发的射线族" |
| H1.5 **误差是有界区间** | 偏差 ∈ [−1°, +1°]，非随机分布 | 若改为概率分布 ⇒ 定位区域变水平集（一般非凸），凸性链断裂 | 明确声明"采用**有界不确定性**模型，非概率模型" |
| H1.6 **真源存在性** | 存在真源 G 落在所有角域内（L ≠ ∅） | 若 L = ∅ ⇒ 输入数据自相矛盾，问题无解 | 在退化分类中显式讨论（G3） |

### H2 问题结构假设

| 假设 | 内容 | 若违背的后果 | 论文写法 |
|---|---|---|---|
| H2.1 **各站误差区间相同** | 每站误差均在 [−1°,1°] | 若各站精度不同 ⇒ 各角域半角 εᵢ 不同（模型可推广，但题设未给） | "假定各检测点测向精度一致，εᵢ≡1°" |
| H2.2 **无系统偏差** | 各站示向度无固定偏置（题目：同地误差固定，跨地服从统计规律） | 若有系统偏置 ⇒ 真源不落在任何单一角域内，L = ∅ | "各站误差相互独立，无公共系统偏置" |
| H2.3 **定位区域口径** | L = 纯角域交集（**不与目标圆域求交**） | 若截断到 D(0,1800) ⇒ D 变小，与"交会定位语义"不符 | **须显式声明**；建议给出两口径对照 |
| H2.4 **非退化输入** | n ≥ 2，且各示向度方向不全平行 | n=1 或近平行 ⇒ 区域无界，D 未定义 | 退化为分类讨论（G1/G2） |

### H3 计算假设

| 假设 | 内容 | 若违背的后果 | 论文写法 |
|---|---|---|---|
| H3.1 **精确实数算术** | 坐标/角度以双精度浮点实现，判定用容差 1e-9 | 无容差 ⇒ 边界顶点被误删，区域缺角 | "判定采用相对容差 1e-9" |
| H3.2 **顶点枚举完备** | 交点集含 L 的全部顶点 | 漏枚举（如只取相邻角域）⇒ 凸包缺顶点，D 偏小 | "枚举全部 2n 条边界射线的两两交点并过滤" |
| H3.3 **凸包无退化** | 候选点集不共线（除退化情形） | 退化为线段/点时凸包算法返回退化输出 | 显式处理 G4/G5 |

### H4 报告假设

| 假设 | 内容 | 论文写法 |
|---|---|---|
| H4.1 **D 口径** | 由凸包顶点对的最大距离给出 | 同时报告直径端点坐标，便于复核 |
| H4.2 **覆盖口径** | "以直径为直径的圆" = 以直径两端点为对径点的圆（解读 a） | 显式枚举三种解读并说明取 a（见 §三 T1） |
| H4.3 **精度** | D、R_MEC 保留 2 位小数；γ 保留 4 位 | 报告 γ = R_MEC/(D/2) 而非仅报结论 |

## 二、模型级陷阱深挖（M1-M12）

### M1. "一条示向度 = 一条射线"是错误升格（最深的陷阱）
- **现象**：把示向度当成精确方位，直接画一条射线求交。
- **后果**：与题设"误差在 [−1°,1°]"直接矛盾；两条射线交于一点 ⇒ 区域退化 ⇒ D=0 ⇒ 后续推理全错。
- **对策**：必须升格为 **2° 角域**（F3/F5）。
- **论文卖点**：这就是为什么"交会定位"在本题是"**角域求交**"而不是"**射线求交**"——不是口味，是**误差模型决定的**。

### M2. 覆盖问题的"直觉陷阱"（本问最大概念坑）
- **现象**："直径是最长距离，那以它为直径的圆当然装得下"。
- **后果**：Q1 第二问直接答错。
- **根因**：**直径是两两约束（任意两点 ≤ D），圆覆盖是单点约束（所有点到固定圆心 ≤ D/2）**。后者严格更强。
- **对策**：反例（等边三角形）+ Thales 判据 + Jung 界，四层回答。
- **论文卖点**：这说明"区域的多尺度描述不能只靠一个标量"——D 只能刻画"最坏两点"，不能刻画"整体延展"。**这就是引入最小包围圆的根本原因**。

### M3. 误以为区域非凸
- **现象**：因为"误差是区间"就以为区域是"区域边界"而非凸体；或直接对射线做布尔运算。
- **后果**：凸包/直径算法失效，可能得到不正确的"最远点对"。
- **对策**：牢记 **角域 = 两半平面交 ⇒ 凸**（F5），凸集之交仍凸。

### M4. 把误差当概率分布
- **现象**：引入高斯误差、置信椭圆、95% 置信区域。
- **后果**：**自己给题目加条件**，模型与题设不符；且区域非凸，凸几何工具全废。
- **对策**：严格按题设"有界区间"建模；若想讨论"概率视角"，只能放在"模型评价/推广"一节，不进主模型。

### M5. 把 D 当作"定位误差"的全部
- **现象**：只报 D，声称"定位精度 = D"。
- **后果**：D 是"区域内最坏两点距离"，是**最坏情况**度量，远大于典型误差；只报 D 会让定位显得比实际差。
- **对策**：同时报 D（最坏）、R_MEC（覆盖尺度）、区域面积（整体不确定度）、区域质心（点估计）。**多尺度描述**。

### M6. 顶点过滤漏掉"在所有角域内"
- **现象**：只取两条射线交点，不校验是否落在其余角域内。
- **后果**：候选点含大量假点 ⇒ 凸包错误 ⇒ D 偏大（假点通常在远方）。
- **对策**：**强制**执行 F13 的 `∀k: P ∈ Wₖ`。单元测试：用基准算例验证输出恰为 4 个顶点、坐标对表。

### M7. ε 单调性的误用
- **现象**：由"ε 越小 L 越小"推出"检测点越多 D 越小"。
- **后果**：**该推论在真源不在新角域内时不成立**——若新增的示向度本身有更大误差或方向偏差，交集可能变空。
- **对策**：加站改善的**前提是真源落在所有角域内**（H1.6）。论文中写明前提。

### M8. 与圆域求交后 D 的性质改变
- **现象**：为"限制在目标区域内"而把 L 截断到 D(0,1800)，然后仍称之为"交会定位区域"。
- **后果**：截断后 L' = L ∩ D 可能**非凸**吗？不会（圆盘凸，交集仍凸）。但 **D' ≤ D**，且 D' 反映的是"目标区域内的不确定度"，语义不同。
- **对策**：口径二选一并声明；建议主口径不截断，截断版作对照。

### M9. 退化情形崩溃
- **现象**：n=1、近平行、空交集时程序报错或给出 NaN。
- **对策**：G1-G7 分类处理（见 `Q1建模数学化.md` §G）。

### M10. 角度环绕错误
- **现象**：θ₁ = 359°，θ₂ = 1°，直接相减得 −358°。
- **后果**：角域方向完全错误。
- **对策**：**强制**使用 F1 `angdiff`；单元测试跨 0° 用例。

### M11. 覆盖判定只看边不看顶点
- **现象**：只校验直径区间内的点，或只校验几个采样点。
- **后果**：漏判（凸多边形上角函数极值在顶点，但采样可能漏掉最不利顶点）。
- **对策**：**校验全部顶点**（F21）。

### M12. 声称"最小包围圆就是答案"而不给界
- **现象**：只说"应该用最小包围圆"。
- **后果**：没有量化"差多少"，回答不完整。
- **对策**：必须给出 Jung 双侧夹逼 `[D/2, D/√3]` 与缺口比 γ。

## 三、题设级陷阱（T1-T12，题目文本里的坑）

### T1. "以定位区域直径为直径的圆"的三种解读
- (a) 以直径两端点连线为直径的圆，半径 D/2 —— **题设所指**
- (b) 以 D 为半径的圆 —— 平凡恒覆盖
- (c) 最小包围圆 —— 正解
- **对策**：论文显式枚举并说明取 (a)，同时给出 (c) 的算法与界。

### T2. 附录 2 图 2 的"±1°"含义
- 图注："实线与相邻两条虚线的夹角均为 1°" ⇒ 角域半角 1°，**总张角 2°**。
- 陷阱：误把 1° 当总张角（半角 0.5°）⇒ 区域算小一半。
- **对策**：明确 "ε = 1° 为半角，角域张角 2ε = 2°"。

### T3. 误差范围的闭开
- 题设"所有误差在 [−1°, 1°] 范围内" —— 方括号 = **闭区间**。
- **对策**：取闭角域（H1.3）。

### T4. 示向度的方向定义
- 题设："x 轴正向逆时针旋转至**检测点指向干扰源**的向量方向的角度" —— **从检测点指向源**。
- 陷阱：若理解成"从源指向检测点"，方向反 180°，区域完全错。
- **对策**：实现时用 `atan2(G_y−S_y, G_x−S_x)` 的符号约定核对一次。

### T5. 单位是度不是弧度
- 示向度单位为度；三角函数实现用弧度。
- **对策**：统一在函数入口做 `rad = deg·π/180`；`angdiff` 在度域运行。

### T6. 定位区域是否含目标圆域约束
- 题设只给"检测点坐标 + 示向度"，**未提圆域**（圆域是 Q3/Q4 的设定）。
- **对策**：主口径**不加**圆域；在讨论中说明"若限制在目标区域内的对照结果"。

### T7. "任意两点之间距离的最大值"
- 定义是 **max**，不是 sup ⇒ 要求区域紧（闭且有界）。闭角域 + 有界 ⇒ 紧 ⇒ max 可达。
- **对策**：退化情形（无界）时明确指出"直径不存在（无界）"，而不是给 inf。

### T8. 检测点可能共线
- 若所有检测点共线（实际不太可能，但要防），交会角可能为 0 或 180°。
- **对策**：在退化分类中覆盖；实现时检查 det 接近 0 的射线对并跳过。

### T9. 示向度可能为整数/小数
- 题目给的是概念，实际输入可能 2 位小数（同模拟器返回）。
- **对策**：全程双精度，不做取整。

### T10. 检测点与源的相对位置无先验
- 没有说源在检测点的哪一侧 ⇒ 不能假设 θ₁ 与 θ₂ 的简单关系。
- **对策**：算法对任意输入几何成立，不做方位先验假设。

### T11. 与"交会定位"名称相关的误解
- 传统"交会定位"指两条射线交于一点；本题因误差而变成"区域"。
- **对策**：论文中说明"本题的交会定位是**带误差的交会**，结果为区域而非点"。

### T12. 图中虚线的角色
- 附录 2 图 2 中"实线 = 示向度方向，虚线 = ±1° 边界"，红线四边形 = 定位区域。
- 陷阱：把红线四边形误认为"两站的矩形区域"（其实是角域交）。
- **对策**：以 F3/F5 的定义为准，图标仅作示意。

## 四、新几何思路（B 系列，补充主线的可选深化）

**B1. Hough 变换视角（点-线对偶）**
- 把每条示向度看作"方位-距离"参数空间中的一族可能点；多站交会 = 这些族在真源处的公共交。
- 用途：**与射线交会互为印证**的另一种表述；论文"方法对比"一节可提。**不进主实现**。

**B2. 圆几何三定理簇（真正的工具）**
- **Thales**：圆周角定理 → 覆盖判据（F20/F21）
- **Jung**：直径 → 最小包围圆半径上界（F23）
- **Helly 定理**：凸集族两两相交 ⇒ 全体相交（可用于**快速判定 L 是否为空**：若任意两角域都相交，则 L≠∅）
- 用途：B2 三条全进方法层，是 Q1 的"正牌几何"。

**B3. 半平面交的对偶（点-线对偶）**
- 半平面交问题有经典的对偶表述（对偶后变成凸包问题）。
- 用途：理论小节，说明"求交"与"求包"的对偶性。**不进实现**。

**B4. 误差椭球类推广（区间 → 一般不确定集）**
- 若误差是"以角域为中心的不确定集"，可推广为"以 S 为顶点、开角 2ε 的锥"在投影下的交。
- 用途：模型推广一节，说明本模型是更一般框架的特例。

**B5. 区域形状的度量族**
- 除 D 外，可算：区域面积 A_L、最小宽度 w（宽度函数极小值）、周长 P_L、各向异性比 D/w。
- 用途：**多尺度描述定位不确定度**（解 M5），论文结果表可加一列 `A_L`。

**B6. Reuleaux 多边形视角**
- "等宽图形"（宽度处处为 D）——其最小包围圆半径 = D/√2 之类，是另一个极端。
- 用途：说明"D 固定的集合族"在形态上跨度很大 ⇒ 强化 M2 的论点。理论点缀。

**B7. 计算几何的标准工具箱对照**
- 本题 = 「半平面交 + 凸包 + 直径 + 最小包围圆」四件套，全部有教科书写法（de Berg 等《Computational Geometry》）。
- 用途：论文"算法可行性"论证——**说明所用算法皆有理论保障**。

## 五、化归思路（C 系列）

| # | 化归 | 转成 | 用途 |
|---|---|---|---|
| C1 | 角域 → 2 半平面 | 半平面交 | **核心化归**，接入计算几何工具箱，O(n log n) |
| C2 | 半平面交 → 凸包 | 顶点集 | 实现路径（排序增量/分治/两两求交） |
| C3 | 凸多边形直径 → 对踵点对 | 旋转卡壳 | 直径算法 |
| C4 | 覆盖判定 → 顶点角度判据 | Thales 逆定理 | 可计算判据 |
| C5 | 半径估计 → 最小包围圆 | Welzl 随机增量 | 正解，期望 O(n) |
| C6 | 空性判定 → Helly 定理 | 两两相交检验 | 快速预筛 L≠∅ |
| C7 | 误差传播 → 小角近似 | `D ≍ 2εd/sinφ` | Q2 选点的解析依据 |
| C8 | 多站定位 → 最小二乘估计 | Stansfield 估计器 | 当需要**点估计**时的经典方法（Q1 不需要，但可作对照） |

**C1 值得展开**：这是全题最重要的化归——"方位定位"这一传统无线电测向问题，在本模型下**等价于一个标准计算几何问题**（2n 个半平面求交）。这一句能让评阅立刻定位到你的方法学。

**C8 值得展开**：若题目改为"求干扰源的最佳点估计"，则应使用 Stansfield 加权最小二乘（`01_背景研究/背景全量研究报告.md` §4.2 [3]）——但**本题问的是区域不是点**，故仅作对照说明。

## 六、一页速查

- **假设必写**：H1.4 角域是射线族、H1.5 有界非概率、H2.3 不用圆域截断、H1.3 闭角域
- **最深的陷阱**：M1 射线 vs 角域、M2 直径圆直觉错、M6 顶点过滤
- **四层回答**：反例（等边三角形）→ 判据（Thales）→ 正解+界（最小包围圆 + Jung）
- **正牌几何**：Thales / Jung / Helly —— 进方法层
- **陪衬几何**：Hough / 对偶 / Reuleaux —— 只进理论小节或推广
- **报告**：D + R_MEC + γ + 区域面积 + 直径端点坐标

## 七、一句话总结

**Q1 的深度不在"会不会求交"，而在三件事**：把"示向度"正确升格为"角域"（M1，决定区域语义）、把"直径圆能否覆盖"答完整（M2，反例+判据+Jung 界）、把顶点过滤与退化情形做干净（M6/T8，决定实现正确性）。三者都做对，Q1 就是全题最稳的满分点。
