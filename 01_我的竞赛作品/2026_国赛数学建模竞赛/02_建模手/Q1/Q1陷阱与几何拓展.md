## A. 工程级陷阱（W 系列：写代码时会踩的坑）

### A1 致命陷阱（结果错但看不出来）

**W1. 用直线代替射线**
- 角域是 `t ≥ 0` 的**射线族**。若按直线求交（t∈ℝ），反向延伸的边界会造出假交点。
- **后果**：候选点集混入远处假点，凸包被撑大，D 偏大甚至区域变空。
- **对策**：求交时**必须**校验 `t ≥ 0 ∧ s ≥ 0`（F12）。

**W2. 顶点不过滤（最高频 bug）**
- 两条边界射线的交点未必落在其余角域内。
- **后果**：凸包含假点 ⇒ D 错（通常偏大）。
- **对策**：强制 `∀k: P ∈ Wₖ`（F13）。**验收**：基准算例必须恰好输出 4 个顶点且坐标对表。

**W3. 角度直接用减法**
- `θ₁ = 359°`、`θ₂ = 1°` 直接相减得 −358°。
- **后果**：角域方向完全错误。
- **对策**：强制用 `angdiff`（F1）。**验收**：跑跨 0° 用例。

**W4. 度/弧度混用**
- 示向度单位是度，`cos/sin/atan2` 用弧度。
- **后果**：方向整体偏移，且不报警（`cos(59)` 有值）。
- **对策**：入口统一转换；建议**全程用度定义、内部转弧度**并加注释。

**W5. 覆盖判定只看"某一对"直径端点（**本问隐藏最深的坑**）**
- **直径对可能不唯一。** 例如正方形的两条对角线都是直径对——本例恰好给出同一个外接圆，但一般凸多边形不保证。
- **后果**：以不同的直径对作圆，"能否覆盖"可能给出**不同答案**，而题目问的是唯一的是非。
- **对策**：
  1. 论文中明确指出该歧义，并说明**任取一对**的处理口径（题目隐含"某条直径"）；
  2. 同时给出 **最小包围圆**（唯一）作为无歧义的正确答案；
  3. 实现上：枚举**所有**达到 D 的顶点对，报告"存在一对使覆盖成立"与"所有对都使覆盖成立"两种结论（**更强也更诚实**）。
- **论文卖点**：指出"直径对不唯一 ⇒ 覆盖问题本身有歧义 ⇒ 更应使用唯一的最小包围圆"——这是把陷阱转成亮点的典型。

**W6. 浮点精确比较**
- 判定"点在角域内"用 `>= 0` 而无容差。
- **后果**：边界顶点因 1e-16 的误差被误删，区域缺角。
- **对策**：用相对容差 `>= -1e-9`。

### A2 高发陷阱（结果不稳/边界崩）

**W7. 行列式接近 0 未处理**
- 两条边界射线近平行时 `det = cross(uᵢ^a, uⱼ^b) ≈ 0`，除零/数值爆炸。
- **对策**：`|det| < 1e-12` 时跳过该射线对（其交点在无穷远，不属于紧区域）。

**W8. 凸包共线点未去重**
- 单调链（Andrew 1979）需注意共线点的处理：`cross ≤ 0` vs `< 0` 决定是否保留共线点。
- **后果**：保留共线点 ⇒ 凸包顶点数虚高，旋转卡壳在共线边退化。
- **对策**：用**严格** `cross ≤ 0` 剔除共线点（`V` 中只留严格极点）。

**W9. 旋转卡壳的终止条件**
- 经典实现细节：对踵点指针推进需用 `while` 配合"面积比较"，且**必须限制环回一圈**，否则死循环。
- **后果**：死循环或漏算对踵点对。
- **对策**：与 O(m²) 暴力**双实现互验**（F16 ≡ F17）。二者不一致即为 bug。

**W10. 最小包围圆的退化情形**
- Welzl 随机增量算法需要正确处理边界集为 0/1/2/3 个点的情况（`trivial` 圆 / 直径圆 / 三角形外接圆）。
- **后果**：n=1 或 n=2 时崩溃或返回错误圆。
- **对策**：显式实现四种边界情形；**并用 O(n³)/O(n⁴) 暴力法交叉验证**（枚举点对定圆 + 三点定圆）。

**W11. 单位量纲**
- 坐标单位是米、角度是度。混用会得到无意义数值（如把米当角度）。
- **对策**：变量名带单位后缀（`d_m`、`theta_deg`）。

**W12. 输出顶点序**
- 论文与可视化要求顺时针或逆时针一致。
- **对策**：统一输出**逆时针**（CCW），并在文档中注明。

### A3 低级陷阱（审题/接口）

**W13. 输入示向度的取值范围**
- 可能给 [0,360) 也可能给带负数的角度。
- **对策**：入口统一 `mod 360` 归一。

**W14. 是否把 L 与目标圆域求交**
- 实现里若"顺手"截断，会与建模口径不一致。
- **对策**：做成**开关**，默认关闭；两种结果都报。

**W15. n=1 未处理**
- 单条示向度 ⇒ 无界楔形 ⇒ D 无定义。
- **对策**：显式返回"无界"状态码，不返回 NaN。

## B. 更多几何思路（主线之外的深化）

**B1. 圆几何三定理簇（本题的正牌工具）**
- **Thales 逆定理**：`X 在以 PQ 为直径的圆内 ⟺ ∠PXQ ≥ 90°` → 覆盖判据（F20/F21）。
- **Jung 定理（1901）**：直径 D 的点集可被半径 `D/√3` 的圆覆盖，等边三角形取等 → 双侧夹逼（F23/F25）。
- **Helly 定理**：平面凸集族若任意三个相交则全体相交（平面情形 3 即可）→ **快速判定 L≠∅**（比完整求交便宜）。
- 用途：**三条全进方法层**，是 Q1 的理论骨架。

**B2. 旋转卡壳家族（一类算法，不止求直径）**
- 除直径外，旋转卡壳还能求：凸多边形**最小宽度**、**最小面积外接矩形**、**最大面积内接三角形**、两凸多边形**最小距离**。
- 用途：
  - 最小宽度 `w` → 与 D 一起构成"区域形态描述"（D/w 反映各向异性）；
  - 最小面积外接矩形 → 刻画定位区域的"主轴方向"（**Q2 选点的可用信息**）。
- 引用：Toussaint 1983 / 2014。

**B3. Hough 变换视角（点-线对偶）**
- 每条示向度在"方位-距离"参数空间对应一族点；多站交会 = 这些族在真源参数处的公共交。
- 用途：论文"方法对比"一节可提"与传统 Hough 投票法同源，但本文给出解析解而非投票"。

**B4. 半平面交的对偶**
- 半平面交问题经点-线对偶可转为凸包问题（经典对偶性）。
- 用途：理论小节，说明"求交"与"求包"的结构对偶。**不进实现**。

**B5. 区域度量族（多尺度描述）**
- 除 D 外：面积 `A_L`、最小宽度 `w`、周长 `P_L`、各向异性比 `D/w`、质心（点估计）。
- 用途：解 M5（单一标量 D 不足以描述不确定度），并使结果表更丰满。

**B6. Reuleaux 等宽图形（解释"为什么 D 不够"）**
- **等宽图形**：宽度函数处处等于 D 的凸体（Reuleaux 三角形是最小者）。
- **意义**：D 相同的凸体在形态上可以差很多——从"线段"（最扁）到"Reuleaux 三角形"（最圆）。**这正是 M2 的几何根源**，也给 Jung 界的直觉：越"圆"越难覆盖。
- 用途：理论讨论一节，强化"引入最小包围圆"的动机。

**B7. Ritter 近似最小包围圆**
- 一次扫描的 O(n) 近似算法，比 Welzl 更简单（但非最优）。
- 用途：**实现交叉验证的第三个来源**（Welzl 最优、暴力精确、Ritter 近似上界）。

**B8. 定位区域的"主轴"与 Q2 接口**
- 定位区域是"沿交会角的垂直方向被拉长"的细长四边形。
- 最短方向（最小宽度方向）**垂直于**交会角的角平分线。
- 用途：**Q2 第二检测点的选择方向**——沿最短方向移动能最快压缩区域。这是 Q1→Q2 的直接几何接口。

**B9. 与最小二乘点估计的关系**
- 若要求**点估计**，经典做法是 Stansfield 加权最小二乘（见 `01_背景研究/背景全量研究报告.md` §4.2 [3][4]）。
- 用途：论文"模型对比"——说明本文给的是**区域估计**（更保守、更严格），点估计可作为区域质心的近似。

## C. 化归思路（补充 C1-C8 之外）

| # | 化归 | 转成 | 用途 |
|---|---|---|---|
| C9 | 覆盖判定 → 半平面判定 | `∀X∈V: (X−P)·(X−Q) ≤ 0` | W5 的澄清判据（不依赖具体直径对的选择） |
| C10 | 最小包围圆 → 线性规划 | 约束 `‖X−c‖ ≤ r` 的 LP（Megiddo 线性时间） | 理论复杂度上界（O(n) 确定性） |
| C11 | 空性判定 → Helly 三元组检验 | 任意三角域相交则全体相交 | 快速预筛，避免无解输入 |
| C12 | 区域刻画 → 凸体理论 | 宽度函数 / 支撑函数 | 理论小节（B2/B5/B6 的统一语言） |
| C13 | 定位不确定度 → 信息熵/体积 | 区域面积作为"不确定度度量" | 多尺度描述（B5）的理论解释 |
| C14 | 多站融合 → 加权最小二乘 | Stansfield 估计器 | 点估计对照（B9） |

**C9 值得展开**：注意 `(X−P)·(X−Q) ≤ 0` 中的 P,Q 是**直径对**。若改写成"存在某个固定方向的支撑线"形式，可绕开直径对选择问题（承接 W5）。论文里写"覆盖判定等价于一组半平面约束"更干净。

**C11 值得展开**：Helly 定理在平面只需检验**任意三个**凸集是否相交。n 个角域的公共交非空 ⟺ 任意三个角域交非空。这把"空性判定"从 O(n) 次完整求交降为 O(n³) 次两两/三三求交——**但因为没有完整求交便宜的反例，仅在 n 大时优先**。

## D. 射影几何与非欧几何评估（诚实结论）

**直接结论：射影几何与非欧几何均不适用于 Q1。**

**原因（三条硬理由）**：
1. **射影变换不保角度**——而 Q1 的**全部输入信息就是角度**（示向度 ±1°）。射影下"1°"没有不变意义 ⇒ 模型本身被破坏。
2. **射影不保距离、垂直、圆**：圆可变成一般圆锥曲线 ⇒ "直径""圆覆盖"两个核心概念全部失效。
3. **非欧几何（双曲/球面）的"直线"不是欧氏直线**，而题设附录 2(7) 明确"测向机与所有干扰源位于同一平面" ⇒ **平面欧氏是题设给定的，不是可选项**。

**可借鉴的"对偶/结构"思想（射影精神，非射影操作）**：

**D1. 点-线对偶**
- 检测点 ↔ 角域边界射线；在对偶空间里"角域求交"变成"对偶包"。
- 这是射影对偶精神的正统应用（**与 B4 同源**）。**进理论小节**。

**D2. 交比与"角度的组合结构"**
- 多条示向度之间的相对角关系可用交比思想描述（比例结构在变换下不变）。
- 诚实表述：本题的角度是**度量角**（度），不是交比意义下的"射影角"。**只作一句话类比**，不展开。

**D3. 圆几何（真正用到的"经典几何"）**
- Thales / Jung / Helly / Reuleaux —— 这些是欧氏圆几何，**不属于射影也不属于非欧**，但它们是本题的**正牌工具**。
- 定位建议：把 D3 写成"经典圆几何的应用"小节，与 D1/D2 的"不适用"形成对照。

**论文定位建议**：
> "由于定位信息完全由角度给出，而射影变换不保持角度，射影几何不适配本问题；非欧几何亦不适用（题设明确限定平面）。本文采用平面欧氏几何，核心工具为圆几何的三个经典结果：Thales 定理（覆盖判据）、Jung 定理（覆盖半径上界）、Helly 定理（交非空判定）。"

**点透**：**说明"为什么不适用"本身就是严谨性的体现**。评阅比看到硬套射影更欣赏这种自觉。

## E. 采纳建议（真用 vs 点缀）

**主战武器（实现）**：
- 角域 → 半平面交建模（F5）
- 射线求交 + 过滤 + 凸包 + 双实现直径（F11-F17）
- Thales 覆盖判据（F20/F21）+ 等边三角形反例（F22）
- 最小包围圆 Welzl + Jung 夹逼（F23-F26）
- 退化分类 G1-G7
- W1-W15 全部规避

**交叉验证（论文加分）**：
- 旋转卡壳 ⊕ O(m²) 暴力
- Welzl ⊕ O(n³) 暴力 ⊕ Ritter 近似
- C9 的半平面形式覆盖判据

**理论小节（展现深度，不实现）**：
- B1 圆几何三定理簇（Thales/Jung/Helly）——**这条要实现**，属方法层
- B6 Reuleaux 等宽图形——解释 D 不足
- B4 半平面交对偶、D1 点-线对偶——结构分析
- C10 Megiddo 线性时间 MEC——复杂度注脚

**丢弃**：
- 概率/统计误差模型（M4，与题设不符）
- 射影变换的实际使用（D，不保角度）
- 任何启发式/优化算法（本题是精确问题，用了是扣分）

## F. 一页速查（给队友）

- **角域是射线族**（t≥0），不是直线 —— W1
- **顶点必须过滤**（∈所有角域）—— W2，验收：基准算例恰 4 顶点
- **角度必用 angdiff**，跨 0° 用例必测 —— W3
- **直径对可能不唯一** ⇒ 覆盖问题有歧义 ⇒ 更该用最小包围圆 —— W5
- **浮点用 1e-9 容差**；det<1e-12 跳过 —— W6/W7
- **双实现互验**：直径（卡壳⊕暴力）、MEC（Welzl⊕暴力）—— W9/W10
- **覆盖四层回答**：反例（等边三角形）+ 判据（Thales）+ 正解界（Jung `[D/2, D/√3]`）
- **圆几何三定理进方法层**；射影/非欧**不进**（说明理由即严谨）
- **报告**：D + R_MEC + γ + 区域面积 + 直径端点坐标 + 所有直径对
- **基准算例**：D=39.598 m、R_MEC=19.799 m、γ=1.000（下界取等）
