## 一、第一性原理：Q4 到底是什么问题

### 1.1 从题设到数学对象：一句话的几何化

`附录1(3)` 是 Q4 的全部新增信息：

> "定向干扰源具有特定的发射方向（简称定向方向），有效覆盖角度范围为定向方向两侧各 90°（含）"

这一句的几何化只有一行：

```
|∠((X−G), u)| ≤ 90°  ⟺  (X−G)·u ≥ 0  ⟺  X ∈ H(G,u) := {X : (X−G)·u ≥ 0}
```

`H(G,u)` 是**过源 `G`、以 `u` 为外法向的闭半平面**。⇒

- **可测域 `M(G) = D(G,R_eff) ∩ H(G,u)` 是半圆盘**——两个凸集之交，**仍是凸集**；
- 所有"源是否被看见"的问题，都归结为"检测点是否落在这个半圆盘里"。

**为什么这一步是 Q4 的关键**：Q3 靠"角域是凸集"（Q1-F5）把问题接入计算几何；
Q4 靠"扇区是半平面"把问题接入 **凸集分离定理**。**两处是同一手法：把一个无线电问题化归成一个凸几何问题。**

### 1.2 为什么"一个点看不见背对它的一半空间"是本质，而不是细节

把 Q3 的发现条件写成最朴素的形式：

```
Q3：∀G ∈ D, ∃p ∈ P : ‖p−G‖ ≤ 1000               （覆盖）
Q4：∀G ∈ D, ∀u, ∃p ∈ P : ‖p−G‖ ≤ 1000 ∧ (p−G)·u ≥ 0    （包围）
```

`∀u` 这个量词是全部难度所在。它可以被消掉（定理 Q4-A）：

```
∀u ∈ S¹, ∃p : v_p·u ≥ 0    ⟺    0 ∈ conv{v_p}    ⟺    G ∈ conv Q(G)
```

⇒ **"任意朝向都能被看见" ⟺ "源被检测点包围"**。这个等价把"∀u"这个无穷量词换成了
一个有限的、可计算的几何条件——这正是 Q4 从"无法论证"变成"可以论证"的转折点。

**几何直觉**：一个点可以被一个圆盘罩住；但**不可能被任意少的点包围**——
至少需要 3 个非共线点，且要"绕着"它。⇒ Q4 的布点比 Q3 **本质上更密**（不是"多一点"，而是"必须成环"）。

### 1.3 为什么"死角"是伪影而不是问题的性质

`深度钻研` §8.2 的反例（源在 `(1800,0)`、朝正东）确实成立——**只要检测点在圆内**。
但它的证明只用了两件事：

1. `‖p‖ ≤ 1800`（检测点在圆内）；
2. 圆的边界在 `G` 处的外法向就是 `u`。

⇒ **是"检测点集被限制在凸域内"造成了死角，而不是"定向"本身。**
一旦允许检测点出圆域（`附件2` §1.1 明文允许），反例立刻被破解：
`G` 的三个最近格点中必有一个 `x ≥ 1800`（在 `G` 的外侧），它就能看到源。

**方法论**：遇到"某个约束下无解"的结论时，**先检查那个约束是不是题面强加的**。
这里"检测点在圆内"是一个**自己加上去的假设**，题面从未要求。

### 1.4 为什么 Q4 比 Q3 贵，以及贵得值不值

| | Q3 | Q4 |
|---|---|---|
| 检测点数（**d=1000**） | **13** | **≈ 28**（环带后单元数 28.4404；原 d=1500 行作废） |
| 扫描 | ~952 s | **~1 700~2 000 s** |
| 移动 | ~1 263 s | **~2 562 s** |
| 粗算合计 | ~1 500~1 700 s（d=1000） | **~6 600~7 300 s** |

**贵在哪里**：唯一来源是**外扩环带把检测点从圆内推到圆外 `d`**（原写 `d/√3`，已作废），点数约翻倍。
**值不值**：付这笔钱换来的是**从"概率完备"到"确定性完备"**——
题面第一句就是"在**确保**所有干扰源被清除的前提下"，**这个"确保"不能用概率换**。
⇒ 结论：**值得付，且必须付**。

## 二、核心数学原理（逐条展开）

### 2.1 半平面化：为什么"含"字是最后一环

定理 Q4-A 的证明用的是 `0 = Σλ_p(v_p·u) ⇒ 某个 v_p·u ≥ 0`。
若 `G` 恰落在两个格点的连线上，取该连线的外法向 `u`，则那两个格点处 `v_p·u = 0`——
**等号成立，命题仍然通过**（因为我们要的就是 `≥ 0`）。

⇒ 若 `附录1(3)` 写的是"各 90°（**不含**）"，则 `v_p·u = 0` 会被判为**不在覆盖内**，
该 `G` 就重新变成死角。⇒ **"含"这一个字，决定了外扩环带方案能不能成立。**
论文里把这一点写明，是"读题细致"的直接证据。

### 2.2 surrounding 条件：为什么必须"充要"

只证"充分"（如"格点足够密就能保证发现"）是不够的：
- 评阅会问"够密是多密"；
- 自己也不知道当前的 `P` 到底行不行（无法自检）。

充要条件给出**可执行的自检**：对圆域采样，逐点检查 `G ∈ conv Q(G)`。
这比"估计一下够不够"强得多。**这也是把"∀u"消掉的价值**——它把不可验证的量词命题变成了可验证的几何谓词。

### 2.3 外扩环带的宽度：为什么是 `d` 而不是 `d/√3`（🚨 **2026-09-12 更正**）

```
需要 P ∋ G 的三个最近格点；而三点的最远者（**第三近邻**）可达 `d`
                            ⇒  P 必须包含所有"到 D 的距离 ≤ `d`"的格点
                            ⇒  环带宽度 = `d`（**下限**；原写 `d/√3` 只覆盖了最近邻）
```

- 取**更宽**：纯浪费（多测点、多移动）；
- 取**更窄**：可能漏掉某个 `G` 的包围顶点 ⇒ surrounding 失效 ⇒ 可能的死角。

⇒ **`d` 是精确的临界宽度**（下限）。这是一个"由证明反推出的设计值"，
和 Q3 的 `d ≤ 992.3920 m` 是同一种手法（由判据反解参数）。

### 2.4 扫掠清除：为什么它比 homing 更"Q4 友好"

| | homing | 扫掠清除 |
|---|---|---|
| 需要示向度？ | **需要**（连续读） | **不需要**（只读 `/clear` 结果） |
| 受盲区影响？ | **是**（滑出扇区即断） | **否**（清除与朝向无关） |
| 成本 | `≈ 213.49 s`（与 `R_MEC` 无关） | `10·N`，`N ≈ 1.2092(R_MEC/20)²` |
| 拐点 | — | `R_MEC ≤ 84.0369 m` 胜出 |

⇒ **扫掠的成本函数与"源好不好测"完全正交**。在一个"难测"是主要难点的问里，
这是最有价值的性质。**Q4 的清除环节因此比发现/定位环节更轻松**——
这是"负负得正"：`附录2(8)` 那句"清除与朝向无关"在 Q3 里只是个小便利，在 Q4 里成了主心骨。

### 2.5 扇区探针：为什么"垂直偏移"是对的

直观：源在某个方向，视线是一条线；扇区边界是过源的直线。
"我们是否在扇区内"等价于"视线方向与 `u` 的夹角是否 ≤ 90°"。
沿着视线垂直方向挪一小步，夹角会改变 `±` 一点 ⇒ **两个方向至少一个让夹角变小**。

形式化后就是引理 Q4-D 的 `max{(q₊−G)·u, (q₋−G)·u} = (p−G)·u + b|n̂·u| ≥ 0`。
**注意垂直偏移不改变距离**（`‖q_±−G‖ = √(r²+b²) ≈ r`），
⇒ 不会因为探针而掉出 `R_eff`（这正是选垂直方向而不是任意方向的原因）。

### 2.6 末端判据的替换：为什么"等 near"在 Q4 会死锁

`附录2(9)`：`near` 需要"距离 ≤ 5 m **且位于覆盖角度范围内**"。
⇒ 定向源从盲侧接近时，程序永远收不到 `near`，永远不会触发清除，**无限逼近**。
这是一个**死锁**（liveness 失败），不是性能问题。

**修正后的末端逻辑**：

```
while r̂ > 20 − 裕量:
    走一步（步长 ≈ r̂），/measure
    若 near      → 立即 /clear（扇区已确认，这是最快的路径）
    若 direction → 更新 r̂，继续
    若 no_signal → 已滑出扇区或越过源 ⇒ 反向半步重测（承 Q3 的过冲兜底）
最后 /clear 判定（与扇区无关）
若 R_MEC ≤ 84.0369，则跳过 homing，直接用扫掠清除
```

## 三、成本与目标设计：完整逻辑链

### 3.1 为什么 Q4 与 Q3 共用同一个目标

题面："其他条件与问题 3 相同"。⇒ 双钟、清除半径、near 阈值、接收半径、串行规则、
幂等规则、表 1 的两列口径**全部不变**。**不要因为"源多了一种"就改目标函数。**

### 3.2 为什么 Q4 更要盯住现实时间

虚拟时间余量仍然巨大（Q4 粗算 6 600~7 300 s ≪ 360 000 s），
但**请求数约为 Q3 的 2 倍**（点数翻倍 + 探针 + 扫掠）⇒ 现实时间更接近 1200 s。
⇒ 约束式 `n_req·τ_req ≤ remaining_real_duration_s − 60`（Q4-F48）**从"顺带合规"升级为"必须盯住"**。

### 3.3 为什么 Q4 的下界几乎不变、而实际值上升

```
移动下界（Steiner）依赖的是"检测点的 1000-圆盘覆盖圆域"
surrounding ⇒ 存在 p ∈ Q(G) ⇒ ‖p−G‖ ≤ 1000  ⇒ 蕴含 1000-覆盖
⇒ 下界【不变】：3518.5838 m / 703.7168 s
```

但 Q4 的检测点被推到圆外 ⇒ 网格 TSP 覆盖范围从半径 1800 增到 2666（d=1500）
⇒ **实际移动上升，离下界的倍数变大**。

**论文写法**：下界不变 + 实际值上升 + 差距归因（环带），三段式。**不要偷偷改下界去"配平"。**

## 四、策略（算法）选择的合理性

### 4.1 为什么"继承 + 三处替换"优于"重写"

- Q3 已验证的部分（交会几何、homing、双钟、状态机、接口纪律）在 Q4 **依然正确**，重写只会引入新 bug；
- Q4 真正新增的只有**一条前提**和**两个机制**；
- `Q3 ⊆ Q4` 可作**免费的正确性自检**（全向源用例下 Q4 必须复现 Q3 的答案）。

⇒ 论文按"从 Q3 到 Q4 的严格扩展"来写，比从零叙述更能体现对问题的理解，也更容易让评阅相信整套策略。

### 4.2 为什么外扩环带不算"钻空子"

题面 `附件2` §1.1 原文："机器狗可以向模拟器提交目标区域外的位置；模拟器仍会按提交的位置计算移动耗时和检测、清除结果。"
⇒ **题面显式允许并规定了计费方式**（按实际距离算移动耗时）。
⇒ 外扩环带是**题面允许的正常设计**，且代价被如实计入（移动增加）。
**不是钻空子，是"读到了别人没读到的一句"。**

### 4.3 为什么 `d` 在 Q4 倾向更小

| 考虑 | 倾向 |
|---|---|
| 定位富余（半平面内格点数：`d=1500` 仅 1~2 ⇒ 常需探针；`d=1000` 有 ~4~5） | **小 `d`** |
| 扫描/移动成本（点数：`d=1000` **≈ 28**） | 大 `d` |
| 覆盖/包围约束（**`d ≤ R_eff = 1000`**；原写 `1732.0508` 已作废） | 两者都满足 |

⇒ Q4 的 `d` 取舍比 Q3 更紧张，且**新增了"定位富余"这一项权重**。
**仍需模拟器标定**，但 Q4 的天平明显偏向 `d=1000`（或更小）。

### 4.4 为什么探针次数上界是 2（而不是更多）

引理 Q4-D 说明"两个候选点里至少一个在扇区内" ⇒ 最坏情况是"第一次错、第二次对" ⇒ **2 次足够**。
⇒ 探针成本有**硬上界**（`≤ 2×(5+1) ≈ 12 s`），不会失控。这是"用几何性质封顶"的又一例。

### 4.5 为什么不放弃死角源（或对死角源特判）

- 死角源**仍要被清除**（题面要求，且演练会报总数）；
- 且它有实际影响：它仍在发射，仍在圆域内；
- 且 surrounding 已能覆盖它 ⇒ **不需要特判**。
⇒ 特判是多余的复杂度，且会引入新的漏判风险。
