## B. 更多几何思路（Q4 专属）

### B1 半平面的三种等价刻画（论文可用）

| 刻画 | 形式 | 适用 |
|---|---|---|
| 点积 | `(X−G)·u ≥ 0` | **实现首选**（无三角函数，闭性天然） |
| 角度 | `\|angdiff(∠(X−G), ψ)\| ≤ 90°` | 论文叙述（直观） |
| 有向距离 | `u·X − u·G ≥ 0`（关于 `X` 的线性式） | 与"半平面交"（Q1-F5）接轨 |

**点透**：第三种把它写成**线性不等式**，于是"定向源的可测性"与"Q1 的角域"是**同一类对象**——
都是半平面的交。这让 Q1 与 Q4 在方法学上完全统一。

### B2 死角的几何画像（论文主打图的底稿）

```
源 G 在圆周上，定向方向 u = 圆的外法向（朝外）
  ⇒ 有效半平面 H = {X : (X−G)·u ≥ 0} 与圆域 D 的交 = 【仅 G 一点】（切点）
  ⇒ 圆内任意检测点 p ≠ G 都有 (p−G)·u < 0 ⇒ 全在盲区
  ⇒ 圆内任何网格（无论多密）都测不到该源
```

**关键几何事实**：`H ∩ D = {G}`。这是"切线与半径垂直"的直接推论。
**修复**：把检测点放到 `u` 这一侧（圆外），`H ∩ D` 立刻从"一点"变成"一大块"。

### B3 环带 = "包围壳"

Q3 的检测点集只需"罩住"圆域（覆盖壳，厚度由 `R_eff` 决定）；
Q4 的检测点集需要"包住"圆域（包围壳，厚度由**第三近邻距离 `d`** 决定 —— **不是**最近邻半径 `d/√3`）。
⇒ **两个壳的厚度由两个完全不同的量决定**：

| | Q3 覆盖壳 | Q4 包围壳 |
|---|---|---|
| 需要的厚度 | 0（检测点可全在圆内，圆盘出圆即可） | **`d`**（三顶点必须都在 `P` 内；最远那个是**第三近邻**） |
| 由什么决定 | 圆盘半径 `R_eff` | **第三近邻距离 `d`**（= 格距，**不是**覆盖半径 `d/√3`） |
| 直觉 | "圆盘能伸出去" | "点不能伸出去，所以要把点放出去" |

### B4 "包围"与"覆盖"的几何层次

```
1 个点      → 只能"覆盖"一个源（若够近）
2 个点      → 仍不能对任意朝向可见（一条线段的凸包是零面积）
3 个非共线点 → 第一次可以"包围"一个小三角形
N 个点      → 可包围的区域 = 其凸包
```

⇒ **Q4 的发现条件本质是"每个可能的源位置都要落在某三个检测点的凸包里"**——
这解释了为什么 Q4 的布点比 Q3 **本质上更密**（不是多一点，而是必须成环）。

### B5 扫掠清除与 Q3 的覆盖论是同一个工具

| 问题 | 用覆盖论做什么 | 参数 |
|---|---|---|
| Q3 发现 | 用 1000-半径盘覆盖圆域 | 间距 `d ≤ 1732.0508` |
| Q4 发现 | 用 1000-半径盘覆盖圆域 **∧ 包围** | 同上 + 环带 |
| **清除** | **用 20-半径盘覆盖 `L`** | `N ≈ 1.2092(R_MEC/20)²` |

⇒ **"圆盘覆盖"这个工具在本题出现了三次**，且都用同一个密度常数 `2π/(3√3) = 1.2091996`。
论文里把这三处并列写出，是很漂亮的方法学一致性证据。

### B6 扇区探针的几何本质：边界探测

`H` 是过 `G` 的半平面；`p ∈ H` 已知，但`p` 离边界 `∂H` 多远未知。
垂直视线方向偏移 `±b`，相当于**在离边界的方向上做一次对称探测**：
`(q_±−G)·u = (p−G)·u ± b·(n̂·u)`，两者的对称中心是 `(p−G)·u ≥ 0`，
幅度是 `b|n̂·u|`。⇒ **"凸组合的均值非负 ⇒ 至少一个非负"**——
这正是引理 Q4-A（surrounding）的同一个论证的局部版。
⇒ **surrounding 与探针是同一个数学事实（凸性 ⇒ 至少一个非负）在不同尺度上的应用。**

### B7 三路清除的成本曲线与拐点

```
直接清除： 常数 ≈ 5 + 移动       （仅在 R_MEC ≤ 20 可用）
扫掠清除： 10·1.2092·(R_MEC/20)²   （二次增长）
homing：   常数 ≈ 213.49 s         （与 R_MEC 无关）
拐点：     R* = 84.0369 m
```

**几何解释**：扫掠的成本正比于"需要多少个 20-盘去盖住 `L`"，即 `L` 的**面积/尺度**；
homing 的成本正比于"从多远开始逼近"，与 `L` 的大小无关。
⇒ **大 `L` 用 homing（因为扫掠面积爆炸），小 `L` 用扫掠（因为 homing 有固定开销）。**

### B8 定向源可测域的面积

`M(G) = D(G,R_eff) ∩ H` 是半圆盘，**面积恰为整圆盘的一半**（`πR_eff²/2`）。
⇒ **"可见面积减半"** 是 Q4 与 Q3 在"发现概率"层面的直观差别——
但注意：**这是"面积"减半，不是"保证"减半**。保证层面的差别是
"覆盖 → 包围"（本质不同），不是"概率减半"。

## D. 射影几何与非欧几何评估（诚实结论）

**直接结论：与 Q1/Q3 一致——射影几何与非欧几何均不适用于 Q4 的求解。**

原因：

1. **射影变换不保角度**：扇区的定义（"两侧各 90°"）完全依赖角度 ⇒ 射影下无意义；
2. **射影不保距离与圆**：`R_eff`、清除半径 20 m、`R_MEC` 全部失效；
3. **非欧不适用**：`附录2(7)` 明确平面欧氏是题设给定。

**但有一处"射影精神"的结构观察值得点一句（不进方法层）**：
射影变换**保持直线与凸性**，因此**保持"半平面"这个结构**（保关联、保凸）。
⇒ 虽然射影**不能**用来化简求值（因为丢了 90° 与距离），但
**"扇区是半平面"这一结构事实是射影不变的**——即"定向源的可测域是一个凸的、由一条过源的直线界定的集合"
这个定性结论，在任何保直线的变换下都成立。
**论文里可以一句话点出这个层次感（"结构保、度量不保"），但不做任何射影计算。**

**真正属于 Q4 的数学工具（正牌）**：

| 工具 | 用在哪 |
|---|---|
| **凸集分离定理（有限点集版）** | surrounding 条件的充要性（定理 Q4-A）—— **Q4 新引入** |
| 半平面（凸集）与半圆盘 | 可测性判据（Q4-F3/F4） |
| 圆盘覆盖论（密度 `2π/(3√3)`） | 环带点数的估计 + **扫掠清除**（`N_sweep`） |
| Steiner 公式（Minkowski 和面积） | 移动下界（承 Q3） |
| 压缩映射（Banach） | homing 收敛（承 Q3） |
| 最小包围圆（Welzl） | 清除点 `c*`（承 Q1/Q3） |
| 反证法 + 谓词化 | 完备性定理（命题 Q4-E） |
