## 一、第一性原理：问题到底是什么

### 1.1 从题设到数学对象

题设的四个事实决定问题形态：

- **"一个检测点…测得的示向度"** → 只有一条方位约束。**源在这条射线上的位置（距离）完全未知** ⇒ 单站不可定位。
- **"全向干扰源"** → 可探测性只与距离有关，无方向盲区（Q4 会改）⇒ 约束形式简单。
- **"第二个检测点的选择策略"** → **实验设计**：在取得 S₂ 处观测**之前**决定 S₂。这是本问区别于"估计问题"的根本特征。
- **"较好的定位效果"** → 定性词，必须量化 ⇒ 借用 Q1 的 D。

数学对象：在不确定集 `U = W₁ ∩ {5 < |S₁G| ≤ 1500} ∩ D(0,1800)` 上，选定 S₂ = S₁ + a·u + b·v（**不得依赖 G 的真值**），使定位不确定度最小，且满足可探测与非退化约束。

### 1.2 为什么这是"鲁棒"实验设计（而不是普通实验设计）

普通实验设计中，参数（这里是 G）**已知或可测**；本题中 G **完全未知**，且不是"未知但有分布"，而是"未知但有界"。因此：

```
min_{S₂}  max_{G ∈ U}  E(G; S₁, S₂)
```

这是标准的 **min-max 鲁棒优化**。**关键区别**：若不鲁棒化（假装知道 G），结论只在特定 G 下成立，一旦真源偏离就失效 —— 这在竞赛里是致命缺陷。

### 1.3 为什么难点在"鲁棒性建模"而不在"算法"

- 目标函数 E(a,b) **光滑、二维、有闭式最优性条件**（命题 C.1），没有局部极小、没有组合爆炸；
- 因此**不需要任何启发式算法**（SA/GA 一律不用）；
- 真正的难点是：**如何把"源距未知"这个模糊陈述转成一个可计算的数学对象**。答案是区间 `[d̂−Δd, d̂+Δd]` 与最坏情况取界（L5/L6）。

**点透**：Q2 的"难度"是**建模难度**不是**算法难度**。识别这一点，就能避免把简单问题复杂化。

## 二、核心数学原理（逐条展开）

### 2.1 三行关系式（全部推导的起点）

在 S₁ 为原点、θ₁ 中线为 +x 轴的坐标下，源 G = (d₁, 0)，第二点 S₂ = (a, b)，记 Δ = d₁ − a：

```
d₂  = √((a−d₁)² + b²) = √(Δ² + b²)
cos φ = (d₁ − a)/d₂ = Δ / d₂
sin φ = |b| / d₂
```

**推导**：`G→S₁ = (−d₁, 0)`，`G→S₂ = (a−d₁, b) = (−Δ, b)`。点积 = d₁Δ；模长分别 d₁ 与 d₂ ⇒ 第一式。第二式由 `sin² = 1−cos²` 且 `d₂² = Δ²+b²` 得 `sinφ = |b|/d₂`。∎

**这三行的价值**：
1. φ 只通过 **Δ 与 b** 依赖几何，与 d₁ 的绝对值解耦（在 Δ 记法下）——**这正是鲁棒化的可操作基础**；
2. `sin φ = |b|/d₂` 一眼看出 **b=0 ⇒ sinφ=0（退化）**；
3. `cos φ = Δ/d₂` 一眼看出 **Δ=0 ⇒ φ=90°（最优）**。

### 2.2 最优性条件的几何读法：正侧方 + Thales

**a = d₁** 的含义：S₂ 与源在**沿视线的同一深度**。此时 `G→S₂ = (0, b)` 垂直于 `G→S₁ = (−d₁, 0)` ⇒ φ = 90°。

**几何重述**：S₂ 落在"**过源、垂直于 S₁G**"的直线上。等价地由 Thales 定理：

> ∠S₁GS₂ = 90° ⟺ **G 落在以 S₁S₂ 为直径的圆上**。

**为什么这很重要**：Q1 已经把 Thales 用作覆盖判据；Q2 复用同一工具作为**选点条件**。**两问共享同一几何工具**，论文叙事上是一条主线（创新 2）。

### 2.3 目标函数：为什么是 E 而不是别的

见 §三（目标函数设计独立成节，因其逻辑链较长）。

### 2.4 鲁棒化：把"未知源距"变成"区间 Δd"

**可用信息清单**（决定 Δd）：

| 信息 | 结论 |
|---|---|
| S₁ 返回 `direction`（不是 `near`/`no_signal`） | d₁ > 5（否则 `near`） |
| 测到说明在接收半径内 | d₁ ≤ R_true ≤ 1500 |
| 目标区域半径 1800 | 可进一步缩小 d₁ 上界（取决于 S₁ 位置） |

⇒ `d₁ ∈ (5, 1500]`，取中点 d̂ = 752.5、半宽 Δd = 747.5。

**为什么用中点而不是别的**：中点使最坏偏差最小（min-max 的朴素最优）；且 Δ 的符号对称处理（Δ 可正可负，最坏取 |Δ| = Δd）。

### 2.5 两条边界约束的推导（L5/L6）

**角度质量约束**：要求 ∀Δ（|Δ| ≤ Δd），`sin φ = |b|/√(Δ²+b²) ≥ sin φ_min`。
最坏在 |Δ| = Δd。解之：
```
|b|² ≥ sin²φ_min (Δd² + b²)
b²(1 − sin²φ_min) ≥ Δd² sin²φ_min
b² cos²φ_min ≥ Δd² sin²φ_min
|b| ≥ Δd · tan φ_min                        ⇒  b_min
```

**可探测约束**：要求 ∀Δ，`d₂ = √(Δ²+b²) ≤ R_worst`。
最坏在 |Δ| = Δd：
```
Δd² + b² ≤ R_worst²   ⇒   |b| ≤ √(R_worst² − Δd²)   ⇒  b_max
```

### 2.6 可行性不等式：本问的"天花板"（L7）—— **⚠️ 仅 α=0**

`b_min ≤ b_max` ⟺ `Δd·sec φ_min ≤ R_worst` ⟺ **`Δd ≤ R_worst·cos φ_min`**。

> **v1.2.0 联合校验修正**：本式的推导把"角度质量"与"可探测"两条约束**合并成了一条**，
> 而这一步**只在 `α = 0` 时合法**。计入示向度误差 `α ∈ [−1°,1°]` 后两条约束**不可再合并**，
> 须用双约束组（见 `Q2建模数学化.md` 的 L5'/L6'/L7'）。
> **数值后果：真正的天花板不是 41.6257° 而是 39.6161°**（`b_min^{α}=650.00 > b_max^{α}=638.00`
> ⇒ `φ_min=40°` 下候选区域为空集）。

**推论（必须写进论文的诚实结论）**：

> 在源距不确定半径为 Δd、最坏接收半径为 R_worst 时，**无论第二个检测点怎么选**，能保证的交会角上界为
> `φ_min ≤ arccos(Δd / R_worst)`

本算例（Δd=747.5, R=1000）⇒ **φ_min ≤ 41.6°**。这不是算法不足，是**信息量的硬限制**：单条方位线不含距离信息，能补上的方向信息有限。

**突破途径**（论文可提）：取得额外距离信息（场强-距离模型、多点连续测量、目标区域几何先验）⇒ Δd 减小 ⇒ φ_min 增大。

## 三、目标函数设计：完整逻辑链

### 3.1 为什么不能直接用"交会角 φ"当目标

- φ 是**纯角度**，不含距离尺度：远源 90° 与近源 80° 孰优无法比较（实际上距离越远，同样的角误差造成的位置误差越大）；
- φ 只是 E 的一个因子（sin φ），丢掉 d₁、d₂ 两个尺度因子会得出错误结论（例如"把 S₂ 放得越远越好"）。

### 3.2 为什么用 E = ε√(d₁²+d₂²)/sin φ

**动机起点**：一条方位线若有角误差 ε，其**横向位置偏移**为 `d·ε`（半径乘角）。两条线的交点位置由两条线的位移合成，夹角 φ 使位移被 `1/sin φ` 放大。

```
E ≍ ε_rad · √(d₁² + d₂²) / sin φ
```

**三个因子各有明确含义**：
| 因子 | 含义 |
|---|---|
| ε_rad | 观测精度（题设固定 1°） |
| √(d₁²+d₂²) | 两个测点的**尺度因子**（越远越差） |
| 1/sin φ | **几何放大因子**（即 GDOP 的两站特例） |

**性质**（用于优化）：
- 固定 b，E 是 Δ² 的单调增函数 ⇒ **Δ=0 最优**（命题 C.1）；
- 固定 Δ=0，E = √(d₁²+b²) 关于 |b| 单调增 ⇒ **b 尽量小**（受 b_min 与可探测约束限制）。

### 3.3 为什么用 Q1 的 D 做交叉验证

E 是小角近似，D 是精确几何量。**两者必须同量级**（断言 7）。若不一致 ⇒ 要么近似失效（φ 太小），要么几何模块有 bug。**双度量互验是免费的正确性检查**。

**论文定位**：E 用于**优化与解析推导**（闭式、可求导、可写给评阅）；D 用于**最终结果验证与可视化**（Q1 的严格几何）。

### 3.4 为什么目标里不含"移动成本"

题面只问"定位效果好"。移动成本属于 Q3 的效率考量。但**论文应顺带说明**：候选区域内 |S₁S₂| 的差异（本算例 976→1004 m，差 27 m ≈ 5.5 s）很小，故按定位质量优先选择不影响后续效率。

## 四、策略（算法）选择的合理性

### 4.1 为什么不需要启发式算法

| 问题特征 | 结论 |
|---|---|
| 决策空间是 ℝ²（连续、二维） | 可用解析/网格法 |
| E 光滑、无局部极小 | 不需要全局搜索 |
| 有闭式最优条件（a = d₁） | 一个自由度（b）的区间问题 |
| 鲁棒化后约束是两条不等式 | 直接解出区间 |

**因此推荐流程（无启发式）**：
```
1. 由 S₁、θ₁、目标圆域 ⇒ d̂, Δd
2. a = d̂                                  （最优性条件）
3. b_min = Δd·tan φ_min ；b_max = √(R²−Δd²)
4. 若 b_min > b_max → 报"不可行"，回退给出 φ_min^max = arccos(Δd/R)
5. 输出候选区域 S₂ = S₁ + d̂·u + b·v, b ∈ ±[b_min, b_max]
```

### 4.2 为什么用"网格扫描"做验证而非求解

网格扫描 (a,b) 平面上 E 的等高线，用途是：
1. **可视化**候选区域（论文主打图）；
2. **验证**命题 C.1（数值极小点应在 a = d₁）；
3. **检查**约束边界的正确性。

**求解靠闭式，验证靠扫描** —— 两者的角色不能颠倒（扫描求解既慢又不精确）。

### 4.3 为什么 φ_min 要作为可调参数而非固定值

φ_min 是**设计者的选择**：取大（要求高）⇒ 可行域窄甚至不可行；取小（要求松）⇒ 定位差。**正确做法是给出权衡曲线**（C.3 的 φ_min^max vs Δd 表），让读者看到"给定先验能保证多好的角度"，而不是擅自替题目定一个值。

**论文写法**：主结果给"在 Δd=747.5 下取 φ_min=40°（接近可行上限）"，并附权衡曲线说明其他取值的代价。

### 4.4 为什么 R 取最坏值 1000 而非期望值

| 策略 | 后果 |
|---|---|
| 按 R=1500 设计 | 候选区域宽（b_max=1301），但若该源实际 R=1000，**S₂ 可能收不到信号** ⇒ 策略失败 |
| **按 R=1000 设计** | 候选区域窄，但**保证一定收得到** ⇒ 鲁棒 |

**纪律**：与 Q3"确保所有干扰源被清除"的硬要求一致 —— **"确保"优先于"可能更好"**。这个纪律在 Q2 就要确立。
