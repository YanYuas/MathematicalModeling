## 5. 第四层：方向偏差 α 的鲁棒性（P1）—— ❌ 不通过（本报告的核心）

### 5.1 编程手两个反例：**复现一致**

| 反例 | 配置 | 编程手报 | 独立复算 |
|---|---|---|---|
| 角度失保 | `b=b_min, d=1500, α=+1°` | d₂=959.00, γ=39.81° | **d₂=958.9963, φ=39.8106°** ✓ |
| 距离失保 | `b=b_max, d=1500, α=−1°` | d₂=1017.41 | **d₂=1017.4098** ✓ |

### 5.2 补正：**反例1 的违反程度被低估**

编程手取 `r = 1500` 展示，但**角度约束的最坏 `r` 是 `r = 5`**（分子与 `r` 无关 ⇒ 最坏 `r` = 使 `d₂` 最大的端点）：

```
b = 627.227, α = +1°：
   r = 1500 ⇒ φ = 39.8106°   ← 编程手报的值
   r =    5 ⇒ φ = 38.9960°   ← 真实最坏（差 40° 达 1.004°）
```
⇒ **反例成立，且比编程手报的更严重**（保守起见应报 38.996°）。

### 5.3 结构性发现：两个约束的最坏 α **方向相反**

| `b` | α=+1° | α=0° | α=−1° |
|---|---|---|---|
| 627.227 | 保证 φ=**38.996°** / max d₂=975.736 | φ=40.000° / d₂=975.792 | φ=40.166° / d₂=**992.650** |
| 664.262 | φ=40.622° / d₂=999.943 | φ=41.626° / d₂=1000.000 | φ=41.736° / d₂=**1017.410** |

**机理**：`sinφ 的分子 = |a·sinα − b·cosα|` 中，`b·cosα` 随 `|α|` 增大而**减小**（利于不失保），
而 `a·sinα` 的符号随 `α` 翻转 ⇒ **α > 0 使分子变小（角度约束变紧）、α < 0 使分子变大（角度约束变松）**；
`d₂` 则相反（`a·cosα + b·sinα` 随 `α` 减小而减大 ⇒ α<0 使 `d₂` 变大）。
⇒ **角度约束最坏出现在 α=+ε；距离约束最坏出现在 α=−ε。**

### 5.4 α 修正后的边界（`a = d̂ = 752.5`）

```
b_min(φ ≥ 40°)   = 650.00 m      （原闭式解 627.227）
b_max(d₂ ≤ 1000) = 638.00 m      （原闭式解 664.262）
⇒ b_min > b_max ⇒ 【可行域为空集：φ_min = 40° 下不存在候选区域】
```

### 5.5 二维扫描：**目标 40° 不可达**，最大可保证 **39.6161°**

在 `(a,b)` 平面上（`a ∈ [700,821]` 细网格 + 局部 0.25 m 细化），对 α ∈ [−1°,1°]（801 点）与
`r ∈ {5,1500}` 取最坏：

```
α = ±1° 下【可保证的最大交会角】 = 39.6161°   在 (a,b) = (764.00, 651.00)
   此时四个最坏情形同时逼近边界：d₂(α=−1°,r=5) = 999.998、d₂(α=+1°,r=5) = 999.885
                                 φ(α=+1°,r=5)  = 39.6161°（约束主作用）
α = 0 时（Q2 原声称）            = 41.6257°
⇒ 代价 2.0096°
满足 φ ≥ 40° 且 d₂ ≤ 1000 的 (a,b) 个数：0
```

**⇒ 结论：Q2 在其自身声明的模型（`U` 含 ±1° 楔形）下，目标 `φ_min = 40°` 无解；
可保证的上限是 39.6161°，且最优设计退化为一个点（不再是"区域"）。**

### 5.6 对 Q2 结论的影响（须重述）

| 原表述 | 修正后 |
|---|---|
| `b_min = Δd·tan φ_min = 627.23`、`b_max = 664.26` | 该闭式解**仅对 α=0 成立**；α 修正后 `b_min=650.00 > b_max=638.00` ⇒ **空集** |
| `φ_min ≤ arccos(Δd/R) = 41.63°`（"信息量的硬限制"） | 该上界**只来自源距未知**；叠加 α 后真实上限 **39.6161°** |
| "候选区域 `b ∈ ±[627.23, 664.26]`" | **φ_min=40° 下不存在**；若接受 39.6161°，退化为孤立点 `(a,b)=(764,651)` |
| "**鲁棒**最优选点" | 应改为"**中线理想模型（α=0）**下的条件最优 + 中点对准策略" |

**论文写作建议**：把这一条**正面写**——"**源距未知（Δd）与示向度误差（α）是两个独立的信息缺口，
前者给出 `arccos(Δd/R)` 的上界，后者再削去约 2°**"，比藏起来强得多；这也与 Q1 的"有界不确定性"叙事一致。

## 8. 第七层：实现层 —— ⚠️ 1 处帧错误

编程手结果汇总写：Q1 基准行"`E` 计算为 inf（**因为 b=0，S2 在 x 轴上**，属于退化情况）"。

**核对**：Q1 基准的 S₂=(600,0) 在 **Q2 局部系**（`u` 沿 θ₁=59.036°）下应为
`a = 308.70`、`b = −514.49` —— **b ≠ 0，不是退化**。
`E = inf` 的真实原因是**把世界坐标 `(600,0)` 直接喂进了要求 `(a,b)` 局部坐标的 `E` 函数**
（于是 `b = 0` ⇒ `E → ∞`）。⇒ **帧错误 + 归因错误**。
**影响范围**：仅 Q1 基准那一行（其 Q2 候选行的 `E` 值经反算 ρ=2.244 与 D=35.414 自洽，正确）。
**处置**：`E` 入口加"世界坐标 → 局部坐标"的归约调用（Q2 清单已要求 `to_local/to_world` 往返恒等，应加断言）。
