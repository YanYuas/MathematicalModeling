## 0. 一句话定位

**Q2 = 用一条示向度做"下一个观测点"的最优实验设计（带未知源距**与示向度误差**的鲁棒版）。核心几何结论：使交会角 φ = 90° 的充要条件是 S₂ 落在"过源、垂直于视线"的直线上——即 S₂ 与源"正侧方"对齐。**候选区域（⚠️ 仅 `α = 0`）**：以 S₁ 为顶点、沿示向度伸到 d̂ 再横向偏移 b 的两条线段，`b ∈ [Δd·tan φ_min, √(R²−Δd²)]`。
**⚠️ 2026-09-11 联合校验修正**：把最坏化扩到完整楔形（`α ∈ [−1°,1°]`）后，**`φ_min = 40°` 下候选区域为空集**，可保证的最大交会角为 **39.6161°** —— 见 §4.8b。**

## 1. 题设逐词点透

> "已知某全向干扰源在一个检测点处测得的示向度，请给出第二个检测点的选择策略，以获得关于该干扰源较好的定位效果，并给出第二个检测点的候选区域。"

| 词 | 字面 | 点透（为什么重要） |
|---|---|---|
| "一个检测点…测得的示向度" | 只有 S₁ 和 θ₁ | **只有一个观测**。一条示向度只能确定一条射线，源在射线上的位置完全未知 ⇒ 单站无法定位。第二个点的全部价值就在"补上另一个方向约束" |
| "全向干扰源" | 360° 覆盖，无盲区 | **关键简化**：可探测性只取决于距离（|S₂−G| ≤ R），与方向无关。Q4 的定向源会把这条约束换成"且在 ±90° 扇区内" |
| "第二个检测点" | 再选一个点 | **这是一个实验设计问题**——选点发生在测量之前，只能依赖已有信息（S₁, θ₁, 误差界、接收半径范围、目标圆域） |
| "较好的定位效果" | 定性 | **必须量化**。"定位效果"= 交会区域的不确定度。Q1 已给出度量（区域直径 D）⇒ **Q2 的目标函数就是 Q1 的 D**。这是 Q1→Q2 的接口 |
| "候选区域" | 一个集合 | 答案不是"一个点"而是"一片区域"。**必须参数化给出**（而不是给个例子点），并说明区域边界由什么约束决定 |
| "（未给源距）" | 题面没说源多远 | **本问最大难点**：源在视线上的距离 d 完全未知，而最优选点依赖 d（见 §4.1）。**必须做鲁棒设计**，把"未知 d"变成"不确定区间 Δd" |

**点透结论**：Q2 是一个**带未知参数的鲁棒实验设计问题**。三个隐藏决策：(a) 用什么度量"定位效果好"（→ 用 Q1 的 D）；(b) 如何处理未知源距（→ Δd 区间 + 最坏情况）；(c) 候选区域怎么参数化（→ 沿示向度 + 横向偏移 b）。

## 2. 约束与条件点透

```
已知：S₁、θ₁（示向度）、ε = 1°（误差半角）
源的不确定集：
   U = { G : G ∈ W₁(θ₁±1°)  ∧  |S₁G| ∈ (5, R_max]  ∧  G ∈ 目标圆域 D((0,0),1800) }
   其中 R_max = 1500 m（S₁ 能测到说明 d₁ ≤ 该源的实际接收半径 ≤ 1500）
决策：S₂ ∈ ℝ²（在测量之前选定）
目标：minimize 定位不确定度（Q1 的 D，或其解析代理）
硬约束（S₂ 必须满足）：
   C1 可探测：|S₂ − G| ≤ R_worst = 1000 m（R 未知，取最坏下界）
   C2 非退化：两视线不共线（否则 φ = 0，零信息）
   C3 有效：仅依赖 S₁、θ₁ 可得的信息（不能假设已知 G 或 d）
```

**为什么约束这么写**：
- **R 取最坏 1000 而不是 1250 或 1500**：题目明确"有效接收半径在 1000 米到 1500 米之间"且**接口不返回**。要"确保"第二个点能收到信号，就必须按最小可能值 1000 设计。**这是 Q2 的第一个鲁棒性决策**（与 Q1 的 ε=1° 同理）。
- **C2 非退化的量化**：不是"不共线"就行，而是**交会角要足够大**（见 §4.3 的 φ_min）。
- **C3 是本质约束**：S₂ 在测量前选定 ⇒ 只能用先验信息。这一条把问题从"最优选点"变成"鲁棒选点"（**注意：是"鲁棒选点"而非"鲁棒最优"** —— 见 §4.5 的 `sup_d E` 反例与 §4.8b）。

## 3. 问题本质点透

- **为什么是实验设计不是估计**：估计是"拿到数据后算最优解"，实验设计是"**先决定怎么取数据**"。Q2 属于后者——选 S₂ 时还没有 S₂ 处的观测。
- **为什么不能"沿示向度前进"**（最常见的错误直觉）：
  > 若 S₂ = S₁ + a·u（只沿视线走，横向偏移 b = 0），则 S₁、S₂、G **三点共线**，两条视线**重合**，交会角 φ = 0 或 180° ⇒ **交会定位完全失效**（sin φ = 0，误差发散）。
  >
  > **结论：沿示向度前进对定位零信息增益。** 必须**横向偏移**。这是 Q2 最重要的单点结论，也解释了为什么 Q3 的"侦察"与"逼近"是两个不同动作。
- **与 Q1 的关系**：Q1 给定两点求区域直径 D；Q2 让 D 尽量小。**Q1 是评价函数，Q2 是优化问题**。
- **复杂度**：连续域上的**两变量（a, b）鲁棒优化**，目标函数光滑，有闭式最优性条件（a = d₁）。**不是 NP-hard，也不需要启发式**；难点在**鲁棒性建模**而非算法。
- **诚实边界**：由于 d 未知且区间宽（5–1500 m），最坏情况下能保证的交会角有限（φ_min ≤ 40° 量级）。**论文应如实说明这个极限**，而不是假装能保证 90°。

## 4. 数学结构点透（本问灵魂）

### 4.1 最优性条件：φ = 90° ⟺ S₂ "正侧方"（本问最漂亮的结论）

设 S₁ 在原点、示向度 θ₁ = 0°（不失一般性，坐标可旋转），源 G = (d₁, 0)，第二点 S₂ = (a, b)。

则：
```
G→S₁ = (−d₁, 0)，  G→S₂ = (a − d₁, b)
cos φ = (d₁ − a)/d₂,   sin φ = |b|/d₂,   d₂ = √((a−d₁)² + b²)
```

**结论**：
| 条件 | 几何含义 |
|---|---|
| **a = d₁** | ⟺ cos φ = 0 ⟺ **φ = 90°（最优）** |
| b = 0 | ⟺ sin φ = 0 ⟺ **φ = 0/180°（退化，零信息）** |
| a = 0, b ≠ 0 | S₂ 在 S₁ 正侧方，φ = arctan(\|b\|/d₁) |

**"a = d₁" 的几何读法**：S₂ 与源在**沿视线的同一深度**上，横向拉开。即 **S₂ 位于"过源、垂直于 S₁G"的直线上**。

**Thales 等价表述**（与 Q1 的工具接续）：∠S₁GS₂ = 90° ⟺ **G 落在以 S₁S₂ 为直径的圆上**。于是"选最优 S₂"⟺"选 S₂ 使该圆过源"。这是 Q1 的 Thales 定理在 Q2 的复用，两问数学工具一脉相承。

### 4.2 目标函数：Q1 的 D 的解析代理

Q1 已证定位区域直径 D 度量定位不确定度。对两站交会，小角近似给出**位置不确定度**：

```
E(S₂) ≍ ε_rad · √(d₁² + d₂²) / sin φ
       = ε_rad · √(d₁² + Δ² + b²) · √(Δ² + b²) / |b|
其中 Δ = d₁ − a（深度偏差），d₂ = √(Δ² + b²)
```

**推导依据**：一条方位线有角误差 ε 时，其横向偏移为 d·ε；两线夹角 φ 的相交点位移被 1/sin φ 放大 ⇒ 合成误差 ≈ ε·√(d₁²+d₂²)/sin φ。

**用 E 检验 §4.1**：
- 固定 b，对 Δ 求极小 ⇒ **Δ = 0（即 a = d₁）**，此时 E = √(d₁²+b²)；
- 再对 b 求极小 ⇒ **b 越小越好**（在可探测与非退化约束内）。

**点透**：解析代理 E 与 Q1 的 D 同源（都由 ε 和几何放大决定），且**给出闭式最优性条件**——这比"跑个数值优化"高一个层次。

### 4.3 鲁棒化：源距未知 ⇒ 区间 Δd

**唯一未知量是 d₁**。可得的信息：S₁ 能测到 ⇒ d₁ ≤ R_true ≤ 1500；且 d₁ > 5（否则返回 `near`）。故

```
d₁ ∈ (5, 1500]   ⇒   d̂ = 752.5 m（区间中点），Δd = 747.5 m（半径）
```

设 a = d̂（按估计对准），则**真实深度偏差 Δ = d₁ − d̂ ∈ [−Δd, +Δd]**。

**要求交会角不劣于 φ_min**（即 sin φ ≥ sin φ_min）：

```
sin φ = |b|/√(Δ² + b²) ≥ sin φ_min  ⟹  |b| ≥ |Δ|·tan φ_min
最坏取 |Δ| = Δd  ⟹  b_min = Δd · tan φ_min
```

**要求可探测**（|S₂ − G| ≤ R_worst）：

```
d₂ = √(Δ² + b²) ≤ R_worst = 1000  ⟹  b ≤ √(R_worst² − Δ²) ≤ √(R_worst² − Δd²)
⟹  b_max = √(1000² − Δd²)
```

### 4.4 可行性条件（本问最诚实的结论）

要求 b_min ≤ b_max：

```
Δd · tan φ_min ≤ √(R² − Δd²)
⟹ Δd² (tan²φ_min + 1) ≤ R²
⟹ Δd · sec φ_min ≤ R
⟹ Δd ≤ R · cos φ_min          ← 可行性条件
⟹ φ_min ≤ arccos(Δd / R)      ← 能达到的最小交会角
```

> **⚠️ 本小节的四个式子（含下面的 41.6°）只对 `α = 0` 成立** —— 见紧随其后的 **§4.8b**（联合校验修正）。

**含义**：**源距的不确定度 Δd 决定了你能保证的最好交会角**。Δd 越大，能保证的 φ 越小（定位越差）。

- 若 Δd = 747.5、R = 1000 ⇒ cos φ_min ≥ 0.7475 ⇒ **φ_min ≤ 41.6°**。即：**在完全不知道源距的情况下，最多只能保证约 40° 的交会角**。
- 若能缩小 d₁ 的范围（例如由场强估计、或已知源在圆域内某带），Δd 减小 ⇒ φ_min 增大 ⇒ 定位质量提升。
- **论文卖点**：把"源距未知"这个模糊困难，转成一条**定量可行性不等式** `Δd ≤ R·cos φ_min`。这是 Q2 从"定性讨论"跨到"定量结论"的关键一步。

### 4.8b ⚠️ 联合校验修正：α 缺口（**2026-09-11 补**）

> 来源：`建模手-联合校验报告.md`（建模手 × 编程手，含复现脚本 `_联合校验独立复算.py`）

**上面的 41.6° 上界只计入了一个不确定量（源距 Δd），漏了另一个：示向度误差 `α`。**

定义 `G = r(cosα, sinα)`（α 是真实示向度相对**测量值**的偏差，|α| ≤ 1°）。求 `sinφ` 的精确式：

```
sin φ = |a·sinα − b·cosα| / d₂ ,   d₂ = √(a²+b²+r² − 2r(a·cosα + b·sinα))
（α = 0 时退化为 F7 的 |b|/d₂ ✓）
```

**三条量化结论**：

| # | 结论 | 数值 |
|---|---|---|
| 1 | **两个约束的最坏 α 方向相反** | 角度约束最坏在 **α=+1°**；距离约束最坏在 **α=−1°**（因分子含 `−a·sinα` 与 `b·cosα` 两项，符号相反） |
| 2 | **α 修正后 `a = d̂` 处可行域为空** | `b_min(φ≥40°) = 650.00 m > b_max(d₂≤1000) = 638.00 m` |
| 3 | **可保证的交会角上限降至 39.6161°** | 在 `(a,b) = (764, 651)`；**φ_min = 40° 不可达**（穷举 0 解）；对比 α=0 的 41.6257° ⇒ **代价 2.0096°** |

**⇒ 修正三处表述**：
1. `φ_min^max` 的诚实上界应为 **39.6161°**（不是 41.63°）—— 它是**两个信息缺口的合成**：
   源距未知给出 `arccos(Δd/R)`，示向度误差再削去约 2°；
2. **候选区域 `b ∈ ±[627.23, 664.26]` 在 `φ_min=40°` 下不存在**；若接受 `φ_min = 39.6161°`，
   最优设计**退化为一个点**（不再是一段区域）；
3. "**鲁棒**最优选点"应改为"**中线理想模型（α=0）**下的条件最优 + 中点对准策略"
   （且 `a = d̂` 只保证"条件最优"而非"鲁棒最优"，见 §4.5 的 `sup_d E` 反例）。

**论文写法建议**：把这一条**正面写**——"源距未知与示向度误差是两个独立的信息缺口，
前者给出 `arccos(Δd/R)` 的上界，后者再削去约 2°"。这比藏在脚注里强得多，也与 Q1 的"有界不确定性"叙事一致。

## 5. 建模点透（每一步为什么）

### 5.1 为什么用 Q1 的 D 而不是自定义指标

| 候选指标 | 问题 |
|---|---|
| 交会角 φ | 只反映角度，不含距离尺度（无法比较"远源 90°"与"近源 80°"） |
| 面积/直径 D | **综合了 φ 与距离**，是 Q1 已有的严格度量 ✓ |
| 误差椭圆 | 需要概率模型（题设给的是有界误差，非分布） |
| **E ≍ ε√(d₁²+d₂²)/sinφ** | **D 的小角近似解析代理**，闭式、可优化 ✓ |

**选 E 作优化目标、用 Q1 的 D 做最终验证**——两者一致（E 是 D 的近似），互相校验。

### 5.2 为什么"正侧方"（a = d̂）是最优的对准方式

由 §4.2 的极小化：固定 b 时 Δ = 0 最优。而 Δ = d₁ − a，故 a = d₁。我们不知道 d₁，只能取最优估计 **a = d̂**。

**更深的解释**：a = d₁ 时，两视线正交，误差椭圆**各向同性**（两个方向的放大倍数都最小）。a ≠ d₁ 时误差椭圆被拉长——这正是 Q1 中"定位区域是沿某方向被拉长的细长四边形"的成因。

### 5.3 为什么候选区域是"两条线段"而不是"一整片"

因为 a 被**最优性条件唯一确定**（a = d̂），只剩横向偏移 b 一个自由度。b 的取值范围由两条约束夹出（下界管角度质量，上界管可探测性），且**正负对称**。

**推广（若允许 a 变动）**：若取 a ∈ [d̂ − a_span, d̂ + a_span]，其中 `a_span = R·cos φ_min − Δd ≥ 0`，则候选区域变成 (a,b) 平面上的**两片"翼形"区域**：

```
|a − d̂| ≤ a_span
m(a)·tan φ_min ≤ |b| ≤ √(R² − m(a)²),    m(a) = |a − d̂| + Δd
```

论文可给"简化版（两条线段）+ 完整版（两翼形）"两级答案。

### 5.4 为什么 R 取最坏 1000 会"浪费"性能

若实际接收半径是 1500，则 b 上限可达 √(1500²−Δd²) = 1301 m，候选区域宽得多。但**我们在选择 S₂ 时不知道 R**（接口不返回）。**"确保能收到"优先于"可能更好"**——这是 Q3"确保全部清除"硬要求的前置纪律，在 Q2 就要确立。

## 6. 陷阱点透（浓缩为机理）

| 陷阱 | 一句话机理 |
|---|---|
| T1 沿视线选点 | b = 0 ⇒ 三点共线 ⇒ φ=0 ⇒ **零信息**。最常见的错误直觉 |
| T2 用 R=1250/1500 设计 | R 未知且接口不返回，必须按**最坏 1000** 设计 |
| T3 假装知道源距 | d 未知是题设核心；假装知道 ⇒ 结论只在特定 d 下成立，无鲁棒性 |
| T4 只答一个点 | 题问"**候选区域**"，必须参数化给集合 |
| T5 忽略"选点在测量前" | 若用 G 的真值算 S₂ ⇒ 逻辑循环（那还定位什么） |
| T6 交会角只看"不共线" | 要够大（≥φ_min），否则 sinφ 小 ⇒ 误差发散 |
| T7 忘记 S₂ 也要能收到信号 | |S₂−G| ≤ R 是硬约束，决定 b 的上界 |
| T8 把 φ 的定义搞反 | φ 是**源处**两视线的夹角（∠S₁GS₂），不是 S₂ 处的角 |
| M1 目标函数用面积/距离混搭 | 量纲混乱；用 E（长度）统一 |
| M2 忽略 Δ 的符号 | Δ 可正可负，最坏要取 \|Δ\| = Δd |
| M3 声称能保证 90° | 源距未知时不可能；诚实给 φ_min ≤ arccos(Δd/R) |

（完整分级见 `Q2模型假设与陷阱深挖.md` + `Q2陷阱与几何拓展.md`）

## 9. 射影/非欧评估点透

**直接结论：射影几何不适用**（同 Q1，理由一致）：射影不保角度，而 Q2 的目标函数 `1/sin φ` **本质是角度度量**。非欧同样不适用（题设限定平面）。

**但有一个正向的"投影"澄清**（与 VLSI Q2 的手法一致）：
- 与 Q1 相同，本题的核心是**度量几何**（角度、距离、正弦律），不是交比结构；
- 可借用的"对偶"思想：把"选 S₂"看成"在 (a,b) 参数空间选点"，约束是两族曲线 —— 这是**参数空间视角**，不是射影变换。
- **圆几何（Thales）在本问再次成为正牌工具**（§4.1），进一步说明"圆几何才是本题的方法层"。

## 12. 开放问题（下一步验证）

1. **d₁ 的先验区间是否应更窄？** 若用目标圆域几何（S₁ 位置 + 半径 1800）可将 d₁ 限制在更小区间，Δd 减小 ⇒ φ_min 增大 ⇒ 定位更好。需按 S₁ 实际位置分情况讨论。
2. **是否利用 Q1 的"区域形状"而非仅 D？** Q1 指出区域是沿某方向拉长的四边形；其**最短方向**（⊥ 角平分线）正是最优移动方向 —— 可作为 S₂ 的解析答案的直接几何解释。
3. **多测点推广**：若允许选第 3、4 个点，Δd 会被进一步压小（多个方位线交会）——为 Q3 的多点交叉定位铺路。
4. **R 的不确定性**：本文按最坏 1000 设计；若愿意冒一定风险（按 1250 设计），候选区域会宽得多。需在论文中说明这一权衡。
