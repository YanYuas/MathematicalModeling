## 1. 题设精读

> "已知某全向干扰源在一个检测点处测得的示向度，请给出第二个检测点的选择策略，以获得关于该干扰源较好的定位效果，并给出第二个检测点的候选区域。"

**逐词拆解**：

| 词 | 含义 | 建模影响 |
|---|---|---|
| 一个检测点…测得的示向度 | 只有 S₁ 与 θ₁ | **单条方位线**：源在射线上的距离未知 ⇒ 单站不可定位 |
| 全向干扰源 | 360° 覆盖 | 可探测性只取决于距离 ⇒ 约束简单（Q4 才加方向） |
| 第二个检测点 | 再选一个点 | **实验设计**：选点在测量之前，只能用先验信息 |
| 较好的定位效果 | 定性 | 必须量化 ⇒ 用量 Q1 的 D（或其解析代理 E） |
| 候选区域 | 一个集合 | 答案必须**参数化**给出，不能只给一个点 |

**关键结论：Q2 = 带未知源距的鲁棒最优实验设计（两站方位定位）。** 连续二维决策、有闭式最优性条件、**不需要启发式**。

## 2. 参数事实（决定 Δd 的全部信息）

本题**无外部数据集**，Q2 的可量化事实只有"误差界"与"接收半径范围"两条：

| 参数 | 值 | 来源 | 对 Q2 的作用 |
|---|---|---|---|
| 误差半角 ε | 1° | 题设正文 | 目标函数 E 的尺度因子 |
| 有效接收半径 R | [1000, 1500]，每源不同，接口不返回 | 附录 2 §2.1 | 设计取 **R_worst = 1000** |
| 近距阈值 | 5 m | 附录 2 §2.4 | d₁ 的下界（>5 才有示向度） |
| 目标区域 | 半径 1800 m 圆域 | 题设正文 | 可进一步约束 d₁（可选） |
| 源距 d₁ 的可得范围 | **(5, 1500]** | 由上述两条推出 | ⇒ d̂ = 752.5，Δd = 747.5 |

**推导细节**：S₁ 返回的是 `direction`（不是 `near`、不是 `no_signal`）⇒ `5 < d₁ ≤ R_true ≤ 1500`。

**关键发现**：**Δd 的宽度（747.5 m）几乎等于 R_worst（1000 m）** ⇒ 由可行性不等式 `Δd ≤ R·cos φ_min`，交会角上界仅 **41.63°**。
**⚠️ v1.2.0 联合校验修正**：该 41.63° **只计入源距未知（Δd）**；计入示向度误差 `α ∈ [−1°,1°]` 后真实上界为 **39.6161°**，且 `φ_min=40°` 下候选区域为**空集**。**这才是本问真正最要命的数字。**

**1° 的横向放大（承 Q1）**：

| 测距尺度 | d·tan1° |
|---|---|
| 1000 m | 17.455 m |
| 1500 m | 26.183 m |

⇒ 两站交会的合成定位误差约 17 m（见 §3.5），与 20 m 清除半径同量级。

## 3. 数学建模

### 3.1 决策变量与坐标归约

取 S₁ 为原点、θ₁ 中线为 +x 轴（WLOG）。则：

```
决策：S₂ = S₁ + a·u + b·v      即 (a, b) ∈ ℝ²
其中 u = u(θ₁) 沿示向度中线，v = u(θ₁+90°) 为其左法向
```

### 3.2 交会角的三行关系式（全部推导的起点）

设源 G = (d₁, 0)，记 Δ = d₁ − a：

```
d₂  = √(Δ² + b²)
cos φ = Δ / d₂
sin φ = |b| / d₂
```

### 3.3 目标函数

```
E(S₂) ≍ ε_rad · √(d₁² + d₂²) / sin φ
       = ε_rad · √(d₁² + Δ² + b²) · √(Δ² + b²) / |b|
```

**物理三因子**：ε（观测精度）× √(d₁²+d₂²)（尺度）× 1/sin φ（几何放大，即两站 GDOP）。

### 3.4 最优性条件（本问核心）

**由 E 关于 Δ² 单调（因 Δ 只以 Δ² 出现）**：

```
固定 b 时，E 在 Δ = 0 处取唯一极小  ⟺  a = d₁
即：S₂ 与源"正侧方"对齐（S₂ 在过源、垂直于 S₁G 的直线上），此时 φ = 90°
```

**Thales 表述**：∠S₁GS₂ = 90° ⟺ G 落在以 S₁S₂ 为直径的圆上。

**退化**：b = 0 ⇒ sin φ = 0 ⇒ E → ∞ ⇒ **沿示向度前进对定位零信息增益**。

### 3.5 鲁棒化与候选区域

源距未知 ⇒ Δ ∈ [−Δd, Δd]（Δd = 747.5）。取 a = d̂ = 752.5 后：

```
角度质量约束  : sin φ ≥ sin φ_min  ∀Δ   ⇒  |b| ≥ Δd·tan φ_min   = b_min
可探测约束    : d₂ ≤ R_worst       ∀Δ   ⇒  |b| ≤ √(R_worst²−Δd²) = b_max
```

**候选区域（简化版）**：

```
A = { S₁ + d̂·u + b·v : b ∈ ±[b_min, b_max] }        —— 两条对称线段
```

**候选区域（完整版，允许 a 偏离 d̂）**：

```
A' = { S₁ + a·u + b·v : |a − d̂| ≤ a_span,
                          m(a)·tan φ_min ≤ |b| ≤ √(R² − m(a)²) }
其中 a_span = R·cos φ_min − Δd,  m(a) = |a − d̂| + Δd   —— 两片"翼形"
```

### 3.6 可行性（本问最诚实的结论）

```
b_min ≤ b_max  ⟺  Δd ≤ R_worst · cos φ_min
⟺  φ_min ≤ arccos(Δd / R_worst)
```

本算例：`arccos(747.5/1000) = 41.63°`（**仅 α=0**）⇒ **叠加 α 后 39.6161°** ⇒ **无论第二个点怎么选，最多只能保证约 39.6° 的交会角。**

**这不是算法不足，是信息量的硬限制**：单条方位线不含距离信息，能补的方向信息有限。突破途径：额外距离信息（场强估计 / 多点连续测量 / 目标区域几何先验）。

## 4. 策略设计（无启发式）

### 4.1 求解流程（闭式）

```
1. 由 S₁、θ₁、先验 ⇒ d̂ = 752.5, Δd = 747.5
2. a = d̂                                    （最优性条件，命题 C.1）
3. b_min = Δd·tan φ_min
   b_max = √(R_worst² − Δd²),  R_worst = 1000
4. 若 b_min > b_max → 报"不可行"，回退给出 φ_min^max = arccos(Δd/R)
5. 输出 A = {(d̂, ±b) : b ∈ [b_min, b_max]}（简化版）
         + A'（翼形完整版，作一般性展示）
```

### 4.2 为什么不需要模拟退火/遗传算法

| 问题特征 | 结论 |
|---|---|
| 决策空间 ℝ²，连续 | 可解析求解 |
| E 光滑、无局部极小（关于 Δ² 单调） | 无需全局搜索 |
| 有闭式最优条件 | 自由度降为 1（只有 b） |
| 约束是两条不等式 | 直接解区间 |

**用启发式解 Q2 = 用大炮打蚊子**，且会让评阅怀疑你没识别出问题类型。

### 4.3 φ_min 与 R 的选择纪律

| 参数 | 选择 | 理由 |
|---|---|---|
| φ_min | **作为可调参数**，给权衡曲线 | 取大⇒可行域窄甚至空；取小⇒定位差。应展示而非独断 |
| R_worst | **1000（最坏）** | "确保 S₂ 能收到"优先于"可能更好"（与 Q3 的硬要求一致） |

### 4.4 验证方式（无真值，靠双度量互验）

```
E  （解析近似）  ← 优化与推导
D  （Q1 精确几何）← 验证：ρ = D/E 应 ∈ [0.5, 2]
网格扫描 (a,b)    ← 可视化 + 验证 E 的极小点在 a = d̂
```

## 6. 几何创新点（论文展示素材）

1. **正侧方最优性定理**：φ=90° ⟺ a = d₁ 的闭式条件。把"选个好的第二点"变成一条可证明的几何命题。**本问最大卖点。**
2. **Thales 接续 Q1**：最优 S₂ ⟺ 以 S₁S₂ 为直径的圆过源。两问共用圆几何工具，论文叙事一脉相承。
3. **反直觉结论：沿视线前进零信息**：证伪最常见的错误直觉（b=0 ⇒ 三点共线 ⇒ 无交会），并直接解释 Q3 中"侦察"与"逼近"是两种动作。
4. **未知源距的鲁棒化**：Δd 区间 + 最坏取界 ⇒ b_min = Δd·tanφ_min（角度质量）与 b_max = √(R²−Δd²)（可探测）。
5. **可行性不等式 Δd ≤ R·cos φ_min**：把"能保证多好的交会角"写成闭式。**⚠️ v1.2.0：该单式只在 α=0 成立**；计入 α 后须拆为双约束组，天花板由 41.63° 降为 **39.6161°**（`φ_min=40°` 不可达）。**本问最诚实也最有分量的结论。**
6. **候选区域参数化（两级）**：线段版（a 锁定）直接可编程；翼形版（a 可动）展示一般性。
7. **双度量互验**：E（解析，小角近似）与 Q1 的 D（精确几何）互相校验。
8. **GDOP 接口**：`1/sin φ` 是两站几何稀释因子的特例，接上 `01_背景研究/背景全量研究报告.md` 的 CRLB 文献（Gavish & Weiss 1992）。

## 8. 一句话总结

**Q2 = 用一条方位线设计第二条的最优实验设计。** 三行关系式给出一切：**a = d₁ ⇒ φ=90°（正侧方最优）**、**b = 0 ⇒ 零信息（沿视线前进无用）**、**Δd ≤ R·cos φ_min ⇒ 交会角有硬天花板 41.63°**（**仅 α=0**；含 α 为 **39.6161°**）。前两条给策略，第三条给诚实边界。全题无启发式、无概率假设，**难点在鲁棒性建模而非算法**。
