## 一、坐标归约与参数化

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F1 | 坐标归约 | 取 S₁ 为原点、θ₁ 中线为 +x 轴（旋转+平移，不失一般性） | 推导用；实现时最后旋转回原坐标 |
| F2 | 方向基 | `u = u(θ₁) = (cos θ₁, sin θ₁)`；`v = u(θ₁ + 90°)` | u 沿示向度中线，v 为其左法向 |
| F3 | 候选点参数化 | `S₂ = S₁ + a·u + b·v` | **决策变量 = (a, b)** |
| F4 | 深度偏差 | `Δ := d₁ − a` | Δ 的**符号**任意；|Δ| 是鲁棒化的对象 |
| F5 | 第二点距离 | `d₂ = √(Δ² + b²)` | 同时进入目标与可探测约束 |

## 二、交会角关系（全部推导的起点）

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F6 | 交会角余弦 | `cos φ = (d₁ − a)/d₂ = Δ/d₂` | φ = ∠S₁GS₂（**源处**两视线夹角） |
| F7 | 交会角正弦 | `sin φ = \|b\|/d₂` | 一眼看出 b=0 ⇒ 退化 |
| F8 | **正交最优性** | `φ = 90° ⟺ a = d₁`（Δ=0） | **本问最核心的结论**；几何含义 = S₂ 与源"正侧方"对齐 |
| F9 | 退化条件 | `b = 0 ⟺ sin φ = 0` | 三点共线，零信息；必须排除 |
| F10 | 一般情形 | `φ = arctan(\|b\|/Δ)`（Δ>0）；`φ = 90° + arctan(Δ/\|b\|)`（Δ<0） | 完整分段表达 |

## 三、目标函数

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F11 | **位置不确定度（解析代理）** | `E(S₂) ≍ ε_rad · √(d₁² + d₂²) / sin φ` | 两条方位线误差经 1/sinφ 放大后合成 |
| F12 | E 的展开式 | `E = ε_rad · √(d₁² + Δ² + b²) · √(Δ² + b²) / \|b\|` | 优化用的显式形式 |
| F13 | 最优情形（Δ=0） | `E = ε_rad · √(d₁² + b²)` | 关于 \|b\| 单调增 ⇒ b 越小越好 |
| F14 | 几何放大因子 | `GDOP_2 = 1 / sin φ` | 定位文献中 GDOP 的两站特例 |
| F15 | 定位区域直径（Q1，交叉验证用） | `D = max{‖p−q‖ : p,q ∈ L}`，L = 两角域之交 | 与 E 必须同量级（断言7） |

## 四、鲁棒化（未知源距 → 区间）

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F16 | 源距可行区间 | `d₁ ∈ (d_lo, d_hi] = (5, 1500]` | 下界：>5 否则返回 `near`；上界：接收半径最大值 |
| F17 | 区间中点与半宽 | `d̂ = (d_lo + d_hi)/2 = 752.5`；`Δd = (d_hi − d_lo)/2 = 747.5` | 最坏取 `\|Δ\| = Δd` |
| F18 | **角度质量下界**（**仅 α=0**） | `b_min = Δd · tan φ_min` | 由 `sin φ ≥ sin φ_min` 对最坏 Δ 解出。**⚠️ v1.2.0：对 α 不成立** ⇒ 见 F21b/F21c |
| F19 | **可探测上界**（**仅 α=0**） | `b_max = √(R_worst² − Δd²)`，`R_worst = 1000` | 由 `d₂ ≤ R_worst` 对最坏 Δ 解出。**⚠️ v1.2.0：对 α 不成立** |
| F20 | **可行性不等式**（**仅 α=0**） | `b_min ≤ b_max ⟺ Δd ≤ R_worst · cos φ_min` | **仅在 α=0 时两约束可合并为单式**；α≠0 须拆回双约束组（F21b/F21c） |
| F21 | 可达角度上界（**仅 α=0**） | `φ_min^max = arccos(Δd / R_worst)` | 本算例 = 41.63°。**⚠️ v1.2.0：此式只计入源距未知 Δd，未计入示向度误差 α** ⇒ α 修正后真值 **39.6161°**（见 F21b） |
| **F21b** | **α 修正后的可达角度上界（v1.2.0 补）** | `φ_min^max = max over (a,b) of min over (α∈[−1°,1°], r∈{5,1500}) of arcsin(\|a·sinα − b·cosα\|/d₂)`，约束 `max d₂ ≤ R_worst` | **= 39.6161°**（在 `(a,b)=(764,651)`）；**φ_min=40° 不可达**；两个约束的最坏 α 方向相反（角度↔+1°，距离↔−1°）。见 `建模手-联合校验报告.md` |
| **F21c** | α 下 `a=d̂` 处的修正边界 | `b_min(φ≥40°)=650.00 > b_max(d₂≤1000)=638.00` | ⇒ **空集**（原 627.23/664.26 仅对 α=0 成立） |

## 五、候选区域

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F22 | **简化版（两条线段）** | `A = { S₁ + d̂·u + b·v : b ∈ [±b_min, ±b_max] }` | a 由最优性条件锁定为 d̂，只剩 b |
| F23 | 完整版（双翼形） | `A' = { S₁ + a·u + b·v : \|a − d̂\| ≤ a_span, m(a)·tan φ_min ≤ \|b\| ≤ √(R² − m(a)²) }` | 允许 a 偏离 d̂ |
| F24 | a 的可动幅度 | `a_span = R_worst·cos φ_min − Δd ≥ 0` | 非负才可行 |
| F25 | 深度裕度函数 | `m(a) = \|a − d̂\| + Δd` | 对给定 a 的最坏深度偏差 |

## 六、几何与成本

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F26 | **Thales 选点条件** | `∠S₁GS₂ = 90° ⟺ (G − S₁)·(G − S₂) = 0` | 等价于 G 落在以 S₁S₂ 为直径的圆上 |
| F27 | 圆方程形式 | `‖G − (S₁+S₂)/2‖ = ‖S₁S₂‖/2` | 与 F26 等价，便于绘制 |
| F28 | 移动距离 | `L = ‖S₂ − S₁‖ = √(d̂² + b²)`（简化版） | 与 a 有关的一般式 `√(a²+b²)` |
| F29 | 移动耗时 | `t_move = L / 5`（秒，速度 5 m/s） | Q3 的成本接口 |
| F30 | Q1 的横向偏移（复用） | `Δ_perp = d · tan(ε)` | 1° 在千米尺度放大：1000m→17.455m |
| F31 | 候选区域宽度 | `w = b_max − b_min` | 本算例 41.93 m |
| F32 | 可探测余量 | `slack = R_worst − √(Δd² + b²)` | b=b_min 时 = 27.5 m |
| F33 | 最坏交会角（给定 b） | `φ_worst(b) = arcsin( b / √(Δd² + b²) )` | 用于校验候选区域 |
| F34 | E 与 D 的一致性比（**v1.1.0 修正**） | `ρ = D / E`；**实测 ρ ≈ 2.2~2.4**（Q1 基准 2.43、Q2 候选 2.23~2.24）；`ρ = 2` 是 φ=90° 对称构型的**精确值**，一般 φ 下 `ρ > 2` | ~~断言7 的 `[0.5, 2]` 已作废~~：⇒ **改为分别报告 D 与 E**，不用比值做互验 |

## 公式索引速查

```
参数化： S₂ = S₁ + a·u + b·v  [F3]，  Δ = d₁ − a  [F4]，  d₂ = √(Δ²+b²)  [F5]
交会角： cos φ = Δ/d₂  [F6]；  sin φ = |b|/d₂  [F7]
核心：   φ=90° ⟺ a=d₁  [F8]（正侧方）；  b=0 ⟺ 退化  [F9]
目标：   E ≍ ε√(d₁²+d₂²)/sinφ  [F11]，与 Q1 的 D  [F15] 互验
鲁棒：   b_min = Δd·tanφ_min  [F18]；  b_max = √(R²−Δd²)  [F19]
可行性： Δd ≤ R·cos φ_min  [F20] ⟹ φ_min^max = arccos(Δd/R)  [F21]   ⚠️ 仅 α=0
含 α：  b_min=650.00 > b_max=638.00 ⇒ 空集 [F21c]；φ_min^max = 39.6161°  [F21b]
候选区： 两条线段  [F22]｜双翼形  [F23]
Thales： (G−S₁)·(G−S₂)=0  [F26]
```
