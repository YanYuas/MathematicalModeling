## A. 问题的严格形式化

### A.1 记号

| 符号 | 含义 | 定义域 |
|---|---|---|
| S₁, S₂ | 第一/第二检测点 | ℝ² |
| θ₁ | 在 S₁ 处测得的示向度 | [0°,360°) |
| ε | 示向度误差半角 | 1° |
| W₁ | S₁ 处的角域（楔形） | ℝ² |
| G | 干扰源真位置（未知） | ℝ² |
| d₁ = \|S₁G\| | 源距（未知） | (5, 1500] |
| d₂ = \|S₂G\| | 第二点到源距离 | ℝ≥₀ |
| φ | **源处**两视线夹角 ∠S₁GS₂ | [0°,180°] |
| R | 源的（该源实际的）有效接收半径 | [1000,1500]（未知） |
| R_worst | 设计用最坏接收半径 | **1000 m** |
| u, v | 沿/垂直示向度中线的单位向量 | u=u(θ₁)，v=u(θ₁+90°) |
| a, b | S₂ 在 (u,v) 基下的坐标 | ℝ |

### A.2 源的不确定集（Q2 的核心对象）

```
U = { G : G ∈ W₁(θ₁±1°)  ∧  |S₁G| ∈ (5, R_max]  ∧  G ∈ D((0,0),1800) }
```

- `G ∈ W₁`：源在角域内（θ₁ 有 ±1° 误差）；
- `|S₁G| ∈ (5, R_max]`：S₁ 测到的是 `direction` ⇒ 源不超过 S₁ 的接收半径，且大于 5 m（否则返回 `near`）；
- `R_max = 1500 m`：题设接收半径上界；
- `D((0,0),1800)`：目标区域（若题目限定）。

**坐标约定**：本文一律取 S₁ 为原点、θ₁ 的中线为 +x 轴（即 u = (1,0)，v = (0,1)）。这不失一般性——任何实际输入可先做一次旋转+平移归约。

### A.3 决策变量与目标

```
决策：S₂ = (a, b) ∈ ℝ²      （在测量之前选定，只能用先验信息）
目标：minimize E(S₂)         （定位不确定度）
约束：
  C1  可探测   : ∀G ∈ U,  |S₂ − G| ≤ R_worst = 1000
  C2  非退化   : ∀G ∈ U,  sin φ(G; S₂) ≥ sin φ_min
  C3  可先行   : S₂ 不得依赖 G 的真值
```

### A.4 关键几何关系（推导起点）

对任意 G = (d₁, 0)（即 Δ 记法下的情形）与 S₂ = (a, b)：

```
d₂  = √((a−d₁)² + b²) = √(Δ² + b²),      Δ := d₁ − a
cos φ = (d₁ − a)/d₂ = Δ/d₂
sin φ = |b|/d₂
```

**这三行是全部后续推导的基础**（F4-F6）。

## B. 论文引理草稿（"模型建立"节素材）

### L1 正交最优性引理
> 给定 d₁ 与 |b|，`cos φ = (d₁−a)/d₂` 中令 a 变化：E 关于 Δ = d₁ − a 在 Δ = 0 处取唯一极小。
> **推论**：**最优 S₂ 满足 a = d₁**，即 S₂ 落在"过 G 且垂直于 S₁G"的直线上（S₂ 与源"正侧方"对齐）。

### L2 Thales 等价
> ∠S₁GS₂ = 90° ⟺ G 落在以 S₁S₂ 为直径的圆上（Thales 定理）。
> **推论**：选最优 S₂ ⟺ 选 S₂ 使"以 S₁S₂ 为直径的圆"过源。

### L3 退化引理
> 若 b = 0，则 S₁、S₂、G 共线，两条示向度射线重合 ⇒ sin φ = 0 ⇒ 定位不确定度发散。
> **推论**：**沿示向度方向前进对定位零信息增益**；必须横向偏移。

### L4 位置不确定度解析式（小角近似）
> 两条方位线各有角误差 ε，线 i 的横向偏移为 d_i·ε；两线夹角 φ 处交点位移被 1/sin φ 放大。合成得
> `E(S₂) ≍ ε_rad · √(d₁² + d₂²) / sin φ = ε_rad · √(d₁² + Δ² + b²) · √(Δ² + b²) / |b|`
> **性质**：固定 b 时 E 在 Δ=0 取极小；固定 Δ=0 时 E = √(d₁²+b²) 关于 |b| 单调增。

### L5 鲁棒下界（角度质量约束）—— **⚠️ 仅对 α = 0（中线理想模型）成立**
> 设 d₁ 的不确定半径为 Δd（即 |Δ| ≤ Δd）。要求 ∀Δ, sin φ ≥ sin φ_min，则
> `|b| ≥ Δd · tan φ_min`，即 **b_min = Δd·tan φ_min**。
> **限定（2026-09-11 联合校验修正）**：本式把源放在测量中线上（方向偏差 `α = 0`）。
> 完整楔形下须改用 **L5'**（见下方 L5'/L6'/L7'）；数值后果见该节的表。

### L6 可探测上界约束 —— **⚠️ 仅对 α = 0 成立**
> 要求 ∀Δ, d₂ ≤ R_worst，则 `b² ≤ R_worst² − Δd²`，即 **b_max = √(R_worst² − Δd²)**。
> **限定**：同 L5，完整楔形下须改用 **L6'**。

### L7 可行性不等式 —— **⚠️ 仅对 α = 0 成立**
> 候选区域非空 ⟺ `Δd · sec φ_min ≤ R_worst` ⟺ **`Δd ≤ R_worst · cos φ_min`**。
> **限定（2026-09-11 联合校验修正）**：本式是**单约束**形式，它把"角度质量"与"可探测"两条约束
> **合成了一个**——这一步**只在 `α = 0` 时成立**。计入 α 后两条约束**不再可合并**，
> 须用 **L7'（双约束组）**；数值后果是交会角上限由 41.6257° 降到 **39.6161°**（见 L7'）。
> 等价地，**在源距不确定半径为 Δd 时能保证的最小交会角上界为 `φ_min ≤ arccos(Δd / R_worst)`**。

### L5' / L6' / L7' 完整楔形版（**v1.1.0 补，2026-09-11 联合校验**）

> 来源：`建模手-联合校验报告.md`；复现：`_联合校验独立复算.py`。
> **触发**：编程手 Q2 实现发现——原闭式解对方向偏差 `α` 不成立（两个反例）。

**精确化**：设 `G = r(cosα, sinα)`（`r ∈ (5, R_max]`，`|α| ≤ ε = 1°` 为真实示向度相对**测量值**的偏差）：

```
sin φ = |a·sinα − b·cosα| / d₂ ,     d₂ = √( a² + b² + r² − 2r(a·cosα + b·sinα) )
```
`α = 0` 时分子退化为 `|b|`、`d₂` 退化为 `√(Δ²+b²)` ⇒ **L5/L6/L7 全部还原** ✓

**结构（两条关键事实）**：
1. **分子与 `r` 无关**；**`d₂²` 关于 `r` 是开口向上的抛物线** ⇒ 区间 `[5, R_max]` 上最坏 `r` **必在端点**（`r ∈ {5, R_max}`）；
2. **两个约束的最坏 `α` 方向相反**：角度约束最坏在 `α = +ε`，距离约束最坏在 `α = −ε`
   （因分子含 `−a·sinα` 与 `b·cosα` 两项，前者随 `α` 减、后者随 `|α|` 减）。

**⇒ C1/C2 等价于一组"端点 × α"的联合不等式**：

```
(L5') 角度：∀α ∈ [−ε,ε]:  |a·sinα − b·cosα| ≥ sin φ_min · max{ d₂(5,α), d₂(R_max,α) }
(L6') 距离：∀α ∈ [−ε,ε]:  max{ d₂(5,α), d₂(R_max,α) } ≤ R_worst
(L7') 可行：`b_min^{α} ≤ b_max^{α}`（两界分别由 L5'/L6' 解出；**不可再合并为单式**）
```

**数值（Q2 设定：`a = d̂ = 752.5`、`Δd = 747.5`、`R_worst = 1000`、`φ_min = 40°`、`ε = 1°`）**：

| 量 | α = 0（原闭式解） | **α ∈ [−1°,1°] 修正** |
|---|---|---|
| `b_min` | 627.227 m | **650.00 m** |
| `b_max` | 664.262 m | **638.00 m** |
| 判定 | 可行（带宽 37.03 m） | ❌ **`b_min > b_max` ⇒ 空集** |

**⇒ 全局结论（命题 L7'-max）**：把 C1/C2 的最坏化范围扩到完整楔形后，
本问**能保证的最大交会角**为

```
φ_min^max(α) = max_{a,b}  min_{α∈[−ε,ε], r∈{5,R_max}}  arcsin( |a·sinα − b·cosα| / d₂ )
               s.t.  max d₂ ≤ R_worst
本算例： 39.6161°   在 (a,b) = (764, 651)
对照： α = 0 时 41.6257°  ⇒ 代价 2.0096°
```
且 **`φ_min = 40°` 不可达**（在 `(a,b)` 网格上穷举 0 解）。

**⇒ 三点重述**：
1. `φ_min^max` 的诚实上界是 **39.6161°**（不是 41.63°）——它是**两个信息缺口的合成**：
   源距未知给出 `arccos(Δd/R)`，示向度误差再削去约 2°；
2. **候选区域在 `φ_min = 40°` 下不存在**；若接受 `φ_min = 39.6161°`，最优设计**退化为一个点**（不再是线段）；
3. "**鲁棒**最优选点"应改述为"**中线理想模型（α = 0）**下的条件最优 + 中点对准策略"。

**判据的严格性**：L5'/L6' 用的是**端点判据**（分子的 `r` 无关性 + `d₂²` 的抛物线端点性），
**是精确判据、不是网格采样** ⇒ "不可达"不是"采样没找到"。

## C. 两个核心命题的完整证明

### C.1 命题一：正交最优性（a = d₁）

**陈述**：固定 d₁ 与 |b| > 0，E(a) 在 a = d₁ 处取唯一极小。

**证明**：
在 S₁ 为原点、源为 G=(d₁,0) 的坐标下，S₂ = (a,b)，Δ = d₁ − a，d₂ = √(Δ²+b²)。

```
E(a) = ε_rad · √(d₁² + Δ² + b²) · √(Δ² + b²) / |b|
```
以 Δ 为变量（a 与 Δ 一一对应）。注意 Δ 仅以 **Δ² 的形式**出现（因为 d₂ 与 sin φ 都只依赖 Δ²）。因此 E 是 Δ² 的单调增函数（两个因子 √(d₁²+Δ²+b²) 与 √(Δ²+b²) 都随 Δ² 单调增），故 E 在 **Δ² = 0** 处取极小，即 **Δ = 0 ⟺ a = d₁**。

（唯一性：当且仅当 Δ=0；因为 |b|>0 时分母 |b| 非零，函数良定。）∎

**几何解释**：此时 cos φ = 0，φ = 90°，两条视线正交，位置误差椭圆各向同性。

### C.2 命题二：可行性不等式

**陈述**：候选区域 `{b : b_min ≤ |b| ≤ b_max}` 非空 ⟺ `Δd ≤ R_worst·cos φ_min`。

**证明**：
需要 `Δd·tan φ_min ≤ √(R_worst² − Δd²)`。两边非负，平方：

```
Δd² tan²φ_min ≤ R_worst² − Δd²
Δd² (tan²φ_min + 1) ≤ R_worst²
Δd² sec²φ_min ≤ R_worst²          （因 tan²+1 = sec²）
Δd sec φ_min ≤ R_worst            （取正根）
Δd ≤ R_worst · cos φ_min          （等价变形）
```
∎

**推论（本问的"天花板"）**：在完全不知道源距（Δd 由 (5,1500] 给出 ⇒ Δd = 747.5）且 R_worst = 1000 时，

```
cos φ_min ≥ 747.5/1000 = 0.7475  ⟹  φ_min ≤ 41.6°
```

**即：单站测向后，无论第二个点怎么选，最多只能保证约 40° 的交会角。** 这是信息量的硬限制，不是算法问题。论文应如实陈述，并指出"要突破必须获得额外的距离信息（场强估计/多点测量）"。

### C.3 对偶命题：Δd 与 φ_min 的权衡曲线

由 L7，`φ_min^max(Δd) = arccos(Δd/R_worst)`（Δd ≤ R_worst）。这是一条**递减曲线**：

| Δd (m) | 能达到的最好 φ_min |
|---|---|
| 0 | 90.0° |
| 250 | 75.5° |
| 500 | 60.0° |
| 707 | 45.0° |
| 766 | 40.0° |
| 866 | 30.0° |
| 1000 | 0°（不可行） |

**点透**：这张表把"源距越不确定，定位质量越差"从定性直觉变成定量曲线，是 Q2 论文里最有信息量的一张图。

## H. 与 Q1 / Q3 的接口

### H.1 Q1 → Q2（评价函数）

### H.2 Q2 → Q3（策略骨架）

| Q2 结论 | Q3 用法 |

### H.3 与 Q1 的"最小宽度方向"呼应

Q1 指出定位区域是"沿某方向被拉长的细长四边形"，其**最短方向（最小宽度方向）垂直于角平分线**。Q2 的结论 `a = d₁`（横向偏移）正好是**沿该最短方向移动** —— 两个问题从不同角度给出同一个几何事实，**论文可作为跨问一致性证据**。
