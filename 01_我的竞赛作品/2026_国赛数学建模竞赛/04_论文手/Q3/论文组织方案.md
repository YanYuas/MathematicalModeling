## 二、🚨 前置修正（**写完再改不如先改**）—— 审核独立推翻的 5 条

来源：`99_归档/审核报告_多AI协作_2026-09-11/Q3Q4方案审核报告_多AI协作.md`。每条都由第三方 Agent 独立复现，我不复述证据，只给结论与应改成什么。

### 2.1 【P0-13｜最严重】**U2「`R_MEC ≤ 34.9066` ⇒ homing 永不启用」是假定理**

- **错因**：把**单点最坏**（源在单元中心 ⇒ φ=120°）当成了**全域上界**。
- **反例（Agent 1 独立抽样 6000 点，ε=1°，R_eff=1000）**：d=1500 时 **56.8% 的区域连 2 条示向度都拿不到**；
  可解区 `R_MEC` 中位 **55.0 m**、p95 **453 m**、max **750 m**，**32.7% > 84.0369**（即该走 homing）；
  文档里的 `30.23 m` 只覆盖 **13.9%**。具体反例：源 `(−1153.3, −600.6)`，两格点夹角 **φ = 179.994°** ⇒ `R_MEC = 718.75 m`。
- **论文处置**：
  - **禁止**出现「homing 永不启用」「扫掠恒优于 homing」；
  - U2 降级为**条件命题**：「**格心构型下** `R_MEC = ε_rad·d/sin 120°`」；
  - 主路径的依据改为**分布/期望**（中位 55 m、p95 453 m），并写**自适应补测**；
  - 「两主一兜底」口径需重述为「直接清除为主，扫掠/逼近按 `R_MEC` 分档」。
- **影响节**：5.3.3、5.3.5、5.3.6 + §模型评价。

### 2.2 【P0-14】**`d` 双轨取舍方向被 v1.1.0 改反了** —— 默认档应回到 **d = 1000**

- v1.1.0 用「d=1500 每源只多付 ≈30 s 扫掠」推出「几乎打平」，而 **30 s 只对应格心源**（占比极小）。
- Agent 1 复算：**d=1000 有 81.6% 面积 `R_MEC ≤ 20`（可直接清除）、100% ≤ 84.04**；
  d=1500 清除侧粗估 **≥1380 s** vs d=1000 **≈50 s**，差 **~1300 s**，远超扫描项之差 714 s
  ⇒ **d=1000 净胜 ~600 s**（**v1.0.0 的原始判断反而更接近事实**）。
- **论文处置**：**默认档写 d=1000**，用「**免扫掠面积占比 81.6%**」作论证；d=1500 仅作对照。
- **影响节**：5.3.3 + 表 1 的 `d` 定档说明。

### 2.3 【P1-4｜**这条是批评我方的**】「三方吻合」的独立性不足

- 审核指出：MATLAB 与 Python 两套实现**同出编程手一人**；而 `99_归档/一次性往来_2026-09-11/建模手核验-编程手实跑验证-2026-09-11.md:5` 自述
  「本机无 MATLAB ⇒ `.m` 的输出**采信其报告**」（该自述确为我方文档）。
- **我方认账**：我此前写的「**两套独立实现 / 三方吻合**」**夸大了独立性**——
  我那次「独立复算」实际是**调用编程手的 `q1_main.py`**，并非第三方独立实现；
  唯一真正独立的部分是我按几何直接算出的 `0.6914`（旧错配置下的 R_MEC）。
- **论文处置**：
  - **不得**把「三方吻合」当作论文证据；若要在论文里提实现互验，只能写成
    「**同源两套实现**（MATLAB/Python）结果一致，并由建模手按几何独立复核**该错误配置**的数值 `0.6914`」；
  - 论文层面的正确性依据应是**解析证明 + CAS 复核**（建模手侧），而不是编程手的两套实现。
- **补正**：审核提到「同一次提交同时引入『已实跑报告』与『本机无 MATLAB』两种自述」——
  两者**不冲突**（编程手机器有 MATLAB，我本机没有），但它**确实说明我无法验证其 MATLAB 输出**，故独立性结论要收窄。

### 2.4 【P0-13 附带】**命题 C.8 里的 `N` 公式方向错了**

- 文档用 `N ≈ ⌈1.2091996·(R_MEC/20)²⌉` 当作**构造性覆盖的中心数**并写进完备性证明；
  实际它是**覆盖密度给出的渐近计数**，且方向上是「**至少**」而非「至多」。
- **应写成**：「存在 `N ≤ C·(R_MEC/20)²` 的覆盖（**六边形构造，含边界修正项**）」；
  且实现上**必须真的产出覆盖集**（当前两个实现都没有，见审核 P0-2：`clear_source` 只取前 `N_sweep` 个点，
  真源可能距所有尝试点 >20 m ⇒ 「必有一次成功」在实现里不成立）。
- **影响节**：5.3.2、5.3.4 + 5.3.7。
