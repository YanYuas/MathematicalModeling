## 一、⚠️ 命名规范已变更（v1.0.0 的写法作废）

| | 旧规范（v1.0.0，**作废**） | 新规范（现行） |
|---|---|---|
| 命名 | `Q{问号}_{图类型}_{序号}_{描述}.png`，如 `Q1_MAIN_01_三域布图对比.png` | **`图<节>-<序>_<描述>_vX.Y.png`**，如 `图5.1-1_角域示意_单站楔形_已采用.png` |
| 依据 | 本文件 v1.0.0 模板 | `03_编程手/图表库/QX/图号映射表.md`（图件的唯一权威索引） |
| 存放 | 本目录（`04_论文手/配图/`） | **按问**：`04_论文手/Q1/配图/`、`04_论文手/Q2/配图/` |

**为什么改**：旧规范的 `MAIN/SIDE/TEMP` 类型前缀与论文的**图号体系**（图 5.1-1、图 5.2-3…）脱节——
论文手排版时要靠图号找文件，而文件名里没有图号。新规范以**图号开头**，图号即文件名前缀，
`03_编程手/图表库/QX/图号映射表.md` 与各问 `配图清单.md` 两端一致。

## 三、图片规范（仍适用）

1. **分辨率**：≥300 DPI，宽度 ≥1000 px
2. **格式**：PNG（矢量优先 SVG——Word 2016+ 支持 SVG，印刷质量更好）
3. **中文显示**：字体正确，**不得出现方框**
4. **坐标轴**：有标签、有单位、有刻度
5. **图例**：清晰可辨
6. **配色**：统一配色方案（本项目用 **Okabe-Ito** 色盲友好色板）
7. **数据来源**：每张图须能追溯到**公式编号**或**数据文件**（如 `q1_scan_results.json`）

> 🚨 **红线（`实践反馈融入.md` R9）**：**图的数值只能来自模型，不能反过来**。
> 图件曾出现**两次数值编造**（Q1 的 `np.random.beta` 伪造 γ 分布；Q2 v3.0 的硬编码流带宽度/玩具公式）。
> "定性/简化"注释**不构成免责**；弃用图**必须从交付目录移出**并加标记（`99_归档/废弃方案/`）。
