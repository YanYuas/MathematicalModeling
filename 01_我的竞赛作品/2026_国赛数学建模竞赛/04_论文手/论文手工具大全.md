## 一、排版工具（选一个主力）

### 1.1 LaTeX（学术排版首选）

**适用场景**：公式多、交叉引用多、追求专业排版

**优点**：
- 公式排版无敌，复杂公式轻松搞定
- 图表自动编号，一改全改
- 参考文献自动管理（BibTeX）
- 版面专业，国奖级论文标配

**缺点**：
- 学习成本高，需要记语法
- 所见非所得，要编译才能看效果
- 插图调位置麻烦

**推荐发行版**：
- TeX Live（Windows，完整版约4GB）
- MiKTeX（Windows，按需安装包）
- Overleaf（在线版，不用装，支持多人协作）

**国赛模板**：搜索"CUMCMThesis"、"国赛LaTeX模板"

**快速上手**：
```latex
\documentclass[12pt]{article}
\usepackage{ctex}  % 中文支持
\begin{document}
\section{问题重述}
...
\end{document}
```

---

### 1.2 Word（上手最快）

**适用场景**：团队都会用、公式不太多、时间紧

**优点**：
- 所见即所得，不用学
- 团队协作无障碍
- 图表拖拽调整方便

**缺点**：
- 长文档编号容易乱
- 公式编辑器难用
- 排版要手动调，费时

**Word技巧**：
- 用"样式"统一标题格式，不要手动改字号
- 用"题注"给图表编号，自动更新
- 用"交叉引用"引用图表编号
- 用"目录"自动生成目录

---

### 1.3 Typora + Pandoc（Markdown流）

**适用场景**：喜欢Markdown写作、需要快速导出Word/PDF

**优点**：
- Markdown语法简单，专注写作
- 实时预览，所见即所得
- Pandoc一键转Word/LaTeX/PDF
- 有专门的数模模板主题（搜索"typora-math-modeling-template"）

**缺点**：
- 复杂排版能力有限
- 需要配置Pandoc和参考模板

**工作流**：
```
Markdown写作 → Pandoc转换 → Word微调 → 提交
```

---

### 1.4 LyX（LaTeX可视化版）

**适用场景**：想要LaTeX的排版质量，但不想记语法

**优点**：
- 可视化编辑，类似Word
- 底层是LaTeX，排版质量高
- 公式编辑器友好

**缺点**：
- 国内用的人少，资料少
- 还是需要了解一点LaTeX

---

### 1.5 排版工具选择建议

| 情况 | 推荐 |
|------|------|
| 时间充裕，想冲国奖 | LaTeX |
| 时间紧，团队都会Word | Word |
| 喜欢Markdown，有配置能力 | Typora + Pandoc |
| 想要LaTeX质量但怕语法 | LyX |

## 二、公式编辑工具

### 2.1 MathType（Word公式首选）

- 最常用的公式编辑器，和Word集成好
- 支持LaTeX语法输入
- 可以直接复制到LaTeX

### 2.2 AxMath（国产精品）

- 比MathType轻量，价格便宜
- 支持LaTeX语法
- 和Word集成好

### 2.3 LaTeX原生公式

- 写LaTeX文档时直接用
- 语法参考：`$...$`行内公式，`$$...$$`独立公式

### 2.4 在线公式编辑器

- [Latex在线公式编辑器](https://www.latexlive.com/)
- 可视化编辑，复制LaTeX代码

## 三、绘图工具（按图类型选）

### 3.1 数据图（折线/柱状/散点/热力图）

#### Matplotlib（Python，免费首选）

**优点**：
- 免费，和Python代码无缝集成
- 可复现，改数据重新跑就出新图
- 论文级质量，支持矢量输出

**常用设置**：
```python
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei']  # 中文
plt.rcParams['axes.unicode_minus'] = False    # 负号
plt.figure(dpi=300)  # 高清
# ... 画图 ...
plt.savefig('fig1.png', dpi=300, bbox_inches='tight')
```

**进阶库**：
- Seaborn：统计图表更美观
- Plotly：交互式图表
- PaperPlot：专门为论文设计的Matplotlib封装

#### Origin（专业数据绘图）

- 科研圈标配，100+种图形类型
- 数据探索和分析功能强
- 收费，学校一般有授权

#### Excel（快速出图）

- 简单图表最快
- 适合临时看数据趋势
- 论文最终图建议用Matplotlib或Origin重画

---

### 3.2 流程图/框架图/技术路线图

#### Visio（Windows首选）

- 功能强大，模板丰富
- 和Office集成好
- 对齐、连接功能专业

#### draw.io（免费首选）

- 完全免费，开源
- 在线版：app.diagrams.net
- 桌面版也有
- 导出SVG/PNG/PDF

#### PPT（最快上手）

- 人人都会
- 形状、连接线够用
- 适合简单流程图
- 技巧：用"对齐"和"组合"功能

#### 亿图图示（国产）

- 模板丰富，中文友好
- 跨平台
- 部分功能收费

---

### 3.3 矢量编辑/后期处理

#### Inkscape（免费矢量编辑）

- 开源免费，类似Illustrator
- 适合给图加标注、拼子图
- 导出PDF/EPS矢量格式
- LaTeX插图推荐用PDF矢量图

---

### 3.4 绘图工具选择速查

| 图类型 | 首选工具 | 备选 |
|--------|---------|------|
| 数据折线/柱状图 | Matplotlib | Origin / Excel |
| 流程图/框架图 | Visio / draw.io | PPT |
| 技术路线图 | draw.io | PPT |
| 多子图拼接 | Inkscape | PPT |
| 3D图 | Matplotlib / Origin | - |
| 热力图 | Matplotlib (Seaborn) | Origin |

## 四、参考文献管理工具

### 4.1 Zotero（免费首选）

**优点**：
- 完全免费，开源
- 浏览器插件一键抓取文献
- 支持知网（需装Jasminum插件）
- 无限级文件夹分类
- 支持Word/LaTeX/Google Docs
- 社区活跃，插件多

**缺点**：
- 同步空间有限（免费300MB）
- 界面不如Mendeley美观

**必备插件**：
- Jasminum：抓取知网文献
- Zotero PDF Translate：PDF翻译
- Better BibTeX：LaTeX用户必备

---

### 4.2 EndNote（机构首选）

**优点**：
- 老牌权威，6000+引用格式
- Word集成最好
- 海量文献不卡

**缺点**：
- 收费（学校一般有授权）
- 学习曲线陡
- 只支持二级分类

---

### 4.3 Mendeley

**优点**：
- 界面美观
- PDF阅读器集成好
- 社交功能（推荐文献）

**缺点**：
- 被Elsevier收购，有隐私顾虑
- 对新系统支持慢
- 国内同步不稳定

---

### 4.4 参考文献工具选择

| 情况 | 推荐 |
|------|------|
| 大多数人 | Zotero（免费够用） |
| 学校有EndNote授权 | EndNote |
| 主要读PDF | Mendeley |
| 写LaTeX | Zotero + Better BibTeX |

## 五、AI辅助写作工具

### 5.1 Grammarly（英文语法检查）

- 英文语法、拼写、标点检查
- 支持Word/浏览器/Google Docs
- 免费版够用，付费版有润色建议
- 美赛英文论文必备

### 5.2 Quillbot（改写/润色）

- AI改写句子，调整语气
- 多种模式：标准、流畅、正式、简洁
- 适合英文论文润色

### 5.3 通用大模型（Claude / GPT）

**适用场景**：
- 论文框架设计
- 文献摘要整理
- 讨论部分打磨
- 回复审稿意见
- 图表解读和图注撰写

**使用原则**：
- 仅作辅助，严禁代写
- 核心观点和数据必须自己来
- AI生成的内容要人工核实

### 5.4 Writeful（学术润色）

- 专门针对学术论文
- 保留原意，减少AI腔
- 适合外文期刊润色

## 六、格式转换工具

### 6.1 Pandoc（文档转换瑞士军刀）

- 支持Markdown ↔ Word ↔ LaTeX ↔ PDF ↔ HTML
- 命令行工具，免费
- 配合参考模板可以控制输出格式

**常用命令**：
```bash
# Markdown转Word
pandoc input.md -o output.docx --reference-doc=template.docx

# Markdown转LaTeX
pandoc input.md -o output.tex

# Word转Markdown
pandoc input.docx -o output.md
```

### 6.2 在线转换

- SmallPDF：PDF转Word/Excel
- iLovePDF：PDF合并/拆分/压缩
