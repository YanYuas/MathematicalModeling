## 摘要

针对"已知单个检测点的示向度、如何选择第二个检测点"这一问题，本文将其识别为**带未知源距的鲁棒实验设计**，而非参数估计。本文首先以位置不确定度 `E ≍ ε·√(d₁²+d₂²)/sin φ` 量化"定位效果好"，并引入 Fisher 信息矩阵验证该式恰为均方根位置误差（即 A-最优设计准则）；由几何关系证明**正交最优性定理**：使交会角达到 90° 的充要条件是第二检测点与干扰源沿视线方向"**正侧方对齐**"（即 a = d₁），此时以 S₁S₂ 为直径的圆必过源（Thales 定理）。进一步证明该结论**与设计准则无关**（A-最优、D-最优与 E 极小给出同一最优点）。由于源距 d₁ 完全未知，本文由其可得信息推出 d₁ ∈ (5, 1500]，以区间半宽 Δd = 747.5 m 做最坏情况鲁棒化，得到参数化候选区域 `S₂ = S₁ + d̂·u + b·v, b ∈ ±[Δd·tan φ_min, √(R²−Δd²)]`（R 取最坏接收半径 1000 m），并推出**可行性不等式 Δd ≤ R·cos φ_min**，指出源距完全未知时可保证的交会角不超过 41.63°；进一步地，将示向度误差 $α \in [−1°,1°]$ 与源距不确定度**一并纳入最坏化**后，可保证的交会角上界降至 **39.62°**——即"源距未知"与"示向度误差"是**两个独立的信息缺口**，共同构成本问的硬限制而非算法不足。基准参数下，$α = 0$ 时得 $b \in [627.23, 664.26]$ m；计入 $α$ 后该区间收缩为空集，故本文以 39.62° 为实际可达上界。与问题一的交叉验证表明：将该规则用于问题一算例，定位区域直径由 39.598 m 降至 **35.41 m（降幅 10.57%）**。

**关键词**：交会定位；实验设计；Fisher 信息矩阵；Thales 定理；鲁棒优化；候选区域

## 一、问题重述

### 1.1 问题背景

在无线电干扰源的定位清除流程中，前两个阶段（初步监测与区域性排查）已把目标压缩到一片区域，第三阶段需在区域内精确确定干扰源位置并清除。测向机通过比较各方向的场强确定**示向度**——即检测点指向干扰源的最大场强方向对应的方位角。受环境电磁干扰与仪器精度限制，示向度与真实方位角存在误差，全局误差落在 ±1° 范围内。

由于单条示向度只给出**方向**而不含**距离**，单个检测点无法确定干扰源位置。增加检测点可使多个方向约束相交，从而把干扰源限制在一小片区域内。因此，"第二个检测点应选在哪里"直接决定了定位效果。

### 1.2 问题提出

**问题二**：已知某**全向**干扰源在一个检测点处测得的示向度，请给出第二个检测点的选择策略，以获得关于该干扰源较好的定位效果，并给出第二个检测点的**候选区域**。

## 二、问题分析

### 2.1 任务结构

问题二与问题一在性质上有本质差别：

| | 问题一 | **问题二** |
|---|---|---|
| 已知 | 多个检测点及其示向度 | **一个**检测点及其示向度 |
| 求 | 定位区域直径 + 覆盖判定 | **第二个检测点的选择策略 + 候选区域** |
| 性质 | 确定性**计算**问题 | **实验设计**问题 |
| 何时决策 | — | **在取得第二个观测之前** |

**关键矛盾**：最优选点依赖干扰源的位置，而干扰源的位置恰恰是未知量。因此本问不是"给定数据求最优"，而是**带未知参数的实验设计**。

### 2.2 三个难点

**难点一：选点发生在测量之前。** 选择第二检测点时尚无该点的观测数据，只能依赖已有信息（S₁ 的示向度、误差界、接收半径范围、目标区域范围）。若用真源位置去反推最优点，则构成逻辑循环。

**难点二："定位效果好"是定性表述。** 必须给出可量化的度量。本文沿用问题一的思想，以位置不确定度为度量，并将其整理为具有闭式表达的目标函数。

**难点三：源距完全未知。** 单条示向度不含距离信息，源在视线上的位置完全未知。这既使最优选点无法精确实现，也从根本上限制了可保证的定位质量。

### 2.3 本文思路

对此，本文采用"**量化目标 → 求闭式最优 → 鲁棒化 → 给候选区域与界**"四步路线：

1. **量化**：以位置不确定度 E 量化"定位效果好"，并证明它即 A-最优设计准则；
2. **求最优**：由几何关系推出闭式最优条件——第二检测点与源"正侧方对齐"；
3. **鲁棒化**：把源距未知量化为区间 [d̂−Δd, d̂+Δd]，对最坏情况设计；
4. **给区域与界**：解两条不等式得参数化候选区域，并给出可行性不等式以界定可保证的交会角上限。

**本文需要特别指出：本问不需要任何优化搜索算法。** 最优条件有闭式解，候选区域边界由两条不等式直接解出，网格扫描仅用于验证与出图。

## 五、模型的建立与求解

## 5.2 问题二：第二检测点的选择策略与候选区域

**● 题设关键点拆解**

- **"一个检测点…测得的示向度"**：只有一条方位约束，源在该方向上的距离完全未知 → 单站不可定位；
- **"全向干扰源"**：可探测性只取决于距离、与方向无关 → 约束形式简单；
- **"第二个检测点的选择策略"**：选点在取得观测之前 → 属**实验设计**；
- **"较好的定位效果"**：定性表述 → 必须量化；
- **"候选区域"**：答案是一个集合 → 必须参数化给出。

**数学抽象**

```
已知： S₁、θ₁、误差半角 ε = 1°、接收半径范围 [1000,1500]、近距阈值 5 m
未知： 干扰源 G（方向受 θ₁±1° 约束，距离完全未知）
决策： S₂ = S₁ + a·u + b·v     （在取得 S₂ 处观测之前选定）
目标： 最小化位置不确定度 E(S₂)
约束： C1 可探测 |S₂−G| ≤ R_worst = 1000；C2 非退化（两视线不共线）
主输出：选择策略
副输出：候选区域（参数化）
```

---

### 5.2.0 参数与源距不确定区间

本问不含外部数据集，其"数据"为题设参数与一个未知量的可行区间。

**可得信息**有三条：其一，S₁ 处返回的是示向度（而非"距离过近"或"无信号"），故源距大于近距阈值 5 m；其二，S₁ 能测得信号说明源位于 S₁ 的接收半径之内，而接收半径不超过 1500 m；其三，接收半径本身未知且接口不返回，故设计时取其下界 1000 m 以保证第二检测点必然能收到信号。

由前两条得

```
d₁ ∈ (5, 1500]
d̂ = (5 + 1500)/2 = 752.5 m,      Δd = (1500 − 5)/2 = 747.5 m
```

**关键结论**：Δd 的宽度（747.5 m）已接近 R_worst（1000 m）。这一事实将在 5.2.7 中直接推出"可保证交会角不超过 41.63°"的硬上界（**计入示向度误差后为 39.62°**），是本问最要紧的数字。

**表 5.2-1　题设参数与设计取值**

| 参数 | 题设取值 | 设计取值 | 说明 |
|---|---|---|---|
| 误差半角 ε | 1° | 1° | 直接采用 |
| 有效接收半径 R | [1000, 1500]，每源不同、接口不返回 | **1000（下界）** | 保证第二点必然收到 |
| 近距阈值 | 5 m | 5 m | 与 `near` 判据一致 |
| 清除半径 | 20 m | 20 m | 用于评价定位效果 |

### 5.2.1 选点问题的本质：实验设计

交会定位的精度由**两条视线的夹角**决定：单条示向度只含方向信息，第二个检测点的价值在于追加一个方向约束。但选点在取得第二个观测之前完成，此时源的位置与距离均未知——因此本问属于**实验设计**，而非参数估计。

**核心追问**：能否让"最优选点"不依赖未知的源距？

本文的回答是**部分可以**。最优选点的**方向特征**（与源正侧方对齐）由几何关系唯一确定，与源距无关；只有**横向偏移量**的取值依赖源距的不确定程度。这一分解是本问的建模枢纽：把问题拆成"与未知量无关的部分"（选点方向）与"依赖未知量的部分"（偏移量下界），后者交由鲁棒化处理。

### 5.2.3 交会角的三行关系式

**坐标归约**：取 S₁ 为原点、θ₁ 的中线为 +x 轴（旋转与平移不改变距离与夹角，故不失一般性）。设源 G = (d₁, 0)，第二检测点 S₂ = S₁ + a·u + b·v，记**深度偏差** Δ = d₁ − a。

**命题 5.2-1（三行关系式）**

```
d₂ = √(Δ² + b²),        cos φ = Δ/d₂,        sin φ = |b|/d₂
```

**证明**：在归约坐标下 G→S₁ = (−d₁, 0)，G→S₂ = (a − d₁, b) = (−Δ, b)。两向量点积为 d₁·Δ，模长分别为 d₁ 与 d₂，故 cos φ = Δ/d₂。又由 d₂² = Δ² + b² 及 sin²φ = 1 − cos²φ，得 sin φ = |b|/d₂。证毕。

**三行关系式的三重作用**：

1. **解耦**：φ 只通过 Δ 与 b 依赖几何，与 d₁ 的绝对值无关——这是后续鲁棒化的可操作基础；
2. **退化条件**：`sin φ = |b|/d₂` 直接给出 b = 0 ⇒ sin φ = 0；
3. **最优条件**：`cos φ = Δ/d₂` 直接给出 Δ = 0 ⇒ φ = 90°。

**注（实现约定）**：归约坐标仅在推导中使用；任何输出必须经逆变换回到原坐标系。

### 5.2.4 最优性定理

#### (1) 目标函数

一条方位线存在角误差 ε 时，其横向位置偏移为 d·ε（距离乘角度）；两线交点处的位置不确定度被 1/sin φ 放大，合成得位置不确定度

```
E(S₂) ≍ ε·√(d₁² + d₂²) / sin φ
```

其中三个因子各有明确含义：ε 为观测精度；√(d₁²+d₂²) 为尺度因子；1/sin φ 为**几何放大因子**（即两站情形下的几何精度衰减因子 GDOP）。

**注（E 的严格身份：A-最优设计准则）** E 并非经验近似。方位观测 `θᵢ = atan2(G_y − S_{iy}, G_x − S_{ix})` 对源位置的梯度为

```
Jᵢ = ∂θᵢ/∂G = (1/dᵢ)·n̂ᵢ^⊥        （n̂ᵢ^⊥ 为垂直于第 i 条视线的单位向量）
```

故 Fisher 信息矩阵为 `M = (1/σ²)Σᵢ JᵢᵀJᵢ`。在归约坐标（S₁ 为原点、θ₁ 中线为 +x 轴、G = (d₁,0)、S₂ = (a,b)、Δ = d₁ − a、d₂ = √(Δ²+b²)）下，

```
J₁ = (0, 1/d₁),        J₂ = (b, Δ)/d₂²

M = (1/σ²)·[ [  b²/d₂⁴  ,       bΔ/d₂⁴        ],
             [  bΔ/d₂⁴  ,  1/d₁² + Δ²/d₂⁴     ] ]
```

由此得两个闭式不变量

```
det M      =  b²/(σ⁴ d₁² d₂⁴)  =  sin²φ/(σ⁴ d₁² d₂²)
trace(M⁻¹) =  d₂²(d₁² + d₂²)/b² · σ²
```

于是 `E² = ε²·(d₁²+d₂²)·d₂²/b² = ε²·trace(M⁻¹)`，即 **E = ε·√(trace M⁻¹)**，恰为**1σ 位置的均方根误差**。因此本文的目标函数是标准的 **A-最优实验设计准则**，而非经验公式。

#### (2) 定理 5.2-1（正交最优性）

**陈述**：固定 d₁ 与 |b| > 0，则 E 关于 a 在 **a = d₁** 处取得唯一极小。

**证明**：在归约坐标下

```
E = ε·√(d₁² + Δ² + b²) · √(Δ² + b²) / |b|,      Δ = d₁ − a
```

注意 Δ 仅以 Δ² 的形式出现（因为 d₂ 与 sin φ 都只依赖 Δ²）。两个因子 `√(d₁²+Δ²+b²)` 与 `√(Δ²+b²)` 均关于 Δ² 单调递增，故 E 关于 Δ² 单调递增，在 Δ² = 0 处取得唯一极小，即 a = d₁。由于 |b| > 0，分母非零，函数良定。证毕。

**推论 5.2-1**：此时 cos φ = 0，即 **φ = 90°**，两条视线正交，位置误差椭圆各向同性。

**推论 5.2-2（几何表述）**：最优第二检测点落在"**过源、且垂直于视线 S₁G**"的直线上——即与源**正侧方对齐**。

**推论 5.2-3（Thales 等价）**：φ = 90°（即 ∠S₁GS₂ = 90°）等价于**源 G 落在以 S₁S₂ 为直径的圆上**（Thales 定理）。

#### (3) 命题 5.2-2（外接圆分解：正交最优性的第二证明）

定理 5.2-1 的证明基于 E 关于 Δ² 的单调性。下面再给出一个更具几何直观的独立证明，并揭示目标函数的**尺度–形状分解**。

记 `L = |S₁S₂|`，`R_c` 为三角形 △S₁GS₂ 的**外接圆半径**。由正弦定理（边 L 对应角 φ）：

```
L / sin φ = 2 R_c        ⟹        1 / sin φ = 2 R_c / L
```

代入目标函数即得分解式：

```
E = ε · √(d₁² + d₂²) · ( 2 R_c / L )
     ╰──── 尺度因子 ────╯   ╰─ 形状因子 ─╯
```

**命题 5.2-2** 对任意非退化三角形，形状因子满足

```
2 R_c / L  ≥  1
```

等号成立**当且仅当** `φ = ∠S₁GS₂ = 90°`。

**证明**：由正弦定理 `L = 2R_c·sin φ`，故 `2R_c/L = 1/sin φ`。因 `φ ∈ (0°, 180°)`，有 `sin φ ≤ 1`，故 `2R_c/L ≥ 1`，等号当且仅当 `sin φ = 1`，即 `φ = 90°`。证毕。

**几何读法**：`R_c ≥ L/2` 即"外接圆半径不小于任一边之半"，等号当且仅当该边为直径——这正是 Thales 定理。

**推论 5.2-4（最优构型的刻画）** 由命题 5.2-2，`E ≥ ε·√(d₁²+d₂²)`，等号当且仅当 `φ = 90°`。此时

- 三角形 △S₁GS₂ 在**源 G 处直角**，故 `S₁S₂` 为斜边，`L² = d₁² + d₂²`；
- 其**外接圆恰以 S₁S₂ 为直径**，即命题 5.2-2 中的 Thales 圆；
- 形状因子取到最小值 1。

故**最优第二检测点的完整刻画为：使三角形 △S₁GS₂ 在源处构成直角三角形，且其外接圆恰为以 S₁S₂ 为直径的圆。**

**注（两条证明的分工）**：定理 5.2-1 由目标函数关于 Δ² 的单调性给出最优点的**位置坐标**（a = d₁）；命题 5.2-2 由正弦定理给出最优构型的**几何形状**（源处直角、外接圆为 Thales 圆）。两者互为补充、结论一致。

#### (4) 命题 5.2-3（准则无关最优性）

**陈述**：上述最优性结论与设计准则的选择无关——A-最优（min trace M⁻¹）、D-最优（max det M）与 E 极小三者给出同一最优第二点 a = d₁。

**证明**：考察 M 的四个元素。其中 Δ 只以 Δ² 的形式出现，以及在非对角元中以 Δ·|b|·sign(Δ) 的形式出现。后者对应于坐标轴的反射，**不改变 M 的特征值**。因此 M 的谱只依赖 Δ²，所有仅依赖谱的准则（A-最优、D-最优、E-最优）的最优解均在 Δ = 0。证毕。

**注**：这一结论把"正侧方最优"从"本文选择了一个合适目标函数的结果"提升为"**几何结构本身决定的性质**"。

#### (5) 命题 5.2-4（退化）

**陈述**：若 b = 0，则 S₁、S₂、G 三点共线，两条示向度射线重合，sin φ = 0，位置不确定度 E 发散。

**推论（反直觉结论）**：**沿示向度方向前进对定位零信息增益**——最常见的直觉（"往源的方向走一段再测一次"）恰恰是最无效的做法，必须**横向偏移**。

**注（与问题三的联系）**：这一结论解释了问题三中"侦察扫描"与"渐进逼近"为何是两种不同的动作：前者需要横向几何以获得定位信息，后者只需沿视线收敛距离。

### 5.2.5 候选区域求解

#### (1) 鲁棒化

由于源距未知，取 a = d̂（最优估计），则真实深度偏差满足 |Δ| = |d₁ − d̂| ≤ Δd。要求以下两项约束对**所有** Δ ∈ [−Δd, Δd] 均成立：

**角度质量约束**：要求 sin φ ≥ sin φ_min。由 `sin φ = |b|/√(Δ²+b²)`，最坏情形在 |Δ| = Δd 时取到，解得

```
|b|² ≥ sin²φ_min (Δd² + b²)  ⟹  b²cos²φ_min ≥ Δd²sin²φ_min
⟹  b_min = Δd · tan φ_min
```

**可探测约束**：要求 d₂ = √(Δ²+b²) ≤ R_worst。最坏情形同样在 |Δ| = Δd 时取到，解得

```
Δd² + b² ≤ R_worst²   ⟹   b_max = √(R_worst² − Δd²)
```

**注（实现约定）**：由于 E 与约束均关于 Δ² 单调，最坏情形确实在两个端点取到；但实现中仍应对区间做密集扫描作为交叉校验，并在文档中写明该单调性依据。

#### (2) 候选区域

**简化版（a 锁定为 d̂）**：

```
A = { S₁ + d̂·u + b·v :  b ∈ ±[b_min, b_max] }
```

即**两条关于示向度线对称的短线段**。

**完整版（允许 a 偏离 d̂）**：令 a 的可行幅度 `a_span = R_worst·cos φ_min − Δd`，深度裕度 `m(a) = |a − d̂| + Δd`，则

```
A' = { S₁ + a·u + b·v : |a − d̂| ≤ a_span,   m(a)·tan φ_min ≤ |b| ≤ √(R_worst² − m(a)²) }
```

即 (a, b) 平面上的**两片翼形区域**。

**主动暴露取舍**：本文同时给出两级答案。简化版把 a 锁定为最优估计，区域退化为两条线段，**可直接执行**；完整版允许 a 在其可行范围内变动，区域扩张为两片翼形，**展示模型的一般性**。二者的取舍在于：简化版便于现场执行，完整版便于灵敏度分析。

#### (3) 关于不引入优化算法的说明

本问的最优条件由定理 5.2-1 以闭式给出，候选区域边界由两条不等式直接解出，**无需任何迭代搜索**。若对本题使用模拟退火或梯度下降，不仅不能提高精度，反而掩盖了问题可解析求解的本质。网格扫描在本问中仅用于**验证与出图**，不用于求解。

### 5.2.7 可行性与界的验证

#### (1) 定理 5.2-2（可行性不等式）

**陈述**：**在源点位于测量中线上（方向偏差 $α = 0$）的前提下**，候选区域非空，当且仅当

```
Δd · sec φ_min ≤ R_worst      ⟺      Δd ≤ R_worst · cos φ_min
```

等价地，**源距不确定半径为 Δd 时，可保证的交会角上界为 $φ_{\min} ≤ \arccos(Δd / R_{\text{worst}})$**。

> 本定理是下述**定理 5.2-3** 在 $α = 0$ 时的特例。当把题目给定的示向度误差区间一并纳入最坏化时，其结论须按定理 5.2-3 修正。

**证明**：候选区域非空即需 b_min ≤ b_max，即

```
Δd·tan φ_min ≤ √(R_worst² − Δd²)
```

两端均非负，平方得 Δd²tan²φ_min ≤ R_worst² − Δd²，即 Δd²(tan²φ_min + 1) ≤ R_worst²。由 tan²φ_min + 1 = sec²φ_min 得

```
Δd · sec φ_min ≤ R_worst      ⟺      Δd ≤ R_worst · cos φ_min
```

即得所证。证毕。

#### (2) 定理 5.2-3（含示向度误差的可行性上界）

定理 5.2-2 的推导把源点置于测量中线上，即取方向偏差 $α = 0$。然而题目设定示向度误差在 $[−1°,1°]$ 范围内，意味着源的真实方位相对**测量值**存在偏差 $α \in [−\varepsilon, \varepsilon]$。若把这一维不确定性一并纳入最坏化，定理 5.2-2 的单式可行性条件将不再充分——其推导在把"角度质量"与"可探测"两条约束合并为一条时，隐含使用了 $α = 0$。

**陈述**：设 $G = r(\cos α, \sin α)$，其中 $r \in (5, R_{\max}]$、$|α| ≤ \varepsilon$，则

$$
\sin φ = \frac{|a \sin α − b \cos α|}{d_2}, \qquad d_2 = \sqrt{a^2 + b^2 + r^2 − 2r\,(a\cos α + b\sin α)}
$$

（$α = 0$ 时退化为 §5.2.3 的 $\sin φ = |b| / d_2$）。此时约束须拆回**两条**分别最坏化的不等式：

$$
\begin{aligned}
\text{角度：}\quad & \forall α \in [−\varepsilon,\varepsilon]:\quad |a\sin α − b\cos α| \;\ge\; \sin φ_{\min} \cdot \max_{r \in \{5,\, R_{\max}\}} d_2(r, α) \\
\text{距离：}\quad & \forall α \in [−\varepsilon,\varepsilon]:\quad \max_{r \in \{5,\, R_{\max}\}} d_2(r, α) \;\le\; R_{\text{worst}}
\end{aligned}
$$

**证明（要点）**：分子 $|a\sin α − b\cos α|$ 与 $r$ 无关，而 $d_2^2$ 关于 $r$ 是**开口向上的抛物线**，故其在区间 $[5, R_{\max}]$ 上的最大值必在端点取到——且该结论与 $α$ 无关。于是只需对 $r$ 的两个端点与 $α \in [−\varepsilon,\varepsilon]$ 取最坏。进一步地，两条约束的最坏 $α$ **方向相反**：角度约束最坏在 $α = +\varepsilon$（分子中 $b\cos α$ 取最小、$−a\sin α$ 贡献负向），距离约束最坏在 $α = −\varepsilon$（$a\cos α + b\sin α$ 取最小，$d_2$ 最大）。证毕。

**结果（基准参数 $a = \hat d = 752.5$ m）**：$b_{\min}^{α} = 650.00$ m，$b_{\max}^{α} = 638.00$ m，从而 $b_{\min}^{α} > b_{\max}^{α}$，**候选区域为空集**。

**推论（可达上界）**：在整个 $(a, b)$ 平面上优化，本问能保证的最大交会角为

$$
φ_{\min}^{\max} = \max_{a,\,b} \; \min_{α \in [−\varepsilon,\varepsilon],\; r \in \{5,\, R_{\max}\}} \arcsin \frac{|a \sin α − b \cos α|}{d_2}
\qquad \text{s.t.} \quad \max d_2 \le R_{\text{worst}}
$$

其数值结果为 **39.6161°**（在 $(a, b) = (764, 651)$），即 $φ_{\min} = 40°$ **不可达**。作为对照，$α = 0$ 时同一优化给出 41.626°，故示向度误差单独削去约 **2.0°**。

> **关于 $φ_{\min}^{\max}$ 数值性质的说明**：39.6161° 是上式在 $(a,b)$ 平面上的**数值搜索峰值**（宽域粗扫 20 m → 邻域细化 2 m → 0.25 m 三级，并经建模手与编程手两套独立实现互验，逐位一致），**不是闭式解**。该搜索域覆盖 $a \in [-800, 2400]$、$b \in [0, 1400]$，其中**未出现任何保证交会角 $≥ 40°$ 的可行点**；故"$φ_{\min} = 40°$ 不可达"这一结论由"宽域网格穷举 + 端点判据"共同支撑，本文如实标注为**数值结论**而非已证明的定理。$Δd$ 与可达上界的定量关系见图 5.2-8。

#### (4) 讨论：两个独立的信息缺口

上表说明一个反直觉的事实：源距未知与示向度误差看似同属"精度损失"，但在可行域上作用于**两个不同的方向**——前者决定交会角的上限尺度 $\arccos(Δd/R)$，后者在此之上再削去约 2°。二者的叠加使候选区域在 $φ_{\min} = 40°$ 时**消失**。这并非算法不足，而是**先验信息量不足以同时支撑该交会角要求与全区间鲁棒性**。

因此本问结论的准确表述是：**在源距完全未知（$Δd = 747.5$ m）且示向度误差达 $\pm 1°$ 的条件下，两个检测点的设计最多保证约 39.6° 的交会角**。若要达到 $40°$ 及以上，须补充额外信息——例如以场强估计收紧 $d_1$ 的区间，或增加观测点以引入冗余约束；由 $φ_{\min}^{\max}$ 的表达式可见 $Δd$ 与可达交会角之间的定量关系（图 5.2-4）。**需要强调的是，只有 $α = 0$ 时该关系才是闭式 $\arccos(Δd/R)$**；把示向度误差一并最坏化后，上界随 $Δd$ 下降得更快，且两个缺口不再可以合并为一个因子（图 5.2-8）。

| $Δd$ 区间与 $φ_{\min}$ 上界（含 $α$：39.62°） | 判定"当前定位是否够准"，决定是否进入渐进逼近 |
| R 按最坏 1000 设计 | 覆盖设计同样按最坏接收半径，保证不漏源 |

## 六、模型评价

### 6.1 模型优点

1. **问题类型识别准确**：将本问识别为带未知参数的鲁棒实验设计，而非优化搜索问题，避免了方法论错配；
2. **目标函数有严格依据**：位置不确定度 E 经 Fisher 信息矩阵验证恰为均方根位置误差（A-最优准则），非经验公式；
3. **最优条件有闭式解**：由几何关系直接推出"正侧方对齐"，并可证明该结论与设计准则无关；
4. **鲁棒化处理得当**：把"源距未知"这一模糊困难转化为可计算的区间与最坏情况，使问题由不可解变为可解；
5. **回答完整**：给出参数化候选区域（两级）、可行性不等式与移动耗时，并附跨问交叉验证。

### 6.2 模型缺点

1. **两个信息缺口共同构成硬上界**：仅计入源距未知时，可保证的交会角不超过 41.63°（定理 5.2-2）；再计入示向度误差 $α \in [−1°,1°]$ 后降为 **39.6161°**，且 $φ_{\min} = 40°$ 下候选区域为空集（定理 5.2-3）。这是先验信息量的限制，非算法可改善；
2. **"最优"在估计意义下成立**：定理 5.2-1 的 a = d₁ 在 d₁ 未知时只能取 a = d̂，故最优性以 d̂ 为估计中心；
3. **R 取最坏值牺牲性能**：按 1000 m 设计保证了"必然收到信号"，但若实际接收半径较大，候选区域本可宽得多；
4. **本问结论不适用于定向干扰源**：定向源存在 ±90° 覆盖扇区，可探测性判据需修改（属问题四）；
5. **$E$ 与 $D$ 并非固定比例**：两者是不同尺度的不确定度度量，实测比值 $ρ = D/E$ 随几何构型变化（本文算例为 2.23~2.43），既不可互换，亦不可用作一致性判据。

### 6.3 改进方向

1. **多点序贯设计**：每取得一次新观测即可更新源距的先验区间，Δd 逐步收紧，可保证的交会角随之提高；
2. **利用目标区域几何收紧 d₁ 先验**：若检测点位置已知，可由"源位于半径 1800 m 圆形目标区域内"进一步压缩 d₁ 的可行范围，从而提高 φ_min 上界；
3. **接收半径的不确定性权衡**：对比"按 1000 m 保守设计"与"按 1250 m 承担一定风险设计"的候选区域宽度，为实际决策提供依据。
