## 三、问题分析怎么写（对应 2007"先定五因素"）

**沿用 B477 的问题分析句式**（"核心任务为…关键矛盾在于…对此，本文…"）：

> 问题二的核心任务为：已知某全向干扰源在一个检测点处的示向度，给出第二个检测点的选择策略并给出候选区域。关键矛盾在于：**选点发生在取得第二个观测之前**，而最优选点依赖源的位置——恰恰是未知量。因此本问不是"给定数据求最优"，而是**带未知参数的实验设计**。对此，本文先以"定位不确定度"量化"定位效果好"（沿用问题一的直径度量及其解析代理），再由几何关系推出最优选点的闭式条件，最后以源距的不确定区间做鲁棒化，给出参数化候选区域。

**必须写清的三个点**：
1. **这是实验设计而非估计**——选点在测量之前，只能用先验信息
2. **最优选点依赖未知的源距**——必须鲁棒化（区间 + 最坏情况）
3. **本问无启发式**——最优条件有闭式解（`a = d₁`），用优化搜索是误解

## 四、5.2.0 参数与源距不确定区间（对应 2007"数据清洗独立小节"）

**2007 做法**：专门一节把"公交线路 → 图论边"。**Q2 做法**：专门一节把"源距未知"转成可计算的区间。

> 本问的可得信息有三条：其一，S₁ 处返回的是**示向度**（而非"距离过近"或"无信号"），故源距大于近距阈值 5 m；其二，S₁ 能测得信号说明源位于 S₁ 的接收半径之内，而接收半径不超过 1500 m；其三，接收半径本身未知且接口不返回，故设计时取其**下界 1000 m** 以保证第二个检测点必然能收到信号。综合前两条得源距 d₁ ∈ (5, 1500]，其区间中点 d̂ = 752.5 m、半宽 Δd = 747.5 m。

**关键结论句**（学 2007 的"参数化约束"）：**Δd 的宽度（747.5 m）已接近 R_worst（1000 m）**——这一事实在 5.2.7 中直接推出"可保证交会角不超过 41.63°"的硬上界（**计入 α 后 39.62°**），是本问最要紧的数字。

## 五、5.2.1 选点问题的本质：实验设计

> 交会定位的精度由两条视线的夹角决定：单条示向度只含方向信息，第二个检测点的价值在于**追加一个方向约束**。但选点在取得第二个观测之前完成，此时源的位置与距离均未知——因此本问属于**实验设计**而非参数估计。

**核心追问**（沿用 B477 句式）：

> 核心追问是：能否让"最优选点"不依赖未知的源距？本文的回答是**部分可以**——最优选点的**方向特征**（正侧方）与源距无关，只有**横向偏移量**依赖源距的不确定度。

**这一发现是本问的建模枢纽**：把问题分解为"与未知量无关的部分"（选点方向）与"依赖未知量的部分"（偏移量的下界），后者由鲁棒化处理。

## 七、5.2.3 交会角的三行关系式

坐标归约：取 S₁ 为原点、θ₁ 中线为 +x 轴。设源 G = (d₁, 0)、第二检测点 S₂ = S₁ + a·u + b·v，记 Δ = d₁ − a：

**命题 5.2-1（三行关系式）**

```
d₂ = √(Δ² + b²),      cos φ = Δ/d₂,      sin φ = |b|/d₂
```

**证明**：G→S₁ = (−d₁, 0)，G→S₂ = (−Δ, b)。两向量点积为 d₁Δ，模长分别为 d₁ 与 d₂，故 cos φ = Δ/d₂；又 sin²φ = 1 − cos²φ 且 d₂² = Δ² + b²，得 sin φ = |b|/d₂。证毕。

**三行关系式的三重作用**（写一段解读）：
1. φ 只通过 Δ 与 b 依赖几何，**与 d₁ 的绝对值解耦**——这是鲁棒化的可操作基础；
2. `sin φ = |b|/d₂` 直接给出退化条件：**b = 0 ⇒ sin φ = 0**；
3. `cos φ = Δ/d₂` 直接给出最优条件：**Δ = 0 ⇒ φ = 90°**。

**坐标归约的合法性**：旋转与平移不改变距离与夹角，故归约不损失一般性；实现时须做逆变换回原坐标。

## 八、5.2.4 最优性定理（对应 B477"命题+证明"）

### 8.1 目标函数

> 一条方位线存在角误差 ε 时，其横向位置偏移为 d·ε（距离乘角度）；两线交点处的位置不确定度被 1/sin φ 放大，合成得

```
E(S₂) ≍ ε·√(d₁² + d₂²) / sin φ
```

**三因子的物理含义**：ε（观测精度）× √(d₁²+d₂²)（尺度因子）× 1/sin φ（几何放大因子，即两站 GDOP）。

**注**：E 并非启发式近似。引入 Fisher 信息矩阵 M = JᵀJ（J 为方位观测对源位置的雅可比矩阵）可得闭式

```
det M = sin²φ / (σ⁴d₁²d₂²),      trace(M⁻¹) = d₂²(d₁²+d₂²) / b²
```

从而 **E = ε·√(trace M⁻¹)**，即 **1σ 位置的均方根误差**。故本文的目标函数是**A-最优实验设计准则**，而非经验公式。

### 8.2 定理 5.2-1（正交最优性）与命题 5.2-2（外接圆分解）

> **陈述**：固定 d₁ 与 |b| > 0，则 E 关于 a 在 **a = d₁** 处取得唯一极小。
>
> **证明**：在归约坐标下 E = ε·√(d₁² + Δ² + b²)·√(Δ² + b²)/|b|，其中 Δ = d₁ − a。注意 Δ 仅以 **Δ²** 的形式出现，而两个因子 √(d₁²+Δ²+b²) 与 √(Δ²+b²) 均关于 Δ² 单调递增，故 E 关于 Δ² 单调递增，在 Δ² = 0 处取唯一极小，即 a = d₁。证毕。

**推论 5.2-1**：此时 cos φ = 0，即 **φ = 90°**；两条视线正交，位置误差椭圆各向同性。

**推论 5.2-2（几何表述）**：最优第二检测点落在"过源、且垂直于视线 S₁G"的直线上，即与源**正侧方对齐**。

**推论 5.2-3（Thales 等价）**：φ = 90° 等价于**源 G 落在以 S₁S₂ 为直径的圆上**（Thales 定理）。

**命题 5.2-2（外接圆分解：正交最优性的第二证明）**

记 `L = |S₁S₂|`、`R_c` 为 △S₁GS₂ 的外接圆半径。由正弦定理 `L/sin φ = 2R_c`，目标函数可**正交分解**为

```
E = ε·√(d₁² + d₂²) · ( 2R_c / L )
     ╰── 尺度因子 ──╯   ╰ 形状因子 ╯
```

**命题**：形状因子 `2R_c/L ≥ 1`，等号当且仅当 `φ = 90°`。
**证明**：`L = 2R_c·sin φ ⇒ 2R_c/L = 1/sin φ ≥ 1`，等号 ⟺ `sin φ = 1` ⟺ `φ = 90°`。∎

**推论 5.2-4（最优构型的刻画）**：最优第二检测点使 △S₁GS₂ **在源处直角**，且其**外接圆恰以 S₁S₂ 为直径**（即命题 5.2-2 的 Thales 圆）。

**注（两条证明的分工）**：定理 5.2-1 给出最优点的**位置坐标**（由 E 关于 Δ² 单调）；命题 5.2-2 给出最优构型的**几何形状**（由正弦定理）。两者结论一致、互为补充。

### 8.3 命题 5.2-3（准则无关最优性）

> **陈述**：上述最优性结论与设计准则无关——A-最优（min trace M⁻¹）、D-最优（max det M）与 E 极小三者给出同一最优第二点 a = d₁。
>
> **证明**：M 的四个元素中，Δ 只以 Δ²、以及非对角元中的 Δ·|b|·sign(Δ) 形式出现。后者对应坐标轴的反射，**不改变 M 的特征值**。故 M 的谱只依赖 Δ²，即所有谱准则的最优解均在 Δ = 0。证毕。

**注**：这一条把"正侧方最优"从"我们选了个好目标函数的结果"升级为"**几何本身决定的性质**"。

### 8.4 退化命题

> **命题 5.2-4（退化）**：若 b = 0，则 S₁、S₂、G 三点共线，两条视线重合，sin φ = 0，E 发散。
> **推论**：**沿示向度方向前进对定位零信息增益**，必须横向偏移。

**注（与问题三的联系）**：这一反直觉结论解释了问题三中"侦察扫描"与"渐进逼近"为何是两种不同的动作——前者需要横向几何，后者只需沿视线收敛。

## 九、5.2.5 候选区域求解

### 9.1 鲁棒化

源距未知 ⇒ Δ = d₁ − a，取 a = d̂（最优估计），则 |Δ| ≤ Δd。要求两项约束对**所有** Δ 成立：

```
角度质量： sin φ ≥ sin φ_min   ∀Δ   ⟹   |b| ≥ Δd·tan φ_min  =: b_min
可探测：   d₂ ≤ R_worst        ∀Δ   ⟹   |b| ≤ √(R_worst² − Δd²) =: b_max
```

**候选区域（简化版）**：

```
A = { S₁ + d̂·u + b·v :  b ∈ ±[b_min, b_max] }        —— 两条对称线段
```

**候选区域（完整版）**：允许 a 偏离 d̂，令 `a_span = R·cos φ_min − Δd`、`m(a) = |a − d̂| + Δd`，则

```
A' = { S₁ + a·u + b·v : |a − d̂| ≤ a_span,   m(a)·tan φ_min ≤ |b| ≤ √(R² − m(a)²) }
```

—— (a,b) 平面上的两片"翼形"。

### 9.2 主动暴露取舍（学 2007）

> 本文同时给出两级答案：简化版把 a 锁定为最优估计 d̂，候选区域退化为两条对称线段，**可直接执行**；完整版允许 a 在其可行范围内变动，区域扩张为两片翼形，**展示模型的一般性**。两者的取舍在于：简化版便于现场执行，完整版便于灵敏度分析。

### 9.3 关于不引入优化算法的说明

> 本问的最优条件由定理 5.2-1 以闭式给出，候选区域的边界由两条不等式直接解出，**无需任何迭代搜索**。若对本题使用模拟退火或梯度下降，不仅不能提高精度，反而掩盖了问题可解析求解的本质。网格扫描在本问中仅用于**验证与出图**，不用于求解。

## 十一、5.2.7 可行性与界的验证（对应 B477"三层下界+上界=可行区间"）

### 11.1 先给界（Q2 版的"表 1.0"）

**命题 5.2-5（可行性不等式）**

> 候选区域非空 ⟺ **Δd · sec φ_min ≤ R_worst** ⟺ **Δd ≤ R_worst · cos φ_min**。
> 等价地，**源距不确定半径为 Δd 时，可保证的交会角上界为 φ_min ≤ arccos(Δd / R_worst)**。

> **本定理是定理 5.2-3 在 $α = 0$ 时的特例**。当把题目给定的示向度误差区间一并纳入最坏化时，其结论须按定理 5.2-3 修正——该定理给出双约束组（角度 / 距离分别最坏化），基准参数下 $b_{\min}^{α} = 650.00$ m $> b_{\max}^{α} = 638.00$ m（候选区为空集），可达上界降为 **39.6161°**。

**证明**：需 b_min ≤ b_max，即 Δd·tan φ_min ≤ √(R² − Δd²)。两端非负，平方得 Δd²tan²φ_min ≤ R² − Δd²，即 Δd²(tan²φ_min + 1) ≤ R²。由 tan²+1 = sec² 得 Δd·sec φ_min ≤ R，等价变形即 Δd ≤ R·cos φ_min。证毕。

### 11.2 再给结果

| 量 | 值 |
|---|---|
| 本算例 φ_min 上界（$α = 0$，定理 5.2-2） | arccos(747.5/1000) = **41.63°** |
| **含示向度误差的上界（定理 5.2-3）** | **39.6161°**（且 $φ_{\min}=40°$ 下候选区为空集） |
| Δd 可行上限 | 1000·cos 40° = **766.044 m** |
| 本文取 φ_min | 40°（接近可行上限） |

**论证句式**（学 2007"结果落在区间内 = 正确性验证"）：

> 本算例所取 $φ_{\min} = 40°$ 接近理论上界，说明在源距完全未知的条件下候选区域已逼近先验信息所能支持的极限。**这一上界不是算法不足，而是信息量的硬限制**：单条方位线不含距离信息，能补充的方向信息有限。把示向度误差 $α \in [−1°,1°]$ 一并纳入最坏化后，上界降至 **39.6161°**，且 $φ_{\min} = 40°$ 不可达——**"源距未知"与"示向度误差"是两个独立的信息缺口**，前者给出 $\arccos(Δd/R)$，后者再削去约 2°。若以场强估计或目标区域几何先验缩小源距的不确定度，$Δd$ 减小，可保证的交会角随之提高。

## 十二、灵敏度与评价（诚实）

### 12.1 灵敏度分析

1. **Δd 灵敏度**：Δd 越小（源距越确定），b_min 越小、可行域越宽、φ_min 上界越高
2. **φ_min 灵敏度**：φ_min 越大，候选区域越窄，直至不可行
3. **R_worst 灵敏度**：按 1000 设计 vs 按 1500 设计，候选区宽度的差异（保守设计的代价）
4. **d̂ 灵敏度**：基准先验区间是否可被目标圆域几何收紧

### 12.2 诚实局限（**必须写**）

| 局限 | 诚实表述 |
|---|---|
| **源距完全未知时存在硬上界** | 由命题 5.2-5，Δd=747.5、R=1000 时可保证的交会角不超过 41.63°；**再计入示向度误差 `α` 后为 39.6161°**（2026-09-11 联合校验）。这不是算法问题，而是信息量的限制 |
| **"最优"依赖对 d₁ 的估计** | 定理 5.2-1 的 a = d₁ 在 d₁ 未知时只能取 a = d̂，故最优性在估计意义下成立 |
| **R 取最坏值会牺牲性能** | 按 1000 设计保证"必然收到信号"，但若实际接收半径为 1500，候选区域本可宽得多 |
| **不适用于定向干扰源** | 本问限定全向源；定向源存在 ±90° 覆盖扇区，可探测性判据需修改（属问题四） |
| **E 与 D 并非固定比例** | E（RMS）与定位区域直径 D（最坏两点）是两种度量，实测比值随几何在 2.43 至 2.00 间变化，不可互换 |

### 12.3 改进方向

1. **多点序贯设计**：每取得一次新观测即可更新源距的先验区间，Δd 逐步收紧，交会角质量随之提升
2. **利用目标圆域几何收紧 d₁ 先验**：若检测点位置已知，可由"源在半径 1800 m 圆域内"进一步压缩 d₁ 的可行范围
3. **R 的不确定性权衡**：给出"按 1000 保守设计"与"按 1250 冒一定风险设计"的候选区域宽度对比，供实际决策

## 十三、摘要写法

> ⚠️ 不得沿用 B477 摘要。

> 针对"已知单个检测点的示向度、如何选择第二个检测点"这一问题，本文将其识别为**带未知源距的鲁棒实验设计**，而非参数估计。本文首先以交会定位的位置不确定度 E ≍ ε·√(d₁²+d₂²)/sin φ 量化"定位效果好"（该式经 Fisher 信息矩阵验证恰为均方根位置误差，即 A-最优设计准则），并由几何关系证明**正交最优性定理**：使交会角达到 90° 的充要条件是第二检测点与干扰源沿视线方向"正侧方对齐"（即 a = d₁），此时以 S₁S₂ 为直径的圆必过源（Thales）。进一步证明该结论与设计准则无关（A-最优、D-最优与 E 极小给出同一最优点）。由于源距 d₁ 完全未知，本文由其可得信息推出 d₁ ∈ (5, 1500]，并以区间半宽 Δd = 747.5 m 做最坏情况鲁棒化，得到候选区域 `S₂ = S₁ + d̂·u + b·v, b ∈ [Δd·tan φ_min, √(R²−Δd²)]`（R 取最坏接收半径 1000 m）。相应推出**可行性不等式 Δd ≤ R·cos φ_min**，指出源距完全未知时可保证的交会角不超过 41.63°；进一步把示向度误差 $α \in [−1°,1°]$ 与源距不确定度一并最坏化，上界降至 **39.62°**——"源距未知"与"示向度误差"是两个独立的信息缺口，共同构成硬限制。基准参数下得 $b \in [627.23, 664.26]$ m（$α = 0$ 时），名义定位误差约 17.1 m。与问题一的交叉验证表明：将该规则用于问题一算例，定位区域直径由 39.598 m 降至 **35.41 m（降幅 10.57%）**。
