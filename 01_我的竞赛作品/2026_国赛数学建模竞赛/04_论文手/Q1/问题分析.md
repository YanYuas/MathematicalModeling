# 二、问题分析（问题一：定位区域直径与覆盖判定）

## 2.1 问题背景与定位

无线电干扰源的定位与清除是无线电频谱管理的重要任务，其中利用多站示向度交会确定干扰源所在区域，是"区域性排查→精准定位"链条上的关键环节。国际电信联盟 **ITU-R SM.854-3** 建议书对"示向度""交会定位""定位精度"等术语给出了标准定义[11]，本文对上述概念的表述均以此为术语锚点。

问题一的核心任务为：在给定若干检测点及其带 ±1° 误差的示向度条件下，构造交会定位区域并求其直径，同时判定以该直径为直径的圆能否覆盖该定位区域。

## 2.2 任务结构：计算与判定两类任务须分开处理

问题一包含两项性质不同的任务，二者的性质、目标与写法完全不同，必须在分析阶段首先讲清：

| 任务 | 性质 | 要求 |
|---|---|---|
| **(1) 计算任务** | **确定性几何计算**（P 类，多项式可解） | 构造交会定位区域 L，并精确求其直径 D；给出算法、复杂度与实现验证 |
| **(2) 判定任务** | **证伪型判定** | "以 D 为直径的圆能否覆盖 L"以"能否"设问，须给出**反例、充要判据与正确替代**四层回答，而非仅答"能/不能" |

**本文需要特别指出：问题一不属于优化问题。** 定位区域由输入唯一确定，本文的任务是把它精确计算出来，而非在若干可行方案中寻优；因此本文采用**精确的凸几何算法**，不引入任何启发式搜索方法（模拟退火、遗传算法等）。与之相对，若题目改为求干扰源的**点估计**（单点坐标）而非区域，则退化为经典的方位交会加权最小二乘估计问题（Stansfield, 1947）[5]——本文求的是**区域**，故不采用该估计路线，仅在此说明口径差异。

## 2.3 三个难点

**难点一：示向度必须"升格"为区域，而非"线"。** 单条示向度只含方向信息，源在该方向上的距离完全未知。若将示向度视为一条精确射线，则两条射线交于一点、区域退化为点、直径为零，与题设"误差在 ±1° 范围内"直接矛盾；若将误差建模为概率分布，则区域成为水平集、一般非凸，凸几何工具全部失效。**正确的抽象是把一条带误差的示向度升格为一个 2° 角域（有界不确定性模型）**——这是全问的建模起点。

**难点二："以直径为直径的圆"与直觉相悖。** 直觉认为"直径是区域内最远两点距离，则以它为直径的圆当然能覆盖整个区域"。此直觉有误：**直径约束的是"任意两点之间的距离"（两两约束），而圆覆盖约束的是"所有点到某个固定圆心的距离"（单点约束）**，后者严格更强——等边三角形即给出反例。

**难点三：退化情形必须分类处理。** 检测点数不足、两条示向度近乎平行（源极远）、数据自相矛盾等情形下，定位区域可能无界或为空，直径未定义。这些情形必须**显式判定**并报告（"无界""无可行区域"），而非返回异常值或 NaN。

## 2.4 本文思路：升格 → 表示 → 定理 → 算法 → 验证

对此，本文采用"**升格 → 表示 → 定理 → 算法 → 验证**"五步路线：

1. **升格**：把示向度抽象为 2° 角域（有界不确定性模型），使误差成为几何对象的内建结构；
2. **表示**：证明角域为两半平面之交，从而定位区域必为凸多边形；
3. **定理**：建立凸性、顶点枚举与过滤、有界性三条定理，每条落一条实现红线；
4. **算法**：以四件套（构造区域 → 凸包 → 直径 → 最小包围圆）精确求解，直径与最小包围圆各设两套独立实现交叉验证；
5. **验证**：以 **Jung 夹逼** `D/2 ≤ R_MEC ≤ D/√3` 作为理论基准[1]，对覆盖问题给出**反例—判据—定量界—结构定理**四层回答，并以"理论界 + 实算值 + 全量校验"三元组自证正确性。

**复杂度判定（问题类型）**：角域为两个闭半平面之交，n 个角域即 2n 个半平面求交，可在 **O(n log n)** 内完成；凸包采用单调链（Andrew, 1979）[4]，O(m log m)；直径采用旋转卡壳（Toussaint, 1983）[3]，O(m log m)，并以 O(m²) 暴力枚举互验；最小包围圆采用随机增量算法（Welzl, 1991）[2]，期望 O(n)，并以 O(n³) 暴力互验。**全问为多项式可解的确定性问题**，故不引入任何启发式或近似方法。

## 2.5 与问题二的联系

问题一求得的直径 D 与最小包围圆半径 R_MEC，是刻画定位不确定度的**几何度量**，恰好为问题二"较好的定位效果"提供可量化目标——**问题一是问题二的评价函数**。进一步地，若引入 Fisher 信息矩阵 M = JᵀJ（J 为方位观测对源位置的雅可比矩阵），则本问的 D（最坏两点距离，精确非线性）与 RMS 位置误差 E（线性化）是同一不确定度的两种描述，二者共享同一信息矩阵[6]——**问题一与问题二因此构成一对伴随问题**：前者把观测映射为区域，后者用同一度量评价候选测点。

## 附：可直接粘贴的核心段（合并版）

> 问题一的核心任务为：在给定若干检测点及其带 ±1° 误差的示向度条件下，构造交会定位区域并求其直径，同时判定以该直径为直径的圆能否覆盖定位区域。该问题**不属于优化问题**——定位区域由输入唯一确定；其难点在于：示向度的误差使区域成为连续凸区域而非点，须先完成"观测→区域"的抽象；直径与圆覆盖是两种不同的几何约束，直觉易误判；退化情形（无界、空集）必须分类处理。对此，本文采用 **2° 角域**刻画示向度不确定性（有界不确定性模型），证明角域为两半平面之交从而定位区域必为**凸多边形**，以精确凸几何算法（半平面交 O(n log n) → 凸包 O(m log m) → 直径/最小包围圆双实现互验）求解直径，并对覆盖问题给出**反例—判据—定量界**的四层回答（等边三角形反例 / Thales 充要判据 / Jung 夹逼 D/2 ≤ R_MEC ≤ D/√3）。
