## 三、问题分析怎么写（对应 2007"先定五因素"）

**Q1 不是优化问题**——定位区域 L 由输入唯一确定，我们要把它**精确算出来**。所以"目标结构"= **任务结构**。

**沿用 B477 问题分析的句式**（"核心任务为…难点在于…对此，本文…"）：

> 问题一的核心任务为：在给定若干检测点及其带 ±1° 误差的示向度条件下，构造交会定位区域并求其直径，同时判定以该直径为直径的圆能否覆盖定位区域。该问题不属于优化问题——定位区域由输入唯一确定；其难点在于：示向度的误差使区域成为连续凸区域而非点，须先完成"观测→区域"的抽象；直径与圆覆盖是两种不同的几何约束，直觉易误判；退化情形（无界、空集）必须分类处理。对此，本文采用 **2° 角域**刻画示向度不确定性（有界不确定性模型），证明角域为半平面之交从而定位区域必为凸多边形，以精确凸几何算法求解直径，并对覆盖问题给出**反例—判据—定量界**的四层回答。

**必须写清的三个点**：
1. **升格**：示向度 → 2° 角域（不是射线、不是概率分布）
2. **无优化无启发式**：L 由输入唯一确定 ⇒ 精确算法
3. **复杂度**：角域 = 两半平面 ⇒ 2n 半平面交 O(n log n)；凸包 O(m log m)；直径 O(m log m)/O(m²)；MEC 期望 O(n)。**全题多项式可解**

## 五、5.1.1 交会定位的几何本质

> 交会定位的复杂性来源于**方位观测只含方向信息**：单个检测点仅给出一条方位线，源在该线上的距离完全未知，故单站不可定位；多站交会通过多个方向约束的交集把"线"压成"区域"。由于示向度存在 ±1° 误差，该区域不是点而是一个**角域之交**。

**沿用 B477 的"核心追问"句式**：

> 核心追问是：能否让"不重叠/合法性"成为编码的内建性质？ —— B477（对照）
> 核心追问是：能否把"误差"从需要额外处理的扰动，变成几何对象本身的内建结构？**角域正是这个内建结构**——把误差直接写进区域的定义，后续所有运算都在精确几何内完成，无需任何误差传播近似。

**复杂度**：角域 = 2 个闭半平面 ⇒ 2n 个半平面求交 ⇒ O(n log n)；**P 类，无启发式**。

## 七、5.1.3 角域与定位区域的表示

**写法**：先给角域定义，再给**两半平面等价式**，最后一句点透凸性。

```
角域： W(S,θ,ε) = { S + t·u(φ) : t ≥ 0, |angdiff(φ,θ)| ≤ ε }
等价： W = {X : cross(u₋,X−S) ≥ 0} ∩ {X : cross(u₊,X−S) ≤ 0},  u± = u(θ±ε)
定位区域： L = ⋂ᵢ Wᵢ
```

**必须显式声明**（否则实现口径打架）：
- 角域是 **t ≥ 0 的射线族**，不是直线族
- 角域取**闭集**（含 ±1° 边界）
- **不与目标圆域求交**（主口径；题面未给圆域约束）

## 八、5.1.4 三个定理（沿用 B477"命题+证明"格式）

B477 用 **命题 1 + 证明 1** 保证"模型与题设一致"。Q1 用**三个定理**，**每个定理落一条实现红线**（把数学严谨性直接转成工程可靠性）。

### 定理 1（凸性）
> **陈述**：每个 Wᵢ 为两闭半平面之交，故为凸集；有限交仍凸 ⇒ 定位区域 L 是**凸多边形**。
> **证明**：`cross` 关于 X 线性 ⇒ 两个集合均为闭半平面；半平面凸，凸集之交凸。∎
> **推论**：L 上最远点对必在极点取到 ⇒ 直径可枚举顶点求得。
> **实现红线**：无（这是"能多项式求解"的根基）。

### 定理 2（顶点枚举与过滤）
> **陈述**：L 的每个顶点必是某两条角域边界射线的交点；**但反向不成立**。
> 故 `P 是 L 的顶点 ⟺ t ≥ 0 ∧ s ≥ 0 ∧ ∀k: P ∈ Wₖ`。
> **证明（正向）**：L 的边界由各角域边界射线片段拼成，两片段相接处即顶点。∎
> **实现红线**：漏掉 `∀k` 过滤 ⇒ 凸包含假点、D 偏大。**这是 Q1 第一大实现坑。**

### 定理 3（有界性判据）
> **陈述**：`L = ⋂Wᵢ` 有界 ⟺ 各方向区间 `[θᵢ−ε, θᵢ+ε]` 之交为空。
> **证明**：凸集的回收锥 `recess(⋂Wᵢ) = ⋂recess(Wᵢ)`；L 有界 ⟺ `recess(L)={0}` ⟺ 无公共方向。∎
> **推论**：n=2 时 L 无界 ⟺ `|θ₁−θ₂| < 2ε = 2°`。
> **实现红线**：不有界时须报"无界"，**不得返回 NaN**。

## 九、5.1.5 求解算法设计

**四件套 + 双实现互验**（对应 2007"双求解器互补"）：

| 环节 | 方法 A | 方法 B | 复杂度 | 选用 |
|---|---|---|---|---|
| 构造 L | 射线两两求交 + 过滤 | 半平面交 | O(n³) / O(n log n) | **n≤8 用 A**；n 大用 B |
| 凸包 | Andrew 单调链 | — | O(m log m) | 单调链（严格去共线点） |
| 直径 | **旋转卡壳** | **O(m²) 暴力** | O(m log m) / O(m²) | **两者都实现，结果必须完全一致** |
| 最小包围圆 | **Welzl 随机增量** | **O(n³) 暴力** | 期望 O(n) / O(n³) | 同上，容差 1e-9 |

**主动暴露取舍**（学 2007"用方案的丰富性取代计算的准确性"）：

> 本题顶点数 m ≤ 2n 且 n 为个位数至十几，**性能并非瓶颈**。故本文对直径与最小包围圆各实现两套独立算法并强制结果一致——**双实现互验是离散几何实现中最有效的 bug 探测手段**，其价值在正确性自证而非速度。

**"为何不引入启发式算法"**（对应 B477 的"试错调整"段，写成一段诚实说明）：

> B477 曾记录"模仿参考论文采用模拟退火，理论成立、实践频发问题"的教训。与之相对，本问在问题分析阶段即判定为 **P 类确定性几何问题**（区域由输入唯一确定、无组合爆炸、有精确算法），因此**不引入任何启发式算法**。若误用模拟退火类方法，不仅无益，反而说明未识别出问题类型。

**必写参数**：`ε = 1°`、几何比较容差 `1e-9`、行列式判平行阈值 `1e-12`。

## 十一、5.1.7 覆盖判定与 Jung 界验证（对应 B477"三层下界+构造上界=可行区间"）

**B477 的做法**：三层下界（总面积 / 近方形 / 固定宽）+ 构造性上界 = 方形边长**可行区间**，结果居中 ⇒ 可信。
**Q1 的对应**：**Jung 夹逼取代"可行区间"的角色**。

### 11.1 先给界（Q1 版的"表 1.0"）

> **Jung 定理（1901）**：平面上直径为 D 的点集必可被半径 `R ≤ D/√3` 的圆覆盖。
> 结合显然下界 `R ≥ D/2`，得 **`D/2 ≤ R_MEC ≤ D/√3 ≈ 0.5774 D`**。
>
> **上界证明**：最小包围圆圆周上有 2 或 3 个支撑点。
> 2 点：必互为对径 ⇒ R = D/2 ≤ D/√3；
> 3 点：构成三角形，最大角 α ≥ 60°，其对边 s ≤ D，由正弦定理 `s = 2R sinα ≥ √3 R` ⇒ R ≤ D/√3。∎

### 11.2 再给结果

| 量 | 值 |
|---|---|
| 实测 R_MEC | 19.799 m（= D/2，**下界取等**） |
| Jung 理论区间 | [19.799, 22.863] |
| 全部扫描算例 | 均满足 `D/2 ≤ R_MEC ≤ D/√3`，无违例 |

**论证句式**（学 B477"结果落在区间内 = 正确性验证"）：

> 本文实算结果位于 Jung 理论区间的**下端点**，即该算例的直径圆恰好覆盖。更重要的是，**该夹逼关系对全部扫描算例成立、无任何违例**——因此 Jung 界不仅是对结果质量的论证，同时充当了实现的**自动正确性检验**（结果低于下界意味着实现有误）。本文以"理论界 + 实算值 + 全量校验"三元组如实报告，不宣称已证明最优。

## 十二、覆盖问题的四层回答（本问最大得分点）

题面只问"能否覆盖"，但**完整回答必须四层递进**——这节写法直接决定 Q1 的得分档次。

### 12.1 第一层：反例（答"不能"）
> 取 L 为等边三角形，边长 a，则 D = a。以任一边 AB 为直径作圆（圆心为 AB 中点、半径 a/2），顶点 C 到该圆心距离为高 `(√3/2)a ≈ 0.866a > 0.5a` ⇒ **C 在圆外，不覆盖**。

**配图 5.1-3（必画）**：等边三角形 + 直径圆（对角顶点在圆外）+ 外接圆对照。

### 12.2 第二层：充要判据（Thales）
> `X 在以 PQ 为直径的圆内 ⟺ ∠PXQ ≥ 90°`。
> **证明**：设 M = (P+Q)/2，则 `‖X−M‖² − (D/2)² = (X−P)·(X−Q)`。左 ≤ 0 ⟺ 在圆内；右 ≤ 0 ⟺ ∠PXQ ≥ 90°。∎
> **判据**：`D-圆覆盖 L ⟺ 对 L 的每个顶点 X，∠PXQ ≥ 90°`。

**为何只需校验顶点**（必须写清，否则是逻辑跳跃）：圆盘凸、L 为凸多边形且 `L = conv(V)` ⇒ `V ⊆ 圆盘 ⟹ L ⊆ 圆盘`。

### 12.3 第三层：正解 + 定量界
> 正确做法是求**最小包围圆**，半径由 Jung 定理夹在 [D/2, D/√3]；以 D 为直径的圆最坏比所需圆**小 `2/√3 − 1 ≈ 15.5%`**。

### 12.4 **第四层：结构定理（本问最有辨识度的一层，2026-09-11 新增）**
> 前三层回答"对一般凸区域"；本层回答"**对本模型能生成的定位区域族**"。

**要写三件事**：

1. **定理（可给完整证明）**：中心对称紧凸集 K ⇒ `γ ≡ 1`。
   *证*：MEC 唯一 + K 中心对称 ⇒ 圆心 = 对称中心 c ⇒ `R_MEC = max‖x−c‖`；对径点 `2c−x ∈ K` ⇒ `D = 2max‖x−c‖` ⇒ γ = 1。∎
   *数值旁证*：正方形 / 一般平行四边形 / 中心对称六边形 γ = 1.000000；等边三角形 1.154692。

2. **结构观察**：L 的两条**对边**落在**同一顶点**的两条边界射线上，夹角**恰为 2ε**
   ⇒ **L 是"2ε-近平行四边形"**（n 站时"近平行 2n 边形"）⇒ 中心对称形状的 **O(ε) 扰动** ⇒ `γ = 1 + O(ε)`。

3. **数值实验**：ε = 0.05°~4° 的 γ−1 上界表；**题设 ε=1° 下 γ ≤ 1.01**（十余万组配置搜索）。

**结论句**：等边三角形（γ = 1.154701）**在本题区域族内不可达** ⇒ **对本题实际出现的定位区域，直径圆总能覆盖（至多差 3%）**。

**诚实边界**：`γ ≤ 1 + C·ε` 的常数 C 未定出，属开放问题；论文中**如实标注为实验发现**，不声称定理。

### 12.5 附加歧义（再深一层）
> **直径对可能不唯一**：凸多边形达到 D 的顶点对可能不止一组，**不同对给出不同的圆**，"能否覆盖"可能给出不同答案。本文报告三种口径（任取一对 / 存在一对 / 所有对都），并指出**唯一无歧义的做法是采用最小包围圆**。

|---|---|---|

| L2 | + 反例 | 良好 |
