## 摘要

针对带 ±1° 测向误差的交会定位精度问题，本文将"示向度"严格升格为 **2° 角域**（有界不确定性模型），证明角域为两半平面之交，从而定位区域必为**凸多边形**；据此以"边界射线两两求交 + 落在所有角域内过滤 + 单调链凸包"精确构造定位区域，并以**旋转卡壳与 O(m²) 暴力双实现**求其直径 D，两实现结果完全一致。针对"以 D 为直径的圆能否覆盖定位区域"，本文给出**四层递进回答**：以**等边三角形**为反例证明**对一般凸区域不能覆盖**；由 **Thales 定理**建立**充要判据**（覆盖 ⟺ 所有顶点处 ∠PXQ ≥ 90°）；指出正确做法是求**最小包围圆**，其半径由 **Jung 定理**严格夹在 [D/2, D/√3] 内，最坏缺口 2/√3 ≈ 15.5%，等边三角形取等；**第四层给出结构定理**——证明**中心对称紧凸集必满足 γ ≡ 1**，并观察到定位区域的两条对边来自同一检测点、夹角恰为 2ε，即定位区域是"**2ε-近平行四边形**"（中心对称形状的 O(ε) 扰动），故 **γ = 1 + O(ε)**，数值实验（数十万组配置）表明题设 ε=1° 下 **γ ≤ 1.01** —— **等边三角形在本题区域族内不可达，直径圆实际上总能覆盖**。基准算例（S₁=(0,0)、S₂=(600,0)、源 (300,500)、ε=1°）得 **D = 39.598 m、R_MEC = 19.799 m、缺口比 γ = 1.000**（该例下界取等、恰好覆盖）；全部实测算例均满足 Jung 夹逼关系，该关系同时充当实现的自动正确性检验。

**关键词**：交会定位；示向度；凸几何；旋转卡壳；Thales 定理；Jung 定理；最小包围圆

## 一、问题重述

### 1.1 问题背景

无线电干扰源的定位与清除是无线电频谱管理的重要任务。定位通常分三阶段：初步监测、区域性排查、精准定位。前两阶段由固定监测站、移动监测车或无人机进行大范围信号采集，确定干扰源的分布区域；而第三阶段——在目标区域内徒步逼近并最终清除——受环境遮挡与低功率源影响，仍需技术人员携带便携式测向机完成，效率低且存在人身风险。

测向机通过检测场强变化推断干扰源相对检测点的方位：将接收天线指向干扰源时场强最大，该方向对应的方位角称为**示向度**。由于环境电磁干扰与仪器精度限制，示向度与真实方位角之间存在误差；在一段时间内同一地点的误差固定，不同地点则呈现统计规律，全局误差落在 ±1° 范围内。多个检测点的示向度方向线相交，即可把干扰源定位到一片区域内。

### 1.2 问题提出

**问题一**：已知若干检测点坐标及某干扰源关于这些检测点的示向度，请给出采用交会定位法计算**多边形定位区域直径**（即区域内任意两点之间距离的最大值）的算法。**以定位区域直径为直径的圆能否覆盖此定位区域？**

## 二、问题分析

### 2.1 任务结构

问题一包含两项性质不同的任务，须分别处理：

| 任务 | 性质 | 要求 |
|---|---|---|
| **(1) 计算任务** | 给定检测点与示向度，构造交会定位区域并求其直径 | 这是一个**确定性几何计算问题**（P 类，多项式可解），要求给出算法并保证精确 |
| **(2) 判定任务** | 判断"以直径为直径的圆"能否覆盖该区域 | 这是一个**证伪型判定问题**。题面以"能否"设问，完整回答需给出**反例、充要判据与正确替代**，而非仅答"能/不能" |

**本文需要特别指出：问题一不属于优化问题。** 定位区域由输入唯一确定，本文的任务是把它精确计算出来，而非在若干可行方案中寻优。因此本文采用**精确的凸几何算法**，不引入任何启发式搜索方法。

### 2.2 三个难点

**难点一：示向度必须升格为"区域"，而非"线"。** 单条示向度只含方向信息，源在该方向上的距离完全未知。若将示向度视为一条精确射线，则两条射线交于一点、区域退化为点、直径为零，与题设"误差在 ±1° 范围内"直接矛盾；若将误差视为概率分布，则区域成为水平集、一般非凸，凸几何工具全部失效。**正确的抽象是把一条带误差的示向度升格为一个 2° 角域**——这是全问的建模起点。

**难点二："以直径为直径的圆"与直觉相悖。** 直觉认为"直径是区域内最远两点距离，那么以它为直径的圆当然能覆盖整个区域"。此直觉有误：**直径约束的是"任意两点之间的距离"（两两约束），而圆覆盖约束的是"所有点到某个固定圆心的距离"（单点约束）**，后者严格更强。

**难点三：退化情形必须分类处理。** 检测点数不足、两条示向度近乎平行、数据自相矛盾等情形下，定位区域可能无界或为空，直径未定义。这些情形必须显式判定而非返回异常值。

### 2.3 本文思路

对此，本文采用"**升格 → 表示 → 定理 → 算法 → 验证**"五步路线：

1. **升格**：把示向度抽象为 2° 角域（有界不确定性模型）；
2. **表示**：证明角域为两半平面之交，从而定位区域必为凸多边形；
3. **定理**：建立凸性、顶点枚举与过滤、有界性三条定理；
4. **算法**：以四件套（构造区域 → 凸包 → 直径 → 最小包围圆）精确求解，直径与最小包围圆各设两套独立实现交叉验证；
5. **验证**：以 **Jung 夹逼** `[D/2, D/√3]` 作为理论基准，并对覆盖问题给出**反例—判据—定量界—结构定理**四层回答。

## 五、模型的建立与求解

## 5.1 问题一：定位区域直径与覆盖判定

**● 题设关键点拆解**

- **示向度带误差**：观测不是精确方位，而是一个方向区间 → 约束从"射线"变为"角域"；
- **交会定位法**：附录 2 图 2 已把定位区域定义为两条示向度方向线及其 ±1° 边界所围的四边形 → 即**角域之交**；
- **多边形定位区域**：区域是"多边形"这一措辞本身给出了凸性的线索；
- **"以直径为直径的圆"**：直径与圆覆盖是两个不同的几何量，须辨析。

**数学抽象**

```
输入： n 个检测点坐标 S₁…Sₙ，对应示向度 θ₁…θₙ，误差半角 ε = 1°
决策： 无（定位区域由输入唯一确定，本问为计算与判定问题）
约束： 角域定义式（见 5.1.3）
主输出：定位区域直径 D
副输出：最小包围圆半径 R_MEC 与覆盖判定
```

---

### 5.1.0 数据与坐标约定

本问不含外部数据集（模拟器接口涉及问题三、四）。为使后续讨论具有统一参照，本节明确坐标与角度约定，并给出基准算例。

**坐标约定**：以圆域中心为原点，正东方向为 x 轴正向，正北方向为 y 轴正向，单位为米。

**角度约定**：所有方位角均自 x 轴正向逆时针度量，取值 [0°,360°)。为避免角度跨越零点时的环绕错误，本文定义**角度差函数**

```
angdiff(φ, θ) = ((φ − θ + 180°) mod 360°) − 180° ∈ (−180°, 180°]
```

**注**：若直接以 (φ − θ) 计算角差，则 θ = 359°、φ = 1° 将被算作 −358° 而非 +2°，导致角域方向完全错误。故本函数是全问的强制约定。

**误差口径**：示向度误差半角 ε = 1°，取**闭角域**（含边界）。

**基准算例**：为便于全篇对照与验证，本文构造基准算例 S₁=(0,0)、S₂=(600,0)、真源 G=(300,500)，误差半角 ε = 1°（等效示向度 θ₁ = 59.036°、θ₂ = 120.964°）。该算例的交会角为 61.92°，两站到源的距离均为 583.10 m。

**关键参数**：有效接收半径 R ∈ [1000,1500] m；光学精确清除半径 20 m；近距阈值 5 m；机器狗移动速度 5 m/s。其中接收半径与清除半径在问题三、四中起作用，此处列出以保证全篇参数一致。

### 5.1.1 交会定位的几何本质

交会定位的复杂性来源于**方位观测只含方向信息**：单个检测点仅给出一条方位线，源在该线上的距离完全未知，故单站不可定位；多站交会比合多个方向约束，才能把"线"压缩为"区域"。

**核心追问**：能否把"误差"从需要额外处理的扰动，转化为几何对象本身的内建结构？

本文的回答是**可以**——角域正是这一内建结构。将 ±1° 的误差直接写入区域的定义式后，后续所有运算均在确定性的凸几何内完成，**无需任何误差传播近似**。这既保证了结果精确，也使问题从"带噪估计"化简为"几何计算"。

**问题类型与复杂度判定**：角域为两个闭半平面之交，n 个角域即 2n 个半平面求交，可在 O(n log n) 内完成；凸包 O(m log m)；直径 O(m log m)（旋转卡壳）或 O(m²)（暴力）；最小包围圆期望 O(n)（随机增量）。**全问为多项式可解的确定性问题**。

### 5.1.3 角域与定位区域的表示

**定义 5.1.1（角域）** 设检测点 S、示向度 θ、误差半角 ε，定义**角域**

```
W(S, θ, ε) = { S + t·u(φ) : t ≥ 0, |angdiff(φ, θ)| ≤ ε }
```

**命题 5.1（角域的两半平面形式）** 记 u₋ = u(θ−ε)、u₊ = u(θ+ε)，则

```
W = { X : cross(u₋, X−S) ≥ 0 } ∩ { X : cross(u₊, X−S) ≤ 0 }
```

其中 cross(a,b) = aₓb_y − a_ybₓ。

**证明**：`cross(u₋, X−S) ≥ 0` 表示向量 X−S 位于 u₋ 的逆时针一侧；`cross(u₊, X−S) ≤ 0` 表示 X−S 位于 u₊ 的顺时针一侧。两者同时成立，当且仅当 X−S 的方向介于 u₋ 与 u₊ 之间（逆时针张开 2ε），即 X−S 与 u(θ) 的夹角不超过 ε。证毕。

**定义 5.1.2（定位区域）** 给定 n 个检测点及其示向度，**定位区域**为各角域之交：

```
L = ⋂ᵢ₌₁ⁿ Wᵢ
```

**注（三条口径声明）**：
1. 角域是 **t ≥ 0 的射线族**，不是直线族——若误用直线族，反向延伸的边界将产生虚假交点，使区域错误扩大；
2. 角域取**闭集**（含 ±1° 边界），以保证 L 为闭集、直径可达；
3. 本问的 L 为**纯角域之交**，不与目标圆域求交（题面未给出圆域约束）。

---

### 5.1.4 定位区域的三个定理

**定理 5.1（凸性）**

设 Wᵢ 为角域，则定位区域 L = ⋂ᵢ Wᵢ 是**凸多边形**。

**证明**：由命题 5.1，每个 Wᵢ 是两个闭半平面之交，而半平面是凸集，故 Wᵢ 为凸集。凸集的有限交仍为凸集，故 L 为凸集。又 L 由有限条直线围成，故 L 为凸多边形。证毕。

**推论 5.1**：L 上的最远点对必在 L 的极点（顶点）处取得。因此直径 D 只需在顶点集上枚举求得，无需遍历区域内部。

**注**：凸性是本问能够在多项式时间内精确求解的根本原因。若误差被建模为概率分布，区域将退化为水平集、一般非凸，本问随即由确定性计算问题变为困难问题。

**定理 5.2（顶点枚举与过滤）**

(i) L 的每个顶点必是某两条角域边界射线的交点；
(ii) 反之不成立——两条边界射线的交点未必属于 L。因此

```
P 是 L 的顶点  ⟺  t ≥ 0  ∧  s ≥ 0  ∧  ∀k: P ∈ Wₖ
```

其中 t、s 分别为 P 在两条边界射线上的参数。

**证明**：(i) L 的边界由各角域边界射线的片段拼接而成，两条片段的相接处即为顶点。(ii) 两条边界射线可以在 L 之外相交——例如当该交点落在某个第三角域之外时。故必须附加"落在所有角域之内"的过滤条件。证毕。

**注**：定理 5.2(ii) 是本问最易出错的实现环节。若省略 `∀k: P ∈ Wₖ` 的过滤，候选点集将包含大量位于区域之外的假点，导致凸包错误、直径偏大。

**定理 5.3（有界性判据）**

定位区域 L 有界，当且仅当各方向区间之交为空：

```
L 有界  ⟺  ⋂ᵢ [θᵢ − ε, θᵢ + ε] = ∅
```

**证明**：先给出两个引理。

**引理 5.1（回收锥对交的可分配性）** 设 C₁,…,Cₙ 为闭凸集且 ⋂ᵢCᵢ ≠ ∅。则

```
recess( ⋂ᵢ Cᵢ ) = ⋂ᵢ recess( Cᵢ )
```

*证明*：(⊆) 设 d ∈ recess(⋂ᵢCᵢ)。取 x ∈ ⋂ᵢCᵢ，则对一切 t ≥ 0 有 x + td ∈ ⋂ᵢCᵢ ⊆ Cᵢ，故 d ∈ recess(Cᵢ) 对每个 i 成立。
(⊇) 设 d ∈ ⋂ᵢrecess(Cᵢ)。取 x ∈ ⋂ᵢCᵢ，则对每个 i 与一切 t ≥ 0 有 x + td ∈ Cᵢ，故 x + td ∈ ⋂ᵢCᵢ，即 d ∈ recess(⋂ᵢCᵢ)。证毕。

**引理 5.2（有界性的回收锥刻画）** 非空闭凸集 C 有界，当且仅当 `recess(C) = {0}`。

*证明*：(⇒) 若存在 0 ≠ d ∈ recess(C)，取 x ∈ C，则 ‖x + td‖ → ∞（t → ∞），与 C 有界矛盾。
(⇐) 若 C 无界，取 x₀ ∈ C 与点列 xₙ ∈ C 满足 ‖xₙ − x₀‖ → ∞。令 eₙ = (xₙ − x₀)/‖xₙ − x₀‖，由单位圆的紧性取子列 eₙ → e（‖e‖ = 1）。对任意固定的 t ≥ 0，当 n 充分大时 t/‖xₙ − x₀‖ ≤ 1，由凸性

```
x₀ + t·eₙ = ( 1 − t/‖xₙ − x₀‖ )·x₀ + ( t/‖xₙ − x₀‖ )·xₙ ∈ C
```

令 n → ∞ 并由 C 为闭集得 x₀ + te ∈ C，对一切 t ≥ 0 成立，故 e ∈ recess(C) 且 e ≠ 0。证毕。

现证定理。角域可写为 Wᵢ = Sᵢ + Kᵢ，其中 Kᵢ 是以原点为顶点、张角 2ε 的闭凸锥；锥的回收锥为其自身，故 `recess(Wᵢ) = Kᵢ`。当 L ≠ ∅ 时，由引理 5.1

```
recess(L) = ⋂ᵢ recess(Wᵢ) = ⋂ᵢ Kᵢ
```

再由引理 5.2，`L 有界 ⟺ ⋂ᵢKᵢ = {0}`，即各角域不存在公共方向，等价于 `⋂ᵢ[θᵢ − ε, θᵢ + ε] = ∅`。证毕。

**推论 5.2**：n = 2 时，L 无界当且仅当 |θ₁ − θ₂| < 2ε = 2°，即两检测点近乎朝同一方向观测（对应源极远、两视线近乎平行）。

**注**：定理 5.3 把题面中含糊的"退化情形"转化为**可计算、可验证的充要条件**。实现中若判定为无界，应显式报告"无界"而非返回异常值。

### 5.1.5 求解算法设计

#### (1) 总体框架

由定理 5.1~5.3，本问的求解框架为四件套：

```
Step 1  角域构造：对每个 i 生成两条边界射线 rᵢ^± = Sᵢ + t·u(θᵢ ± ε)，t ≥ 0
Step 2  求交与过滤：枚举射线对求交，保留满足 t ≥ 0 ∧ s ≥ 0 ∧ ∀k: P ∈ Wₖ 的交点
Step 3  凸包：对候选顶点施行单调链凸包，得严格顶点序列 V
Step 4  度量：在 V 上求直径 D 与最小包围圆 R_MEC
```

#### (2) 双实现交叉验证

**核心追问**：能否让"正确性"通过算法本身自证，而非依赖外部真值？

本问顶点数 m ≤ 2n，而实际检测点数 n 为个位数至十几，**计算性能并非瓶颈**。因此本文对两个关键量各实现两套相互独立的算法，并要求结果完全一致：

**表 5.1-3　双实现交叉验证**

| 环节 | 实现 A | 实现 B | 一致性要求 |
|---|---|---|---|
| 直径 D | 旋转卡壳（Toussaint, 1983） | O(m²) 暴力枚举 | **完全相等** |
| 最小包围圆 R_MEC | Welzl 随机增量（Welzl, 1991） | O(n³) 暴力（枚举点对定圆 + 三点定外接圆） | 差 < 10⁻⁹ |

双实现互验是离散几何实现中最有效的缺陷探测手段：两套独立算法给出不同结果即意味着必有一处存在错误。其价值在于**正确性自证**，而非速度。

#### (3) 关于不引入启发式算法的说明

**本问明确不采用任何启发式优化算法（模拟退火、遗传算法等）。** 理由有三：

其一，**问题类型判定**：定位区域由输入唯一确定，不存在"候选方案集合"，故本问不是优化问题；
其二，**可精确求解**：由定理 5.1，问题为凸几何计算，存在多项式时间的精确算法；
其三，**误用代价**：对确定性几何问题使用随机搜索，不仅无法提高精度，反而引入不可复现性与额外误差。

### 5.1.7 覆盖判定与 Jung 界验证

#### (1) 覆盖问题的四层回答

**第一层：反例——一般不能覆盖**

**命题 5.2（反例）** 存在定位区域 L，使得以 L 的直径为直径的圆不能覆盖 L。

**证明（构造成立）**：取 L 为边长为 a 的等边三角形 ABC，则其直径 D = a（任一边均为直径对）。以边 AB 为直径作圆，圆心为 AB 中点 M，半径为 a/2。顶点 C 到 M 的距离等于三角形的高：

```
|CM| = (√3/2)·a ≈ 0.866a > 0.5a
```

故 C 位于圆外，该圆不能覆盖 L。证毕。

**注**：用 Thales 定理表述更为简洁——∠ACB = 60° < 90°，故 C 不在以 AB 为直径的圆内。

**第二层：充要判据——Thales 定理**

**定理 5.4（圆内判据）** 设 P、Q 为直径两端点，D = |PQ|，M = (P+Q)/2，则对任意点 X：

```
X 在以 PQ 为直径的圆内（含边界）  ⟺  ∠PXQ ≥ 90°
```

**证明**：由 M 的定义可直接验证恒等式

```
‖X − M‖² − (D/2)² = (X − P)·(X − Q) = ‖P−X‖·‖Q−X‖·cos∠PXQ
```

左端 ≤ 0 等价于 X 在以 PQ 为直径的圆内；右端 ≤ 0 等价于 cos∠PXQ ≤ 0，即 ∠PXQ ≥ 90°。证毕。

**推论 5.3（可计算判据）** 设 P、Q 为 L 的某组直径端点，则

```
以 PQ 为直径的圆覆盖 L  ⟺  对 L 的每个顶点 X，均有 ∠PXQ ≥ 90°
```

**证明**：圆盘为凸集，L 为凸多边形且 L = conv(V)（V 为顶点集）。故若 V ⊆ 圆盘，则 conv(V) = L ⊆ 圆盘。反之显然。证毕。

**注**：上述推理同时说明了为何"只需校验顶点即可判定整体覆盖"——这正是把"点集最小覆盖圆"的结论合法迁移到"连续凸区域"的关键一步。

**定理 5.6（90° 阈值的临界性）** 记

```
S(α) = { X ∈ ℝ² : ∠AXB ≥ α },     α ∈ (0°, 180°)
```

则 `S(α)` 为凸集**当且仅当** `α ≥ 90°`；换言之，**90° 是使该超水平集成为凸集的最小阈值**。

**证明**：不妨取 A = (−1, 0)、B = (1, 0)（相似变换保持角度与凸性）。

**(i) 结构。** 过 A、B 的圆，圆心在 AB 的中垂线上。设圆心为 (0, h)、半径为 ρ，则由 `1 + h² = ρ²`。取 `ρ = 1/sin α`，则 `h = ±cot α`。记以 `(0, ±cot α)` 为心、`1/sin α` 为半径的闭圆盘为 `D±`。由圆周角定理，`S(α)` 的边界为这两个圆上的弧，且

- 当 α > 90° 时，两段弧分别在 AB 两侧向内凸出，`S(α) = D₊ ∩ D₋` 为**两圆盘之交**；
- 当 α < 90° 时，两段弧分别向外凸出，`S(α) = D₊ ∪ D₋` 为**两圆盘之并**；
- 当 α = 90° 时 `cot 90° = 0`，两圆盘重合为以 AB 为直径的圆盘。

沿中垂线可直接验证：设 X = (0, y)，则 `∠AXB = 2·arctan(1/|y|)`，故 `S(α) ∩ {x=0} = { |y| ≤ cot(α/2) }`；而 `D₊ ∩ {x=0} = [cot α − csc α, cot α + csc α] = [−tan(α/2), cot(α/2)]`，与之一致。

**(ii) α ≥ 90° 时凸。** 由 (i)，`S(α) = D₊ ∩ D₋`；圆盘为凸集，凸集之交仍凸。

**(iii) α < 90° 时非凸（构造见证）。** 取

```
X± = ( −1 − δ , ± rδ ),      r > tan α,   δ > 0 充分小
```

对 `X±`，向量 `X±→A = (δ, ∓rδ)`、`X±→B = (2+δ, ∓rδ)`，故

```
cos∠AX±B = [ δ(2+δ) + r²δ² ] / ( δ√(1+r²)·√((2+δ)² + r²δ²) )  ⟶  1/√(1+r²)    (δ → 0)
```

从而 `∠AX±B → arctan r > α`，即当 δ 充分小时 `X± ∈ S(α)`。而其中点 `X₀ = (−1−δ, 0)` 处，`X₀→A = (δ, 0)` 与 `X₀→B = (2+δ, 0)` 同向，`∠AX₀B = 0 < α`，故 `X₀ ∉ S(α)`。于是 `X± ∈ S(α)` 而中点在集外 ⇒ `S(α)` 非凸。证毕。

**推论 5.5（顶点判据成立的确切原因）** 覆盖判据（推论 5.3）之所以**只需校验顶点**，根本原因正是：**90° 这个阈值恰好使超水平集成为凸集**。由 `L = conv(V)` 与 `S(90°) = D(P,Q)` 凸，立得 `V ⊆ S ⟹ conv(V) ⊆ S`。

**注**：这条推论说明了本节判据的**成立边界**——若题设问的是"能否用 120° 视角锥覆盖"，由于对应超水平集虽凸但校验对象改变，需另行论证；若问的是 60°，则超水平集非凸（如取 A=(−1,0)、B=(1,0)、α=60°，点 `(−1.04, ±0.15)` 处 ∠ = 70.87° ≥ 60° 在集内，而二者中点 `(−1.04, 0)` 处 ∠ = 0° 在集外），顶点判据将失效。

**第三层：正解与定量界**

正确的做法不是寻找"以直径为直径的圆"，而是求**最小包围圆**。其半径由下述定理严格界定。

**定理 5.5（Jung 定理，1901）** 平面上直径为 D 的点集必可被半径不超过 D/√3 的圆覆盖。

**证明**：设最小包围圆圆心为 O、半径为 R。由最小性，圆周上存在 2 个或 3 个支撑点。

- **情形一（2 个支撑点）**：两点必互为对径（否则可缩小圆），故 R = D/2 ≤ D/√3。
- **情形二（3 个支撑点）**：三点构成一个内接于该圆的三角形，其最大角 α ≥ 60°（三角形内角和为 180°），且 α 所对的边 s ≤ D。由正弦定理 s = 2R·sin α，得

```
D ≥ s = 2R·sin α ≥ 2R·sin 60° = √3·R    ⟹    R ≤ D/√3
```

证毕。

由定理 5.5 与显然的下界 R ≥ D/2（圆须容纳直径两端点），得到**双侧夹逼**：

```
D/2  ≤  R_MEC  ≤  D/√3 ≈ 0.5774·D
```

**推论 5.4**：以 D 为直径的圆与所需的最小包围圆相比，其半径最坏小 `2/√3 − 1 ≈ 15.5%`。取等形状为等边三角形（上界）与线段形退化区域（下界）。

##### 第四层：结构定理 —— 本模型区域族内直径圆实际上总能覆盖

前三层回答的是"对**一般凸区域**"的命题。本层进一步回答："对**本模型能生成的定位区域族**"又如何？

**定理 5.7（中心对称 ⇒ γ ≡ 1）** 设 K 为中心对称的紧凸集，c 为其对称中心，则

```
γ(K) = R_MEC / (D/2) = 1
```

**证明**：由最小包围圆的唯一性与 K 的中心对称性，MEC 的圆心必为 c，故 `R_MEC = max_{x∈K}‖x − c‖`。又对任意 x ∈ K，其对径点 `2c − x ∈ K`，故

```
D = max_{x,y∈K}‖x − y‖ ≥ ‖x − (2c − x)‖ = 2‖x − c‖
```

取使 ‖x−c‖ 最大的 x 得 `D ≥ 2R_MEC`；另一方面显然 `D ≤ 2R_MEC`。故 `D = 2R_MEC`，即 γ = 1。证毕。

*数值验证*：正方形、一般平行四边形、中心对称六边形均给出 γ = **1.000000**；等边三角形给出 1.154692 ≈ 2/√3 ✓

**结构观察 5.1** 定位区域 L 的两条**对边**分别落在**同一检测点**的两条边界射线上，而这两条射线的夹角**恰为 2ε**。因此 **L 的两组对边各自偏离平行不超过 2ε** —— **L 是一个"2ε-近平行四边形"**（n 个检测点时为"近平行 2n 边形"）。

**推论 5.5** 由定理 5.7，**严格中心对称**的区域必有 γ = 1；而 L 只是中心对称形状的 **O(ε) 扰动**，故

```
γ = 1 + O(ε)
```

**数值实验（本文实测，数十万组配置搜索）**：

| 误差半角 ε | γ − 1 的实测上界 |
|---:|---:|
| 0.05° | 1×10⁻⁶ |
| 0.25° | 2.9×10⁻⁴ |
| **1°（题设）** | **5.7×10⁻³** |
| 2° | 9.0×10⁻³ |
| 4° | 3.4×10⁻² |

其中 **n = 2 的情形可给出更强的结果**：γ 是相似不变量，故两站构型在相似意义下**只有 (θ₁, θ₂) 两个形状参数**，
可对其做**穷举网格搜索**（步长 2° 粗搜 + 0.05° 细化）。结果为

```
n = 2, ε = 1°：  max γ = 1.000610，在 (θ₁, θ₂) = (89°, 91°) 取到 —— 该构型的区域退化为锐角三角形
```

（该三角形最大内角 α ≈ 88°，而**对锐角三角形恒有 γ = 1/sin α**，故 γ = 1/sin 88° = 1.00061 ✓ 与网格结果精确吻合。）
多站配置（n = 5）的搜索结果略高，为 γ = 1.0057。**故 ε = 1° 下 γ 实测不超过 1.01**，而理论上界为 2/√3 = 1.154701。

**结论**：**在本题的定位区域族内，等边三角形（γ = 1.154701）不可达**；γ 与 1 的偏离随 ε 趋于零，
**题设 ε = 1° 时 γ ≤ 1.01**。**因此对本题实际出现的定位区域，以直径为直径的圆总能覆盖（至多差 1%）。**

**诚实边界**：本层由一条**已证明的定理**（中心对称 ⇒ γ≡1）、一条**几何事实**（对边来自同一顶点、夹角 2ε）
与**数值实验**共同支撑；**"γ ≤ 1 + C·ε^p 的常数 C 与指数 p 尚未定出**（实测 γ−1 随 ε 大致呈平方增长，
但受"取最大值"的采样误差影响，拟合不稳定），属开放问题。本文如实标注为**实验发现**而非定理。

#### (2) 覆盖缺口比与验证

定义**覆盖缺口比** γ = R_MEC/(D/2) ∈ [1, 2/√3 ≈ 1.1547]。

#### (3) 关于直径对不唯一的补充说明

| B | 存在一组直径对使覆盖成立（较弱结论） |
| C | 所有直径对都使覆盖成立（较强结论） |

**本文认为，唯一无歧义的做法是采用最小包围圆**：最小包围圆对任意紧集存在且唯一，覆盖问题在该口径下不依赖于任何选取。

### 5.1.8 与问题二的联系

本问给出的直径 D 与最小包围圆半径 R_MEC，是刻画定位不确定度的**几何度量**。在问题二中，"较好的定位效果"需要一个可量化的目标，本问的 D 恰好提供了这一度量；换言之，**问题一是问题二的评价函数**。

进一步地，若引入 Fisher 信息矩阵 M = JᵀJ（J 为方位观测对源位置的雅可比矩阵），则两站情形下有闭式

```
det M = sin²φ / (σ⁴d₁²d₂²)
```

其逆的迹给出**均方根位置误差** E = ε·√(trace M⁻¹)。本问的 D（最坏两点距离，精确非线性）与 E（RMS 误差，线性化）是同一不确定度的两种描述，二者共享同一信息矩阵——**问题一与问题二因此构成一对伴随问题**：前者用 M 把观测映射为区域，后者用 M 评价候选测点。

**需要如实说明的是，D 与 E 并非成固定比例**（实测比值随几何构型在 2.43 至 2.00 之间变化），故本文将两者同时报告而不相互替代。

## 六、模型评价

### 6.1 模型优点

1. **建模起点准确**：把示向度升格为 2° 角域，与题设的"有界误差"模型严格对应，避免了概率模型带来的非凸困难；
2. **求解精确**：问题被归约为凸几何计算，可在多项式时间内精确求解，结果不依赖随机性，可完全复现；
3. **关键量双实现互验**：直径与最小包围圆各设两套独立算法强制一致，正确性自证；
4. **回答完整**：对覆盖问题给出反例、充要判据与定量界四层递进回答，并补充了直径对不唯一的歧义讨论；
5. **理论基准明确**：Jung 夹逼 `[D/2, D/√3]` 既论证了结果质量，又充当自动正确性检验。

### 6.2 模型缺点

1. **单一标量度量的局限**：直径 D 刻画的是"区域内最坏两点距离"，是保守度量，不反映不确定度的整体形态；本文以最小包围圆、缺口比等多尺度量补充，但未给出完整的不确定度描述；
2. **射影与非欧几何不适用**：由于射影变换不保持角度，而本问的全部信息即为角度，故本文仅借用射影几何的**对偶与圆锥结构**，未施加射影变换；
3. **有界误差模型的强假设**：题设给出的是误差区间；若实际误差呈重尾分布，区间模型将过于保守；
4. **依赖"真源落在所有角域内"的前提**：多检测点改善定位的结论以此为条件，否则交集可能为空。

### 6.3 理论补充（对偶、不变量与 Helly 结构）

本节给出三个理论观察，用于说明本问结构的深层性质。它们不改变主结果，但提供了理解问题的第二视角。

**命题 5.3（配极对偶与 Jung 定理的对偶形式）**

对含原点为内点的闭凸集 C，定义其**极集** `C° = { y : ⟨x,y⟩ ≤ 1, ∀x ∈ C }`。则有以下三条基本事实：

```
( ⋂ᵢ Cᵢ )° = conv( ⋃ᵢ Cᵢ° )        （交 ⟷ 包）
C ⊆ D          ⟹   D° ⊆ C°          （包含反转）
( B(0,R) )°    =    B(0, 1/R)
```

设 L 为含原点的紧凸集，记 `R₀(L) = max{‖x‖ : x ∈ L}`（以原点为中心的最小包围圆半径），则有

```
R₀(L) = 1 / inr( L° )
```

*证明*：由定义 `inr(L°) = max{ r : B(0,r) ⊆ L° }`。由包含反转与双极定理 `(L°)° = L`（对含原点的闭凸集成立），

```
B(0,r) ⊆ L°   ⟺   L ⊆ B(0,1/r)
```

故 `inr(L°) = max{ r : L ⊆ B(0,1/r) } = 1 / min{ R : L ⊆ B(0,R) } = 1/R₀(L)`。证毕。

取 L 的最小包围圆圆心为原点，则 `R₀(L) = R_MEC`，于是 Jung 定理 `R_MEC ≤ D/√3` 对偶为

```
inr( L° )  ≥  √3 / D
```

等号当且仅当 L 为**等边三角形**。

**验证**：等边三角形 L（外接圆半径 1、直径 `D = √3`、内切圆半径 1/2）的半平面表示为 `{x : ⟨û_k, x⟩ ≤ 1/2}`（û_k 为单位外法向），故 `L° = conv{2û₁, 2û₂, 2û₃}`，即外接圆半径 2、内切圆半径 `2·cos 60° = 1` 的等边三角形。于是 `inr(L°) = 1 = √3/√3 = √3/D` ✓ **取等**。

本文基准算例（§5.1.6）：`R_MEC = 19.799`、`D = 39.598`、`√3/D = 0.04374`。将区域平移使最小包围圆圆心为原点后，其极集最紧半平面到原点的距离为 `1/19.799 = 0.05051`，故 `inr(L°) = 0.05051 ≥ 0.04374` ✓ 成立（本例取下界 `R_MEC = D/2`，故取严格不等号）。

**自洽检验**：把直径圆半径 `D/2` 代入对偶，得对偶内切半径 `2/D`；它与 Jung 界给出的 `√3/D` 之比为 `2/√3 ≈ 1.1547`——**与 §5.1.7 主推导给出的最坏缺口完全一致**。对偶视角与主视角互相印证。

**命题 5.4（组合型的仿射不变性）**

设 A 为可逆仿射变换。则 L 与 A(L) 的**顶点数相同**，且"哪两条边界射线产生哪个顶点"的对应关系相同。

*证明*：仿射变换保持直线与凸性，故把凸多边形映为凸多边形、顶点映为顶点；角域 `Wᵢ = Sᵢ + Kᵢ`（Kᵢ 为锥）在 A 下映为 `A(Sᵢ) + A(Kᵢ)`（A 的线性部分把锥映为锥）；且 `A(⋂ᵢWᵢ) = ⋂ᵢA(Wᵢ)`。故顶点与其射出对的对应关系被保持。证毕。

**推论**：本问的答案分两部分——**组合部分**（顶点数、顶点与约束对的对应）是仿射不变量；**度量部分**（D、R_MEC、面积）依赖具体的角度与距离。等价地，L 的组合型由 `2n` 条边界射线的**有序拟阵**（oriented matroid）决定。

据此，n = 2 时 L 的形状可由定理 5.3 完全分类：

| 条件 | L 的形状 | 顶点数 |
|---|---|---|
| 方向区间相交 | 无界（直径未定义） | — |
| 区间不相交，一般位置 | 凸四边形 | 4 |
| 区间不相交，且一个边界射线交点落在其余角域之外 | 凸三角形 | 3 |
| 交集为空 | 空集 | 0 |

基准算例中方向区间 [58.036°, 60.036°] 与 [119.964°, 121.964°] 不相交，属一般位置，实测恰得 4 个顶点 ✓ 与分类一致。

**Helly 数「3」的三重奏**

平面上的数值 `d + 1 = 3` 在本问中以三种面貌出现，且根源相同：

| 出现处 | 陈述 | 依据 |
|---|---|---|
| **L ≠ ∅ 的判定** | 任意 **3** 个角域相交 ⇒ 全体相交 | **Helly 定理**（平面 Helly 数 = 3） |
| **最小包围圆的决定** | MEC 由不超过 **3** 个边界点决定 | **LP-type** 组合维数 = 3 |
| **Jung 上界取等** | 等边三角形（**3** 点配置）取等 | 三支撑点情形 |

三者相互独立，但同为平面 Helly 数的体现。其工程含义有二：判定 L 是否为空只需检验三元组（n 较大时可作快速预筛）；最小包围圆算法的**基**（basis）大小不超过 3，实现时只需处理边界点数为 0/1/2/3 的四种情形。

### 6.4 改进方向

1. **各向异性推广**：将"圆"替换为"椭圆"（即由欧氏范数推广到加权范数），可刻画清除精度或测向精度在不同方向上不一致的情形。需要注意此时 Jung 常数不再是 1/√3，需重新推导；
2. **对偶视角**：由点线对偶，本问可转化为"求与 n 条对偶线段均相交的直线"这一经典的**直线横截问题**，并与 Hadwiger 横截定理（Helly 型）衔接；
3. **配极对偶**：由配极变换 `(⋂Cᵢ)° = conv(⋃Cᵢ°)`，覆盖问题可对偶化为"对偶多边形的内切圆是否足够大"，与本文主推导互为印证。
