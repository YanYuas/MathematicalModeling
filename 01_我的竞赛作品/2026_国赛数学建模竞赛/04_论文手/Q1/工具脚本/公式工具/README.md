## 一、本目录内容

| 文件 | 说明 |
|---|---|
| `问题一公式.tex` | Q1 公式的 **LaTeX 源** |
| `问题一公式.html` | 渲染预览（依赖同目录 `katex/`） |
| `问题一公式_LaTeX编辑器.html` | **单文件版**（KaTeX 字体已内联为 base64，663 KB，可离线双击打开） |
| `katex/` | KaTeX 渲染库（`katex.min.js` + `katex.min.css` + 25 个 `woff2` 字体） |
| `inline_katex.py` | **把 `katex/` 的字体内联进 HTML**，产出上面的单文件版 |
| `strip_fonts.py` | 清掉 HTML 里残留的 `.woff`/`.ttf` 引用（只留 `woff2`） |

