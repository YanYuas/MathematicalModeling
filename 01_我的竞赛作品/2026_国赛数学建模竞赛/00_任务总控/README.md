## 使用规范

1. **数字唯一来源**：所有论文、代码、讨论中的数字，必须与 `权威数字表.md` 一致。发现冲突时，以权威数字表为准，并更新其他文档。
2. **进度实时更新**：每次完成重要工作后，更新 `进度看板.md`。
3. **变更必记**：每次提交前，在 `CHANGELOG.md` 记录变更内容。
4. **窗口文档**：Q3/Q4有严格的时间窗口限制，相关规则和转交文档集中在 `02_窗口与转交/`。
