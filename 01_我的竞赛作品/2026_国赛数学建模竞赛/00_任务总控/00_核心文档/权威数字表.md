### 6.4 【新·2026-09-12】Q4 外扩环带与 surrounding 的设计条件（**更正 L4 引理**）

> 来源：建模手本机实测（Python 复现 `generate_extended_grid` + `is_surrounding`，全域 3000 点抽样 + 边界带加密）。
> **起因**：第三方审核报「环带网格全域 16522 点有 546 点（3.30%）surrounding 失败，全落在 `‖G‖∈[1750,1800]`」。

| 指标 | 数值 | 说明 |
|---|---|---|
| 三角格**最近邻**最大距离 | **`d/√3`**（d=1000 → 574.56 m） | 这是**覆盖**半径 —— 正是 L4 误用的量 |
| 三角格**第三近邻**最大距离 | **`d`**（d=1000 → 997.77 m） | **关键**：surrounding 需要「三最近格点」，第三近邻可达 `d` |
| 「`G ∈ conv{三最近格点}`」 | **成立**（4000 点抽样，失败 **0**） | L4 的**这一半是对的** |
| 外扩宽度 `R + d/√3`（577） | 全域失败 **2.47%**；边界带 **42.05%** | ❌ **错** |
| 外扩宽度 **`R + d`**（1000） | 全域失败 **0.00%** ✅ | ✔ **正确**（`d = R_eff` 时与 `R + R_eff` 同宽） |
| surrounding 失败的 `d` 阈值 | **`d ≤ R_eff` = 1000 m** ⇒ 失败 **0.00%** | 实测：1050→**1.77%**；1100→7.43%；1200→35.5%；1500→**91.4%**；1732.05→**100%** |

**⇒ 更正后的引理 L4′**：取 `P = Lattice ∩ D(0, R_domain + d)`（外扩宽度 **`d`**，**不是** `d/√3`）。
则 `∀G ∈ D(0, R_domain)`：其三最近格点均在 `P` 内、且距 `G ≤ d`；由「`G ∈ conv{三最近格点}`」得
`G ∈ conv Q(G)` ⟺ 需 **`d ≤ R_eff`**。

**⇒ Q4 的设计条件（新）**：**`d ≤ R_eff`（=1000 m）且外扩宽度 ≥ `d`**。
`d = 1000` 恰好卡在阈值上（余量为 0）⇒ **建议 `d ≤ 950` 留余量**（实测 950 → 0.00%，|P| = 31）。

**连带影响**：① Q4 **必须**用 `d ≤ 1000`（不只是"更省"，而是 surrounding 的**成立条件**）；
② `Q4建模数学化` 的 L4、`Q4全解总览` 的环带宽度数值均须按此改；
