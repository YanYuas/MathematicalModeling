A.1.1

问题一：多站交会定位区域直径与覆盖判定算法

Problem I · Localization
▸ 输入 INPUT

n 个检测点坐标 {S1, S2, …, Sn}、对应示向度 {θ1, θ2, …, θn}、测向误差半角 ε

▸ 输出 OUTPUT

定位区域直径 D、最小包围圆半径 RMEC、直径圆覆盖判定结果

A.1.1.1 整体流程
  1. 角域构造：为每个检测点构造对应角域 Wi，每个角域由两条边界射线表示（算法 A.1.1.2）
  2. 有界性判定：检查所有角域的方向区间是否存在公共方向，若存在则输出"区域无界"并终止（算法 A.1.1.7）
  3. 候选顶点生成：枚举所有边界射线的交点，经全域角域包含性过滤得到有效顶点集（算法 A.1.1.3）
  4. 凸包计算：采用 Andrew 单调链算法对有效顶点集计算凸包，得到定位区域 L（算法 A.1.1.4）
  5. 直径求解：暴力枚举法与旋转卡壳法双实现交叉验证，输出区域直径 D 及对应端点对（算法 A.1.1.5）
  6. 最小包围圆求解：暴力枚举法与 Welzl 随机增量法双实现交叉验证，输出 RMEC 及圆心（算法 A.1.1.6）
  7. 覆盖判定：基于 Thales 定理验证直径圆对凸多边形的覆盖性，结合 Jung 定理完成边界验证
A.1.1.2 角域构造

输入：顶点 S、中心示向度 θ、误差半角 ε　|　输出：角域对象（左、右边界射线）

  1. 计算边界方向：θ− = θ − ε，θ+ = θ + ε
  2. 生成单位方向向量 u−、u+，构造两条射线 R−(S, u−)、R+(S, u+)
  3. 返回角域 W = (S, θ, ε, R−, R+)
✦
设计要点

角域等价于两个闭半平面的交集，天然具有凸性，为后续全部凸几何运算奠定基础。

A.1.1.3 候选顶点生成（含全域过滤）

输入：角域列表 {W1, …, Wn}　|　输出：定位区域有效顶点集

  1. 收集所有角域的边界射线，构成射线集合
  2. 枚举所有射线对，计算交点；若无交点或交点在射线反向延长线上则跳过
  3. 全域过滤：对每个交点，验证其属于所有角域；仅全部满足的点加入有效顶点集
  4. 返回有效顶点集
⚡
核心创新

必须对每个交点做全域角域包含性校验，剔除落在其他角域外的虚假交点。这是本算法最关键的正确性保障，省略该步会导致顶点集混入大量假点，最终直径结果偏大。

A.1.1.4 凸包计算（Andrew 单调链算法）

输入：平面点集　|　输出：凸多边形（逆时针顶点序列）

  1. 按坐标升序对点集排序
  2. 分别构造下凸壳与上凸壳，维护右转性质，非右转则弹出末端点
  3. 合并上下凸壳，去除首尾重复点，得到凸多边形顶点序列
◆
性质

凸多边形的直径必在顶点处取得，因此后续直径求解仅需枚举顶点对。

A.1.1.7 有界性判定

输入：角域列表　|　输出：有界 / 无界

  1. 收集每个角域的方向区间 [θi − ε, θi + ε]
  2. 检查所有区间的交集是否为空
  3. 交集为空则返回有界，存在公共方向则返回无界
A.1.1.5 直径求解（双实现交叉验证）

输入：凸多边形 L　|　输出：直径 D、直径端点对

  1. 实现一 · 暴力枚举法：枚举所有顶点对，计算两两距离，取最大值 D1
  2. 实现二 · 旋转卡壳算法：逆时针遍历多边形边，同步旋转对踵点指针，记录最大距离 D2
  3. 交叉校验：若 |D1 − D2| < εgeom，输出 D = D1 及对应端点；否则触发异常
⚖
创新机制

两种独立算法互为基准，实现正确性自校验，无需外部真值即可发现实现错误。

A.1.1.6 最小包围圆求解（双实现交叉验证）

输入：平面点集　|　输出：最小包围圆圆心 c*、半径 RMEC

  1. 实现一 · 暴力枚举法：枚举所有两点定圆、三点定外接圆，取能覆盖全部点的最小圆 (c1, R1)
  2. 实现二 · Welzl 随机增量算法：随机打乱点集，递归构造最小包围圆，边界点分 0/1/2/3 个情形处理，输出 (c2, R2)
  3. 交叉校验：若 |R1 − R2| < εgeom，输出 RMEC = R1 及圆心；否则触发异常
A.1.2

问题二：第二检测点候选区域与选点策略算法

Problem II · Station Selection
▸ 输入 INPUT

第一检测点 S1、示向度 θ1、最小交会角要求 φmin、最坏接收半径 Rworst、源距范围 [dmin, dmax]

▸ 输出 OUTPUT

候选区域边界、可行性判定、可达交会角上界

A.1.2.1 整体流程
  1. 坐标归约：建立以 S1 为原点、示向度中线为 +x 轴的局部坐标系（算法 A.1.2.2）
  2. 基准候选区域求解：在 α = 0（源在测量中线）假设下，推导闭式边界，判定可行性（算法 A.1.2.3）
  3. 鲁棒候选区域求解：纳入示向度误差 α ∈ [−ε, ε]，逐点取最坏情形，求解广义可行边界与可达上界（算法 A.1.2.4）
  4. 跨问交叉验证：调用问题一算法，验证候选点位的定位精度改善效果（算法 A.1.2.5）
A.1.2.2 坐标归约与逆变换

输入：世界坐标 S1、示向度 θ1、待转换点 P　|　输出：局部坐标 (a, b)

  1. 计算沿示向度单位向量 u、垂直示向度单位向量 v
  2. 向量 S1P 分别向 u、v 投影，得到 a、b
  3. 逆变换：P = S1 + a·u + b·v
✦
设计要点

刚体变换不改变距离与夹角，归约后公式大幅简化，且不失一般性。

A.1.2.5 跨问交叉验证

输入：候选点位 S2、真实源位置 G、误差半角 ε　|　输出：定位区域直径 D、精度改善率

  1. 调用问题一算法，输入 S1、S2 及对应示向度，计算定位区域直径 D
  2. 与基准配置的直径对比，计算精度改善率
  3. 返回验证结果
🔗
体系优势

问题二可直接复用问题一的完整几何计算管线，两问算法天然自洽，无需重复开发。

A.1.2.3 基准候选区域求解（α = 0 闭式解）

输入：源距中值 d̂、源距不确定半径 Δd、φmin、Rworst　|　输出：bmin、bmax、可行性、可达交会角上界

  1. 可行性判据：候选区域非空当且仅当 Δd ≤ Rworst · cos φmin
  2. 若不可行，计算可达交会角上界 φmax = arccos( Δd / Rworst )，返回不可行
  3. 若可行，计算边界：
    • 角度约束下界：bmin = Δd · tan φmin
    • 距离约束上界：bmax = √( Rworst2 − Δd2 )
  4. 返回 bmin、bmax、可行标记、可达上界
◆
核心结论

最坏情形出现在深度偏差取端点 |Δ| = Δd 处，由目标函数与约束关于 Δ2 的单调性保证。

A.1.2.4 含示向度误差的鲁棒候选区域求解

输入：纵向坐标 a、φmin、Rworst、源距端点集、α 采样集　|　输出：鲁棒边界、可行性、最大可达交会角

  1. 对横向偏移 b 进行网格扫描，对每个 (a, b)：
    1. 遍历所有 α ∈ [−ε, ε] 与源距端点 r
    2. 计算最坏交会角 sin φworst = minα,r |a·sin α − b·cos α| / d2(a, b, r, α)
    3. 计算最坏站源距 d2,max = maxα,r d2(a, b, r, α)
  2. 找到满足 φworst ≥ φmin 的最小 b（bminα）与最大 b（bmaxα）
  3. 若 bminα > bmaxα，判定不可行，求解全域最大可达交会角 φminmax
  4. 返回鲁棒边界、可行性标记、最大可达交会角
⚡
关键发现

角度约束与距离约束的最坏 α 方向恰好相反（角度在 α = +ε 最坏、距离在 α = −ε 最坏），两条约束无法合并为单式判据。
