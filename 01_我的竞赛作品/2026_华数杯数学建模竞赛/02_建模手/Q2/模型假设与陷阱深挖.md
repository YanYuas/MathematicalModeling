## 二、模型级陷阱深挖（M1-M15，区别于工程级T1-T13）

### M1. 线长目标与轮廓约束的对冲张力（Q2核心矛盾）
- HPWL优化把块拉向终端 → 块分布变稀 → 打包包围盒变大 → 逼近/超过轮廓 S。
- 这是**结构性张力**：两个目标天然对冲，不是实现bug。
- 陷阱：λ（轮廓惩罚）太小 → 解超轮廓不可行；太大 → 线长差、又回到M2陷阱。
- 对策：λ自适应（可行时小、不可行时大，等效论文自适应α）；报告"可行best + 死区余量"。

### M2. 直接轮廓惩罚的陷阱（论文已警告，Q2再强调）
- 论文明确：`max{W−W*,0}+max{H−H*,0}` 大权重 → 找到首个可行解后困局部极小；小权重 → 得不到可行解。
- 对策：用 $(R-1)^2$ 平滑惩罚（论文式）或 $A\cdot R - S^2$ 软惩罚（我们式，见深度分析§4.2）。

### M3. "引脚中心"的自我升级陷阱
- 真实EDA引脚在块边缘（引脚引出到块外接），中心假设使HPWL乐观且**对称**（旋转不影响中心点到自身的距离结构）。
- 陷阱：参赛者觉得"中心太假"，自己算边缘引脚 → 偏离题设、无对标。
- 对策：**严格按题设中心算**，假设节声明。自我升级是丢分项。

### M4. 旋转的"中心漂移"双刃
- 旋转后中心 $(x+h/2, y+w/2) \ne (x+w/2, y+h/2)$（w≠h时）→ 引脚位置变 → 影响HPWL。
- **洞察**：旋转是Q2有效算子（既为装箱也为线长），Op1概率要够；方形块（w=h）旋转无效果。
- 陷阱：以为旋转"只是换朝向"，忽略中心漂移对网包围盒的影响。

### M5. 死区宽松 ≠ 可忽略轮廓
- Γ=15%可行容易（论文100%成功），但**线长优化本身制造超轮廓风险**（M1）。
- 陷阱：看到"可行容易"就把轮廓惩罚设零 → 块散开超轮廓。
- 对策：惩罚保留但权重自适应小；验收仍必须 M≤S。

### M6. I/O网结构利用不足（数据洞察→算法机会）
- 334/564/569个混合网，每条终端恰连一组块 → **终端锚定**结构。
- 陷阱：SA随机初始不利用 → 收敛慢。
- 对策：终端感知初始化（把连接终端的块放近）+ 图布局初始化（见化归C3/C4）。

### M7. HPWL的XY可分 ≠ 可独立求解
- $\sum HPWL = X部分 + Y部分$，各自只依赖单维。
- **陷阱**：误以为可分 → 独立优化x和y。**块移动同时改x和y**，packing约束耦合两者。
- 正确用法：可分性是**分析工具**（下界、维度理解），不是求解分解。

### M8. 多pin网包围盒的"离群主导"
- 高pin网（n300有6-pin）包围盒被单个离群块撑大 → 目标对单块移动噪声大。
- 陷阱：SA抖动大、收敛慢；不要因此给高pin网降权（HPWL定义如此）。
- 对策：接受噪声（SA天然鲁棒）；2-pin占72-89%，主体还是L1距离。

### M9. 终端被块覆盖的可视化"观感陷阱"
- 块可压终端（题设允许），但可视化里终端被遮 → 评阅觉得物理不合理。
- 对策：声明题设允许；可视化终端画在最上层（Z序置顶）+ 标点。

### M10. 增量更新的边界错误
- 移动块bi只影响含bi的网。增量更新需维护"网→块"索引。
- 陷阱：增量漏更新某网 / 全量重算但用旧数据。
- 对策：n100-300规模小（引脚1873-4358），**全量重算最稳**，别为省时间引入增量bug。

### M11. 2-pin下界的诚实度
- 2-pin网= |Δx|+|Δy|。下界难构造（块有面积不能任意近）。
- 陷阱：声称某个"下界"实则不紧/不真。
- 对策：Q2不用强下界自证（无对标真值时），用**基线对**（全堆/strip，见深度分析§2.4）+ 收敛曲线 + best-of-N。

### M12. 死区口径再确认（承T1）
- Γ=0.15 → 轮廓面积=1.15A，死区占比13.04%。编程手别用0.15直接当占比。
- 对策：代码常量 `side=sqrt(area*1.15)`，注释口径。

### M13. "总连线长度"计算口径
- 每个网HPWL一次，Σ。多pin网不得重复/拆分。
- 陷阱：把网当2-pin拆开算 → 多pin网被高估。
- 对策：严格按包围盒定义；评估器（hpwl.py）已正确实现。

### M14. best_so_far的可行性门槛（关键）
- 不可行解（超轮廓）线长可能更小 → 记不可行best → 报告错误解。
- 对策：**best_so_far仅更新满足 M≤S 的解**；若全程无可行解（Q2不会，Γ=15%宽松），退而求其次记"违反最小"解。

### M15. warm start的局部陷阱
- Q1解作初始（可行）是好的，但Q1结构（面积最优、线长未优化）可能困住SA。
- 对策：warm start只作**初始化**；SA需足够扰动打破Q1结构；同时跑随机初始对照，取全局best。

## 三、新几何思路（补充深度分析 §6 之外）

**G1. 终端锚定距离场（I/O几何）**
- 每个终端作"引力点"，块的目标区域 = 所连终端方向的邻域。
- 构造初始：连接底边终端的块放底部、顶边放顶部 → 对称利用四边均匀性（85/84/82/83）。
- 这直接服务于 M6——把数据结构变成几何初始化。

**G2. 超图聚类几何（共享块→近邻）**
- 两块共网多 → 应靠近。网=超边，聚类块 → 簇内紧密布局。
- 用途：初始化的"聚类→布局→细化"三级（multilevel）。

**G3. L1球（菱形）几何**
- 2-pin网HPWL=|Δx|+|Δy| = L1距离 = 菱形等值线。
- 无面积约束时最优 = 中位数聚类；面积约束破坏中位数 → L1几何提供"为什么块要聚"的直觉。
- 论文可画菱形等值线解释线长地形。

**G4. 死区分配几何**
- 死区13%是缓冲带。终端四边 → 死区宜沿边分布（给I/O块靠边空间）。
- 洞察：**死区放哪 ≠ 均匀**。最优布局死区形态 = 边缘缓冲 + 内部密实。
- 可作论文的"布局画像"分析（可视化死区分布）。

**G5. 凸包/包围盒的分离**
- 多pin网HPWL ≤ 凸包半周长。弱上界，分析用。

**G6. 网格离散化几何**
- 轮廓网格化，块落格 → 化归图割/QAP（C1）。交叉验证。

## 五、射影几何（诚实评估 + 投影澄清）

**结论保持**：射影变换不保轴/面积/距离，HPWL是度量量，**射影硬套是错的**。

**重要澄清（Q2特有的正射影角度）**：
- $\text{span}_x(net)$ = 引脚集在 **x轴上的正交投影** 的长度；span_y同理。
- **HPWL = 两个正交投影长度之和**。这是"投影几何"的正确应用——但这是**正射影/仿射**，不是射影几何（射影保交比不保长度）。
- 论文可点破："HPWL本质是正交投影度量"，借此解释XY可分（M7）与下界构造。诚实区分"正射影（度量）"vs"射影几何（交比）"，显成熟。

**可借鉴对偶思想**（同Q1）：
- **块-间隙对偶**：死区=虚块，布局 ⇔ 实块+虚块填充。死区分配分析（G4）的理论框架。
- **平面图对偶**：布图结构分类。

## 六、图论深挖

**F1. 超图布局（Q2图论核心）**
- 线网=**超边**（连接≥2块）。Q2 = 超图布局问题 + 装箱约束的度量实例。
- 度数分布：2-pin占72-89% → 近图布局（普通图），多pin是超边。

**F2. 二分图（终端-块）**
- I/O网 = 终端↔块的二分边，终端固定位置。
- **终端锚定**：块的"目标区域" = 所连终端方向（G1）。二分图结构直接给初始化。

**F3. 共邻相似图 → 谱聚类**
- 两块共网次数 = 相似度 → 聚类。相连块放近（C3）。
- multilevel的基础。

**F4. 约束图（packing侧）**
- 水平/垂直约束图最长路径 = W/H（同Q1）。线长+packing双图论。

**F5. 区间图下界（承Q1）**
- 宽>W/2的块 = 区间图团 → 堆叠下界。轮廓下界仍用（Q2可行性）。

**F6. 展开图**
- 超边→星展开（虚中心节点）→ 普通图布局工具直接可用（C4）。

**图论卖点**：Q2 = **超图布局 + 装箱** 的复合。图论给线长初始化（谱/力导向/聚类），几何给装箱约束，两者通过B\*-Tree+SA统一。

## 七、一页速查

- **假设必写**：H1.3引脚中心、H2.1终端不占面积、H2.2块可压终端、H3.4 best只记可行

- **投影澄清**：HPWL=正交投影和（正射影，非射影几何）
- **化归卖点**：slicing DP保守对照、图割交叉验证
- **报告**：best-of-N + 收敛曲线 + 按网型分解

## 八、一句话总结

**Q2的深度在"线长×轮廓的对冲张力"**：这不是bug是问题本质。破解靠三件——终端锚定/图布局初始化（利用数据结构）、软惩罚自适应（平衡张力）、best只记可行（守住合法性）。图论给初始化，几何给装箱，射影只做投影澄清。
