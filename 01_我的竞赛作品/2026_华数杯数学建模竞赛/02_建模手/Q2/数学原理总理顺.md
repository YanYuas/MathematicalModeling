## 一、第一性原理：问题到底是什么

### 1.1 从题设到数学对象

题设四个关键词决定问题形态：
- **"芯片轮廓通常为正方形，尺寸由公式(1)确定"** → 轮廓是**硬约束**（不是Q1的可优化对象），S=√(1.15A) 固定；
- **"模块之间也会有连接关系"** → HPWL 进入，线长成为唯一目标；
- **"总HPWL最小"** → 单目标（不像Q1双目标，无权重问题）；
- **"引脚位于模块几何中心"** → HPWL 由中心点坐标定义（题设简化，见假设H1.3）。

数学对象：n 个硬矩形块 {bᵢ(wᵢ,hᵢ)}、k 个固定终端 {tᵢ(x,y)}、m 个线网（每条=引脚集），在固定 [0,S]² 内放块（90°旋转），min Σ_net HPWL(net)，约束无重叠、不超轮廓。

### 1.2 为什么是 NP-hard（复杂性根源）

两个 NP-hard 结构叠加：
1. **无重叠约束的析取性**（同Q1）：每对块四选一逻辑或 → 非凸离散组合；
2. **超图布局目标**：HPWL 是超边（网）上的跨度函数，本身是组合度量。

固定轮廓布图规划（在给定 outline 内布图）是已知 NP-hard（论文引证）；最小面积装箱（Q1）也是。**含义：100-300 块无多项式精确解，必须启发式，且"可行"与"近优"都要论证。**

### 1.3 为什么"可行 + 近优 + 对标"是唯一出路

- **可行**：Γ=15% 死区宽松，参考论文 n100 上 100% 成功（对比 GFA 30.3%、Parquet-SP 65.5%）→ 可行性有背书，但**线长优化本身制造超轮廓风险**（见§3.3核心矛盾），验收仍必须 M≤S；
- **近优**：线长下界难构造（块有面积不能任意近），改用**基线对**（全堆原点/strip打包）量化 gap；
- **对标**：参考论文表V给出 Parquet/论文法真值（PDF图片，待OCR回填）；2023 RL类论文量级 n100~2e5/n200~3.5e5/n300~5e5 可参考。

## 二、核心数学原理（逐条展开）

### 2.1 admissible 压缩定理迁移（B*-Tree 为什么还能用）

**定理**（Q1已证，Q2复用）：任意合法布局可"左下压实"化为 admissible 布局，外接框不增大。
**推论**：固定轮廓下，最优线长布局的可压缩版仍合法（压缩不增 W/H → 不超轮廓）、线长**只可能变好**（块向中心收缩不增 span）→ **压缩不丢最优，B*-Tree 搜索无损失**。

**解码免重叠**：左子贴父右（x不交）、右子在父上（y不交）→ 打包天然合法。
**复杂度**：x 前序 O(n)，y 轮廓均摊 O(n) → 每次扰动评估 O(n)。

### 2.2 HPWL = 两个正交投影之和（线长本质）

对每个网 net：
$$\text{span}_x(net) = \max_p x_p - \min_p x_p, \quad \text{span}_y(net) = \max_p y_p - \min_p y_p$$
$$\text{HPWL}(net) = \text{span}_x + \text{span}_y$$

**本质**：span_x = 引脚集在 **x 轴上的正交投影长度**，span_y 同理。HPWL 是两个正交投影长度之和。

**XY 可分性**（分析工具）：
$$\sum_{net}\text{HPWL} = \underbrace{\sum_{net}\text{span}_x}_{\text{只依赖x}} + \underbrace{\sum_{net}\text{span}_y}_{\text{只依赖y}}$$
- 对 2-pin 网（占72-89%）：HPWL = |Δx|+|Δy| = L1 距离；
- 可分是**分析工具**（下界、维度理解），**不是求解分解**——块移动同时改 x 和 y，packing 约束耦合两者（陷阱M7）。

### 2.3 M²=A·R 恒等式迁移（可行性判据）

Q1 用 M=√(A·R) 做 min-max 目标；Q2 迁移为**固定轮廓可行性判据**：
$$W \le S \text{ 且 } H \le S \iff M = \max(W,H) \le S \iff A\cdot R \le S^2$$
其中 R = max/min ≥ 1。

**为什么不能用面积 A ≤ S² 判可行**：瘦长解（如 50×4000）面积 200000 < S²=206426，但高 4000 ≫ S，超轮廓。**必须用 M 判据。**

**恒等式双用**：Q1 目标、Q2 判据，同一几何视角贯通两个问题——这是全篇的叙事主线（创新1）。

### 2.4 数据结构的图论读法（实测）

- **I/O 二分网**：334/564/569 条混合网（1终端 + k块），每条终端恰在一个网 → **终端锚定**：连接某终端的块应靠近该终端；
- **终端四边均匀**（85/84/82/83）→ 布局画像 = 四边 I/O 块 + 内部聚类块；
- **2-pin 主导**（88.9%/75.0%/72.4%）→ 主体线长是 L1 距离，图布局直觉成立；
- **无纯终端网** → 不要假设有 terminal-only net；
- **全块 4 角矩形、最大边长 67/48/48 ≪ S** → 全可旋转，无被迫固定朝向块。

## 三、目标函数设计：完整逻辑链

### 3.1 为什么线长目标直接可用（与Q1对比）

Q1 是双目标（面积+长宽比）→ 需要 min-max 重构免权重。Q2 是**单目标 min HPWL**：HPWL 定义即目标函数，无权重、无量纲混淆问题。直接写：
$$\Phi = \frac{W_{HPWL}}{W_{norm}}$$

### 3.2 为什么必须加轮廓惩罚（约束进目标）

约束"不超轮廓"是硬约束，但 SA 的 Metropolis 接受准则需要**可比较的数值**——硬拒绝（不可行=inf）会困死 SA（陷阱M12类）。所以把轮廓约束软化为惩罚项。

**为什么不用直接惩罚** max{W−S,0}+max{H−S,0}（论文明确警告）：
1. 大权重 → 找到首个可行解后**困局部极小**（惩罚主导、线长不再被优化）；
2. 小权重 → **得不到可行解**（惩罚太弱压不住超轮廓）。

**我们式**（利用恒等式 §2.3）：
$$\Phi = \frac{W_{HPWL}}{W_{norm}} + \lambda \cdot \max\Big(0,\ \frac{A\cdot R - S^2}{S^2}\Big)$$
- A·R = M² 天然非负，惩罚只在 M>S 时激活；
- 平滑（非尖角硬阈值）→ SA 能"试探"着逼近轮廓；
- λ 归一化量级（÷S²）与主目标可比。

### 3.3 为什么 λ 必须自适应（核心矛盾的动力学解）

**核心矛盾（M1）**：线长目标把块拉向终端 → 块分布变稀 → 打包包围盒变大 → 逼近/超过轮廓。线长与轮廓**天然对冲**。

**固定 λ 的两难**：λ 小 → 解超轮廓；λ 大 → 线长差、陷局部。**唯一出路是自适应**——可行性是"开关式"状态，应随解的可行性动态调权：

- 论文式自适应 α（β=0 面积版推广到线长）：
$$\alpha = \alpha_{base} + (1-\alpha_{base})\frac{n_{feasible}}{n}, \quad \alpha_{base}=0.5,\ n=500$$
- 或我们式自适应 λ：最近 n 次可行多 → λ↓（聚焦线长）；可行少 → λ↑（压回轮廓）。

**动力学的意义**：λ 自适应让 SA 在"可行区边界"徘徊——既可探索线长更优但逼近轮廓的解，又不越过边界。这是对"线长×轮廓"张力的最优平衡。

### 3.4 为什么 best 只记可行解（报告守门）

不可行解（超轮廓）线长可能更小（块挤一起或极端分布）→ 若 best_so_far 不设可行性门槛，最终报告超轮廓错误解（M14）。

**规则**：best_so_far 仅更新满足 M ≤ S 的解；无可行解时（Q2 不会发生，Γ=15% 宽松）退求违反最小者。

## 四、算法选择的合理性

### 4.1 为什么是模拟退火（复用Q1 + 参考论文背书）

- NP-hard 现实 → 无多项式算法；
- SA 的 Metropolis 接受准则允许爬山跳出局部最优 = 探索/利用最成熟框架；
- **参考论文正是 B*-Tree + SA + GSRC n100-n300，100% 固定轮廓成功率 → 赛题数据方案已被验证**。

### 4.2 为什么 Fast-SA（三阶段）

高温随机→伪贪心（k=7, c=100）→爬山。温度公式（含修正）：
```
T₁ = Δ_avg/|lnP|   （绝对值，ln0.9<0）
Tₙ = T₁⟨Δcost⟩/(n·c)   2≤n≤k
Tₙ = T₁⟨Δcost⟩/n       n>k
```
归一化（W_norm）保证 ⟨Δcost⟩<1 降温有效（Q1 T8 教训复用）。实测 12-13.9× 提速。

### 4.3 为什么三算子齐全 + 旋转权重足够

- Op1 旋转：Q2 中旋转改变**引脚中心**（中心 (x+h/2,y+w/2) ≠ (x+w/2,y+h/2)）→ 既改装箱也改线长，**双效算子**，概率要够（M4）；
- Op2 删插：拓扑重构（缺则树形状冻结）；
- Op3 交换：重排标签。

### 4.4 为什么双引擎初始化（Q2 独有策略）

| 引擎 | 提供 | 短板 |
|---|---|---|
| **Q1 解 warm start** | 可行性保证（§Q1→Q2 迁移定理：方形解 M<S） | 线长未优化，结构可能困局部 |
| **FDP/谱布局初始化** | 线长导向（终端锚定/共享网连边放近） | 可能超轮廓 |

**组合**：Q1 解作主起点（保可行），FDP/谱解作对照起点（保线长），SA 从多起点跑，取全局可行 best。两个引擎互补。

### 4.5 为什么验证用基线对而非下界（与Q1差异）

Q1 有线长无关的紧下界（⌈√A⌉ 等）；Q2 的线长下界**难构造**（块有面积、终端锚定复杂）。改用：
- **基线对**：全堆原点（150k/251k/321k，终端网拉长上界） vs strip 打包（295k/553k/833k，块散开下侧）——最优落在两者之间；
- **量级对标**：n100~2e5 / n200~3.5e5 / n300~5e5（参考论文量级）；
- **收敛曲线**：cost-vs-iteration 平台期证明迭代足够。

这给出"结果可信"的三重证据，替代 Q1 的下界族。
