## 一、题设精读

**问题2原文要点**：芯片轮廓为正方形，尺寸由公式(1)确定（死区比例0.15），模块之间有连接关系。求：模块摆放使总HPWL最小，满足不重叠、不超轮廓。对三组芯片给出总连线长度 + 可视化。

**关键定义（从题面+附件说明逐句拆）**：
1. 轮廓：$w_f=h_f=\sqrt{total\_block\_area \times (1+dead\_space\_ratio)}$，死区比 0.15。
2. HPWL：连接所有引脚的最小包围矩形半周长。引脚在模块**几何中心**。
3. 模块类型：HardBlock（待定位，可90°旋转）、Terminal（位置固定，仅参与HPWL，**不占面积、不参与重叠约束**）。
4. 附件三文件：`.blocks`（模块尺寸）、`.nets`（线网）、`.pl`（终端固定坐标）。

**与Q1的本质差异**：

| | Q1 | Q2 |
|---|---|---|
| 轮廓 | 不固定（最小化） | **固定正方形** W*=H*=S |
| 目标 | min 面积 → 长宽比→1 | **min 总HPWL** |
| 数据 | 只读 .blocks | .blocks + **.nets + .pl** |
| 自由度 | 位置+方向 | 位置+方向（终端固定） |
| 关键挑战 | 压面积 | **在轮廓内配线** |

## 二、数据事实（已实测验证，2026-08-08）

### 2.1 轮廓与规模

| 指标 | n100 | n200 | n300 |
|---|---|---|---|
| 硬模块数 | 100 | 200 | 300 |
| 终端数 | 334 | 564 | 569 |
| 模块总面积 A | 179501 | 175696 | 273170 |
| 轮廓边长 S=√(1.15A) | **454.34** | **449.50** | **560.49** |
| 轮廓面积 S² | 206426 | 202050 | 314146 |
| 死区占比 (S²−A)/S² | 13.04% | 13.04% | 13.04% |
| 最大模块边长 | 67 | 48 | 48 |
| 模块形态 | 全4角矩形 | 全4角矩形 | 全4角矩形 |

- **死区占比 = Γ/(1+Γ) = 0.15/1.15 ≈ 13.04%**（不是15%！Γ是"比例基数"，见陷阱1）。
- 最大模块边长 67/48/48 远小于 S → **所有块均可旋转**（无被迫固定方向块）。

### 2.2 线网结构（关键发现）

| 指标 | n100 | n200 | n300 |
|---|---|---|---|
| 线网总数 | 885 | 1585 | 1893 |
| 引脚总数 | 1873 | 3599 | 4358 |
| 2-pin 网占比 | 88.9% | 75.0% | 72.4% |
| 度数分布 | {2:787,3:93,4:5} | {2:1189,3:364,4:31,5:1} | {2:1371,3:475,4:45,5:1,6:1} |
| **混合网（终端+模块）** | **334** | **564** | **569** |
| 纯模块网 | 551 | 1021 | 1324 |
| 纯终端网 | 0 | 0 | 0 |

**结构性发现（实测）**：
1. **每条终端仅出现在一个线网中**，且该网 = 1终端 + k个模块（k≥1）。共 334/564/569 个"I/O网"，把模块拉向边界。
2. **没有纯终端网**（不像教科书假设那样有 terminal-only net）。
3. 2-pin 网占绝对多数 → HPWL ≈ 加权L1距离。

### 2.3 终端空间分布（实测）

```
n100: bottom 85 / top 84 / left 82 / right 83  （全部在边界，无内部）
n200: 143/141/140/140
n300: 144/143/140/142
```

终端坐标范围：n100 x∈[0,444] y∈[0,444]（均在轮廓 [0,454.34] 内）。**四边均匀分布 = I/O pad 模式**。

### 2.4 HPWL 基线与量级（实测，供编程手sanity check）

| 布局 | n100 | n200 | n300 |
|---|---|---|---|
| 全堆(0,0)（重叠，仅测尺度） | 150,761 | 251,410 | 321,484 |
| strip打包填轮廓（可行） | 295,222 | 552,768 | 832,706 |
| **目标量级（参考）** | **~2.0e5** | **~3.5e5** | **~5.0e5** |

- 全堆原点低估（内部网≈0但终端网拉长），strip高估（块散开拉长内部网）。
- 最优在两者之间：块应向所连终端"扩散"，同时内部聚类。
- 参考：2023年RL类论文 GSRC 最优线长量级 n100 1.97e5 / n200 3.46e5 / n300 5.03e5（终端处理方式可能略异，仅作量级参考）。

## 三、数学建模

### 3.1 决策变量

- 每块 $b_i$：左下角坐标 $(x_i,y_i)$，方向 $\theta_i \in \{0,90°\}$。
- 旋转后尺寸：$(w_i',h_i') = (w_i,h_i)$ 或 $(h_i,w_i)$。
- 终端坐标 $t=(x_t,y_t)$ 固定（来自 .pl）。

### 3.2 引脚坐标

- 模块引脚 = 几何中心：$p_i = (x_i + w_i'/2,\; y_i + h_i'/2)$。
- **注意**：旋转90°后 $w'=h,\ h'=w$，中心变为 $(x_i+h_i/2, y_i+w_i/2)$，**与旋转前不同**（除非 w=h）。见陷阱3。

### 3.3 目标函数

$$\min \sum_{net \in \mathcal{N}} \text{HPWL}(net)$$

$$\text{HPWL}(net) = \Big(\max_{p \in net} x_p - \min_{p \in net} x_p\Big) + \Big(\max_{p \in net} y_p - \min_{p \in net} y_p\Big)$$

**XY可分性（几何洞察）**：
$$\sum_{net} \text{HPWL} = \underbrace{\sum_{net}\text{span}_x(net)}_{\text{只依赖 }x} + \underbrace{\sum_{net}\text{span}_y(net)}_{\text{只依赖 }y}$$

对 2-pin 网：$\text{HPWL} = |x_i - x_j| + |y_i - y_j|$（即L1距离）。88.9% 的网是 2-pin。

### 3.4 约束

1. **不重叠**：$\forall i\ne j$，矩形 $b_i,b_j$ 内点不交。
2. **不超轮廓**：$0 \le x_i,\; x_i+w_i' \le S$；$0 \le y_i,\; y_i+h_i' \le S$。
3. **方向**：$\theta_i \in \{0,90°\}$。
4. **终端**：不占面积、不参与重叠（题设明确）。

### 3.5 轮廓可行性的等价刻画（核心几何工具）

轮廓约束 $W\le S,\ H\le S$（W,H为打包后包围盒）等价于：
$$M = \max(W,H) \le S \iff A\cdot R \le S^2$$
其中 $R = \max(W,H)/\min(W,H)\ge 1$，$A=WH$，恒等式 **$M^2 = A\cdot R$**（Q1 已证）。

**为什么不能用面积 $A \le S^2$ 判可行性**：瘦长解（如 50×4000）面积 200000 < S²=206426，但高 4000 ≫ 454，超轮廓。必须用 $M\le S$。

**创新卖点**：Q1 的 min-max 目标 $\Phi = M$，Q2 的可行性判据 $M \le S$，**同一个恒等式 $M^2 = A\cdot R$ 贯通两个问题**。

## 四、算法设计（B*-Tree + Fast-SA，Q1框架迁移）

### 4.1 编码与扰动（复用Q1）

- B*-Tree 打包保证无重叠、贴左贴底。
- 三算子：Op1旋转（仅可旋转块）/ Op2删插 / Op3交换。
- 种子固定 + best-of-N（论文取10次best）。

### 4.2 成本函数（核心设计决策）

**参考论文方案**（已全文精读，IV节）：
$$\Phi = \alpha\frac{A}{A_{norm}} + \beta\frac{W}{W_{norm}} + (1-\alpha-\beta)(R - R^*)^2, \quad R^*=1$$

- $A$=当前面积，$W$=当前线长，$R$=长宽比。
- 论文明确警告**不可直接惩罚** $\max\{W-W^*,0\}+\max\{H-H^*,0\}$：大权重 → 找到首个可行解后陷入局部极小；小权重 → 得不到可行解。
- 改用 $(R-1)^2$ 平滑惩罚 + 自适应 $\alpha$。

**自适应 $\alpha$**（论文式6）：
$$\alpha = \alpha_{base} + (1-\alpha_{base})\frac{n_{feasible}}{n}, \quad \alpha_{base}=0.5,\ n=500$$

- $n_{feasible}$ = 最近 $n$ 次解的可行数。
- 可行越多 → 面积权重越大 → 线长权重 $(1-\alpha)$ 越小，聚焦配线。

**建模手推荐形式（与Q1统一，供论文写"我们方案"）**：
$$\Phi = \frac{W}{W_{norm}} + \lambda \cdot \max\Big(0,\ \frac{A\cdot R - S^2}{S^2}\Big)$$

- 主目标归一化线长；惩罚项用 $M^2=A\cdot R$ 恒等式写成 $A\cdot R - S^2$（= $M^2-S^2$），平滑软惩罚。
- $\lambda$ 自适应：不可行时加大，可行时减小（等效论文自适应$\alpha$的思想，形式更贴近Q1的软惩罚框架）。
- 数值上 $A\cdot R = M^2$ 天然非负，惩罚只在 $M>S$ 时激活。

### 4.3 Q1→Q2 可行迁移定理（warm start，强创新点）

**定理**：若 Q1 得到正方形解（边长 ∈ 可行区间），则该解自动在 Q2 轮廓内可行。

验证（实测数据）：
| 组 | Q1方形可行区间 | Q2轮廓边长 S | 是否迁移 |
|---|---|---|---|
| n100 | [424, 443] | 454.34 | ✓ 443 < 454.34 |
| n200 | [420, 440] | 449.50 | ✓ 440 < 449.50 |
| n300 | [523, 538] | 560.49 | ✓ 538 < 560.49 |

**推论**：Q2 用 Q1 的最优 B*-Tree 作为初始解，SA 从可行区出发，直接聚焦线长优化。两个问题共享解空间，工作量不重复。

### 4.4 复杂度与增量

- B*-Tree 打包 O(n)；HPWL 全量重算 O(总引脚) = O(1873~4358)，SA每扰动一次可接受。
- 若需提速：2-pin网增量更新（只影响被移动块的网）。

## 六、几何创新点（论文展示素材）

1. **$M^2=A\cdot R$ 恒等式贯通 Q1/Q2**：Q1 的 min-max 目标、Q2 的固定轮廓可行性，同一恒等式。两个问题一个几何视角，论文叙事主线。
2. **Q1→Q2 可行迁移定理**：三组数据下 Q1 方形解自动落入 Q2 轮廓 → warm start 有严格保证。这是"两问题一模型"的衔接亮点。
3. **HPWL 的 XY 可分性**：$\sum HPWL = X部分+Y部分$，各自只依赖单维坐标。2-pin 网 = L1 距离。可用于下界构造与维度解耦分析。
4. **终端边界引力几何**：终端四边均匀分布（85/84/82/83），每个 I/O 网把块拉向对应边界。最优布局的几何画像 = 边界 I/O 块 + 内部聚类块。
5. **死区宽松 → 可行与线长解耦**：Γ=15% 时论文 100% 可行（对比 GFA 30.3%、Parquet-SP 65.5%），Q2 的本质难点在线长而非可行性，惩罚权重可小、SA 自由探索。
6. **软惩罚 vs 直接惩罚的论证**：用论文的反例（大权重陷阱/小权重不可行）+ 我们的 $A\cdot R-S^2$ 平滑形式，证明"软约束 > 硬约束"在 SA 下的普适性（与Q1的μ·max(0,·)呼应）。
