## 一、第一性原理：问题到底是什么

### 1.1 从题设到数学对象

题设三个关键词决定了问题形态：
- **"芯片轮廓不固定"** → 轮廓是决策结果（外接矩形），不是硬约束 → 面积成为可优化目标；
- **"模块之间没有连接关系"** → 无 HPWL、无 nets → 问题退化为**纯几何填充**，电学全消失；
- **"长宽比越接近1越好（面积相同的情况下）"** → 词典序双目标。

数学对象：n 个矩形 {bᵢ(wᵢ,hᵢ)}，可 90° 旋转（2 朝向），求摆放使外接框面积最小、同面积下长宽比趋近 1。

### 1.2 为什么是 NP-hard（复杂性根源）

矩形装箱的复杂性来自**不重叠约束的析取性**：

```
∀i≠j: (xᵢ≥xⱼ+wⱼ) ∨ (xⱼ≥xᵢ+wᵢ) ∨ (yᵢ≥yⱼ+hⱼ) ∨ (yⱼ≥yᵢ+hᵢ)
```

每对模块的位置关系是**四选一的逻辑或**——这是非凸、离散的组合约束。Hakimi (1988) 由划分问题（partition）归约证明了最小面积布图规划的 NP-hard。**含义：最优解无法在多项式时间求得，100-300 块必须用启发式 + 近似质量论证。**

### 1.3 为什么"近似最优 + 下界论证"是唯一出路

- 精确算法（分支定界/ILP）只能处理 <50 块（MCNC 5 例中 3 例可证最优）；
- 启发式（SA/遗传/解析法）秒-分钟级出近似解；
- **但"近似"必须量化**——这就是下界论证存在的全部理由：没有下界，"最小面积"只是自封的称号。

## 二、核心数学原理（逐条展开）

### 2.1 admissible 布局与无损压缩定理（表示法的地基）

**定义**：admissible（可接受）布局 = 无任何模块能再向左或向下移动的布局。

**无损压缩定理**：任意合法布局可经反复"左下压实"（把能左移/下移的块推到贴边）化为 admissible 布局，且**外接框不增大**。

**证明直觉**：压实只把块往左下挪，外接框的右/上边界只会缩小或不变，左/下边界贴住被移块后仍被原布局的最左/最下块约束。

**推论**（关键）：最小面积最优解必存在于 admissible 布局集合中。**因此搜索 admissible 布局无任何损失**——这是 B*-Tree 能一一生效的前提。

### 2.2 B*-Tree：从布局到树的编码理论

**构造（布局→树）**：根=左下角模块。递归：左孩子=该块右侧相邻的最矮未访问块；右孩子=正上方同 x 坐标的块。

**解码（树→布局）**：
- 根在 (0,0)；
- 左孩子 nⱼ（父 nᵢ）：xⱼ = xᵢ + wᵢ（**紧贴父右侧**）；
- 右孩子 nⱼ：xⱼ = xᵢ（**同列正上**）；
- y 坐标由轮廓结构确定：yⱼ = 覆盖区间 [xⱼ, xⱼ+wⱼ) 的 skyline 最大高度。

**核心性质**：
1. **一一对应**：admissible 布局 ↔ B*-Tree 双射 → 无冗余编码，解空间不浪费；
2. **线性解码**：x 一次前序 O(n)，y 轮廓均摊 O(n) → 每次扰动评估 O(n)；
3. **天然免重叠**：左子在父右边（x 不交）、右子在父上方（y 不交），递推全树不相交 → **装箱最贵的重叠检查直接删除**。

### 2.3 轮廓（skyline/contour）结构：为什么 O(n) 而非 O(n²)

naive 做法：每次放置检查所有已放块的 y → O(n) 每次、总 O(n²)。n300 下 90000 次比较。
轮廓结构：维护 (x0,x1,height) 分段列表，放置块时只查其 x 区间覆盖的段（均摊常数个），抬高后合并等高邻段 → **整体 O(n)**。n300 下约 300 次。差 n 倍（300×）。

### 2.4 解空间与选型依据

| 表示法 | 解空间规模 | 解码 | 冗余 | 判定 |
|---|---|---|---|---|
| Sequence Pair | (n!)² | O(n²)/O(nlogn) | 大 | 慢 |
| **B*-Tree** | O(n!·2^(2n)/n^1.5) | **O(n)** | 无 | **选它** |
| O-tree | 同量级 | O(n) | 有 | 可 |
| Corner Sequence | — | O(n) | 声称 P-adm | 可 |

B*-Tree 胜出三重理由：(a) 解空间比 SP 小指数级；(b) O(n) 解码使 10 万次迭代可行；(c) 无冗余。ISPD'05 补充结论：表示法差异对结果影响小，**SA 调度/代价函数才是瓶颈**——不在换表示法上耗时间。

## 三、目标函数设计：完整逻辑链

### 3.1 为什么不能用简单加权（动机起点）

题设词典序"面积最小；面积相同长宽比趋近1"。直接加权 `Cost = A + λ(R−1)²` 有三个致命问题：
1. **权重主观**：λ 取多少无客观依据；
2. **量纲混乱**：面积（长度²）与长宽比（无量纲）直接相加需归一化；
3. **λ 失衡毁主目标**：λ 过大时，牺牲面积换方形会"赢"，违反题设面积优先（陷阱T2）。

**结论**：需要一种**单量纲、免权重、天然词典序**的目标表达。

### 3.2 M=√(A·R) 恒等式：目标重构的钥匙

记 M=max(W,H)、m=min(W,H)，A=W·H、R=M/m。则：

```
M² = M·m · (M/m) = A·R   ⇒   M = √(A·R)
```

**这个恒等式把两个目标锁进一个量**：
- 固定 A：M 单调于 R → **min M ⟺ min R**（副目标）；
- 固定 R：M 单调于 A → **min M 同时压面积**（主目标）；
- A ≤ M² → M 小则面积上界小（几何直觉：等面积矩形中正方形长边最小）。

**min-max 目标的本质**：`Φ = max(W,H)` 是"面积与长宽比的乘性耦合量"，单量纲、免权重、几何直观——这就是动机。

### 3.3 为什么必须加面积约束（诚实边界）

**反例**（min-max 与词典序一般不等价）：
```
布局 X: W=100,H=100 → A=10000, M=100, R=1
布局 Y: W=101,H=99  → A=9999,  M=101, R≈1.02
题设取 Y（面积小）；无约束 min-max 取 X（M 小）→ 冲突！
```
原因：M=√(A·R) 是耦合量，最小化它隐含"面积与长宽比的折中"，非题设的严格面积优先。

**解决方案**：附加面积近优约束：

```
min Φ = max(W,H)
s.t.  A ≤ A_opt(1+ε)      ε=1%
```

**为什么这彻底解决**：
- 面积约束锁死主目标（超面积解被排除）；
- 约束内 M 单调于 R → 副目标严格生效；
- ε 对应题设"面积相同"的操作化（SA 无法严格同面积，ε 邻域是工程正确解读）；
- **无近似假设**——比"近最优区等价"定理更硬，命题直接可证。

**命题**：面积约束下，min-max 解 = 面积 ≤ A_opt(1+ε) 的布局中长宽比最小者 = 题设词典序严格实现。

### 3.4 与备选目标的完整对比

| 目标 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 加权 A+λ(R−1)² | 实现简单 | 权重主观/量纲混乱/λ大毁面积 | 对照 |
| 两阶段词典序 | 数学最严谨 | 需先求 A_opt（与 min-max 方案等价） | 基准 |
| **min-max + 面积约束** | 单量纲免权重/几何直观/惩罚自然/严格一致 | 需先求 A_opt（两阶段） | **采用** |

## 四、算法选择的合理性

### 4.1 为什么是模拟退火（而不是别的启发式）

- **NP-hard 现实**：无多项式算法，必须在"解质量"与"计算时间"间权衡；
- **SA 的优势**：Metropolis 接受准则（Prob=min{1,e^(−ΔC/T)}）允许爬山跳出局部最优，是"探索+利用"平衡最成熟的框架；
- **参考论文背书**：Chen & Chang (2006) 用 B*-Tree+SA 在 GSRC n100-n300 取得 100% 固定轮廓成功率——**这正是赛题数据，方案已被验证**；
- 遗传/粒子群无增量优势（ISPD'05：SA 配置比表示法更关键）。

### 4.2 为什么是 Fast-SA（三阶段）而非经典 SA

经典 SA 冷热同一节奏：开头浪费在"不该接受的劣解"（高温过早接受），结尾浪费在"该接受的探索"（低温太早收敛）。TimberWolf 用变 λ 缓解但仍笨重。

**Fast-SA 三阶段**把时间花在最有效处：
1. **高温随机**：接受概率→1，先撒网防陷局部；
2. **伪贪心**（k=7 次，c=100）：温度趋零，快速下沉到局部最优；
3. **爬山**：温度回升跳出，再缓降细搜。

温度公式（含修正）：

```
T₁ = Δ_avg/|lnP|   （取绝对值：ln 0.9 < 0，否则负温度）
Tₙ = T₁⟨Δcost⟩/(n·c)   2≤n≤k
Tₙ = T₁⟨Δcost⟩/n       n>k
```

- ⟨Δcost⟩ = 当前温度运行平均，归一化后 <1 保证降温；
- n=k+1 时温度回升约 87× → 爬山跳变；
- 实测 12-13.9× 提速。

### 4.3 为什么三个扰动算子齐全

- Op1 旋转（O(1)）：只换朝向 → 方形度微调（Q1 特别重要，朝向直接改纵横比）；
- Op2 删插（O(n)）：改树形状 → 拓扑重构（缺它则树形状冻结、解空间受限）；
- Op3 交换：重排标签。

概率 rotate 0.1 / swap 0.4 / move 0.5 = **探索为主、微调为辅**。

### 4.4 为什么构造初解（混合算法）

**痛点**：SA 初值决定从哪个区域搜——烂初值把 10 万次迭代浪费在差区域。

**FFD 行堆叠构造**：高降序、逐行填，行高=行内最大高。确定性、**保证可行**（死区 8-9%），作 SA 起点。

**为什么"混合"而非纯 SA**：构造定骨架（快、保证可行），SA 打磨（紧、逼近下界）——两者互补非替代。构造还免费提供**构造性上界**（§五）。

### 4.5 为什么长条配对预处理

**痛点**：n100 有 15 个长条块（纵横比≥2.5，最大 3.9）——**长条是破坏方形的主敌**（一个 3.9:1 的长条直接拉爆外接框长宽比）。

**想法**：把"一高瘦一矮宽"的互补块配对成近方复合块。

**数学形式**：质量函数 q(i,j) = squareness(i∪j) − max(squareness(i), squareness(j))，只配 q>0 的对；最大权匹配（匈牙利 O(n³)）。**动机**：预处理先把最难塞的长条变成好塞的近方块，压缩解空间里对方形度破坏最大的分量。

### 4.6 为什么下界验证（三层下界）

**痛点**：无下界的"最小面积"是自封称号，评阅可直接质疑。

**三层下界**：
- 面积下界 A ≥ A_total（平凡）；
- 方形下界 A ≥ ⌈√A⌉²（R=1 时）；
- 固定宽下界 H(W) ≥ max(A_total/W, max块高)（工程可用）。

**构造性上界**：FFD 保证可行 → [LB,UB] 区间。**结果落区间内 = 代码正确 + 结果可信**：低于下界=bug，高于上界=还有优化空间。这是全算法正确性的最终校验。
