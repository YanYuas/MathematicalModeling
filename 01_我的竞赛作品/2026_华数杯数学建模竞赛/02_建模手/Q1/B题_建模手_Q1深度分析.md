## 1. 题设精读

> 假设芯片轮廓不固定，模块之间也没有连接关系。请问如何摆放模块，使得芯片轮廓面积最小；在轮廓的面积相同的情况下，其长宽比越接近1则结果越好。请根据所建立的模型和.blocks文件信息,对附件中的三组芯片(n100、n200、n300)分别完成模块摆放(即确定.blocks文件中类型为block的模块位置，每组芯片独立布图)，分别给出三组芯片轮廓的面积、长宽比、模块摆放的可视化结果。

**逐词拆解**：

| 词 | 含义 | 建模影响 |
|---|---|---|
| 芯片轮廓不固定 | 无固定外框，轮廓=布图外接矩形 | 面积是可优化目标，非硬约束 |
| 模块之间没有连接关系 | 无线网、无 HPWL、无 .nets/.pl 需求 | **Q1 只需 .blocks**，问题退化为纯装箱 |
| 面积最小 | 主目标 min(W·H) | 目标函数主项 |
| 面积相同 | 副目标生效的条件 | 词典序：先面积后长宽比 |
| 长宽比越接近1越好 | 副目标 min\|R−1\| | 次级目标，R=max/min |
| .blocks 中 block 类 | Terminal 不参与 Q1 | 只摆硬模块 |

**关键结论：Q1 = 经典最小面积矩形装箱问题（minimum-area rectangle packing）**，长宽比作次级目标。NP-hard（Hakimi 1988 划分归约）。

## 2. 约束与条件形式化

```
输入：n 个矩形块 {(wᵢ,hᵢ)}，可 90° 旋转
决策：每块左下角坐标 (xᵢ,yᵢ) + 朝向（2 选 1）
硬约束：任意两块内部不相交（可相邻可留隙）
轮廓：外接矩形 W×H（自适应，非预定义）
主目标：min A = W·H
副目标：min |R−1|，R = max(W,H)/min(W,H) ≥ 1
```

注意：不重叠是唯一硬约束。admissible packing（无块能再左移/下移）不增大轮廓 → 只需搜索 admissible 布局，无损失。

**死区口径**：死区比例 = (W·H − A_total)/(W·H)。A_total=179501/175696/273170。

## 3. 数学结构深度理解

### 3.1 下界（Q1 结果的锚点）

- **面积下界**：A ≥ A_total（平凡）
- **方形下界**：R=1 时 W=H ≥ ⌈√A_total⌉ → A ≥ ⌈√A_total⌉²
  - n100：⌈√179501⌉=424 → 方形面积 ≥ 179776（死区上限 275/179776=0.15%）
  - n200：420 → 176400（死区 704，0.40%）
  - n300：523 → 273529（死区 359，0.13%）
- **加宽高下界**（固定宽 W）：H(W) ≥ max(A_total/W, max块高) → 更有用的可行性判据

**关键洞察：三组的"完美方形"死区都在 0.1-0.4% 量级**——理论上极小。但 100-300 个整数尺寸块放进几乎零死区的方形，可行性极低（Adya&Markov：<5% 空白几乎不可行）。**真实答案的死区落在 1-5%**，方形边 428-435（n100）。这给论文一个漂亮的论证：下界清晰 + 实际可行区间 + 差距量化。

### 3.2 长宽比结构

- 长宽比 tie-break 只在面积相等时生效 → 正确建模是**词典序/加权小系数**，不能让长宽比干扰主目标
- R=1 的最优解 = 该面积下能否放进的方形问题
- 从 min-max 视角：min A s.t. R≈1 等价于 min max(W,H)（当 R=1 时 A=max²）。**这给出一个优雅的统一目标**（见创新点1）

### 3.3 数据几何画像（实测）

| | n100 | n200 | n300 |
|---|---|---|---|
| A_total | 179501 | 175696 | 273170 |
| √A_total | 423.7 | 419.2 | 522.7 |
| ⌈√A⌉² | 424² | 420² | 523² |
| 近方块(ar≤1.2) | 21/100 | 59/200 | 88/300 |
| 长条(ar≥2.5) | 15/100 | 29/200 | 27/300 |
| 最大纵横比 | 3.9 | 3.7 | 3.9 |
| 最大边长 | 67 | 48 | 48 |
| top块面积 | 4087(占2.3%) | 2256 | 2256 |

**几何结论**：
1. **n100 最难**：块大（61×67 占 2.3% 总面积）、近方块比例最低（21%）、长条多——大块+长条是方形化最大障碍
2. n200/n300 块小且匀（最大边长 48），近方块多 → 构造初解容易，SA 收敛快
3. **长条块（ar≥2.5）是创新点主战场**：正交配对可拼近方

## 4. 建模：B*-Tree + Fast-SA 面积模式

### 4.1 表示：B*-Tree
有序二叉树，根=左下角块；左子=右侧相邻块（x=父x+w）；右子=正上方块（x=父x）。admissible 布局与树一一对应，解码 O(n)（轮廓结构）。解空间 O(n!·2^(2n)/n^1.5)。

### 4.2 成本函数（Q1 面积模式）
```
Cost = A/A_norm + λ·(R−1)²      λ 取小（0.05-0.1）
```
- 主项 A/A_norm 驱动面积最小（归一化保证 ⟨Δcost⟩<1，SA 温度自洽）
- 次项 λ(R−1)² 只在面积相近时起作用（面积差 >> 长宽比差的加权）→ 近似词典序
- A_norm = SA 前试扰动 n 次的平均面积

### 4.3 Fast-SA
三阶段（高温随机→伪贪心k=7,c=100→爬山）+ Op1旋转/Op2删插/Op3交换 + Metropolis 接受 + 固定种子多次运行取最优。

### 4.4 终止与输出
- 记录全程最优（最小面积，同面积取更方），非末态
- 输出：面积 W·H、长宽比 R、死区比例、布图可视化

## 5. 几何创新点考察（本报告重点）

### 创新点 1：min-max 边长统一目标（重定义 Q1）
**想法**：把双目标合成一个——`min max(W,H)`（最小化包围方形边长）。
- R=1 时 A=max²，min-max 严格等于"面积+长宽比"的组合
- R 偏离 1 时，min-max 惩罚不平衡 → 自动偏向方形
- **数学关系**：A = R·W² 且 max(W,H)=W·max(1,R)。固定 A，max 最小化于 R=1。min-max 目标天然同时压面积和 R。
- **实现**：成本 `Cost = max(W,H)/norm`，SA 直接搜。比 `A+λ(R−1)²` 更干净——一个量纲，无权重调参，天然词典序
- **论文价值**：优雅的目标重构，几何直觉强，评阅友好

### 创新点 2：固定宽度 packing + 1D 扫描（不动点法）
**想法**：定义 H(W)=固定宽 W 下的最小高（SA 面积模式加硬约束 W≤W_target）。R(W)=H(W)/W。对 W 扫描/二分求 R≈1 的不动点 W*。
- 把 2D 优化压成 1D：对每个候选宽，一个 packing
- R(W)>1 增宽，R(W)<1 减宽，收敛到平衡宽
- 同时得到"该宽下面积最优"的直接图景，可画 W-R 曲线
- **论文价值**：算法视角清晰，可输出"宽度扫描图"作论文图，展示求解过程

### 创新点 3：几何构造初解（零迭代高质量初值）
**想法**：SA 前用确定性几何构造法生成近方形低死区初解：
- **Strip-snake 蛇形铺**：按面积降序，蛇形逐排铺，排宽≈目标宽 → 控制宽高均衡
- **Square-priority**：大块先放，填当前轮廓的最矮缺口（skyline 贪心）
- **配对预组**：长条块先正交配对成近方（见创新4）
- 初解死区可能直接 <3% → SA 只需精修
- **论文价值**：可作"独立构造算法"对照实验（构造 vs SA vs 混合），方法多样性加分

### 创新点 4：纵横比互补配对（长条整形预处理）
**想法**：n100 有 15 个长条块（ar≥2.5，最大 3.9）。长条是方形化元凶。预处理把长条**正交配对**拼近方：
- ar≈2 的长条两块正交拼 → 2:2 方形
- 一般：块 A(w×h) 找块 B(h×w) 或两长条并置
- 配对后当复合模块参与 packing，或 SA 算子加"配对合并/拆开"
- **几何美学**：纵横比互补拼接是经典几何思想（类似"对偶矩形"）
- 实现成本低，n100 收益大
- **论文价值**：独特的几何预处理创新，非套模板

### 创新点 5：下界论证 + 近最优性证明
**想法**：用解析+LP 下界量化结果与最优的距离：
- 面积下界 A_total、方形下界 ⌈√A⌉²、固定宽高下界 H(W)≥max(A_total/W, 最长块边)
- 对比实际结果死区，给出"距理论下界差距 X%"
- 若想更强：对给定宽 W 用列生成/LP 松弛求高下界
- **论文价值**："我们的死区 2.1%，理论下界 0.4%，差距 1.7%——已近最优"是可量化的强论证。评审最吃这套

### 创新点 6：面积-长宽比 Pareto 前沿
**想法**：跑多次+变权重，收集 (A, R) 非支配解，画前沿。
- 展示"牺牲 X% 面积换多少方形度"
- 直接回答题设 tie-break 的完整图景
- **论文价值**：比单点答案信息量大，体现"完整理解问题"，还能解释为什么取最终点

### 创新点 7：分层聚类布图（层级几何）
**想法**：把块聚成近方簇（簇内先 pack 成近方），簇间再 pack。
- 层级 = 两次 packing，天然方形化
- 对 n100 大块+小块混合有利：大块独立，小块聚类填充缝隙
- **论文价值**：层级结构展示（树状图），体现结构化思维

### 创新点 8：两阶段词典序（严谨处理 tie-break）
**想法**：Phase1 SA 纯面积（λ=0）得 A_min；Phase2 约束 A≤A_min(1+ε)，min |R−1|。
- 数学上最严谨的词典序实现，避免权重争议
- **论文价值**：双目标处理规范化，可与创新1（单目标统一）互证
