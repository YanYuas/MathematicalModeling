## 0. 一句话定位

**Q1 = 最小面积矩形装箱（minimum-area rectangle packing）+ 长宽比次级目标。只读 .blocks，无线网。NP-hard。解法 = B*-Tree + Fast-SA，配几何构造初解 + 下界论证 + 陷阱规避。**

## 1. 题设逐词点透

> "假设芯片轮廓不固定，模块之间也没有连接关系。请问如何摆放模块，使得芯片轮廓面积最小；在轮廓的面积相同的情况下，其长宽比越接近1则结果越好。"

| 词 | 字面 | 点透（为什么重要） |
|---|---|---|
| 轮廓不固定 | 无预定义外框 | **面积是可优化目标而非硬约束** → 问题从"在给定框内满足约束"降级为"自己找最小框"。这决定了成本函数以面积为主项 |
| 没有连接关系 | 无线网无 HPWL | **Q1 只需 .blocks 的 block 行**。.nets/.pl 完全无用。问题退化为纯几何装箱——这是全题最简单的问，也是几何创新的主战场 |
| 面积最小 | 主目标 min(W·H) | W·H 是外接矩形面积。**面积下界 = 模块总面积 A_total**，死区 = (W·H−A_total)/W·H。主目标 = 压死区 |
| 面积相同 | 副目标生效条件 | **词典序**（lexicographic）：面积优先，长宽比只在面积相等时生效。这是建模最重要的结构——权重设计、两阶段、min-max 统一目标都为此 |
| 长宽比接近1 | 副目标 min\|R−1\| | R 定义必须自洽（见陷阱T1）。R→1 从等周看 = 等面积下周长最小（B5） |
| .blocks 中 block 类 | 只摆硬模块 | Terminal 无连接关系+尺寸被省略 → 完全忽略（假设节声明） |

**点透结论**：Q1 是"纯几何装箱"，无任何电学耦合。三个隐藏决策：(a) 面积 vs 长宽比的权重结构；(b) R 的定义口径；(c) Terminal 去留。这三处正是评审会看的严谨性。

## 2. 约束与条件点透

```
输入：n 个矩形 {(wᵢ,hᵢ)}，可 90° 旋转（每块 2 朝向：w×h 或 h×w）
决策：每块 (xᵢ,yᵢ) + 朝向
硬约束：任意两块内部严格不相交（贴边合法，距离 0 允许）
轮廓：自适应外接矩形 W×H
主目标：min A = W·H
副目标：min |R−1|，R = max(W,H)/min(W,H) ≥ 1
```

**为什么只有一个硬约束**：
- "不超轮廓"在 Q1 是空洞的——轮廓就是外接框，天然包含所有块
- 因此唯一真约束 = 不重叠
- 不重叠的连续性是装箱难的根源：它不是凸约束，是析取的（块i在块j左/右/上/下，四选一）

**admissible 无损收缩（关键定理）**：任何合法布局可通过"左下压实"变成 admissible（无块能再左移或下移），且**外接框不增大**。→ 只需搜索 admissible 布局，无任何损失。这是 B*-Tree 一一生效的基础，也是论文该写明的理论锚点。

## 3. 问题本质点透

- **为什么叫装箱不是布局**：无 nets → 无线长目标 → 纯填充。和"瓷砖铺地""货箱装货"同一数学骨架。
- **复杂度**：NP-hard（Hakimi 1988 由划分问题归约）。精确算法仅 <50 块（MCNC 5 例中 3 例可证最优）。
- **为什么 NP-hard 仍可做**：100-300 块，模拟退火这类启发式秒级-分钟级出高质量近似解。**竞赛要的是近似最优 + 严谨论证，不是证明最优**。
- **搜索空间**：B*-Tree 编码后 O(n!·2^(2n)/n^1.5)，SA 在此空间随机游走逼近最优。

## 4. 数学结构点透（本问灵魂）

### 4.1 三层下界（结果的锚）

1. **面积下界**：A ≥ A_total（平凡但必须）
2. **方形下界**：R=1 时 A ≥ ⌈√A_total⌉²
   - n100: 424² = 179776（死区上限 0.15%）
   - n200: 420² = 176400（0.40%）
   - n300: 523² = 273529（0.13%）
3. **固定宽下界**：H(W) ≥ max(A_total/W, 最长块高) → 固定宽 packing 的可行性判据（创新2 基础）

**点透**：下界 1 太松（死区可为 0 的荒谬情形）、下界 2 太紧（完美平铺不现实）、下界 3 才是工程可用。论文的"近最优"论证应挂在下界 3 上：对每个候选宽 W，算出理论最小高，对比实际。

### 4.2 长宽比结构

- 副目标只在面积相等时生效 → 实际是"最小面积邻域内的方形化"
- **等周重述**：面积固定 ⇔ 周长 2(W+H) 最小（等周不等式思想）。周长 = 2√A(√R+1/√R)，R=1 最小。这是副目标的几何本质
- **min-max 统一**：R=1 时 A=max(W,H)²。`min max(W,H)` 一个量纲同时压面积和方形度 → 免权重调参（创新1）

### 4.3 约束图最长路径（最深刻的理解）

- 布图 ↔ 水平约束图 G_h（块 i 在 j 左 → 有向边）：**W = G_h 最长路径**
- 同理 H = 垂直约束图最长路径
- **Q1 的图论本质**：min (最长路径_h)·(最长路径_v) over 朝向+相对序
- 推论：要减 W 只能动**关键路径**上的块（B1 定向扰动）
- 论文价值：把"面积优化"写成"两方向最长路径积最小"——结构清晰，评阅认可

### 4.4 数据几何画像（实测）

| | n100 | n200 | n300 |
|---|---|---|---|
| A_total | 179501 | 175696 | 273170 |
| ⌈√A⌉² | 424² | 420² | 523² |
| 近方块(ar≤1.2) | **21%** | 29.5% | 29.3% |
| 长条(ar≥2.5) | 15个 | 29个 | 27个 |
| 最大纵横比 | 3.9 | 3.7 | 3.9 |
| 最大边长 | 67 | 48 | 48 |

**点透**：n100 最难（大块 61×67 占 2.3%、近方块比例最低、长条多）——**长条是方形化主敌**，配对它收益最大。n200/n300 块小匀、近方块多 → 构造初解容易。三组策略必须分化（陷阱T10）。

## 5. 建模点透（B*-Tree + Fast-SA 每一步为什么）

### 5.1 为什么 B*-Tree
| 候选 | 解空间 | 解码 | 冗余 | 定论 |
|---|---|---|---|---|
| Sequence Pair | (n!)² | O(n²) | 大 | 慢 |
| **B*-Tree** | O(n!·2^(2n)/n^1.5) | **O(n)** | 无 | **选它** |
| O-tree | 同量级 | O(n) | 有 | 可 |
| Corner Seq | — | O(n) | 声称P-adm | 可 |

点透：**解码 O(n) 是救命属性**——SA 一次扰动=一次解码，O(n) 让 10 万次迭代成为可能。SP 的 O(n²) 解码在 n300 上要慢一个数量级。无冗余 = 解空间不浪费。

### 5.2 B*-Tree 机制点透
- 根 = 左下角块（(0,0)）
- 左子 = 右侧相邻最低未访问块，x = 父x+w（**紧贴右边**）
- 右子 = 正上方同 x 块，x = 父x（**同列上方**）
- y 用**轮廓结构**：模块底 = 其 x 区间覆盖的轮廓段最大高度
- 一次前序 = 全部 x，轮廓逐段 = 全部 y → 均摊 O(n)

点透：树结构**天然保证不重叠**（左子必在父右、右子必在父上），解码后无需再校验重叠——这消除了装箱最难的约束检查。

### 5.3 成本函数点透

**方案A（加权）**：`Cost = A/A_norm + λ·(R−1)²`，λ∈[0.05,0.1]
- A_norm = SA 前试扰动 n 次的平均面积 → 归一化保 ⟨Δcost⟩<1 → Fast-SA 温度公式自洽（陷阱T8）
- λ 小 → 面积主导，长宽比只在面积相近时起作用 → **近似词典序**

**方案B（min-max，推荐）**：`Cost = max(W,H)/norm`
- R=1 时 A=max²，一个量纲同时压面积和方形度
- 无权重调参、天然词典序、几何直觉强
- 点透：这是对 Q1 双目标的**最优雅统一**，论文亮点

### 5.4 Fast-SA 三阶段为什么快
1. 高温随机：接受概率→1，**先撒网防陷局部**
2. 伪贪心（k=7,c=100）：温度→0，**快速下沉到局部最优**
3. 爬山：温度回升，**跳出局部极小再细搜**

点透：经典 SA 冷到热全用同一节奏，浪费大量迭代在"开始不该接受的劣解"和"结束该接受的探索"。Fast-SA 把时间花在最有效的阶段。实测 12-13.9× 加速。

### 5.5 扰动算子
Op1 旋转（O(1)，2朝向切换）/ Op2 删插（O(n)，改拓扑）/ Op3 交换。**旋转算子对 Q1 特别重要**——朝向选择直接改变块纵横比，影响方形度。

### 5.6 工程纪律
固定种子 ×10 次取最优 + 报统计（T7）；报告 best_so_far（T6）；三组参数分化（T10）。

## 9. 射影几何评估点透

**不适用**：射影不保轴对齐/面积/垂直——装箱是度量问题。硬套 = 生搬硬套。
**可借对偶/拓扑**：
- D1 平面图对偶（rectangular dual）：布图⇔平面图，可实现性判定
- D2 间隙对偶：空白当虚块，最小死区=补集最小化
- D3 连分数纵横比：slicing 长宽比递归组合，R=1 ⇔ 每层子块互补（**支撑配对创新**）
- 定位：进理论小节，**不进方法层**
