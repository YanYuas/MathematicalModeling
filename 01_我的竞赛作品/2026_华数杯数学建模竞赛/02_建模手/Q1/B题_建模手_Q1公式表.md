## 一、问题模型公式

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F1 | 不重叠约束（析取） | ∀i≠j: (xᵢ≥xⱼ+wⱼ)∨(xⱼ≥xᵢ+wᵢ)∨(yᵢ≥yⱼ+hⱼ)∨(yⱼ≥yᵢ+hᵢ) | 唯一硬约束；B*-Tree 解码下自动满足 |
| F2 | 轮廓宽高 | W=maxᵢ(xᵢ+wᵢ)−minᵢxᵢ；H=maxᵢ(yᵢ+hᵢ)−minᵢyᵢ | admissible 下 min=0 |
| F3 | 轮廓面积 | A = W·H | 主目标量 |
| F4 | 长宽比 | R = max(W,H)/min(W,H) ≥ 1 | 副目标量；口径统一 |
| F5 | 死区比例 | 死区% = (A−A_total)/A × 100 | 分母=轮廓面积 |
| F6 | 最优差距 | gap = (A−A_opt)/A_opt | 验证未牺牲主目标 |

## 二、目标函数公式

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F7 | min-max 主目标 | Φ = max(W,H) | 采用的主目标 |
| F8 | 面积近优约束 | A ≤ A_opt·(1+ε)，ε=1% | 封死词典序偏差 |
| F9 | M-A-R 恒等式 | M² = A·R，即 M=√(A·R) | 固定 A 时 min M ⟺ min R |
| F10 | 加权目标（对照） | Cost = A/A_norm + λ(R−1)²，λ∈[0.05,0.1] | 近似词典序 |
| F11 | 两阶段词典序（对照） | Phase1: min A；Phase2: min\|R−1\| s.t. A≤A_opt(1+ε) | 严谨基准 |
| F12 | 面积越界惩罚（Phase2 成本） | Φ = max(W,H)/Φ_norm + μ·max(0, A−A_opt(1+ε))，μ大 | 软约束实现 |

## 三、B*-Tree 解码公式

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F13 | 左子 x | xⱼ = xᵢ + wᵢ | 右侧相邻 |
| F14 | 右子 x | xⱼ = xᵢ | 正上方同列 |
| F15 | y 坐标 | yⱼ = max{skyline(x) : x ∈ [xⱼ, xⱼ+wⱼ)} | 轮廓结构均摊 O(n) |

## 四、Fast-SA 公式

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F16 | 初始温度 | T₁ = Δ_avg/\|lnP\| | **取绝对值保 T>0**（lnP<0） |
| F17 | 伪贪心段温度 | Tₙ = T₁⟨Δcost⟩/(n·c)，2≤n≤k | c=100 使 T→0 |
| F18 | 爬山段温度 | Tₙ = T₁⟨Δcost⟩/n，n>k | n=k+1 时温度回升 |
| F19 | Metropolis 接受 | Prob = min{1, e^(−ΔC/T)} | 接受准则 |
| F20 | 归一化 | A_norm = 试扰动 500 次平均面积 | 保 ⟨Δcost⟩<1 |
| F21 | 自适应 α（固定轮廓备用） | α = α_base + (1−α_base)·n_feasible/n | Q2 用，Q1 备用 |

## 五、下界与上界公式

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F22 | 面积下界 | A ≥ A_total | 平凡下界 |
| F23 | 方形下界 | A ≥ ⌈√A_total⌉² | R=1 时 |
| F24 | 固定宽下界 | H(W) ≥ max(A_total/W, max块高) | 工程可用 |
| F25 | 构造上界（FFD） | 总高 = Σ行高，行高 = 行内最大块高 | 保证可行 |

## 六、配对预处理公式

| 编号 | 名称 | 公式 | 说明 |
|---|---|---|---|
| F26 | 方形度 | squareness(S) = min(w_S,h_S)/max(w_S,h_S) | ∈(0,1]，越近1越好 |
| F27 | 复合块-并排 | w=wᵢ+wⱼ, h=max(hᵢ,hⱼ) | 高瘦+矮宽 |
| F28 | 复合块-叠放 | w=max(wᵢ,wⱼ), h=hᵢ+hⱼ | 取更方者 |
| F29 | 配对质量 | q(i,j) = squareness(i∪j) − max(squareness(i), squareness(j)) | 仅 q>0 配对 |
| F30 | 最大权匹配 | max Σq(i,j)x_ij s.t. Σx_ij≤1 ∀i, x_ij∈{0,1} | 匈牙利 O(n³) |
