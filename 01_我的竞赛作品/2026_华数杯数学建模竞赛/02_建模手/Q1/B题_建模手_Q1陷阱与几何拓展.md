## A. 陷阱清单（按严重度分级）

### A1 致命陷阱（答案错误/丢分）

**T1. 长宽比定义口径**
- "长宽比越接近1" — 歧义：R=H/W（可<1）还是 R=max/min（恒≥1）？
- 你若报 R=H/W=0.9（自我感觉接近1），评阅用 max/min 得 1.11 → 误判
- **对策**：论文明确 `R = max(W,H)/min(W,H) ≥ 1`，且结果表同时给 W 和 H 原始值，消除歧义

**T2. 词典序误解（权重过重毁面积）**
- 题设"面积最小；面积相同时长宽比→1"是**词典序**：面积优先
- 陷阱：把 (R−1)² 权重设大，换来更方但面积更大 → 直接违反主目标
- 例：面积 183k 的 R=1.0 vs 面积 181k 的 R=1.15，正确答案是后者
- **对策**：λ 取小（0.05-0.1）；或两阶段词典序（Phase1 面积，Phase2 约束面积 min R）；或 min-max 统一目标（创新1）

**T3. Terminal 处理不明确**
- Q1 说"确定 type=block 的模块位置"，无连接关系 → Terminal 不参与 Q1
- 陷阱 A：把 terminal 当块摆 → 面积/重叠全错
- 陷阱 B：有人认为轮廓须包含 terminal 坐标（0-444 区间）→ 无题设依据，但**须在模型假设节声明**
- **对策**：Q1 轮廓 = 纯模块外接矩形；论文假设节写明"Q1 忽略 Terminal，因其无连接关系且尺寸被省略"

**T4. 死区/下界混淆（声称不可达的最优）**
- 方形下界死区仅 0.4%（n100: 424²−179501=275）——但那是**完美平铺才可达**，100 个整数块塞近零死区方形可行性极低
- 陷阱：论文写"理论死区 0.4%，我们 2%"，暗示接近最优 → 对，但若写"死区可到 0.4%"→ 假
- **对策**：下界只是下界。报死区时同时给下界+差距，且说明方形可行性未证实。真正可信的"近最优"论证靠 LP/固定宽下界

### A2 高发陷阱（实现 bug / 结果不稳）

**T5. 重叠判定边界**
- 不重叠 = 内部不相交；**贴边（abut）合法**（距离 0 允许）
- 陷阱：用 `<=` 判重叠把贴边合法布局判死 → SA 搜索空间被错误收缩
- **对策**：严格用 `<`（内部严格不相交），边界接触不判重

**T6. SA 末态 vs 最优**
- 陷阱：报告退火结束时的布局，而非全程最优 → 结果明显差
- **对策**：全程记录 `best_so_far`（最小面积；同面积取更方），终态只作参考

**T7. 单次运行 / 无种子**
- SA 随机性大（Cornell 实测 100 次仅 70% 胜过随机重启爬山）
- 陷阱：跑一次报结果 → 复现不了、不稳
- **对策**：固定种子跑 N=10 次，取最优，报均值/标准差；论文写明方法学

**T8. 无归一化 → 温度公式失效**
- Fast-SA 温度 `Tn=T1⟨Δcost⟩/n` 依赖 ⟨Δcost⟩<1（归一化后）
- 陷阱：成本不归一，⟨Δcost⟩ 大，温度降不下去，SA 变随机搜索
- **对策**：`Cost=A/A_norm`，A_norm=试扰动 n 次平均

**T9. 旋转 90° vs 任意角**
- 题设明确 90° 旋转 → 每块 2 种朝向（非方形）
- 陷阱：有人允许任意角/连续旋转（想当然"转45°更省"）→ 错，轴对齐矩形任意角无法装箱，且违反题设
- **对策**：朝向集合 = {原, 90°旋转} = {w×h, h×w}

**T10. n100 与 n200/n300 参数一刀切**
- n100 块大（最大 67）、近方块仅 21%、长条 15 个 → 难
- n200/n300 块小匀、近方块多 → 易
- 陷阱：同一 SA 参数三组套用 → n100 收敛差
- **对策**：n100 加构造初解（创新3）+ 长条配对（创新4），迭代数加码；n200/n300 标准即可

**T11. 坐标取整/尺度**
- 块尺寸整数；坐标可实数。GSRC 惯例整数坐标
- 陷阱：坐标取整引入微小重叠/间隙 → 面积失真
- **对策**：保持精确坐标；若必须整数，重叠判定留 1e-9 容差

### A3 低级陷阱（审题）

**T12. Q1 误用 .nets/.pl**
- Q1 无线网无 HPWL → 完全不用 nets/pl
- 陷阱：把 nets 解析写进 Q1 流程，白耗时间还引入错误
- **对策**：Q1 只读 .blocks 的 block 行

**T13. 公式(1) 死区 0.15 误套 Q1**
- `W*=H*=√(A×(1+Γ))` 是 Q2 的，Γ=0.15
- 陷阱：Q1 也套 15% → 轮廓被撑大，面积假大
- **对策**：Q1 轮廓 = 实际 packing 外接矩形，无死区公式

**T14. terminal 行误当块解析**
- .blocks 里 `p100 terminal` 行（无尺寸）若被正则 `block 4` 之外的路抓错 → 崩溃/错块
- **对策**：解析只认 `block` 关键字行；terminal 行跳过

**T15. 三组独立 → 不许共享模块**
- 每组独立布图，模块不能跨组移动
- 陷阱：无（常识），但别把 n100 的布局误用给 n200

### A4 高级陷阱（评阅视角）

**T16. "面积相同"的操作化**
- 实际 SA 不会两次给完全相同面积 → 副目标生效区间是"最小面积邻域"
- **对策**：论文讲清楚——主目标最小化面积，副目标在最优面积邻域内生效（Pareto 前沿展示最完整）

**T17. 死区比例分母口径**
- 死区 = (W×H − A_total)/(W×H)（分母=轮廓面积），别用 A_total 作分母
- 口径不一致会与 Q2/Q3 的死区定义打架

**T18. 声称最优无证明**
- 无下界论证就写"最小面积 18.2 万" → 评阅可质疑"凭什么是最小"
- **对策**：必配下界论证（创新5），量化差距

## B. 更多几何思路（创新1-8 之外）

**B1. 关键路径压缩（约束图最长路径）**
- 布图 ↔ 约束图：水平约束图（块左右关系）的最长路径 = 轮廓宽 W；垂直同理 = H
- **几何洞察**：要减 W，只能动"关键路径"上的块（旋转/移位/换序）——沿关键路径对偶收缩
- 可实现：SA 的移动算子偏向关键路径上的块 → 加速收敛（定向扰动）
- 化归：packing → 有向图最长路径（DAG），W、H 都是图论量

**B2. 天空线平坦启发式（俄罗斯方块）**
- 放置块选"使当前轮廓最高处增长最小"的位置 → 保持 skyline 平坦
- 平坦 skyline → 外接框接近矩形 → 接近方形、死区小
- 直觉：像俄罗斯方块不堆塔，避免碎片化小缝隙
- 可实现：贪心构造初解的核心判据（配合创新3）

**B3. 距离变换最大间隙填充**
- 对空白区做距离变换，块放"离已放块最远的空隙"（最大化局部填充密度，减少不可用小缝）
- 比 B2 更全局；可作构造初解的第二个判据
- 代价：O(网格) 略高，n300 可承受

**B4. 递归方形引导分裂**
- 当前区域（目标近方）递归二分，子区也保持近方 → 整树方形化
- 化归：2D packing → 递归 1D 切分（guillotine 层级），DP 可解子问题
- 局限：只覆盖 slicing 布局；非 slicing 可能更紧。可作"保守构造"对照

**B5. 等周/周长最小化（面积→R→周长）**
- 关键洞察：面积固定时，长宽比→1 ⇔ 周长 2(W+H) 最小（等周不等式味道）
- `周长 = 2√A·(√R + 1/√R)`，R=1 取最小
- **几何重述**：Q1 副目标 = "等面积下周长最小" → 更直观、可画"周长-面积"图
- 与创新1（min-max）数学等价（R=1 时 W+H 最小 ⇔ max 最小），但给出不同解释框架

**B6. 连续松弛 + 投影（解析法交叉验证）**
- 允许块重叠，用势函数（重叠惩罚）连续优化，再投影回合法布图
- ePlace/RePlAce 的静电模拟思想（黄志鹏综述主推的现代方向）
- 对 Q1 是"不同方法"，可与 B*-Tree+SA **交叉验证**（论文加分：两法互证）
- 代价：实现重，n300 连续松弛可行

**B7. 对称转置闭包（R→1/R）**
- 全块 90° 转置 + 布局转置 → 宽高互换，R→1/R
- 最优布局在此对称变换下自洽 → 只搜 R≤1 的一半空间，另一半对称补全
- 节省一半搜索 + 几何对称性论证（论文点缀）

**B8. 方形残余模约束**
- n100: 424²−179501 = 275 的"残余"必须分布成小孔
- 若全块面积模某数 ≠ 方形面积模 → 严格方形不可能（数论不变量）
- 论文可提：方形可行性的**必要性检验**（面积模约束），作为可行性探测的廉价预筛
- 例：若所有块面积和 ≡ r (mod g)，方形边长须满足 424² ≡ r → 先筛

**B9. 形态学膨胀/腐蚀视角**
- 块视为像素集；不重叠 ⇔ 卷积支撑不相交；装箱 ⇔ 平移最小化外框
- 理论优雅，实现昂贵，论文可作概念引言

## C. 化归思路（转成已知/更简单问题）

| # | 化归 | 转成 | 用途 |
|---|---|---|---|
| C1 | 2D 装箱 → 1D strip packing | 固定宽 W 最小化高 H(W) | 创新2 的数学依据；可用 strip packing 理论下界 |
| C2 | 装箱 → 约束图最长路径 | DAG 最长路径 = W/H | B1 的图论化；分析关键块 |
| C3 | 长条配对 → 二分图最大权匹配 | 找最大化近方度的配对 | 创新4 的正规解法（匈牙利算法） |
| C4 | 面积副目标 → 等周周长 | 等面积下 min 周长 | B5 的化归；解释框架 |
| C5 | 布图 → 平面图对偶（rectangular dual） | 布图⇔平面图（Whittlesey 1964） | 非切片布图可实现性判定（理论） |
| C6 | 方形平铺 → 电网络（B-S-S-T 1940） | 方形剖分⇔电网络（电流/电势） | 完美平铺可行性；深但难用 |
| C7 | 非切片 → 切片松弛 | 波兰表达式/切分树 DP | 保守构造+B4 |
| C8 | 离散装箱 → 连续优化 | 解析法势函数 | B6 交叉验证 |
| C9 | 可行性探测 → SAT/CP | 无重叠析取约束 | 424² 方形可行性小规模探测（n100 或过重） |

**C2 值得展开**：水平约束图 G_h（块 i 在块 j 左侧 → 有向边 i→j），W = G_h 最长路径长度。最小面积 = 选朝向+相对序使 (最长路径_h)·(最长路径_v) 最小。**这是 Q1 最深刻的图论化归**——把"最优面积"转成"两方向最长路径积最小"。SA 本质上在搜这个。

**C3 值得展开**：长条配对 = 在"纵横比互补图"上求最大权匹配。块 i(w×h) 与块 j 配对的"方形度增益"可定义 → 最大权匹配（匈牙利/Kuhn-Munkres）得最优配对 → 复合模块。干净、可发表。

## D. 射影几何评估（诚实结论）

**直接结论：射影几何不直接适用于 Q1。**

原因：
1. 射影变换不保持轴对齐（矩形变平行四边形/梯形）
2. 射影变换不保持面积、不保持垂直、不保持长宽比
3. 装箱是度量问题（面积/距离），射影是交比/共线结构问题
4. 强行套射影会破坏问题本身

**但可借鉴的"对偶/拓扑"思想**（射影精神，非射影操作）：

**D1. 平面图对偶（rectangular dual）——真正有用的对偶**
- 每个轴对齐布图对应一个平面图：块=节点，共享边=边，外框=外节点
- 反之：非所有平面图可作矩形对偶（Whitney 条件）
- **用途**：(a) 布图可实现性判定；(b) 非切片结构分类（哪些块必须非切片）
- 这是"对偶空间"思想的正统几何应用，射影对偶的点线互换在装箱里变成"块-间隙互换"

**D2. 间隙对偶（块↔空白互换）**
- 把空白区域当"虚块"，布图 ⇔ 实块+虚块的填充
- 死区分布 = 虚块集合的结构 → 分析最小死区的分布形态
- 对偶视角：最小死区 = 虚块面积最小，即"块的补集最小化"

**D3. 交比/连分数：切片长宽比的组合结构**
- slicing 布图的长宽比由子块长宽比递归组合，形如连分数
- R=1 的目标 = 递归组合收敛到 1 → 每层子块纵横比互补（呼应创新4）
- 这是"比例结构"思想，射影的交比精神，但用的是比值的乘性结构

**D4. Tutte 嵌入 / 应力布局**
- 平面图 → 直边绘制（Tutte），与装箱共享"结构→几何"映射思想
- 理论上可把布图问题转成图嵌入问题（理论深度，工程无益）

**论文定位建议**：D1/D2 作为"问题结构分析"的理论小节（展现深度），D3 支撑长条配对创新的理论解释。**不要在方法层硬套射影**——评阅会认为生搬硬套。诚实表述"轴对齐度量问题不适配射影，但对偶/拓扑结构可借用"反而显成熟。

## E. 采纳建议（真用 vs 点缀）

**丢弃**：D4（Tutte，工程无益）、C9（SAT 探测 n100 过重）、C6（电网络，深而不适用）
