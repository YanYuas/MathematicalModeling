## A. 长条配对 ILP 建模（创新4 数学化）

### A.1 动机
n100 有 15 个长条块（ar≥2.5，最大 3.9），是方形化主敌。配对 = 预处理把长条组合成近方复合块。

### A.2 组合定义
块 i(wᵢ,hᵢ) 与块 j(wⱼ,hⱼ) 两种组合方式：
```
并排：w = wᵢ+wⱼ, h = max(hᵢ,hⱼ)
叠放：w = max(wᵢ,wⱼ), h = hᵢ+hⱼ
```
取组合后更方的（min/max 大者胜）。

### A.3 质量函数
```
squareness(S) = min(w_S,h_S)/max(w_S,h_S) ∈ (0,1]，越近1越好
q(i,j) = max(组合方式) squareness(i∪j) − max(squareness(i), squareness(j))
仅当 q(i,j) > 0 时配对有益（配前更方才算）
```

### A.4 匹配模型
```
max Σ_{(i,j)∈E} q(i,j)·x_ij
s.t. Σ_j x_ij ≤ 1  ∀i        （每块至多配一次）
      x_ij ∈ {0,1}           （E = {q(i,j)>0 的边}）
```
**解法**：最大权匹配 → 匈牙利算法（Kuhn-Munkres），O(n³)。n300 秒级。
**输出**：配对后的复合块集合 → 参与后续 B*-Tree packing。

### A.5 论文地位
独立几何预处理模块：**"纵横比互补配对预处理"**。理论支撑 = D3（连分数纵横比：复合块的纵横比是子块之比的乘性组合）。

## B. 论文引理草稿（"模型建立"节素材）

### L1 admissible 压缩无损定理
> 任意合法布局可通过反复"左下压实"化为 admissible（无块能再左移或下移），且外接框不增大。
> 推论：最小面积最优解必存在于 admissible 布局集合中 → 搜索无损失。

### L2 三层下界
> (a) 面积下界：A ≥ A_total。
> (b) 方形下界：R=1 ⟹ A ≥ ⌈√A_total⌉²。
> (c) 固定宽下界：H(W) ≥ max(A_total/W, max_i h_i)。

### L3 词典序 ⇔ min-max 等价（近最优区）
> 在面积近最优区（A = A_opt(1+δ)，δ→0）内，min max(W,H) 与词典序目标（先 min A，再 min R）等价，误差 O(δ)。
> 证明见 C。

### L4 等周重述
> 面积 A 固定时，轮廓周长 2(W+H) = 2√A(√R + 1/√R)，在 R=1 取最小。
> 推论：长宽比副目标 ⇔ 等面积下周长最小化。

### L5 约束图最长路径
> 布图对应水平约束图 G_h（块 i 在 j 左 → i→j）：轮廓宽 W = G_h 最长路径；垂直图同理 H。
> 推论：min A = min (最长路径_h)·(最长路径_v) over 朝向与相对序。

## C. min-max 等价性证明（含诚实边界）

### C.1 形式陈述
设布局外接框 (W,H)，M=max(W,H)，m=min(W,H)，A=W·H，R=M/m。定义两个目标：
- 词典序：min A，等面积时 min R
- min-max：min M

### C.2 一般情形反例（诚实警示）
```
布局X: W=100,H=100 → A=10000, M=100, R=1
布局Y: W=101,H=99  → A=9999,  M=101, R≈1.020
词典序取Y（面积小），min-max取X（M小）→ 两目标在一般情形冲突！
```
**结论：min-max 严格 ≠ 词典序。** 不可声称数学等价。

### C.3 近最优区等价定理
**命题**：在面积近最优区 A = A_opt(1+δ)（δ 小）内，min max(W,H) ⟺ min R（在近最优面积布局集合内）。
**证明**：
```
M = √(A·R) = √(A_opt(1+δ)·R)
固定 δ 时 M 单调增于 R → min M ⇔ min R
且集合 {A = A_opt(1+δ)} 内，R 最小化正是词典序副目标
```
**推论**：Q1 工作区（死区 2-5% ⟹ δ≤0.05）内，min-max 是词典序的有效代理。

### C.4 论文定位（诚实）
- **主目标**：词典序（面积优先）——这是评阅口径
- **min-max 作算法代理**：因近最优区等价（C.3），用 min-max 成本函数跑 SA 更稳（免权重），再报告其面积与词典序最优的差距（实测应 <2%）
- 论文写：*"在近最优面积区，min-max 目标与题设词典序目标等价（定理C.3），故以 min-max 作主成本函数"*——有定理支撑，且不撒谎

## D. 构造性上界（已计算，[LB,UB] 区间）

FFD 行堆叠（按高降序，行宽 ≤ W，行高=行内最大高）——确定性构造，保证可行。

| | 面积下界边 LB | **构造可行方形边 UB** | UB 死区 | SA 预期 |
|---|---|---|---|---|
| n100 | 424 | **443** | 8.53% | 432-435 |
| n200 | 420 | **440** | 9.25% | ~425 |
| n300 | 523 | **538** | 5.62% | ~530 |

**结论**：
1. **方形可行性构造性证明**（UB 侧）：n100 方形在 443² 可构造，n200 在 440²，n300 在 538²
2. 结合面积下界 → **方形边长可行区间 [LB, UB]**：n100 [424,443]、n200 [420,440]、n300 [523,538]
3. 贪心 UB 松（8-9% 死区）→ SA 应明显更紧（目标 2-5%）→ SA 结果落在区间内 = 正确性验证

**论文价值**：报"我们的方形边长 X ∈ [424,443]，理论区间 [LB,UB]"，评阅认可"下界+构造上界+启发式居中"三层结构。

## G. DFF 下界评估

**结论：面积界已近紧，DFF 增量有限。**
- 面积界裕度：n100@424 仅 0.65 单位、n300@523 仅 0.69 → 面积界已几乎贴着方形下界
- 更高 DFF（如 f(w)=⌈2w/W⌉ 类）最多再贡献 ~1-2 单位高度界
- **建议**：不引入 DFF 重机械；论文用面积界 + 固定宽下界即可，注明"面积界在方形目标下已近紧"

## H. "面积相同"操作化（消 T16 歧义）

### H.1 形式定义
```
A_opt = min 面积（SA 面积目标收敛值）
ε-近最优集 S_ε = {布局 L : A(L) ≤ A_opt(1+ε)}
报告解 = argmin_{L∈S_ε} R(L)，ε 取 1% 或 2%（论文写明）
```

### H.2 与题设对应
- 题设"面积相同" → 实际操作化为 ε 邻域（SA 无法保证严格同面积，邻域化是工程正确解读）
- 报告时同时给：主解（min area）+ 邻域内最方解 + Pareto 前沿

### H.3 论文表述
> "题设要求面积相同时长宽比趋近 1；由于搜索的随机性，实际操作化为：在最小面积 ε-邻域（ε=1%）内最小化 |R−1|，并通过 Pareto 前沿展示面积-R 权衡。"
