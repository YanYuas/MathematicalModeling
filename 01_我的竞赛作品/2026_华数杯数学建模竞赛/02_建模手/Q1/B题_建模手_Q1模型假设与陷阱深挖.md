## 一、模型假设系统化（H1-H4，每个带"若违背"后果）

数学建模 = 现实 → **假设** → 模型 → 求解 → 验证。假设是评阅审稿第一眼。没写清楚 = 被误读。

### H1 几何假设

| 假设 | 内容 | 若违背的后果 | 论文写法 |
|---|---|---|---|
| H1.1 **轴对齐** | 块边平行轮廓边，仅90°旋转 | 任意角装箱是不同问题（连续旋转无装箱解），结果不可比 | 显式声明"仅考虑轴对齐矩形布图" |
| H1.2 **刚性块** | hard block，面积/尺寸不可变 | 若软块可缩放 → 下界失效、问题变软块问题（参考论文Sec.VI） | "模块为硬块（尺寸固定）" |
| H1.3 **离散朝向** | θ∈{0,90°}，方形块方向退化 | 无（题设明确） | 朝向集合 {w×h, h×w} |
| H1.4 **贴边合法** | 距离0不重叠，abut允许 | 误判贴边为重叠 → SA搜索空间错误收缩 | "内部严格不交，边界接触合法" |
| H1.5 **连续坐标** | 允许实数坐标 | 若强制整数坐标需证明不损最优 | 见 M6（整数坐标WLOG可证） |

|---|---|---|---|

## 二、模型级陷阱深挖（M1-M12，区别于工程级T1-T18）

### M1. 面积目标的退化性（最深的陷阱）
- 旋转不改变面积、B\*-Tree压缩只减面积 → **面积在扰动下是阶梯函数**（多数扰动面积不变，突变时跳变）。
- 后果：SA在平台上搜索，接受准则对"同面积"解无区分 → 收敛慢、易停。
- **对策**：min-max目标 Φ=max(W,H)（有"连续"的压力感）；或加"压缩/去死区"定向算子；高温阶段靠跳变。
- 论文卖点：这就是为什么"面积目标"要改成"min-max目标"的根本原因——**不是口味，是SA动力学**。

### M2. B\*-Tree压缩完备性陷阱
- 定理方向对：任何无重叠布局压缩后可由某B\*-Tree表达，压缩不增面积 → 不丢最优。
- **陷阱在实现**：packing若只压左不压上、或有水平缝，面积虚高，SA比较失真。
- 对策：规范压缩（先x后y，y取下方最低空位）；单元测试：构造已知布局验证打包W/H。

### M3. 旋转算子比例陷阱
- 面积目标下旋转"无效"（面积不变），但min-max/方形目标下旋转是关键。
- 陷阱：Op1（旋转）概率设太低 → 方形度上不去；太高 → 纯面积阶段浪费时间。
- 对策：阶段自适应——Phase1纯面积时旋转概率低，Phase2 min-max时升高。

### M4. 方形可达性的虚假下界
- `⌈√A⌉` 下界给出 n100 死区0.15%（275单位）——完美平铺才可达，实际几乎不可能。
- **更深的**：即使面积模允许（B8预筛通过），整数矩形平铺的可行性还受**平铺理论**约束（Dehn不变量/矩形剖分可性）——两个方形剖分同构需要对应矩形比例匹配。
- 对策：报"下界 + 实际死区 + gap"三元组，不声称可达。评阅问"为何不到0.4%"——答"平铺组合约束"。

### M5. R在W=H处不可微（尖点抖动）
- R=max/min 与 Φ=max(W,H) 在 W=H 处都不可微 → SA接受准则在最优解附近抖动。
- 后果：终点不收敛到精确方形，报告R=1.00±ε。
- 对策：(a) 接受"近方"（R≤1.05）；(b) 光滑近似 max≈log-sum-exp（论文可提理论，不必须实现）。

### M6. 整数坐标WLOG（可证的非陷阱，但要点破）
- 块尺寸整数、规范压缩坐标 = 整数块尺寸的整数线性组合 → **整数坐标不损最优**。
- 陷阱反例：有人用实数坐标，输出乱；有人四舍五入产生缝隙。
- 对策：论文写"尺寸整数 + 规范压缩 ⇒ 最优解可取整数坐标"，坐标全整数输出。

### M7. "面积相同"等价类的正确操作化
- 面积离散且扰动下常不变 → "面积相同的解"是等价类；min-max目标下"同M"等价类更常见。
- **洞察**：min-max目标天然定义"同面积邻域"=同M邻域，副目标（R）在其中生效。这就是 min-max 优于"面积→长宽比"字典序**在SA里的结构性原因**（见 M1 联动）。

### M8. 下界报告的单点陷阱
- 只报 `⌈√A⌉` 一个下界 → 评阅用更紧的（LP/链式）质疑你"这不是下界"。
- 对策：报**下界族**（单块最大边长 / ⌈√A⌉ / 链式 / LP），取最紧的作claim，其余作附表。

### M9. 对称性冗余（D4群）
- 布局90°转置 = 等价解，SA重复搜索一半空间。
- 对策：约束 R≤1 搜索（转置自动对称），或接受冗余（增益小，可作论文点缀不提实现）。

### M10. 长条块放大的死区
- 长条块（宽高比大）自身面积小、周长长 → 打包制造细缝，死区被不成比例放大。
- n100有15个长条，n200/n300少 → **三组死区天然不同**，报告别一刀切对比。
- 对策：长条配对（C3，已有）；报告分组死区。

### M11. "近最优"的自证陷阱
- 报best不报gap → 无法自证近最优（T18已有）。**更深**：只报最终值不报**收敛曲线** → 无法证明迭代足够。
- 对策：论文附图 cost-vs-iteration（温度下降+best平台期），用"平台期"论证收敛。

### M12. 数据集结构差异
- n100（最大块67、近方块仅21%、长条15）难；n200/n300（块小匀）易。
- 陷阱：三组报同一死区水平 → 评阅发现n100死区应更大。
- 对策：参数分开调（n100加构造初解+配对），报告分组的死区/下界/gap。

## 三、新几何思路（补充 B1-B9 之外）

**G1. 闵可夫斯基和的无重叠判据**
- 两轴对齐矩形不重叠 ⟺ $|Δx| \ge \frac{w_1+w_2}{2}$ 或 $|Δy| \ge \frac{h_1+h_2}{2}$（L∞分离）。
- 无重叠 = 每对块"至少一个方向分离" → 布尔析取结构 → 化归SAT/CSP（C9）的几何基础。
- 用途：理论判据 + 校验器（一个干净的is_overlap函数）。

**G2. 加权Voronoi / 死区分配**
- 把死区当"空间资源"，分析死区分布形态（哪里该留缝）。
- 用途：构造初解时"最大间隙填充"（B3）的理论解释；非核心。

**G3. 递归面积分配（Mondrian风格）**
- 给定目标矩形（A_total×(1+ε)），递归切成子矩形按块面积配额。
- 比guillotine（B4）更灵活（不要求整切），可生成"结构化近方解"。
- 用途：保守构造 + 交叉验证（与SA结果比较）。

**G4. D4对称群的表述**
- 布局的8个对称（二面体群）→ B7的群论表述。理论点缀。

**G5. 平铺理论 / Dehn不变量**
- 矩形剖分可性、正方形平铺可性 → M4的理论深挖。
- 诚实：深但难用，论文作"方形可行性"的理论注脚即可。

**G6. 极值组合装箱密度**
- 推广链式下界：宽度 $> W/k$ 的块需要 ≥k 列 → 下界族。例如宽>W/3的块至少3列。
- 给出更紧下界的一个系统构造法（论文下界节素材）。

**G7. 周长-面积等周深化（B5续）**
- 周长 $P = 2\sqrt{A}(\sqrt R + 1/\sqrt R)$，R=1最小。LP可对P做连续下界。
- 化归为"等面积最小周长"的凸优化relaxation，可作交叉验证。

## 五、射影几何深挖（补充 D1-D4）

**保持已有诚实结论**：射影变换不保轴对齐/面积/垂直，装箱是度量问题，**硬套射影是错的**。

可借鉴的"对偶/结构"思想：

**D5. 对偶的正确姿势（深化D1/D2）**
- 布图 ⇔ 平面图 ⇔ **对偶图**（矩形对偶，Whittlesey 1964）。块↔间隙在对偶空间互换。
- "块-间隙互换" = 射影"点-线互换"精神的正确类比。**最小死区 = 虚块（间隙）面积最小**。
- 用途：非切片结构的识别（对偶图无四点环 ⟺ 非切片）。理论小节素材。

**D6. 交比 / 连分数（深化D3）**
- slicing布局的长宽比 = 子块纵横比的递归组合 = **连分数**结构。R→1 ⇔ 每层互补。
- 交比（射影不变量）精神：比例结构在递归下保持。支撑长条配对（C3）。
- 诚实表述："仿射比例结构，非射影操作"。

**D7. 共形映射（Schwarz-Christoffel）**
- 连续区域 → 方形区域的共形映射，用于"区域均匀化"概念。离散布图不直接适用。
- 论文可一句带过作为"连续极限"直觉，**不进方法**。

**论文定位**：D5（对偶）作结构分析小节，D6支撑配对理论，D7一句带过。方法层绝不套射影。

## 六、图论深挖（补充 C2/C3）

**F1. 下界的图论解释（最美的连接）**
- 块 x 投影 = 区间。区间长度 > W/2 的两两必交（区间不交需总长≤W）。
- x投影相交 → 不能并排 → **必须垂直堆叠** → 高度累加 = 链式下界。
- **图论重述**：宽>W/2的块集合 = 区间图里的团（pairwise交叠）→ 堆叠下界。
- 推广（G6）：宽>W/k 的块 → 区间图色数 ≥ k → k列下界。**这是区间图+着色的漂亮应用**。

**F2. 约束图双最长路径（深化C2）**
- 水平约束图 $G_h$：块i在j左 → 边i→j；$W = $ 最长路径($G_h$)。垂直同理 $H$。
- Q1 = 选朝向+相对序使 $W\cdot H$（=最长路径积）最小。**图论化核心**。
- 对偶性：$G_h$ 与 $G_v$ 是"正交约束系统"，SA同时在两个DAG上搜索。
- 关键路径分析（B1）在此图上有意义：改关键路径上的块才动W。

**F3. 区间图/完美图**
- 块x投影形成区间图（完美图）。区间图性质（团/着色多项式时间）解释列下界。
- 理论小节素材。

**F4. 矩形对偶图（与D5同源）**
- 非切片结构 = 对偶图有K4/4环。分类"哪些块组合必须非切片"。

**F5. 二分图最大权匹配（深化C3）**
- 长条配对 = 纵横比互补图上的最大权匹配（Kuhn-Munkres）。
- "方形度增益"定义权 → 最优配对 → 复合模块。干净可发表。

**F6. 树**
- B\*-Tree 本身 = 有序二叉树的图论对象。树→packing的映射是核心编码。

## 七、一页速查（新维度）

- **假设必写**：H1.1轴对齐、H1.2刚性块、H2.2 Terminal忽略（重点声明）、H2.4轮廓可变、H3.4下界≠可达
- **最深的陷阱**：M1面积目标退化（→min-max的理由）、M2压缩完备性（实现细节）、M5尖点不可微
- **下界报族**：单块边长/⌈√A⌉/链式（区间图团）取最紧
- **图论卖点**：宽>W/2堆叠=区间图团；约束图最长路径积=Q1图论化；长条配对=二分图匹配
- **化归卖点**：slicing DP精确解作保守对照
- **射影**：不进方法，只进理论小节（对偶/连分数）
- **报告**：best-of-N + 收敛曲线 + 下界gap + 分组参数

## 八、一句话总结

**Q1的深度不在"会跑SA"，而在三件事**：假设声明消除歧义（Terminal/轴对齐/死区口径）、模型级陷阱的机制理解（面积目标退化是换min-max的根本原因）、跨领域思路的诚实取舍（图论解释下界、对偶解释结构、射影只做理论）。
