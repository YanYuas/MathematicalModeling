## 二、题目数据识别方法论

### 2.1 数据识别流程

1. **逐字段验证**：模块数、线网数、总面积、终端坐标与标准基准集对比
2. **格式识别**：.blocks/.nets/.pl是标准bookshelf格式
3. **参考文献匹配**：找到使用同一基准集的权威论文
4. **数值对标**：论文中的实验数字可作为对标真值

### 2.2 华数杯B题的识别结果

- 数据 = GSRC标准基准集n100/n200/n300
- 权威解法 = Chen & Chang, IEEE TCAD 2006（B*-Tree + Fast-SA）
- 对标数值 = 论文Table V中的成功率、线长、死区数据

### 2.3 可复用经验

- **拿到题目先查数据来源**：如果是标准基准集，直接找对应论文
- **参考文献是金矿**：权威解法论文不仅给算法，还给实验数据和对比基线
- **诚实引用**：不得包装成"原创发现"，必须明确引用参考文献

## 三、B*-Tree表示法

### 3.1 核心思想

用二叉树表示模块的拓扑关系：
- **左子节点**：与父节点水平相邻（contour上的最右点）
- **右子节点**：与父节点垂直相邻（同x坐标，y方向堆叠）
- **模块坐标**：从根节点开始，按树结构递归计算

### 3.2 优势

1. **O(n)面积计算**：遍历树即可计算轮廓面积
2. **紧凑性**：比序列对（Sequence Pair）更省空间
3. **固定轮廓成功率高**：100% vs 序列对的50-71% @10%空白
4. **易于扩展**：支持旋转、软模块、L/T型模块

### 3.3 实现要点

- **contour数据结构**：记录每个x坐标的最大y值，用于放置模块
- **打包算法**：按树结构从左到右、从上到下放置模块
- **扰动操作**：旋转、移动、交换子树

## 四、快速模拟退火（Fast-SA）

### 4.1 传统SA的问题

- 温度调度慢：需要大量迭代才能收敛
- 权重固定：面积和HPWL的权重需要手动调
- 结果不可复现：随机性导致每次结果不同

### 4.2 Fast-SA的改进

1. **自适应权重**：根据当前解的面积和HPWL比例动态调整α/β
2. **快速温度调度**：初始温度 = 平均代价变化的若干倍，指数降温
3. **固定种子**：保证结果可复现
4. **多次运行取最优**：至少跑10次，取最优结果

### 4.3 参数设置

| 参数 | 取值 | 说明 |
|------|------|------|
| 初始温度 | ⟨Δcost⟩ × 20 | 平均代价变化的20倍 |
| 降温系数 | 0.85 | 每轮温度乘以0.85 |
| 每轮迭代 | 10×n | n为模块数 |
| 终止温度 | 0.001 | 低于此温度停止 |
| 运行次数 | 10次 | 取最优结果 |

## 五、四问递进策略

### 5.1 Q1 → Q2 → Q3 → Q4的递进关系

```
Q1（纯面积最小化，无轮廓无线网）
    ↓ 增加固定轮廓约束 + HPWL目标
Q2（固定轮廓15%死区 + HPWL最小化）
    ↓ 死区比例可变，求最小值
Q3（最小死区比例，二分搜索套Q2模型）
    ↓ 引入L/T型非矩形模块
Q4（L/T模块包络面积最小化，B*-Tree扩展）
```

### 5.2 每问的核心技巧

- **Q1**：B*-Tree基础实现，验证打包算法正确性
- **Q2**：自适应权重 + 固定轮廓可行性判断
- **Q3**：二分搜索套Q2模型，注意死区<5-8%时可行布局不存在
- **Q4**：L/T模块拆为2/3个矩形子块，邻接关系扩展

## 六、避坑指南

### 6.1 固定轮廓可行性坍缩

- **问题**：死区比例<5-8%时，可行布局可能不存在
- **表现**：SA无论怎么跑都无法满足不超界约束
- **对策**：Q3用二分搜索时，先验证可行性边界，不要假设总是可行

### 6.2 SA随机性

- **问题**：每次运行结果不同，交卷结果不可复现
- **对策**：固定随机种子 + 多次运行取最优 + 记录种子和运行次数

### 6.3 B*-Tree的contour实现

- **问题**：contour数据结构实现复杂，容易出bug
- **对策**：先用小规模（n=10）验证打包算法，再扩展到n=300
- **验证方法**：手动计算几个模块的坐标，与程序输出对比

### 6.4 HPWL计算

- **问题**：引脚在模块几何中心，HPWL是模块中心坐标的函数
- **注意**：Terminal只参与HPWL，不占面积、不参与重叠约束
- **优化**：2引脚网占89%，HPWL=曼哈顿距离，计算可简化

### 8.2 B*-Tree + Fast-SA通用模板

适用于：矩形模块布局、芯片 floorplanning、仓库布局、房间排布等问题。

### 8.3 二分搜索套模型模板

适用于：求最小/最大可行参数值的问题（如Q3求最小死区比例）。

```
1. 确定参数范围 [low, high]
2. 取mid = (low+high)/2
3. 用Q2模型验证mid是否可行
4. 可行 → high=mid；不可行 → low=mid
5. 重复直到high-low < 精度要求
```
