## 一、主力方案（B*-Tree + Fast-SA）：可行性 ✅ 确认

**判定：可行，且有参考论文背书。**

- B*-Tree 编码 admissible 布局、O(n) 解码、天然免重叠——已被 Chen & Chang (2006) 在 GSRC n100-n300（正是赛题数据）验证，固定轮廓下 100% 成功率；
- 编程手文档 1.4 的实现细节正确：树结构、轮廓线、温度公式（含 |lnP| 修正）、归一化纪律、best_so_far、种子×10；
- **无阻塞性问题**。

**两个小修**：
1. **扰动编号不统一**：文档表 1.4.4 写"Op1旋转/Op2交换/Op3删插"，建模手约定"Op1旋转/Op2删插/Op3交换"。三个算子内容一样，但编号要统一，否则论文正文引用对不上；
2. **Fast-SA 主循环的 n 索引**：代码 `while T>T_final: if n<=k...` 从 n=0 起，而温度公式要求 2≤n≤k 才用 (n·c)——n=0/1 时公式不成立，需从 n=2 开始按公式分段，或单独处理前两步。

## 二、min-max 主目标：可行性 ⚠️ 有条件，关键缺口必须补

**这是调整后方案的最大风险点。**

### 2.1 现状问题：min-max 缺面积约束

文档 3.2.5 的 min-max 代码：
```python
def min_max(W, H, norm):
    return max(W, H) / norm   # ← 只有主项，无面积约束
```

**若以这个作为主目标，理论站不住**：
- 无约束 min-max 与题设词典序**一般不等价**（反例：X(100,100) vs Y(101,99)，面积 Y 小但长边 X 小）；
- 直接最小化 max(W,H) 会在"面积"与"长宽比"间取隐含折中，**可能牺牲面积**——正是陷阱 T2；
- 论文若声称"min-max 实现词典序"而无面积约束，评阅可直接质疑。

### 2.2 必须补的结构：两阶段 + 面积近优约束

调整后方案必须实现：

```
Phase 1：纯面积 SA → A_opt（min-max 的参照）
Phase 2：min Φ = max(W,H)/Φ_norm + μ·max(0, A−A_opt(1+ε))，μ大
         （min-max 主项 + 面积越界软惩罚）
```

- **Phase 1 不可省**：min-max 需要 A_opt 定义"面积相同"的阈值；
- **惩罚必须软约束**（μ·max(0,...) 而非硬拒绝）：文档 3.2.5 的两阶段代码用 `else: return float('inf')` 硬惩罚——这会困住 SA（无法翻越不可行区），必须改成软惩罚。

### 2.3 文档里两阶段代码的缺陷

```python
if abs(W*H - target_area)/target_area <= 0.01:
    return abs(R - 1)
else:
    return float('inf')   # ← 硬惩罚，SA 会被困
```
改为：
```python
return max(W,H)/norm + MU * max(0, A - A_opt*(1+eps))   # 软惩罚
```

### 2.4 可行性结论

- **补上两阶段+面积约束后**：min-max 主目标可行、理论自洽（命题 1 保证）；
- **不补**：不可行，论文目标论证失败。

**这是调整后方案唯一需要编程手返工的结构性点。**

## 四、弃用对比方案与 Memetic 融合：合理性评估

**判定：弃用合理，但建议保留一个低成本 baseline。**

| 方案 | 调整后 | 评估 |
|---|---|---|
| SP+SA（表示验证） | 弃用 | ✅ 合理。ISPD'05 已证表示法差异影响小，验证意义不大 |
| B*-Tree+GA（算法验证） | 弃用 | ✅ 合理。GA 对离散树编码无优势，SA 已成熟 |
| 贪心+LS（确定性 baseline） | 弃用 | ⚠️ **建议保留**。论文"结果优于确定性 baseline X%"是很有说服力的一行，成本极低（FFD 已实现，LS 很简单） |
| Memetic 四阶段融合 | 弃用 | ✅ **正确**。过度设计：SP 跳跃、GA 内嵌 SA 调试成本高、风险大，对竞赛时间不可控。主力方案已够 |

**建议**：方案收敛为"主力（min-max 两阶段）为主 + 加权对照 + 贪心 baseline"，不碰 Memetic。

## 五、调整后方案的完整形态（建议）

```
算法（最终）：
  Phase 0：解析+FFD 构造初解（含长条配对开关）
  Phase 1：纯面积 SA → A_opt
  Phase 2：min-max + 面积软惩罚 SA → 最终布局
  Phase 3：贪心+LS baseline（论文对比用）

目标（最终）：
  Φ = max(W,H)/Φ_norm + μ·max(0, A−A_opt(1+ε))     [主，命题1保证]
  Φ_weighted = A/A_norm + λ(R−1)²                    [对照]
  Φ_twophase = 硬性词典序                            [对照基准]

验证：
  [LB,UB] 区间 + gap + 死区 + R
```

## 六、结论

**可行性判定：可行，需两处返工。**

| 项 | 判定 | 动作 |
|---|---|---|
| B*-Tree+Fast-SA 主力 | ✅ 可行 | 扰动编号统一；Fast-SA n 索引修正 |
| **min-max 主目标** | ⚠️ **有条件** | **补 Phase1+面积软约束**（结构性返工） |
| 加权对照 | ✅ | 归一化修正 |
| 两阶段对照 | ⚠️ | 硬惩罚→软惩罚 |
| 弃 Memetic | ✅ 正确 | 保持 |
| 弃 SP/GA | ✅ 合理 | 保持 |
| 贪心 baseline | ⚠️ 建议保留 | 低成本高论文价值 |

**一句话**：主力方案地基稳，min-max 目标理论核心在"面积约束"，必须从"裸 min-max"升级为"两阶段+软惩罚"，否则调整后方案的核心卖点（词典序）会塌。
