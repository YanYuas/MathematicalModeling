# 第一部分：问题分析与方案设计（理论视角）

## 1.1 问题描述与核心难点

### 问题描述

给定 $n$ 个**硬模块**（固定宽度 $w_i$、固定高度 $h_i$）和连接关系（网表 netlist），设计布图方案，实现：

- **主目标**：芯片总面积 $A_{total} = W \times H$ 最小
- **副目标**：芯片长宽比 $R = \max(W, H) / \min(W, H)$ 尽可能接近 1（即芯片形状接近正方形）

模块不可重叠，允许90°旋转。

**数据规模**：
- n100：100个模块，总面积 179501
- n200：200个模块，总面积 175696  
- n300：300个模块，总面积 273170

### 核心难点

| 难点 | 说明 | 应对策略 |
|------|------|---------|
| **组合爆炸** | $n!$ 种排列，30模块≈$2.65×10^{32}$ | 启发式搜索（SA/GA） |
| **拓扑表示** | 如何紧凑编码位置关系且保证无重叠 | B*-Tree O(n)编码 |
| **评估效率** | 每次迭代需解码坐标，n300若O(n²)则打不动 | 轮廓线结构O(n)解码 |
| **多目标冲突** | 面积最优可能导致极狭长布局 | 加权和：面积为主+长宽比惩罚 |
| **局部最优** | 贪心易陷入差区域 | 构造解+SA全局搜索 |

## 1.2 多目标处理策略

### 统一代价函数

$$
C(T) = A_{total} + \lambda \cdot (R - 1)^2
$$

| 符号 | 含义 | 计算方式 |
|------|------|---------|
| $A_{total}$ | 芯片总面积（**主目标**） | $W \times H$ |
| $R$ | 芯片长宽比（**副目标**） | $\max(W,H) / \min(W,H) \geq 1$ |
| $\lambda$ | 长宽比惩罚系数 | $0.05 \sim 0.1 \times A_{min}$ |

**设计原则**：
- $(R-1)^2$ 平方惩罚：偏离越多惩罚越重
- $\lambda$ 取值保证主目标优先：面积改善2%的收益 >> 长宽比从1.5降到1.4的收益
- 推荐 $\lambda = 0.05 \times \sum w_i h_i$

### 三种目标函数变体（用于实验对比）

| 目标 | 公式 | 适用场景 |
|------|------|---------|
| **加权和** | $A/A_{norm} + \lambda(R-1)^2$ | 通用，主次分明 |
| **min-max** | $\max(W,H)/norm$ | 面积已优（gap≤5%）后单纯优化R |
| **两阶段** | Phase1优化面积 → Phase2固定面积±1%优化R | 严格分离两目标 |

## 1.4 主力方案：B*-Tree + Fast-SA详解

### 1.4.1 B*-Tree拓扑表示

**核心洞察**：树结构本身保证解码不重叠。

**编码规则**：
- 有序二叉树，每个节点对应一个模块
- 根节点位于左下角 (0, 0)
- **左子节点**：置于父节点右侧紧邻（x = 父x + 父w）
- **右子节点**：置于父节点正上方（x = 父x，y由轮廓线决定）
- 每个节点附带旋转标志 $r \in \{0, 1\}$

**关键性质**：
1. 每棵 $n$ 节点的 B*-Tree 唯一对应一个无重叠紧凑布局
2. 树结构天然保证左子在右、右子在上的相对关系
3. 解空间规模 $O(n! \times 2^n)$（排列 × 旋转）

### 1.4.2 Packing算法（O(n)解码）

**轮廓线（Contour）结构**：维护已放置模块的上边界分段表示。

```python
PACK(T):
  contour = [(0, ∞, 0)]       # 初始轮廓：(x_start, x_end, height)
  for node in DFS(T):
    if node is root:
      (x, y) = (0, 0)
    elif node is LEFT_CHILD(parent):
      x = parent.x + parent.w
      y = contour.max_height_in(x, x + node.w)  # O(1)均摊
    elif node is RIGHT_CHILD(parent):
      x = parent.x
      y = contour.max_height_in(x, x + node.w)
    
    contour.update(x, x + node.w, y + node.h)   # 更新轮廓
    W = max(W, x + node.w)
    H = max(H, y + node.h)
  
  R = max(W, H) / min(W, H)
  return (W, H, R, coords)
```

**复杂度**：DFS遍历O(n) + 轮廓线操作O(1)均摊 = **总O(n)**

**为什么轮廓线是O(1)？**
- 用分段存储，每次更新最多新增2个分段
- n个模块最多产生2n个分段
- 总操作O(n)，均摊O(1)

### 1.4.3 Fast-SA算法

**与经典SA的核心区别**：

| 经典SA | Fast-SA | 差异原因 |
|--------|---------|---------|
| 高温长时间接受烂解 | 高温快冷跳过可行性修复 | 贪心初始解已可行 |
| $T_n = \alpha^n T_0$ | $T_n = T_1 \cdot \langle\Delta\rangle/n$ | 动态跟踪代价尺度 |
| 低温缓慢降温 | 伪贪心快速下沉 | 逼近局部最优后靠爬山 |

**温度公式**（关键创新）：

$$
\begin{cases}
T_1 = \frac{\Delta_{avg}}{|\ln P|} & \text{初始温度，P=0.9接受率} \
T_n = T_1 \cdot \frac{\langle\Delta cost\rangle}{n \cdot c} & 2 \leq n \leq k \
T_n = T_1 \cdot \frac{\langle\Delta cost\rangle}{n} & n > k
\end{cases}
$$

**参数说明**：
- $P = 0.9$：初始接受率（高温充分探索）
- $k = 7$：快冷阶段数
- $c = 100$：快冷系数
- $\langle\Delta cost\rangle$：**当前温度**新旧代价差的运行平均（不是初始值！）

**两个必须死守的纪律**：
1. ❗ **代价必须归一化**：$A_{norm}$ = SA前500次扰动的平均代价，保证 $\langle\Delta\rangle < 1$，否则温度公式失效
2. ❗ **记录best_so_far而非当前扫描点**：SA扫描是"正在探索的位置"不是"最优解"

**Metropolis接受准则**：
$$
\text{Prob}(accept) = \min\left(1, e^{-\Delta C / T}\right)
$$

**实施要点**：
- 每温度级迭代 $L = 100n$ 次
- 固定种子运行10次，取均值±std
- 早停：连续50温度级无改善

### 1.4.4 扰动算子

| 操作 | 描述 | 复杂度 | 概率 |
|------|------|--------|------|
| **Op1-旋转** | 随机节点翻转旋转位（w↔h） | O(1) | 0.1 |
| **Op2-交换** | 随机两节点交换树位置 | O(1) | 0.4 |
| **Op3-删除插入** | 删除节点后随机位置重插 | O(n) | 0.5 |

**为什么Op3占比最高？**
- 旋转：微调，改变纵横比但不改变拓扑
- 交换：探索，改变局部顺序
- 删除插入：重构，可能跳出局部最优陷阱

## 1.5 对比方案（简述）

### 方案2：Sequence Pair + SA

**表示**：两个排列 $(\Gamma^+, \Gamma^-)$，通过"同序定左右、逆序定上下"确定相对位置。

**解码**：构造水平/垂直约束图，最长路径算法求坐标，**O(n²)**。

**作用**：验证B*-Tree表示充分性。若SP结果显著更优，说明B*-Tree有表达盲区。

### 方案3：B*-Tree + GA

**编码**：排列（前序遍历）+ 旋转位串。

**遗传操作**：
- 交叉：子树交换
- 变异：节点交换 + 旋转翻转
- 选择：锦标赛（size=3）+ 精英保留10%

**作用**：验证SA搜索充分性。若GA显著更优，说明SA陷入局部最优。

### 方案4：贪心 + 局部搜索

**贪心策略**：按"线网度×面积权重"排序，逐个最佳适应插入。

**局部搜索**：2-opt风格邻域扰动，接受任何改进。

**作用**：确定性baseline，展示启发式提升幅度。

## 1.6 融合方案：Memetic四阶段混合

**核心思路**：不是"平等拼接"，而是在关键节点嵌入不同方案的优势。

### 阶段1：贪心注入初始化

```
1. 贪心+LS → 可行解 S_greedy
2. 种群生成（梯度扰动）：
   pop[0] = S_greedy
   for i in 1..POP_SIZE:
     k = ceil(i × K_max / POP_SIZE)  # 扰动次数递增
     pop[i] = PERTURB(S_greedy, k)
```

**设计要点**：形成"以贪心为中心、向外扩散"的初始种群。

### 阶段2：Memetic GA（内嵌短SA）

```
每代流程：
1. 锦标赛选择 → 交叉 → 变异
2. ★ 每个子代跑50次短SA精炼
   - T_short自适应，快冷α=0.9
3. 精英保留 + 轮盘赌替换
```

**为什么内嵌>串联？** 选择压力作用在**精炼后**的解上，收敛效率高。

### 阶段3：精英完整SA + SP跳跃

从最终种群取前3个精英，各自跑完整SA。**SP跳跃算子**每100次迭代触发1次：

```
SP跳跃（防表示盲区）：
1. B*-Tree → 坐标 → 提取SP (Γ⁺, Γ⁻)
2. Γ⁺中随机交换两模块
3. SP解码 → 评估 → Metropolis接受
4. 若接受：SP → B*-Tree
```

**成本**：1% O(n²)跳跃 + 99% O(n)主搜索 = 总成本增加约10%。

### 阶段4：LS扫尾

对最终解做确定性局部搜索，遍历所有邻域至局部最优。

## 2.3 阶段1：B*-Tree核心

**【思路】** 核心洞察：**树结构本身保证解码不重叠**。左子在父右边（x=父x+父w），右子在父上方（x=父x，y看轮廓）——递推下去任何子树都不相交。轮廓线结构让查询y坐标是O(1)均摊，**不是O(n²)两两比较**——n300时两者差n倍（**约300倍**）。

### 数据结构

```python
class Node:
    def __init__(self, block_idx, w, h):
        self.idx = block_idx
        self.w, self.h = w, h
        self.rotated = False  # 旋转标志
        self.left = None      # 左子
        self.right = None     # 右子
        self.parent = None
        self.x, self.y = 0, 0 # 解码后坐标
```

### 解码算法（Packing）

- [ ] 初始化轮廓线：`contour = [(0, inf, 0)]`
- [ ] DFS遍历树：
  - 根节点：(0, 0)
  - 左子：`x = parent.x + parent.w`，`y = contour.max_at(x, x+w)`
  - 右子：`x = parent.x`，`y = contour.max_at(x, x+w)`
- [ ] **轮廓线更新**：放置后更新(x, x+w, y+h)，合并相邻等高段
- [ ] 计算包围盒：`W = max(x+w)`, `H = max(y+h)`

### 待办清单

- [ ] `Node` 结构：block_idx, left, right, rotated
- [ ] 树初始化：完全二叉树（或从构造布局建树）
- [ ] **解码O(n)**：DFS序遍历 + 轮廓线结构
- [ ] 轮廓线：分段(x0,x1,height)，放置后更新+合并等高相邻段
- [ ] 自检：解码后检查包围盒W,H，无重叠（树结构保证）

### 验证标准

```python
# 任意合法B*-Tree解码后：
assert all(check_no_overlap(blocks))  # 树结构天然保证
assert packing_time < 0.01 * n        # O(n)验证
```

## 2.4 阶段2：扰动算子

**【思路】** SA靠"微扰+评估"探索解空间。三个算子看不同黑盒尺度：**Op1旋转**（O(1)，只换宽高方向）是方形度微调；**Op3交换**（改树标签、大幅）负责重构；**Op2删除插入**（O(n)，改树形状）是最粗粒度探索。概率分配rotate小、swap/move大，**探索为主、微调为辅**——先找结构，再调方向。

### 待办清单

- [ ] **Op1-旋转**：随机节点 w↔h（树不变），O(1)
- [ ] **Op2-交换**：随机两节点交换树标签，O(1)
- [ ] **Op3-删除插入**：删除节点（修复子节点O(1)/孙节点O(h)）→随机位置重插，O(n)
- [ ] 概率分配：rotate 0.1 / swap 0.4 / move 0.5

### 验证标准

```python
# 扰动1000次后：
assert tree.is_valid()              # 树结构完整
assert set(tree.node_ids) == original_ids  # 节点不丢失
```

## 2.5 阶段3：Fast-SA算法

**【思路】** Fast-SA三阶段=**把时间花在最有效的阶段**。经典SA高温乱飞浪费在"不该接受的烂解"，结尾浪费在"该接受的探索"。Fast-SA高温快冷跳过局部→伪贪心快速下沉→爬山跳出陷阱。**公式来自2026-08-07 PDF核对**：c是乘法系数`n·c`非`n^c`，T1必须除|lnP|（ln(0.9)<0，直接用lnP得负温度），<Δcost>是**当前温度**的运行平均非初始值。

### 参数设置

```python
P = 0.9           # 初始接受率
k = 7             # 快冷阶段数
c = 100           # 快冷系数
```

### 温度公式

```python
T1 = delta_avg / abs(log(P))  # 初始温度，|lnP|保证T>0
Tn = T1 * avg_delta_cost / (n * c)  # 2≤n≤k，快冷
Tn = T1 * avg_delta_cost / n        # n>k，正常冷却
```

**<Δcost>维护**：当前温度新旧代价差的运行平均（滑动窗口或指数平均），**归一化**后<1。

### 待办清单

- [ ] 参数：P=0.9, k=7, c=100
- [ ] 温度：`T1=Δ_avg/|lnP|`（**ln P<0，取绝对值保T>0**），`Tn=T1·<Δcost>/(n·c)` (2≤n≤k)，`Tn=T1·<Δcost>/n` (n>k)
- [ ] <Δcost> = **当前温度**下新旧代价差的运行平均（非初始值），归一化<1保证降温
- [ ] **归一化**：A_norm = SA前500次扰动平均代价，保证<Δcost><1
- [ ] Metropolis接受：`Prob=min(1, exp(-ΔC/T))`
- [ ] **best_so_far记录**：min面积（当面积更新才改），**不是当前扫描点**
- [ ] 固定种子×10次运行，取均值±std

### 验证标准

```python

assert std(deadspace) < 2%       # 稳定性

```

## 2.6 阶段4：代价函数（3目标开关）

**【思路】** 假设是**词典序**（面积优先，长宽比只在面积相同时生效）。三种目标：
- **加权和** `A/Anorm+λ(R-1)²`（λ必须小0.05-0.1，否则牺牲面积换方形=违背主目标，踩雷T2）
- **min-max** `max(W,H)/norm`（基于**定理**——面积近最优Δ≤5%后优化R与词典序等价，M=√(A·R)固定A时单调于R）
- **两阶段**：先面积后长宽比（数学上严谨，但对称）

三种都跑，对比验证等价性。R定义必须`max/min≥1`（踩雷T1，否则口径不一致）。

### 待办清单

- [ ] **加权和**：`A/Anorm + λ(R-1)²`，λ=0.05-0.1
- [ ] **min-max**：`max(W,H)/norm`
- [ ] **两阶段**：Phase1面积 → Phase2面积Δ≤1%下min|R-1|
- [ ] **R = max(W,H)/min(W,H) ≥ 1**（口径统一）
- [ ] 死区% = (W·H - A_total)/(W·H) × 100

## 2.3 阶段1：B*-Tree核心

**【思路】** 核心洞察：**树结构本身保证解码不重叠**。左子在父右边（x=父x+父w），右子在父上方（x=父x，y看轮廓）——递推下去任何子树都不相交。轮廓线结构让查询y坐标是O(1)均摊，**不是O(n²)两两比较**——n300时两者差n倍（**约300倍**）。

### 数据结构

```python
class Node:
    def __init__(self, block_idx, w, h):
        self.idx = block_idx
        self.w, self.h = w, h
        self.rotated = False  # 旋转标志
        self.left = None      # 左子
        self.right = None     # 右子
        self.parent = None
        self.x, self.y = 0, 0 # 解码后坐标
```

### 解码算法（Packing）

- [ ] 初始化轮廓线：`contour = [(0, inf, 0)]`
- [ ] DFS遍历树：
  - 根节点：(0, 0)
  - 左子：`x = parent.x + parent.w`，`y = contour.max_at(x, x+w)`
  - 右子：`x = parent.x`，`y = contour.max_at(x, x+w)`
- [ ] **轮廓线更新**：放置后更新(x, x+w, y+h)，合并相邻等高段
- [ ] 计算包围盒：`W = max(x+w)`, `H = max(y+h)`

### 待办清单

- [ ] `Node` 结构：block_idx, left, right, rotated
- [ ] 树初始化：完全二叉树（或从构造布局建树）
- [ ] **解码O(n)**：DFS序遍历 + 轮廓线结构
- [ ] 轮廓线：分段(x0,x1,height)，放置后更新+合并等高相邻段
- [ ] 自检：解码后检查包围盒W,H，无重叠（树结构保证）

### 验证标准

```python
# 任意合法B*-Tree解码后：

assert packing_time < 0.01 * n        # O(n)验证
```

def weighted_sum(W, H, A_total, lambda_=0.05):
    """加权和：A + λ(R-1)²"""
    R = max(W, H) / min(W, H)
    return A_total + lambda_ * A_total * (R - 1)**2

def min_max(W, H, norm):
    """min-max：max(W,H)/norm"""
    return max(W, H) / norm

def two_phase(tree, phase, target_area=None):
    """
