```python
def phase2_cost(W, H, A_chip, A_opt, eps=0.01, mu=1e6, norm=None):
    primary = max(W, H) / norm
    A_limit = A_opt * (1.0 + eps)
    penalty = mu * max(0.0, A_chip - A_limit)
    return primary + penalty
```

### C3. EMA平滑（fast_sa.py）

**改动**：
```python
class FastSA:
    def __init__(self, ..., ema_alpha=0.3):
        self._ema_delta = None
    
    def _run_temperature_level(...):
        avg_delta = sum(deltas) / len(deltas)
        if self._ema_delta is None:
            self._ema_delta = avg_delta
        else:
            self._ema_delta = (
                self.ema_alpha * avg_delta +
                (1.0 - self.ema_alpha) * self._ema_delta
            )
        return ..., self._ema_delta, ...
```

**效果**：温度更新使用 EMA-smoothed Δcost，减少震荡

**文件**：`fast_sa.py`
