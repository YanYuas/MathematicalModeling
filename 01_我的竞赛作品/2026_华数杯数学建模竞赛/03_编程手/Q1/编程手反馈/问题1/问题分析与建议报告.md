## 💡 实施的优化方案

### 方案B: Greedy-Random混合初始化

**核心思想**:
- 80%块按FFD贪心排列
- 20%块随机shuffle
- 目标: 降低初始gap从500%→80%，加速SA收敛

**实施代码**:
```python
def greedy_random_init(blocks, greedy_ratio=0.8, seed=None):
    """80% greedy FFD + 20% random shuffle"""
    sorted_pairs = sorted(enumerate(blocks), 
                         key=lambda x: x[1].h, reverse=True)
    split_idx = int(len(sorted_pairs) * greedy_ratio)
    greedy_part = sorted_pairs[:split_idx]
    random_part = sorted_pairs[split_idx:]
    random.shuffle(random_part)
    combined = greedy_part + random_part
    return ffd_to_btree(combined)
```

**修改文件**:
- `constructive.py`: +80行
- `config.py`: 'random' → 'greedy_random'
- `experiment_runner.py`: 动态参数调整
