
### 阶段3：分层参数设计（核心，2小时）

**目标**: 解决FFD+SA探索性丧失问题

**问题根因**:
```
Ultra-fast参数 → 针对random初始化（gap=445%）
                ↓
           对FFD初始化（gap=4.78%）过激
                ↓
           11次迭代即终止，seed无效
```

**方案**: 动态参数（已在experiment_runner.py实现，需验证）

**当前代码**（experiment_runner.py:60-64）:
```python
if dataset == 'n300' and initial_method == 'greedy_random':
    sa_params['L_factor'] = 5       # 10 -> 5
    sa_params['max_no_improve'] = 3  # 8 -> 3
    sa_params['T_final'] = 1.0       # 0.1 -> 1.0
```

**问题**: 只针对n300+greedy_random，未覆盖FFD

**修复**:
```python
# 分层参数策略
def get_sa_params(dataset, initial_method, initial_gap):
    """根据初始gap动态调整SA参数"""
    base_params = SA_PARAMS.copy()
    
    if initial_gap < 10:  # FFD初始化（gap<10%）
        # 保守参数：允许更多精细搜索
        base_params['L_factor'] = 50      # 增加迭代
        base_params['max_no_improve'] = 20 # 增加容忍
        base_params['T_final'] = 0.01      # 降低终止温度
    elif initial_gap < 100:  # greedy_random（gap 10-100%）
        # 标准参数
        base_params['L_factor'] = 10
        base_params['max_no_improve'] = 8
    else:  # random初始化（gap>100%）
        # 激进参数：快速下降
        base_params['L_factor'] = 5
        base_params['max_no_improve'] = 3
        base_params['T_final'] = 1.0
    
    return base_params
```
