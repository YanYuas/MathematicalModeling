## 二、必须返工（结构性，优先级最高）

### M1. min-max 目标必须加面积近优约束 + 两阶段

**现状（错误）**：`min_max(W,H,norm) = max(W,H)/norm`，裸目标无约束。

**改为（正确）**：

```python
# cost_functions.py
def phase2_cost(W, H, A, A_opt, eps=0.01, mu=1e6, norm=None):
    """Phase 2 主成本：min-max + 面积软惩罚
    A_opt: Phase 1 纯面积优化的结果
    eps:   面积容忍度 1%
    mu:    惩罚系数（远大于主项量级）"""
    primary = max(W, H) / norm if norm else max(W, H)
    penalty = mu * max(0.0, A - A_opt * (1 + eps))   # 软惩罚，非硬拒绝
    return primary + penalty
```

**禁止** `return float('inf')` 硬惩罚——SA 无法翻越不可行区会被困住。

### M2. 必须实现两阶段主流程

```python
# main.py / fast_sa.py
def solve_two_phase(blocks, init_tree, seed):
    # Phase 1：纯面积 SA → A_opt
    cost_phase1 = lambda W,H,A: A / A_norm                 # 纯面积，归一化
    A_opt = run_sa(blocks, init_tree, cost_phase1, seed).area

    # Phase 2：min-max + 面积软惩罚 → 最终布局
    cost_phase2 = lambda W,H,A: phase2_cost(W,H,A, A_opt)
    return run_sa(blocks, init_tree, cost_phase2, seed)
```

- Phase 1 **不可省**——min-max 依赖 A_opt 定义"面积相同"的阈值；
- Phase 2 的 mu 取大值（如 1e6 相对主项），保证终解合规；
- 报告 gap = (A_final − A_opt)/A_opt，证明未牺牲主目标。

### M3. 加权对照目标必须归一化

**现状（错误）**：`weighted_sum = A_total + λ·A_total·(R−1)²`，未归一化。

**改为**：
```python
def weighted_cost(W, H, A, A_norm, lam=0.05):
    R = max(W,H) / min(W,H)
    return A / A_norm + lam * (R - 1)**2     # 归一化，λ 相对量
```
不归一化 → ⟨Δcost⟩≥1 → 温度公式失效（红线 3）。
