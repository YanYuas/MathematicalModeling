# PRD｜Q1 六张结果图（布图×3 + 扫描曲线×3）

> 2026-08-08 | 编程手 | 方法：PRD 写作技法（Claude Design 沉淀）——"感觉→可验收工程参数 + 可点算编号"
> 现状：初版图细节不足（信息不全/视觉无层次/无 token 体系）→ 本 PRD 重设计

---

## 1. 目标

六张图服务论文 Q1 两个目的：**三组布图 = 评阅第一眼（结果可信）**，**三组扫描曲线 = 构造上界证明（方法可信）**。

硬指标（每条可验收/可证伪）：
1. 每张图信息完整：W×H、R、死区%、构造法、target_width 全部标注
2. 数字进图：评阅第一眼读到关键数字，不看正文
3. 视觉统一：六图共用同一 design token 体系（配色/字号/线宽/间距）
4. 可读性：n300（300 块）编号不重叠不截断，字号可辨
5. 反例锚定：**不靠装饰性元素凑数**（无意义的渐变/阴影/背景图），每个视觉元素都有信息职能

## 2. 视觉规范（design token 制度，硬验收项）

**色板 token**（全图只能引用，不得出现 token 外写死色）：

| token | HEX | 用途 |
|---|---|---|
| `--fill-normal` | #D6EAF8 | 普通块填充（冷蓝） |
| `--edge-normal` | #2874A6 | 普通块边框 |
| `--fill-strip` | #FDEBD0 | 长条块填充（暖橙，AR≥2.5 高亮） |
| `--edge-strip` | #D35400 | 长条块边框 |
| `--outline` | #C0392B | 芯片外框（3px，强调） |
| `--grid` | #E8E8E8 | 网格线（虚线 0.6） |
| `--curve-base` | #2874A6 | 扫描-基础行堆叠曲线 |
| `--curve-rot` | #E67E22 | 扫描-长条旋转曲线 |
| `--ref` | #7F8C8D | 参考线（y=target） |
| `--feasible` | #E8F8F5 | 可行区域填充（浅绿） |
| `--infeasible` | #FDEDEC | 不可行区域填充（浅红） |
| `--annot` | #2C3E50 | 标注文字（深灰蓝） |

**字体 token**：标题 16 / 轴标签 12 / 刻度 10 / 块编号 5-7（按规模） / 信息卡 11 / 注释 9
**线宽 token**：主曲线 2.5 / 次曲线 1.8 / 外框 3 / 网格 0.6
**间距 token**：布图留白 5%、扫描坐标轴 margin 5%

## 3. 图规格（每图：信息职能 + 实现）

### 3.1 layout_n100/200/300.png（布图）

信息职能：评阅 3 秒内确认"布局合法、死区可辨、结果数字明确"。

| 元素 | 规格 |
|---|---|
| 块填充 | 普通 `--fill-normal`+`--edge-normal`；长条 AR≥2.5 `--fill-strip`+`--edge-strip`（长条视觉高亮 = 传达"长条旋转预处理"） |
| 块编号 | 块内居中，n100 字号 7、n200 6、n300 5；宽<30 旋转 90° |
| 外框 | `--outline` 3px，右下角标注 W×H |
| 尺寸线 | 上边线 W 标注、右边线 H 标注（箭头+数字） |
| 信息卡 | 右上角白底黑框圆角，含：`n100 | 443×442 | R=1.002 | 死区 8.33% | 面积 195,806 | 长条旋转` |
| 坐标轴 | 隐藏刻度数值，保留轴线浅灰（视觉焦点在块） |

### 3.2 scan_n100/200/300.png（扫描曲线）

信息职能：3 秒内确认"构造上界怎么来的、最优边长多少、两种构造的取舍"。

| 元素 | 规格 |
|---|---|
| 双曲线 | 基础 `--curve-base` 实线圆标 + 旋转 `--curve-rot` 虚线方块标 |
| 参考线 | `--ref` 点线 y=target |
| 区域 | y>target 上方 `--infeasible` 浅红；y≤target 下方 `--feasible` 浅绿（用 axhspan 画全幅） |
| 最优点 | 大星标 ★ + 箭头 + 标注 `target=443 (长条旋转)` |
| 次优点 | 小圆标 + 标注 `基础 444` |
| 图例 | 右上角，含基础/旋转/y=target/可行区 |
| 坐标轴 | x=target_width，y=max(W,H)，范围留 5% margin，网格 `--grid` 虚线 |

## 4. 技术约束

- 允许：matplotlib（Agg），Microsoft YaHei 字体，dpi 150，PNG，`--*` token 引用
- 禁止：token 外写死颜色、emoji、装饰性渐变/阴影、重叠文字、截断文字
- 降级：无 YaHei → 回落 SimHei → sans-serif（图内中文转英文保可读）

## 5. 交付与验收（编号自检清单）

交付物：`layout_n100/200/300.png` + `scan_n100/200/300.png`，共 6 张，dpi 150。

自检（做完再交）：
1. **信息完整**：每张 layout 信息卡含 W/H/R/死区/面积/构造法；scan 含最优 target
2. **长条可辨**：长条块暖橙高亮，与普通冷蓝区分
3. **外框尺寸**：红框 + W/H 尺寸线标注
4. **scan 区域**：可行/不可行区域填充可辨，★ 最优点 + 箭头 + 标注
5. **无重叠截断**：n300 编号不重叠、无文字截断（目测抽查）
6. **风格一致**：六图色板/字体/线宽一致（对照 token 表）

## 6. 一句话总结

**把"精美"翻译成可验收项：token 制度锁风格（色板/字号/线宽/间距），布图图"数字进图+长条高亮+尺寸线+信息卡"，扫描图"可行区域填充+最优点★标注"，六图统一，自检 6 条全过才算交付。**
