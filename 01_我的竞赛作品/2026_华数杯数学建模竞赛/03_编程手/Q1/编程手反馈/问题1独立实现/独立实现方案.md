# Q1 独立实现方案（建模手视角全量重新设计）

> 2026-08-08 | 视角：建模手/总指挥 | 目的：第二条独立实现路径，交叉核实编程手成果
> 依据：建模手 Q1 全套（数学原理总理顺/公式表/经验总结/建模数学化）+ 编程手实现审计
> 结论：**编程手实现存在 8 处系统性缺陷，根因是归一化与温度调度在含惩罚 cost 下失效，导致 SA 退化为随机游走。独立实现须忠实建模手理论，不继承这些缺陷。**

### 1.2 代码级根因（8 处）

**R1. phase2 的 T1 被软惩罚主导 → 温度爆炸 → 随机游走**（最严重）
- `fast_sa.py::_init_temperature` 用**原始 cost** 采样 delta：`abs(new_cost - old_cost)`
- phase2_cost 原始量：`max(W,H)/A_total + mu*max(0, A-A_limit)`，mu=1e6
- FFD 起点附近扰动后面积超 A_limit → penalty = 1e6 × 超额(≈10²-10³) = 10⁸-10⁹
- delta_avg ≈ 10⁸ → T1 = delta_avg/|ln0.9| ≈ 10⁹
- Metropolis `e^(-ΔC/T)`，ΔC~O(1) 归一化，T~10⁹ → 接受率恒≈1 → **纯随机游走**
- 证据：10 seed 全返回 FFD 初始解（best 从未更新）

**R2. 归一化失效（A_norm 含 penalty）**
- `_compute_norm` 返回 avg cost（含 penalty≈10⁹）→ A_norm≈10⁹
- 归一化后主项 `max(W,H)/A_total/A_norm ≈ 0.002/10⁹ = 10⁻¹²`，**主项信息全丢**
- SA 只见 penalty 项，不见面积/形状目标

**R3. 温度公式量级不同步**
- `_init_temperature` 采样**原始** cost delta → T1 原始量级
- `_run_temperature_level` 记录**归一化** delta → avg_delta_n ≈ O(1)
- T_n = T1·avg_delta_n/n，两项量级错配，温度失去物理意义

**R4. 早停双闸太激进**
- T_final=0.1 + max_no_improve=8
- phase1：T1≈0.1-1，n=2 时 T=T1/200≈0.005 < T_final → **1-2 级即停**（2000 次扰动）
- 建模手理论 k=7,c=100，编程手改 k=5 + T_final=0.1 是"性能优化"但牺牲收敛

**R5. FFD 行宽口径漂移**
- `constructive.py::ffd_packing` target_width = sqrt(A_total)×1.05
- n100: 444.85 → 行堆 444×444，max=444 > 建模手 UB=443
- 建模手上界 443 的构造口径（行宽）未传达到编程手 → **UB 需独立验证**

**R6. seed 控制失效**
- `random.seed(seed)` 设了，但 SA 不收敛（R1-R4）→ seed 差异全被"best=初始解"吞掉
- FFD 构造确定性 → seed 只影响 SA 随机链，而 SA 无优化能力

**R7. greedy_random 反效果**
- 80% 贪心结构 + 20% 随机 = 结构性扰动
- SA 不收敛时结构优势发挥不出，随机部分反而制造更差解
- 学术口径模糊：greedy_random 既非 random 也非 ffd（问题分析报告已判方案 A）

**R8. 配对实验空转**
- `pairing.py` 已实现，但 experiment_runner 未接入（pairs_count=0）
- 配对消融实验 20 次全是假数据

## 二、独立实现设计（忠实建模手理论）

### 2.1 模块结构与差异点

| 模块 | 编程手实现 | 独立实现（建模手视角） | 修正 |
|---|---|---|---|
| 数据加载 | `data_loader.py` | `m_data.py` | 独立写，面积校验 |
| B*-Tree | `btree.py`（含 left-skew 退化 build） | `m_btree.py` | 完整树 + skyline contour |
| 算子 | `operators.py` Op1/Op2/Op3 | `m_operators.py` | 同三算子，独立实现 |
| 代价 | `cost_functions.py` μ=1e6 未归一化惩罚 | `m_cost.py` | **惩罚归一化 + μ 匹配量级** |
| SA | `fast_sa.py` T1 原始量级 | `m_fastsa.py` | **全归一化采样 + 温度正确调度 + 不激进早停** |
| 构造 | `constructive.py` target=√A×1.05 | `m_construct.py` | **target_width 参数化扫描** |
| 边界 | `bounds.py` UB=FFD 单点 | `m_bounds.py` | **UB 扫描验证** |
| 实验 | `experiment_runner.py` | `m_experiment.py` | 交叉核实协议 |

### 2.2 核心修正：归一化（建模手 F20 的正确实现）

建模手 F20：A_norm = 试扰动 500 次平均。但含惩罚 cost 的平均会被 penalty 主导。**修正：分项归一化。**

```
phase2_cost = M/Φ_norm + μ · max(0, A − A_opt(1+ε)) / A_opt
  Φ_norm  = 初始解 max(W,H)（≈450）   → 主项 O(1)
  惩罚项  = 超额比例（超额1%→0.01）    → 副项 O(0.01)
  μ       = 10（超额 1% → 惩罚 0.1 ≈ M 变化 45 单位）
```

**效果**：两项都无量纲 O(1)/O(0.01)，delta_avg≈O(0.1-1)，T1≈O(1-10)，温度调度恢复物理意义。μ 不再需要 1e6。

对比编程手：`max(W,H)/A_total + 1e6·max(0,A−A_limit)`，A_total=1.8e5 非 Φ_norm≈450 → 主项 0.002 vs 惩罚 1e6·超额 → 量级爆炸。

### 2.3 核心修正：温度采样一致

```
_init_temperature：对归一化 cost 采样 delta → delta_avg 归一化量级
_run_temperature_level：记录归一化 delta → avg_delta_n 同量级
T1 = delta_avg/|lnP|，T_n = T1·avg_delta_n/(n·c)（2≤n≤k）
T_n = T1·avg_delta_n/n（n>k），k=7, c=100（建模手理论值）
```

best-so-far 仍记**原始 cost**（不变，比较基准一致）。

### 2.4 核心修正：停止条件

```
不设 max_no_improve 或设大（≥20）
T_final = 0.01（允许低温细搜）
迭代预算兜底：max_levels = 40（防死循环）
每级 L = L_factor × n，L_factor = 10
```

n100：40 级 × 1000 = 40000 次扰动，预计 30-60s。n300 时间 ×3。

### 2.5 构造上界验证协议（UB 口径决定）

扫描 target_width：
```
for W_t in [ceil(√A), ceil(√A)+1, ..., UB_claim+5]:
    layout = FFD行堆叠(blocks, W_t)
    M = max(行宽填充, Σ行高)
    记录第一个 M ≤ W_t 且 M 最小的可行方形 → 真 UB
```
对比编程手 target=√A×1.05 的 M。**若真 UB > 建模手声称值，修正建模手区间。**

### 2.6 seed 有效性验证协议

```
对固定初始解（FFD），跑 10 seed：
    断言 10 结果不全相同（R6 修复验证）
    若全同 → SA 仍随机游走，回溯温度诊断
```

### 2.7 配对验证协议

```
pair_strips(n100) → 配对后 blocks
构造配对前后 FFD 初始解 M 对比
断言配对后 M 不增（配对无负收益）
```

## 五、一句话总结

**编程手的 90 条实验数据全部是"FFD 初始解 + 随机游走噪音"，不是 SA 优化结果。根因是 phase2 的 T1 被 mu=1e6 软惩罚主导（温度爆炸）导致接受率恒 1。独立实现按建模手 F12/F16-F18/F20 正确归一化 + 温度调度，先验证 UB 口径，再跑真 SA，最后 10-seed 交叉核实。**
