# 编程手 Q1 实施清单（附每步思路）

> 视角：编程手 | 2026-08-07 | 每阶段附【思路】= 为什么这么做
> 配套 `编程手.md`（结构/参数）+ `Q1建模数学化.md`（A/E 项）+ `Q1全解总览.md`（理论）

**总思路一句话**：Q1=最小面积装箱。B*-Tree 把"布局"编码成"树"，让 SA 能在离散解空间游走；轮廓结构让每次解码 O(n)（否则评估太慢搜不动）；几何构造+配对给 SA 好起点（否则 10 万次迭代可能浪费在烂区域）；三层下界给结果可信度（否则"最小面积"没依据）。**每步都为"又快、又准、又可信"三件事服务。**

## 阶段 1：B*-Tree 核心

**【思路】** 核心洞察：**树结构本身保证解码不重叠**。左子必在父右边（x=父x+父w）、右子必在父正上方（x=父x，y 取覆盖区间的 skyline 最高点）——递推下去任何子树都不相交，于是"重叠检查"这个装箱最贵的一环直接从每次评估里删掉。轮廓（skyline）结构是 y 坐标的加速器：放置时查覆盖区间的最大高度即可，均摊 O(n)，**不是 O(n²) 两两比较**——n300 下两者差 n 倍（**约 300 倍**），是能否跑完的关键。

- [ ] `Node` 结构：block_idx, left, right
- [ ] 树初始化：完全二叉树（或从构造布局建树）
- [ ] **解码**：前序遍历 + 轮廓结构，O(n)
  - 左子 x = 父x + 父w；右子 x = 父x
  - y = 覆盖 x 区间内 skyline 最大高
- [ ] **轮廓结构**：分段 (x0,x1,height)，放置后抬高+合并等高相邻段
- [ ] 自检：解码后外接框 W,H，无重叠（树结构保证）

## 阶段 2：扰动算子

**【思路】** SA 靠"微扰动+评估"探索邻域。三个算子覆盖不同邻域尺度：**Op1 旋转**（O(1)）只换朝向不改拓扑，是方形度微调的主手段——对 Q1 特别重要，因为朝向直接改块纵横比；**Op3 交换**（改标签、大变）负责重排结构；**Op2 删插**（O(n)）改变树的形状（父子关系），是拓扑重构的粗粒度探索。三者共同构成论文标准完备算子集，建议全用：**缺删插则树形状被冻结（只换标签），解空间受限**。概率分配 rotate 小、swap/move 大：**探索为主，微调为辅**——先找结构，后调朝向。

- [ ] Op1 旋转：随机块 w↔h（树不变），O(1)
- [ ] Op2 删插：删节点（叶子 O(1)/单孩子 O(1)/双孩子 O(h)）→ 插随机父节点，O(n)
- [ ] Op3 交换：随机两节点交换
- [ ] 概率分配：rotate 0.1 / swap 0.4 / move 0.5

## 阶段 3：Fast-SA

**【思路】** Fast-SA 三阶段 = **把时间花在最有效的阶段**。经典 SA 冷热同一节奏，开头浪费在"不该接受的劣解"、结尾浪费在"该接受的探索"。Fast-SA 高温先撒网防陷局部 → 伪贪心快速下沉 → 爬山跳出再细搜，实测 12-13.9× 提速。**公式自查（2026-08-07，PDF 原文核对）**：c 是分母乘法 `n·c` 非 `n^c`（"c 控制 T 多低"仅 n·c 有意义，且伪贪心需非零 T 接受少量劣解）；**T1 必须取 |lnP|——ln(0.9)<0，直接用 lnP 得负温度**；⟨Δcost⟩ 是当前温度的运行平均。**两个必须死守的纪律**：① 成本必须归一化（A_norm=试扰动均值），否则 ⟨Δcost⟩≥1，温度公式 Tn=T1·⟨Δcost⟩/n 失效，SA 退化成纯随机搜索；② 报告 **best_so_far** 而非末态——SA 末态是"正在搜索的位置"不是"最好解"。加固定种子×10 次：**SA 方差大（Cornell 课程实验统计：100 次中仅约 70% 胜过随机重启爬山），单次运行等于赌博**，多次取最优+报均值才是可信结果。

- [ ] 参数：P=0.9, k=7, c=100
- [ ] 温度：`T1=Δ_avg/|lnP|`（**ln P<0，取绝对值保 T>0**，P=0.9 → T1≈9.5·Δ_avg）；`Tn=T1·⟨Δcost⟩/(n·c)` (2≤n≤k)；`Tn=T1·⟨Δcost⟩/n` (n>k)
- [ ] ⟨Δcost⟩ = **当前温度**下新代价−旧代价的运行平均（非初始值）；归一化后 <1 保降温
- [ ] **归一化**：A_norm = SA 前试扰动 500 次平均（保 ⟨Δcost⟩<1）
- [ ] Metropolis 接受：Prob=min(1, e^(−ΔC/T))
- [ ] **best_so_far** 记录（min 面积；同面积取更方）——报告它，非末态
- [ ] 固定种子 × 10 次运行，取最优，报 mean±std

## 阶段 4：成本函数（3 目标开关）

**【思路】** 题设是**词典序**（面积优先，长宽比只在面积相同时生效）。三种目标：
- **加权** `A/Anorm+λ(R−1)²`：λ 必须小（0.05-0.1），否则牺牲面积换方形=违反主目标（陷阱T2）；
- **min-max** `max(W,H)/norm`：基于**定理**——面积近最优区（δ≤5%）内 min max(W,H) 与词典序等价（M=√(A·R) 固定 A 时单调于 R）。免权重调参，是主成本函数；
- **两阶段**：先面积后长宽比，数学最严谨，作对照。
三种都跑，对比验证等价性。R 定义必须 `max/min≥1`（陷阱T1，评阅口径）。

- [ ] 加权：`A/Anorm + λ(R−1)²`，λ=0.05-0.1
- [ ] min-max：`max(W,H)/norm`
- [ ] 两阶段：Phase1 面积 → Phase2 面积 ε 邻域(1%)内 min|R−1|
- [ ] **R = max(W,H)/min(W,H) ≥ 1**（口径统一）
- [ ] 死区% = (W·H − A_total)/(W·H) × 100

## 阶段 5：构造初解（开关）

**【思路】** SA 初值决定它从哪个区域开始搜——**烂初值把大量迭代浪费在差区域**。FFD 行堆叠是确定性构造：高降序、逐行填，总高=行高和，**保证可行**（这是它作为"构造上界"的价值）。天空线平坦贪心更进一步：放块选"让最高处增长最小"的位置，保持轮廓平 → 外接框接近矩形 → 接近方形。构造初解不是最终答案（实测死区 n100 8.5%、n200 9.3%、n300 5.6%），但给 SA 一个"已经不错"的起点去精修——**这就是"混合算法"：构造定骨架，SA 打磨**。

- [ ] FFD 行堆叠：按高降序，行宽 ≤ W，行高 = 行内最大高，总高 = 行高和
- [ ] 天空线平坦贪心（可选）：放块使 skyline 最高处增长最小
- [ ] 从构造布局建 B*-Tree → 替代随机树初始化

## 阶段 6：长条配对（开关）

**【思路】** n100 有 15 个长条块（纵横比≥2.5，最大 3.9）——**长条是破坏方形的主敌**。配对思路：把**一高瘦一矮宽**两块互补组合，并排/叠放使复合块的总宽≈总高（如高瘦块放矮宽块旁，总宽≈高瘦块高）。质量函数 q(i,j)=组合方形度−原方形度，只配有益的对。**配对=预处理，把最难塞的长条先变成好塞的近方块**，压缩解空间里对方形度破坏最大的分量。求最大权匹配用匈牙利算法 O(n³)，n300 秒级。开关控制便于实验隔离收益。

- [ ] 质量函数 q(i,j)：并排/叠放两组合取更方，q = 组合方形度 − 原方形度
- [ ] 配对图（仅 q>0 的边）→ 匈牙利最大权匹配
- [ ] 复合块参与 packing（或作独立算子）

## 阶段 7：验证

**【思路】** "最小面积"要让人信服，必须**证明它离理论界有多近**。下界：面积界 A_total、方形下界 ⌈√A⌉²（424/420/523）、固定宽下界 A/W。上界：FFD 构造保证可行 → 方形边长可行区间 [LB,UB] = n100 [424,443] 等（建模手已算）。**SA 结果必须落在这个区间内**——这是整套代码正确性的最终校验：结果在下界之下=代码 bug，在上界之上=还有优化空间。

- [ ] 下界：方形下界边长 ⌈√A⌉ = 424/420/523（方形面积下界 = 179776/176400/273529），面积界 A/W
- [ ] 构造上界 UB：FFD 方形可行边 = 443/440/538（已由建模手算出）
- [ ] **检查：SA 结果 ∈ [LB,UB]**（n100: [424,443] 等）
- [ ] 方形可行性探测：固定宽 424/420/523 跑 SA 最小高 H(W)，验证 > 424（预期）

## 阶段 8：实验（120 次/目标，×3 目标 = 360 次）

**【思路】** 单次运行不能回答问题"构造初解/配对到底有没有用"——**必须做对照实验**。全因子矩阵：4 组合（随机/构造 × 无/有配对）× 3 数据集 × 10 种子。10 个种子 = 统计稳定性（SA 方差大）。关键对比：**C0 vs C1 隔离初解增益、C0 vs C2 隔离配对增益**（n100 重点）。这组对比直接产出论文的核心表——证明每个创新点的增量价值，不是自说自话。

- [ ] 矩阵：4 组合（随机/构造初解 × 无/有配对）× 3 数据集 × 10 种子（=120 次/目标）
- [ ] 度量：A, R, 死区%, gap%=(A−LB)/LB, 时间, 收敛迭代数
- [ ] 关键对比：C0 vs C1（初解增益）；C0 vs C2（配对增益，n100 重点）
- [ ] 3 目标对比（加权/min-max/两阶段）

## 关键红线（违者返工）

**【思路】** 六条红线全是"错一个就全盘错/不可信"的坑，每条的机理：
1. 重叠用严格 `<`——贴边合法，`<=` 会把合法布局判死、错误收缩搜索空间（T5）
2. 只读 .blocks 的 block 行——Q1 无线网，读多引错（T12）
3. 成本归一化——⟨Δcost⟩≥1 → 温度公式失效 → SA 变随机搜索（T8）
4. 报 best_so_far——末态是"正在搜的位置"不是最优（T6）
5. 90° 旋转——题设限定，任意角违反且无法装箱（T9）
6. 种子复现——无种子 = 结果不可复现 = 交卷风险（T7）

1. 重叠判定用严格 `<`（**贴边合法**）
2. Q1 只读 .blocks 的 block 行（.nets/.pl 不碰）
3. 成本必须归一化（⟨Δcost⟩<1，否则温度公式失效）
4. 报告 best_so_far，不是末态
5. 只允许 90° 旋转（每块 2 朝向），禁止任意角
6. 固定种子可复现；不报单次运行结果
