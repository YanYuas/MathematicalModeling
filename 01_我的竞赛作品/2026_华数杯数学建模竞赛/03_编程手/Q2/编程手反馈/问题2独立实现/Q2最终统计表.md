## 3. 可行性验证

- M=max(W,H) ≤ S：三组全部通过（M 贴边，S−M ≤ 0.5）
- 死区 = (W·H − A)/W·H ≈ 12.7% < 理论 13.04%（Γ=0.15）
- best 只记可行解（红线 1）

## 4. 收敛与稳定性

- 贪心 best 改善：n100 27%（301k→220k）、n200 22%、n300 21%
- 第二轮更长迭代（25k→35k）仅改善 2% → 接近 B*-Tree 三算子能力饱和
- seed 敏感性：n200 各 seed 430k-452k（±5%），best-of-N 必要

## 5. 方法速览

```
Q1 方形解 443/432/533 → B*-Tree（严格可行）
→ 贪心可行下降：可行性硬门(M≤S) + 接受线长改善扰动
→ 两轮 best-of-N：n100 5seed×30k / n200 6seed×25-35k / n300 5seed×20-30k
```
