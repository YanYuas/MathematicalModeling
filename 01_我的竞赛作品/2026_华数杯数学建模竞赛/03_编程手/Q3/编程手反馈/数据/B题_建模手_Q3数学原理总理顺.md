## 一、第一性原理：问题到底是什么

### 1.1 词义解析（题设四个关键处）

- **"死区比例最小可以是多少"** → 求**存在性临界** Γ* = min{Γ : ∃可行布局}。主语是"存在"，不是"最优布局"；
- **"使得存在一个可行布局方案"** → 存在量化（∃），判定问题，非优化问题；
- **"见公式1"** → 口径锁定：Γ = (S²−A)/A（相对总面积），不是死区占比 (S²−A)/S²；
- **"更新问题2的总HPWL"** → 在 Γ* 轮廓下重跑 Q2 模型，是**优化层**。

**点透①**：题设把两个不同数学操作缝进一个问号——先求"存在性临界"（层A，判定），再求"该临界下最优线长"（层B，优化）。**层序不可颠倒**：Γ* 未定，HPWL 无意义的轮廓约束。这决定了 Q3 是两阶段结构，不是单目标。

### 1.2 为什么 NP-hard（复杂性根源）

- 矩形装箱 NP-hard；死区→0 ⟺ 无间隙平铺正方形 = 完美矩形问题，含 **Partition**（NP-complete）作特例 → **Q3 在死区→0 极限 NP-hard**；
- 含义：100-300 模块无多项式精确解；"可行性判定"本身只能启发式逼近（构造性判定，见§六 P1）；
- 论文复杂度小节素材：若 Q3 有多项式算法，则可判 Partition。

## 二、核心数学原理（逐条点透）

### 2.1 恒等式三问贯通（M²=A·R）

Q1 用 M²=A·R 做 min-max 目标；Q2 做固定轮廓判据；Q3 做**临界刻画**：

```
可行(Γ) ⟺ ∃布局: M ≤ √(A(1+Γ)) ⟺ ∃布局: R ≤ 1+Γ
```

**点透②**：恒等式把"死区面积约束"翻译成"长宽比约束"。死区比例 Γ ⟺ 长宽比盈余 R−1。这是全篇几何叙事的支柱——三问共享同一个几何事实，Q3 只是把它用在"临界"而非"目标/判据"。

### 2.2 闭式：Γ* = R* − 1（Q3 最核心公式）

设 R* = min{ R(L) : L 可行布局 }。则：
$$M^* = \sqrt{A\cdot R^*}, \qquad \Gamma^* = \frac{M^{*2}}{A} - 1 = R^* - 1$$

**点透③**：最小死区 = 最优可行布局的长宽比减 1。几何直觉：把布局"压得最方"的长宽比，超出 1 的部分就是必须牺牲的死区。**M* 不一定等于 Q1 解的 M**——Q1 是矩形面积最优（R=1.002 是巧合），Q3 要正方形边长最优，布局不同，M* ≤ Q1 的 M。

### 2.3 单调性与二分（为什么省掉全局搜索）

固定布局集，Γ 增大 → S 增大 → 约束放宽 → 可行集单调增大：
$$\text{可行}(\Gamma) \implies \text{可行}(\Gamma'),\ \forall \Gamma'>\Gamma$$
故可行集 = [Γ*, ∞)，**单调**。二分/收缩扫描即可，无需在 Γ 维上做全局优化。

**点透④**：这是 Q3 可解性的关键——存在性临界是"单参数单调边界"，不是"多峰优化"。方法上只需"判可行"子程序 + 二分。

### 2.4 下界族与数据特性（为什么下界不紧）

| 下界 | 值 (n100/n200/n300) | 紧度 |
|---|---|---|
| 面积 M≥√A | 423.68/419.16/522.66 | 几乎是唯一有效下界 |
| 最大模块 M≥max(w,h) | 67/48/48 | 极松（≪√A） |
| 整数效应 M≥⌈√A⌉ | 424/420/523 | 条件下界，非可行下界 |

**点透⑤**：下界不紧是**数据特性**——模块小而均匀，面积下界接近唯一约束。不能拿 ⌈√A⌉ 当 Γ*（424×424 几乎不可行）。Q3 交付值 = 构造可达值（FFD/贪心构造的最小可行），诚实分三档：下界方向 / 构造可达 / 参考趋势。

### 2.5 固定拓扑缩放限制（为什么必须改拓扑）

给定布局外接框 W0×H0，各向同性缩放 s 需 s·M0≤S → **s≤S/M0**。缩放不改变长宽比 R → **不突破 M0**。

**点透⑥**：直接拿 Q2 的 Γ=0.15 解缩放去压轮廓是错误捷径——M0 不变，Γ* 只能靠重打包（改拓扑）突破。这解释了 q1warm 收缩必须"重打包 + 硬门"，而非"缩放 + 检查"。也呼应 Q2 教训：超轮廓起点拉不回，起点必须本身可行。

## 三、目标与约束的分离（为什么两阶段）

### 3.1 二象性：网络视角 vs 容器视角

- **Q2（网络视角）**：块=节点、网=边，最小线长偏好块向终端**分散** → 包围盒变大；
- **Q3（容器视角）**：块=物品、容器最小化偏好块**聚拢** → 线长变差。

**两目标方向相反。** 联合优化 = 帕累托前沿（权衡曲线），单点最优不存在。

### 3.2 建模决策 H7：顺序化

题设明确要"最紧轮廓下的线长" → **层A 只判可行（不含线长），层B 在 Γ* 下优化线长**。

**点透⑦**：Q3 不能写"min 死区 × min 线长"的联合目标。两阶段分离不是简化，是**对准题设语义**——先锁死轮廓（存在性），再在锁死的轮廓内优化线长。这也天然给出创新图：死区-线长权衡曲线（Γ 从 Γ* 扫到 0.15，每点跑 Q2 引擎，量化压缩代价）。

## 四、方法设计（两层）

### 4.1 层A：可行性扫描（Q3 主算法）

```
起点: Q2 Γ=0.15 解（已可行）
链:   q1warm 收缩 —— 逐步减 S（步长1 或二分），每步用上一步可行布局 warm start
判:   FFD target=S 打包 + 硬门 M≤S + best-of-N 多run
收:   找最大不可行 S*−1 与最小可行 S* 边界
出:   Γ* = (S*²/A) − 1
```

**点透⑧（连续可行链 = 本方法灵魂）**：Q2 核心发现"可行起点稀缺"（只有 q1warm 唯一直接可行）。临界区（Γ≈Γ*）可行解更稀缺，冷启动判定基本不可信（搜索失败 vs 真不可行不可区分）。连续可行链把"存在性搜索"变成"**可行路径追踪**"——每步有已知可行布局过渡，搜索失败概率大降。"可行由起点保证"纪律从 Q2 的"单起点"升级为"沿 Γ 的起点序列"。

### 4.2 层B：Γ* 下更新 HPWL（复用 Q2 引擎）

```
输入: S* = √(A(1+Γ*))
过程: q1warm 起点 + 贪心可行下降（硬门）+ best-of-N —— 原样复用
输出: 总HPWL + 可视化（轮廓+终端+模块+信息卡）
```

**点透⑨**：层B 不是新算法，是 Q2 引擎换轮廓。引擎一致性验证：Γ*=0.15 时必须复现 Q2 结果（220k/431k/672k），保证"更新"是同一引擎同口径，可归因于轮廓收紧。

## 五、验证与诚实分层

| 档位 | 内容 | 能证明什么 |
|---|---|---|
| 构造可达值 | FFD+贪心构造的最小可行 Γ | ∃：找到解 |
| 面积下界 | Γ ≥ 0（M≥√A） | ∀：所有布局 M≥√A |
| 参考趋势 | n100 存在 436 布局（死区5.57%） | ∃ 更优存在，但需强搜索 |
| slicing DP（可选） | 切片布局精确最优 | M_slicing ≥ M*，验证最优近切片性 |

**点透⑩**：存在性 gap 不可闭合（无多项式判定）。∃ 构造证得、∀ 下界证得、中间无法填平。**不宣称"证明最小 Γ*"**——报"构造可达 Γ*"，附带下界与参考方向。这是对 P10 的正面对策，也是论文诚实叙事的锚。

## 九、一句话总结

**Q3 = 存在性临界（最小正方形装箱，Q1 方形对偶）＋ 该临界下的线长优化（Q2 复用）。一根恒等式 M²=A·R 把死区翻译成长宽比盈余（Γ*=R*−1），可行域单调可二分；方法灵魂是 q1warm 连续可行链（"可行由起点保证"的推广）；验证靠诚实分层（构造/下界/参考），陷阱根上三条（构造≠存在、同名异义、断言超证据）。建模手下一动作 = 给编程手 Q3 清单 + 权衡曲线/切片下界的实验设计。**
