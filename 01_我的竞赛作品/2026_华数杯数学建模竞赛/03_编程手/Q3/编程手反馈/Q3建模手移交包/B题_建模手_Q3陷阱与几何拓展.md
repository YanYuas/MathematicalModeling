## 一、陷阱深挖（重点，12条分三组）

### A组：判定系统陷阱（可行性判定本身会错）

**P1 构造性判定的系统偏置。** FFD/贪心判可行只回答"我能构造出解"，不回答"解存在但我构造不出"。两种错：
- 漏判（构造不出但存在）→ Γ* 偏高。保守方向，可接受，但要标"构造可达值"；
- **误报（构造出"看似可行"实则超轮廓的解）→ Γ* 偏低，虚假答案，不可接受。**
防：硬门严格验证 M≤S（不信任打包器自身宣称）+ best-of-N；输出永远带标签"构造可达 Γ"，不与下界混淆。

**P2 二分误收敛到噪声边界。** 启发式判定有噪声：同一 Γ 多次 run 有时可行有时不可行 → 二分收敛到"噪声边界"而非真边界。防：每点多 run 取多数；判定加 margin（M≤S−δ 才算可行，δ=1）；二分区间锁在 [√A, Q1解M] 内不越界。

**P3 临界区不可行 vs 搜索失败不可区分。** Γ 接近 Γ* 时，判定失败可能是"真不可行"也可能是"搜索没找到"。P4 与 P3 是同一陷阱的两面，关键在**连续可行链**（深度分析创新3）：从 Γ=0.15 解沿 Γ↓ 追踪，每步有可行起点，则搜索失败概率大降。若脱离连续链冷启动，临界区判定基本不可信。

**P4 长条朝向自由度爆炸。** 长条（AR≥2.5）是死区杀手（Q1 实证 n100 15 长条死区最差）。每个长条 2 朝向 → 2^15=32768 组合，贪心朝向选择局部次优。防：长条朝向作为 FFD 内层自由度，与 target 扫描耦合（不预设 AR≥2.5 横放，逐 target 重选）。

**P5 朝向可行性漏检。** 题设 90° 旋转是"允许"不是"必可"。临界区某模块两种朝向都放不进 S*×S* → 假可行。判可行函数必须含：每模块至少一朝向能放入轮廓。Q2 提过"不可旋转块预标定"，Q3 临界区更频繁触发，必须成硬校验。

### B组：口径与数字陷阱（错一次全篇废）

**P6 题设 Γ vs 死区占比。** 公式(1) 的 Γ=(S²−A)/A（相对总面积）；死区占比=(S²−A)/S²（相对轮廓）。Q2 的 0.15→13.04% 已埋一次，Q3 再错全篇作废。**全篇主口径 = 题设 Γ，死区占比辅列**。参考论文"死区 5.57%"是占比口径 → Γ=0.0589，直接比会错位。

**P7 整数 vs 连续 S。** 附件坐标/尺寸整数 → 布局外接框整数 → S 有效值离散（步长1）。若编程手连续扫描（步长0.01）得非整数 S，与整数坐标不符。防：S 步长 1，Γ* 报整数 S 对应值。

**P8 ⌈√A⌉ 不是 Γ*。** 整数效应给"若 424×424 可行则死区仅 275 单元（Γ=0.0015）"。但 424×424 几乎不可行（模块排不这么满）。**这是条件下界不是可行下界**——拿 ⌈√A⌉ 当 Γ* 是经典错误（T3 深化）。

**P9 更新 HPWL 的引擎一致性。** Γ* 下 Q2 引擎跑出 M>S*（硬门失效）→ 假可行。防：验收 M≤S* + 死区回算 = (S*²−A)/S*² 与理论值核对。

### C组：语义与因果陷阱

**P10 "存在性"的哲学边界。** 题设"存在一个可行布局"是存在量化。我们能证明"找到解"（∃构造）与"面积下界"（∀布局 M≥√A），中间 gap 无法闭合（无多项式算法）。防：诚实分层报告（构造可达/下界/参考趋势），**不宣称"证明了最小"**。

**P11 权衡曲线的因果误读。** Γ↓→HPWL↑ 可能部分是"搜索变难"而非"结构变差"。防：best-of-N 多 run 平均化搜索噪声；论文区分"搜索困难"与"结构代价"两个解释。

**P12 Q3 与 Q2 结果不可直接比。** Q2 HPWL 在 Γ=0.15，Q3 在 Γ*。数字差 = 轮廓效应 + 搜索效应混合。防：同引擎同 seed 隔离变量，只在"轮廓收紧"维度归因。

## 三、化归思路（5条，由主到次）

1. **Q3 → Q1 对偶（主化归）**：正方形 = R=1 约束的 Q1。Q1 自由矩形，Q3 固定 R=1。层A 可视为 Q1 在"R=1 流形"上求最小。深度分析创新1 即此化归的叙事化。

2. **Q3 → 一维装箱序列化（编程核心）**：判可行 ⟺ 存在布局 W≤S 且 H≤S。用 FFD target_width=S 打包，得 (W_ffd, H_ffd)，可行充分条件 W_ffd≤S ∧ H_ffd≤S。这把二维判定化成一维 FFD 的两次检查（x 排满、y 累积）。**Q1 编程手的 FFD target 扫描直接复用**，只加 H 方向对称检查。

3. **Q3 → Partition / 2D bin packing（复杂度论证）**：死区→0 ⟺ 完美矩形平铺判定（含 Partition 作为特例，NP-complete）。故 Q3 在死区→0 极限是 NP-hard。论文复杂度小节可用："若 Q3 有多项式算法，则可判 Partition"。

4. **Q3 → slicing DP（验证工具）**：仅考虑切片布局（可递归二分）时，最小正方形边长可由两半最优拼合递归求，**精确**。M_slicing ≥ M*（切片布局 ⊂ 全体布局）。若 M_slicing 接近构造值 → 最优近切片；差距大 → 非切片布局必要。这是**下界验证**工具，不是主算法。

5. **Q3 → 固定拓扑的缩放分析（理论视角）**：给定布局 L 外接框 W0×H0，各向同性缩放 s 需 s·max(W0,H0)≤S → s≤S/M0。**缩放不改变长宽比 → 不突破 M0**。故突破 M0（443→436）必须改拓扑。这解释了 q1warm 收缩为何要重打包而非纯缩放，也解释了为何"直接用 Q2 解缩放"是错误捷径。

## 四、图论视角（4工具 + 1二象性）

| 工具 | 作用 | 在Q3的角色 |
|---|---|---|
| 接触图/对偶图 | 布局邻接结构，B*-Tree 是支撑树 | 解释"拓扑固定→缩放受限"（化归5） |
| 水平条带下界 | 穿过任一水平线的模块宽和 ≤ M | 布局相关下界，可对给定布局数值化 max_c g(c)，验证紧度 |
| slicing DP | 切片布局精确最优 | 保守下界对照（化归4） |
| Partition 归约 | 死区→0 特例 NP-complete | 复杂度论证（化归3） |

**关键二象性（论文亮点素材）**：Q2 是**网络视角**（网=边，块=节点，希望边短 → 块分散）；Q3 是**容器视角**（块=物品，希望容器小 → 块聚拢）。两目标方向相反，权衡曲线（深度分析创新4）正是此二象性的量化。一张图同时呈现两个视角的张力。

**诚实结论**：图论在 Q3 提供下界/验证/复杂度论证工具，不直接给最优算法。最有价值的是 slicing DP（对照）+ 接触图（缩放限制解释）+ Partition 化归（NP-hard 论证）。别把图论硬包装成"求解方法"。

## 五、射影几何的判断（诚实排除 + 真连接）

**结论：Q3 装箱问题无实质射影结构，不引入射影几何。**

理由：
- 射影几何（中心投影/交比/无穷远点）处理**共线/交比/对偶曲线**等结构；
- Q3 是**组合几何**（装箱/镶嵌/覆盖/分离），核心是"无重叠"的离散组合约束，非射影不变性；
- 投影几何唯一真实角色在 **Q2 线长**（HPWL = 正交投影和）。Q3 无投影度量。

**若论文硬挂"射影几何"，是硬伤。** 可用的是"对偶**思想**"（非射影理论）：
- Q1↔Q3 对偶（矩形↔正方形约束）；
- W↔H 旋转对偶（布局绕 45° 的对称，90°旋转不变性）。
这两个是"对偶视角"，不是"射影几何"，措辞要精确。

**一个值得提的真几何连接：完美矩形（perfect rectangle）与平铺。** 死区=0 ⟺ 模块集合无间隙平铺成正方形 ⟺ 完美矩形存在（经典图论问题，Smith's diagram / 电流网络构造）。可作**极限情形**讨论：Γ*=0 当且仅当 A 为可平铺的平方结构。对 n100/200/300 不现实（A 非平方、模块数大），但给"死区最小能压到哪"以理论锚点。叙事一句话："死区趋于 0 等价于完美矩形平铺问题（NP-complete），这正是 Q3 无平凡下界的原因。"

## 六、几何极端情形与长条主导（数据特性洞察）

1. **长条主导死区（关键几何洞察）**：Q1 实证死区与长条数正相关（n100 15 长条最差 8.53%，n300 死区最紧 3.66% 模块小而灵活）。几何机制：长条 AR 大，塞进方形轮廓的剩余空隙难（横竖都占长边）。**Q3 Γ* 的差异（n100 0.093 > n300 0.040）主要由长条模块驱动，非规模。**
2. **死区排序预测**：Γ*_n100 > Γ*_n200 > Γ*_n300（与 Q1 死区 8.33/5.86/3.66% 同序）。可作 sanity check。
3. **最大模块 vs 面积下界**：max边长 67/48/48 ≪ √A，故 M≥max_i 不紧，下界几乎就是面积下界——**Q3 下界不紧是数据特性（均匀小模块），非方法缺陷**，诚实报告。

- 挂"射影几何"标签（§五）

- 口径混用（P6）
- ⌈√A⌉ 当 Γ*（P8）
- 图论当求解方法（§四诚实结论）

## 八、一句话总结

**Q3 陷阱集中在"判定系统"（构造 vs 存在偏置、噪声二分、临界区搜索失败、长条朝向、朝向可行性）与"口径"（题设Γ vs 死区占比、整数 vs 连续、⌈√A⌉ 误用）。化归主链 = Q3→Q1 对偶 + 一维 FFD 序列化；图论给下界/验证/复杂度工具不给出算法；射影几何应诚实排除（投影是 Q2 的工具）；唯一真几何连接是完美矩形平铺（死区→0 的 NP-complete 极限）与长条主导死区的数据洞察。**
