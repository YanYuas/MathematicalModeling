## 阶段 1：判可行子程序（Q3 核心模块）

**【思路】** 判"存在布局 W≤S ∧ H≤S"。FFD target_width=S 打包：行内 W≤S 自动保证，判可行 ⟺ 打包高 H≤S。**已验证**：h_desc 行堆叠 + 长条旋转能复现 Q1 解（443×442/432×432/533×532），skyline_h 在部分 case 更紧（n300）。两策略都留，best-of-N。

- [ ] `feas_s(S, strategy)`: FFD h_desc 行堆叠 / skyline_h（h 降序），返回 (bool, (W,H))
- [ ] 长条旋转预处理：AR≥2.5 长边水平（Q1 结论，**n100/n300 必需**——不旋连 Q1M 都不可行）
- [ ] 硬门严格：W≤S∧H≤S（**不信任打包器自称**，独立算 W/H）
- [ ] **口径**：S 整数步进（附件坐标/尺寸整数）；判可行含"每模块至少一朝向能放入"检查（临界区 P5）

## 阶段 2：可行性扫描求 Γ*（Q3 主算法）

**【思路】** 可行域对 Γ 单调（Γ↑→S↑→约束放宽）→ 二分。从 Q1 解 M 往下压（已验证构造上界 = Q1M）。**本窗口已轻量验证**（m3_scan.py，省重跑确认阶段）：
- 构造最小可行 S = Q1 解 M = **443/432/533** → Γ* = **0.0933/0.0622/0.0400**（死区占比 8.53%/5.86%/3.84%）
- 死区排序 n100>n200>n300 验证 ✓
- **临界 gap（S=Q1M−1）**：n100 超1（442×443）/ n200 超1（431×432）/ n300 超8-13 → 突破机会在 n100/n200

- [ ] 二分 S ∈ [⌈√A⌉, Q1解M]：n100 [424,443] / n200 [420,432] / n300 [523,533]
- [ ] 每点多策略（h_desc/skyline_h）× 多 run 多数判（P2 噪声防）
- [ ] 二分 margin δ=1（M≤S−δ 才判可行，防误报 P1）
- [ ] 输出：最大不可行 S*−1 / 最小可行 S* → Γ* = (S*²/A)−1
- [ ] **sanity**：S=Q1M 必须可行（复现 443/432/533），S=⌈√A⌉ 必须不可行

## 阶段 4：层B —— Γ* 下更新 HPWL（复用 Q2 贪心引擎，零改动）

**【思路】** S* = √(A(1+Γ*))。把 Q2 的 `greedy_solve` 原样复用，只换轮廓参数（q1warm 起点 target 改 S*）。**引擎一致性验证**：Γ*=0.15 时必须复现 Q2 结果（220,252/430,628/672,474）——否则"更新"无意义。

- [ ] S* 下 q1warm 构造起点（target=S*）
- [ ] `greedy_solve` 贪心可行下降（硬门 M≤S*）+ best-of-N 多 seed
- [ ] **验收**：M≤S* 严格；死区回算 = (S*²−A)/S*² 与理论核对

## 关键红线（违者返工）

1. **禁软惩罚/自适应λ/双引擎/SA主搜索**（Q1Q2 实践否决，全删）
2. **best 只记可行**（M≤S）；判可行严格硬门，不信任打包器自称
3. **口径**：题设 Γ=(S²−A)/A（相对面积）；死区占比=(S²−A)/S²（相对轮廓）。**主口径=题设Γ，报告两列**
4. **S 整数步进**；二分 margin δ=1
5. **更新 HPWL 用 S*=√(A(1+Γ*))**，不是 Q1 解
6. **层序**：先层A 定 Γ*，再层B 更新 HPWL，不混
7. **诚实标签**：构造 Γ* 报"构造可达"，不宣称证明最小（存在性 gap 不可闭合）
8. 种子复现（Q1/Q2 纪律延续）
