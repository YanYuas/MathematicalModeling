## 1. 数据解析（bookshelf 格式）

## 2. 核心数据结构：轮廓（Contour）

packing 时维护 y 坐标分段轮廓，均摊 O(n)。不要用 O(n²) 两两比较。

**实现思路**：一个列表存轮廓段 [(x_start, x_end, y_top)]，按 x 排序、相邻段合并。放置模块时：找到模块 x 区间覆盖的轮廓段，其最大 y 即模块底；放完更新轮廓（覆盖段抬高为 y+h，合并邻段）。

**放置顺序**：按 B*-Tree 前序遍历。根在 (0,0)。左孩子 x = 父x + 父w（查轮廓得 y）；右孩子 x = 父x。

## 4. 扰动算子

```python
def perturb(root, blocks):
    r = random.random()
    if r < p_rotate:   Op1 旋转：随机模块 w↔h（树不变，O(1)）
    elif r < p_swap:   Op3 交换：随机两节点交换（拓扑可大变）
    else:              Op2 移动：删一节点（叶子O(1)/单孩子O(1)/双孩子O(h)）再插入随机父节点左右
```

概率分配建议（可调）：旋转 0.1、交换 0.4、移动 0.5（移动改变拓扑，探索力强）。

## 6. HPWL 计算

```python
def hpwl(net, blocks, terminals):
    xs, ys = [], []
    for pin in net.pins:
        if is_terminal: xs.append(t.x); ys.append(t.y)
        else: b = blocks[idx]; xs.append(b.x + b.w/2); ys.append(b.y + b.h/2)
    return (max(xs)-min(xs)) + (max(ys)-min(ys))
```

**加速**：2 引脚网占 72-89%（n100 89%），直接曼哈顿：|Δx|+|Δy|。多引脚网才开包围盒。总 HPWL = Σ。

## 8. Q3 二分搜索

```python
lo, hi = 0.02, 0.15          # 死区比例区间
while hi - lo > 0.001:
    mid = (lo + hi) / 2
    side = sqrt(A_total * (1 + mid))
    if feasible(side): hi = mid     # 死区越小越好
    else: lo = mid
# feasible(): 该轮廓下跑 N 次 SA，多数次找到可行解 → True
```

注意每个二分点都多次运行取多数，防 SA 随机性误判。

## 9. Q4 L/T 型扩展

- L 型拆 2 子块、T 型拆 3 子块，子块间加**邻接约束**（坐标差判定：abut 必须严格相接）
- 扰动后检查：子块邻接失效 → 惩罚/丢弃
- **可行性条件**（Wu & Chang）：部分 B*-Tree 对 rectilinear 块无法生成可行布局 → 解空间收缩，无效扰动直接拒绝
- T 型三子块排列有限（8 个可行），可预生成合法排列枚举
