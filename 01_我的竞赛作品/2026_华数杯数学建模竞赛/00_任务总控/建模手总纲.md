## 1. 问题重述与形式化

### 1.1 基本定义

给定 n 个矩形硬模块 B={b₁,…,bₙ}，模块 bᵢ 宽 wᵢ、高 hᵢ、面积 Aᵢ=wᵢhᵢ，允许 90° 旋转。给定 m 个终端（固定坐标，只进线网）。给定线网集合 N，每网连接若干引脚，引脚位于模块几何中心。

布图规划 = 分配每个模块左下角坐标 (xᵢ,yᵢ) 与朝向（0°/90°），使：

```
约束1（不重叠）：任意 i≠j，矩形(xᵢ,yᵢ,wᵢ,hᵢ) 与 (xⱼ,yⱼ,wⱼ,hⱼ) 内部不相交
约束2（不超界）：0 ≤ xᵢ，xᵢ+wᵢ ≤ W*；0 ≤ yᵢ，yᵢ+hᵢ ≤ H*
约束3（朝向）：硬模块可旋转90°，旋转后仍满足约束1/2
```

### 1.2 目标函数

- **Q1**：芯片轮廓面积 A = W·H 最小；面积相同时 |R−1| 最小（R=H/W 为长宽比）
- **Q2/Q3**：总 HPWL 最小。线网 N_k 的 HPWL = 该网所有引脚外接轴对齐矩形半周长
  ```
  HPWL(N_k) = (max_j x_j − min_j x_j) + (max_j y_j − min_j y_j)
  2引脚网特例：HPWL = |x_a−x_b| + |y_a−y_b| （曼哈顿距离）
  总HPWL = Σ_k HPWL(N_k)
  ```
- **Q4**：L/T 型模块（各拆为 2/3 个矩形子块）包络面积最小

### 1.3 轮廓与死区

正方形固定轮廓边长：`W* = H* = √(A_total × (1 + Γ))`，Γ=死区比例，A_total=Σ模块面积。

- Q2：Γ=0.15 → 边长 454.3 / 449.5 / 560.5（n100/n200/n300，已实证）
- Q3：求最小 Γ 使得存在可行布局（死区 <5-8% 时可行布局可能不存在，见 §4）

### 1.4 符号表

| 符号 | 含义 |
|---|---|
| B | 模块集合，\|B\|=n |
| wᵢ, hᵢ, Aᵢ | 模块宽/高/面积 |
| (xᵢ,yᵢ) | 模块左下角坐标 |
| W, H, R | 布图外接框宽/高/长宽比 |

## 2. 模型框架：B*-Tree 表示 + Fast-SA

### 2.1 B*-Tree 表示（参考文献[2]机制，建模依据）

**表示**：有序二叉树，根=左下角模块（坐标原点）。左孩子=右侧相邻的最低未访问模块（x = 父x+w）；右孩子=正上方同x坐标模块。

**核心性质**：
1. 合法"admissible placement"（无模块能再左移/下移）与 B*-Tree **一一对应** → 解空间无冗余
2. 解码 O(n)：x 坐标一次前序遍历；y 坐标用轮廓数据结构均摊常数
3. 解空间 O(n!·2^(2n)/n^1.5)，远小于序列对 (n!)²

**建模价值**：把连续布局问题转化为离散树编码问题，使模拟退火可搜索。每次扰动+评估 O(n)。

### 2.2 成本函数

- 面积+线长（Q1 用面积，Q2 用线长）：
  ```
  Cost = α·(A/A_norm) + (1−α)·(W/W_norm)
  ```
  归一化分母 = SA 前试扰动 n 次的平均面积/线长，保证 ⟨Δcost⟩<1，温度公式自洽。

- **固定轮廓（Q2/Q3）关键**：加纵横比惩罚
  ```
  Φ(F) = α·A + β·W + (1−α−β)·(R − R*)²
  ```
  轮廓 H* = √((1+Γ)·A_total·R*)，W* = √((1+Γ)·A_total/R*)。Q2 正方形 R*=1。

- **自适应 α（论文100%成功率机制）**：
  ```
  α = α_base + (1−α_base)·(n_feasible / n)
  ```
  α_base=0.5，n=最近 500 个解，n_feasible=其中可行解数。可行解越多 → 纵横比惩罚权重 (1−α) 越小 → 搜索转向线长/面积优化。机制：避免"一找到首个可行解就困在局部"（惩罚权重过大）或"死活不满足轮廓"（惩罚权重过小）两个极端。

### 2.3 Fast-SA 三阶段退火

| 阶段 | 行为 | 目的 |
|---|---|---|
| 1 高温随机 | 接受概率→1 | 避免初陷局部最优 |
| 2 伪贪心局部（k次, c=100） | 温度→0，几乎只接受改进 | 快速到局部最优 |
| 3 爬山 | 温度回升再缓降 | 跳出局部极小，提高解质量 |

温度更新：
```
T₁ = Δ_avg / ln P          （P=初始接受概率≈0.9，Δ_avg=平均上涨代价）
Tₙ = T₁·⟨Δcost⟩/(n·c)      （2≤n≤k，c 大 → T→0 实现伪贪心）
Tₙ = T₁·⟨Δcost⟩/n          （n>k，爬山阶段缓降）
```

接受准则：`Prob = min{1, e^(−ΔC/T)}`（Metropolis）。

### 2.4 扰动算子

- **Op1 旋转**（O(1)）：交换模块宽高，树结构不变
- **Op2 移动=删除+插入**（O(n)）：删节点再插到别处，改树拓扑
- **Op3 交换**：交换两节点
- **Op4 软模块缩放**（Q4 才可能用）

## 3. 各问建模方案

### 3.1 Q1 — 面积最小化（无轮廓无线网）

```
模型：min A，tie-break |R−1| 最小
成本：Cost = A/A_norm + λ·(R−1)²，λ 取小值（如 0.1，仅作平局指标）
算子：Op1/Op2/Op3，无 Op4
终止：SA 收敛（温度低）后取记录最优面积对应的布图
```

**输出**：三组芯片最小轮廓面积、长宽比 R=H/W、布图可视化。对照参考论文死区水平（目标 ≤2-5%）。

### 3.2 Q2 — 固定轮廓 + HPWL 最小

```
模型：min 总HPWL
       s.t. 模块不重叠、全在 [0,W*]×[0,H*] 内、90°旋转合法（W*=H*=√(A_total×1.15)）
成本：Φ = α·A + β·W + (1−α−β)·(R−1)²，自适应 α
预标定：只能单朝向进轮廓的模块锁定朝向（SA 前）
```

**关键点**：
- 不可旋转块预标定——死区 15% 下部分模块只有一种朝向放得进轮廓
- 自适应 α 保证成功率，全程记录最小 HPWL 布图（非末态）
- 对标：参考论文 Table IV（成功率 100%）、Table V（线长）

### 3.3 Q3 — 最小死区比例

```
模型：求 min Γ 使 Q2 模型存在可行布局
算法：对 Γ 做二分搜索（初区间 [0.02, 0.15] 或 [0.05, 0.15]）
      每个 Γ：跑 Q2 的 SA（多次运行取多数判可行），输出可行性
      收敛到最小可行 Γ
```

**可行性判据**：死区 <5-8% 时可行布局可能不存在（Adya & Markov 实证，见 §4）。预期答案落 5-10% 区间。

### 3.4 Q4 — L/T 型模块

**表示扩展**：L 型拆 2 个矩形子块、T 型拆 3 个矩形子块，加**邻接(abutment)约束**（子块必须相邻，否则表示非法）。

**理论依据**（Wu & Chang, TODAES 2003）：B*-Tree 处理 rectilinear 块需**可行性条件**——存在无法从给定 B*-Tree 生成可行布局的情形，须缩小解空间。T 型三子块的可行排列恒为 8 个（非 (k!)²=36）。

**两条路线**：
1. B*-Tree 扩展 + 可行性条件 + 邻接约束
2. Corner Block List (CBL) 扩展（Ma et al. 2006），专门处理 L/T 型 + abutment

**模型验证**：4 个给定模块（图3），包络面积最小，输出最优摆放示意图+最小面积。

## 4. 可行性分析（Q3 理论边界，论文"问题分析"素材）

**固定轮廓可行性与死区/宽高比关系**（Adya & Markov 2003 奠基结论）：
- 成功率强依赖相对空白量与目标宽高比；偏差显著恶化线长与成功率
- GSRC 实测阈值：

| 空白量 | 成功率表现 |
|---|---|
| 15%/10% | B*-Tree+自适应α = **100%** |
| 8% | LFF 法 ≈100%（AR=1-4） |
| 6% | 骤降（n100: AR=1-4 下 54/24/46/30%） |
| <5% | 仅 PolarBear 等专门工具稳定出解 |
| 1% | 需惩罚函数（电压岛专用 94%） |

**建模意义**：(1) 证明 Q3 需二分逼近而非线性搜索；(2) 多次运行取多数判可行性；(3) 死区下界是组合性质，不受工艺更新影响。

## 5. 算法复杂度论证（论文"模型评价"素材）

- 矩形布图规划 **NP-hard**（Hakimi 1988 由划分问题归约）
- 给定 B*-Tree 后 packing **O(n)** 摊还（轮廓结构）→ 单次扰动评估 O(n)
- SA 总复杂度 O(迭代数 × n)；n100-n300 分钟级可行
- 精确算法仅适用 <50 模块（MCNC 5 例中 3 例可证最优）→ 本规模必须启发式

## 6. 建模假设清单（论文"模型假设"节素材）

1. 模块视为刚体矩形，不考虑物理/电气约束（简化）
2. 引脚位于模块几何中心（题设给定）
3. 终端固定，不参与面积与重叠约束（题设给定）
4. HPWL 作为线长度量（题设给定；2引脚主导下低估失真小）
5. 死区比例 Γ 定义见公式(1)（题设给定）
6. 90° 旋转为唯一允许朝向变换（题设给定）
7. SA 随机性：固定种子 + 多次运行取最优，结果可复现
