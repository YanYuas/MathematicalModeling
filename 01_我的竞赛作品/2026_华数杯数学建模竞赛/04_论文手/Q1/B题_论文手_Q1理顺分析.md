## 〇、理顺总判据

盖住正文任一公式/结论，评阅应能从上下文推出它为什么出现。推不出 = 没理顺。

**操作检查**：正稿每个小节先问一句"这一段回答评阅的哪个为什么？"，答不出 = 段落要重写。

## 一、Q1 叙述主线：研究顺序 ≠ 论文叙述顺序

```
研究顺序                    论文叙述顺序（评阅理解顺序）
问题本质                      ① 问题分析：目标结构（词典序锚）
  → 表示层                   ② 数据预处理：对象数学化
  → 目标层                   ③ 模型表示：B*-Tree 完备性
  → 算法层                   ④ 目标函数：min-max 动机链
  → 验证层                   ⑤ 算法：组件×痛点
                             ⑥ 下界验证：可信度

                             ⑧ 假设与局限：诚实收尾
```

**核心**：目标结构是序言的锚；每个环节回答一个"为什么"。

## 二、每环节"理清楚 + 可下笔"蓝本

### 环节① 问题分析：目标结构先定

**讲清楚**：词典序（面积第一序键，长宽比只在面积相同时生效），不是加权。

**可下笔段落模板**：
> 问题1 的优化目标为**词典序双目标**：主目标为芯片轮廓面积最小，副目标为轮廓面积相同时长宽比趋近 1。所谓"面积相同的情况下"是副目标生效的前提条件，故不能将两目标简单加权求和——加权目标 λ·(R−1)² 权重过大将牺牲面积换取方形，违反题设的面积优先原则。

**关键词**：词典序 / 第一序键 / 前提条件 / 不能加权。

### 环节② 数据预处理：对象数学化

**讲清楚**：.blocks → 数学对象，带校验；Q1 不读 .nets/.pl。

**可下笔段落模板**：
> 附件 .blocks 文件以 4 顶点坐标描述每个矩形模块，经解析提取宽 wᵢ、高 hᵢ 与面积 Aᵢ，朝向候选为 {原朝向, 90° 旋转}。三组芯片模块总面积经校验为 179501 / 175696 / 273170，与 GSRC 标准基准一致，数据正确性得到确认。由于问题1 不涉及线网连接关系，.nets 与 .pl 文件不参与本问题建模。

**关键词**：解析 / 校验 / GSRC 一致 / 不参与。

### 环节③ 模型表示：B*-Tree 完备性

**讲清楚**：为什么 B*-Tree、为什么无损失、为什么快。三问缺一评阅必问。

**可下笔段落模板**：
> 采用 B\*-Tree 编码 admissible（无可再向左或向下移动的模块）布局：任一合法布局可经反复"左下压实"化为 admissible 布局且外接框不增大，故最优解必存在于 admissible 布局集合中，搜索无损。B\*-Tree 与 admissible 布局一一对应（无冗余编码），左孩子表示右侧相邻模块（x = 父x + w）、右孩子表示正上方模块（x = 父x，y 取轮廓最高点），解码采用轮廓结构整体线性时间 O(n)，且树结构天然保证解码结果不重叠，消除了装箱问题中最困难的重叠检查。相较 Sequence Pair（解空间 (n!)²、解码 O(n²)），B\*-Tree 解空间更小、解码更快、无冗余。

**关键词**：压缩定理 / 一一对应 / 天然免重叠 / 相对 SP 对比（一句带过）。

### 环节④ 目标函数：min-max 动机链（最易讲乱，优先理顺）

**讲清楚**，顺序必须固定：动机 → 恒等式 → **反例（不能省）** → 面积约束 → 命题。

**可下笔段落模板**（四段）：
> **动机**：词典序双目标若直接加权存在三弊——权重 λ 无客观依据、面积（长度²）与长宽比（无量纲）量纲混乱、λ 失衡毁主目标。需要单量纲、免权重、几何直观的目标表达。
>
> **恒等式**：记 M=max(W,H)、m=min(W,H)，则 A=W·H、R=M/m，恒有 M²=M·m·(M/m)=A·R，即 M=√(A·R)。固定面积时 M 单调于 R，故 min M 同时驱动"面积更小"与"长宽比趋近 1"两个方向，单一量纲。
>
> **诚实边界（反例）**：min-max 与词典序一般情形**不等价**。设布局 X: W=100,H=100（A=10000,M=100,R=1），布局 Y: W=101,H=99（A=9999,M=101,R≈1.02），题设取面积更小的 Y，而无约束 min-max 取 M 更小的 X——两者冲突。故须附加面积约束封死偏差。
>
> **约束与命题**：附加面积近优约束 A ≤ A_opt(1+ε)（ε=1%），约束内 M 单调于 R，min-max 解即为面积近优邻域内长宽比最小者，与题设词典序**严格一致**（命题 1）。ε 作为可调参数，用于灵敏度分析。

**写作红线**：只写"面积约束下严格一致"，**不写"min-max 等价于词典序"**。

### 环节⑤ 算法：组件×痛点

**讲清楚**：每个组件回应一个痛点（表格一次讲清），不堆技术。

**可下笔表格 + 主动取舍句**：
| 组件 | 痛点 | 方案 |
|---|---|---|
| 模拟退火 | NP-hard 无精确解 | Metropolis 允许爬山跳局部，参考论文 GSRC 验证 |
| Fast-SA | 经典 SA 冷热同一节奏 | 高温撒网→伪贪心下沉→爬山细搜，提速 12× |
| 构造初解 | 烂初值浪费迭代 | FFD 行堆叠，确定性保证可行（死区 8-9%） |
| 长条配对 | n100 长条破坏方形度 | 纵横比互补配对为近方块，最大权匹配 |

> 需要指出的是，构造初解保证可行但解较松（死区 8-9%），SA 在其上精修至 2-5%；两者互补而非替代。这一取舍是刻意的：确定性构造定骨架，随机搜索打磨细节。

**关键词**：互补而非替代（学公交"主动暴露取舍"）。

### 环节⑥ 下界与验证：可信度

**讲清楚**：下界报族 + 下界≠可达 + [LB,UB] 结果居中。

**可下笔段落模板**：
> 为量化结果质量，建立三层下界：面积下界 A≥A_total、方形下界 A≥⌈√A⌉²、固定宽下界 H(W)≥max(A_total/W, 最大块高)，并给出 FFD 构造性可行上界。三组方形边长可行区间为 [424,443]、[420,440]、[523,538]。需指出，方形下界 ⌈√A⌉（如 n100 的 424²）对应近乎完美平铺（死区 0.4%），受矩形平铺组合约束实际几乎不可达，故下界仅作为质量基准而非可达目标。本文结果落于区间内、gap=(A−A_LB)/A_LB=X%，验证了启发式解的质量。

**关键词**：下界族 / 下界≠可达 / gap 必报。

### 环节⑦ 结果呈现：对标与解释

**可下笔**：主表（面积/W×H/R/死区/gap/时间）+ 三组布图 + 下界对标表 + 排序按"先面积、同面积内 R"（与题设一致）。

### 环节⑧ 假设与局限：主动声明

**可下笔段落模板**（模型假设小节，每条一句 + 边界）：
> **假设 1（轴对齐）**：模块边平行于轮廓边，仅允许 90° 旋转——题设限定，任意角装箱为不同问题。**假设 2（刚性）**：模块为硬块，尺寸固定。**假设 3（无连接）**：问题1 不涉及线网，Terminal 无连接关系且尺寸被附件省略，故不参与面积与重叠约束，轮廓取纯模块外接矩形。**假设 4（死区口径）**：死区比例以 (W·H−A_total)/(W·H) 计。

**关键词**：每条假设给"若不成立"边界，是评阅找严谨性的第一眼。

## 五、从理顺到下笔的操作路径

1. **按环节②③④⑥⑧ 重排正稿**（①⑤⑦ 已基本就位）；
2. **优先理顺环节④**（min-max 动机链）：用本节四段模板替换正稿当前目标函数段；
3. **补环节⑧ 假设小节**（正稿缺）：用假设模板直接插入；
4. **补环节⑥ 下界≠可达句**：正稿"预期死区"段后加一句平铺约束说明；
5. **对照质疑排查表逐条打勾**，漏答的补句子；
6. 数字（gap/死区/R）等编程手实验回填。

## 六、一句话总结

**Q1 论文理顺 = 让每个环节回答评阅的一个"为什么"，且给得出可直接下笔的句子**。锚（词典序）→表示（完备性）→目标（反例+约束）→算法（组件×痛点）→可信（下界族+gap）→诚实（假设+局限）。公交国一的"顺着读零障碍"由此达成。
