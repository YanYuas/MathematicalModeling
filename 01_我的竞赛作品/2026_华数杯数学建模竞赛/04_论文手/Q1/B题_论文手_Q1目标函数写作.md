## 5. 目标函数构建

### 5.1 问题的目标结构（动机起点）

题设对目标的表述是："使芯片轮廓面积最小；在轮廓的面积相同的情况下，其长宽比越接近 1 则结果越好。"

这一表述蕴含三层要求：

**(1) 词典序结构。** "面积相同的情况下"是副目标生效的**前提条件**——即面积最小是**主目标**，长宽比趋近 1 是**副目标**，二者构成词典序（lexicographic）而非简单的加权。任何在面积未达到最优时就追求更方布局的做法，都违反了题设。

**(2) 副目标的邻域性质。** 由于搜索的随机性与离散性，优化算法不可能严格达到"面积完全相同"的多个解；"面积相同"必须操作化为"面积落入最优值的某一邻域"。这引出了 ε 邻域的概念（见 5.4）。

**(3) 双目标的量纲差异。** 面积（长度²）与长宽比（无量纲）量纲不同，若直接加权，需要额外引入权重并归一化，而权重本身难以客观确定。

上述三点共同指向一个建模需求：**构造一个单量纲、免权重、且与词典序结构相容的优化目标**。这是本文引入 min-max 目标的出发点。

### 5.2 min-max 目标的引入与几何直觉

定义目标函数：

```
Φ = max(W, H)
```

其中 W、H 为布图外接框的宽与高。min-max 目标即最小化外接框的较长边。

**几何直觉**（动机的核心）：
- 等面积的所有矩形中，**正方形的长边最小**——长边小 ⟹ 布局越接近方形 ⟹ 长宽比接近 1；
- 同时，外接框面积 A = W·H ≤ max(W,H)² = Φ²，即 **Φ 越小，面积的上界越小**。

因此 min-max 目标天然地同时施加"压面积"与"促方形"两个方向的力，且**不需要任何权重**——这是它在几何上最吸引人的性质。

**数学结构**（严格刻画）：记 M = max(W,H)、m = min(W,H)，则 A = W·H = M·m、R = M/m，故

```
M² = (M·m)·(M/m) = A·R，  即  M = √(A·R)
```

此恒等式揭示了 min-max 目标与词典序双目标的精确关系：
- **固定面积 A 时**，M 是 R 的单调增函数 ⟹ 最小化 M ⟺ 最小化长宽比（副目标）；
- **固定长宽比 R 时**，M 是 A 的单调增函数 ⟹ 最小化 M 同时压低面积（主目标）。

### 5.3 为何不能直接采用（诚实边界）

若直接以 min-max 为目标而不加任何约束，它**并非**严格实现题设词典序。反例：布局 X（W=100, H=100，A=10000，R=1，M=100）与布局 Y（W=101, H=99，A=9999，R≈1.020，M=101）。按题设，Y 面积更小应当胜出；但按无约束 min-max，X 的 M 更小。二者冲突。

原因在于：min-max 的 M = √(A·R) 是面积与长宽比的**乘性耦合**，最小化它是在"压低面积"与"压低长宽比"之间取一个隐含的折中，而非题设要求的严格面积优先。**若不处理这一偏差，论文结论会被评阅质疑为"换目标"。**

因此，必须对 min-max 附加一个强制面积优先的约束，将它与词典序结构缝合在一起——这是 5.4 的核心。

### 5.4 严格化：面积近优约束（本文采用的形式）

在 min-max 目标上附加**面积近优约束**，得到本文最终采用的目标：

```
min Φ = max(W,H)
s.t.  A ≤ A_opt·(1+ε)
```

其中：
- **A_opt** 为第一阶段（Phase 1）纯面积优化所得的最小面积（见 5.5）；
- **ε** 为面积容忍度，取 1%，是对题设"面积相同"的工程操作化。

**选择该形式的理由**：
1. **主目标不被牺牲**：面积约束 A ≤ A_opt(1+ε) 直接锁死了"面积优先"这一词典序要求——任何面积超出的解被排除，min-max 只在最优面积邻域内活动；
2. **副目标精确实现**：在约束内，M = √(A·R)，A 已限制在近优邻域，最小化 M 即最小化 R（长宽比趋近 1）——副目标严格生效；
3. **与题设一一对应**：题设"面积相同的情况下"恰对应本模型的"面积落入 A_opt(1+ε) 邻域"，ε 有明确的面积语义而非抽象权重，可解释、可调参、可灵敏度分析；
4. **无近似假设**：与 5.2 的"近最优区等价"定理不同，面积约束使 min-max 与词典序**严格一致**，论文无需依赖任何近似性论证。

**理论性质（命题）**：在面积约束 A ≤ A_opt(1+ε) 下，min-max 最优解满足：(i) 面积不超过最优面积 A_opt 的 (1+ε) 倍；(ii) 在所有满足 (i) 的布局中长宽比最小。此即题设词典序目标的严格实现。

### 5.5 两阶段求解算法

**动机**：面积约束中的参照 A_opt 必须先求得——这决定了分两阶段：

- **Phase 1：面积优化**。以加权目标（λ=0，即纯面积）跑 SA，得 A_opt。此处不用 min-max，因为我们需要的是**面积真值**，而非折中值。
- **Phase 2：min-max 优化**。固定 A_opt、ε，以成本函数：

```
Φ = max(W,H)/Φ_norm + μ·max(0, A − A_opt(1+ε))
```

跑 SA。其中第二项为面积越界惩罚（μ 取大值），第一项 min-max 在可行域内推进方形化。

**理由**：
- Phase 1 提供客观的 A_opt 参照，避免"面积多少算最优"的主观性；
- Phase 2 的惩罚项把面积约束松弛为软约束，便于 SA 跨越不可行解，同时 μ 大保证最终解满足约束；
- 两阶段解耦了"求面积下界"与"在最优面积内求方形"，各阶段目标单一、结果可解释。

### 5.6 与备选目标的对比（选择 min-max 的依据）

| 目标 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 加权 A/A_norm + λ(R−1)² | 实现简单 | 权重 λ 难定；λ 过大致面积次优；需归一化两个量纲 | **对照** |
| 两阶段词典序（Phase1 面积 → Phase2 面积约束内 min\|R−1\|） | 数学最严谨 | 与 min-max 方案等价但需额外定义 R 的二次项 | **基准对照** |
| **min-max + 面积约束** | 单量纲免权重；几何直觉强；惩罚项自然；与词典序严格一致（命题） | 需先求 A_opt（两阶段） | **采用** |

**最终采用理由总结**：
1. **免权重调参**——max(W,H) 是长度量纲，无需在面积与长宽比间权衡权重；
2. **几何可解释**——"外接框较长边最小"直观对应"最紧凑的近似方形";
3. **严格性**——面积约束保证与题设词典序一致，无近似假设，评阅无懈可击;
4. **工程友好**——Phase 2 的惩罚项形式天然适配 SA 的跨越搜索;
5. **结果可验证**——报告 gap=(A−A_opt)/A_opt（实测 <2%），直接证明未牺牲主目标。
