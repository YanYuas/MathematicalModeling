## 一、问题的本质：我们面对的是什么

### 1.1 从题设到数学对象

我们建模的第一步，是从题设的措辞里读出问题的形态。三个关键词各指向一个关键性质：

- **"芯片轮廓不固定"**——轮廓不是给定的约束，而是决策的结果，面积因此成为可优化的目标；
- **"模块之间没有连接关系"**——无线网、无 HPWL，电学指标全部退出，问题退化为**纯几何填充**；
- **"面积相同的情况下长宽比越接近1越好"**——这句话隐含严格的先后次序，是一个**词典序双目标**，而非简单的加权。

此外，"允许 90° 旋转"把每个模块的朝向限制为两种（原朝向与旋转 90°），使问题成为离散组合优化。

基于此，我们把问题抽象为：给定 n 个可 90° 旋转的矩形模块，求一个摆放方案，使外接矩形面积最小；在面积相同的方案中，长宽比最接近 1。

### 1.2 难点诊断：复杂性从何而来

进一步审视，我们识别出三个结构性困难，它们分别指向建模的三个环节：

**难点一：不重叠约束的析取性。** 任意两模块的相对位置是"左/右/上/下"四选一：

```
∀i≠j: (xᵢ≥xⱼ+wⱼ) ∨ (xⱼ≥xᵢ+wᵢ) ∨ (yᵢ≥yⱼ+hⱼ) ∨ (yⱼ≥yᵢ+hᵢ)
```

这是非凸、离散的组合约束——每对模块引入一个"逻辑或"。这一性质正是问题 **NP 困难**（Hakimi 1988 的归约证明）的来源，也决定了：对 100-300 个模块无法在多项式时间内求最优解，必须采用启发式算法，并**用下界论证结果质量**。这一难点指向**表示方法**的选择（第二节）。

**难点二：词典序双目标的处理。** 面积与长宽比是两个不同量纲的目标，且存在严格的先后次序。直接加权需要主观确定权重，权重失衡还会牺牲主目标——这一矛盾贯穿目标函数设计的始终。该难点指向**目标函数**的构造（第三节）。

**难点三：数据的差异性。** 我们对三组数据做了几何画像（表 1），发现差异显著：n100 含大模块（61×67，约占总面积 2.3%）、近方块比例仅 21%、另有 15 个长条模块（纵横比≥2.5），方形化难度最高；n200/n300 模块尺寸小且均匀。这提示：三组需差异化策略，且**任何方法都绕不开长条模块这个方形化的主要障碍**。该难点指向**预处理与初值构造**（第四、五节）。

**表 1 三组芯片模块几何画像**
| 指标 | n100 | n200 | n300 |
|:---|:---:|:---:|:---:|
| 模块数 | 100 | 200 | 300 |

**小结**：问题本质是 NP 困难的矩形装箱，三个难点分别指向表示、目标、数据三个环节。这自然确定了我们"表示 → 目标 → 算法 → 验证"四步的建模路线，以下四节逐一展开。

## 二、表示层：为什么树编码是必然选择

### 2.1 一个关键的观察

面对难点一，我们首先追问：**能否让"合法"成为编码的内建性质，而不是每次评估都要检查的约束？** 这一追问把我们引向两个观察。

**观察 1（无损压缩）**：任一合法布局可反复"左下压实"化为 admissible 布局——即没有任何模块还能再向左或向下移动的布局——且这一过程**不增大外接框**。压实只把模块向"空档"推移，右、上边界不可能变大，左、下边界则始终被最靠边界的模块贴住。

**推论**：面积最小化的最优解必存在于 admissible 布局集合中，搜索 admissible 布局**无任何损失**。

**观察 2（双射结构）**：admissible 布局与有序二叉树之间存在**一一对应**：根为左下角模块，左孩子为右侧相邻的最矮模块，右孩子为正上方模块。给定布局可唯一建树，给定树可唯一还原布局。

### 2.2 由此得到的决策

这两个观察让我们确信：**树编码是自然的选择（B*-Tree，Chang et al., 2000）**，因为它同时带来三重收益：

- **内建合法性**：左孩子在父右侧（x 区间不相交）、右孩子在父上方（y 区间不相交），递推至整棵树，任意两模块不重叠——**重叠检查从每次评估中彻底消失**，而这是装箱最昂贵的环节；
- **线性时间解码**：x 坐标经一次前序遍历确定，y 坐标由轮廓结构均摊常数时间给出，整体 O(n)——在 100-300 块规模下，每次扰动评估都是秒级完成的；
- **编码无冗余**：admissible 布局与树一一对应，解空间不浪费。

我们同时比对了备选表示：序列对（Sequence Pair）解空间为 (n!)²、解码 O(n²)，在 n300 下比树编码慢一个数量级；O-tree 存在冗余编码。**树编码在解空间规模、解码复杂度、冗余性三项上均占优**——这是权衡后的选择，而非预设。

## 三、目标函数：从词典序到单量纲

### 3.1 为什么加权不可行

面对难点二，最先想到的自然是加权：Cost = A + λ(R−1)²。但深入一想，它有三个不可回避的缺陷：

1. **权重主观**——λ 取多少没有客观依据；
2. **量纲混乱**——面积（长度²）与长宽比（无量纲）不能直接相加，必须归一化；
3. **失衡毁主目标**——λ 过大时，牺牲面积换来的方形反而"赢"，**直接违反题设的面积优先原则**。

于是我们转向一个更根本的问题：**有没有一个量，能同时表达两个目标且天然尊重它们的先后次序？**

### 3.2 一个揭示结构的恒等式

我们考察双目标的数学关系，得到关键恒等式。记 M=max(W,H)、m=min(W,H)，则面积 A=M·m、长宽比 R=M/m，于是：

```
M² = (M·m)·(M/m) = A·R    ⇒    M = √(A·R)
```

这个恒等式揭示了两层含义。**其一**，固定面积 A 时，M 是长宽比 R 的单调增函数——**最小化长边 M，在面积不变时等价于最小化长宽比**；**其二**，由 A ≤ M²，M 越小，面积的上界越小。也就是说，**单一量 max(W,H) 同时施加"压面积"与"促方形"两个方向的力，且无需任何权重**。几何直觉同样支持：等面积的矩形中，正方形的最长边最短。

### 3.3 进一步分析发现的边界

但严谨性要求我们不能止步于此。深入检查后我们发现问题并不简单：**无约束的 min-max 与词典序目标一般并不等价**。反例：

```
布局 X: W=100, H=100 → A=10000, M=100, R=1
布局 Y: W=101, H=99  → A=9999,  M=101, R≈1.02
```

按题设，Y 面积更小，应当胜出；但按无约束 min-max，X 的长边更小。二者冲突。原因在于 M=√(A·R) 是面积与长宽比的**乘性耦合**——最小化它是在两者之间取一个隐含折中，而非题设要求的面积绝对优先。

### 3.4 因此：附加面积近优约束，并给出命题保证

**为解决这一偏差，我们附加面积近优约束**，将目标函数确定为：

```
min Φ = max(W,H)
s.t.  A ≤ A_opt(1+ε)          ε=1%
```

其中 A_opt 为第一阶段面积优化所得（见 4.1），ε 为面积容忍度。这个约束一举解决三个问题：

- **锁死主目标**——面积超出阈值 A_opt(1+ε) 的解被排除，面积优先被结构性地保证；
- **激活副目标**——约束内 A 固定在近优邻域，最小化 M 即最小化长宽比；
- **操作化"面积相同"**——题设"面积相同的情况下"在随机搜索下无法严格实现，ε 邻域是其工程正确解读。

关于 ε 的取值：取 0.1% 则可行布局过少、搜索无空间；取 10% 则面积差 10% 也算"相同"，违背面积优先；**1% 是两者的折中**，其稳健性由灵敏度分析（ε=0.5%/1%/2%）验证。

更进一步，我们给出命题，使模型**无近似假设**：

> **命题 1**：在面积约束 A ≤ A_opt(1+ε) 下，min-max 最优解满足：(i) 面积不超过最优面积的 (1+ε) 倍；(ii) 在所有满足 (i) 的布局中长宽比最小。此即题设词典序目标的严格实现。
>
> **证明**：由 M²=A·R，在满足 (i) 的布局中 A 固定于近优邻域，M 单调于 R，故最小化 M 等价于最小化 R；约束 (i) 又直接排除面积超阈值的解，主目标优先得以保证。∎

至此，目标函数完成设计：**单量纲、免权重、与题设严格一致**。这是我们在加权、两阶段词典序、min-max 三者间权衡后的选择。

## 四、算法设计：从困难到决策

### 4.1 两阶段：先校准，再优化

面积约束依赖 A_opt，而 A_opt 必须先求得，求解因此分两个阶段：

- **Phase 1（面积校准）**：以纯面积为目标跑模拟退火，得最小面积 A_opt。此处刻意不用 min-max——我们需要的是面积的**真值**，而非与长宽比的折中值；
- **Phase 2（方形优化）**：以 min-max 为主项、面积超阈值为惩罚项（见 4.3），在面积近优约束下求最方布局。

两阶段解耦的意义在于：校准（求 A_opt）与优化（求布局）各司其职，共用同一套搜索骨架，仅替换目标函数即完成切换。

### 4.2 为什么是模拟退火，以及为什么是分段温度

NP 困难意味着必须在解质量与计算时间间权衡。我们考察过常用启发式：遗传算法对离散树编码无增量优势且参数更多，粒子群与树结构不自然。**模拟退火（SA）的 Metropolis 接受准则（Prob=min{1,e^(−ΔC/T)}）提供了"探索+利用"平衡的成熟框架**，其接受爬山解的能力天然适合逃离局部最优。

但经典 SA 有一个效率缺陷：冷热同一节奏，开头浪费在"不该接受的劣解"，结尾浪费在"该接受的探索"。**为此我们设计分段温度调度**：

```
T₁ = Δ_avg/|ln P|                       （初始温度，取绝对值保证 T₁>0）
Tₙ = T₁⟨Δcost⟩/(n·c),  2 ≤ n ≤ k       （伪贪心段：温度趋零，快速下沉）
Tₙ = T₁⟨Δcost⟩/n,      n > k           （爬山段：温度回升，跳出再细搜）
```

其中 ⟨Δcost⟩ 为当前温度下的平均代价变化，Δ_avg 为平均上涨代价，P=0.9 为初始接受概率，c=100、k=7。**关键前提**：成本必须归一化（除以 A_norm、Φ_norm），否则 ⟨Δcost⟩≥1，温度不再单调下降，退火退化为随机搜索。n=k+1 时温度由 T₁⟨Δcost⟩/(k·c) 回升至 T₁⟨Δcost⟩/(k+1)，约放大 87 倍，实现爬山跳变。参考论文报告该调度对 GSRC 基准相对经典 SA 提速 12-13.9 倍（Chen & Chang, 2006），我们的实现以同量级为目标。

### 4.3 三个扰动算子为什么齐全

搜索完备性要求三个算子互补：**旋转**（O(1)）只改朝向、不触拓扑，是方形度的微调手段——对 Q1 尤为重要，因为朝向直接改变模块纵横比；**删插**（O(n)）改变树的形状——缺了它，树形状被冻结，解空间严重受限；**交换**重排标签。三者概率分配（旋转 0.1 / 交换 0.4 / 删插 0.5）体现"探索为主、微调为辅"。此外，全程记录 best_so_far 而非末态——SA 末态只是"正在搜索的位置"。

### 4.4 软约束机制：面积约束如何与搜索互动

面积约束若以**硬约束**实现（面积超阈值即拒绝候选），SA 将无法翻越不可行区域，**被困于首个可行解附近**——这正是加权目标中 λ 过大的早陷根源。**因此我们把约束软化为惩罚项**：

```
Φ = max(W,H)/Φ_norm + μ·max(0, A − A_opt(1+ε))
```

μ 取大值：SA 可**暂时**越界探索（付出惩罚成本），从而保留跨区域搜索的能力；重罚又保证最终解合规。μ 过小则终解可能越界，过大则退化为硬约束、丧失跨越能力——**"探索自由"与"结果合规"的平衡，正是这一软约束设计的核心**。

### 4.5 构造初解：确定性方法为何必要

SA 的收敛质量依赖初值——烂初值把大量迭代浪费在差区域。**我们设计了确定性行堆叠构造（FFD）**：按高度降序逐行堆叠，行高取行内最大块高。按高降序的意义在于让大块先占位、减少行数。该构造确定性、**保证可行**，且**免费给出构造性上界**（见第五节）。它作为 SA 初值，预期把死区从 8-9% 精修至 2-5%——**构造定骨架，SA 打磨**，二者互补而非替代。

### 4.6 长条配对：数据驱动的预处理

面对表 1 揭示的难点三（n100 的 15 个长条），我们提出**纵横比互补配对预处理**：把"一高瘦一矮宽"的模块两两组合，使复合块的总宽≈总高。配对质量定义为复合块方形度（min/max）与配对前两者较大方形度之差，仅对质量为正的组合配对，以最大权匹配（匈牙利算法）求解。**动机直接来自数据**：长条是对方形度破坏最大的分量，先把它们合成近方块，再进入树编码搜索，能显著缩小对长宽比破坏最大的解空间部分。

## 五、验证层：下界让结果可信

### 5.1 为什么需要下界

NP 困难问题的启发式解自称"最小面积"，若无参照便只是自封。**我们建立了三层下界与一个构造性上界**：

```
面积下界：A ≥ A_total
方形下界：A ≥ ⌈√A_total⌉²            （R=1 时）
固定宽下界：H(W) ≥ max(A_total/W, max块高)
构造性上界：FFD 行堆叠保证可行
```

### 5.2 由此得到可行区间

三层下界与构造上界合并，给出方形边长的**可行区间 [LB, UB]**：

**表 2 三组芯片方形边长可行区间**
| 芯片 | 面积下界边长 ⌈√A⌉ | 构造可行边长（FFD） | 可行区间 |
|:---|:---:|:---:|:---:|
| n100 | 424 | 443 | [424, 443] |
| n200 | 420 | 440 | [420, 440] |
| n300 | 523 | 538 | [523, 538] |

**这个区间是整套方法的验证锚**：我们的启发式结果必须落在其中——低于下界意味着实现有误，高于上界意味着仍有优化空间。基于数据我们还量化了方形本身的可行性：面积下界距方形边长的裕度仅 0.65/1.68/0.69 单位，方形要求近乎完美平铺，实际几乎必然不可行，死区下限约 1%。此外，我们以 gap=(A−A_opt)/A_opt 报告与 Phase 1 面积最优的差距，直接证明 min-max 求解未牺牲主目标。

## 七、摘要段（按本文叙述重写）

针对芯片轮廓不固定、模块间无连接关系下"面积最小且长宽比趋近1"的矩形装箱问题（NP困难），我们识别其核心难点为不重叠约束的析取性与词典序双目标结构。基于"任一合法布局可无损压实为与二叉树一一对应的 admissible 布局"的观察，采用树编码使解码结果天然合法、评估线性时间；推导恒等式 M²=A·R 揭示长边 max(W,H) 可同时表达面积与长宽比两目标，并附加面积近优约束、证明其严格实现题设词典序（命题1）；以分段温度调度的模拟退火求解，辅以确定性构造初解与长条互补配对预处理；经三层下界与构造性上界验证，三组芯片可行区间为 [424,443]、[420,440]、[523,538]，预期死区 2%-5%、长宽比趋近1。
