## 问题分析

### 1. 问题本质与定位

问题 2 要求在给定**固定正方形轮廓**内摆放各矩形硬模块（可 90° 旋转），使模块间的**总 HPWL 最小**，同时满足模块互不重叠、不超出轮廓。轮廓尺寸由公式(1)确定（死区比例 0.15），终端位置固定于 .pl 文件坐标。与问题 1（纯面积装箱）相比，本问题引入了**连线关系与固定轮廓双重约束**，本质上是**固定轮廓布图规划**（fixed-outline floorplanning）与**超图布局**（线网=超边）的复合优化问题，属已知 **NP 困难问题**。模块仅 2 种朝向、解空间离散，100-300 块规模必须采用启发式算法。

### 2. 问题特性分析

**(1) 轮廓固定性。** 轮廓为边长 $S=\sqrt{A_{total}(1+\Gamma)}$ 的正方形（$\Gamma=0.15$），是硬约束而非可优化对象。三组轮廓边长 454.34 / 449.50 / 560.49。注意死区占芯片面积的比例为 $\Gamma/(1+\Gamma)\approx 13.04\%$（非 15%）。

**(2) 目标单一性。** 唯一目标为总 HPWL，无问题 1 的双目标词典序结构，目标函数定义即 HPWL 公式（包围盒半周长）。但**线长目标与轮廓约束天然对冲**：HPWL 优化把模块拉向所连终端，使模块分布变稀、打包包围盒增大、逼近甚至超出轮廓——这是本问题最核心的结构性张力。

**(3) 连接结构特殊性（实测）。** 终端（334/564/569 个）四边均匀分布（85/84/82/83 等），每条终端恰出现于**一个**线网中，且该网为"1 终端 + 若干模块"的 I/O 混合网。线网中 2-pin 网占 88.9%/75.0%/72.4%，多 pin 网度数最高 6。终端不占面积、不参与重叠约束。

**(4) 数据差异性。** n100 含大模块（最大边长 67）与 15 个长条块；n200/n300 模块小且均匀（最大边长 48）。三组线网规模 885/1585/1893。

### 3. 建模难点

- **线长与轮廓的对冲**：不存在"先压面积再配线"的简单分解——线长优化本身会破坏轮廓可行性（模块向终端扩散）；
- **轮廓可行性判据**：不能仅以面积 $A \le S^2$ 判可行（瘦长解面积达标但超轮廓），需用 $M=\max(W,H)\le S$（等价于 $A\cdot R \le S^2$，$R$ 为长宽比）；
- **惩罚的软硬取舍**：硬拒绝（不可行=inf）会困死模拟退火；直接线性惩罚 $max\{W-S,0\}+max\{H-S,0\}$ 权重过大会在找到首个可行解后陷入局部极小、过小则得不到可行解（参考论文明确警告）；
- **结果可信度**：线长下界难以紧致构造（模块有面积、终端锚定复杂），需以基线对 + 参考论文量级对标 + 收敛曲线三重论证；
- **报告合法性**：不可行解（超轮廓）线长往往更小，最优解记录必须设可行性门槛。

### 4. 求解思路

本文沿用问题 1 的"**表示-搜索-构造-验证**"框架，替换目标与增加轮廓处理：

**(1) 表示层——B\*-Tree 复用**。admissible 无损压缩定理成立（压缩不增外接框、不增线长），B\*-Tree 与无冗余 admissible 布局一一对应，解码 O(n) 且天然免重叠。打包后得到 W、H，据此判定轮廓可行性。

**(2) 搜索层——Fast-SA 复用**。三阶段退火 + 三扰动算子（旋转/删插/交换）。旋转在本问题中尤为重要：旋转改变模块**几何中心**坐标（中心 $(x+h/2,y+w/2)\ne(x+w/2,y+h/2)$），既改装箱形态也改线长。

**(3) 目标层——线长主目标 + 轮廓软惩罚 + 自适应权重**。成本函数：
$$\Phi = \frac{W_{HPWL}}{W_{norm}} + \lambda \cdot \max\Big(0,\ \frac{A\cdot R - S^2}{S^2}\Big)$$
其中 $A\cdot R = M^2$ 由恒等式给出，惩罚仅在 $M>S$ 时激活且平滑（利于 SA 试探逼近轮廓）。权重 $\lambda$ 自适应：近期可行解多则减小（聚焦线长），可行解少则增大（压回轮廓），从而在"线长×轮廓"张力间动态平衡，并规避固定权重的两难。

**(4) 初始化层——双引擎**。① 问题 1 最优解 warm start：已证 Q1 方形解（边长 424-443 等）自动落入 Q2 轮廓（454.34 等），保证初始可行；② 力导向/谱布局初始化：以终端为锚点、线网为弹簧（或共享网连边嵌入），产出线长导向初解。两引擎对照运行，取全局可行最优。

**(5) 验证层——基线对 + 量级对标**。建立两个基线：全模块堆叠于原点（150761/251410/321484，终端网拉长的上界量级）与 strip 打包填轮廓（295222/552768/832706，模块散开的下侧量级），最优线长应落于两者之间；并结合参考论文线长量级（n100~2×10⁵、n200~3.5×10⁵、n300~5×10⁵）与收敛曲线论证结果可信。

### 5. 目标函数设计要点

- 主目标 $W_{HPWL}/W_{norm}$：线长归一化（$W_{norm}$ 为 SA 前试扰动平均线长），保证退火温度公式自洽；
- 轮廓惩罚 $(\lambda/S^2)\max(0, A\cdot R-S^2)$：用恒等式写成平滑软惩罚，量级与主目标可比；
- $\lambda$ 自适应：$\lambda$ 随最近 $n=500$ 次解的可行率动态调整（或采用参考论文的 $\alpha=\alpha_{base}+(1-\alpha_{base})n_{feasible}/n$ 形式，$\alpha_{base}=0.5$）；
- best 记录：仅更新满足 $M\le S$ 的可行解。

### 6. 求解路线图

1. **数据解析**：读 .blocks/.nets/.pl，校验总面积/线网数/终端数，构建块、终端坐标、线网表（评估器 hpwl.py 已备）；
2. **初始化**：Q1 最优解建树（保可行）+ 力导向/谱布局（保线长）双引擎；
3. **SA 迭代**：扰动 → 解码 → 计算 HPWL 与轮廓惩罚 → Metropolis 接受 → 三阶段降温 → $\lambda$ 自适应更新；
4. **多运行**：固定种子多次运行取最优可行解，报告总 HPWL、轮廓占用、运行时间及统计量；
5. **验证**：M≤S 校验、与两个基线及参考论文量级对比；
6. **可视化**：三组布图（轮廓框、终端点、模块、可选关键线网）。

### 7. 预期结果与可行性区间

**可行性**：$\Gamma=15\%$ 时参考论文在 n100 上取得 100% 成功（对比 GFA 30.3%、Parquet-SP 65.5%），三组可行性均有保证；且 Q1 方形解（424-443/420-440/523-538）全部小于轮廓边长（454.34/449.50/560.49），初始解即可行。

**预期线长**：最优总 HPWL 落在基线对之间（如 n100 在 150761 与 295222 之间），预期量级 n100~2×10⁵、n200~3.5×10⁵、n300~5×10⁵。结果若低于"全堆原点"基线则可疑（可能越界），需检查可行性门槛。

**主要风险**：λ 自适应实现不当导致超轮廓或线长差；旋转算子概率不足导致线长优化不充分；best 未设可行性门槛导致报告越界解。

## 8. 符号表（"符号说明"节素材）

### 8.1 集合与索引

| 符号 | 含义 |
|---|---|
| $\mathcal{B}$ | 模块集合，$\|\mathcal{B}\|=n$（100/200/300） |
| $\mathcal{T}$ | 终端集合（334/564/569） |
| $\mathcal{N}$ | 线网集合，$\|\mathcal{N}\|=m$（885/1585/1893） |
| $b_i$ | 第 i 个矩形硬模块 |
| $t_j$ | 第 j 个固定终端 |

### 8.2 几何量

| 符号 | 含义 |
|---|---|
| $w_i, h_i$ | 模块宽、高 |
| $A_{total}=\sum w_i h_i$ | 模块总面积 |
| $S$ | 正方形轮廓边长，$S=\sqrt{A_{total}(1+\Gamma)}$ |
| $\Gamma$ | 死区比例基数，=0.15 |
| $(x_i,y_i)$ | 模块左下角坐标 |
| $\theta_i \in \{0,90°\}$ | 模块朝向 |
| $W, H$ | 布图外接框宽、高 |
| $A=W\cdot H$ | 布图面积 |
| $R=\max(W,H)/\min(W,H)$ | 长宽比，≥1 |
| $M=\max(W,H)$ | 外接框大边 |
| $(x_t,y_t)$ | 终端固定坐标 |

### 8.3 线网量

| 符号 | 含义 |
|---|---|
| $p \in net$ | 引脚（模块中心或终端坐标） |
| $x_p, y_p$ | 引脚坐标 |
| $\text{HPWL}(net)$ | 网包围盒半周长 $=\text{span}_x+\text{span}_y$ |
| $W_{HPWL}$ | 总 HPWL $=\sum_{net}\text{HPWL}$ |
| $W_{norm}$ | SA 前试扰动的平均线长（归一化基准） |
| $\lambda$ | 轮廓惩罚权重（自适应） |
| $\alpha$ | 线长/轮廓权重（参考论文自适应式） |
