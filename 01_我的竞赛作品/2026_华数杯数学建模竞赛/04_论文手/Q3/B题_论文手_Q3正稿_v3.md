## 摘要

问题三要求在问题二基础上求**使得存在一个可行布局的最小死区比例 Γ\***，并基于 Γ\* 更新问题二的线长结果。本文将其分解为两层：第一层（存在性层）本质是**问题一的方形约束版**——最小正方形装箱，求可行临界；第二层（优化层）在临界轮廓下复用问题二的贪心引擎更新线长。

核心几何工具是贯穿三问的恒等式 $M^2 = A\cdot R$（$M=\max(W,H)$ 为外接框大边，$R$ 为长宽比）。由此得临界刻画：$\text{可行}(\Gamma) \iff \exists\,\text{布局}: R \le 1+\Gamma$，即**最小死区比例等于最优可行布局的长宽比减一：$\Gamma^* = R^* - 1$**。可行域对 $\Gamma$ 单调，故采用**参数化收缩二分**：以判可行子程序（FFD 行堆叠与 skyline 双构造器 + 长条旋转 + 硬门 $W\le S\wedge H\le S$ + best-of-N）为核心，从问题一解（边长 443/432/533）向下收缩，求得构造最小可行轮廓。

对三组芯片，构造 $\Gamma^* = 0.0933 / 0.0622 / 0.0400$（对应轮廓边长 443/432/533），死区占轮廓面积比例 $8.53\%/5.86\%/3.84\%$；面积下界 $\Gamma\ge 0$；参考论文表明 n100 存在边长约 436 的更优布局（$\Gamma\approx 0.0589$），需强搜索可达。在 $\Gamma^*$ 轮廓下复用问题二贪心引擎更新线长，得 **233,578 / 472,286 / 761,907**，相对问题二**复现值**增加 **+4.5%/+6.8%/+11.1%**（死区收紧的线长代价，n300 最显著，见权衡曲线）。方法的关键创新：①恒等式三问贯通与 $\Gamma^*=R^*-1$ 临界闭式；②收缩可行性曲线（死区-可行分界可视化）；③q1warm 连续可行链（从 $\Gamma=0.15$ 可行解沿 $\Gamma$ 下降的可行路径追踪）。

**关键词**：最小死区比例；正方形装箱；恒等式 $M^2=A\cdot R$；收缩二分；半周长线长（HPWL）

## 1. 问题重述与分析

### 1.1 问题重述

问题三在问题二的基础上：求最小死区比例 $\Gamma^*$ 使得存在一个可行布局（模块互不重叠、不超出轮廓边长 $S=\sqrt{A_{total}(1+\Gamma)}$ 的正方形轮廓），并基于问题二模型和 $\Gamma^*$，更新问题二的总 HPWL 与可视化。

### 1.2 问题本质：从存在性到最优性的两层结构

问题三**不是新的优化问题，而是存在性判定嵌套优化**：

- **层A（存在性层，主答案）**：$\Gamma^* = \min\{\Gamma : \exists\,\text{可行布局}\}$。主语是"存在"，是判定问题。其数学结构恰为**问题一的方形约束版**——求最小正方形边长 $S^*$ 使存在 $S^*\times S^*$ 内可行布局（问题一允许任意矩形轮廓，此处锁定长宽比 $R=1$）；
- **层B（优化层）**：在 $S^*=\sqrt{A_{total}(1+\Gamma^*)}$ 下复用问题二模型更新总 HPWL。

**层序不可颠倒**：$\Gamma^*$ 未定，HPWL 无轮廓约束。两层结构见 **图 1**（流程示意）。

### 1.3 问题特性

**(1) 存在性临界。** 题设"使得存在一个可行布局方案"是存在量化（$\exists$布局），非连续目标优化。判定本身只能启发式逼近（见 §4.2）。

**(2) 参数化与单调性。** $\Gamma$ 是公式(1)的参数，可行域对 $\Gamma$ **单调**：$\Gamma$ 增大 $\Rightarrow$ $S$ 增大 $\Rightarrow$ 约束放宽，故可行集 $=[\Gamma^*,\infty)$。这使临界可用二分求取，无需在 $\Gamma$ 维上全局优化。

**(3) 口径二义。** 题设 $\Gamma=(S^2-A)/A$（相对**总面积**，公式1口径）与死区占比 $(S^2-A)/S^2$（相对**轮廓面积**）不同：$\Gamma=0.15$ 时死区占比 $=\Gamma/(1+\Gamma)\approx 13.04\%$。本文主口径采用题设 $\Gamma$，死区占比辅列。

**(4) 数据差异性。** 长条模块主导死区：n100 含 15 个长条，死区最紧难以突破；n300 模块小而灵活（最大边长 48），死区可压得更低。实测死区排序 $8.53\%>5.86\%>3.84\%$（n100>n200>n300）。

### 1.4 求解思路

```
判可行子程序（FFD/skyline + 长条旋转 + 硬门 W≤S∧H≤S + best-of-N）
   → 收缩二分（S ∈ [⌈√A⌉, 问题一解边长]，q1warm 连续可行链）
   → 层A 输出 Γ* = (S*²/A) − 1
   → 层B 在 S* 下复用问题二贪心引擎更新 HPWL
```

核心不是优化，是"判可行"与"连续收缩"。

## 4. 模型建立

### 4.1 恒等式临界刻画（核心定理）

**定理（三问贯通的临界形式）**。对死区比例 $\Gamma$，存在可行布局当且仅当存在布局满足
$$R \le 1 + \Gamma,$$
其中 $R$ 为布局长宽比。

*证明*。可行 $\iff \max(W,H) \le S$。由恒等式 $M^2 = A\cdot R$ 与 $S^2 = A(1+\Gamma)$：
$$\max(W,H)\le S \iff M^2 \le S^2 \iff A\cdot R \le A(1+\Gamma) \iff R\le 1+\Gamma. \quad\square$$

**推论（最小死区的闭式）**。设 $R^* = \min\{R(L) : L \text{ 为可行布局}\}$ 为最优可行长宽比，则最小可行轮廓边长 $M^*=\sqrt{A\,R^*}$，且
$$\Gamma^* = \frac{M^{*2}}{A} - 1 = R^* - 1.$$

**几何直觉**：死区比例等于最优布局长宽比减一——把布局压得最方时，超出 $1$ 的部分就是必须牺牲的死区。临界刻画见图 **图 2**（可行区域：斜线 $R=1+\Gamma$ 分界，$\Gamma$ 收缩时边界下移、可行区收窄）。

### 4.2 判可行子问题（存在性的构造逼近）

对给定 $S$，判定是否存在布局满足 $W\le S$ 且 $H\le S$。采用**装箱构造逼近**：

**命题（充分性判定）**。按某次序对模块行堆叠（FFD，行宽 $\le S$），若打包高度 $H_{\text{FFD}} \le S$，则 $S$ 可行。反之不构成不可行证明（构造性判定的本质局限）。

为降低漏判，采用**多构造器 best-of-N**：FFD 行堆叠（h 降序）与 skyline bottom-left（h 降序）双构造器，各自多随机次序多次运行，任一给出 $W\le S\wedge H\le S$ 即判可行。长条模块（纵横比 $\ge 2.5$）预旋转为长边水平（问题一结论：n100/n300 必需，否则连问题一解边长都不可行）。**硬门严格**：不信任打包器自称，独立计算 $W,H$ 再校验。构造器对比见 **图 9**（h_desc vs skyline 打包高度 vs S，无绝对赢家）。

### 4.3 单调性与二分（临界搜索）

**引理（可行域单调）**。$\Gamma_1 < \Gamma_2 \Rightarrow$ 可行$(\Gamma_1) \Rightarrow$ 可行$(\Gamma_2)$。故可行集为 $[\Gamma^*,\infty)$。

因此临界 $S^*$ 在区间 $[\lceil\sqrt{A}\rceil, M_{\text{Q1}}]$ 内**二分**求取（上界 = 问题一解边长，已验证可行；下界 = 面积下界取整，几乎不可行）。每点多 run 取多数判定（启发式噪声防），二分判定设 margin $\delta=1$（$W\le S-\delta \wedge H\le S-\delta$ 才判可行，防误报）。极限情形（$\Gamma\to 0$ 要求完美矩形平铺）见图 **图 12**。

### 4.4 更新子问题（层B）

在 $S^*$ 下复用问题二模型：**q1warm 起点（问题一解构造，target=$S^*$）+ 贪心可行下降（硬门 $M\le S^*$）+ best-of-N**。零改动只换轮廓。**一致性验证**：$\Gamma=0.15$ 时必须复现问题二结果（220,252/430,628/672,474 量级，gap<3%）——否则"更新"无意义。

### 5.5 收敛与稳定性（层B）

层B 贪心 best_wl 随迭代单调下降至平台：相对 q1warm 起点（n100 301,774）改善约 21-27%（贪心下降方向）；轮廓从 $\Gamma=0.15$ 收紧到 $\Gamma^*$ 后，同引擎 HPWL 从复现值（n100 223,590）增至 **233,578（+4.5%）**——这是死区收紧的线长代价，方向与贪心下降相反，两者不可混淆。更长迭代仅改善约 2%——贪心接近 B\*-Tree 三算子能力饱和。多 seed best-of-N 必要（n200 各 seed ±5%）。

## 7. 鲁棒性讨论

- **构造器选择**：h_desc 行堆叠与 skyline 无绝对赢家（n100 行堆叠好、n300 skyline 好）——best-of-N 多构造器必要（图 9）；
- **噪声判定**：临界区多次 run 判定波动，多 run 取多数 + margin $\delta=1$ 缓解；
- **长条旋转**：n100/n300 必需，n200 无长条不敏感；
- **权衡中间点噪声**：单 seed 采样非单调（T5），端点多 seed 定值、中间为趋势；
- **参考对比**：构造值非全局最优（n100 参考 436 < 构造 443），如实报告方法边界。

## 8. 模型评价

**优点**：①构造法快（秒级）、确定、可复现（固定种子）；②三档锚诚实分层，不虚报；③连续可行链使临界区判定可靠；④层B 复用保证与问题二口径一致（复现 gap 1.5-2.7% 验证）。

**局限**：①构造性判定非存在性证明，$\Gamma^*$ 是"构造可达值"；②FFD 类构造无法突破问题一解（n100 参考 436 需强搜索）；③n300 临界 gap 大，突破难。

**改进方向**：①n100 逼近参考 436 需更强搜索（SA 百万级/更紧打包）；②问题四 L/T 模块下子块分解后面积变化、$\Gamma^*$ 需重算，连续可行链方法可扩展（邻接约束）；③权衡曲线更细采样 + 多 seed 平均，量化边际压缩成本。
