## 二、Q3 论文环节逐步理清

### 环节1：问题分析

**结构对齐论文手 Q2 问题分析**（问题本质→特性→难点→求解思路→预期）：

**(1) 问题本质与定位。** Q3 = 求最小死区比例 Γ*（使得存在可行布局），并基于 Γ* 更新问题2的 HPWL。**它不是新优化问题，是两层复合**：层A = 问题1的方形约束版（最小正方形装箱，存在性判定）；层B = 问题2换轮廓重跑（固定轮廓线长优化）。层序不可颠倒——Γ* 未定，HPWL 无轮廓约束。

**(2) 问题特性。**
- **存在性临界**：题设"使得存在一个可行布局"是存在量化（∃布局），判定问题非优化；
- **参数化**：Γ 是公式(1)的连续参数，可行域对 Γ 单调（Γ↑→S↑→约束放宽），可行集=[Γ*,∞)；
- **口径二义**：题设 Γ=(S²−A)/A（相对总面积，公式1口径）≠ 死区占比 (S²−A)/S²（相对轮廓）。全篇主口径=题设Γ，死区占比辅列；
- **数据差异性**：长条模块主导死区（n100 15 长条死区最差，n300 模块小而灵活死区最紧）。

**(3) 建模难点。**
- **构造性判定 ≠ 存在性**：FFD/贪心判可行只回答"我能构造出解"，临界区可行解稀缺，"构造不出"与"真不存在"不可区分；
- **无紧下界**：面积下界 M≥√A 几乎唯一（max 模块边长 67/48/48 ≪ √A），下界不紧是数据特性；
- **长条朝向**：长条 2^15 朝向组合，贪心局部次优；
- **口径陷阱**：⌈√A⌉ 不是 Γ*（条件下界非可行下界）；更新 HPWL 必须用 S*=√(A(1+Γ*)) 非 Q1 解。

**(4) 求解思路。** 判可行子程序（FFD h_desc 行堆叠 + skyline + 长条旋转 + 硬门 W≤S∧H≤S）→ 收缩二分求 Γ* → 层B 复用 Q2 贪心引擎更新 HPWL。**核心不是优化，是"判可行"和"连续收缩"**。

**(5) 预期结果。** 构造 Γ* = 0.0933/0.0622/0.0400（死区占比 8.53%/5.86%/3.84%）；面积下界 Γ≥0；参考趋势 n100 存在 436 布局（Γ≈0.0589）。三档并列，诚实分层。

### 环节2：模型建立

**(1) 核心几何定理（三问贯通）。** 恒等式 M²=A·R。Q3 临界刻画：
```
可行(Γ) ⟺ ∃布局: M ≤ √(A(1+Γ)) ⟺ ∃布局: R ≤ 1+Γ
```
设 R*=最优可行布局长宽比，则 **Γ* = R* − 1**（死区=长宽比盈余）。这是 Q3 模型的数学支柱，一图/一式讲透。

**(2) 判可行模型（层A 核心）。** 对给定 S，判存在布局 W≤S∧H≤S。FFD target_width=S 打包（行内 W≤S 自动保证），判可行 ⟺ 打包高 H≤S。两构造器互补：h_desc 行堆叠（n100/n200 临界 gap 仅1）vs skyline（n300 更紧），best-of-N。长条旋转（AR≥2.5 长边水平）是 n100/n300 可行前提。**硬门严格**：不信任打包器自称，独立算 W/H。

**(3) 扫描模型。** 可行域对 Γ 单调 → 二分 S ∈ [⌈√A⌉, Q1解M]。每点多 run 多数判（噪声防）+ margin δ=1（误报防）。输出 Γ*=(S*²/A)−1。

**(4) 更新模型（层B）。** 在 S* 下复用 Q2 贪心引擎（q1warm 起点 + 硬门 + best-of-N），零改动只换轮廓。**一致性验证**：Γ=0.15 必须复现 Q2（220k/431k/672k）——否则"更新"无意义。

### 环节3：求解与结果

**(1) 先给下界锚（2007 方法3）。** 求解前先给三档表，建立信心：
| 档位 | 内容 |
|---|---|
| 构造可达 | Γ*=0.0933/0.0622/0.0400（S=443/432/533，已构造验证） |
| 面积下界 | Γ≥0（M≥√A，平凡但诚实） |
| 参考趋势 | n100 存在 436 布局（Γ≈0.0589，需强搜索非 FFD 可达） |

**(2) 收缩扫描表。** Γ 从 0.15 收缩到 Γ*，列可行/不可行表（或曲线图），展示临界边界。参数化判定（对标 2007 换乘上限 c）。

**(3) 更新 HPWL 表。** Γ* 下 S* 重跑 Q2 引擎，得 233,578/472,286/761,907（相对层B 复现值 223,590/442,138/685,740 增量 +4.5%/+6.8%/+11.1%）。**结果表带解读指南（2007 方法7）**：死区越紧线长越差——权衡曲线的深层含义，教读者"Γ 是设计自由度，不是任意给"。

**(4) 诚实标签。** 报"构造可达 Γ*"，不宣称"证明最小"（存在性 gap 不可闭合）。

### 环节4：评价（2007 方法8/9）

- **构造法优点**：快（秒级）、确定（多策略 best-of-N）、可复现（固定种子）；
- **局限**：非全局最优——n100 参考 436 < 构造 443；临界 gap 仅1单位（n100/n200），溢出重定位可压进但非保证；
- **层B 一致性**：Γ=0.15 复现 Q2 数字，证明"更新"是同一引擎同口径；
- **改进方向**：① n100 逼近参考 436 需强搜索（SA 百万级/更紧打包）；② L/T 模块（问题4）下子块分解后面积变、Γ* 重算，连续可行链方法可扩展；③ 死区-线长权衡曲线的更细采样。

## 三、写作红线与叙事要点

1. **口径**：主口径题设 Γ（公式1），死区占比辅列；"死区 5.57%"必须是死区占比口径（Γ=0.0589）
2. **禁叙事**：软惩罚/自适应λ/双引擎/SA主搜索（Q1Q2 实践否决）；"SA 精修至 2-5%"旧叙述禁用
3. **数字**：Γ* 0.0933/0.0622/0.0400；死区占比 8.53%/5.86%/3.84%；Q2 区间用修正 [424,443]/[420,432]/[523,533]
4. **叙事主线**：Q3 = Q1 方形对偶（恒等式三问贯通）+ 收缩曲线 + 权衡曲线 + 诚实分层
5. **对标**：参考 n100 死区占比 5.57%（Γ≈0.0589）带口径对齐；构造 443 与参考 436 的 gap 如实写
6. **创新表述**：Γ*=R*−1（死区=长宽比盈余）、q1warm 连续可行链（可行由起点保证）、死区-线长权衡（网络 vs 容器二象性）
7. **避免硬伤**：射影几何标签、宣称证明最小、⌈√A⌉ 当 Γ*、图论当求解方法

## 四、一句话总结

**Q3 论文按"两阶段问题分析 → 恒等式临界建模（Γ*=R*−1）→ 三档下界锚 → 收缩扫描表 → 更新 HPWL + 权衡曲线 → 诚实评价"的闭环写。最重要的两点借鉴 2007 国一：先给下界锚建立信心（构造Γ*/面积下界/参考趋势三档）、主动诚实暴露取舍（构造可达≠存在性证明）。红线：口径两列分列、禁否决叙事、数字用构造实测值。**
