## 三、马尔可夫链预测方法论

### 3.1 状态定义

三类老人状态：
- 自理老人
- 半失能老人
- 失能老人

### 3.2 转移概率矩阵

```
        自理    半失能  失能
自理    1-p1    p1      0
半失能  0       1-p2    p2
失能    0       0       1（吸收态）
```

- 失能老人无法恢复（吸收态）
- 半失能老人有概率转移为失能，但不会恢复为自理
- 自理老人有概率转移为半失能

### 3.3 递推公式

```
N(t+1) = N(t) × P + 新增老年人
```

其中：
- N(t) = 第t年末各类老人数量
- P = 转移概率矩阵
- 新增老年人 = 当前总老年人口 × 7%
- 自然死亡率 = 5%

### 3.4 可复用经验

- 适用于人口结构、疾病进展、状态转移类预测问题
- 注意吸收态的处理（失能老人不会恢复）
- 验证方法：总人口应保持合理增长，不应出现负数量

## 四、多目标遗传算法方法论

### 4.1 问题建模

- **决策变量**：每个小区是否建站（0/1）+ 建站规模（1/2/3 = 小/中/大）
- **目标1**：服务覆盖率最大化（至少享受一项服务的老人比例）
- **目标2**：服务满意度最大化（距离+响应+价格加权）
- **约束**：总建设预算≤120万元，服务半径≤1000米

### 4.2 编码方式

```
染色体 = [站点1规模, 站点2规模, ..., 站点10规模]
每个基因 = 0（不建）/ 1（小型）/ 2（中型）/ 3（大型）
```

### 4.3 适应度函数

```
适应度 = w1 × 覆盖率 + w2 × 满意度 - 惩罚项
惩罚项 = 超出预算的部分 × 大系数
```

### 4.4 可复用经验

- 多目标问题可以用加权法转为单目标，也可以用Pareto前沿
- 约束处理用惩罚函数，注意惩罚系数要足够大
- 枚举验证：小规模问题（10个小区×4种规模=4^10≈100万）可以枚举验证GA结果

## 五、定价优化方法论

### 5.1 问题建模

- **决策变量**：各项服务定价（助餐、日间照料、上门护理、康复理疗、助浴）
- **目标**：最大化老人满意度（价格满意度是其中一部分）
- **约束1**：利润率≤8%（保本微利）
- **约束2**：政府补贴上限（单站每日：小型1000/中型1800/大型2600元）
- **约束3**：紧急救助公益免费，不计补贴

### 5.2 利润率公式

```
利润率 = (服务总利润 + 政府补贴 - 年运营成本总额) / 年运营成本总额 × 100%
```

### 5.3 可复用经验

- 政府补贴类问题要注意补贴上限和补贴条件
- 保本微利约束是关键，定价不能太高也不能太低
- 价格满意度是满意度的一部分，定价降低会提高满意度但降低利润

## 六、灵敏度分析方法论

### 6.1 参数变化清单

| 参数 | 基线值 | 变化值 |
|------|--------|--------|
| 老人年增长率 | 7% | 8% |
| 自理→半失能转移概率 | 原值 | 5.5% |
| 半失能→失能转移概率 | 原值 | 9.5% |
| 日固定管理成本 | 原值 | +20% |
| 总建设预算 | 120万 | 140万 |

### 6.2 三场景设计

- 场景A：基线场景
- 场景B：老人增长加快（需求增加）
- 场景C：成本上升+预算增加（双重变化）

### 6.3 对比指标

- 站点数量与位置
- 服务定价
- 政府补贴总额
- 覆盖率
- 满意度
- 利润率

### 6.4 可复用经验

- 灵敏度分析不要只改一个参数，要设计组合场景
- 对比指标要全面，包括决策变量和目标函数
- 鲁棒性评价：方案在参数变化下的稳定性

## 七、避坑指南

### 7.1 马尔可夫链的坑

- **问题**：转移概率矩阵的行和不为1
- **对策**：构建矩阵后验证每行和为1
- **问题**：出现负的老人数量
- **对策**：检查死亡率和转移概率的计算顺序

### 7.2 遗传算法的坑

- **问题**：GA结果不稳定，每次运行不同
- **对策**：固定随机种子，多次运行取最优
- **问题**：约束违反（超预算）
- **对策**：惩罚系数要足够大，或者用修复算子
- **问题**：早熟收敛
- **对策**：增加种群多样性，自适应变异概率

### 7.3 定价优化的坑

- **问题**：利润率计算错误
- **对策**：仔细核对公式，政府补贴要计入收入
- **问题**：补贴上限忽略
- **对策**：每个服务站单独计算补贴，不超过日上限

### 7.4 灵敏度分析的坑

- **问题**：只改参数不重新求解
- **对策**：每个场景都要从头跑Q1→Q2→Q3
- **问题**：对比指标不全面
- **对策**：建立完整的对比表格，包括所有关键指标
