# Q2 双目标 Pareto GA 重写 — 设计规格

## 目标

用双目标非支配排序遗传算法（NSGA-II风格），从零重写问题二的求解，输出覆盖率-满意度的完整 Pareto 前沿。

## 核心修改（相比旧代码）

### 1. 覆盖率定义修正

| 旧（错误） | 新（正确） |
|-----------|-----------|
| 小区1000m内有任意站点→全部老人"覆盖" | 老人被分配到具体站点+站点有容量服务→计入覆盖 |
| 空站不影响覆盖率 | 空站=18万白花，拉低其他站预算，自然淘汰 |
| `cov = sum(E[covered]) / total` | 容量不足按比例削减后，实际服务人数/总人数 |

### 2. S2 满意度：阶跃→连续线性插值

```
u ≤ 0.60: S2 = 1.00
0.60 < u ≤ 0.75: S2 = 1.00 → 0.93 (线性)
0.75 < u ≤ 0.85: S2 = 0.93 → 0.85 (线性)
0.85 < u ≤ 0.95: S2 = 0.85 → 0.72 (线性)
u > 0.95: S2 = 0.72 → 0.50 (线性)
```

**理由**：阶跃函数是固定点迭代不收敛的根因。连续函数保证收敛到唯一均衡。

### 3. 固定点迭代：去掉阻尼

连续S2下直接重复"分配→算利用率→分配→..."直到max(|Δu|) < 1e-6。

### 4. 目标函数：两个独立目标

- **目标1（最大化）**：覆盖率 C = 实际服务老人数 / 总老人数
- **目标2（最大化）**：满意度 S = Σ(E_i × S_i) / Σ(E_i)，仅对实际被服务的小区

不再使用加权求和 0.6×C+0.4×S。

## 算法设计

### 编码
```
x = [x_A, x_B, ..., x_J],  x_i ∈ {0,1,2,3}
0=不建站, 1=小型(18万,1000人/日), 2=中型(32万,2000), 3=大型(45万,3000)
```

### 约束
- 总建设成本 ≤ 120万
- 老人只能分配到1000m内的站点
- 每个站点服务量 ≤ 其容量（超出按比例削减）

### 非支配排序
1. 对每个个体计算两个目标值 (C, S)
2. Fast Non-Dominated Sort：将种群分为层 F1, F2, F3...
3. F1 = Pareto前沿（没有任何个体在两个目标上同时优于它们）

### 拥挤距离
同一层内按每个目标排序，计算相邻个体的归一化距离之和。
层内选择时，拥挤距离大者优先（保持前沿均匀分布）。

### 选择算子
锦标赛选择(k=5)：
- A支配B → A胜
- 互不支配 → 拥挤距离大者胜

### 交叉
单点交叉 p_c=0.8，和旧代码一致。

### 变异
随机选一个基因位重新取随机值 0-3，p_m=0.15。

### 预算修复
超出120万时随机降级或移除站点，直到可行。

### 精英保留
按 Pareto 层号和拥挤距离排序，保留前 15 个进入下一代。

### 参数
- 种群大小：200
- 代数：150
- 精英数：15
- 锦标赛 k：5
- 交叉率：0.8
- 变异率：0.15
- 独立运行：5次，合并所有运行的非支配个体

## 输出

1. **Pareto 前沿数据**：每个非支配解的配置、成本、覆盖率、满意度
2. **Pareto 前沿图**：散点图（X=覆盖率, Y=满意度）
3. **推荐方案**：TOPSIS 从 Pareto 前沿中选折中解

## 正确性验证

1. Pareto 前沿上覆盖率 ≥ 0 且 ≤ 1，满意度同
2. 覆盖率随站点数增加单调不减
3. 前沿上存在覆盖率=100%的解
4. 所有站点在均衡分配中都有非零分配（无空站）
5. 预算约束严格满足
