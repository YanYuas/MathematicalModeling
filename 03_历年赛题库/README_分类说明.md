## 文件命名规范

- **赛题**：`年份+题号_赛题.扩展名`
  - 例：`2018A题_赛题.docx`、`2025A题_沙漠光伏电站集热管道_课件版.pdf`
- **附件**：`附件序号_内容说明.扩展名`
  - 例：`附件1_123家有信贷记录企业数据.xlsx`
- **优秀论文**：`年份+题号_组别_论文主题.扩展名`（扫描版jpg保留原始编号）
- **分析/评述**：`年份+题号_类型_主讲人.扩展名`
  - 例：`2020B题_真题分析_穿越沙漠.pptx`、`2020B题_赛题评述_谈之奕.pdf`
- **校赛题**：`题号_题目简称/` 子目录

## 后续添加规则

- 校赛题：在 `校赛/` 下建 `第N次模拟_日期范围/` 目录，题目建 `题号_题目简称/` 子目录
