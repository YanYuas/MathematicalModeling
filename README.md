# MathematicalModeling

本人是数学与应用数学专业本科生，聚焦数学建模与 AIGC 技术的融合实践。本仓库沉淀了我在课程学习、学科竞赛与 AIGC 实训中的核心产出，涵盖经典算法模板、题型思路拆解、历年真题题解、完整实战项目，并特别整理了 AIGC 辅助建模的 Prompt 模板、工具指南与落地案例，主打学生向、实战化、开箱即用。 本仓库同时也是「数智稷下」技术交流圈的配套资源库，欢迎同好交流指正。
