## 文件命名规范

- **课件**：`主题_主讲人_日期_类型.扩展名`
  - 例：`优化模型概述_卢鹏_7.11课件.pdf`
- **真题**：`年份+题号_题目简称_类型.扩展名`
  - 例：`2024A题_板凳龙_赛题.pdf`
- **优秀论文**：`年份+题号_组别_论文主题.扩展名`
  - 例：`2024A题_A114_板凳龙运动模型与优化.pdf`
- **附件**：`附件序号_内容说明.扩展名`
  - 例：`附件1_123家有信贷记录企业数据.xlsx`
- **讲座**：`主题_主讲人_日期.扩展名`
  - 例：`AI辅助数学建模_杨咏_11.23培训.pdf`
